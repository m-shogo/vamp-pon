# Sprite Size Guide（素材サイズ規定）

ドット絵素材の基本サイズと描き方。正本のサイズは `src/game/assets/assetManifest.ts`。
論理解像度 390x844（スマホ縦）で潰れず、夜の背景の上で見えることが最優先。

---

## 1. 基本サイズ（px / 透過PNG）

| 要素 | サイズ | 備考 |
|---|---|---|
| ユイ | 32x32 | idle / move（move は任意） |
| 敵 小（インク影/紙くず） | 24x24 | |
| 敵 普通（標識/カプセル/もや） | 24x24 | |
| エリート（黒ラベル） | 32x32 | |
| 記憶の欠片 | 12x12 | 10〜12px |
| 回復（包帯紙） | 14x14 | 12〜14px |
| カプセル | 16x16 | |
| レアアイテム4種 | 16x16 | |
| 通常武器の弾 | 8〜16px | 横長は 16x8 等 |
| 進化/覚醒武器の弾 | 12〜24px | name_line等は横長 24x12 |
| 範囲タイル（インク/街灯/夜明け） | 64x64 / 128x128 | 中心から円形に減衰 |
| 背景タイル | 128x128 | 繰り返し可能なシームレス |
| UIアイコン | 16x16 / 24x24 | |
| UIカード紙 | 320x144 | 実装のカード寸法に合わせる |

実装側は `setDisplaySize()` で表示サイズに合わせるため、**素材は等倍ドットで作る**。

---

## 2. ドット密度・描き方

```txt
1ドット=1px で描く。中間サイズで描いて縮小しない（潰れる）。
小物（欠片/弾）は 12〜16px に意味を1つだけ込める（盛らない）。
スマホで 2〜3倍表示される前提。細すぎる1pxラインは消える。
```

## 3. stroke（縁取り）

```txt
基本: 1px の暗い縁を付けて背景から浮かせる（黒インク影は縁が同化しないよう少し明るい紫縁）。
ユイ/敵: 輪郭が読めること優先。縁なしのベタ塗りは夜背景で消える。
```

## 4. 色数

```txt
1スプライト 4〜8色程度に抑える（絵本風・統一感）。
パレットは docs/visual-direction.md の三色構成（藍紫 / 暖色 / 古紙）に従う。
共有パレットは public/assets/palettes に置く（.gpl 等）。
```

## 5. アニメーション

```txt
MVPは静止画でよい。
動かすなら 2〜4フレームの軽い揺れ（ユイの呼吸、もやのゆらぎ）。
スプライトシート化は public/assets/atlases に置き、後で atlas 対応を追加。
```

## 6. 透過・2x/3x

```txt
背景は不透明、それ以外は透過PNG。
2x/3x 表示でにじまないよう、Phaser 側は NEAREST フィルタ前提（ドットを保つ）。
※ 画像導入時に scene 側で texture の filter を NEAREST に設定する想定。
```

## 7. 背景の上で見えるコントラスト

```txt
夜背景 #2a2747 の上で、
  欠片/灯り = 暖色で明るく（最も目立つ）
  ユイ = 古紙クリーム + 暖色の灯りで浮かせる
  敵（黒インク） = 背景より暗いが、白い目と少し明るい縁で位置が分かる
黒インク影と背景が同化しないよう、敵には必ず白目 or 明るい縁を残す。
範囲（インク染み）は半透明で、上に乗る敵が消えない濃さに。
```

## 8. 禁止

```txt
ネオン / 高彩度シアンの発光
リアル質感 / アニメ塗りの厚塗り
文字・ロゴ入り
ただのアイコン（モチーフが伝わらない記号）
1スプライトに要素を盛りすぎる
```

# Implementation-ready Canon Lock

## 目的

実装に入る前に、Vamp Ponの世界観・物語・システム解釈を固定する。

この文書は、実装者が迷わないための最終ロック。

---

# 1. P1で作るもの

P1の目的は、世界観を全部実装することではない。

```txt
ユイを動かす
黒インクの影が追ってくる
夜の鉛筆が自動攻撃する
記憶の欠片を拾う
レベルアップする
朝まで残る/夜にのまれる
```

これだけでよい。

---

# 3. 実装で守る世界法則

```txt
黒インク = 間違った意味を固定するもの
欠片 = 固定から剥がれた意味片
朝 = その夜にほどけた意味の確定処理
ゲームオーバー = その夜の仮接続が黒インクに固定し直されること
再戦 = 未確定ページを別の読み順で開くこと
```

P1では全部説明しない。

ただし、表示文・命名・演出がこの法則と矛盾しないようにする。

# 9. 後から拡張できる余地

P1では使わないが、データ設計で邪魔しない。

```txt
bond

characterRole
loreTags
pageId
bundleId
canonSeedId
```

ただし、P1に無理に入れない。

---

# 10. 実装判断

何か迷ったら、以下で判断する。

```txt
気持ちよく遊べるか
P1に必要か
現行正史と矛盾しないか
後から拡張できるか
説明しすぎていないか
```

この5つを満たせば採用。

---

# 11. 最重要

P1は、物語を全部語る場所ではない。

```txt
触って気持ちいい。
拾って気持ちいい。
朝まで残りたい。
```

これを最優先する。

世界観は、文言・小物・影の挙動でにじませる。

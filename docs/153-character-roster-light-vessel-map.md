# 153. Character Roster Light Vessel Map

This document remaps the existing 20 character seeds through the new light-vessel canon.

It does not make all 20 characters implementation targets.
It is a story and design map so future characters feel planned from the start.

Source roster: `docs/126-character-seed-roster-20.md`.
Canon source: `docs/147-light-lineage-and-memory-vessels.md` and `docs/148-protagonist-relationship-web.md`.

## Rules

- Every major character has a unique light vessel or vessel-like focus.
- Similar vessels imply relation.
- Every major character has met Yui at least once, directly or indirectly.
- Every character keeps one blank space.
- First action comes from the vessel.
- Memory items come from the vessel context.
- Under P1, only Yui is required. Others can appear as traces.

## Fire family note

Yui and Tomori must not both be normal lantern characters.
Yui keeps the full lantern.
Tomori should use a repaired lantern part, lamp tool, or fire maintenance object.
If a future torch character appears, the relation to Yui's fire line is mandatory.

## Relationship web rule

Every character should connect in two directions:

- one link to Yui
- one link to another non-Yui character

This keeps Yui central without making her the only important person.

## P1 traces

P1 should not introduce all characters.
Allowed traces:

- Yui only as playable
- Asa handwriting seed
- Tomori repaired-lantern trace
- Michiru ticket trace
- Nagi box trace
- one or two unnamed background traces from Circle 10
- no Shadow 5 explanation, only black-fold or blank-card traces

## Production use

Before turning any seed into a visual asset, fill:

- vessel
- lineage
- first action
- memory item set
- Yui link
- non-Yui link
- blank space
- A/B/C design plan

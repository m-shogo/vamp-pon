# 1. 作品の人物トーン

ヨルノシルベの世界は暗い。

しかし、人間まで全員暗くしないし、全員を無理に明るくもしない。

- 明るい
- ネガティブ
- 無口
- 強気
- 怖がり
- 子ども
- 渋い大人
- ぽっちゃり
- 眼鏡
- ギャル
- お嬢様

などが自然に同居する。

**全員がその人らしいまま成長する。**

例:

- ネガティブな人 → ネガティブなまま人を頼れる
- 無口な人 → 無口なまま必要な時に名前を呼べる
- 明るい人 → 明るいまま自分の弱音も出せる
- 強い人 → 人に任せられる
- 優しい人 → 自分も助けてもらえる

# 4. Strong relationships

## ユイ × アサ — 主人公ともう一人の主人公

**USER DIRECTION: 恋愛なし。**

- ユイは待てる
- アサは先へ走る
- お互いの長所に救われる
- 本気で喧嘩できる
- 同じ考えになる必要はない
- 違うまま相手を選べるようになる

狙う強度は、片方がいなければ今の自分になっていないほどのバディ / ライバル友情。

## リツ × コヨリ — 兄妹

**CANON: 恋愛なし。**

- 兄が妹を守る一方向にしない
- 妹も兄を救う
- 兄は任せることを覚える
- 妹は守られるだけの役から出る

同じりょうけん座の二頭が兄妹伏線にもなる。

## ユイ × クロオリ — 取り戻す / 閉じて守る

思想的ライバル。

ユイだけが正しい、クロオリだけが間違い、にはしない。

## ユイ × トモリ — 獅子座が二人

同じ獅子座は意図的な伏線。

候補:

- 親族
- 遠い血縁
- 火の系譜
- ランタン継承
- shared memory fire

真相はまだLOCKしない。

# 7. Bond / Support

Main Gameでは仲間をSupportとして呼べる方向。

```txt
一緒に戦う
↓
Bondが育つ
↓
戦闘連携が強くなる
↓
呼び方 / 敬語 / 日常も変わる
```

**一次報酬はGameplay。情報は副作用。**

読む人は読む。
読まない人は「強くなった、ラッキー」でよい。

また:

- 仲良し = 強い
- 不仲 = 弱い

だけにはしない。

対立ペアはhigh-risk / high-upsideな連携へ育てる余地がある。

詳細: `docs/BOND.md`

# 9. 日常で人物を好きにする

日常回は全部明るくしない。

- 楽しい食事
- 静かな雨
- 喧嘩翌日
- 掃除
- 寝坊
- 眠れない夜
- 買い物
- 修理
- 手紙
- 星獣の小事件

何も起きない回も大切。

## 例 — 喧嘩した次の日

ユイとアサはほぼ話さない。

でも:

- アサはユイのカップに名前を書く
- ユイはアサの忘れ物を机へ戻す

その回で仲直りしなくてもよい。

## 例 — 星獣が帰ってこない

ユイの子獅子を皆で探す。

最後にトモリの若獅子の隣で寝ている。

楽しい日常でありながら、同じ獅子座の伏線になる。

詳細: `docs/CHARACTER-LIFE-AND-SPEECH.md`

# 10. 人物の謎

人物はそれぞれCharacter Mysteryを持てる。

例:

- ユイはなぜ記憶を分けた？
- ユイとトモリはなぜ獅子座が同じ？
- トモリはなぜユイのランタンを知る？
- アサとユイ、先に名前をつけたのはどちら？
- Shadowは本当に「消す敵」なのか？
- 星獣は人間より先に何を覚えている？

人物謎を全部解かなくてもMain Storyはクリアできる。

好きになったplayerがBond / 灯録 / 日常から深く読める。

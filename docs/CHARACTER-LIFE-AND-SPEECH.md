# 1. 日常は「明るい回」だけではない

ヨルノシルベの日常会は、暗い世界の休憩時間。

使える温度:

- よく笑う
- 静か
- 気まずい
- ネガティブ
- 喧嘩中
- 仲直り前
- 疲れている
- 誰か一人だけ元気
- 星獣だけが騒がしい
- 何も起きない

暗いキャラを日常回だから明るくしない。
明るいキャラをギャグ装置にしない。

# 2. 日常イベントの棚

## 食事

関係性が最も自然に出る。

見るポイント:

- 食べる速度
- 量
- 好き嫌い
- 誰へ取り分けるか
- 誰の隣へ座るか
- 自分の分を忘れるか
- 好物を半分渡せるか
- 星獣が盗み食いするか

## 掃除 / 片付け

- 道具の位置にこだわる
- 人の物を勝手に触らない
- 思い出の紙を見つけて手が止まる
- 捨てる / 残すの価値観が出る

## 雨

静かな人物回に向く。

- 雨音が好き
- 外へ出られず苛立つ
- 紙や工具が濡れるのを心配する
- 涙が分からなくなる
- 星獣の反応を見る

## 眠れない夜

本音を説明台詞で言わせず、何をしているかで見せる。

- ランタンを触る
- 靴紐を結び直す
- 地図を折る
- 工具を磨く
- 手紙を書くが出さない
- 眼鏡を拭く
- 星を測る
- 紙を繕う

## 朝

キャラの成長を日常へ返す場所。

性格が変わるのではなく、小さな行動が変わる。

## 買い物 / 仕事 / 移動

キャラの能力を戦闘以外で見せる。

## 星獣だけの小事件

- いなくなる
- 仲の悪い星獣同士が一緒に寝る
- 主人より先に誰かへ懐く
- 同じ星座の星獣だけ反応が似る

人物伏線を重く説明せず置ける。

# 3. 1キャラに持たせる生活レイヤー

Current 21の各人物は、詳細profileに加えて会話制作時に次を意識する。

```txt
好きな食べ物
嫌い / 苦手
趣味
小さな癖
朝の行動
眠れない時にすること
怒り方
よくつく小さな嘘
人を助ける時の行動
助けてほしい時に出るサイン
```

全項目をUIへ表示する必要はない。
制作側が人物を理解するための裏レイヤーとして持ってよい。

---

# 4. 「嘘」は弱さを見せる

嘘 = 悪意に限定しない。

例:

- 「大丈夫」→ 怖い
- 「平気」→ かなり疲れている
- 「迷ってない」→ 帰り道が見えない
- 「直せる」→ 直らないかもしれないと分かっている
- 「別にいらない」→ 本当は助けてほしい

Bondが高くなるほど、同じ嘘をつかなくなる / 嘘の後に一言本音が増える、という変化が使える。

---

# 5. 怒り方で本質を見せる

全員が声を荒げない。

怒り方の種類:

- 静かに言い切る
- 早口になる
- 無言になる
- 作業音が大きくなる
- 丁寧語が硬くなる
- 笑わなくなる
- 距離を取る
- 普段より名前をはっきり呼ぶ

その人物が**何を粗末にされた時に怒るか**を大切にする。

---

# 6. 呼び方 / 敬語は関係性のUI

Bond Levelが上がれば全員呼び捨て、にはしない。

変化軸:

- さん / ちゃん / 呼び捨て
- 呼び方は同じだが名前を呼ぶ回数が増える
- 敬語が少し抜ける
- 文が短くなる
- 命令がお願いになる
- 弱音が出る
- 冗談を言える
- 相手へ任せる
- 名前を初めて自分から呼ぶ

## 代表パターン

### ユイ型

呼称そのものが少し変わる。

`アサちゃん → アサ`

### アサ型

呼称はほぼ変わらない。

`先に行く → 一緒に行く`

### 無口型

名前を呼ぶこと自体が親密イベント。

### お嬢様型

礼儀は残る。
完璧な敬語から、自然な短い言葉が混ざる。

### ゲン型

呼び名は変わらない。
自分の失敗談を話せることが親密さ。

### Shadow型

初期は役割 / 距離ある呼称。
信頼後、本名を使うこと自体が変化になり得る。

# 7. 会話の3レイヤー

各キャラの台詞は次を別に管理する。

## Base voice

通常時の語彙 / 長さ / テンポ。

## Bond delta

仲良くなったことで変わる部分。

## Crisis delta

黒耀化、仲間の危機、終盤などでだけ崩れる部分。

親密になったから別人のように喋らせない。

---

# 8. 会話は情報解放の主目的ではない

Bond会話を見ること自体を強化作業にしない。

```txt
一緒に戦う
→ Bondが上がる
→ gameplay traitが強くなる
→ 副作用として新しい会話 / 呼び方 / 情報が出る
```

読む人は読む。
読まない人は性能が上がってラッキーでよい。

会話本文の読了を戦闘強化の条件にはしない。

---

# 9. 伏線を日常へ隠す

伏線を「謎の台詞」だけで置かない。

使える場所:

- 座る位置
- 食べ物を渡す相手
- 名前の呼び方
- 星獣同士の距離
- 道具の扱い
- 書き癖
- 誰が先に起きるか
- 誰が誰の忘れ物に気づくか
- 喧嘩していても無意識にしてしまう世話

初見では日常。
後から見ると意味がある、を狙う。

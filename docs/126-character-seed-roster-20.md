# Character Seed Roster 20

## 目的

Vamp Ponのキャラクターを、将来増やしても破綻しないように20人分のSeedとして設計する。

これは実装確定ではない。

```txt
今すぐ全員を出すためではなく、後付け感をなくすための貯金。
```

---

# 1. キャラSeedの型

各キャラは以下で管理する。

```txt
名前
関係語Seed
役割
痛み
温かい反転
初期武器/アイテム
プレイ感
初出Seed
回収タイミング
```

# 5. 20人を全部出す必要はない

この台帳は、実装ノルマではない。

```txt
出すキャラより、最初から存在していた感を作るための貯金。
```

初期実装はユイだけでよい。

ただし、背景や一言Seedで他の存在を薄く置く。

---

# 6. 使い方

## Prototype 1

```txt
ユイだけ
アサの筆跡Seedだけ
ランタン修理跡だけ
```

## Full Season 1

```txt
Core 5を回収
Circle 10は一言Seedだけ
Shadow 5は痕跡だけ
```

## 2 / Future

```txt
Circle 10やShadow 5から選んで本格登場
```

# 7. 最重要

20人を出すことが目的ではない。

```txt
名前を出す前から、誰かがいた気配を出す。
```

これが後付け感を防ぐ。

# Pixel Art Generation / Production Prompts

ドット絵のプロ / Aseprite作業者 / 外部画像生成サイト / MCP に渡す素材仕様。
**生成サイトの出力はラフ用**。最終素材はドット絵ツールで仕上げる。
サイズ正本は `src/game/assets/assetManifest.ts`、規定は [sprite-size-guide.md](sprite-size-guide.md)。

---

## 共通指示（すべてのプロンプトに含める）

```txt
スタイル: 紙片・絵本風のドット絵（pixel art）。やさしく、寂しく、少し切ない、でも温かい。
世界観: 夜の街 / 地図帳 / 忘れ物 / 黒インク / 小さな灯り / 朝に向かう。
配色: 深い藍紫の夜 (#2a2747) を背景に置いても見える。暖色の灯り (#ffce7a) と
      古紙クリーム (#f3e9cf)、欠片の金 (#ffd45e) をアクセントに。色数は控えめ(4〜8色)。
背景: 透過PNG（背景タイルを除く）。等倍ドット。1px縁取りで背景から浮かせる。
用途: スマホ縦 390x844 の小さな画面で視認できること。背景の上で潰れない。
```

## 禁止（すべてのプロンプトに含める）

```txt
ネオン / 魔法陣 / SFレーザー・ビーム / ギラギラした発光 / アニメ爆発
リアルすぎる描写 / アニメ塗りの厚塗り / 文字・ロゴ入り / ただのアイコン記号
光量だけで強さを出す表現
```

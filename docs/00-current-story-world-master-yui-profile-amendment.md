# 3. Favorite foods

Status: `DECIDED`

ユイの代表的な好きな食べ物は:

# **もんじゃ焼き**
# **たい焼き**
# **大判焼き**

旧 `favoriteFood: 焼きおにぎり` は**代表FavoriteからSUPERSEDED**。
焼きおにぎり自体を嫌いにする必要はないが、今後ユイのプロフィール / Character Book / Lorebook / daily-life sceneで「ユイの一番らしい食」を示す場合は上記3種を優先する。

## Food identity

### もんじゃ焼き

- 下町の鉄板を囲んで食べる**共有型Food**としてユイと相性が良い。
- 一人で完成品を受け取るより、皆で囲み、焼きながら喋る時間を含めて好き。
- ヨルノシルベのParty / intermissionで高価値。
- 「正しい焼き方講座」を延々する食通Characterにはしない。

### たい焼き

- 歩きながら / 誰かと寄り道しながら食べられる。
- 餡の好み、頭から食べるか尻尾から食べるか等を軽いCharacter会話に使える。
- 実在店の広告Characterにはしない。

### 大判焼き

- 日常的な甘味として好き。
- 地域で呼び名が変わるFoodなので、別地域 / 別Era Characterとの自然な会話ネタにできる。

Candidate dialogue engine:

```txt
Yui: 「大判焼き食べる？」
別地域Character: 「それ、○○って呼んでた。」
Yui: 「同じやつなのに名前違うんだ。」
```

この小ネタは、ヨルノシルベの:

> **同じものでも名前が違う / 名前が違っても同じものを指す**

という星座・identity Themeへ薄く響かせられる。

ただしFood名称差をMain Mysteryの説明装置にしない。

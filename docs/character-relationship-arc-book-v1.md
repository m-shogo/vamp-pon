# 0. Arcの5段階

各強関係は原則として次の5段階を持つ。

```txt
A. First read
   初対面 / 誤読 / 表面上の相性

B. Useful friction
   一緒に戦うと便利だが、考え方が噛み合わない

C. Failure / exposure
   片方の長所が過剰化し、連携が一度壊れる

D. Chosen trust
   相手を「理解したから同意する」のではなく、違いを知った上で任せる

E. Dawn proof
   大げさな友情宣言ではなく、初期なら出来なかった小さな行動が自然に出る
```

重要:

- Eで全員仲良し口調にしない
- 思想差は残ってよい
- 最大Bondでも呼び捨てにする必要はない
- 友情 / 兄妹 / ライバル / 師弟 / 恋愛を同じ演出へ揃えない
- 「過去に実は知り合いだった」で関係をショートカットしない
- Currentで一緒に過ごした時間を必ず途中に置く

# 1. ユイ × アサ — 速さと確認

Relationship type: **CURRENT strong buddy / non-romance**

## A. First read

アサはユイを「人のことを気にしすぎて遅い」と見る。
ユイはアサを「助けたい気持ちは分かるけど、聞く前に決める」と見る。

短い会話seed:

> アサ「名前、分かった。行くよ。」  
> ユイ「本人に聞いた？」  
> アサ「……今それ？」  
> ユイ「今だから。」

## B. Useful friction

戦闘では非常に相性がいい。

- アサが先行して敵群へ印を付ける
- ユイが散った記憶片とSupport位置をまとめ直す

ただしアサが先へ出すぎ、ユイが全部拾おうとして遅れる。

## C. Failure / exposure

アサが「名前を返せば救える」と急ぎ、対象がまだ名乗りたくない状況でmarkを固定する。
ユイは逆に、落ちた記憶を一つも残せず回収して危険へ入る。

互いに相手の欠点を責めるが、実際には**同じ“置いていきたくない”焦り**を別方向へ出している。

## D. Chosen trust

アサ:

> 「先に行く。……でも、決めるのは待つ。」

ユイ:

> 「拾える。……でも、今拾っていいか見る。」

Gameplay:

- アサの先行Assistがplayer速度から離れすぎなくなる
- ユイの吸引が重要対象を自動確定せず、保留対象を残せる

## E. Dawn proof

初期はアサが一人で先に立つ。
高Bondでは出発前、アサが何も言わず半歩だけ待つ。
ユイも「待って」と言わず並ぶ。

友情を説明しない。
**歩き出すタイミングが揃う**ことで見せる。

# 2. ユイ × クロオリ — 開く / 預かる

Relationship type: **CURRENT ideological rival / high-value mystery connection remains partially OPEN**

## A. First read

ユイ:

> 隠しているなら返して。

クロオリ:

> 返せば正しいとは限らない。

ユイから見るとクロオリは「奪う人」。
クロオリから見るとユイは「開ける準備を待てない人」。

## B. Useful friction

Pairは高出力だが不安定。

- ユイが記憶を引き寄せる
- クロオリが危険な記憶だけ閉じて一時保留する

低Bondでは互いに相手の処理へ干渉し、pickup loss / delayed releaseのriskが出るCandidate。

## C. Failure / exposure

ユイが「本人に返すため」と封を破る。
内容は悪ではないが、**まだ受け取る時ではなかった**。

逆にクロオリも「守るため」に閉じ続け、本人が自分から開ける機会まで奪う。

ここで善悪を決めない。

## D. Chosen trust

ユイ:

> 「預ける。でも、忘れたことにはしないで。」

クロオリ:

> 「開ける時は、君じゃなく本人に聞く。」

Main Mysteryに接続する「過去のユイ自身が何かを預けた」案はHIGH-VALUEのまま保持し、Human decision前に事実化しない。

## E. Dawn proof

クロオリが折った紙をユイへ渡す。
ユイはすぐ開かない。

> ユイ「いつ？」  
> クロオリ「分からない。」  
> ユイ「そっか。じゃあ持っとく。」

ユイが“開けない選択”を出来ることが成長証明。

# 3. ナギ × カナメ — 二つの守り

Relationship type: **CURRENT ideological mirror / unstable-to-coordinated defense**

## A. First read

ナギ:

> 「なんで傷つく前提なの。」

カナメ:

> 「閉じ込めて守ったことになるのか。」

互いに相手を自己犠牲 / 過保護だと思う。

## B. Useful friction

- ナギ = hazard seal / temporary safe storage
- カナメ = bodyguard / intercept

低Bondでは同じ攻撃へ二人とも防御を使ってしまい、次の攻撃に手段が残らない。

## C. Failure / exposure

カナメが全攻撃を引き受けて倒れる。
ナギは助けるためarenaごと閉じ、他の仲間の退路を狭める。

二人とも「守った」結果、party全体を危険にする。

## D. Chosen trust

役割を交互にする。

```txt
カナメが時間を稼ぐ
→ ナギが危険そのものを封じる
→ ナギの封印が切れる前にカナメが退路を守る
```

カナメ:

> 「次、お前。」

ナギ:

> 「分かってる。だから下がって。」

命令ではなく、互いの次の一手を前提にした会話へ変わる。

## E. Dawn proof

カナメが重い荷物を全部持とうとする。
ナギは止めず、一つだけ取る。

> 「それは私。」

カナメも返さない。

# 4. ミチル × トキ — 道を選ぶ / 道を測る

Relationship type: **CURRENT ideological mirror / route pair**

## A. First read

トキは「測定値がない道」を信用しない。
ミチルは「歩いてみないと分からない道」を切り捨てない。

> トキ「根拠は？」  
> ミチル「行けそう。」  
> トキ「それは根拠じゃない。」  
> ミチル「じゃあ一緒に確かめよう。」

## B. Useful friction

- トキが危険角度 / timingを測る
- ミチルがrouteを現場で組み替える

低Bondではトキの最適線にミチルが寄り道し、ミチルの improvisationをトキが補正しすぎる。

## C. Failure / exposure

トキの測定では「安全」だった道が、夜の時間層混在で成立しない。
ミチルの勘だけで選んだ道も、帰路を確保できず孤立する。

双方が自分の方法だけでは足りないと知る。

## D. Chosen trust

トキ:

> 「測れない部分がある。」

ミチル:

> 「じゃあ、そこから私が見る。」

Gameplay:

- measured safe lane + adaptive reroute
- Boss48の同じrouteを戻るattackに対する強pair Candidate

## E. Dawn proof

トキが地図へ正確な線を引いた後、最後の分岐だけ空白にする。

> 「ここは？」  
> 「歩いて決める。」

ミチルが笑って鉛筆を受け取る。

# 5. トモリ × ツムギ — 直す / 跡を残す

Relationship type: **CURRENT craft mirror / quiet high-affinity pair**

## A. First read

トモリは壊れた箇所を見ると直したくなる。
ツムギは「直さない部分」にも意味を見る。

> トモリ「ここも塞げる。」  
> ツムギ「そこは残したい。」  
> トモリ「壊れてるぞ。」  
> ツムギ「壊れた場所だから。」

## B. Useful friction

二人ともrepair系だが目的が違う。

- トモリ = function recovery
- ツムギ = continuity / trace preservation

## C. Failure / exposure

トモリが完全修復し、元の傷に残っていた誰かの手直し跡を消す。
ツムギは逆に痕跡を守りすぎ、危険な破損まで残す。

## D. Chosen trust

repair前に二人で決める。

```txt
動かすために直す場所
記録として残す場所
将来また直せるよう仮留めする場所
```

Gameplayではrepair量最大化ではなく、状態を選ぶ能力へ成長。

## E. Dawn proof

トモリが直したランタンに、小さな継ぎ目が一つ残っている。

> ツムギ「そこ、直せたでしょ。」  
> トモリ「知ってる。」

説明しない。

# 6. リツ × コヨリ — 守る兄 / 救う妹

Relationship type: **CURRENT sibling / non-romance / stable bond**

## A. First read

リツは何でも先に人数を数え、コヨリを守る側へ置く。
コヨリは守られることを嫌ってはいないが、「できない人」扱いは嫌う。

## B. Useful friction

- リツがdamage / resourceを分ける
- コヨリが小さい対象 / 名札 / 星獣signalを見つける

## C. Failure / exposure

リツがコヨリを安全地帯へ送り、自分だけ危険へ残る。
結果、コヨリにしか見つけられないroute / 小さい手掛かりを失う。

コヨリ:

> 「守ったから失敗した、じゃないよ。」  
> 「一緒に行かせなかったから。」

兄を悪人にしない。

## D. Chosen trust

リツが「大丈夫か？」ではなく:

> 「どっちやる？」

と役割を選ばせる。

Gameplay:

- sibling warningだけでなく、交互救援 / role selectionへ

## E. Dawn proof

食べ物を半分にするとき、リツが先に切らない。
ナイフをコヨリへ渡す。

少し不均等になる。
リツは直さない。

# 7. セン × コヨリ — 教える人 / ruleを作る子ども

Relationship type: **CURRENT night-born friendship / teacher-role inversion**

## A. First read

センはコヨリの遊びへ正しいruleを足したくなる。
コヨリは成立していないruleでも遊び始める。

## B. Useful friction

センが説明し、コヨリが例外を見つける。

## C. Failure / exposure

センが全部説明してしまい、コヨリが自分で気づく瞬間を奪う。
コヨリは説明を聞かず危険へ触る。

## D. Chosen trust

セン:

> 「答えじゃなくて、ヒント一個でいい？」

コヨリ:

> 「うん。で、センも一回まちがえて。」

Gameplayではguide lineが強制経路ではなく、playerが使う / 外すを選べる補助へ。

## E. Dawn proof

コヨリが新しい遊びを説明する。
センは口を挟まず最後まで聞く。

> 「……次のrule、教えて。」

# 8. ユウビ × トバリ — 届ける時 / 門を開ける時

Relationship type: **CURRENT functional friendship / timing pair**

## A. First read

ユウビは「宛先まで届ける」が仕事。
トバリは「帰れる状態まで残す」が仕事。

## B. Useful friction

- ユウビ = target delivery
- トバリ = route / gate control

## C. Failure / exposure

ユウビが急いで届けた物が、相手にはまだ重すぎる。
トバリは安全のため門を閉じ、届ける機会そのものを失う。

## D. Chosen trust

二人は「行けるか」ではなく:

> **今、行くべきか / 後で戻れるか**

をセットで考える。

Gameplay Candidate:

- delayed delivery stash
- return-gate recall
- heal / pickupを今使うか保留するpair mechanic

## E. Dawn proof

ユウビが封筒を持って来る。
トバリが門を開ける。

> トバリ「帰りは？」  
> ユウビ「今日は、泊まってく。」

仕事以外の選択をする小さな親密さ。

# 9. マドカ × レン — 気づく / 伝える

Relationship type: **CURRENT + reserve analytical pair**

## A. First read

レンは違いを見つける。
マドカは遠くの変化を見る。
二人とも慎重なので、情報がpartyへ届くのが遅い。

## B. Useful friction

レン:

> 「昨日と違う。」

マドカ:

> 「遠くでも同じ変化がある。」

一緒だと年代差 / mimic / boss phaseを早く見抜ける。

## C. Failure / exposure

二人とも確証を待ち、warningが遅れる。

ここで「慎重 = 悪」にしない。
誤報riskも実在する。

## D. Chosen trust

情報を二種類に分ける。

```txt
確定
未確定だが共有価値あり
```

マドカ:

> 「見えた。確定じゃない。でも言う。」

レン:

> 「差はある。意味はまだ分からない。」

## E. Dawn proof

レンが違和感を口にした瞬間、マドカがすぐ窓を見る。
以前のように「本当に？」と聞かない。

# 10. シロ × ツムギ — 未分類 / 未完

Relationship type: **CURRENT quiet conceptual friendship**

## A. First read

シロは分からないものを分類せず保存する。
ツムギは終わっていないものを終わらせず残す。

似ているようで:

- シロ = 意味が分からない
- ツムギ = 続きがある

と理由が違う。

## B. Useful friction

収集物を捨てないのでarchive系runでは強い。
ただし二人とも保留しすぎる。

## C. Failure / exposure

「まだ」を重ねすぎ、選ぶべき時にも決められない。

## D. Chosen trust

保留へ期限ではなく**再訪条件**を付ける。

> シロ「分からない。」  
> ツムギ「じゃあ次に何が分かったら戻る？」

## E. Dawn proof

ツムギがノートの最後を空白にする。
シロがそこへ分類番号を振らない。

ネム:

トキ:

と予言役を降りる。

ネムの夢日記の横に、トキが小さく日付だけ書く。
訂正しない。

# 12. ゲン × ミチル — 昔の道 / 今の道

Relationship type: **CURRENT intergenerational friendship / time-layer candidate**

## A. First read

ゲン:

> 「ここを真っ直ぐだ。」

ミチル:

> 「道、ないよ。」

## B. Useful friction

ゲンの古い地理知識とミチルの現在route senseを重ねる。

## C. Failure / exposure

ゲンが古い道へ固執し、現状の危険を見落とす。

地図を一枚に統合しない。

```txt
昔あった道
今歩ける道
夜でだけ繋がる道
```

を別線で残す。

## E. Dawn proof

ゲンが近道を教える代わりに:

> 「今日は、お前の道で行くか。」

と言う。

# 13. Ensemble arcs — 3人以上でしか出ない関係

Pairだけで世界を作らない。

## 13.1 ユイ / アサ / クロオリ — 「本人のため」を誰が決めるか

- ユイ: 戻したい
- アサ: 名前を返したい
- クロオリ: まだ開けたくないものを守りたい

三人で同じ記憶を扱うと、善意同士が衝突する。
最終的な答えは:

> **本人へ選択肢を返す。**

ただしMain Mysteryの答えそのものにはしない。

## 13.2 ナギ / カナメ / リツ / コヨリ — 守る側を固定しない

- ナギ = 危険を閉じる
- カナメ = 危険を受ける
- リツ = 分けて守る
- コヨリ = 小さい手掛かり / 他者救援

「大人 / 強い人だけが守る」を崩すgroup。

## 13.3 ミチル / トキ / ゲン / マドカ / レン — 夜の時間層を理解する班

役割を分ける。

- ミチル = 歩けるroute
- トキ = measurement
- ゲン = old memory
- マドカ = distant witness
- レン = discrepancy

誰か一人を設定解説役にしない。
5人の異なる証拠が揃って初めて「夜が一つの年代ではない」と見えてくる。

## 13.4 トモリ / ツムギ / ハナ / シロ — 残すとは何か

- トモリ = 使えるよう直す
- ツムギ = 傷を残す
- ハナ = 保存する
- シロ = 分からなくても捨てない

同じold objectへ四人が別の扱いを提案できる。
どれかを常に正解にしない。

# 15. 関係を人気へつなげる日常反復

大イベントだけでは好きにならない。
各strong relationへ**3回以上使える小さな反復記号**を持たせる。

| Relation | 初期 | 中盤 | 高Bond |
| --- | --- | --- | --- |
| ユイ×アサ | アサが先に歩く | ユイが「待って」と言う | 言わずに歩幅が揃う |
| ナギ×カナメ | 同じ危険を二重防御 | どちらが守るか揉める | 「次、お前」で交代 |
| ミチル×トキ | 勘 vs 数字 | 地図へ両方書く | 最後の分岐だけ一緒に選ぶ |
| トモリ×ツムギ | 全修理 vs 痕跡保存 | repair前に相談 | 意図的に一つ継ぎ目を残す |
| リツ×コヨリ | 兄が全部分ける | 妹が役割を要求 | コヨリへ選択を渡す |
| マドカ×レン | 二人とも言わない | 未確定warningを試す | 一人が言えばもう一人が動く |
| ユウビ×トバリ | 宛先 / 門だけ確認 | timingを相談 | 用事がなくても同じ場所にいる |

この「同じ行動の意味が変わる」反復を優先する。

# 16. Conflict rule — 喧嘩を人格破壊にしない

良い衝突:

- 両者の長所から発生する
- どちらにも守りたいものがある
- 相手を傷つける目的ではない
- 後で片方だけ全面謝罪して終わらない
- 成長後も価値観差が少し残る

避ける:

- 突然怒鳴る
- 秘密を話せば全部解決
- 誤解を5分説明すれば終わる
- 仲直り後に人格まで明るくなる
- 恋愛候補だけ特別に深く、友情を薄くする

---

# 17. Black Youka rescue rule

黒耀化救出を「相手が正しい説教をする」イベントにしない。

有効な救出:

```txt
普段の関係で覚えた癖
↓
黒耀化中も残っている
↓
相手がその癖を利用して接続する
↓
本人自身が選び直す
```

例:

- アサが暴走して全対象へ名前を固定 → ユイが「名前を消す」のではなく、本人にもう一度何と呼ばれたいか聞く余地を作る
- カナメが全damageを引受 → ナギが本人ごと閉じず、攻撃だけを短時間封じて「下がる」選択肢を作る
- トキが全routeを測定固定 → ミチルが計測外の細い道を示すが、無理に引っ張らず選ばせる

救った側が「真の答え」を持つのではない。
**本人が戻るための一手を作る。**

---

# 18. Enemy pressureとの接続

関係arcは会話専用にしない。
EnemyはPairの弱点をmechanicで突ける。

例:

| Relation | Pressure enemy motif | 何を試されるか |
| --- | --- | --- |
| ユイ×アサ | 名札 / 持ち主のない名前 | 名前 / 所有者を急いで確定しない |
| ユイ×クロオリ | 余白 / 黒折 / Boss47系 | 開く / 閉じるtiming |
| ナギ×カナメ | 月箱 / 墨腕 | hazard sealとinterceptの使い分け |
| ミチル×トキ | 方位 / 迷針 / Boss48 | measured routeを途中で捨てられるか |
| トモリ×ツムギ | 継ぎ目 / 糸 / 余白枠 | repair対象と残す傷を選ぶ |
| リツ×コヨリ | 鈴 / 犬切符 | protection対象を固定しすぎない |
| マドカ×レン | レンズ / 古写真 | 差分に気づき、未確定でも共有する |

Enemyは関係の正解を説明しない。
**戦闘で同じ問いをもう一度させる。**

# 19. Production checklist

Pair / group sceneを追加する前に確認する。

- [ ] 二人の既存長所から始まっている
- [ ] 新しい悲劇を盛らないと成立しない関係ではない
- [ ] 初期と高Bondで同じ人物に見える
- [ ] 関係変化が小さな行動でも見える
- [ ] Gameplayへ1つ以上返せる
- [ ] Enemy / Stage mechanicへ1つ以上接続できる
- [ ] 相手へ同意することを成長にしていない
- [ ] Currentで一緒に過ごした経験がある
- [ ] 血縁 / 過去の旧知を増やしすぎていない
- [ ] Romanceなら友情より自動的に上位へしない
- [ ] Future15はCurrent21へ昇格させていない
- [ ] Main Mystery候補を台詞で確定していない

# 20. 一文

> **ヨルノシルベの関係は、秘密を知ったから深まるのではない。一緒に失敗し、相手のやり方が自分と違うと知り、それでも次の一手を任せられるようになった時に深まる。**

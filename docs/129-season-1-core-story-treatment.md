# Season 1 Core Story Treatment

## 目的

Vamp Pon Season 1 の物語の心臓を定義する。

キャラ表や設定だけではなく、プレイヤーが最後に何を感じるか、どの順番で驚き、悲しみ、楽しさ、恋愛、友情、感動が出るかを決める。

---

# 1. ユーザーの好みから見えたもの

ユーザーが好きな作品群から見える好みは、以下。

```txt
仲間がいる
でも全員が何かを隠している
楽しい日常が後から泣ける意味を持つ
恋愛・友情・家族愛が混ざっている
見えていた小物の意味が終盤で反転する
主人公が孤独ではなかったと分かる
選択には代償がある
でも最後は前を向ける
```

Vamp Ponでは、この好みを以下に変換する。

```txt
楽しい欠片集め
↓
誰かの忘れ物を拾っていたと分かる
↓
自分が一人ではなかったと分かる
↓
自分が消したと思っていた名前が、実は残されていたと分かる
↓
このページは救えた、でも地図帳にはまだ余白がある
```

---

# 2. Season 1の一文

```txt
忘れ物係だった子どもたちが、遊びで作った地図帳。
その地図帳は、誰かを忘れないための約束だった。
ユイは全部を忘れたと思っていたが、本当はみんなが残した小さな道具に助けられて、毎晩朝まで歩いていた。
```

---

# 3. プレイヤーに見える表の話

プレイヤーが最初に見るのは、これだけでよい。

```txt
夜になると黒インクの影が出る。
ユイは欠片を拾って強くなる。
朝まで残れば、少しだけ記憶が戻る。
```

この時点では、仲間も恋愛も大きな真相も出さない。

---

# 4. 裏の話

実際には、ユイは一人ではなかった。

昔、忘れ物係という遊びをしていた子どもたちがいた。

```txt
ユイは拾う
アサは名前をつける
ナギはしまう
ミチルは道を読む
トモリは灯す
```

彼らは世界を救うために集まったのではない。

ただ、落ちているものを拾い、誰のものか考え、地図帳に書いて、いつか返そうとしていた。

その遊びが、後に黒インクから記憶を守る仕組みになった。

---

# 5. 中心の傷

Season 1の中心の傷は、死や絶望ではない。

```txt
自分は見られていなかった、と思い込んだこと。
```

ユイは、自分がアサを忘れたと思っている。

アサは、自分の名前が呼ばれなかったと思っている。

ナギは、しまったせいで届かなかったと思っている。

ミチルは、帰り道を残せなかったと思っている。

トモリは、自分だけが待っていたと思っている。

全員が少しずつ誤解している。

でも、その誤解の裏には、誰かが誰かを見ていた証拠がある。

---

# 6. Season 1の感情設計

## 楽しみ

```txt
欠片を拾う
武器が増える
影を払う
朝まで逃げ切る
小物が少しずつ増える
```

まず遊びとして気持ちよくする。

## 不穏

```txt
ユイ以外の筆跡
修理済みのランタン
片方だけの切符
名前のない名札
開かないページ
```

## 悲しみ

```txt
誰かを忘れたかもしれない
呼ばれなかった名前
届かなかった手紙
帰れなかった道
消えそうな灯り
```

## 恋愛/親密さ

恋愛は明言しない。

```txt
何度も消して書き直した名前
同じ帰り道を選んでいた跡
半分だけ残した飴
相手の癖だけ覚えている
```

友情にも恋愛にも読める余白にする。

## 驚き

```txt
敵は悪ではなく、読めなくなった記憶だった
片道切符ではなかった
空白の名札ではなく、書き直し跡だった
ユイは一人ではなかった
忘れたのではなく、守るために分けた
```

## 感動

```txt
ユイが朝まで歩けたのは、みんなが残した道具のおかげだった
```

# 7. 5ページの物語

## Page 1: 忘れ物のページ

表:

```txt
ユイが欠片を拾う。
```

裏:

```txt
ユイは、誰かの残した筆跡に導かれている。
```

最後のSeed:

```txt
地図帳の端に、ユイの字ではない小さな丸印がある。
```

感情:

```txt
楽しい、不穏、少し寂しい
```

---

## Page 2: 名前のページ

表:

```txt
名前のラベル、名札、通学路が出る。
```

裏:

```txt
アサは、名前をふざけてつけていたのではなく、忘れられないようにしていた。
```

反転:

```txt
空白の名札だと思っていたものには、何度も名前を書き直した跡があった。
```

感情:

```txt
親密さ、照れ、切なさ
```

---

## Page 3: しまったページ

表:

```txt
箱、図書室、しおり、閉じた手紙が出る。
```

裏:

```txt
ナギは閉じ込めたのではなく、黒インクから守るためにしまった。
```

反転:

```txt
開けるな、と書かれた箱は、拒絶ではなく保護だった。
```

感情:

```txt
秘密、後悔、温かさ
```

---

## Page 4: 帰り道のページ

表:

```txt
駅、切符、コンパス、改札が出る。
```

裏:

```txt
ミチルは帰れなかったのではなく、帰り道を残していた。
```

反転:

```txt
片道切符の裏に、帰りの印があった。
```

感情:

```txt
離別、待つこと、驚き
```

---

## Page 5: 灯りのページ

表:

```txt
ランタン、灯り、朝が出る。
```

裏:

```txt
トモリは一人で待っていたのではなく、みんなが帰れるように灯りを守っていた。
```

大反転:

```txt
ユイが一人で朝まで歩いていたと思っていた道には、みんなの道具が置かれていた。
```

最後:

```txt
朝になった。
このページの名前は、もう消えなかった。
```

感情:

```txt
感動、安心、次への余白
```

---

# 8. Season 1の終盤で分かること

終盤で分かる真実は、黒幕ではない。

```txt
ユイは一人ではなかった。
```

もう一段深い真実。

```txt
ユイは忘れたのではなく、消えないように分けた。
```

さらに温かい真実。

```txt
みんなもユイを忘れていなかった。
それぞれの道具が、毎晩ユイを助けていた。
```

---

# 9. エンディング

Season 1は完結させる。

未完にはしない。

閉じるもの:

```txt
ユイの最初の誤解
アサの名前
最初の班の約束
最初のページ
```

残すもの:

```txt
閉じた別ページ束
四つ折りの地図
未配達の封筒
知らない筆跡
```

エンディング案:

```txt
朝になった。
このページの名前は、もう消えなかった。

地図帳は静かに閉じた。
でも、背表紙のすきまから、まだ読んでいない紙片が一枚だけ見えていた。
```

---

# 10. 2への接続

2へ繋げるなら、次は以下が強い。

```txt
Vamp Pon 2: 届かなかった手紙
```

理由:

```txt
地図帳から自然に出せる
恋愛、家族、先生、郵便屋、兄妹を混ぜやすい
暗すぎず、感動にできる
未配達の封筒SeedをSeason 1から置ける
```

2での核:

```txt
届かなかった言葉も、なかったことにはならない。
```

---

# 11. 最重要

Season 1の物語の心臓はこれ。

```txt
ユイは一人で拾っていたのではない。
みんなが残した小さな手助けを、毎晩拾っていた。
```

そして最後の感情はこれ。

```txt
自分は忘れられていなかった。
自分も誰かを忘れなかった。
このページだけは、朝まで守れた。
```

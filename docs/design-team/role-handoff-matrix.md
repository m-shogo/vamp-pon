# Role Handoff Matrix

This matrix defines which designer role must review each kind of visual task.

## Matrix

| Work type | Primary role | Secondary role | Required docs |
| --- | --- | --- | --- |
| player avatar | Avatar design | Art direction, Pixel art | avatar rules, pro rubric, pixel rules |
| monster | Monster design | Art direction, Pixel art | monster rules, pro rubric, pixel rules |
| pickup item | Item design | Graphic design, Pixel art | item rules, graphic rules, pixel rules |
| level-up card | UI/UX design | Graphic design, Item design | UI rules, graphic rules, item rules |
| HUD | UI/UX design | Graphic design | UI rules, graphic rules |
| icon row | Graphic design | UI/UX design | graphic rules, UI rules |
| stage tile | Background design | Art direction, Pixel art | background rules, art direction, pixel rules |
| art board | Art direction | all roles | board goal, pro rubric, all role docs |

## Handoff requirement

Before moving to the next role, write:

- what this role approved
- what this role rejected
- what the next role must check

## Example

For a memory capsule item:

1. Item designer checks function and story.
2. Graphic designer checks icon/card consistency.
3. Pixel art director checks 1x readability and clusters.
4. UI/UX checks if it is confused with HUD or pickup marks.

## Do not

- Do not let one role approve everything.
- Do not skip gameplay readability.
- Do not let graphic style override item meaning.
- Do not let background mood override playability.

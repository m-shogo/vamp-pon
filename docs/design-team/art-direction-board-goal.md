# Art Direction Board Goal

This document defines the target quality of the shared Vamp Pon art-direction board.

## Board purpose

The board is not only a mood board. It is a production handoff sheet.

It must communicate:

- concept
- gameplay image
- character design
- monster design
- item design
- UI/UX design
- background direction
- graphic design system
- color palette
- common motifs
- NG examples

## Target feeling

- premium mobile game pitch board
- dark navy base with warm gold accents
- paper / ink / memory / little light motifs
- organized grid, not collage chaos
- readable Japanese headings
- strong central gameplay mock
- asset examples that look like the same product

## Board sections

1. title and subtitle
2. concept statement
3. central gameplay mock
4. design team roles
5. avatar sheet
6. monster families
7. item collection
8. UI and level-up cards
9. stage thumbnails
10. graphic system
11. color palette
12. motif icons
13. NG examples

## Quality bar

The board reaches 80 when:

- it looks like one app, not separate images
- gameplay screen is immediately understandable
- UI cards are readable
- avatars and monsters have different roles
- items have story and function
- background is beautiful but quiet
- the NG section teaches what not to make

## Do not

- Do not make the board only decorative.
- Do not add unreadable long text.
- Do not mix inconsistent sprite styles.
- Do not make UI mockups that cannot become real screens.

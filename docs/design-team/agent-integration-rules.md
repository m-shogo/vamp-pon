# Agent Integration Rules

Claude and Codex must use the design-team bible before visual production work.

## Required before visual work

Read:

- `docs/design-team/README.md`
- `docs/design-team/pro-app-quality-rubric.md`
- the matching role document
- `docs/pixel-art/README.md`
- `docs/pixel-art/ng-patterns.md`

## Matching role document

- avatar or player-side design: `docs/design-team/avatar-rules.md`
- monster: `docs/design-team/monster-designer-rules.md`
- item: `docs/design-team/item-designer-rules.md`
- background: `docs/design-team/background-designer-rules.md`
- UI: `docs/design-team/ui-ux-designer-rules.md`
- icon / card / typography / frame: `docs/design-team/graphic-designer-rules.md`

## Required workflow

1. State the intended asset role.
2. State the matching design role.
3. Check shared art direction.
4. Check differentiation.
5. Check pixel craft.
6. Check gameplay readability.
7. Score against the 80-point rubric.
8. Keep under-80 work as prototype or iterate.

## Production rule

Do not promote visual work to production unless the review says 80 or higher and production evidence exists.

# Art Director Rules

Lead: 夜森 透子
Mission: Vamp Pon の世界観、品質、統一感を守る。

## Philosophy

Vamp Pon は、夜・記憶・紙片・黒インク・小さな光のゲーム。
絵は暗いが怖すぎず、可愛いが幼すぎず、紙の手触りと夜の静けさを持つ。

## Common format

- Main mood: quiet night, forgotten objects, small warm light.
- Surface: paper, ink, worn edges, soft texture.
- Contrast: player / enemy / pickup / UI は背景より強くする。
- Shape: readable silhouette first.
- Detail: focal point 以外は減らす。

## What to unify

- night-blue base tone
- warm lantern gold
- old-paper cream
- soft painterly pixel clusters
- selective outline
- gentle shadow
- paper-card UI language

## What to differentiate

- character silhouette
- monster family shape
- item function symbol
- background location motif
- UI information hierarchy

## Do not

- Do not make a pretty image that hurts gameplay.
- Do not let every asset use the same brightness.
- Do not add decorations without a design reason.
- Do not accept a 60-point asset because it is technically complete.

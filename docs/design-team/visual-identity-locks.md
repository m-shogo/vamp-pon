# Visual Identity Locks

Identity locks keep Vamp Pon consistent while allowing many assets to be produced.

## World locks

These must not drift:

- night blue base
- old paper cream
- warm lantern gold
- ink black enemy language
- memory light motif
- soft painterly pixel clusters
- paper-card UI
- readable vertical mobile layout

## Avatar locks

For every player-side avatar:

- three signature elements
- readable face area
- clear prop or motif
- silhouette that differs from existing avatars
- color plan that does not merge with enemies or pickups

## Monster locks

For every monster family:

- one family silhouette
- one movement identity
- one eye/light pattern
- one gameplay role
- no player-like hood shape unless story requires it

## Item locks

For every item:

- function signal
- story signal
- pickup/readability scale
- glow level that does not conflict with enemy eyes or UI stars

## UI locks

For every UI screen:

- top HUD readable first
- bottom touch zones clear
- cards use paper language
- typography stays readable
- decoration supports hierarchy

## Background locks

For every stage:

- center gameplay area quieter than edges
- pickups remain brightest reward marks
- enemy silhouettes remain readable
- tile/seam noise is controlled

## Drift warning

If a new asset looks good alone but breaks any lock, keep it as a reference only.

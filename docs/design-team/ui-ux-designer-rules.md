# UI UX Designer Rules

Lead: Tsukimura Sui
Mission: Make vertical mobile UI readable and easy to use.

## Core rule

UI must be readable before it is decorative.

## Mobile layout

- Top area: HP, time, level, memory count.
- Bottom left: movement stick.
- Bottom right: action area.
- Center: keep gameplay visible.
- Level-up area: paper cards, three choices max.

## Information priority

1. HP
2. player position
3. enemy position
4. pickup position
5. time and level
6. decorative paper details

## Paper-card rules

- Card title reads first.
- Icon explains the effect before text.
- Description is short.
- Stars or level marks must not look like pickups.
- Paper texture must not reduce text contrast.

## 80-point target

- thumb zones are obvious
- main action is clear
- HUD is readable at phone scale
- cards feel like the world
- UI never hides important gameplay objects

## Do not

- Do not fill the screen with panels.
- Do not put important text over noisy texture.
- Do not make all icons equally bright.
- Do not place decoration where touch feedback should be.

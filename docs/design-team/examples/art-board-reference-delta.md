# Art Board Reference Delta

Use this to judge whether a board or screen is moving toward the current art-direction target.

## What to keep

- vertical mobile gameplay framing
- night blue base
- warm lantern and memory light accents
- paper-card UI language
- organized gold-line board structure
- readable role sections for avatar, monster, item, UI, background, and graphic design

## What must improve from rough drafts

- avoid dense text blocks
- avoid unrelated illustration styles
- avoid UI that looks like a poster but cannot become a real game screen
- avoid stage images that are brighter than gameplay objects
- avoid item icons that are too similar to each other

## Target result

The board should look like a production handoff sheet, not only a mood board.

It must explain:

- concept
- gameplay image
- avatar rules
- monster families
- item language
- UI and card language
- stage direction
- graphic system
- forbidden patterns

## Review question

Can another agent create a consistent new asset by reading the board?
If not, the board needs another iteration.

# Vamp Pon Design Team Bible

This directory defines design rules for Vamp Pon.

## Roles

- Art direction: world tone, consistency, final quality.
- Avatar design: player-side silhouettes, signature elements, outfit and prop identity.
- Monster design: enemy families, threat shapes, movement identity.
- Background design: stage readability, tile density, atmosphere.
- Item design: collectible symbols, story props, reward clarity.
- UI/UX design: mobile layout, readable HUD, touch zones.
- Graphic design: color, typography, cards, frames, icon system.

## Rule

Every visual asset must pass both pixel-art craft rules and design-role rules.

## Production target

The goal is the quality level shown in the current art-direction references:

- unified night / memory / paper / ink / small-light world
- professional mobile vertical screen readability
- paper-card UI with clear hierarchy
- character, monster, item, background, and UI all using one brand language
- no production promotion below 80-point visual quality

## Must not do

- Do not use hair only as avatar differentiation.
- Do not make enemies only black blobs.
- Do not make backgrounds brighter than gameplay objects.
- Do not make UI cards beautiful but hard to read.
- Do not make items generic symbols only.
- Do not mix unrelated graphic styles.
- Do not promote one-shot AI output to production.

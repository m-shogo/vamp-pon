# Pro App Quality Rubric

This rubric raises Vamp Pon visual work from prototype quality to app-store-ready quality.

## Score bands

| Score | Meaning |
| --- | --- |
| 60 | Works, but generic or weak. |
| 70 | Readable and on-theme, but not memorable. |
| 80 | Professional enough for a small commercial app. |
| 90 | Key visual / merch / trailer quality. |

## 80-point requirements

A visual asset needs all of these:

- role is clear at 1x
- silhouette is recognizable
- focal point is obvious
- palette separates from background
- texture supports the shape
- style matches Vamp Pon
- it has one memorable design idea
- it does not need explanation to read

## Role-specific 80 targets

| Asset | 80-point test |
| --- | --- |
| human | three identifiers, readable face, sticker-like charm |
| monster | one family silhouette, readable motion role, not a black blob |
| item | function and story are both visible |
| background | location identity without gameplay noise |
| UI | phone-readable and thumb-friendly |
| graphic | palette, type, icon and card language are unified |

## Reject below 80 if

- only color changed
- only hair changed
- silhouette is unclear
- focal point is missing
- background competes with gameplay objects
- UI is beautiful but hard to read
- icon meaning is unclear
- one-shot AI output was not refined
- before/after does not show real improvement

## Production rule

Production promotion should not happen under 80.
If the asset is under 80, keep it as prototype or iterate.

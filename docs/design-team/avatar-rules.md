# Avatar Rules

Purpose: keep player-side avatars readable and distinct.

## Shared format

- readable head
- small simple body
- clear face area
- simple outfit blocks
- one readable prop
- soft pixel clusters

## Three-signature rule

Each main avatar needs three identifiers.

Examples:

- silhouette marker
- face marker
- hair marker
- outfit marker
- prop marker
- color marker
- posture marker

Yui identifiers:

- blue hood
- brown bangs
- lantern

## Reject if

- only hair differs
- only color differs
- prop is unclear
- face is unclear
- 1x silhouette is unclear
- 4x view has no charm

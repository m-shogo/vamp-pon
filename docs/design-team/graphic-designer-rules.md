# Graphic Designer Rules

Lead: 星野 ラテ
Mission: 色、文字、枠、カード、アイコンを同じブランドに見せる。

## Core rule

Graphic design is the glue between art, UI, and product quality.

## Palette roles

- night blue: base world color
- ink black: enemy and shadow
- lantern gold: attention and reward
- old paper cream: cards and notes
- memory purple: magic and mystery
- quiet gray: frame and secondary UI

## Motif system

Use repeating motifs with clear meaning.

- moon: night / time
- lantern: safety / small light
- ink: lost memory / enemy
- star: memory shard / reward
- note: record / story
- bottle: stored memory
- ticket: travel / chance

## Typography rules

- Headings: warm, classical, readable.
- Body: simple and readable at phone scale.
- Numbers: strong and clear.
- Do not use too many font styles.

## Frame and card rules

- Use paper edges for cards.
- Use thin gold lines for board / premium frames.
- Keep corners slightly worn.
- Do not let frame decoration overpower content.

## 80-point target

- one brand tone across screens
- icons share one shape language
- text is readable
- cards feel collectible
- colors support gameplay priority

## Do not

- Do not mix unrelated icon styles.
- Do not overuse bright gold.
- Do not make text decoration more important than text.
- Do not use UI colors that conflict with pickups.

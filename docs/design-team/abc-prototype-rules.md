# A/B/C Prototype Rules

Use A/B/C prototypes to avoid one-shot 60-point assets.

## Required directions

For important visual assets, create or describe three directions.

| Direction | Purpose | Example focus |
| --- | --- | --- |
| A | silhouette-first | strongest outline and role readability |
| B | charm-first | face, emotion, collectible feeling |
| C | gameplay-first | contrast, scale, HUD/background separation |

## How to compare

Score each direction with the pro app rubric.

- 1x readability
- silhouette
- focal point
- differentiation
- style fit
- gameplay visibility
- memorable idea

## Merge rule

Do not simply pick the highest score.
Build v2 from the best parts.

Example:

- A has the best silhouette.
- B has the best face or item charm.
- C has the best contrast.
- v2 combines those three strengths.

## Reject rule

Reject a direction if:

- it only changes color
- it only changes hair
- it loses Vamp Pon world tone
- it is pretty but unclear at 1x
- it needs long explanation to understand

## Minimum output

Every A/B/C review must include:

- best part of A
- best part of B
- best part of C
- parts to discard
- chosen v2 plan
- current score and target score

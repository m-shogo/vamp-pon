# World Logic and Story Consistency Rules

## 目的

Vamp Pon の物語を、雰囲気だけでなく、理由・理屈・ゲーム仕様が一致する構造にする。

現行正史:

```txt
黒インクで固定された“間違った意味”をほどき、正しい持ち主に返す。
```

---

# 1. 結論

Vamp Pon は、詩的なゲームに見える。

しかし裏では、以下がすべて同じ理屈でつながっている必要がある。

```txt
黒インク
記憶の欠片
朝
ランごとのリセット
アイテム
地図帳
ページ束
キャラの武器
敵
エンディング
```

すべての答えは、以下の1文から出す。

```txt
悲しい出来事は消えない。
でも、その出来事についた間違った意味はほどける。
```

---

# 2. 世界の基本法則

## 法則A: 黒インクは事実ではなく“意味”を固定する

Vamp Ponの世界では、出来事そのものは完全には消えない。

ただし、人が強く信じ込んだ誤解が黒インクによって固定される。

```txt
名前を呼ばれなかった
帰れなかった
閉じ込めた
自分だけが待っていた
忘れられた
```

これらは事実そのものではなく、本人が受け取ってしまった意味。

黒インクは、その意味を固める。

ユイたちは事実を復活させるのではない。

```txt
間違った意味の固定をほどき、正しい持ち主へ返す。
```

---

## 法則B: 黒インクは悪意だけではない

黒インクは敵に見える。

だが、性質は以下。

```txt
痛みを固定する
誤解を変わらないものにする
読まれると壊れる意味を隠す
本人が耐えられない真相から守る
```

つまり黒インクは、敵であり、保護であり、停滞でもある。

---

## 法則C: 欠片は経験値ではなく、固定から剥がれた意味片

表のゲームでは、欠片は経験値や強化素材。

裏の物語では、欠片は黒インクから剥がれた意味片。

```txt
拾うほど強くなる
= その夜だけ意味の接続が増える
= 行動できる読み方が増える
```

---

## 法則D: 朝は確定処理

朝は、ただの救い演出ではない。

```txt
夜 = 仮読みできる時間
朝 = その夜にほどけた意味を地図帳に確定する時間
```

夜の力は一時的。

朝になると、ステータスや武器強化はほどける。

しかし、正しい順番でほどけた意味だけが地図帳へ残る。

---

## 法則E: 順番を間違えると意味が歪む

Vamp Ponでは、拾えば必ず正解ではない。

意味には接続順がある。

```txt
名前
場所
理由
証拠
灯り
```

例:

```txt
名前だけ戻す
→ 誰かは分かるが、なぜ大切だったか分からず痛みになる

場所だけ戻す
→ 帰る場所は分かるが、誰が帰るべきか分からない

証拠だけ戻す
→ 本当にあったことだけが突きつけられ、誤解が強くなることがある
```

# 3. 黒インクの辻褄

## なぜ敵になるのか

黒インクで固定された誤解は、ほどかれることを拒む。

理由:

```txt
ほどけると痛い
ほどけると自分の誤解を認める必要がある
ほどけると守っていたものを手放す必要がある
ほどけると別の人の責任ではなくなることがある
```

だから影は襲ってくる。

これは悪だからではない。

固定された意味が、ほどかれたくないから。

---

## なぜ倒すと欠片になるのか

影を払うと、固定されていた意味が少し剥がれる。

その剥がれた部分が、光る紙片として落ちる。

```txt
敵を払う
= 誤解の固定を少しほどく
= 意味片が落ちる
```

---

## なぜ朝まで残る必要があるのか

夜にほどいた意味は仮読み。

朝まで残らないと、地図帳へ確定できない。

```txt
夜に拾う
夜に仮接続する
朝まで残る
朝に地図帳へ確定する
```

---

# 4. 地図帳の辻褄

## 地図帳とは何か

地図帳は、ただのUIではない。

固定された意味を、正しい持ち主・場所・理由・証拠へ戻すための確定帳。

```txt
地図
= 場所の記録
= 意味の返却先
= 誰に何を返すべきかの順路
```

---

## なぜページ束なのか

1つのページでは、1つの誤解しかほどけない。

ページ束になると、関係性の誤解がほどける。

```txt
1ページ: 1つの誤解
ページ束: 1つの関係性
地図帳1冊: 1つの夜の構造
```

---

# 5. キャラと武器の辻褄

キャラの武器は、本人の性格ではなく、本人が扱う接続に結びつける。

## ユイ

```txt
接続: 持ち主
固有能力: 持ち主を間違えない
武器: 夜の鉛筆
理由: 誰の意味かを仮に書き留める
```

## アサ

```txt
接続: 名前
武器: 名前のラベル
理由: 誰の意味かを表に出す
```

## ナギ

```txt
接続: 理由
武器: 月の箱
理由: 読まれると壊れる理由を一時隔離する
```

## ミチル

```txt
接続: 場所
武器: 金のコンパス
理由: 返すべき場所を読む
```

## トモリ

```txt
接続: 定着
武器: ランタン
理由: 朝まで意味をほどけさせない
```

# 6. 反転の気持ちよさ

反転は、驚かせるためだけに置かない。

反転後に、過去のゲーム体験まで意味が変わる必要がある。

良い反転:

```txt
ずっと使っていたランタンが、実は朝まで意味を保持する装置だった
ずっと拾っていた欠片が、経験値ではなく誤解から剥がれた意味片だった
片道だと思った切符が、帰る予定を固定する接続点だった
```

悪い反転:

```txt
突然黒幕が出る
実は全部夢だった
死後の世界と直接言い切る
```

---

# 7. ハッピーエンドの辻褄

ハッピーエンドは、全部元通りになることではない。

Vamp Ponのハッピーエンドは以下。

```txt
出来事は消えない
でも間違った意味は固定されなくなる
正しい持ち主へ返る
次の朝に持っていける意味が残る
```

---

# 8. 仕様と物語の対応表

```txt
自動攻撃
= 固定された誤解に対して、夜の記憶が自分を守ろうとする

経験値
= 固定から剥がれた意味片が増える

レベルアップ
= その夜だけ扱える接続が増える

朝リセット
= 仮接続がほどける

恒久解放
= 地図帳に正しく確定された接続

アイテム進化
= 小物の誤解が反転し、本来の接続点として機能する

敵の種類
= 固定された誤解の種類

ボス
= そのページで一番強く固定された誤解
```

---

# 9. 最重要

```txt
最初は、ただ気持ちよく拾っていた。
でも後から、拾う順番も、敵の動きも、小物の形も、全部に理由があったと分かる。
```

```txt
悲しいことはあった。
でも、その悲しさについた間違った意味はほどけた。
```

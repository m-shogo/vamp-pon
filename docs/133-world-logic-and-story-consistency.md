# World Logic and Story Consistency Rules

## 目的

Vamp Pon の物語を、雰囲気だけでなく、理由・理屈・ゲーム仕様が一致する構造にする。

目標は以下。

```txt
考察できる
辻褄が合う
後から意味が反転する
でも遊びとして気持ちいい
```

---

# 1. 結論

Vamp Pon は、詩的なゲームに見える。

しかし裏では、以下がすべて同じ理屈でつながっている必要がある。

```txt
黒インク
記憶の欠片
朝
ランごとのリセット
アイテム
地図帳
ページ束
キャラの武器
敵
エンディング
```

すべての答えは、以下の1文から出す。

```txt
読めなくなった大切なものを、もう一度読める形に戻す。
```

---

# 2. 世界の基本法則

## 法則A: 消えたのではなく、読めなくなった

Vamp Ponの世界では、記憶や約束は完全には消えない。

しかし、黒インクによって読めなくなる。

```txt
名前が消えたのではない
道が消えたのではない
手紙がなかったことになったのではない
灯りが最初からなかったのではない
```

すべては、読めなくなっている。

だからユイたちは、消えたものを復活させるのではなく、読める形に戻している。

---

## 法則B: 黒インクは悪意だけではない

黒インクは敵に見える。

だが、長期的には以下の性質を持つ。

```txt
痛みを隠す
読まれると壊れる記憶を覆う
終わらせたくない感情が固まる
誰かが守るために塗ったものでもある
```

つまり黒インクは、敵であり、保護膜でもある。

プレイヤーは最初、黒インクを倒す。

終盤では、黒インクを読む。

---

## 法則C: 欠片は経験値ではなく、読める文字の断片

表のゲームでは、欠片は経験値や強化素材。

裏の物語では、欠片は読めなくなった記憶の文字片。

```txt
拾うほど強くなる
= 読める情報が増える
= 夜の中で行動できる理由が増える
```

だから、欠片を拾う遊びと物語が一致する。

---

## 法則D: 朝になると力はほどけるが、意味は残る

ランごとのリセットはゲーム都合ではない。

夜の力は、黒インクの中でだけ使える一時的な読み直し能力。

朝になると、その力はほどける。

しかし、読めるようになった意味は地図帳に残る。

```txt
ステータスは戻る
武器強化はほどける
でも図鑑/地図帳/読める文章は進む
```

これがローグライト構造の物語的理由。

---

## 法則E: アイテムは道具であり、証拠である

すべての重要アイテムには二重意味が必要。

```txt
表: ゲーム効果
裏: 誰かが残した証拠
```

例:

```txt
夜の鉛筆
表: 攻撃
裏: 名前を書き直した道具

切符
表: 移動/速度
裏: 帰る予定があった証拠

ランタン
表: 範囲攻撃
裏: 誰かが直し続けた灯り
```

# 3. 黒インクの辻褄

## なぜ敵になるのか

読めなくなった記憶は、読まれることを拒む。

理由:

```txt
読まれると痛い
読まれると壊れる
読まれると本当の意味に戻ってしまう
本当の意味に戻ると、隠していた誤解が解ける
```

だから影は襲ってくる。

これは悪だからではない。

読まれたくないから。

---

## なぜ倒すと欠片になるのか

影を払うと、読めなかった記憶の輪郭がほどける。

その結果、小さな文字片/紙片/光の欠片として落ちる。

```txt
敵を倒す
= 記憶を破壊する
```

ではない。

```txt
敵を払う
= 黒インクの膜をほどく
= 読める欠片が落ちる
```

---

## なぜ朝まで残る必要があるのか

夜の間は、黒インクが濃い。

朝になると、黒インクは薄くなる。

ただし、朝まで欠片を抱えて残れなければ、読める形に固定できない。

だからゴールはこうなる。

```txt
夜に拾う
朝まで残る
朝に地図帳へ定着する
```

これが「朝まで残る」の理由。

---

# 4. 地図帳の辻褄

## 地図帳とは何か

地図帳は、ただのUIではない。

読めなくなった記憶を、もう一度読める順番に並べる装置。

```txt
地図
= 場所の記録
= 記憶の順路
= 誰かへ戻るための読み方
```

地図帳があるから、欠片はただの断片ではなく、ページとして読める。

---

## なぜページ束なのか

記憶は1つずつ読めるが、単独では意味が足りない。

いくつかのページが束になると、関係性が読める。

```txt
1ページ: 1つの記憶
ページ束: 1つの関係性
地図帳1冊: 1つの大きな夜の意味
```

---

# 5. キャラと武器の辻褄

キャラの武器は、本人の性格や役割ではなく、本人の誤解と反転に結びつける。

## ユイ

```txt
誤解: 自分が忘れた
武器: 夜の鉛筆
理由: 忘れたのではなく、何度も書き直していた
```

## アサ

```txt
誤解: 名前を呼ばれなかった
武器: 名前のラベル
理由: 名前をつけることで、忘れられないようにしていた
```

## ナギ

```txt
誤解: 閉じ込めた
武器: 月の箱
理由: 閉じたから守れた
```

## ミチル

```txt
誤解: 帰り道を失った
武器: 金のコンパス
理由: 道は残っていたが、読めなくなっていた
```

## トモリ

```txt
誤解: 自分だけが待っていた
武器: ランタン
理由: 待つだけではなく、帰れるように灯していた
```

# 6. 反転の気持ちよさ

反転は、驚かせるためだけに置かない。

反転後に、過去のゲーム体験まで意味が変わる必要がある。

良い反転:

```txt
ずっと使っていたランタンが、実はトモリの手助けだった
ずっと拾っていた欠片が、ユイ自身が分けた記憶だった
片道だと思った切符が、帰るためのものだった
```

悪い反転:

```txt
突然黒幕が出る
実は全部夢だった
実は死後の世界だった、と直接言う
```

# 7. 考察できる余白

考察できる余白には、必ず答えの芯を持たせる。

## 出してよい余白

```txt
黒インクは誰が最初に塗ったのか
影の班は敵か味方か
未配達の封筒は誰宛てか
地図帳は何冊あるのか
街の外にも夜があるのか
```

## 出してはいけない余白

```txt
設定が未定だから曖昧
矛盾をごまかすための謎
何でもありにするための余白
```

余白は、未定ではない。

答えを持って隠す。

---

# 8. 暗い要素の扱い

暗い裏設定は入れてよい。

ただし、直接的な死や破滅を報酬にしない。

Vamp Ponの言葉に変換する。

```txt
死ぬ → ほどける / 朝へ行く / ページが閉じる
天国 → 朝のページ / 地図帳の外 / 灯りの向こう
植物状態 → 読めないまま留まっている / 夜に引っかかっている
人類滅亡 → 街が昨日の続き読めなくなった
```

重要なのは、暗さを入れることではない。

暗い理由が、最後に温かく読めること。

---

# 9. ハッピーエンドの辻褄

ハッピーエンドは、全員が元通りになることではない。

Vamp Ponのハッピーエンドは以下。

```txt
なかったことにはならなかった
読める形に戻った
誰かが見ていた証拠が残った
次の朝に持っていける意味が残った
```

全員生き返る、全員結ばれる、全員完全回復のような強い救済も、将来の候補として否定しない。

ただし、その場合も理屈が必要。

```txt
なぜ戻れるのか
何が代償か
戻った後に何が変わるのか
誰の記憶が定着したから可能なのか
```

理由なく奇跡を起こさない。

---

# 10. 仕様と物語の対応表

```txt
自動攻撃
= 夜の中で記憶が自分を守ろうとする

経験値
= 読める文字片が増える

レベルアップ
= その夜だけ読み方が増える

朝リセット
= 夜の読み方がほどける

恒久解放
= 地図帳に意味が定着する

アイテム進化
= 誤解が反転し、本来の使い方に戻る

敵の種類
= 読めなくなった感情の違い

ボス
= そのページで一番読まれたくない誤解
```

---

# 11. 最重要ルール

Vamp Ponでは、ゲーム都合を先に置いてよい。

ただし、あとから必ず物語の理由をつける。

```txt
気持ちいいから採用
↓
なぜ気持ちいいのかを物語で説明できるようにする
```

逆に、物語が良くてもゲームが気持ちよくならないものは採用しない。

---

# 12. 最後の芯

Vamp Ponの考察の気持ちよさは、これ。

```txt
最初は、ただ気持ちよく拾っていた。
でも後から、拾っていたもの全部に理由があったと分かる。
```

Vamp Ponの物語の気持ちよさは、これ。

```txt
悲しいことはあった。
でも、なかったことにはならなかった。
```

この2つを絶対に守る。

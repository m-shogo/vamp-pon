# 1. ゲーム概要

## タイトル

```txt
Vamp Pon
```

仮タイトル。

## ジャンル

```txt
スマホ縦持ち / サバイバルローグライト / 自動攻撃アクション
```

## 一言コンセプト

```txt
影を払い、記憶を拾い、朝まで残る。
```

## 少し詳しい説明

夜にあふれる影を払い、消えかけた記憶を朝までに取り戻す、縦持ちサバイバルローグライト。

プレイヤーは移動中心。
攻撃は自動。
敵を倒すと「記憶の欠片」が落ち、拾うとレベルアップする。
強敵から得る「記憶カプセル」で武器が進化し、朝まで生き残ることを目指す。

# 2. 最重要判断

Vamp Pon のMVPは、以下の問いにYESを出すために作る。

```txt
仮素材でも、ユイで8分遊んで、もう一度遊びたいか？
```

この問いにYESが出るまで、以下を増やさない。

```txt
2人目キャラ
複数ステージ
本格デザイン
詳細図鑑
PWA/Capacitor
課金/広告
```

# 15. 結論

Vamp Pon は、今の段階では「完成版」ではなく「遊びの核を証明するMVP」を作る。

最初に証明すべきことはこれ。

```txt
ユイで8分遊ぶだけで、もう一度やりたくなるか。
```

YESなら、デザイン本格化・2人目キャラ・アプリ化へ進む。

NOなら、仕様を増やさず、操作感/爽快感/成長テンポを直す。

# 22. Party seating reservoir

固定seat mapではない。Scene purposeごとに変える。

## Pattern A — Core5 comfort table

Candidate:

```txt
Yui — Asa — Nagi
 |             |
Tomori — Michiru
```

Use:
- 初期の安心
- 後にこの並びを崩してgrowthを見せる

Do not use every Party。

## Pattern B — Mixed-generation table

- Gen / Koyori / Yui / Tomori / Asa
- older/child/present/futureを説明係順に並べない
- food or objectを中心にする

## Pattern C — Route table

- Michiru / Tobari / Yubi / Nagi / Gen / Toki
- map中心だが一枚の正解mapを選ばない

## Pattern D — Quiet table

- Nagi / Kasumi / Madoka / Nemu / Kuroori
- silenceを同じ意味にしない
- Nemu may sleep, Madoka observes, Kuroori folds, Kasumi waits, Nagi checks closure

## Pattern E — Repair / preserve table

- Tomori / Tsumugi / Hana / Shiro / Kanna if S2 guest candidate
- what to fix / preserve / classify / discard

## Pattern F — Former enemy surprise seat

Rule:

> old enemyを入口に立たせ続けず、**座るかどうかのchoice**自体をsceneにする。

- Party Guest != absolution
- protagonist groupが一斉に歓迎しない
- one person may move a chair
- one may refuse eye contact
- one may continue eating
- one may leave

## Pattern G — Empty seat

空席を:

- dead person確定
- bloodline clue
- future character teaser

へ自動変換しない。

単にlate arrival / someone choosing spaceでもよい。

# 26. Reconciliation without speeches

Reservoir actions:

- chair moved back but not adjacent
- food portion saved without comment
- tool returned cleaned
- gate left open five more minutes
- box key placed within reach
- blank field added to form
- map route drawn in pencil instead of ink
- one person waits half a step
- umbrella held without forcing closeness
- old message not deleted, correction attached
- unfinished item returned unfinished
- someone asks “帰る？” rather than “帰ろう”

No action automatically resolves harm.

# 1. Hard guards

禁止:

- 高価な物 = 金持ち
- 古い物 = 貧しい
- 壊れた物 = trauma
- 綺麗な部屋 = 善人
- 散らかった部屋 = だらしない悪人
- 褐色肌 = 南国palette
- 女性/男性/gender presentation = wardrobe fixed
- child = colorful only
- older adult = muted color only
- wheelchair = medical prop room
- Robot = no personal object
- animal accessory = owner/identity proof
- Future = everything self-cleaning / no wear
- Past = everything patched / dirty

実在brandは recurring Dream props / generic profileでは避ける。
Exact fashion era detailsはEra research後に確定。

# 4. Wear tells time without exposition

同じobject/服をSeason跨ぎで使う時:

- new → scuffed
- repaired → repaired again
- patch removed
- pocket moved
- label rewritten
- gift exchanged
- object no longer carried
- same bag used by another person with permission

これでrelationship/historyを台詞なしに見せられる。

But:

> 傷が増えた = 成長した

ではない。

# 5. Room design reservoir

部屋はpersonality quizにしない。

A room can be:

- neat because small
- messy because project ongoing
- sparse because recently moved
- full because shared household
- temporary because work
- curated for visitors but private drawer messy
- accessible because person designed it that way
- generic rental with very few modifications

Character-specificity should come from **where the repeated action happens**:

- where Yui charges phone
- where Nagi closes drawer
- where Tomori leaves discard pile
- where Hana leaves empty space
- where Tobari drops keys
- where Amane positions chair/work surface
- where Noa branches start modifying same initial room differently

# 6. Clothing QA

Before final design:

1. Can Character move in it according to Physical Identity?
2. Does body fit look intentional rather than default model scaling?
3. Is costume doing too much lore exposition?
4. Are all women dressed “soft” and all men “practical”?
5. Is every Future character wearing identical techwear?
6. Is every Past character wearing brown/grey old clothes?
7. Are Hiyori/Touma palettes ethnicized from skin tone?
8. Is Suzu coded by stereotype rather than chosen presentation?
9. Is Io dressed to tease gender reveal?
10. Is Amane clothing designed standing-first then awkwardly seated?
11. Is Kaname's size accommodated rather than hidden/mocked?
12. Is Hana's plus-size body getting generic shawl/old-woman disguise?
13. Are Kuu/Yomo accessories welfare-safe and story-motivated?
14. Are Noa/Rum being forced into human clothing conventions?

# 9. Completion

```txt
36 characters

```

Required:

- Physical Identity preserved
- exact costume Open

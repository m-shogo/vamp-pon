# 2. Season finale layers

Season finaleは一枚岩の「解決」にしない。

```txt
Tactical Resolution
↓
Character Resolution
↓
Era / Social Resolution
↓
Series Mystery Resolution
```

各層を別管理する。

## Tactical Resolution

そのSeasonの戦闘 / immediate crisisは止められる。

Example:

- machine停止
- trapped people解放
- Boss / Black Youka crisis鎮静
- false record correction path確保

ここはPlayerへ達成感を与える。

## Character Resolution

主要Characterは一つ成長する。

But:

> **成長 = 全ての悩み解決ではない。**

Season2では別角度からその成長が試される。

## Era / Social Resolution

部分的でよい。

- local rule change
- trial制度
- appeal route
- one district repaired
- emergency workaround

しかし社会全体のpressureは残る場合がある。

## Series Mystery Resolution

Season1では大きく残す。
Season2 / 3で段階的に解く。

# 3. Season1 ending — 「勝った。でも変だ」

Working type:

`UNEASY_PARTIAL_VICTORY`

Player emotion target:

```txt
やった
↓
みんな無事
↓
Party / quiet relief
↓
……でも何かおかしい
↓
次を見たい
```

Horror / discomfortはCharacter deathではなく**構造の残存**から作る。

## Good uneasy signals

- 解決したはずのlabel / record contradictionが別Era資料にも存在する。
- 消したはずの誤分類と同じlogicが違う制度名で残っている。
- Sakuyaza memberが「ここだけ直しても意味がない」と言うが、正解を説明しない。
- Gunjo Zankyorokuの一人と思っていた記録が、実は同じ人物を指していない可能性が出る。
- Core5が別Eraの同じ星を違う星座名で呼び、どちらも古い記録に存在する。
- Partyは成立するが、いつもの食糧庫に**食べ物ではなく、誰も置いた覚えのない古い紙 / name tag / map fragment**が混じる Candidate。

Avoid:

- random monster jump scare
- 急に仲間死亡
- villain laughing in darknessだけ
- 「全部黒幕の計画通り」だけ

不穏さには**既存世界ruleとの関係**が必要。

- enough Core5 Reality resolution
- Sakuyaza major resolution

`DEEPER_PARTIAL_RESOLUTION`

- but the Dream / constellation / memory system still contains one final contradiction

Season3 then becomes final convergence.

# 8. Final Happy End quality bar

Happy End does NOT mean:

- every victim never suffered
- all social problems vanish
- every villain redeemed
- all Sakuyaza become friends
- every Android / Human conflict solved forever
- Reality histories overwrite into perfect worlds

Happy End means:

- worst ending is avoided
- people gain choices they did not have
- institutions / relationships gain correction routes
- key characters can return to their Reality and act differently
- Dream relationships mattered even when explicit memory was fragile
- Main cast is allowed ordinary life after crisis

Most important:

> **最後に残るのは「世界が完璧になった」ではなく、「もう一つ選べるようになった」。**

---

# 9. Uneasy ending vs hopeless ending

Season1 can feel uncomfortable but must not feel pointless.

Need both:

### Achievement

- people saved
- relationship changed
- immediate crisis resolved
- Player action mattered

### Residue

- larger structure remains
- new contradiction appears
- someone has a new question
- familiar ordinary object now means something unsettling

If only residue exists → nihilistic.
If only achievement exists → too clean.

Target:

> **勝利は本物。安心だけがまだ早い。**

# 10. Party as ending contrast

Party is perfect for Season finale.

## S1 Candidate shape

1. major crisis cleared
2. everyone returns to base
3. 食糧庫を開ける
4. 焼肉 / alcohol / soda / laughter
5. relationship callback
6. quiet late-night cleanup
7. one small contradiction remains

The disturbing beat should come **after warmth**, making the warmth more valuable rather than invalidating it.

## Final Season Happy End

Use the same recurring ordinary action:

- same table
- same food request
- same joke
- same cup / label / repair tool

but now Character choices differ.

This allows a final emotional payoff without death.

# 11. Protagonist continuation

Core5 continue because:

- their own Era issue may remain partially unresolved
- another Era's problem changes how they understand their own
- Main Mystery crosses all their Eras
- relationships continue to deepen
- Sakuyaza / Gunjo evidence evolves

Do not justify continuation by deleting their memories / growth every Season.

Yui remains the main viewpoint through Season continuation unless later explicitly changed.

---

# 12. Quality test

Before approving a Season finale:

- Did Player genuinely accomplish something?
- Is the unresolved part larger / different, not the exact same task postponed?
- Did at least one Character complete a real emotional step?
- Does the next Season ask a new macro question?
- Is discomfort based on established world logic?
- Does the finale avoid mandatory death bait?
- Does ordinary life still feel worth protecting?
- Can the final Happy End later callback to this ending?

If yes:

> **partial victory can be more powerful than false closure.**

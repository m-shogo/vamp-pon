# Boss Design Spec

## 目的

Vamp Pon のボス仕様を、将来拡張として定義する。

重要:

```txt
Prototype 1〜3 / MVP Stage 1では本格ボスを作らない。
```

この資料は、Stage 2以降のための仕様。

---

# 1. ボスの役割

Vamp Ponのボスは、ただHPが高い敵ではない。

役割:

```txt
ステージのテーマを体験化する
終盤の山を作る
ビルドの成果を確認する
移動判断を要求する
倒した後の報酬/解放を作る
裏ストーリー断片を渡す
```

---

# 2. ボス戦の基本構造

## 出現時間

Stage 2〜4:

```txt
7:00
```

Stage 5:

```txt
6:30〜7:00
```

## 戦闘時間

```txt
60〜90秒
```

スマホで長すぎるボス戦は避ける。

## 勝利条件

基本:

```txt
ボスHPを0にする
```

Stage 5候補:

```txt
ボスHPを0にする + 欠片回収イベント
```

ただし複雑にしすぎない。

---

# 3. ボスのHP設計

## 原則

ボスは硬いが、耐久だけで時間を稼がない。

## 目標

```txt
普通のビルド: 60〜90秒で撃破
弱いビルド: 時間切れ/苦戦
強いビルド: 45〜60秒で撃破
```

## NG

```txt
2分以上殴り続けるだけ
攻撃が通っているか分からない
HPバーが減らない
```

---

# 4. ボス攻撃パターン原則

## やる

```txt
見て避けられる
予兆がある
安全地帯がある
移動だけで対応できる
パターンが2〜3種類
```

## やらない

```txt
即死
画面全体不可避
細かすぎる弾幕
タップ連打要求
手動エイム要求
複雑なギミック同時発生
```

---

# 5. ボス共通パターン候補

## Pattern A: Line Sweep

```txt
横/縦に影の帯が流れる
予兆後にダメージ判定
```

使い道:

```txt
駅/通学路系
```

## Pattern B: Ink Pool

```txt
足元に黒インクだまりを作る
数秒残る
```

使い道:

```txt
図書室/地図帳系
```

## Pattern C: Summon Shadows

```txt
小型影を呼ぶ
倒すと欠片が出る
```

使い道:

```txt
欠片回収と相性が良い
```

## Pattern D: Memory Pull

```txt
欠片をボス側へ吸う
プレイヤーが拾うと押し返せる
```

使い道:

```txt
Stage 5専用候補
```

## Pattern E: Safe Lane

```txt
一部だけ安全な通路を残して影が通る
```

使い道:

```txt
移動判断を作る
```

# 6. ボス別仕様候補

## Stage 2 Boss: 名札をなくした影

### テーマ

```txt
名前
通学路
紙片
```

### パターン

```txt
紙くずの影を召喚
横方向に紙片の流れ
短い突進
```

### 狙い

```txt
速い敵に慣れたか確認する
```

### 報酬

```txt
新パッシブ候補解放
図鑑断片
```

---

## Stage 3 Boss: 塗りつぶされた司書

### テーマ

```txt
図書室
黒インク
読めないページ
```

### パターン

```txt
黒インクだまり
ゆっくり広がるもや
本の影を召喚
```

### 狙い

```txt
範囲武器/位置取りの重要性を作る
```

### 報酬

```txt
新武器候補解放
図鑑断片
```

---

## Stage 4 Boss: 終点のない車掌

### テーマ

```txt
駅
切符
行き先
迷子
```

### パターン

```txt
列車状の影が画面端から流れる
安全レーンを探す
迷子の方角を召喚
```

### 狙い

```txt
回り込み/流れへの対応
```

### 報酬

```txt
Stage 5解放
重要な地図帳断片
```

---

## Stage 5 Boss: 朝を忘れた影

### テーマ

```txt
朝
地図帳
最後の空白ページ
黒インク
消えなかった影
```

### パターン

```txt
黒インクで画面を狭める
記憶の欠片を吸う
小型影を大量に呼ぶ
安全地帯を一時的に作る
```

### 狙い

```txt
攻撃力だけではなく、欠片回収と移動の両方を使わせる
```

### 特殊案

ボスが吸った欠片が一定量を超えると、画面が暗くなる。

プレイヤーが欠片を拾うと、朝の光が戻る。

ただし複雑なら後回し。

### 報酬

```txt
初期ワールドクリア
最後の空白ページ
エンディング断片
```

# 8. ボス報酬

## 候補

```txt
新ステージ解放
新武器/パッシブ解放
図鑑断片
実績
記憶片
```

## MVP後ルール

ボス報酬は嬉しくするが、必須進行を複雑にしない。

---

# 9. ボス実装順

本格ボスを作るなら、順番は以下。

```txt
1. Stage 2 Boss: 名札をなくした影
2. Stage 3 Boss: 塗りつぶされた司書
3. Stage 4 Boss: 終点のない車掌
4. Stage 5 Boss: 朝を忘れた影
```

Stage 5から作らない。

---

# 10. ボスGo条件

ボス実装へ進む条件。

```txt
Stage 1 MVPが面白い
8分ランが成立
記憶カプセルが嬉しい
進化が機能している
必殺技が使われている
スマホで重くない
```

---

# 11. 最重要

Vamp Ponのボスは、アクションゲームのボスではなく、サバイバルローグライトの終盤イベント。

```txt
操作を増やさず、移動・ビルド・欠片回収で勝たせる。
```

これを守る。

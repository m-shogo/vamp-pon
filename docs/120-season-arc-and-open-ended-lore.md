# Season Arc and Open-ended Lore

## 目的

Stage 1〜5の物語が良すぎて、1本目で世界を閉じてしまう問題を防ぐ。

Vamp Ponを長く続けられるIPにするため、最初の5Stageを「全体の完結」ではなく「最初の章」として設計する。

---

# 1. 結論

Stage 1〜5は、Vamp Pon全体の真相ではない。

```txt
Stage 1〜5 = 最初の地図帳 / 最初の忘れ物係の班 / Season 1
```

ここで一度気持ちよく終わる。

しかし、世界全体は閉じない。

---

# 2. 何を閉じるか

Season 1で閉じるもの:

```txt
ユイの最初の喪失
アサの名前
最初の地図帳の空白ページ
忘れ物係という遊びの意味
朝はちゃんと来る、という実感
```

これはちゃんと回収する。

回収しないと、プレイヤーが気持ちよく終われない。

---

# 3. 何を残すか

Season 1で残すもの:

```txt
他の地図帳
他の忘れ物係
街の外
別の夜
別の欠片
別の班
黒インクの本当の起源
```

ただし、全部を匂わせすぎない。

余白として残す。

---

# 4. 5人の扱いを修正

以前の案:

```txt
5人 = 物語全体の中心
```

これは長期運用だと強すぎる。

修正版:

```txt
5人 = 最初の地図帳を作った子たち
```

つまり、彼らは重要だが、世界唯一の存在ではない。

他にも別の場所に、別の忘れ物係がいた可能性を残す。

---

# 5. Stage 1〜5の新しい位置づけ

## Stage 1: ユイ / 拾うこと / 忘れ物

Season 1の入口。

## Stage 2: アサ / 名前 / 名札 / 通学路

ユイが「呼ばれていなかった」という誤解を崩す。

## Stage 3: ナギ / 箱 / 図書室 / しまったもの

「しまう」は閉じ込めることではなく、残すことだと分かる。

## Stage 4: ミチル / 駅 / 切符 / 帰る道

「帰り道」は場所ではなく、帰る相手だと分かる。

## Stage 5: トモリ + 最初の班 / 灯り / 朝 / 最初の地図帳

Season 1の締め。

ただし「最後の地図帳」ではなく、

```txt
最初の地図帳
```

にする。

---

# 6. 名前の修正

危険な名前:

```txt
最後の地図帳
最後の空白ページ
世界最後の夜
```

これらは完結しすぎる。

推奨:

```txt
最初の地図帳
はじまりの空白ページ
朝を待つ地図帳
まだ読めない余白
```

---

# 7. Season 1エンディング

Season 1の最後はハッピーにする。

ただし、全世界の問題は解決しない。

終わるもの:

```txt
ユイは、自分が一人ではなかったと知る
アサの名前が読める
最初の班の約束が朝に届く
```

残るもの:

```txt
他のページがまだ黒い
地図帳の外側にも余白がある
別の筆跡が一瞬だけ見える
```

最後の一文候補:

```txt
朝になった。
このページの名前は、もう消えなかった。
```

「全部の名前」ではなく「このページの名前」にする。

---

# 8. 余白の残し方

やってよい:

```txt
別の筆跡
別の地図帳の背表紙
知らない印
消えかけた別のランタン
遠くの街灯
```

やってはいけない:

```txt
次の敵の名前を露骨に出す
続編前提の未完エンドにする
黒幕を出す
Season 1の感動を壊す
```

Season 1は、単体で気持ちよく終わる。

でも、世界の余白は残る。

---

# 9. 1アイディアで突き進む方法

核は変えない。

```txt
消えたと思っていたものは、本当は小さな形で残っていた。
それを拾って、朝まで残る。
```

Seasonが増えても、毎回この核に戻す。

変えるのは素材。

```txt
Season 1: 記憶 / 地図帳 / 忘れ物
Season 2: 手紙 / 郵便箱 / 届かなかった言葉
Season 3: 写真 / アルバム / 写っていないと思った人
Season 4: 音 / ラジオ / 聞こえなかった声
```

---

# 10. アプリが増える時の考え方

Vamp Pon本編だけで全部使い切らない。

別アプリ/続編では、以下を変えられる。

```txt
拾うもの
舞台
欠片の形
黒インクに相当するもの
プレイアブル班
最後に戻る感情
```

変えないもの:

```txt
自動攻撃
短時間ラン
欠片回収
一時的に強くなる
朝/区切りでほどける
意味だけは残る
```

---

# 11. カイロソフト的な運用

大事なのは、巨大な一本の神話ではない。

```txt
分かりやすい型
遊びやすい小さな完結
テーマ違いの拡張
気持ちいい反復
少しずつ増える余韻
```

Vamp Ponも、1作ごとに気持ちよく完結する。

でも、型として次を作れる。

---

# 12. 最重要

Season 1は完結させる。

IPは閉じない。

```txt
このページは救う。
でも、地図帳にはまだ余白がある。
```

これが長期運用に耐えるバランス。

# 4. Dialect / accent / register rule

方言はCharacter iconとして毎行使わない。

## Dialect visibility levels

- `D0_STANDARD_DOMINANT` — 普段ほぼ標準語
- `D1_LIGHT_RESIDUE` — 語尾 / 単語 / intonationに少し残る
- `D2_HOME_REGISTER` — 家族 / 同郷相手で明確に戻る
- `D3_EMOTION_BREAKTHROUGH` — 強い驚き / 怒り / 恐怖 / 安堵で隠していた方言が出る

一人のCharacterがsceneによってD0→D3へ変化してよい。

## High-value triggers

方言 / hometown registerが出やすい:

- 驚く
- 本気で怒る
- 泣く
- 怖い
- 安心した瞬間
- 寝起き / 眠い
- 実家へ電話する
- 親 / 祖父母 / siblingと話す
- 幼なじみと再会
- hometown foodを食べる
- 酔う（成人確認済みCharacterのみ）

## Hidden-dialect character

高価値Candidate:

> 普段は「東京で浮かないように」意識して標準語。
> しかし感情が切れると故郷の言葉が出る。

理由は必ずしも恥ではない。

- workplaceで通じやすくする
- schoolで合わせる
- actor / service job等のprofessional register
- 引っ越して長い
- 自分で使い分けている

等でもよい。

## Forbidden

- 方言 = 頭が悪い
- 方言 = 田舎者
- 方言 = comic relief only
- 標準語 = 知的 / 正しい
- 一地域の全員が同じ強さの方言
- phonetic spellingを過剰にして読めなくする

# 7. Reality pilgrimage / commercial-value rule

Goal:

> **Story first → place becomes beloved → player wants to visit.**

Not:

> tourist spot first → force Character to advertise it.

## Three anchor types per strongly localized Character

### DAILY ANCHOR

Characterが普通に使う場所。

- station
- shopping street
- park
- bridge
- library
- ordinary intersection

### EMOTIONAL ANCHOR

重要Relationship / quiet sceneが起きる場所。

### INCIDENT ANCHOR

fictional Reality incidentと接続する公共空間。

Sensitive real memorials / disaster sitesをfictional catastropheの見世物へしない。

## Exact home privacy

- real ward / city may be Canon
- exact real apartment / house addressをCanonにしない
- residenceはfictional block / composite streetでよい

## Business handling

実在店を悪役 /事故現場 /問題企業へしない。
Specific shopをStory coreへ使う場合はseparate legal / permission review。
通常は:

- 商店街 / category
- fictional shop inside real area
- composite business

を使う。

## Commercial expansion candidates

Story完成後に:

- digital location map
- pilgrimage stamp / check-in
- local collaboration
- character food collaboration
- station / transit collaboration
- seasonal event

へ広げられる。

**Canonはcollaborationのために歪めない。**

# 8. Cross-era place inheritance

同じ場所を別Era Characterが知っていることは強い伏線になる。

Example grammar:

```txt
Older Era: empty lot / factory / old tram stop / river path
↓
Middle Era: redevelopment / road / school / apartment
↓
Present: convenience / station / tower / park
↓
Future: preserved digital layer / renamed district
```

Dreamではtime tagが弱いため:

> 「そこ、そんな建物だった？」

という会話だけでEra differenceを出せる。

場所の継承をすべて血縁と結びつけない。

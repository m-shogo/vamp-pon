# 画面起点の素材制作計画

Vamp Pon を「ゲーム画面で売れる見た目」にするため、素材制作は単体画像の完成度ではなく、実際の表示場所から逆算する。

## 優先順

1. 画面のアイテム
   - HUD下部インベントリ、レベルアップカード、カプセル報酬で常に見える。
   - 180px原本だけでなく、実表示の64px/32pxで読めることを採用条件にする。
   - まずゲーム本体に存在するIDを優先し、Asset FactoryだけにあるIDはruntime採用判断を先に行う。
2. キャラ二人
   - まず操作キャラと相棒として画面に出す二人を整える。
   - 現実装ではユイが操作キャラ、アサが次の相棒/二人目候補。
   - 390x844で、プレイヤー本体、HUD肖像、カットインの見え方をまとめて確認する。
3. Stage1/Stage2エネミー
   - 図鑑用の数を増やす前に、実際のウェーブに出る敵だけを作る。
   - Stage1/2の敵は役割差が画面で読めることを優先する。

## 画面アイテムの採用基準

現在のゲーム本体は以下を直接ロードする。

```txt
public/assets/prototypes/sprite-sheets/weapon/<itemId>.png
public/assets/prototypes/sprite-sheets/passive/<itemId>.png
public/assets/prototypes/sprite-sheets/rare/<itemId>.png
```

原本は180x180 PNG RGBA。画面上では主に以下で見える。

| 場所 | 目安サイズ | 見せ方 |
|---|---:|---|
| HUD下部スロット | 32〜34px | 一瞬でカテゴリと形が読める |
| レベルアップカード | 60〜74px | 名前と説明を補強する主役絵 |
| カプセル報酬 | 100px前後 | ご褒美として気持ちよく見える |
| 図鑑/レビュー | 180px | 原本品質と余白を確認する |

必須条件:

- 32pxでシルエットが読める。
- UI枠、レア枠、文字、数字を焼き込まない。
- 白背景、チェッカー背景、白フリンジを残さない。
- 透明余白があり、アイコンがセル端に触れない。
- 同じカテゴリ内でスケール感が揃う。

## 最初に作る/見直すアイテム

ゲーム本体の現IDを優先する。

| 優先 | runtime ID | 表示名 | 理由 |
|---:|---|---|---|
| 1 | `night_pencil` | 夜の鉛筆 | ユイ初期武器。最初に見えるが32pxで細すぎる |
| 2 | `black_ink_bottle` | 黒インクの小瓶 | Stage1ビルドの主力候補。瓶/毒の誤読を避ける |
| 3 | `old_ticket` | あったか靴 | 現runtimeの移動速度パッシブ。互換性のためIDは維持し、画面上のモチーフは `warm-shoes` 相当に寄せる |
| 4 | `name_tag` | 誰かの名前札 | 夜の鉛筆の覚醒導線。覚醒素材としての価値を画面で伝える |

Asset Factory側の `warm-shoes` と `dawn-ticket` は良い制作対象だが、現runtimeにはまだ同名IDがない。
`warm-shoes` は runtime ID として追加せず、互換性維持のため `old_ticket` に吸収採用済み。
`dawn-ticket` は復帰/救済/朝方向のレア候補として扱い、復帰仕様が固まるまで無理にruntime追加しない。
`name_tag` は覚醒素材、`dawn-ticket` は復帰レア候補として役割を分け、両者を混ぜない。

## キャラ二人

最初に画面で完成度を見る二人:

| 優先 | ID | 用途 | 見る場所 |
|---:|---|---|---|
| 1 | `yui` | 操作キャラ、HUD、通常カットイン | 戦闘画面、レベルアップ、必殺演出 |
| 2 | `asa` | 二人目/相棒候補 | キャラ選択、相棒効果、将来のペア必殺 |

ユイは既存ルール通り、ランタンは本人の右手、バッグは本人の左腰。アサは既存seed上はマッチケース/火花系だが、ゲーム本体の初期武器は `postcard_blade` なので、画面に出す前にビジュアル設定と初期武器の整合を見る。

## Stage1/Stage2エネミー

現在のruntimeウェーブで実際に出る敵を優先する。

| runtime ID | Stage | 画面上の役割 |
|---|---|---|
| `ink_shadow` | 1/2 | 基本追尾 |
| `paper_scrap_shadow` | 1/2 | 突進/紙片 |
| `lost_direction` | 1/2 | 回り込み |
| `black_capsule` | 1/2 | 追う報酬敵 |
| `night_haze` | 1/2 | 群れ/面圧 |
| `black_label_shadow` | 1/2 | エリート/ボス役 |

`ombu-umbrella-shield` のような新敵はStage1候補として有望だが、runtimeウェーブへ入れる判断と同時に行う。単体シートだけ先に増やしすぎない。

## 直近の進め方

1. 既存27アイコンの180/64/32pxレビューシートを基準に、画面で弱いものを選ぶ。
2. `night_pencil` と `black_ink_bottle` を先に作り直し、HUD/レベルアップカードで確認する。
3. `old_ticket` は互換性のためIDを維持し、表示名・説明・アイコンを `warm-shoes` 相当に寄せる。
4. `name_tag` は覚醒素材として、`dawn-ticket` は復帰/救済/朝方向のレア候補として整理する。役割を混ぜない。
5. ユイ/アサの画面表示へ進み、その後Stage1/2エネミーを実装順に作る。

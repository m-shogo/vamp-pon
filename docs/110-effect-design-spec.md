# Effect Design Spec

## 目的

Vamp Ponのエフェクト設計を整理する。

エフェクトは重要。

ただし、派手にするためではなく、以下を伝えるために使う。

- 当たった
- 倒した
- 拾った
- 強くなった
- 危ない
- 助かった

---

# 1. 基本方針

```txt
短く
軽く
意味がある
視認性を邪魔しない
```

Vamp Ponのエフェクトは、紙片・光・黒インクを中心にする。

---

# 2. エフェクトの役割分担

## 金色/暖色

意味:

- 記憶
- 回収
- 成長
- 安全
- 必殺技

使う場面:

- 欠片
- レベルアップ
- 進化
- 必殺技
- ランタン

## 黒インク

意味:

- 敵
- ダメージ
- 消えかけ
- 危険

使う場面:

- 敵ヒット
- 敵死亡
- 黒インク床
- ボス

## 赤

意味:

- HP減少
- 被弾
- 危険

使いすぎない。

---

# 3. Prototype 1で必要なエフェクト

## Player move

- 足元に弱いランタン光
- 移動軌跡は最小

## Enemy hit

- 小さいインク粒
- 敵が一瞬だけ揺れる/縮む

## Enemy death

- 黒インクがふっと散る
- 金色欠片が出る

## Fragment magnet

- 欠片が光を少し強める
- 曲線的に寄る

## Fragment collect

- 小さい光
- XPゲージが動く

## Level up

- 一瞬停止
- ユイが少し光る
- HUD/Lvが目立つ

---

# 4. Prototype 2以降のエフェクト

## 武器別

夜の鉛筆:

- 細い金色線
- 進化で文字の一行のような光跡

ビー玉:

- 丸い反射光
- 反射時に小さな光

月のしおり:

- 周囲を回る紙片
- 防御範囲が分かる

黒インクの小瓶:

- 地面の黒いにじみ
- 範囲の縁を薄く表示

星くず弾:

- 小さい星の粒
- ばらまきすぎ注意

---

# 5. Prototype 3 / MVPのエフェクト

## Capsule

- 小瓶が光る
- 取得時に短い紙片演出
- 長くしない

## Evolution

- 画面停止
- 武器名変化
- ユイ周囲に光
- 進化武器の初回発動を少し強調

## Ultimate: 消えない名前

- 右下ボタン発光
- 発動時にユイ中心の暖色円
- 欠片が一斉に吸い寄せられる
- 小型影が欠片に戻る
- 画面が少し明るくなる

---

# 6. エフェクト上限

Prototype 1:

```txt
小粒パーティクル中心
画面揺れなしでもよい
大きな発光なし
```

Prototype 3:

```txt
maxParticlesを意識
敵/欠片/弾が見える範囲
```

## NG

- 敵が見えない
- 欠片が見えない
- 弾が欠片に見える
- 毎回大爆発
- 長い演出でテンポが止まる
- スマホで重い

---

# 7. 画面揺れ

Prototype 1では原則なし。

Prototype 2以降で使うなら:

- 強敵撃破
- 進化
- 必殺技

だけ。

設定でOFF可能にする。

---

# 8. ダメージ数字

Prototype 1では任意。

入れる場合:

- 小さく
- 短く
- 敵の上に出す
- 欠片と混同しない色

Prototype 2以降で設定OFFを検討。

---

# 9. 音との連携

エフェクトとSEは役割を合わせる。

- 欠片取得: 軽い高音
- 敵ヒット: 小さいインク音
- 敵死亡: ぽん/ふわっと
- レベルアップ: 紙が開く+光
- 進化: 短いご褒美音

---

# 10. エフェクトQA

以下を毎回見る。

- 気持ちいいか
- 何が起きたか分かるか
- 敵/欠片を邪魔していないか
- 連続発生しても重くないか
- スマホで目が疲れないか

---

# 最重要

エフェクトは、ゲームの意味を伝えるためにある。

```txt
派手さより、反応の気持ちよさ。
```

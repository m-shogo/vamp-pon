# キャラ・必殺技 追加アイディア集

## 目的

キャラごとの必殺技案をさらに広げる。

Vamp Pon では、必殺技を単なる大ダメージ技にしない。

以下を同時に満たすものを優先する。

```txt
気持ちいい
分かりやすい
操作を忙しくしない
キャラ差が出る
裏ストーリーの断片になる
条件達成/実績/図鑑とつながる
```

## 基本方針

必殺技は、以下のどれかの役割を持たせる。

```txt
一掃する
吸い寄せる
守る
逃がす
変換する
止める
戻す
開ける
照らす
記録する
```

Vamp Pon の裏ストーリーに合わせるなら、特に強いのは、

```txt
戻す
照らす
記録する
開ける
```

## 発動条件アイディア

### ゲージ蓄積

```txt
敵を倒す
経験値を拾う
記憶欠片を拾う
時間経過
ダメージを受ける
アイテムを拾う
図鑑未登録の敵を倒す
黒インク上を一定時間耐える
```

### 自動発動条件

```txt
HP30%以下
周囲に敵が一定数以上
ボス出現時
黒インクに囲まれた時
死亡ダメージを受けた時
残り時間60秒
武器進化時
秘宝武器獲得時
```

### 手動発動条件

```txt
ゲージ満タンで1ボタン
長押しなし
方向指定なし
チャージなし
```

## 裏ストーリー連動のびっくり案

### 1. 必殺技名が変わる

最初:

```txt
黒インク払い
```

図鑑進行後:

```txt
消えかけた道
```

さらに後:

```txt
最後に残った道
```

効果は同じでも、名前だけ変わる。

### 2. 説明文が増える

最初:

```txt
周囲の影を払う。
```

進行後:

```txt
周囲の影を払う。影の下には、消えた文字がある。
```

### 3. 必殺技の演出が少し変わる

図鑑が埋まるほど、影を倒した時に欠片ではなく文字/切符/星が少し混ざる。

### 4. 最終盤で効果が変わる

最終ステージだけ、必殺技が敵を消すのではなく、影を名前に戻す演出になる。

### 5. プレイヤーの行動で最後の必殺技説明が変わる

一番使った必殺技によって、最後のページの文が変わる。

```txt
消えない名前を多用 → 名前を戻した人
黒インク払いを多用 → 道を取り戻した人
朝まで残る光を多用 → 夜を見張った人
```

## MVPで選ぶべき3つ

### 1. 消えない名前

理由:

```txt
初心者向け
吸引が気持ちいい
裏ストーリーと合う
実装しやすい
```

### 2. 黒インク払い

理由:

```txt
爽快感がある
地図帳テーマに合う
ピンチ救済になる
画面整理が分かりやすい
```

### 3. 朝まで残る光

理由:

```txt
防御型キャラを作れる
終盤の詰み救済
演出が分かりやすい
```

## 後回しでよいもの

```txt
巻き戻し系
ワープ系
ランダムカプセル系

最終盤だけ効果変化
```

これらは面白いが、最初から入れると重い。

## 結論

キャラ別必殺技は、Vamp Pon の独自性になり得る。

ただし、最初は以下に絞る。

```txt
吸引型
一掃型
防御型
```

この3タイプを作れば、キャラ差、爽快感、救済、裏ストーリーが揃う。

最初の候補は、

```txt
忘れ物係: 消えない名前
地図読み: 黒インク払い
夜番: 朝まで残る光
```

この3人。

# Unstable Bond / Variance System

## 目的

仲が悪い関係、誤解が強い関係、思想が衝突している関係を、単なるマイナスではなくゲーム上の面白さに変換する。

Vamp Ponでは、関係性を以下にしない。

```txt
仲が良い = 強い
仲が悪い = 弱い
```

正しくは以下。

```txt
接続が安定している = 安定して強い
接続が不安定 = 上振れが大きいが、下振れもある
```

---

# 1. 採用/保留/却下

## 採用

```txt
仲が悪い/誤解が強い組み合わせほど上振れ・下振れがある
関係性の不安定さをランダムステータスとして表現する
不安定コンビは高火力・高リスクにする
安定コンビは低リスク・安定補助にする
上振れ/下振れに物語上の理由を持たせる
```

## 保留

```txt
完全ランダムなステータス変動
キャラごとに個体値のような乱数を持たせる
失敗時に恒久的な悪影響を残す
```

## 却下

```txt
ただの運ゲーにする
友情ポイントが低いほど弱いだけにする
不仲キャラを使う意味がないバランスにする
上振れ/下振れの理由が物語と無関係
```

---

# 2. 世界観上の理由

友情ポイント/きずなは、好感度ではない。

```txt
きずな = 意味の接続安定度
```

だから、不仲や対立は単純な弱さではない。

むしろ誤解が強い組み合わせは、接続が荒い。

```txt
強くつながる瞬間がある
でも、すぐほどける危険もある
```

これが上振れ・下振れの理由。

---

# 3. ステータス分類

## 安定型

関係性:

```txt
信頼
長い付き合い
誤解がほどけている
```

性能:

```txt
ダメージは中程度
範囲や回復が安定
失敗リスクが少ない
リザルト文が安定して良い
```

例:

```txt
ユイ + トモリ
```

---

## 不安定型

関係性:

```txt
仲が悪い
思想が違う
誤解が残っている
```

性能:

```txt
上振れ時は高火力/強効果
下振れ時は欠片喪失/クールタイム増/黒インク増加
```

例:

```txt
ユイ + 影系統キャラ
ナギ + 手紙系統キャラ
```

---

## 片寄り型

関係性:

```txt
片方だけが理解している
片方だけが隠している
```

性能:

```txt
一部能力だけ突出
特定条件では強い
条件外では弱い
```

例:

```txt
アサ + 名前を嫌うキャラ
ミチル + 帰りたくないキャラ
```

---

## 禁忌型

関係性:

```txt
本来同時に扱うべきでない意味を無理につなぐ
```

性能:

```txt
非常に強いが大きな代償
隠しビルド向け
ストーリー上も危険
```

例:

```txt
返却系統 + 背表紙系統
影系統 + 灯り系統
```

---

# 4. 上振れ/下振れの具体例

## ユイ + 影系統キャラ

関係性:

```txt
返す思想と隠す思想の衝突
```

上振れ:

```txt
一気に黒インクの固定を剥がす
広範囲高火力
レア欠片が多く落ちる
```

下振れ:

```txt
欠片の一部が黒インクへ戻る
画面端に新しい影が湧く
リザルト文が不完全になる
```

物語意味:

```txt
返すべき意味と、隠した方が守れる意味が衝突している。
```

---

## ナギ + 手紙系統キャラ

関係性:

```txt
しまうことと届けることの対立
```

上振れ:

```txt
危険な理由を箱にしまい、手紙だけ安全に届ける
ボスの攻撃を一時封印
```

下振れ:

```txt
守りすぎて手紙の到着が遅れる
必殺技の発動が遅延
一部イベントが次ページへ持ち越し
```

物語意味:

```txt
守るために閉じるのか、伝えるために開けるのかが揺れている。
```

---

## ミチル + 帰りたくないキャラ

関係性:

```txt
道を読む者と、道を拒む者
```

上振れ:

```txt
敵の進路を逆利用する
逃げ道が攻撃ルートになる
```

下振れ:

```txt
道しるべが逆向きになる
一時的に移動速度低下
拾った欠片が遠くへ散る
```

物語意味:

```txt
道があることと、帰りたいことは同じではない。
```

---

# 5. ランダム性の扱い

ランダムは入れてよい。

ただし、完全運ゲーにしない。

## 良いランダム

```txt
上振れ/下振れの幅が事前に分かる
関係性から理由が分かる
プレイヤーが選んだ結果として受け入れられる
強い代わりに不安定
```

## 悪いランダム

```txt
理由なく失敗する
強いか弱いかが完全に運
リザルトが納得できない
キャラの関係性と無関係
```

# 6. UI案

コンビ選択画面で、関係性を数値だけでなく形で見せる。

```txt
安定
不安定
片寄り
禁忌
```

表示例:

```txt
きずな: 42
接続: 不安定
上振れ: 高
下振れ: 中
副作用: 欠片が黒インクへ戻ることがある
```

よりVamp Ponらしい表示:

```txt
結び目: ゆるい
灯り: 強い
影: 濃い
折り目: ずれている
```

---

# 7. 必殺技への反映

## 安定コンビ必殺

```txt
発動しやすい
効果が安定
副作用なし
```

## 不安定コンビ必殺

```txt
発動時に上振れ/下振れ判定
上振れなら高火力/広範囲/レア欠片
下振れなら黒インク増加/欠片喪失/CT増
```

## 禁忌コンビ必殺

```txt
非常に強い
ただし、リザルト文が不穏になる
隠し分岐や後作Seedに接続できる
```

---

# 8. リザルト文への反映

同じクリアでも、コンビの安定度でリザルト文が変わる。

## 安定

```txt
ふたつの文字は、同じ行に並んだ。
```

## 不安定・上振れ

```txt
折れた線が、思いがけず近道になった。
```

## 不安定・下振れ

```txt
読めたはずの一文字が、また黒くにじんだ。
```

## 禁忌

```txt
ページは読めた。
けれど、綴じ糸が一本だけ別の色に変わっていた。
```

---

# 9. バランス方針

不安定コンビは、期待値で安定コンビを少し上回ってよい。

理由:

```txt
プレイヤーがリスクを取る意味が必要
```

ただし、下振れが理不尽だと使われない。

目安:

```txt
安定コンビ: 平均70 / 振れ幅10
不安定コンビ: 平均75 / 振れ幅35
禁忌コンビ: 平均90 / 振れ幅60 / 物語副作用あり
```

これは最終数値ではなく設計方針。

# 10. 初期実装への落とし込み

P1では不要。

P2以降で検討。

最小実装:

```txt
コンビタイプだけ持つ
安定/不安定の2種類
必殺技の効果量にランダム幅
リザルト文差分
```

発展実装:

```txt
きずなゲージ
上振れ/下振れイベント
不安定コンビ専用ビルド
禁忌コンビ
シリーズSeed連動
```

---

# 11. 最重要

上振れ/下振れは、単なる乱数ではない。

```txt
関係性の接続が安定しているか、不安定か。
```

これをゲーム化したもの。

仲が悪い関係は弱いのではない。

```txt
強いが、ほどけやすい。
```

これがVamp Ponの不安定きずなシステム。

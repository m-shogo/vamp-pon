# 0. Pilgrimage design rule

Strong pilgrimage place:

```txt
ordinary action
+
repeated relationship beat
+
Character-specific object / food / route
+
small emotional change
```

弱い例:

> famous landmarkの前でCharacterが立っているだけ。

強い例:

> いつも同じ角で待っていた。
> 昔は一人だった。
> 後のSeasonでは元敵と二人で待つ。

場所の意味がrelationship historyで増える。

---

# 1. Hard boundary

- exact home addressを公開しない。
- 実在住宅をCharacter自宅扱いしない。
- 実在店舗を無断で悪役企業 / 事故現場 / 犯罪拠点にしない。
- 実在店とのcollaborationは後の別review。
- tourist popularity != Story value。
- root Candidateをこの文書だけでCurrentへ上げない。
- dialect / food / appearanceから出身地を逆算しない。
- brown skin != foreign origin。
- wheelchair != pilgrimage burden story。
- animal Characterを観光mascot化しない。
- Chloeへsingle true hometownを早期設定しない。
- Future locationを現在のreal cityへ無理に固定しない。

Promotion gate Candidate:

> exact placeを「聖地候補」として公開する前に、Story内で最低2回以上、異なる感情のsceneに使えるか確認する。

例:

1. ordinary scene
2. conflict / separation / return scene

同じ場所の意味が変わることを優先。

# 5. Pilgrimage-worthiness matrix

Exact locationを後で選ぶ時、点数化Candidate:

| Axis | Question |
|---|---|
| Repetition | Storyで2回以上自然に出るか |
| Ordinary life | 事件がなくてもCharacterが来るか |
| Relationship | 別Characterとの関係が変化する場所か |
| Object/Food | Character固有の小物/食/routeと結び付くか |
| Era texture | 時代差を説明台詞なしで感じられるか |
| Reality fit | root / mobility / householdと矛盾しないか |
| Respect | 実在business/residentへnegative fictionを押し付けないか |
| Visit value | Fanが歩いた時「ここで暮らしてた感じ」があるか |

Suggested promotion:

- 6/8以上: strong location candidate
- 4–5: background/research reservoir
- 0–3: famous-only decoration。再設計。

Score is design aid, not Canon truth.

# 6. Same place, changed meaning reservoir

聖地化を強くする構造。

## Type A — Alone → Together

S1:
- Character alone waits.

S2:
- same place with former enemy / new friend.

## Type B — Useful → Painful → Useful again

- route initially convenient
- incident changes meaning
- after resolution ordinary people still use it

Real tragedy site copyは禁止。

## Type C — Parent/child without knowing

Cross-era Dream relationのechoとしてReality placeへ似たhabitを置ける。

Nagi→Yui parent Candidateへ使う場合:
- same physical place proofは慎重
- surname/photo/one-placeだけでbloodline confirmation禁止

## Type D — Object remains / person changes

- repaired chair
- route mark
- old timetable
- cup
- handwritten note

Object history gives rewatch value。

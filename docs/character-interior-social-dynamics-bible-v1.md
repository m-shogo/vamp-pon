# 1. Character interior contract

各人物は最低:

- `desire` — 本人が欲しいと思っているもの
- `need` — 成長に必要だが本人が最初は気づかないもの
- `selfLie` — 悪意ある嘘ではなく、自分を守るため信じている単純化
- `shameTrigger` — 笑い物にするためでなく、弱さが出る地点
- `boundary` — どんな状況でも越えたくない線
- `repairAction` — 失敗後にその人らしく何をするか

を持つ。

# 2. Current21 interior matrix

## ユイ

Self Lie: **自分が見つけたなら、自分が最後まで戻さなければ。**

Boundary: 持ち主が嫌がる記憶を勝手に公開しない。

# 4. Recurring Gag Bible

シリアス世界で、同じ人物を何度も好きになるための軽い反復。

1. ユイが「これ誰の？」と持ち主不明品を中央へ置く。
2. アサが紙コップ / 包みへ全員の名前を書く。
3. ナギがしまう前に二回確認し、三回目を我慢する。
4. ミチルが紙ナプキンまで地図にする。
5. トモリが会話中に椅子 / 留め具を直している。
6. センが説明中、空中へ指で図を書く。
7. リツが食べ物を受け取ると反射で人数を数える。
8. コヨリが食べ物へ名前 / 顔を描こうとする。
9. ゲンが「昔はな」と始めた後、本当に便利な近道を出す。
10. ハナが拾った花をいつの間にかしおりにして返す。
11. ユウビが手渡す直前に宛名をもう一度見る。
12. マドカが言い出す前に紙飛行機 / 視線で先に気づかせる。
13. シロが「その他」を作れず、最終的に「未分類」を作る。
14. トバリが全員通った後に自分が最後になる。
15. ネムが会話を聞いていないようで核心だけ覚えているCandidate。

## Gag guard
- 同じギャグを毎回同じ台詞でやらない。
- humiliating gagにしない。
- 身体 / sexuality / disability / ageを笑いの中心にしない。
- 終盤で一度だけ反復が止まると感情サインとして使える。

# 5. Callback Bank — functions first

Iconic quoteは「名言を書こう」と力むより、普通の言葉を反復する。

## CBL-01 「これ誰の？」 function
Early: ユイが普通の忘れ物へ。
Late: 持ち主を勝手に決められた名前 / 記憶へ。
Payoff: **所有者を探す問い自体が主人公の倫理になる。**

## CBL-02 「まだ開けない」 function
Early: ナギの日常。
Late: 守り /秘密 / Boss。
Payoff: 「開けない」→「いつ開けるか一緒に決めよう」。

## CBL-03 「昔はこれで合ってた」 function
Early: ゲンの昔話。
Late: 地図改訂事件。
Payoff: 間違いではなく時点の違い。

## CBL-04 「分からない、で置いとく」 function
Early: シロの分類。
Late: Main Mystery / ハクマへの対抗。

## CBL-05 「半分でいい」 function
Early: 食べ物。
Late: リツが負担を分ける場面。

## CBL-06 「届いたら終わりじゃない」 function
Early: 郵便の軽口Candidate。
Late: ユウビの成長。

Exact wordingはVoice Book review後に確定する。

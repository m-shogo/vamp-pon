## 1. Rule

体型の多様性を「一人で完結するvisual trait」にしない。

Character popularityは:

```txt
単体
+ Star Beast
+ Named Object
+ Relationship
+ Scene
```

の複数入口から育てる。

ただし:

> **favoriteRelationship != romance vote**

- 友情 / family / ideological mirror / quiet trustを人気だけで恋愛へ変更しない。
- 体型が同じ / 違うことをrelationshipの理由にしない。
- body positivityを説教するためだけの会話を作らない。

## 2. ハナ × ツムギ — 保存 / 傷跡

Current relation:

- ハナ = きれいに保存し、次へ渡す。
- ツムギ = 傷や余白も履歴として残す。

このpairの魅力:

- material culture
- paper / cloth / repair
- 年長女性と若いShadowの静かな会話
- 「直す/残す」の答えを日常小物で見せられる

### Scene reservoir

1. 破れた押し花台紙を前に、ハナが新しい台紙へ移そうとする。
2. ツムギは古い破れも残したいと言う。
3. 二人で「古い台紙の小片を新しい頁へ一緒に綴じる」方法を作る。
4. ハナは保存=無傷ではないと知り、ツムギは傷を残すこと自体を目的にしなくなる。

### Commercial lane

- 2枚1組bookmark
- old/new paper texture postcard
- 花 + 糸 + 余白のstationery
- relation illustration: 同じ机で別の修理方法を選ぶ二人

Romance化不要。静かなmaterial pairとして十分商品価値がある。

## 3. ハナ × シロ — 分かる物 / 分からない物を残す

Current relation:

- ハナ = 何のために残すかを生活経験から判断する。
- シロ = 意味がまだ分からない物も未分類で残す。

このpairの魅力:

- 年代差
- archive / collection
- 「価値を知って保存」vs「価値が不明でも捨てない」
- Lorebookそのものと相性が良い

### Scene reservoir

1. ハナが箱の中身を整理する。
2. シロが用途不明の紙片だけ戻してほしいと言う。
3. ハナは理由を聞くが、シロは「まだ分からないから」と答える。
4. 数run後、その紙片が別人物のNamed Object lineageへつながる。

### Commercial lane

- archive box style goods
- しおりset
- Lorebook限定paper bundle
- ハナの蘇芳 × シロの白練の2色design

## 4. カナメ × ナギ — 二つの守り

Current relation:

- ナギ = 閉じることで守る。
- カナメ = 自分が危険との間へ入って守る。

このpairの魅力:

- 同じ「守る」でもmethodが真逆
- Core / Shadow mirror
- visual silhouetteの差が強い
- Battle / Story / goodsを同じpairで回しやすい

### Scene reservoir

1. ナギは危険な箱を閉じようとする。
2. カナメは閉じる前に中へ残った誰かを迎えに行こうとする。
3. カナメの無茶をナギが止め、ナギの閉じすぎをカナメが止める。
4. 最後は「誰を守るか / いつ閉じるか」を二人で確認する。

### Commercial lane

- 鍵 + 腕帯pair charm
- 小さな蟹 + 大きな灰狼 Star Beast contrast
- 月色 + 蝋色のduo visual
- protective pair battle illustration

Popularityが高くてもromanceへ変更しない。Core / Shadowの思想mirrorを守る。

## 5. カナメ × リツ — Protector × Protector

Current relation:

- 二人とも他者を守ろうとする。
- 相手の無茶は見えるが、自分の無茶は見えにくい。

このpairの魅力:

- 男性同士のcare relation
- 「強い者が一人で背負う」の否定
- battle choreographyが作りやすい
- コヨリを含む3人sceneへ拡張できる

### Scene reservoir

1. 重い荷物を二人同時に持とうとする。
2. 二人がfrontへ出て後方が空く失敗。
3. front intercept / resource split / retreat coverを分担。
4. Dawnで片方の「任せた」を、もう片方が確認し直さず受け入れる。

### Commercial lane

- two-protector emblem
- 腕帯 + 半分の包み紙 motif
- battle formation art
- カナメ / リツ / コヨリ small ensemble

「大柄だから荷物持ち」だけの関係にはしない。

## 7. Series-safe use

ヨルノシルベ2 / 3で再登場する場合:

### Hana

- 作品1で学んだ「保存=無傷だけではない」をresetしない。
- 新作では何を次世代へ渡すか、何を手放せるかへ進める。
- 年齢を若返らせてreturnさせない。

### Kaname

- 作品1で学んだ「全部自分が受けない」をresetしない。
- 新作では守るsystemを誰へ教えるか / 誰に任せるかへ進める。
- 細身体型へredesignしない。

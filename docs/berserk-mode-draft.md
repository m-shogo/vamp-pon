# Berserk Mode Draft

Status: draft / not implemented

暴走モードを必殺技と分離するための暫定仕様案。

## Current problem

現在のHUDには左下に「暴走」表示があるが、実体は必殺技の`ready`と`activeRemaining`を参照している。
必殺技発動中の短い見た目差分であり、独立した暴走モードではない。

必殺技の発動時間は現状0.48秒のポーズ扱いなので、暴走モードのアイコン、カットイン、ゲージを作る前に状態を分離する必要がある。

## Role separation

### Ultimate: 消えない名前

- 安定した救済技
- 手動発動
- 周囲の欠片を吸い寄せる
- 小型の影を欠片へ戻す
- 短い必殺技カットインを表示
- 右上の独立アイコン／ゲージを使う

### Berserk mode

- 高火力だが危うい時間制バフ
- 必殺技とは別ゲージ
- 左下のキャラクターポートレートと外周ゲージを使う
- 発動時に暴走専用カットインを表示
- プレイヤーが手動で発動する

## Proposed MVP rules

### Charge

- 0〜100の独立ゲージ
- 被ダメージで大きく増加
- 近距離で敵を倒すと少し増加
- エリート／中ボス撃破で増加
- 時間経過だけでは満タンにならない

狙いは、苦しい展開を逆転する選択肢にすること。
安全に逃げ続けるだけで毎回使える定期ボタンにはしない。

### Activation

- 100%時に左下ポートレートをタップ
- 発動カットインは約0.45〜0.60秒
- 入力受付を止めすぎず、ゲーム速度を一時的に落とす
- 発動後8秒継続
- 終了後ゲージは0へ戻る

### Buff

暫定値:

- 与ダメージ +30%
- 攻撃クールダウン -25%
- 移動速度 +15%
- ノックバック耐性 +50%

### Risk

暫定値:

- 被ダメージ +20%
- 回復効果 -50%
- 欠片の自動吸引距離 -30%

「押せば常に得」ではなく、攻め切れるタイミングを選ぶモードにする。
ただし終了時スタンや強制HP減少は、爽快感を壊すためMVPでは入れない。

## Ultimate interaction

MVPでは同時発動を禁止する。

- 暴走中は必殺技ボタンを一時ロック
- 必殺技ゲージとREADY状態は保持
- 暴走終了後すぐ必殺技を使える
- 必殺技中は暴走を開始できない

将来、暴走中の必殺技を別演出・別効果へ進化させる余地は残すが、MVPでは実装しない。

## HUD

### Top right

- 必殺技専用アイコン
- 必殺技名: 消えない名前
- charge / READY / TAP

### Bottom left

- 通常時: `portrait_neutral`
- ゲージ満タン: 外周が脈動し`berserk_icon`を表示
- 暴走中: `portrait_berserk`へ切替
- 残り時間を外周ゲージで減算表示
- 小さい「暴走」の文字だけに依存しない

## Cut-in

### Ultimate cut-in

- 暖色の灯り
- 古紙の帯
- 名前や記憶が戻る方向
- 表情は意志が強いが優しい

### Berserk cut-in

- 紫黒と濃紺のインク
- 顔の同一人物性を維持
- 黒い紋章、乱れる布、強い目線
- 怪物化、流血、過剰なホラーは禁止
- 「怒り」だけではなく、忘却に飲まれそうな危うさを出す

両方とも180×180px透過元絵を使い、横長の紙帯や文字はruntime側で合成する。

## Required state separation before art integration

実装時は少なくとも以下を分離する。

- `state.ultimate`
- `state.berserk`
- `ultimateRequested`
- `berserkRequested`
- ultimate active pose
- berserk active duration
- HUD READY / ACTIVE状態
- カットイン再生状態

## Open decisions

実装前に確定が必要:

- 暴走ゲージの正式な獲得式
- 継続秒数
- バフ／リスクの数値
- 各キャラクターで共通仕様か固有仕様か
- 暴走の正式名称
- 友情ポイントとの接続
- 暴走中の必殺技派生を将来採用するか

この文書が確定するまで、暴走専用画像をproduction扱いで量産しない。

# 黒耀化 Draft

Status: draft / implemented baseline / naming fixed

旧称「暴走モード」を、正式には **黒耀化** と呼ぶ。

```txt
共通名: 黒耀化
読み: こくようか
共通ゲージ: 黒耀ゲージ
ユイ固有演出名: 黒灯化
```

内部コード名の `berserk` は当面残す。
これは既存実装への影響範囲を抑えるためであり、プレイヤー表示では使わない。

---

## Current problem

過去のHUDには左下に「暴走」表示があった。
現在は黒耀化として独立ゲージ化し、必殺技とは別状態として扱う。

必殺技は右上の独立ゲージ。
黒耀化は左下のキャラクターポートレート外周ゲージ。

---

## Role separation

### Ultimate: 消えない名前

- 安定した救済技
- 手動発動
- 周囲の欠片を吸い寄せる
- 小型の影を欠片へ戻す
- 短い必殺技カットインを表示
- 右上の独立アイコン／ゲージを使う

### 黒耀化

- 高火力だが危うい時間制バフ
- 必殺技とは別ゲージ
- 左下のキャラクターポートレートと外周ゲージを使う
- 発動時にキャラ固有の黒化カットインを表示
- ユイの場合は **黒灯化** と表示する
- プレイヤーが手動で発動する

---

## Proposed MVP rules

### Charge

- 0〜100の独立ゲージ
- 被ダメージで大きく増加
- 時間経過だけでは満タンにならない

狙いは、苦しい展開を逆転する選択肢にすること。
安全に逃げ続けるだけで毎回使える定期ボタンにはしない。

### Activation

- 100%時に左下ポートレートをタップ
- 発動カットインは約0.45〜0.60秒
- 入力受付を止めすぎず、ゲーム速度を一時的に落とす
- 発動後8秒継続
- 終了後ゲージは0へ戻る
- 終了後は短い黒耀反動へ入る

### Buff

現行実装の基準:

- 与ダメージ 1.5倍
- 継続 8秒
- 終了後に短い移動反動

### Risk

- 発動後に黒耀反動がある
- 必殺技と同時発動できない
- 強いが、押せば常に得ではない

終了時スタンや強制HP減少は、爽快感を壊すためMVPでは入れない。

---

## Ultimate interaction

MVPでは同時発動を禁止する。

- 黒耀化中は必殺技ボタンを一時ロック
- 必殺技ゲージとREADY状態は保持
- 黒耀化終了後すぐ必殺技を使える
- 必殺技中は黒耀化を開始できない

将来、黒耀化中の必殺技を別演出・別効果へ進化させる余地は残すが、MVPでは実装しない。

## HUD

### Top right

- 必殺技専用アイコン
- 必殺技名: 消えない名前
- charge / READY / TAP
- 黒耀化中は `黒耀中` と表示して一時ロック

### Bottom left

- 通常時: `portrait_neutral`
- ゲージ満タン: 外周が脈動し crest を表示
- 黒耀化中: `portrait_berserk` 互換の黒い表情へ切替
- 残り時間を外周ゲージで減算表示
- 表示文言は `黒耀 0%` / `黒耀 OK` / `黒耀 8秒` / `黒耀反動`
- 小さい文字だけに依存せず、外周ゲージ・黒い縁・ポートレート変化で読ませる

## Cut-in

### Ultimate cut-in

- 暖色の灯り
- 古紙の帯
- 名前や記憶が戻る方向
- 表情は意志が強いが優しい

### ユイ黒灯化 cut-in

- 紫黒と濃紺のインク
- 顔の同一人物性を維持
- 黒い紋章、乱れる布、強い目線
- 怪物化、流血、過剰なホラーは禁止
- 「怒り」だけではなく、忘却に飲まれそうな危うさを出す
- タイトル表示は `黒灯化`
- サブ文は `黒い灯りが記憶を照らす`

両方とも180×180px透過元絵を使い、横長の紙帯や文字はruntime側で合成する。

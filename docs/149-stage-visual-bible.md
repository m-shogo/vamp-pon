# Stage Visual Bible

## 目的

Vamp Pon のステージ背景を、キャラ・小物・敵・記憶テーマと接続して設計する。

この文書は、背景を作る時に迷わないための資料。

```txt
キャラごとのステージ
背景モチーフ
見せる小物
出る敵
感情テーマ
リザルト文の方向
```

をまとめる。

---

# 0. 背景の大原則

Vamp Pon の背景は、ただの綺麗な場所ではない。

```txt
記憶が紙の上に残った場所
```

である。

## 共通ルール

```txt
紙片・絵本風ドット
夜の街
地図帳
忘れ物
黒インク
小さな光
朝へ向かう気配
```

## 視認性ルール

```txt
キャラより目立たない
敵より目立たない
ドロップより目立たない
でも、ステージの小物は印象に残る
```

## 色ルール

```txt
青灰
紙茶
くすんだ紫
淡いインク黒
局所的な暖色
```

背景全体を派手にしない。
光は小物やキャラの意味を出すために限定する。

# 2. Stage 01 欠片のページ

対応キャラ:

```txt
ユイ
```

背景:

```txt
夜道
紙の地面
薄い地図線
小さな紙片
遠くにぼんやりした街灯
```

見せる小物:

```txt
記憶の欠片
```

敵:

```txt
まるオンブ
ちびオンブ
にじみオンブ
```

背景ギミック候補:

```txt
拾えなかった欠片が少し黒くにじむ
```

```txt
拾う
待っていたものに気づく
```

リザルト方向:

```txt
落ちていたのではなく、待っていたように見えた。
```

# 10. 背景アセット制作メモ

## タイル背景

```txt
ループ可能
模様控えめ
キャラ/敵/ドロップを邪魔しない
紙の質感は弱め
地図線は薄く
黒インクは敵と混ざらないよう背景では薄く
```

## 印象小物

各ステージに1つだけ強い小物を置く。

```txt
欠片
名札
箱
切符
日記
鏡
鍵
鈴
時計
傘
靴
糸
写真
星図
押し花
笛
本
ぬいぐるみ
半券
インク瓶
```

背景に小物を置きすぎない。
主役小物以外は薄くする。

# 11. リザルト文への接続

背景はリザルト文とセットで意味が反転する。

| ステージ | 最初の見え方 | 反転 |
|---|---|---|
| 欠片 | 落ちている経験値 | 待っていた記憶 |
| 名札 | 名前が消えた | 守るために書き直した |
| 箱 | 閉じ込めた | 壊れないよう閉じた |
| 切符 | 片道だった | 帰りの印が残っていた |
| 日記 | 燃やした | 消えないよう焼き止めた |
| 鏡 | 見たくない | 見ても壊れなかった |
| 鍵 | 開ければ正解 | 開ける責任がある |
| 鈴 | 呼んでも戻らない | 音は残っていた |
| 時計 | 間に合わなかった | 止まったから残った |
| 傘 | 入れなかった | 次は入れてあげられる |

# 12. デザインチェック

背景制作前に必ず確認する。

```txt
その背景はどのキャラの記憶か
主役小物は一目で分かるか
敵の造形と背景が噛み合うか
キャラが埋もれないか
ドロップが読めるか
黒インクが背景に溶けすぎないか
ステージごとに色と形の差があるか
リザルト文で反転できるか
```

# 13. 固定メモ

```txt
ステージはキャラの心の中ではない。
忘れ物が眠る紙の世界。

だから背景は、直接的な回想ではなく、
小物・紙・地図・夜道で“意味が残った場所”として描く。
```

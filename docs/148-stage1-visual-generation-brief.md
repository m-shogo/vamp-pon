# Stage 1 Visual Generation Brief

## 0. 目的

Stage 1「ちぎれた夜の広場」の最初の構図マスターを制作するための正本。

これはproduction背景を直接生成する指示ではない。

目的は次の4点を同時に確認すること。

1. Vamp Ponらしい場所に見えるか
2. ユイ・敵・弾・欠片が見える戦闘面になるか
3. 390×844のスマホ画面で成立するか
4. タブレット・PCブラウザ・将来のアプリ化へ拡張できるか

参照必須:

- `docs/145-stage-1-to-5-emotional-beat-map.md`
- `docs/146-stage-visual-design-guide.md`
- `docs/147-stage-visual-app-safety-plan.md`

---

# 1. 出力順

Stage 1は次の順番で作る。

## Output A: Environment Concept

UI、キャラクター、敵、弾を置かない環境構図。

目的:

- 場所の記憶として魅力があるか
- 中央を静かに保てるか
- 外周に世界観があるか
- 可変クロップへ耐えられるか

## Output B: Gameplay Composite

Output Aと同一構図に、実ゲーム要素を配置する。

必須:

- ユイ
- ポン影複数
- ふくらみポン影
- Stage 1固有敵
- 夜の鉛筆弾
- 記憶の欠片
- 上部HUD
- 左下スティック
- 右下必殺ボタン

## Output C: Device Presentation

同じ構図を次で確認する。

- スマホ縦 390×844
- 縦長スマホ
- タブレット縦
- PC横長。中央にゲーム、左右にshell

Output Aの合格前にB・Cを量産しない。

# 2. Stage 1の固定内容

## 名称

```txt
Stage 1: ちぎれた夜の広場
```

## 一言コンセプト

忘れられた小さな街の広場が、巨大な地図帳の一ページとして夜に残っている。

## 感情

- 静か
- 少し寂しい
- 可愛い
- 怖すぎない
- 拾うことが気持ちいい
- 何かが待っていたように感じる

## プレイ上の役割

- 最初の移動を覚える
- 敵を倒す
- 欠片を拾う
- 画面中央を自由に動く
- 外周へ行く理由が自然に見える

## 象徴物

```txt
記憶の欠片
```

象徴は街灯、家、ポストではない。それらは場所を作る補助物である。

---

# 3. 構図

## 3.1 マスター

```txt
minimum master: 720×1280
orientation: portrait
core gameplay crop: 390×844
```

コア画面外にも世界が続いている構図にする。

## 3.2 中央

画面面積の55〜65%を静かな戦闘床にする。

中央へ置かないもの:

- 家
- 大型街灯
- 大きな裂け目
- 強い地図文字
- 強い発光
- 大型インク溜まり
- 読ませたい小物

中央に置いてよいもの:

- 大きく薄い紙の色むら
- ごく薄い地図線
- 小さな破れ
- 低コントラストの紙片跡

## 3.3 中景

- 名前が消えたポスト
- インクに少し沈んだベンチ
- 低い紙草
- 小さな紙片
- 薄い地図線
- 古い道の輪郭

同格の小物を等間隔に並べない。

## 3.4 外周

- 丸く少し歪んだ紙の家
- 折れた鉛筆街灯
- めくれたページ端
- 下に重なる別の紙層
- ページ間に溜まった黒インク

外周は世界観を強くしてよいが、ゲーム面より明るくしない。

## 3.5 ランドマーク

主ランドマークは1つ。

本命:

```txt
左上または右上に、折れた大きな鉛筆街灯
```

副ランドマークは1つまで。

候補:

- 名前が消えたポスト
- ページ端の裂け目
- 小さな紙の家

---

# 4. 色と光

## 主色

- 青灰色の古紙
- 青紫黒の影

## 光

- 欠片: くすんだ古紙金
- 街灯: 欠片より弱い低彩度の暖色
- ユイの暖色点と競合しない

## 値設計

- 中央床: 中暗度、低コントラスト
- 敵: 背景より暗く輪郭を明確に
- 欠片: 小さくても背景より明るい
- 危険予告: 最優先で読める
- 外周: 中央より暗く、奥へ引く

## 禁止

- 全面を青黒くする
- 純黒で夜を作る
- 白い発光を多用する
- 金色の街灯を大量配置する
- 欠片と街灯を同じ輝度にする

---

# 5. 絵柄

## 必須

- 柔らかいピクセルアート
- 絵本の形をドットへ翻訳
- 丸く少し歪んだシルエット
- 大きな色面
- 手描き感のある不均一な線
- 紙の厚みを少ないピクセルで表現
- 可愛いが幼児向けにはしない

## 参考思想

- 場所の読みやすさ
- 可愛い中の静かな不穏さ
- 地図・ページの記号化
- 暗所戦闘の視認性
- 一つの象徴で記憶させる構図

特定作品の画面、キャラクター、配色、建物を直接模倣しない。

## 禁止

- リアルな石畳
- 中世RPGの村
- ホラー墓地
- 高密度ディテール
- 全面ディザ
- 等間隔のタイル模様
- リアルな紙写真テクスチャ
- 文字、ロゴ、看板の可読テキスト

---

# 6. アプリ・ブラウザ耐性

## Safe Area

重要物は次へ置かない。

```txt
上部HUD帯
下部操作UI帯
左右端48px相当
```

## Crop Safety

390×844へ切り出しても次が残ること。

- 静かな中央戦闘床
- Stage 1らしい紙世界
- 主ランドマークの主要シルエット
- 外周のページ構造の一部

タブレット・PCでは、コア外へ紙の家やページ端が自然に続くこと。

## PC Shell

PC横長では中央のゲーム画面を変更せず、左右へ以下を広げられる構造にする。

- 夜の紙層
- 遠い家
- 街灯の弱い光
- 地図線
- ページ端

shellへ戦闘要素を置かない。

# 7. Environment Concept生成指示

以下を一つの制作指示として使用する。

```txt
スマホ向け縦画面サバイバーライクゲーム「Vamp Pon」のStage 1環境コンセプトを制作する。

縦長720×1280以上の構図マスター。390×844の中央コア領域へ切り出しても成立し、タブレットやPCブラウザでは周囲の背景を追加表示できるoverscan構図にする。

舞台は「ちぎれた夜の広場」。忘れられた小さな街の広場が、巨大な地図帳の一ページとして夜に残っている。紙模様の床ではなく、かつて誰かが覚えていた場所に見せる。

中央55〜65%は戦闘用に静かな青灰色の古紙広場。細かい模様を置かず、大きく薄い紙の色むらと、ごく薄い手描き地図線だけを使う。中央に建物、大型障害物、強い発光、読める文字を置かない。

中景に、名前が消えた小さなポスト、インクに少し沈んだベンチ、低い紙草、小さな紙片、消えかけた道の輪郭を少数配置する。等間隔に並べない。

外周に、丸く少し歪んだ紙の家、折れた鉛筆街灯、めくれたページ端、その下に重なる別の紙層、ページ間へ溜まる黒インクを置く。主ランドマークは上側にある折れた大きな鉛筆街灯ひとつ。外周は中央より暗くして奥へ引かせる。

色は青灰色の古紙、青紫黒のインク影、低彩度の暖色光。欠片用の古紙金を背景に多用しない。夜だが暗すぎず、黒一色にしない。

絵柄は柔らかい高品質ピクセルアート。絵本の丸く歪んだ形をドットへ翻訳し、大きな色面、読みやすいシルエット、手描き感のある不均一な線を使う。リアルな石畳、中世RPG村、ホラー墓地、高密度ディテール、全面ディザ、写真紙テクスチャ、文字、ロゴ、UI、キャラクター、敵は描かない。

可愛いが子供っぽすぎず、静かで少し寂しく、怖すぎない。背景単体の美麗イラストではなく、多数の敵と弾が重なるゲーム画面を支える環境として設計する。
```

# 8. Gameplay Composite生成指示

Environment Concept合格後にのみ使用する。

```txt
承認済みStage 1環境構図を変更せず、390×844のゲームプレイモックへ落とし込む。

中央付近にユイを配置。周囲にポン影を約16体、ふくらみポン影を2体、Stage 1固有敵を2〜3体配置する。敵は黒インクfamilyの暗いシルエットで、背景から明確に分離する。

夜の鉛筆弾を複数方向へ飛ばし、記憶の欠片を約15〜20個置く。欠片は小さな古紙金の紙片で、強い白発光ではなく淡い脈動と明度差で見せる。背景の紙片と混同させない。

上部へ時間・HP・Lv・欠片数のHUD、左下へ半透明スティック、右下へ必殺ボタンを配置する。UI背後の背景は静かに保つ。

画面は戦闘中でもユイを一秒以内に見つけられ、敵、弾、欠片、危険予告の順で読めること。背景を派手に変更しない。文字はモック用の最小限で、装飾文章やロゴを追加しない。
```

# 9. 合格条件

## Environment

- [ ] ただの紙床ではなく場所に見える
- [ ] 中央55〜65%が静か
- [ ] 主ランドマークが一つ
- [ ] 可愛いが少し不穏
- [ ] Stage 1の欠片が置かれる余地がある
- [ ] 390×844で主要構図が残る
- [ ] PC左右へ自然に拡張できる

## Gameplay Composite

- [ ] ユイを一秒以内に発見できる
- [ ] 敵20体前後でも背景と分離する
- [ ] 弾と地図線が競合しない
- [ ] 欠片と背景紙片が競合しない
- [ ] HUDとランドマークが重ならない
- [ ] 操作UI背後が静か
- [ ] 暴走・必殺の強い演出を追加できる余白がある

不合格の場合、色や装飾だけで誤魔化さず、構図と密度へ戻って修正する。

# Page Bundle Arc Format

## 目的

Vamp Ponの長期運用単位を「半年リセット」ではなく「ページ束」として定義する。

半年という時間設定は内部メモとして使えるが、ゲーム内の正本表現にはしない。

---

# 1. 結論

正式な長期Arc単位は以下。

```txt
1 run = 夜
5 stages = 1ページ
15 stages = 1ページ束
```

表の言葉としては、半年ではなくページ束を使う。

---

# 2. なぜ半年を正本にしないか

半年はアイデアとして強い。

しかし、正本にすると以下の危険がある。

```txt
時系列が硬くなる
学校/季節/年齢に縛られる
運用で追加しにくい
後から別テーマへ展開しにくい
```

そのため、半年は「そう読める余白」に留める。

---

# 3. ページ束の強み

```txt
地図帳モチーフと合う
時間をぼかせる
Season運用しやすい
追加Stageを自然に入れやすい
続編へ繋げやすい
別IP/別テーマへフォーマット移植しやすい
```

---

# 4. 構造

## 1 run: 夜

```txt
夜になる
影を払う
欠片を拾う
強くなる
朝になる
その夜の力はほどける
意味は残る
```

## 5 stages: 1ページ

```txt
1つの記憶テーマを読む
1つの関係性を回収する
1つの小さな朝を迎える
```

## 15 stages: 1ページ束

```txt
複数ページが束になる
章として閉じる
次のページ束が少し見える
```

---

# 5. Season 1の扱い

Season 1は全世界の真相ではない。

```txt
最初のページ束
最初の忘れ物係の班
最初に読めるようになる地図帳
```

Season 1は単体で気持ちよく終わる。

しかし、IP全体は閉じない。

---

# 6. 閉じるもの / 残すもの

## 閉じるもの

```txt
ユイの最初の喪失
アサの名前
最初の班の約束
最初のページ束
```

## 残すもの

```txt
別のページ束
別の筆跡
別の忘れ物係
別テーマの欠片
まだ読めない余白
```

---

# 7. エンディング表現

強すぎる表現:

```txt
最後の地図帳
世界最後の夜
すべての名前が戻った
```

推奨表現:

```txt
最初の地図帳
このページの名前
閉じたページ束
まだ読めない余白
```

Season 1最後の一文候補:

```txt
朝になった。
このページの名前は、もう消えなかった。
```

---

# 8. 2へ繋げる方法

2へ繋げる時は、Season 1を未完にしない。

やること:

```txt
Season 1の感情は完結させる
最後に1つだけ別の余白を置く
別ページ束の存在だけ匂わせる
```

やらないこと:

```txt
黒幕登場
未完エンド
説明不足で終わる
急な新設定
```

---

# 9. 他IP/別テーマへ流用する時

ページ束の型は、別テーマに移植できる。

例:

```txt
記憶のページ束
手紙の束
写真アルバム
音の記録
星図
夢日記
```

変えてよいもの:

```txt
拾うもの
敵の見た目
舞台
欠片の形
ページ束のモチーフ
```

変えてはいけないもの:

```txt
短時間ラン
欠片回収
一時的に強くなる
区切りで力がほどける
意味だけは残る
前向きな反転
```

---

# 10. 最重要

Vamp Ponは、世界を全部説明して広げるIPではない。

```txt
このページは救う。
でも、地図帳にはまだ余白がある。
```

このバランスを守る。

# Story Map

Internal story map files for Vamp Pon.

## Files

- `vamp-pon-story-street-map.html`

## Purpose

This is not a public game screen.
It is a private planning map for checking:

- Yui-centered relationship web
- light vessels
- item meanings
- black ink reading rules
- high-order lineage traces
- happy-end direction

## Open locally

Open this file in a browser:

```sh
open docs/story-map/vamp-pon-story-street-map.html
```

## Rule

The map is a planning artifact.
Do not implement mechanics directly from it without a separate gameplay brief.

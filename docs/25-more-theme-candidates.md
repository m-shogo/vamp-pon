# 追加題材候補

## 目的

Vamp Pon の題材候補をさらに広げる。

ただし、以下を前提にする。

```txt
本人が乗れる可能性がある
0から世界観を発明しない
参考素材が多い
敵/武器/報酬/背景に変換できる
著作権/商標/表現リスクを制御できる
個人開発で作れる
```

## 今回の評価軸

| 軸 | 内容 |
|---|---|
| 乗りやすさ | 制作者本人が興味を持てそうか |
| 素材量 | 既存の参考情報・小物・背景が多いか |
| 変換しやすさ | 敵・武器・報酬・ステージにしやすいか |
| リスク | 著作権/商標/表現/動物愛護の危険 |
| 個人開発 | 素材化・実装が重すぎないか |

## A寄り候補の詳細

### 1. ガチャガチャ/カプセルトイ

#### 良い点

- 条件達成報酬と相性が非常に良い
- 図鑑、レアリティ、コレクションを自然に置ける
- カプセル、景品、台座、コイン、ハンドルなど小物が多い
- 0から世界観を作らなくてよい
- 敵や武器を「景品が動く」「カプセルの影」として作れる

#### リスク

- 実在メーカー/実在カプセルトイに似せると危険
- ガチャ課金ゲームに見えると印象が悪い
- 射幸性の見え方に注意

#### 対策

- 課金ガチャではなく、ゲーム内報酬/図鑑として扱う
- 実在ロゴ/筐体デザインを避ける
- 「条件達成でカプセルが開く」演出にする

#### Vamp Ponとの相性

かなり良い。

```txt
敵を倒す
経験値を吸う
条件達成
カプセル解放
小さい永続強化/武器/図鑑が出る
```

この流れが自然。

### 2. 昭和/平成レトロ駄菓子屋

#### 良い点

- 駄菓子、くじ、景品、ビー玉、めんこ、ラムネ、袋、棚など素材が豊富
- 報酬/コレクションが作りやすい
- カイロソフト的な「身近な店」感がある
- 0から発明しなくてよい

#### リスク

- 実在商品名/パッケージに似せると危険
- ノスタルジーが伝わらない層がいる
- 戦闘化しないと経営ゲーム寄りに見える

#### 対策

- 実在菓子名は使わない
- 「夜の駄菓子屋で影が湧く」など非現実を足す
- お菓子は敵より報酬/武器/回復に寄せる

### 3. ゲームセンターの夜

#### 良い点

- 筐体、コイン、景品、クレーン、ネオン、メダル、音が強い
- 爽快感と相性が良い
- 敵・武器・報酬化しやすい
- ユーザーがゲーム好きなら乗りやすい可能性

#### リスク

- 既存ゲーム筐体やキャラに似せると危険
- レトロゲーム風は商標/意匠/音の地雷がある
- 画面がごちゃつきやすい

#### 対策

- 実在筐体風にしない
- 架空の筐体名にする
- ドットやピコピコ音も素材ライセンス注意

### 4. 学校の放課後/夜の教室

#### 良い点

- 机、椅子、黒板、チョーク、ノート、ランドセル、時計など素材が豊富
- 文房具武器と相性が良い
- 夜の学校なら影/悪夢も自然
- 0から作らなくてよい

#### リスク

- 学校ホラーに寄りすぎると怖くなる
- 子どもを攻撃対象にするのは不可
- 実在校名/制服に寄せない

#### 対策

- 敵は影/落書き/紙くず/チョークの粉
- 人間の生徒は出さない、または主人公側だけ
- ホラーではなく不思議な放課後にする

### 5. 夏祭り/縁日

#### 良い点

- 屋台、金魚、ヨーヨー、射的、くじ、提灯、綿あめなど素材が多い
- 報酬/景品/条件達成と相性が良い
- 見た目が華やか
- 和風だが妖怪より乗りやすい可能性

#### リスク

- 金魚など生き物を攻撃対象にしない
- 実在祭りや宗教的行事を雑に扱わない
- 屋台だけだと経営ゲームっぽくなる

#### 対策

- 敵は影、煙、いたずら提灯、紙のおばけ
- 金魚や動物は保護/回収/味方寄り
- 祭り名は架空にする

### 6. 時計屋/からくり工房

#### 良い点

- 歯車、ゼンマイ、時計、ベル、針、からくり人形など武器化しやすい
- 時間停止/加速/巻き戻しなどゲーム効果に変換しやすい
- おもちゃ箱とも相性が良い
- 世界観に芯が出る

#### リスク

- スチームパンク寄りにすると素材が重い
- 架空設定が増えすぎると考えるのが大変
- 色味が地味になりやすい

#### 対策

- あくまで「部屋の古い時計/からくりおもちゃ」程度にする
- 歯車や時計を武器・進化に使う
- 背景を作り込みすぎない

### 7. カード/トランプ/ボードゲーム

#### 良い点

- カード、サイコロ、駒、盤面、チップ、箱など素材が多い
- 武器/敵/報酬/条件に変換しやすい
- 進化やビルドと相性が良い
- ガチャや図鑑ともつながる

#### リスク

- 既存TCGやボードゲームに似せると危険
- トランプはアリス連想が強くなりすぎる可能性
- ルールが複雑に見える危険

#### 対策

- 実在カードゲーム風にしない
- 効果はヴァンサバのまま、見た目だけカード/駒にする
- UIを複雑にしない

### 8. 積み木の王国

#### 良い点

- おもちゃ箱より中心が明確
- ブロック、塔、城、橋、車、兵隊など展開しやすい
- 敵を崩す/弾ける演出が気持ちよくできる
- 素材が単純形状で作りやすい

#### リスク

- LEGO等の実在ブロックに寄せると危険
- 子ども向けに見えすぎる
- 色が多く視認性に注意

#### 対策

- 特定ブロック形状を避ける
- 積み木/木片/紙箱風にする
- 敵は影が入った積み木にする

## 今回の結論

新しくかなり有力なのは以下。

```txt
ガチャガチャ/カプセルトイ
夜の教室/文房具
夏祭り/縁日
ゲームセンターの夜
時計屋/からくり工房
積み木の王国
```

特に、Vamp Ponの「条件達成でアイテムゲット」と一番噛み合うのは、

```txt
ガチャガチャ/カプセルトイ
```

これを主軸にすると、報酬・図鑑・秘宝武器・永続強化が全部自然につながる。

ただし、課金ガチャに見えるのは避ける。

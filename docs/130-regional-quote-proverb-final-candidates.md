# Regional Quote / Proverb Final Candidates

Vamp Pon / ヴァンサバ改のロード知識システムに最初に入れる、Regional quote / proverb 10件の確定候補。

この資料は、`docs/126-loading-knowledge-consistency-guardrails.md` の方針に従い、1カテゴリだけを少数精鋭で詰める。

---

## 1. このカテゴリの役割

Regional quote / proverb は、世界各地域の言葉の質感をロード画面に入れるカテゴリ。

```txt
インド = 繰り返しと手放し
ヨーロッパ = 重荷、沈黙、帰り道
東アジア = 名前、道、役に立たなさ
日本 = 不完全、無常、季節
アメリカ/カリブ = 混ざった言葉、生き残る生活知
```

目的:

```txt
詳しく知りたい人が調べたくなる入口を作る。
原文の雰囲気を残す。
日本語訳/意味は短く。
Vamp Ponらしさはキャラ返信で出す。
```

---

## 2. 選定基準

採用条件:

```txt
地域の特色がある。
Vamp Ponの夜・記憶・忘れ物・名前・道・朝に接続できる。
原文/出典/意味が比較的管理しやすい。
現役宗教を軽く扱わない。
キャラ返信が説明ではなく、その子の価値観になっている。
```

注意:

```txt
宗教/哲学系は final-check-required。
カリブ系は生活格言中心にする。
実在儀式名や神名はMVPでは扱わない。
```

# 8. 破綻チェック

この10件は、以下を満たす。

```txt
□ 各地域から2件ずつ
□ 原文の雰囲気が残る
□ 日本語訳/意味が短い
□ キャラ返信が解説ではない
□ 宗教/文化をギャグにしていない
□ MVPでは危険な固有儀式名を避けている
□ 初期5件はロード向き
□ 後半5件は状況制御/記録室向き
```

注意:

```txt
インド/ヨーロッパ宗教哲学系は最終商用前に必ず確認。
Bajan proverb は生活格言として扱い、宗教/儀式系には踏み込まない。
Dhammapada 33 は長いので、ロード短縮版を別途作る。
```

# 9. 最終方針

Regional quote / proverb は、Vamp Ponに「世界の言葉の質感」を入れるカテゴリ。

最初に入れるなら、次の5件から始める。

```txt
Per aspera ad astra.
反者道之動。
無用之用
すべて何も皆事のととのほりたるはあしき事なり。
Cat luck ain't dog luck.
```

残り5件は、状況制御・記録室・最終確認が整ってから入れる。

```txt
tasmād asaktaḥ satataṁ kāryaṁ karma samācara
phandanaṁ capalaṁ cittaṁ dūrakkhaṁ dunnivārayaṁ...
Sit in thy cell and thy cell will teach thee all.
すべて、何も皆、始め終りこそをかしけれ。
Wuh ain't miss you, ain't pass you.
```

# 1. Episode engine — 6 beat grammar

1話 / 1短sceneは全部同じ長さでなくてよいが、基本候補:

```txt
1. Ordinary anchor
2. Small question
3. Friction / play
4. Reframe
5. Character action
6. Last image
```

## Ordinary anchor
食事 / 道 / 修理 / 名前 / 雨 / 休憩。

## Small question
世界真相ではなく、そのsceneで気になる一点。

## Friction
価値観 / misunderstanding / gameplay pressure。

## Reframe
「最初に思った意味と少し違う」。

## Character action
台詞説明より行動。

## Last image
次を見たくなるvisual / ordinary callback。

# 4. Emotional temperature dimensions

各episodeへ0–5で付ける。

- `warmth`
- `humor`
- `wonder`
- `unease`
- `fear`
- `anger`
- `grief`
- `romanticCharge` — 該当時のみ
- `hope`
- `mystery`

Rule:
- `fear + grief >= 7`のepisodeを3連続させない。
- major grief後は少なくとも1つ`warmth/hope` sceneを置く。
- humorを悲嘆直後の感情無視に使わない。

# 5. Quiet / Breather Episode Plan

Quiet = fillerではない。

Title1 candidate reservoir:

## Q01 — 名前のない紙コップ
アサが全員分へ名前を書くが、一個だけ「誰用？」になる。
笑いながら、後のナシロthemeを薄く置く。

## Q02 — 地図になった紙ナプキン
ミチルが食事中にrouteを描き、ゲンが古い道を一本足す。
地図改訂Incidentの感情less seed。

## Q03 — 半分の夜食
リツが自然に人数を数え、コヨリが「自分も数えた？」と確認。
後の負担分担callback。

## Q04 — 直さない椅子
トモリが壊れた椅子を直そうとするが、持ち主が「この音が好き」と言うCandidate。
直す / 残すの小さな予行。

## Q05 — 未分類箱
シロが説明できない紙を捨てずに箱へ。
ハクマ対比seed。

## Q06 — 雨宿りの改札
トバリが全員を止めるのではなく、雨が弱くなるまで待つ。
境界 = 守るだけでなく通すための時間。

## Q07 — ハナのしおり返却
前に預けた花が数Stage後しおりになって戻る。
「保存 = 手渡す」Dawn seed。

## Q08 — ネムの寝落ち
寝ていたと思ったネムが会話の核心だけ覚えている。
笑い + dream theme。

- major boss直後に必ず長い会話、とはしない。
- Result / Hub / short intermissionへ分散。
- 1scene 10–40秒でも成立。
- skip可能でも、play中のbehaviorでCharacterを感じられるようにする。

# 7. Cliffhanger Library

毎回「敵が現れた」で切らない。

## Type A — Object mismatch
- 修理痕が年代と合わない
- 宛名がない
- 知らない折り目

## Type B — Behavior mismatch
- 星獣だけ先に反応
- 八影二体が互いを邪魔する
- 敵が一枚だけ名札を剥がす

## Type C — Relationship shift
- 敬語が一度だけ外れる
- 呼び方が変わる
- 普段助ける人が助けを求める

## Type D — Institutional contradiction
- 公式地図と古地図が両方正しい
- 存在しない番線の記録

## Type E — Quiet absence
- いつも直してある椅子が今日は壊れたまま
- いつも書かれる名前が一つない

## Type F — Decision
- 開けるかどうか
- 届けるかどうか
- 誰が署名するか

## Type G — Soft reveal
- 「八影」という記録の横に別の語の欠片

---

# 8. Cliffhanger fairness

次話に引っ張るために:
- Characterを突然愚かにしない
- 誤解を会話一言で解けるのに引っ張らない
- fake death連発しない
- Happy Endを嘘扱いしない

---

# 9. Comedy placement

笑いはCharacterから出す。

Good:
- ペタが他の朔盟memberの分類を勝手に貼り替えて迷惑をかける
- アサのlabel几帳面さ
- ミチルの地図癖
- トモリの無意識修理

Avoid:
- elderly body gag
- plus-size body gag
- gender / sexuality gag
- disability gag
- traumaを「重いw」にする

---

# 10. Sakumei episode rule

一人のmember登場時:
- ability
- contradiction
- signature behavior
- Currentとのmirror

を全部説明しない。

最低3回のrecognition:
1. scary / memorable
2. pattern becomes legible
3. past / philosophy reinterprets it

Pair episode:
- Aの能力 + Bの能力 = 火力倍
ではなく
- Aの正解とBの正解が衝突

を主役にする。

---

# 11. Aftercare episode

Black-Youka / major encounter後:

- apologyだけで終わらない
- 周囲もどう接するか迷う
- 食事 / repair / sleep等ordinary actionへ戻す

例:
カナメが戻った後、誰かが大荷物を先に持つ。
台詞なしでもgrowthを見せられる。

---

# 12. Relationship episode variety

Bond up = 仲良し会話だけにしない。

- shared failure
- disagreement survived
- silent cooperation
- one protects privacy
- one asks for help
- joke develops
- ordinary routine

Affinity DOWNでも永続罰にしない。

# 13. Iconic scene test

各主要Characterに最低1scene:

> スクショ1枚 / 10秒clipだけでも「この人らしい」と言える

を作る。

Battle finisherだけでなく:
- cup label
- bench
- map napkin
- flower bookmark
- repair

もiconic scene候補。

---

# 14. Ending rhythm

Final battle後:

```txt
victory noise
↓
short quiet
↓
確認 / 帰路
↓
ordinary callback
↓
朝
↓
small Reality-life change
↓
soft B/A anomaly
```

ラスボス撃破直後にA mystery exposition 20分、は禁止。

# 15. Completion definition

- 1話単位のengineがある。
- Stage bandごとの感情役割がある。
- quiet episodeが8本以上ある。
- cliffhangerが敵登場以外にもある。
- emotional heavy streakを管理できる。
- Sakumei memberを3段階で好き / 怖い / 理解できる。
- EndingがHappy Endをちゃんと味わわせてからseries gapを残す。

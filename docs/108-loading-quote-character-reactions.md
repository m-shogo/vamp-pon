# Loading Quote Character Reactions

Vamp Pon / ヴァンサバ改のロード画面における「名言引用」と「キャラの反応」を組み合わせる仕様。

目的:

```txt
名言は残す。
引用をちゃんと読ませる。
キャラの反応はたまに添える。
キャラポエムは、朝が来た時に読ませる。
```

---

## 1. 役割分担

### ロード画面

ロード画面は、引用が主役。

```txt
本当の名言・古典・詩を読む。
たまに、選択キャラの短い反応が添えられる。
```

ロードではキャラポエムを出しすぎない。
重くなるし、特別感が薄れる。

### 朝明 / クリア / ステージ終了

キャラポエムはここで出す。

```txt
夜を越えた後だから刺さる。
プレイヤーがそのキャラで遊んだ後だから意味が乗る。
同じ文でも、ロード中より重く感じる。
```

つまり:

```txt
ロード = 引用を読む
ロード反応 = キャラが引用を少し受け取る
朝明 = キャラ自身のポエムを読む
```

---

## 2. 基本表示

### Quote only

```txt
We grow accustomed to the Dark.

— Emily Dickinson
```

### Quote + Character Reaction

```txt
We grow accustomed to the Dark.

— Emily Dickinson

慣れたくなんか、なかったけど。
— アサ
```

反応は引用の翻訳ではない。
そのキャラがその言葉を聞いた時の、小さな返事。

---

## 3. 表示頻度

キャラ反応は毎回出さない。

```txt
通常ロード: 25%で反応を表示
キャラ選択後ロード: 45%で反応を表示
ステージ開始: 15%で反応を表示
敗北後/リトライ前: 35%で反応を表示
初回プレイ: 10%で反応を表示
```

キャラポエムはロードに出さない。
原則として、朝明・クリア・キャラ図鑑・PV・SNSカードで使う。

---

## 4. 読ませる時間

キャラ反応が付く場合、表示時間を増やす。

```txt
quoteOnlyMinMs: 3200
withReactionMinMs: 4600
withReactionMaxMs: 7500
reactionExtraMs: 1400
```

ロードが完了しても、最低表示時間を優先する。

---

## 5. レイアウト

```txt
[引用本文]
— 出典

[キャラの反応]
— キャラ名
```

文字優先度:

```txt
引用本文: 一番強い
出典: 小さく薄い
キャラ反応: 引用より少し小さいが読める
キャラ名: かなり薄く
```

引用と反応の間には余白を置く。
キャラ反応が引用を邪魔しないようにする。

---

## 6. 反応文ルール

良い反応:

```txt
短い。
そのキャラにしか言えない。
引用を説明しない。
翻訳しない。
引用への感情だけが見える。
弱さが少し出る。
```

悪い反応:

```txt
現代語訳になっている。
引用を解説している。
全キャラで同じことを言える。
長い。
説教くさい。
```

## 8. 朝明時のキャラポエム

朝が来た時だけ、キャラポエムをしっかり出す。

### 表示タイミング

```txt
ステージクリア後
朝明演出後
リザルトに入る直前
キャラの成長/経験値表示前
```

### 表示時間

```txt
minimumVisibleMs: 5200
recommendedVisibleMs: 6500
skipEnableMs: 2200
```

朝明ポエムはロード文より長く読ませる。

### 表示例

```txt
帰れない人がいるから、
私はまだ帰れない。

— ユイ
```

```txt
あたたかいふりをして、
私はまだ焦げている。

— アサ
```

```txt
私の名前は、
私より先に迷子になった。

— シノ
```

### 朝明で出す意味

```txt
プレイヤーがそのキャラで夜を越えた後に読むから意味が乗る。
ロード中より、感情が残る。
毎回出ても邪魔になりにくい。
キャラの心臓として扱える。
```

---

## 9. 朝明ポエムとロード反応の違い

| 種類 | 役割 | 文字量 | 頻度 |
|---|---|---:|---:|
| 引用 | 知識供給 | 短〜中 | 高 |
| キャラ反応 | キャラの受け取り方 | 短 | 中〜低 |
| 朝明ポエム | キャラの心臓 | 中 | クリア時 |

使い分け:

```txt
ロードで引用を読む。
たまにキャラが小さく反応する。
朝が来たら、そのキャラ自身の言葉を読む。
```

## 10. 実装データ案

```ts
export type LoadingQuoteReaction = {
  quoteId: string;
  characterId: string;
  text: string;
  minVisibleMs?: number;
};

export type MorningCharacterPoem = {
  characterId: string;
  text: string;
  condition?: 'stageClear' | 'firstClear' | 'blackPurified' | 'characterLevelUp';
  minVisibleMs: number;
};
```

ロード表示時:

```txt
1. quoteを選ぶ
2. 選択キャラに対応するreactionがあり、表示確率に当たれば反応を付ける
3. reaction付きなら表示時間を伸ばす
4. 朝明時はquoteではなくMorningCharacterPoemを出す
```

## 11. 最終方針

```txt
名言は残す。
引用をちゃんと読ませる。
キャラの反応はたまに添える。
キャラポエムは朝が来た時に出す。
```

この分け方が一番強い。

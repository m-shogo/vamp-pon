# ヨルノシルベ Character Star-Beast Constellation Canon v1

Date: 2026-07-28
Status: ADOPTED FOR STORY / PROFILE / DAILY-LIFE / COLLECTION DESIGN; GAMEPLAY IMPLEMENTATION DEFERRED

## 1. コンセプト

キャラクターの「星座」は誕生日占いの黄道星座ではない。
その人物が好きで、価値観・記憶・関係性と共鳴する **推し星座 / 守り星座** を意味する。

星座は小さなマスコット **星獣（せいじゅう）** として現れ、日常パート、灯録、集合絵、プロフィール、将来のassist演出でキャラクターと行動する。

## 2. 固定ルール

1. International Astronomical Union (IAU) の現行88星座から選ぶ。
2. 人、道具、建物、幾何学図形ではなく、**生物・動物を表す星座だけ**を使う。
3. 原則として、無関係な人物同士で同一星座を重複させない。
4. **兄弟、親族、同じ血筋、同じ記憶から分かれた存在、継承関係など、物語上の理由がある場合のみ重複を許可する。**
5. 重複は設定ミスではなく伏線として扱う。後で関係性を知った時に「だから同じ星座だった」と分かる構造にする。
6. 同じ星座を共有しても、星獣は同一個体ではない。同じ星座から生まれた別個体として、体格、表情、傷、装飾、性格を変える。
7. 誕生日と守り星座を一致させる必要はない。占星術の性格決めには使わない。
8. 星座の神話、命名史、航海史、図像史などの「由来の核」を拾い、キャラクターの内面へ翻案する。
9. 神話の人物そのものを前世・正体にしない。
10. 星座や星獣そのものを敵として大量に倒す構造にはしない。星獣は味方、案内、記憶、マスコット側。
11. 星獣の戦闘assistは将来機能。現時点でruntime combatへ勝手に追加しない。
12. 通常時は小さく親しみやすい。暁や黒耀化では星線、輪郭、振る舞いが変わるが、巨大召喚獣へ自動昇格しない。

## 3. 旧プロフィール星座の扱い

`docs/character-personal-profile-canon-v1.md` の旧 `zodiac` 欄は、誕生日由来の黄道星座として作られていたため、**この正本により廃止 / superseded** とする。

誕生日は日常プロフィールとして残す。
今後のプロフィール星座欄は次へ置き換える。

```txt
birthday
favoriteConstellation
starBeast
constellationOriginKernel
constellationCharacterFit
sharedConstellationReason?  # 重複時のみ
```

## 5. 重複星座の意味

### ユイ × トモリ — 獅子座

現時点では、同じ獅子座を共有することだけを正本化する。

示唆候補:

- 血縁
- 遠い親族
- 同じ火の系譜
- ランタンの継承者
- 一つの記憶火から分かれた系譜

**どれか一つへ今すぐ固定しない。**
星座共有を先に見せ、物語が進んだ後で理由を回収できるようにする。

### リツ × コヨリ — りょうけん座

既存の兄妹関係を明示的に反映する重複。
二頭で一つの星座という図像自体を利用する。

## 6. 星獣の役割

### 日常

- 食べ物を欲しがる
- 鞄や肩に乗る
- 寝る
- キャラの癖を真似する
- 他キャラの星獣と仲良し / 苦手関係を作る

### 灯録 / Character Detail

- 推し星座
- 星獣名
- 星座線
- 由来の短文
- キャラとの共通点
- 関係性で重複している場合は、理由をstory progressionに応じて段階開示する

### TOP / 集合絵

全員の星獣を常時並べない。
画面にいるキャラだけ、その近くへ小さく出す。

例:

- ユイの子獅子はランタンの近くで丸くなる
- トモリの若獅子は工具袋へ顎を乗せる
- リツとコヨリの二頭は互いの尻尾を追う
- シロの山猫は開いた頁へ前足を置く
- ゲンの大熊は後ろで座り、遠景へ厚みを作る

## 7. Motion

星獣はTOP motionの良い第二候補になる。

優先:

1. ランタン炎 / halo
2. 主人公や主要キャラの小さなidle
3. 星獣の小さな仕草
4. 霧 / 星 / 紙片

星獣は常に動かさない。
数秒に一度、耳、尻尾、瞬き、あくび、紙片を追う等の短いmotionにする。

## 8. 黒耀化

星獣を単純な悪い怪物へ変えない。

- 星線が欠ける
- 体の一部が紙・黒インク・煤へほどける
- いつもの癖が過剰になる
- 飼い主を守ろうとして近づけなくなる

等、キャラ自身の歪みを星獣側にも反映する。

## 9. 暁

暁側では巨大化より、輪郭が明瞭になり、失われていた星が一つ戻る演出を優先する。

## 10. Production boundary

この文書のadoptionは以下を意味しない。

```txt
star-beast canon adopted != runtime summon implemented
favorite constellation adopted != combat ability assigned
shared constellation adopted != exact family relation revealed
star-beast visual brief ready != production asset approved
```

画像制作時は、この正本の星獣種・由来・キャラ適合をasset briefへ引き継ぐ。

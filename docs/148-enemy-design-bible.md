# Enemy Design Bible

## 目的

Vamp Pon の敵を、ただの色違いではなく、記憶・小物・キャラ・ステージに結びついた造形として蓄積する。

この文書は、敵デザインを作る時に困らないための設計書。

```txt
敵の名前
記憶テーマ
造形
動き
対応キャラ
ステージ
倒した後に見える意味
```

を固定する。

---

# 0. 敵の大原則

敵は悪ではない。

```txt
黒インクに固まった記憶の防衛反応。
```

倒すとは、殺すことではない。

```txt
固まった誤解をほどいて、記憶の欠片へ戻すこと。
```

敵は怖すぎない。

```txt
黒くて不穏
でも、どこか小物っぽい
どこか寂しい
どこかかわいい
```

を守る。

---

# 1. 基本系統

## オンブ

小型雑魚。

```txt
丸い黒インク影
短いインク芽
腕なし
柔らかい影炎
口なし
顔前のモヤは薄い
```

役割:

```txt
小さな未練
名前のない不安
大量に出る感情ノイズ
```

## オンブロ

大型影。

```txt
大きい黒インク影
両腕太い
手先は鈍い3房
頭芽2本
長い影炎
待機で垂れる
攻撃時に腕が伸びる
```

役割:

```txt
長く残った後悔
ステージの誤解の核
中ボス/大ボス
```

---

# 2. 敵造形ルール

## やる

```txt
小物の形を体に混ぜる
黒インクのにじみを使う
シルエットで役割を分ける
移動で後方モヤを出す
倒すと紙片/欠片/小物の一部に戻る
```

## やらない

```txt
ただの色違いだけ
ただのゾンビ
怖すぎるホラー顔
牙と血を強調
全員に手足を付ける
全員を丸いだけにする
```

# 3. 造形カテゴリ

| 系統 | 役割 | 造形の方向 | ゲーム挙動 |
|---|---|---|---|
| 影丸系 | 基本雑魚 | 丸い黒インク | 追尾 |
| 小物憑き系 | 記憶雑魚 | 名札/切符/鍵などが混ざる | 小物周辺行動 |

| 偽灯り系 | ユイ反転 | 偽ランタン/偽星 | 誘導/罠 |
| ボス系 | 誤解の核 | 大きい小物 + オンブロ | ギミック連動 |

# 6. スプライト化メモ

敵を sprite にする時の基本。

```txt
1440x1080
8列x6行
1セル180x180
透過RGBA
48セル
端接触なし
罫線なし
正面/左向き/右は反転運用可
```

小型敵:

```txt
セル内の見た目サイズ 55〜95px
余白あり
丸い影炎で動きを出す
```

中型敵:

```txt
セル内の見た目サイズ 95〜135px
小物が読める大きさ
```

大型敵:

```txt
セル内の見た目サイズ 135〜170px
端接触禁止
腕やモヤはセル内に収める
```

# 7. 敵デザインチェック

```txt
小物テーマが一目で分かるか
黒インク影として統一感があるか
怖すぎないか
ただの色違いになっていないか
キャラの記憶テーマと対応しているか
倒した後に何が救われるか説明できるか
ゲーム挙動に落とせるか
スマホ画面で見分けられるか
```

# 8. 固定メモ

```txt
敵はプレイヤーの障害であり、記憶のヒントでもある。
敵の造形が分かるほど、ステージの意味が分かる。
ステージの意味が分かるほど、キャラの戦う理由が分かる。
```

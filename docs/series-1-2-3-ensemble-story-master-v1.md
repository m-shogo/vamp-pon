# 0. Inspiration boundary — 表面をコピーしない

ユーザーが好きな要素として挙げた、強い相棒、兄弟、仲間集団、敵同士の理解、疑似家族、師弟、老い、記憶、再会、長い愛、人間と人外の信頼、群像劇などを**構造原則**として使う。

採用する構造:

- 一番大切な相手でも恋愛とは限らない
- 片方が救うだけでなく、役割が反転する
- 敵対者にも別の正解がある
- グループ全体でいる時に一人では出ない魅力が出る
- 日常の小さな反復が終盤の感情になる
- 名前・記憶・物・癖が時間を越えて人を繋ぐ
- 年を取ること / 年を取らないことの両方に怖さがある
- 人間 / 動物 / Robotを「魂があるか」だけで処理しない
- 人は離反・卒業・別れをしても、その関係が無価値にならない
- 群像劇では偶然の小物や別人の行動が遠くの人物へ届く

採用しない:

- 既存作品固有の台詞、事件、能力、衣装、関係配置のコピー
- 「この二人 = あの二人」と一対一対応させる設計
- 特定作家の文体そのものの模倣
- 死亡だけを感動装置にする
- 続編で前作のHappy Endを無効化する

2. **なぜ別時代の人物を同時に接続できるのか**
3. **なぜ星獣は一部の関係を本人より先に知るように見えるのか**
4. **黒インクは守るための仕組みだった可能性**
5. **“間違った意味”を固定することは、完全に悪いことなのか**
6. **誰かが夜を終わらせない理由**
7. **夜がなければ出会わなかった関係を、終わらせる権利は誰にあるのか**
8. **Robot /動物 /人間で夜への接続条件は同じなのか**
9. **記憶ではなく、関係そのものが接続単位である可能性**
10. **最初のヨルノシルベは“誰かを救う装置”ではなく“別れを保留する装置”だった可能性**

# 14.1 高価値シリーズ仮説

Main Mystery finalではない。

> 夜は「忘れないため」の場所ではなく、**別れを受け入れられない誰か /何かが、関係を未確定のまま置いておくために生まれた**可能性。

この仮説なら:

```txt
1 = 忘れないこと
2 = 離さないこと
3 = 未確定にし続けること
```

が一つのThemeへ集まる。

ただしシリーズ3で:

> 夜は悪だったから壊す

にはしない。

夜があったから出会えた人もいる。

最終問い:

> **必要だった場所を、役目が終わったから終わらせられるか。**

これは卒業Themeの最大化になる。

# 15. BACCANO的な群像密度をオリジナル化する方法

固有事件をコピーしない。

採るのは:

- 主人公一人だけが全事件を動かさない
- 別の人物の小さな行動が遠くの人物へ届く
- 同じ出来事を立場ごとに別の意味で見る
- 一見サブ人物が別人物の人生では主役
- 時系列が後から繋がる

ヨルノシルベでは:

```txt
人物Aが修理したボタン

↓
人物Cが夜でその意味を誤解
↓
人物DのEnemy encounterでほどかれる
↓
人物A本人は最後まで全体像を知らない
```

のように、Named Objectを関係ネットワークの媒体にする。

# 16. 会話のユニークさ

特定作家の文章を真似しない。

代わりに一人ずつ**言葉の論理**を持たせる。

例:

- ユイ: 物の位置から人を考える
- アサ: 名前 /呼称から考える
- ナギ: 許可 /開閉で話す
- ミチル: 道 /寄り道 /目的地で喩える
- トモリ: 壊れ方 /直し方で話す
- セン: 仮説と説明
- シロ: 分類 /未分類
- トキ: 測定 /誤差
- ツムギ: 空白 /続き
- クロエ: 同じ言葉が時代で意味を変えることを知っている
- ノア: 「同じだった」と「同じである」を区別する
- ルム: 「ぼくら」から「ぼく」へ揺れる

## 会話ルール

- 全員を名言製造機にしない
- 一場面に一つだけ言葉のひっかかりを置く
- 面白い喋り方は感情を隠す道具にもする
- Crisis時だけ普段の論理が崩れる

例:

通常のトキ:

> 「測れないので保留します。」

本当に怖い時:

> 「……測れない。けど、行かないで。」

のように**壊れ方で関係を見せる**。

台詞本文は最終script段階で別途制作。

# 23. Happy End architecture

## 1

仲間は全員同じ場所へ残らない。
しかし朝へ帰れる。

> **別れたけど、失敗ではない。**

## 2

時間は止まらない。
老いも消さない。

> **終わる関係があっても、大切だったことは無効にならない。**

## 3

夜の役割が終わる可能性がある。

> **役に立った場所を終わらせることも、裏切りではない。**

シリーズ全体の最終Happy End候補:

> 夜がなくても、夜で会った人たちの選択が現実側へ残っている。

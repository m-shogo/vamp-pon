# PR50-61 Visual Polish QA Checklist

この文書は、新機能追加ではなく、画面品質・押し心地・世界観統一を確認するためのもの。

## 対象PR

- PR50: TOP / premiumPaperUi / pressFeedback
- PR51: StageSelect / Growth 表層
- PR52: Collection 背景 / 忘れ物帳感
- PR53: LevelUpカード紙片化
- PR54: Game Feel / Juice 数値底上げ
- PR55: 共通紙UIの質感強化
- PR56: HUD所持品スロット紙片化

## 390x844 手元確認

### 1. TOP

- 起動直後に、ランタン/ユイ風シルエット/タイトルが主役に見える。
- `夜へ出る` が一番押したいCTAに見える。
- `成長` / `忘れ物帳` / `設定` が主CTAより弱く見える。
- NEW badge が通知丸ではなく、小さい灯りに見える。
- ボタン押下時に紙片が沈むように見える。
- console error が出ていない。

### 2. StageSelect

- `夜の地図` として見える。
- Stage preview card がただの矩形ではなく、紙片/地図帳に見える。
- Easy / Normal / Hard の差が、文字だけでなく紙の痛み・黒インク量・灯りで分かる。
- Stage prev / next が押せる。
- `探索を始める` が主CTAに見える。
- bottom nav が業務UIに見えすぎない。

### 3. Growth

- 強化行が単なる表ではなく、支度カードに見える。
- 強化可能/不可の差が読める。
- 黒曜片不足の表示が読める。
- Reset confirm が読める。
- `探索へ出発` が主CTAに見える。

### 4. Collection

- 6タブが390pxで潰れすぎない。
- `星図 / 影 / 絵札 / 灯 / 言葉 / 実績` のタブが読める。
- 背景がデータベースではなく、忘れ物帳/星図/記録帳に見える。
- NEW / seen 状態が壊れていない。
- 実績タブの文言が長すぎない。
- TOPへ / 夜へ の導線が読める。

### 5. LevelUp

- 3択カードが紙片カードとして見える。
- normal / good / rare の差が分かる。
- rare がネオンではなく、ランタン光の特別感に見える。
- カード選択時に、他カードがdimする。
- 入替カードと所持品表示が読める。
- 説明文が途中で読めなくならない。

### 6. Battle HUD

- 上部HUDが暗い中でも読める。
- HP / Lv / time / 欠片数が読める。
- 所持品スロットが紙片/保管枠として見える。
- 空スロットと所持済みスロットの差が分かる。
- Lv badge が読める。
- 必殺ボタンが邪魔になりすぎない。
- 黒耀ゲージが左下で読める。

### 7. Combat Juice

- 敵撃破時の黒インク/記憶粒子が弱すぎない。
- 画面が粒子で読めなくならない。
- EXP吸引popが邪魔にならない。
- LevelUp停止のテンポが遅すぎない。
- clear warm glow が強すぎない。
- 低スペック設定で重くなりすぎない。

### 8. 黒耀化 / 必殺

- 黒耀化中、黒インクに侵食されるがユイの中心に暖色の灯りが残る。
- 黒耀カットインが単なる赤目悪魔化に見えない。
- 必殺カットインと黒耀カットインの差が分かる。
- 黒耀終了時の浄化/反動が読める。
- 敵 / EXP / HUD が隠れすぎない。

### 9. Result

- 勝利時に朝色の余韻が見える。
- 敗北時も、小さな灯りや持ち帰ったものが残る。
- Rank seal が押印/記録印に見える。
- 新実績文言が世界観に合っている。
- `成長へ` / `もう一度` / `ステージ選択` / `TOPへ` の優先度が分かる。

## NG判定

以下が見えたら、次PRで修正する。

- ただの角丸矩形UIに戻っている。
- 390x844で文字が潰れている。
- 光りすぎて敵やEXPが読めない。
- 黒耀化がただの赤目悪魔化に見える。
- Resultが精算表に見える。
- Collectionがデータベース画面に見える。
- TOPの主役がボタンだけに見える。

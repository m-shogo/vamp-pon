# 150. Memory Item and Action Link Rules

This document links character props, memory items, and first actions.

## Core rule

A character's first action comes from the light vessel.
A character's memory items come from the same context.

## Required fields

- codename
- light vessel
- lineage
- first action
- memory item set
- relation to Yui
- relation to another character
- unknown space

## First action examples

| Vessel | Action direction | Visual rule |
| --- | --- | --- |
| lantern | warm flame | round, gentle, close to body |
| torch | path-opening flame | forward, rough edge |
| candle | small prayer light | tiny orbit, soft rhythm |
| bottle lamp | mist or droplet | transparent edge |
| bulb | spark | sharp small flashes |
| radio light | pulse | repeated ring |
| star lamp | reveal | clean straight light |
| headlight | scan | frontal cone |
| streetlight | zone | fixed area |

## Memory item examples

| Lineage | Item examples |
| --- | --- |
| fire | wick, glass, oil tag, match, burned map edge |
| water | clouded bottle, rain bookmark, shell, surface shard |
| lightning | filament, wire, small switch, static note |
| light | lens, star pin, window chip, dawn paper |
| dark | ink stone, black ribbon, covered mirror, eclipse mark |
| neutral | battery cap, screw, reflector, small sign plate |

## Rules

- Items must not be generic collectibles only.
- Items must show what kind of memory was lost.
- Item glow must not copy another character's vessel glow.
- First action should explain the vessel immediately.
- Later upgrades can reveal deeper meaning.
- Do not make every fire-line character feel the same.

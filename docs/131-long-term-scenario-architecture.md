# Long-term Scenario Architecture

## 目的

Vamp Pon 1 をきちんと終わらせながら、Vamp Pon 2、別ページ束、別テーマ、別アプリへ拡張しても破綻しない長期シナリオ構造を定義する。

ここで決めるのは、細かい年表ではない。

```txt
何を1で閉じるか
何を2へ残すか
何をシリーズ全体の謎にするか
何を絶対に後付けにしないか
```

---

# 1. 最重要方針

```txt
1作目は終わらせる。
シリーズは閉じない。
```

Vamp Pon 1で、ユイたちの最初のページ束は完結させる。

ただし、以下は閉じない。

```txt
黒インクの完全な正体
別のページ束
影の班
届かなかった手紙
街の外側
地図帳を最初に作った本当の理由
```

未完エンドにはしない。

1作目の感情は満足して終わる。

---

# 2. シリーズ全体の構造

## Layer 0: 1ラン

```txt
夜になる
欠片を拾う
強くなる
朝になる
力はほどける
意味は残る
```

## Layer 1: 1ページ

```txt
5Stage程度
1つの記憶テーマ
1つの関係性
1つの小物反転
```

## Layer 2: 1ページ束

```txt
15Stage程度
複数ページのまとまり
1つの大きな誤解が解ける
次のページ束への余白が1つ残る
```

## Layer 3: 1作

```txt
1つの主人公/班の物語が完結
シリーズ全体の謎は一部だけ進む
```

## Layer 4: シリーズ

```txt
複数の地図帳
複数の忘れ物係
複数の黒インクの見え方
```

---

# 3. 1作目で閉じるもの

Vamp Pon 1で必ず閉じるもの。

```txt
ユイは一人ではなかった
アサの名前は消えていなかった
ナギの箱は拒絶ではなく保護だった
ミチルの切符は片道ではなかった
トモリの灯りは待つだけではなく帰るための道標だった
最初のページ束は朝まで残った
```

これらは2へ持ち越さない。

持ち越すと1が弱くなる。

---

# 4. 1作目で閉じないもの

Vamp Pon 1で閉じないもの。

```txt
黒インクはどこから来たのか
なぜ読めなくなるのか
影の班は敵か味方か
未配達の封筒の持ち主は誰か
四つ折りの地図は誰が折ったのか
地図帳は何冊あるのか
街の外にも夜はあるのか
```

ただし、全部を露骨に見せない。

1作目の最後に見せる余白は1つ、多くても2つ。

---

# 5. シリーズ謎の階層

## A級謎: シリーズ全体で扱う

```txt
黒インクとは何か
なぜ記憶は“読めなくなる”のか
地図帳を最初に作ったのは誰か
忘れ物係は本当に遊びだったのか
```

A級謎は1作目で答えを出さない。

ただし、矛盾しないSeedだけ置く。

---

## B級謎: 2以降で回収できる

```txt
未配達の封筒
四つ折りの地図
影の班
知らない筆跡
別のページ束
```

B級謎は2で主軸にできる。

---

## C級謎: 1作目内で回収する

```txt
空白の名札
片方だけの切符
直されたランタン
開けるなと書かれた箱
ユイ以外の筆跡
```

C級謎は必ず1で回収する。

# 6. 後付け防止Seed

最初から置くべきSeed。

```txt
未配達の封筒
四つ折りの地図
知らない筆跡
閉じたページ束
半分の飴
にじんだ絵筆
空白のカード
```

ただし、名前は出さない。

出すのは痕跡だけ。

---

# 7. 黒インクの長期設定

黒インクをただの悪にしない。

長期的には、黒インクには複数の見え方がある。

## 1作目の見え方

```txt
記憶を読めなくする敵
```

## 2以降の見え方

```txt
見たくない痛みを隠す防衛反応
誰かが守るために塗ったもの
言葉になる前の感情
```

## シリーズ後半の可能性

```txt
黒インクは消すものではなく、読み方を変えるものだった
```

ただし、1作目ではここまで言わない。

---

# 8. 影の班の扱い

影の班は、敵として出しすぎない。

役割:

```txt
ユイたちとは別の方法で記憶を守っていた子たち
光に出すより、影に隠した方が守れると信じている
```

1作目での扱い:

```txt
四つ折りの地図
黒い折り紙
空白のカード
影の中の別筆跡
```

2以降での扱い:

```txt
敵対から共闘へ
同じ目的、違う方法
ユイたちの“拾う”思想と、影の班の“隠す”思想の衝突
```

ここは長期的に強い。

---

# 9. 2の最有力テーマ

2の最有力テーマはこれ。

```txt
届かなかった手紙
```

理由:

```txt
1の地図帳から自然に派生する
未配達の封筒Seedを使える
恋愛、家族愛、師弟、街の人を自然に混ぜられる
黒インクの“言葉になる前の感情”という側面を描ける
```

2の一文:

```txt
届かなかった言葉も、なかったことにはならない。
```

1との違い:

```txt
1: 忘れ物を拾う
2: 届かなかった言葉を届け直す
```

変えないもの:

```txt
夜
欠片
朝
力はほどけるが意味は残る
小物の反転
前向きな着地
```

# 11. 破綻しないためのルール

## Rule 1: 主人公の物語は各作で閉じる

```txt
各作の主人公は、その作で救う。
```

未完で引っ張らない。

## Rule 2: シリーズ謎は少しだけ進める

```txt
1作でA級謎を全部解かない。
```

## Rule 3: 追加キャラは既存Seedから出す

```txt
突然の重要キャラは禁止。
```

## Rule 4: 小物は必ず二重意味を持つ

```txt
初見の効果
終盤の意味
```

## Rule 5: 黒インクを単純悪にしない

```txt
倒す対象であり、読む対象でもある。
```

## Rule 6: 恋愛を説明しすぎない

```txt
恋愛として読める。
友情としても読める。
```

## Rule 7: 余白は未定ではない

```txt
答えは持つ。
でも全部は出さない。
```

---

# 12. 長期年表は作りすぎない

今の段階で詳細な年表を作りすぎると、運用が硬くなる。

作るべきなのは年表ではなく、真相の階層。

```txt
1作目で閉じる真相
2で扱える真相
シリーズ後半まで残す真相
永遠に余白として残してもいい真相
```

---

# 13. 永遠に説明しなくていい余白

説明しなくてよいものも残す。

```txt
一部の落書きの持ち主
街の外のすべて
黒インクの完全な物理法則
全てのページ束の数
全キャラのその後
```

全部説明すると、Vamp Ponの余白が死ぬ。

---

# 14. 最重要の長期設計

シリーズ全体の芯はこれ。

```txt
消えたと思ったものは、形を変えて残っていた。
```

各作の変化:

```txt
1: 忘れ物として残っていた
2: 届かなかった手紙として残っていた
3: 写っていない写真として残っていた
4: 聞こえなかった音として残っていた
```

表現は変える。

感情の芯は変えない。

---

# 15. 1作目ラストの推奨

```txt
朝になった。
このページの名前は、もう消えなかった。

地図帳は静かに閉じた。
背表紙のすきまから、未配達の封筒が一枚だけ落ちた。
封は、まだ開いていない。
```

この終わりなら、1は終わる。

でも2へ自然に繋がる。

---

# 16. 最後の判断

Vamp Ponは、巨大な世界設定で長続きさせるゲームではない。

長続きさせる鍵は、これ。

```txt
小さな1作をちゃんと終わらせる。
でも、次に読める小さな紙片を一枚だけ残す。
```

これを守れば破綻しにくい。

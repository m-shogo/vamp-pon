# Long-term Scenario Architecture

## 目的

Vamp Pon 1 をきちんと完結させながら、シリーズを追うほど前作の小物や違和感の意味が変わる長期構造を定義する。

以前の「続編へ自然につなげる」だけでは弱い。

正しくは以下。

```txt
1本だけで完結する。
でも、世界の前提はすべて説明されない。
シリーズを追うと、前作で見えていたものの意味が変わる。
```

---

# 1. 最重要方針

```txt
ローカル完結。
メタ謎継続。
後作で前作の意味が変わる。
```

Vamp Pon 1では、ユイ班のページ束を閉じる。

ただし、地図帳そのもの、黒インクの起源、別の班の痕跡は閉じない。

重要なのは、続編予告をすることではない。

```txt
1では自然な背景/小物だったものが、2以降で別の意味を持つ。
```

---

# 2. シリーズ全体の構造

## Layer 0: 1ラン

```txt
夜になる
意味の欠片を拾う
その夜だけ強くなる
朝まで残る
朝に意味が確定する
夜の力はほどける
```

## Layer 1: 1ページ

```txt
1つの誤解
1つの小物
1つの持ち主
1つの反転
```

## Layer 2: 1ページ束

```txt
複数ページのまとまり
1つの班/関係性の誤解がほどける
```

## Layer 3: 1作

```txt
1つの地図帳の一部、または1冊が閉じる
主人公/班の物語は完結する
世界全体のメタ謎は残る
```

## Layer 4: シリーズ

```txt
地図帳が複数ある理由
黒インクの本当の性質
忘れ物係がなぜ子どもの遊びに見えるのか
朝の確定処理は本当に救いなのか
```

---

# 3. 1作目で閉じるもの

Vamp Pon 1で必ず閉じるもの。

```txt
ユイは持ち主を間違えない子だった
アサの名札は空白ではなく、何度も書き直されたものだった
ナギの箱は拒絶ではなく、隔離/保護だった
ミチルの切符は片道ではなく、帰る予定が残っていた
トモリのランタンは待つ灯りではなく、朝まで意味を保つ灯りだった
ユイ班のページ束は朝に確定した
```

これらは2へ持ち越さない。

1作目の感情はここで閉じる。

---

# 4. 1作目で閉じないもの

Vamp Pon 1で閉じないもの。

```txt
黒インクを最初に生んだ誤解は何か
忘れ物係はなぜ遊びとして現れたのか
地図帳を綴じたのは誰か
朝の確定処理は完全に安全なのか
別の班は同じ目的なのか、別の目的なのか
```

ただし、これらを説明台詞で匂わせない。

置くのは違和感だけ。

---

# 5. シリーズ謎の階層

## A級謎: シリーズ全体で扱う

```txt
黒インクはなぜ誤解を固定するのか
誰が最初に“意味を分けて隔離する”仕組みを作ったのか
地図帳は誰のためのものか
朝の確定処理は救いか、それとも別の固定か
```

A級謎は1作目で答えを出さない。

ただし、最初から答えに矛盾しない痕跡を置く。

---

## B級謎: 2以降で主軸にできる

```txt
未配達の封筒
四つ折りの地図
知らない綴じ糸
影の折り紙
別の地図帳の折り目
```

B級謎は、1では自然な小物として出す。

2以降で意味が変わる。

---

## C級謎: 1作目内で回収する

```txt
空白の名札
片方だけの切符
直されたランタン
開けるなと書かれた箱
ユイ以外の筆跡
```

C級謎は必ず1で回収する。

---

# 6. 後作で意味が変わるSeed

以下は、1では回収しきらない。

```txt
未配達の封筒
四つ折りの地図
知らない綴じ糸
半分の飴
にじんだ絵筆
空白のカード
折り目の違う紙片
```

初見では、ただの雰囲気や背景小物に見える。

後作で、以下のように意味が変わる。

```txt
未配達の封筒
初見: 次の話っぽい紙
後作: 手紙班が誤解を固定させないためにわざと届けなかったもの

四つ折りの地図
初見: 謎の地図
後作: 影の班の“隠す返却方法”の痕跡

知らない綴じ糸
初見: 古い製本跡
後作: 背表紙班が地図帳の順番を書き換えた証拠
```

---

# 7. 黒インクの長期設定

1作目の見え方:

```txt
記憶を読めなくする敵
```

Season 1終盤の見え方:

```txt
人が信じ込んだ間違った意味を固定するもの
```

2以降の見え方:

```txt
固定された誤解を、あえて壊さないことで守られている人もいる
```

シリーズ後半の可能性:

```txt
黒インクを全部消すことが正解ではない。
固定された誤解をほどく順番を間違えると、意味そのものが壊れる。
```

このため、黒インクは単純悪にしない。

---

# 8. 影の班の扱い

影の班は「敵」ではなく、別思想の班。

ユイ班:

```txt
正しい持ち主へ返す
```

影の班:

```txt
間違った意味でも、壊れるよりは隠して守る
```

対立軸:

```txt
返すべきか
隠すべきか
ほどくべきか
固定したまま守るべきか
```

1作目では名前を出さない。

出すのは以下だけ。

```txt
折り目の違う紙片
黒い折り紙
消しゴムのかけら
夜読みの定規
空白のカード
```

---

# 9. 2の候補は固定しない

現時点で「届かなかった手紙」は最有力候補。

ただし、2として固定しない。

候補:

```txt
A. 届かなかった手紙
B. 影の班
C. 写っていない写真
D. 聞こえなかった音
```

どれを選ぶかは、1の最後に残る違和感で決める。

今の最有力:

```txt
届かなかった手紙
```

理由:

```txt
誤解の固定と相性が良い
届けなかった理由を作れる
恋愛、家族、師弟、街の人を混ぜられる
```

2の一文候補:

```txt
届かなかった言葉も、なかったことにはならない。
```

---

# 10. 破綻しないためのルール

## Rule 1: 主人公/班の感情は各作で閉じる

```txt
その作の中心誤解は、その作でほどく。
```

## Rule 2: シリーズ謎は説明しすぎない

```txt
分かる人だけ違和感を覚えるSeedを置く。
```

## Rule 3: 追加キャラはSeedから出す

```txt
突然の重要キャラは禁止。
```

## Rule 4: 小物は二重意味では足りない

```txt
初見の意味
1作内回収後の意味
シリーズ後の意味
```

三重意味を持てる小物を優先する。

## Rule 5: 黒インクは倒すだけにしない

```txt
倒す対象
読む対象
ほどく対象
場合によっては残す対象
```

## Rule 6: 続編予告を安売りしない

```txt
露骨な番号、露骨な未開封アイテムだけに頼らない。
```

違和感で残す。

---

# 11. 永遠に説明しなくていい余白

説明しなくてよいものも残す。

```txt
一部の落書きの持ち主
街の外のすべて
黒インクの完全な物理法則
全てのページ束の数
全キャラのその後
```

全部説明すると、Vamp Ponの余白が死ぬ。

---

# 12. シリーズ全体の芯

シリーズ全体の芯はこれ。

```txt
悲しい出来事は消えない。
でも、その出来事についた間違った意味は、いつかほどける。
```

各作の変化:

```txt
1: 忘れ物として固定された意味を返す
2: 届かなかった言葉に固定された意味をほどく
3: 写っていない視線に固定された意味をほどく
4: 聞こえなかった音に固定された意味をほどく
```

表現は変える。

感情の芯は変えない。

---

# 13. 1作目ラストの推奨

露骨な続編予告ではなく、違和感で終わる。

```txt
朝になった。
このページの名前は、もう消えなかった。

地図帳は静かに閉じた。
ユイはそれを胸にしまった。

最後の一瞬、閉じたはずのページの端だけ、
ユイたちの折り方ではない形に折れていた。
```

この終わりなら、1は終わる。

でもシリーズを追った後に、1のラストの意味が変わる。

---

# 14. 最後の判断

Vamp Ponは、巨大な説明で長続きさせるゲームではない。

長続きさせる鍵はこれ。

```txt
その作ではちゃんと救う。
でも、見えていたものの意味をシリーズ後に変える。
```

# 160. Higher Order Lineage Rules

This document protects the setting when four-lineage or five-lineage characters appear later.

## Core rule

Four-lineage and five-lineage beings are not normal characters.
They are story events in character form.

They must be rare, costly, and partly unresolved.

## Why higher order exists

Allowed reasons:

- a family tried to save one person by combining many vessel parts
- black ink forced unrelated memories into one body
- an old page tried to keep every possible ending
- a vessel became a map for several families
- a final enemy carries too many wrong readings
- a hidden ally survived by becoming incomplete

Forbidden reasons:

- stronger than three-lineage by default
- all colors at once because it looks cool
- late-game power creep without story cost
- random secret boss with no relation web

## Four-lineage rule

Four-lineage means unstable crossroad.

Use for:

- season key rival
- late boss phase
- impossible preserved memory
- old family experiment

Required:

- one primary vessel shape
- two visible secondary marks
- one hidden fourth mark
- clear reason why four lights coexist
- a cost that affects relationship or memory

## Five-lineage rule

Five-lineage means almost too much meaning for one vessel.

Use only for:

- final page entity
- hidden true-boss seed
- old world-system secret
- once-per-season mythic character

Required:

- not fully explained at first
- not all powers usable at once
- one blank space must remain after defeat or rescue
- it must connect at least three characters emotionally
- it must affect item meaning, not only battle power

## Visual rule

Do not draw four-lineage or five-lineage as rainbow designs.

Use hierarchy:

1. main vessel silhouette
2. dominant light family
3. secondary mark
4. broken or hidden marks
5. reveal-only effect

## Gameplay rule

Higher-order characters should not simply have many attacks.

Use:

- phase selection
- unstable rotation
- exposed core
- limited window
- vessel repair objective
- false reading that must be corrected

## Happy-end rule

A higher-order enemy does not need to be erased.
The better ending is to separate the meanings enough that each can be carried by the right person.

## Open-space rule

Even if a higher-order character is resolved, leave one question:

- who created the first combined vessel?
- whether the fusion was rescue or mistake
- which memory was never returned
- whether Yui saw the original event

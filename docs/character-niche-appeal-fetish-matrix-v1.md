# ヨルノシルベ — Niche Character Appeal / Fetish Matrix v1

Date: 2026-08-10  
Status: **USER DIRECTION + CANDIDATE RESERVOIR / NOT AUTO-CANON**

> 目的: キャラクターを「性格ラベルの集合」にせず、少数の人へ強烈に刺さる身体感・生活感・仕草・服装・声・関係性の細部を大量に持たせる。
>
> ここでいう「フェチ」は露骨な性的描写ではなく、**この細部があるだけで好きになる人がいる、ニッチな魅力の軸**を指す。
>
> 一人へ全部を盛らない。1人につき「主刺さり2〜4 + 副刺さり2〜5」程度を目安にし、人格・Gameplay・関係性と接続する。

---

# 1. 絶対ルール

- Current21 / Future15へ勝手に確定配布しない
- 体型・肌色・障害・性別表現・性的指向をギャグや記号だけにしない
- 幼く見える長寿成人を性的フェチ枠へ入れない。**成人であることを明確にし、見た目と人生経験のズレ**として扱う
- 年少キャラクターがいる場合、性的なフェチづけはしない
- 太い / 大きい / 小さい / 老いた身体を「直すべき見た目」にしない
- 傷・義肢・車椅子等は悲劇記号にしない
- 同じ刺さりを複数人へ重複させる場合、理由・出方・生活への影響を変える
- 「人気属性を乗せたから魅力的」ではなく、日常行動と人間関係へ返す

# 13. 三つ子について

USER DIRECTIONに合わせ、**三つ子は不足枠として高価値Candidate**。

ただしFuture15へ即追加しない。

強い方向:

```txt
A = まとめる人
B = ずらす人
C = 外から見る人
```

の固定役割にはしない。

場面ごとに:

- A+Bが意気投合しCが違う
- B+Cが秘密を共有しAが後から知る
- A+Cが似た選択をしBだけ反対する

と**2対1の組み合わせが回転する**。

三人同時に同じ人を好きになる等のテンプレより:

> 「自分だけが知らない二人の思い出がある」

という友情 /兄弟嫉妬を使う方がヨルノシルベ向き。

Robot A/Bや双子とは:

- 双子 = 二人で一つ扱いされる /違いを作りすぎる
- 三つ子 = 2対1の流動性 /秘密 /所属感
- Robot A = 同じdataから始まる本人性
- Robot B = 共有memoryから個人になる

でThemeを分ける。

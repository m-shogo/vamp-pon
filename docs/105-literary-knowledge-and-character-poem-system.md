# Literary Knowledge and Character Poem System

Vamp Pon / ヴァンサバ改における「本当の名言・本・物語・漫画からの知識供給」と「Vamp Pon自身のキャラポエム」を両立させるための正本。

結論:

```txt
Vamp Pon に必要なのは、引用そのものではない。
遊ぶたびに、本・詩・物語・漫画・神話の入口が少し開き、
その知識がキャラの弱さと灯りに結びつく体験である。
```

---

## 1. 現状評価

現状は、まだ完成ではない。

できていること:

```txt
世界観の芯は定義済み。
キャラ20人の肩書き・キャッチコピー・初期ポエムはある。
翻訳なしの原文引用候補100個はある。
星の王子さまを、直接引用ではなく世界観サンプルとして扱う方針はある。
```

足りないこと:

```txt
引用が「知識供給」としてプレイヤーに届く設計がまだ弱い。
キャラポエムが、まだ全員BLEACH巻頭ポエム級まで尖っていない。
引用とキャラの関係が、まだ一部ふわっとしている。
漫画・現代作品からの学びを、引用禁止の設計メモとして整理しきれていない。
ローディングに出す文、図鑑に残す文、PVで使う文の役割分担がまだ弱い。
```

この資料で、ここを正本化する。

---

## 2. 二層構造

Vamp Ponの言葉は、必ず2層に分ける。

### A. Knowledge Layer / 知識の扉

本当の名言・本・物語・詩・神話・古典・漫画から、新しい知識や感情の入口を作る層。

使い道:

```txt
ローディング
ステージ開始
図鑑の小さな注釈
コレクション要素
ライブラリ/記録室
```

目的:

```txt
プレイヤーが「これ何？」と思う。
あとで調べたくなる。
世界の奥行きを感じる。
Vamp Ponが、ただの雰囲気ゲームではなくなる。
```

### B. Heart Layer / キャラの心臓

Vamp Pon自身の言葉。
キャラ選択、カットイン、朝明、黒耀、PVの主役になる。

使い道:

```txt
キャラ選択
カットイン
黒耀演出
朝明演出
PVメインコピー
SNSカード
グッズ台紙
```

目的:

```txt
そのキャラしか言えない。
短い。
声に出したくなる。
初見で刺さり、後から意味が変わる。
```

## 3. 絶対ルール

```txt
引用は主役にしない。
キャラを飾るためだけに名言を置かない。
引用で世界観を借りすぎない。
Vamp Ponのキャラの言葉が、最後に勝つようにする。
```

```txt
安全な古典引用は、原文で短く使う。
翻訳はしない。
現代作品・漫画・映画・歌詞は、画面に引用しない。
ただし、設計メモとして思想や構造を学ぶ。
```

## 4. 星の王子さまの位置づけ

星の王子さまは、Vamp Ponと世界観相性が非常に高い。

合うところ:

```txt
小さな星
子どもの目線
見えない大切さ
孤独
帰る場所
一見かわいいが寂しい
短い言葉に余白がある
```

ただし、画面表示には使わない。
既存訳も原文も商用UIでは避ける。

採るのは思想だけ。

Vamp Pon側の言葉に変える:

```txt
見えないものほど、夜に残る。
```

```txt
小さな星にも、帰れない夜がある。
```

```txt
なくしたあとで、光りはじめるものがある。
```

## 5. 漫画・現代作品から学ぶこと

漫画や現代作品の名台詞は、そのまま使わない。
ただし、構造は学ぶ。

### BLEACHから学ぶこと

```txt
短い言葉で、キャラの傷を言い切る。
説明しない。
余白を残す。
最初に読んだ時と、物語後半で意味が変わる。
キャラの弱さを、詩にする。
```

Vamp Ponへの変換:

```txt
キャラごとに「その子しか言えない一文」を持つ。
ポエムは設定説明ではなく、傷口の形にする。
```

### NARUTOから学ぶこと

```txt
孤独、名前を呼ばれること、帰る場所、仲間になるまでの距離。
強さより、認められたい気持ちが先にある。
```

Vamp Ponへの変換:

```txt
シノ、ユイ、レン、マヨイの関係性に活かす。
```

### ONE PIECEから学ぶこと

```txt
夢、仲間、持ち物、約束、別れの記号化。
小物がキャラの記憶になる。
```

Vamp Ponへの変換:

```txt
星標器、紋章、忘れ物、星灯獣、グッズ展開に活かす。
```

### デジモンから学ぶこと

```txt
子どもごとの紋章。
成長と誤進化。
パートナー存在。
小物がIPの共通記号になる。
```

Vamp Ponへの変換:

```txt
星標器 → 紋章 → 星灯獣。
黒耀は闇落ちではなく、弱さがにじんだ誤灯り。
朝明は救い。
```

### 星の王子さまから学ぶこと

```txt
小さな星に大きな孤独を入れる。
やさしい文なのに、底に寂しさがある。
見えないものを中心に置く。
```

Vamp Ponへの変換:

```txt
夜、忘れ物、小さな灯り、帰り道の核にする。
```

## 6. 知識供給のゲーム内導線

### ローディング

役割:

```txt
短い原文引用を見せる。
読める時間を確保する。
意味を押し付けない。
```

例:

```txt
We grow accustomed to the Dark.
```

```txt
Sunt lacrimae rerum.
```

```txt
E quindi uscimmo a riveder le stelle.
```

表示ルール:

```txt
原文のみ
出典は小さく下部
翻訳なし
最低2.8秒表示
1プレイ中に同じ引用を出しすぎない
```

### 図鑑 / 記録室

役割:

```txt
引用の出典を少しだけ説明する。
Vamp Ponのキャラやステージとの関係を1文で書く。
プレイヤーが調べる入口にする。
```

例:

```txt
Sunt lacrimae rerum.
Virgil, Aeneid.
「物にも涙がある」という思想は、忘れ物が夜を濃くするVamp Ponの核に近い。
```

### キャラ選択

役割:

```txt
引用ではなく、Vamp Ponポエムを出す。
キャラの心臓を見せる。
```

## 11. 最終判断

今のVamp Ponは、方向性としてはそこへ向かっている。
ただし、まだ十分ではない。

完成形はこれ:

```txt
ロード中に、本物の言葉に出会う。
キャラ選択で、Vamp Pon自身の言葉に刺される。
図鑑で、その2つが静かにつながる。
```

これができれば、Vamp Ponはただのヴァンサバ系ではなく、

```txt
遊ぶたびに、夜と言葉が増えるゲーム
```

になる。

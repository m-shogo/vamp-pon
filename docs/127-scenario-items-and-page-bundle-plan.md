# Scenario Items and Page Bundle Plan

## 目的

Vamp Ponのシナリオ、アイテム、キャラ関係、感情の起伏を、現行の世界法則と矛盾しない形で設計する。

現行方針:

```txt
黒インク = 間違った意味を固定するもの
欠片 = 固定から剥がれた意味片
朝 = その夜にほどけた意味の確定処理
友情 = メイン
恋愛 = サブ/別ページ束
シリーズSeed = 予告ではなく再読で意味が変わる小物
```

---

# 1. Page Bundle構成

```txt
1 run = 夜 / 未確定ページの1回の読み直し
5 stages = 1ページ / 1つの誤解と小物反転
15 stages = 1ページ束 / 1つの関係性や系統の誤解がほどける区切り
```

# 4. アイテム設計

## アイテムの基本式

```txt
表の効果
1作内の意味
シリーズ後に変わる意味
持ち主Seed
反転
```

## 夜の鉛筆

```txt
表: 前方へ自動攻撃
1作内: 誰の意味かを仮に書き留める
持ち主Seed: ユイ / アサ
反転: 削れていたのは、何度も名前を書いたから
```

## 名前のラベル

```txt
表: 敵へ印をつける
1作内: 持ち主と名前を接続する
持ち主Seed: アサ
反転: 空白ではなく、書き直し続けた跡だった
```

## 月の箱

```txt
表: 一定時間ごとに欠片を吸い込む
1作内: 読まれると壊れる理由を一時隔離する
持ち主Seed: ナギ
反転: 閉じたから残った
```

## 金のコンパス

```txt
表: 近い欠片や安全地帯を示す
1作内: 返すべき場所/相手を読む
持ち主Seed: ミチル
反転: 明るい方ではなく、覚えている方を指す
```

## ランタン

```txt
表: 周囲の影を払う
1作内: 仮接続した意味を朝まで保持する灯り
持ち主Seed: トモリ
反転: ユイは一人で夜を歩いていなかった
```

## 未配達の封筒

```txt
表: 遅れて敵へ届く追尾弾
1作内: 届かなかった言葉
シリーズ後: 届けないことで守られていた可能性
持ち主Seed: 手紙系統
反転: 届かなかった手紙も、捨てられてはいなかった
```

## 四つ折りの地図

```txt
表: ランダムに地形/敵流れを変える
1作内: まだ開かれていない別系統の痕跡
持ち主Seed: 影系統
反転: 折ったから持ち歩けた
```

# 5. 恋愛の扱い

恋愛は主役にしすぎない。

Season 1では友情と自己肯定を優先する。

恋愛は以下へ分散する。

```txt
手紙系統
写っていない写真
聞こえなかった音
年を取らない魔女 × 年を取る人間
```

ユイとアサは公式恋愛にしない。

---

# 6. 友情の扱い

友情はメイン。

友情は、仲良し会話ではなく以下で見せる。

```txt
半分ずつ持っていた小物
誰かが直した道具
敵が踏まない名札
同じ癖の字
不安定だけど強いコンビ技
```

システム上は「きずな」として扱う。

```txt
きずな = 意味の接続安定度
```

---

# 7. 重い関係の扱い

重い関係はサブ/後作/隠しページ。

採用候補:

```txt
年を取らない魔女 × 年を取る人間
敵だった相手 × 一番理解していた相手
届ける人 × 届けてはいけない手紙
封印する人 × 封印された人
人形/人工物 × 人間
ライバル × ライバル
```

Season 1ではSeedだけ。

---

# 8. 最重要

Vamp Ponのアイテムは、ただエモい小物ではない。

```txt
小物にできる
黒インクの誤解固定にできる
ゲーム効果にできる
回収後に意味が反転する
恋愛以外にも読める
```

この条件を満たすものだけ採用する。

# Scenario Items and Page Bundle Plan

## 目的

Vamp Ponのシナリオ、アイテム、キャラ関係、感情の起伏を、Season 1から2へ繋がる形で設計する。

感情として以下を含める。

```txt
感動
恋愛
驚き
悲しみ
楽しみ
友情
家族愛
師弟関係
不穏さ
ハッピーエンド
```

ただし、全部を前面に出さない。

Vamp Ponは、遊びながらあとで効いてくる物語にする。

# 5. アイテム設計

## アイテムの基本式

```txt
表の効果
裏の意味
持ち主Seed
反転
```

---

## 夜の鉛筆

```txt
表: 前方へ自動攻撃
裏: 読めなくなったものをもう一度書く
持ち主Seed: ユイ / アサ
反転: 削れていたのは、何度も名前を書いたから
```

## 名前のラベル

```txt
表: 敵へ印をつける
裏: 名前を貼れなかった記憶
持ち主Seed: アサ / 妹Seed
反転: 空白ではなく、書き直し続けた跡だった
```

## 月の箱

```txt
表: 一定時間ごとに欠片を吸い込む
裏: なくならないようにしまったもの
持ち主Seed: ナギ / おばあちゃんSeed
反転: 閉じたから残った
```

## 金のコンパス

```txt
表: 近い欠片や安全地帯を示す
裏: 帰る場所ではなく帰る相手を指す
持ち主Seed: ミチル / おじいちゃんSeed
反転: 明るい方ではなく、覚えている方を指す
```

## ランタン

```txt
表: 周囲の影を払う
裏: 誰かが直してくれた灯り
持ち主Seed: トモリ
反転: ユイは一人で夜を歩いていなかった
```

## 半分の飴

```txt
表: HP回復 / 分裂弾強化
裏: 帰ってきたら半分あげる約束
持ち主Seed: お兄ちゃんSeed
反転: 渡せなかったのではなく、残して待っていた
```

## 未配達の封筒

```txt
表: 遅れて敵へ届く追尾弾
裏: 届かなかった言葉
持ち主Seed: 郵便屋さん / ユウビ
反転: 届かなかった手紙も、誰かを動かした
```

## 押し花のしおり

```txt
表: 一定時間ごとに経験値を保存/変換
裏: しまっておいた季節
持ち主Seed: ナギ / おばあちゃん
反転: 枯れたのではなく、残された
```

## 四つ折りの地図

```txt
表: ランダムに地形/敵流れを変える
裏: まだ開かれていない別グループの記憶
持ち主Seed: カゲール / 影の班
反転: 折ったから持ち歩けた
```

# 6. 恋愛の扱い

恋愛は主役にしすぎない。

ただし、濃い余白として使う。

良い恋愛:

```txt
何度も消して書き直した名前
渡せなかったしおり
同じ帰り道を選んでいた
相手の癖だけ覚えていた
```

悪い恋愛:

```txt
告白で全部説明
三角関係をメインにする
恋愛だけが動機になる
```

Vamp Ponの恋愛は、友情/家族愛/師弟愛と並ぶ一つの愛にする。

---

# 7. 驚きの扱い

驚きは、大きな黒幕ではなく小物の再解釈で出す。

例:

```txt
片道切符 → 裏に帰りの印
空白の名札 → 書き直し跡
閉じた箱 → 守るために閉じた
敵の影 → 誰かの読めない記憶
```

---

# 8. 悲しみの扱い

悲しみは必要。

ただし、プレイヤーを沈ませるためではない。

```txt
つらい記憶
↓
見落としていた小さな優しさ
↓
本当は一人ではなかった
```

この順番を守る。

---

# 9. 楽しみの扱い

深い設定があっても、表は楽しくする。

```txt
欠片が気持ちよく吸える
敵がわらわら来る
武器が進化する
キャラごとに遊び方が変わる
リザルトがかわいい
```

物語は、楽しく遊んだ後に効く。


# 11. 最重要

Vamp Ponの物語は、全部を説明しない。

でも、何も考えていない余白にはしない。

```txt
遊びは軽く。
意味は深く。
回収は温かく。
余白は残す。
```

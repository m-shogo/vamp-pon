## 1. 二段階の正体

### 序盤〜中盤前半: 「八影」

Current側が、似た時期に現れた8つの強いWrong Readingを便宜上まとめて呼ぶ**観測上の仮称**。

この時点では既存設定どおり:

- 共通起源を断定しない
- 組織を断定しない
- 上下関係を断定しない
- 真名を断定しない

### 中盤以降: 「朔盟（さくめい）」

8体が同一起源だから集まったのではない。

**それぞれ別の失敗・善意・恐れを抱えた者が、ひとつの思想へ同意して結んだ盟約。**

八影は誤りではなく、朔盟をまだ知らなかった時代の観測名として残す。

```txt
八影 = EARLY_OBSERVER_LABEL
朔盟 = REVEALED_ANTAGONIST_PACT
```

これにより既存の八影資料をretconせず、後から意味を反転させられる。

## 2. 朔盟の中心思想

> 迷いが人を傷つける。なら、世界から迷いをなくせばいい。

朔盟は「悪くなりたい者」の集団ではない。

全員が異なる形で、

- 間違える自由
- 選び直す自由
- 保留する自由
- 忘れる自由
- 開ける / 閉じる自由
- 帰り道を自分で選ぶ自由

を危険だと考え、**本人より先に正解を固定しようとする**。

### 主人公側との対立軸

朔盟:

> 正解を決めれば、もう傷つかない。

Current側:

> 傷つく可能性があっても、本人が選び直せる余白を残す。

作品テーマの中心対立として使う。

## 3. 名前

正式呼称: **朔盟**  
読み: **さくめい**  
英語working label: **Sakumei / Pact of the New Moon**

### 名前の意味

- **朔**: 月の姿が見えない新月。消滅ではなく、次の月が始まる境界。
- **盟**: 血縁・同族・軍隊ではなく、異なる者が意思で結ぶ約束。

「8人だから八〜」「闇だから影〜」という人数・属性直結命名から外し、組織自体を固有IPとして立たせる。

## 4. 共通記号 — 欠円（けつえん）

朔盟の唯一の強い共通visual grammar。

**完全な円ではなく、一部が欠けた円。**

意味:

> 未完成を嫌い、欠けた部分を自分たちの正解で埋めようとする。

ただし全員が同じ制服を着ることは禁止。

各member固有の造形へ欠円を埋め込む。

## 5. 8 memberの思想上の立ち位置

既存character hookを維持し、朔盟思想へ接続する。

### ナシロ — 「名前は一つでなければならない」

- 誤った名前で残されることを恐れる。
- 本人より先に「正しい名前」を決める。
- 朔盟思想の最も純粋な**Identity Fixation**。

### アサトジ — 「失うくらいなら閉じればいい」

- 喪失を恐れる。
- 守るための保管が永久拘束へ変わる。
- **Protection without consent**。

### ミチグレ — 「間違う道なら消せばいい」

- 誰かを迷わせる責任を恐れる。
- 選択肢を減らし、最後は帰路までなくす。
- **Choice Erasure**。

### オリネ — 「危険な意味は隠せばいい」

- 開示による傷を恐れる。
- 意味を折り畳み続け、本人が開く権利まで奪う。
- **Merciful Concealment**。

### ハクマ — 「誤解されるくらいなら意味を消せばいい」

- 間違った説明が残ることを恐れる。
- 説明だけでなく本人の言葉まで空白へ戻す。
- **Meaning Erasure**。

### ツグリ — 「壊れているなら直せばいい」

- 壊れた状態を放置することを恐れる。
- 本人が望む前に修理し、傷や失敗まで消す。
- **Forced Repair**。

### ユラネ — 「苦しい現実なら眠らせればいい」

- 苦痛を見続けることを恐れる。
- 安らぎを与え、戻る理由まで弱くする。
- **Comfort as Captivity**。

### ペタ — 「間違いなら正しい札を貼ればいい」

- 間違いを認めることそのものを嫌う。
- 剥がさず、上から新しい正解を貼る。
- **Correction without Reflection**。

ペタはcomic reliefだけにしない。

普段は「またペタいる」と思わせつつ、一度だけ**笑えないほど正解を上書きするscene**を持たせる。

## 6. 組織構造

軍隊型階級制にはしない。

朔盟は「共通ボスへ従う部下」ではなく、**同じ結論へ別々の理由で到達した8者の盟約**。

### 固定すること

- 全員が朔盟思想へ完全に同じ温度で賛成しているわけではない。
- 任務単位で2人組 / 3人組になる。
- 相互利用、反発、軽蔑、理解、奇妙な相性がある。
- 一枚岩ではないが、重要局面では盟約を優先する。

### 固定しないこと

- 絶対的首領
- 血縁
- 同一創造者
- 同じ種族
- 全員救済
- 全員死亡
- 裏切り担当を最初から一人に固定

leader / founder / first pact memberはMain Mysteryと衝突しないよう別Candidate laneで検討する。

## 7. 既存28pairの昇格

既存の八影28pair dynamicは削除しない。

旧解釈:

> 同じ場所に二つのWrong Readingが偶然発生した。

朔盟revealed後:

> 盟約の任務として意図的に組んだ可能性もあった。

へ再解釈可能にする。

ただし全pairを固定buddyにしない。

### Pair Mission Rule

- 同じ2人を連打しない。
- 能力相性だけでなく**思想衝突**を選定理由にする。
- 一方が一方の弱点を偶然露出させる。
- enemy team内の会話 / gesture / cueだけでも関係性を読める。
- 2人倒すだけのHP足し算にしない。

既存28pairはそのための資産として維持する。

## 9. Reveal choreography Candidate

### Phase A — 8つの影

敵同士が同じ記号を持つことにまだ気づかせない。

### Phase B — 欠円

複数enemyの所持物に同じ「欠けた円」があるとプレイヤーが気づく。

### Phase C — pair mission

偶然では説明しづらい連携が一度だけ出る。

### Phase D — 朔盟

敵自身が大声で組織名を名乗るのではなく、**残された盟約文 / 記録 / 行動の一致**から名称が判明する。

### Phase E — internal fracture

朔盟思想には同意していても「何を正解とするか」がmember間で食い違い始める。

この亀裂を単純な善落ち・裏切りイベントにはしない。

# ヨルノシルベ Character Roster Review v1

Date: 2026-07-28  
Status: **CURRENT ROSTER REVIEW / NOT A POPULARITY POLL / DOES NOT AUTO-PROMOTE FUTURE CAST**

> 目的: Current21 + Future15 = 36候補を、人数だけで削らず「その人にしかない魅力 / 作品上の必要性 / Gameplay / 関係 / 日常 / 黒耀化」で監査する。
>
> 本書の点数は現時点の**設計成熟度と交換不能性**を見る内部指標。将来の実人気順位ではない。

---

# 0. 結論

## シリーズ全体

**36候補は多すぎない。削除を急がない。**

ヨルノシルベは:

- 本編1
- sequel
- 別時代Stage
- optional character
- DLC / expansion
- 灯録 / 観測記録で先行登場

へ人物を分配できる。

## 1作目

36人を同じ密度で出すのは多すぎる。

推奨:

```txt
Narrative spine          6
Major rotating cast      7
Supporting / optional    8
--------------------------
Current playable pool   21

Future candidates       15
→ sequel / later / optional / foreshadowing
```

**Playable人数とStory主役人数を同一にしない。**

Survivors-like gameとして解放キャラが多いことは遊びになるが、Main Storyで全員へ同じ説明時間を与えると人物の印象が薄くなる。

# 1. Review axes

各5点、35点満点。

| Axis | 見るもの |
| --- | --- |
| I — Icon | 一枚絵 / 小物 / 動きだけで判別できるか |
| U — Unique | 他キャラへ設定を移しても成立してしまわないか |
| R — Relation | 強い1対1関係を複数作れるか |
| D — Daily | 何も起きない日常でも好きになれるか |
| B — 黒耀化 | その人物固有の「もう一つの自分」があるか |
| G — Gameplay | 操作 / build / Supportとして違いがあるか |
| T — Theme | ヨルノシルベの問いへ新しい角度を足すか |

Score guide:

```txt
32-35  = Series Anchor級の素材
29-31  = 強い。磨けば推しが生まれやすい
26-28  = 必要性あり。差別化 / 関係をもう一段
23-25  = 現状は他人物に埋もれるriskあり
<=22   = 統合 / 再設計を強く検討
```

# 7. Overlap audit — 削る前にここを分離する

## 7.1 セン / シロ / イオ

一見:

> 言葉 / 分類 / 記録

で近い。

固定する差:

```txt
セン  = 分かるように「教える」
シロ  = 分からなくても「残す」
イオ  = 分類する前に「聞く」
```

恐怖も違う:

- セン: 伝わらない / 教え切れない
- シロ: 分からないものを捨てる
- イオ: 名前を付けた瞬間に可能性を閉じる

## 7.2 ナギ / トバリ / クロオリ

```txt
ナギ      = danger / objectを封じる
トバリ    = passage / 帰還の門を開閉する
クロオリ  = memory / informationを本人が開けるまで預かる
```

同じ「閉じる」でも対象と倫理が違う。

## 7.3 ミチル / ゲン / アマネ

```txt
ミチル = 今この瞬間に一緒に帰れる道
ゲン   = かつて存在した道 / 時代の記憶
アマネ = 自分の身体 /車輪で最も良いrouteを再計算
```

## 7.4 トモリ / トウマ

**最優先で職能を分離する。**

```txt
トモリ = repair / broken object / scar / 継火
トウマ = authorship / craft / anonymous work / 誰の仕事だったか
```

トウマはgeneric repairmanにしない。
製本 / 金具 /木工等から、**制作痕跡で作者を読む職人**へ寄せる。

## 7.5 マドカ / レン / トキ

現状最も重複riskが高い。

固定候補:

```txt
マドカ = witness
         遠くで起きたことを見た。見た以上、声を出すか。

トキ   = measurement
         時間・角度・位置を測る。測れないものをどう信じるか。

レン   = discrepancy
         二つを比較して「違い」を検出する。確証前に共有できるか。
```

レンはReserveのまま磨く。
この差がGameplay / UIで成立しなければ将来的に統合検討可。

## 7.6 アサ / マキ

```txt
アサ = 先に動く / 名前を返す
マキ = 選択を決める / decision responsibility
```

マキは「素早い女性」ではなく、**決断を背負う大人**へ寄せる。

## 7.7 ハナ / セリカ / カナメ

三人とも「自分が負担する」に見えやすい。

```txt
ハナ    = care / 保存 /世話
セリカ  = duty / 礼儀 /責任
カナメ  = physical protection / damage
```

負担の種類を混ぜない。

# 8. Current lowest-score characters — 削除ではなく改修対象

## マドカ — 25

問題:

- 「観察者」がレン / トキと近い
- 鷲 / 窓のVisualは良いが、人生の一場面が弱い

強化方向:

> **見てしまった人。**

何か重大なことを見たのに、その時は確信がなく黙った経験を持つCandidate。

成長:

```txt
100%分かるまで言えない
→
間違っているかもしれないと添えて、それでも共有する
```

Gameplay:

- 遠距離warning
- offscreen telegraph
- boss action preview

へ集中。

## レン — 24

Reserveでよい。

強化方向:

> **違いを見る人。**

レンは「よく見える」ではなく:

- 昨日と今日の違い
- copy A / Bの違い
- 古い地図 / 新しい地図の違い
- 偽物 / 本物ではなく差そのもの

を検出する。

ノア / 双子の章で一気に価値が上がるため、**ヨルノシルベ1で無理に主要化しない。**

## レンジ — 24

削除ではない。

現状:

> クロエの感情を深くするための「年を取る弟子」

への依存が強い。

Playableへ昇格する条件:

1. クロエがいないSceneでも見たい
2. 自分のGameplayがある
3. 自分の失敗がある
4. 自分が愛した別の人 /家族 /仕事がある
5. 「有限だから進む」以外に本人の小さな欲がある

それまでは**Important Story Character**扱いが最も強い。

# 9. Roster budget — 人数を感じさせない演出

## 1 scene

同時に重要な名前付き人物は**3〜5人**程度を基本。
全員集合でも台詞担当を絞る。

## 1 chapter / Stage arc

Focus:

- 1〜2 main
- 1 opposing / mirror
- 2〜3 support

程度。

## Base / daily life

全員を毎回並べない。

- 食卓Group
- repair Group
- late-night Group
- map Group
- quiet Group

など自然にrotationする。

## Playable roster

Story prominenceと独立。

> Storyで脇役だけど、性能が好きで100run使ったら一番好きになった

を成立させる。

これはヨルノシルベのGameplay-first方針に合う。

# 桜井政博さん参考: 制作前チェックリスト

## 目的

Vamp Pon を、勢いだけで実装に入らず、ゲーム会社が作るくらいの制作前資料へ近づける。

桜井政博さんのゲーム制作の考え方を参考に、Vamp Pon 用のチェックリストへ落とし込む。

## 参考にする前提

桜井政博さんは、カービィや大乱闘スマッシュブラザーズなどを手がけたゲームデザイナー/ディレクター。

また、YouTubeチャンネル「桜井政博のゲーム作るには / Masahiro Sakurai on Creating Games」でゲーム制作に関する多数の解説を行っていた。

ここでは、個別動画の細かい引用ではなく、制作思想として参考になる観点に整理する。

## 参考にする考え方

Vamp Pon で特に参考にすべき観点は以下。

```txt
1. 誰でもすぐ分かる入口
2. 入力への気持ちいい反応
3. 情報を出しすぎない整理
4. 遊びながら自然に理解できる導線
5. 仕様を増やすより体験を磨く
6. 小さな差でも手触りに影響する
7. 画面上の情報優先度を明確にする
8. 初心者と上級者の両方に意味を作る
9. プレイヤーのミスを理不尽にしない
10. 作る側の都合をプレイヤーに押し付けない
```

# 1. 誰でもすぐ分かる入口

## チェック

```txt
初回3秒で、何を操作するか分かるか
初回10秒で、敵から逃げる/避けることが分かるか
初回30秒で、敵を倒すと欠片が落ちることが分かるか
初回60秒で、レベルアップの楽しさが出るか
```

## Vamp Ponへの適用

MVPでは、最初から以下を出しすぎない。

```txt
裏ストーリー
図鑑
永続強化
複雑な進化条件
```

最初に伝えるのはこれだけ。

```txt
動く
影を避ける
自動で攻撃する
欠片を拾る
強くなる
朝まで残る
```

## 危険

裏ストーリーを前面に出しすぎると、入口が重くなる。

---

# 2. 入力への気持ちいい反応

## チェック

```txt
スティック入力に遅れがないか
移動開始/停止が気持ち悪くないか
欠片を拾った時に音/反応があるか
レベルアップ時に気持ちいい停止があるか
必殺技ボタンを押した時に即反応するか
```

## Vamp Ponへの適用

必殺技は、押した瞬間に何かが起きるべき。

NG:

```txt
押したのに溜め演出が長い
どこに効いたか分からない
画面が長く止まる
```

OK:

```txt
押す
一瞬光る
欠片が吸われる
近くの影が欠片に戻る
音が鳴る
```

---

# 3. 情報を出しすぎない整理

## チェック

```txt
戦闘中に読む文字が多すぎないか
レベルアップカードが一目で理解できるか
UIが敵や欠片を隠していないか
スマホで読める文字サイズか
```

## Vamp Ponへの適用

レベルアップカードの優先順位:

```txt
1. 名前
2. 新規/強化
3. 効果
4. 裏ストーリー1行
```

裏ストーリーは一番下でよい。

読まなくても選べるようにする。

---

# 4. 遊びながら自然に理解できる導線

## チェック

```txt
チュートリアルなしで動けるか
最初の敵は弱いか
最初の欠片は拾いやすいか
最初のレベルアップが早いか
初カプセルが遅すぎないか
```

## Vamp Ponへの適用

最初の1分は、チュートリアルより体験で教える。

```txt
敵が近づく
自動攻撃で倒れる
欠片が落ちる
プレイヤーが拾う
ゲージが増える
レベルアップする
```

ここで余計な説明を入れない。

---

# 5. 仕様を増やすより体験を磨く

## チェック

```txt
新武器を増やす前に既存武器は気持ちいいか
新キャラを増やす前にユイは楽しいか
新ステージを増やす前に8分は楽しいか
裏ストーリーを増やす前にリザルトでもう一度遊びたくなるか
```

## Vamp Ponへの適用

MVP前に増やさないもの。

```txt
キャラ3人目
武器6個目以降
ステージ2つ目
詳細図鑑
黒インク床の複雑化
演出分岐
```

まず磨くもの。

```txt
ユイ
夜の鉛筆
欠片吸引
3択レベルアップ
記憶カプセル
未完成の一行
消えない名前
```

---

# 6. 小さな差でも手触りに影響する

## チェック

```txt
移動速度は遅すぎないか
敵速度は理不尽ではないか
欠片吸引範囲は狭すぎないか
レベルアップ間隔は長すぎないか
敵の接触ダメージは痛すぎないか
```

## Vamp Ponで必ず測る値

```txt
初回Lv2到達時間
初回被弾時間
初回カプセル到達時間
初回必殺技使用時間
最初の死亡時間
```

---

# 7. 画面上の情報優先度

## 優先度S

```txt
自キャラ
敵
欠片
HP
残り時間
```

## 優先度A

```txt
Lv
必殺技ゲージ
レベルアップカード
カプセル報酬
```

## 優先度B

```txt
武器/パッシブ一覧
実績通知
図鑑通知
裏ストーリー1行
```

## 優先度C

```txt
詳細説明
累計統計
長い図鑑文
```

## Vamp Ponへの適用

戦闘中に優先度Cを出さない。

---

# 8. 初心者と上級者の両方に意味を作る

## 初心者向け

```txt
ユイ
欠片吸引
月のしおり
回復候補
自動必殺技設定
```

## 上級者向け

```txt
進化条件
ビルド選択
敵密度を利用した欠片回収
必殺技の使いどころ
8分クリア後の実績
```

## チェック

初心者にだけ合わせて、選択の面白さが消えていないか。

逆に、上級者に寄せすぎて初回で理不尽になっていないか。

---

# 9. ミスを理不尽にしない

## チェック

```txt
見えない敵に当たっていないか
敵が急に湧いて即被弾しないか
HPが減った理由が分かるか
回復候補が全く出ず詰まないか
必殺技が押しづらくて死なないか
```

## Vamp Ponへの適用

敵スポーンは画面端または十分外側。

プレイヤーの真上には出さない。

紙くずの影は速いがHP低め。

黒いカプセルは硬いが遅め。

---

# 10. 作る側の都合を押し付けない

## チェック

```txt
仕様説明を読まないと遊べない作りになっていないか
裏ストーリーを読まないと報酬の意味が分からないか
操作方法が開発都合で複雑になっていないか
スマホなのにPC向けUIになっていないか
```

## Vamp Ponへの適用

裏ストーリーは任意。

ゲームとしては以下だけで成立させる。

```txt
避ける
倒す
拾う
選ぶ
強くなる
生き残る
```

# 桜井さん参考チェックリスト: MVP版

## 初回体験

```txt
[ ] 3秒で動かし方が分かる
[ ] 10秒で敵の圧が分かる
[ ] 30秒で欠片を拾う意味が分かる
[ ] 60秒以内にレベルアップする
```

## 操作感

```txt
[ ] 移動開始が遅くない
[ ] 指で画面が隠れても自キャラが見える
[ ] 必殺技ボタンが押しやすい
[ ] 自動必殺技設定がある
```

## 戦闘

```txt
[ ] 敵が溶ける気持ちよさがある
[ ] 被弾理由が分かる
[ ] 敵密度がスマホで見える
[ ] 5分以降にちゃんと圧が上がる
```

## 成長

```txt
[ ] 3択が一目で分かる
[ ] 強化後に変化を感じる
[ ] 進化が強く感じる
[ ] 進化できない回が多すぎない
```

## 報酬

```txt
[ ] 記憶カプセルが嬉しい
[ ] リザルトでもう一度遊ぶ理由がある
[ ] 実績/図鑑は邪魔にならない
```

## 裏ストーリー

```txt
[ ] 読まなくても遊べる
[ ] 読むと見え方が少し変わる
[ ] 説明しすぎていない
[ ] 戦闘テンポを止めていない
```

## スマホ

```txt
[ ] 縦持ちで成立している
[ ] 文字が小さすぎない
[ ] 敵/欠片/弾が見える
[ ] 30fpsを下回りにくい
[ ] 中断時にポーズする
```

# Vamp Pon用の制作前合格ライン

以下を満たすまで、本格実装を増やさない。

```txt
1. ワンシート企画書がある
2. コアループ図がある
3. 8分の体験タイムラインがある
4. スマホ入力仕様がある
5. プロトタイプ検証項目がある
6. MVP凍結リストがある
7. 桜井さん参考チェックリストで致命的な穴がない
```

## 結論

桜井さんの考え方を参考にするなら、今は実装を増やすより、以下を固めるべき。

```txt
誰でも分かる入口
触って気持ちいい反応
情報の整理
体験タイムライン
削る仕様
検証項目
```

Vamp Pon は仕様を増やすより、まず「ユイで8分遊んで気持ちいいか」を証明する。

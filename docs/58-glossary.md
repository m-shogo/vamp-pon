# Vamp Pon 用語集

## 目的

Vamp Pon の資料・実装・会話で使う用語を統一する。

用語が揺れると、仕様・UI文言・コードID・デザイン指示が崩れる。

この用語集を、制作中の共通辞書として使う。

---

# 基本用語

## Vamp Pon

本プロジェクトの仮タイトル。

正式タイトルは未定。

## ヴァンサバ系

Vampire Survivors ライクのゲーム構造。

Vamp Ponでは以下を指す。

```txt
移動中心
自動攻撃
大量の敵
経験値回収
レベルアップ選択
武器成長
進化
時間制生存
```

## MVP

Minimum Viable Product。

Vamp Ponでは、完成版ではなく以下を検証する最小版。

```txt
ユイで8分遊んで、もう一度遊びたいか？
```

## Prototype

MVPよりさらに小さい検証版。

Prototype 1〜5に分ける。

# プレイ関連

## ラン

1回のプレイ単位。

Vamp PonのMVPでは8分ランを標準とする。

## 朝まで残る

クリア表現。

通常の「勝利」「クリア」より、Vamp Ponの世界観に合わせた表現。

## 夜に飲まれる

失敗表現。

通常の「ゲームオーバー」より、少し柔らかい表現。

## 影を払う

敵を倒すこと。

ゲーム内文言では「倒す」よりも「払う」を優先してもよい。

ただし、UIで分かりにくい場合は「倒した影」など分かる表現を使う。

## 生存時間

ラン中に生き残った時間。

MVPでは最大8分。

# 世界観用語

## 影

敵の総称。

表では敵。

裏では、忘れられた記憶や消えかけた記録の形。

## 記憶の欠片

敵を倒すと落ちる経験値アイテム。

表では経験値。

裏では、忘れられたものが思い出した小さな断片。

## 記憶片

永続強化などに使う通貨の仮名。

「記憶の欠片」と似ているため、UIで混乱するなら後で改名する。

候補:

```txt
記憶片
小さな記憶
戻った欠片
```

## 黒インク

地図帳や記録を消していくもの。

MVPでは主に世界観/武器名として使う。

黒インク床ギミックはMVP後。

## 記憶カプセル

Vamp Pon版の宝箱。

強敵を倒すと落ちる。

武器強化や進化の報酬になる。

## 忘れ物

パッシブアイテムや収集物の呼び名。

例:

```txt
金のコンパス
古い切符
月明かりのしおり
```

## 地図帳

Vamp Ponの裏ストーリー中核モチーフ。

黒インクで旅の記録や行き先が消えていく。

# 武器用語

## 武器

自動攻撃する道具。

プレイヤーが攻撃ボタンを押す必要はない。

## パッシブ

キャラ性能や武器性能を底上げする忘れ物。

例:

```txt
金のコンパス: 吸引範囲
旅のバッジ: 攻撃力
古い切符: 移動速度
```

## 進化

条件を満たした武器が、記憶カプセルによって強化形態になること。

ゲーム内表現:

```txt
記憶がつながった
```

## 未完成の一行

夜の鉛筆の進化武器。

条件:

```txt
夜の鉛筆 + 月明かりのしおり
```

## 北極星のランタン

星くず弾の進化武器。

条件:

```txt
星くず弾 + 金のコンパス
```

# 必殺技用語

## 必殺技

キャラごとに1つ持つ大きめの効果。

MVPでは1ボタン、または将来自動発動設定。

## 消えない名前

ユイの必殺技。

効果:

```txt
周囲の欠片を吸い寄せ、小型影を記憶の欠片に戻す。
```

## 黒インク払い

ミチルの必殺技候補。

MVP後。

# 注意する用語揺れ

## 経験値 / 記憶の欠片

内部的にはXP。

ゲーム内表示は「記憶の欠片」寄り。

ただし、分かりにくければ「経験値」表現も検討する。

## ゴールド / 記憶片

Vamp Ponではゴールドを使わない予定。

永続強化通貨は「記憶片」仮。

## 敵を倒す / 影を払う

ゲーム分かりやすさ優先なら「倒す」。

世界観優先なら「払う」。

UIでは混在しすぎないよう注意。

# 最重要

```txt
用語は雰囲気より、制作中に迷わないことを優先する。
```

ユーザーに見える文言と、内部コードIDは分けて管理する。

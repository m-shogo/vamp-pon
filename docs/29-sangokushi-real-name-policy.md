# 三国志の実名利用方針

## 目的

三国志テーマで、劉備・曹操・関羽・張飛・諸葛亮などの実名を使ってよいかを整理する。

## 結論

実名が絶対にダメ、ではない。

歴史上・古典上の人物名は、著作権だけで見ると使える可能性が高い。

ただし、ゲームとして安全に公開・販売するなら、以下は分けて考える。

```txt
人物名そのもの
タイトル名
ロゴ
キャラクターデザイン
武器名
ストーリー表現
既存ゲームとの類似
商標
```

## 使える可能性が高いもの

### 歴史/古典人物名

以下のような名前は、古典・歴史人物として扱える可能性が高い。

```txt
劉備
曹操
孫権
関羽
張飛
諸葛亮
趙雲
呂布
周瑜
司馬懿
```

ただし、名前が使えることと、既存作品のキャラ表現を使えることは別。

### 古典的な役職・概念

```txt
軍師
武将
豪傑
将軍
兵法
火計
陣形
旗
軍配
```

これらは比較的扱いやすい。

## 危険なもの

### 既存ゲームのタイトルに近いもの

以下は避ける。

```txt
三國志
三国志
三國無双
真・三國無双
三国志大戦
Sangokushi
Dynasty Warriors
Romance of the Three Kingdoms
```

特にタイトルやロゴで近づけるのは危険。

Koei Tecmo の `Romance of the Three Kingdoms` シリーズは1985年から続く有名ゲームシリーズで、三國志・三国志ゲームの連想が非常に強い。

### 既存ゲームのキャラクターデザイン

名前が同じでも、以下は使えない。

```txt
三國無双風の関羽デザイン
三國無双風の呂布デザイン
コーエー三國志風の武将顔グラ
三国志大戦風カードデザイン
既存スマホ三国志ゲーム風の立ち絵
```

名前よりも、見た目・ロゴ・UI・構図の方が危険。

### 固有武器名や演出

史実/古典由来に見えても、既存作品で強く使われた表現は注意。

避ける方向:

```txt
既存ゲームの武器名そのまま
既存ゲームの必殺技名そのまま
既存ゲームの演出・ポーズ・掛け声
```

## 実名を使う場合の安全寄りルール

### 1. タイトルには使わない

タイトルで「三国志」を前面に出すと商標・既存シリーズ連想が強い。

避ける例:

```txt
三国志サバイバー
三國武将サバイバー
無双三国
```

安全寄り:

```txt
兵法盤の夜
戦略盤の影
武将カプセル
軍配と影の戦場
```

### 2. キャラ名は後回し

MVPでは実名武将を出さず、役割名でよい。

```txt
豪傑
軍師
弓将
槍将
守将
飛将風の男
赤壁風の策士
```

必要になったら、後で実名採用を検討する。

### 3. 見た目は既存ゲームから離す

実名を使うなら、見た目はかなり抽象化する。

```txt
武将本人ではなく、小さな駒
武将風カプセル
兵法札
影絵
木札
紙人形
```

### 4. 敵は実在人間にしない

人間兵を大量に倒すのは避ける。

敵は以下にする。

```txt
影の兵駒
墨の兵
黒い軍旗
暴走する陣形
紙の兵隊
煙の馬影
破れた巻物
```

## 実名利用の段階

### Phase 1: 役割名のみ

MVPではこれが安全。

```txt
豪傑の軍配
軍師のしおり
弓将の羽根
槍将の印
```

### Phase 2: ぼかした古典風名

```txt
桃園の印
赤壁の火計札
白羽の軍師扇
飛将の突撃槍
臥龍風の巻物
```

ただし、固有名に寄せすぎない。

### Phase 3: 実名採用を検討

本当に必要なら、実名武将名を使う。

例:

```txt
関羽の軍配
張飛の槍
曹操の兵法札
諸葛亮の扇
```

ただし、ここまで来たら商標/既存ゲーム/デザイン類似チェックを必ずする。

## 実名を使うメリット

```txt
既存知識が使える
プレイヤーがすぐ理解する
条件達成報酬が強く見える
武将解放が楽しい
三國無双3の最強武器感とつながる
```

## 実名を使うデメリット

```txt
既存三国志ゲームと比較される
デザイン要求が上がる
歴史表現の扱いが重くなる
キャラ数が増えやすい
商標・類似チェックが必要になる
```

## Vamp Ponでの推奨

最初から実名は使わない。

理由:

```txt
MVPが重くなる
既存作品との差別化が難しい
キャラ絵の要求が上がる
ゲーム本体の爽快感検証より前に題材負荷が増える
```

まずは以下で進める。

```txt
盤上三国志
武将風カプセル
兵法札
軍配
火計札
影の兵駒
戦功バッジ
秘宝武器
```

実名は、後で本当に必要になったら採用する。

## 現時点の判断

```txt
実名人物名: 使える可能性はある
タイトルに三国志: 避ける
三國無双風デザイン: 避ける
コーエー風顔グラ/UI: 避ける
三国志大戦風カード: 避ける
MVP: 実名なし推奨
```

## 最終結論

実名は絶対ダメではない。

ただし、Vamp Ponでは最初は使わない方が良い。

まずは、**三国志のゲーム的に強い構造**だけ使う。

```txt
武将
兵法
陣形
軍配
旗
火計
秘宝武器
条件達成
戦功報酬
```

実名は、作品の方向性が固まり、公開/販売の見通しが出てから慎重に検討する。

# Deep Story and Tone Boundary

## 目的

Vamp Ponの深層ストーリーを、安易な記憶喪失ではなく、プレイヤーが後から納得できる構造にする。

同時に、暗くなりすぎて開発する気力や遊ぶ気持ちを削らないための境界線を決める。

---

# 1. 採用するテーマ

Vamp Ponの深層テーマはこれ。

```txt
自分は見られていないと思っていた。
でも、本当は誰かが見ていた。
自分は愛されていないと思っていた。
でも、小さな記憶の中に、ちゃんと愛されていた証拠が残っていた。
```

ただし、直接そう説明しない。

プレイヤーは、欠片・図鑑・アイテム文・リザルトで少しずつ気づく。

---

# 2. 採用しない暗さ

以下は採用しない。

```txt
みんな自殺者だった
死を美化する
消えることを肯定する
最後まで救いがない
プレイヤーに罪悪感を背負わせる
```

理由:

```txt
Vamp Ponは毎日遊ぶゲームになる可能性がある
気持ちよさと相性が悪い
開発側も重くなりすぎる
ハッピーエンドの後味を濁す
```

---

# 3. 代わりに採用する構造

## 消えたのではなく、読めなくなった

黒インクは、存在を消すものではない。

```txt
見えなくする
読めなくする
自分でも意味が分からなくなる
```

つまり敵は「死者」ではなく、

```txt
自分の価値を読めなくなった記憶
```

である。

## 忘れているのは愛された記憶

嫌なことがあった。

そのせいで、本人はこう思った。

```txt
誰も見ていなかった
誰も覚えていなかった
自分はいなくてもよかった
```

でも、記憶の欠片を拾うと、逆の証拠が出てくる。

```txt
誰かが名前を呼んでいた
誰かが待っていた
誰かが小さな癖を覚えていた
誰かが渡せなかった手紙を持っていた
誰かが帰り道を一緒に歩こうとしていた
```

---

# 4. ポジティブな反転

物語の気持ちよさは、敵を倒すことではなく、認識が変わること。

最初:

```txt
自分は忘れられた
```

途中:

```txt
忘れられていたのではなく、自分が読めなくなっていた
```

最後:

```txt
本当は、たくさんの人が自分を見ていた
```

これがハッピーエンドの核。

---

# 5. 十三機兵的に目指すもの

目指すのは、重い設定の開示ではない。

目指すのは、後から意味が変わる体験。

```txt
欠片を拾う = 経験値集め
↓
実は、自分を見てくれていた証拠を集めていた

敵を倒す = 戦闘
↓
実は、読めなくなった記憶を欠片に戻していた

朝になる = クリア
↓
実は、その夜の思い込みが少し解けた

毎回1から = ローグライト都合
↓
実は、夜だけ一時的に結び直せる力だった
```

---

# 6. 見せ方の原則

ストーリーは基本的に見せない。

禁止:

```txt
長い会話
説明カットシーン
泣かせにくる長文
真相を序盤に言う
```

使うもの:

```txt
ステージ名
敵名
アイテム説明
カプセルの一文
リザルトの一文
図鑑断片
実績名
背景小物
```

---

# 7. 嫌なことの扱い

嫌なことはあった。

ただし、具体的に描きすぎない。

描き方:

```txt
置いていかれたと思った
名前を呼ばれなかったと思った
手紙を渡せなかった
約束を忘れられたと思った
帰り道で一人だったと思った
```

あとで反転する。

```txt
実は待っていた
実は呼んでいた
実は手紙は残っていた
実は約束を守ろうとしていた
実は一人ではなかった
```

---

# 8. ハッピーエンドの方向

Vamp Ponの最後はポジティブにする。

ただし、都合よく全部元通りではない。

```txt
過去は消えない
でも、過去の読み方が変わる
```

最終的にプレイヤーが感じること。

```txt
あの夜はつらかった
でも、自分は本当に一人ではなかった
朝が来てよかった
```

---

# 9. トーンの境界線

## OK

```txt
切ない
孤独
誤解
後悔
言えなかった言葉
渡せなかったもの
忘れたふり
自分の価値を見失う
```

## NG

```txt
死の直接描写
自傷の美化
救いのない結末
プレイヤーを責める演出
毎回気持ちが沈む報酬
```

---

# 10. 最重要

深いが、暗いだけにしない。

```txt
痛みを掘る。
でも、最後は朝に向かう。
```

Vamp Ponは、消えたい話ではなく、

```txt
消えたと思っていた自分が、ちゃんと誰かの中に残っていたと知る話。
```

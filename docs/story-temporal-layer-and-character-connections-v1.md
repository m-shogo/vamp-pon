# 1. 異なる時代の人物が同じDreamで会う

Status: `DECIDED`

```txt
Reality A era ── person A sleep / connection ┐
Reality B era ── person B sleep / connection ├→ Yoru-no-Shirube Dream
Reality C era ── person C sleep / connection ┘
```

Dreamでは会える。

帰還は**朝ではなくWaking**。

目覚めると、それぞれ自分の時代 / 自分の人生へ戻る。

したがって:

- Dreamで同年代に見えてもRealityで同世代とは限らない
- 見た目年齢と時代は一致しない
- 年長に見える人物が未来側でもよい
- 明確なsiblings / parent-child等だけ必要な同時代性を持つ
- 「いつの人なのか」をCharacter / Era Mysteryにできる

# 2. Dreamで時間タグが弱い

Status: `DECIDED`

Dreamでは:

- 西暦
- exact date
- calendar chronology
- 「今が何年か」

が曖昧になりやすい。

一方で:

- 言葉
- 身体技能
- 好き嫌い
- 道具の使い方
- 商品知識
- UI慣れ
- 制度感覚

は残る。

この非対称性により年代差を説明台詞ではなく生活差として出す。

---

# 3. Dream内の体感時間

Status: `HIGH_VALUE_CANDIDATE`

Realityで一晩 / 短時間でも、Dreamでは長く過ごした感覚を持てる方向はGameplay / Relationと相性が良い。

候補:

- Reality経過時間とDream体感が一致しない
- 同じCharacterが複数回Dreamへ来る
- 接続痕だけ古く残る
- 初対面なのに星獣 / 動物だけ反応する

ただしexact変換率は作らない。

`1時間現実 = 1年Dream`のような固定計算へしない。

# 6. 月相は時計ではない

Status: `DECIDED`

月相はReality経過日数ではなく**大事件の核心へのdepth**。

そのため:

- Character Aが三日いたから三日分欠ける
- 一晩ごとに一定角度欠ける

のような時計運用をしない。

異常な戻り / 停止 / 未来だけ別挙動もMysteryに使える。

朔では月が消えるが星は残る。

# 13. 魔女にとってDreamが危険な理由

DreamではRealityと同じ老化速度に縛られないCandidate。

そのため魔女には:

> 大切な人と同じ時間を長く保てる場所

に見える。

旧資料の「いつか朝へ帰る」は廃止。

現在は:

- いつかWakingする
- Dream connectionが終わる
- 各自Realityへ戻る
- 弟子のReality人生は進む

ため、別れは避けられない。

それでも:

> 目覚めなければ、もう少し一緒にいられる。

という誘惑が成立する。

# 19. Time-layer quality guard

Bad:
> 私は1987年の人間だ。

Better:
> 「テレホンカード、ないの？」
> 「……何それ？」

Bad:
> 未来ではAndroidと人間が戦争中です。

Better:
> Androidが当たり前に使う制度語を人間Characterが知らない。

Bad:
> この人物は時代ラスボスです。

Better:
> 新聞 / 議事録 / 企業資料 / witnessから、誰が事件の中心だったのかPlayerが後から組み立てる。

年代は説明ではなく**生活Evidence**として出す。

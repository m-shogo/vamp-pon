# 1. USER DIRECTION — 夜にいる人は同じ時代の人ではない

ヨルノシルベで出会う人物は、現実世界では必ずしも同時代に生きていない。

```txt
現実のA時代 ── 人物Aの「夜への接続点」 ┐
現実のB時代 ── 人物Bの「夜への接続点」 ├→ ヨルノシルベの夜
現実のC時代 ── 人物Cの「夜への接続点」 ┘
```

夜では出会える。

しかし朝へ帰れば、それぞれは**自分の時代 / 自分の人生**へ戻る。

したがって:

- 夜で同年代に見えても、現実で同世代とは限らない
- 夜で年下に見える人物が、別人物より古い時代の人でもよい
- 年長者が未来側の人物でもよい
- 兄弟 / 親族など明確な関係だけは同時代性を必要に応じて持つ
- 「いつの人なのか」自体をCharacter Mysteryにできる

---

# 2. HIGH-VALUE CANDIDATE — 夜は時間順に並んでいない

夜は現実時間をそのまま再現する空間ではなく、**記憶・関係・未確定の意味を接続する層**。

そのため、夜内部の「長くいた」は現実世界の経過年数と一致しなくてよい。

例:

- 現実で一晩しか眠っていない人物が、夜では長い時間を過ごした感覚を持つ
- 何十年前の人物の接続痕が、別時代の人物と同じ夜へ残る
- ある人物は何度も夜へ来たため、夜の住人のように見える
- ある人物は初めて来たのに、星獣だけは別人物を知っている

この仕組みにより、周回Gameplayと年代差を同じ世界原理で扱える。

---

# 3. 年代差を伏線に使う方法

年代差を説明台詞で最初から開示しない。

小物で見せる。

候補:

- ゲンだけが古い道や昔の駅名を当然のように知る
- トキが星の位置や暦の前提のズレへ気づく
- トバリの切符規格が別時代のもの
- ユウビの封筒に今は使われない書式がある
- センが使う教育用語が古い / 新しい
- シロの本に別時代の版が混じる
- レンだけが小物の年代差へ先に気づく
- 星獣が、人間より先に古い関係へ反応する

初見ではcharacter flavor。
後から「この人たち、そもそも同じ時代じゃなかった」と再解釈できる。

# 5. 黒耀化 — 「もう一人の自分」

## USER DIRECTION

黒耀化は単なるbuffでも悪人格化でもない。

参考にしたい感触:

- 本来持つ力や願いが、未熟さ・恐怖・焦りによって異常な形へ出た進化
- 本人の中に確かに存在する自分
- 後で消去する別人格ではなく、受け入れて扱い方を学ぶ力

```txt
本人の長所 / 願い
↓
恐怖や焦りで一点へ偏る
↓
黒耀化
↓
圧倒的に強い
↓
その人らしさが極端すぎて周囲が見えなくなる
↓
成長後は同じ力を、自分で選んで扱える
```

したがって黒耀化は「もう一人の自分」ではあるが、別人ではない。

本人が後で:

> あれも自分だった。

と受け止められることが重要。

スカルグレイモン的な「間違った到達」と、九尾化的な「自分の内側にある巨大な力と感情」の両方に近い感触を狙うが、設定・展開は独自にする。

# 6. HIGH-VALUE FUTURE CHARACTER — 年を取らない魔女と、年を取る弟子

## USER IDEA / HIGH-VALUE CANDIDATE

魔女候補は現実世界で老いない、または極端に老化が遅い。

彼女は長い現実人生の中で何人もの弟子を持ってきた。

弟子たちは:

- 成長する
- 恋をする
- 結婚する
- 子どもを持つ
- 老いる
- 師匠より先に亡くなる

魔女はその全てを何度も見届けてきた。

弟子との関係は恋愛ではない。

師弟 / 家族に近い長期関係。

### 彼女が本当に嫌なもの

死そのものだけではない。

> 自分だけが変わらないまま、好きになった人の人生が先へ進み、最後には自分だけが残されること。

弟子の幸せを喜べる。
結婚も子どもも祝福する。

しかし同時に:

> また私だけ残る。

という恐怖が積み重なる。

---

# 7. 魔女にとってヨルノシルベが危険な理由

夜では現実と同じ速度で老いない。

そのため魔女から見ると、初めて:

> **大切な人と同じ時間を長く保てる場所**

に見える。

弟子は夜にいる間、年を取らない。

ただし永遠に同じ場所へ固定されるわけではない。

- いつか朝へ帰る
- 夜との接続が終わる
- 別の時代 / 現実人生へ戻る
- 魔女から見れば「いなくなる」こと自体は避けられない

それでも魔女には:

> 現実よりは長く一緒にいられる。

と思えてしまう。

この感情が彼女を夜へ強く執着させる。

---

# 8. 魔女の黒耀化候補

通常の願い:

> 大切な人と、もう少し長く一緒にいたい。

黒耀化で過剰化:

> ここから誰も出さなければ、誰も老いない。
> 誰も死なない。
> また私だけ残されることもない。

これは悪意ではない。

**愛情と喪失恐怖の暴走。**

Gameplayでは:

- 周囲の時間を止める / 遅らせる
- Allyのdamage / cooldown / 状態変化を一時固定
- 敵も含めて場を「保存」する
- 強いが、戦闘そのものが進まなくなる危険

など「保存するほど強いが、進行まで止めてしまう」特性へ接続できる。

成長後:

> 一緒にいるために時間を止めるのではなく、別れる日が来ても、その人が生きた時間を受け取る。

長寿そのものを治療 / 剥奪して解決しない。

彼女は不老のままでも前へ進める。

---

# 9. 弟子側から見た物語

弟子は「かわいそうな老いる人」にしない。

弟子からすると:

- 師匠と出会えた
- 自分は普通に年を取る
- 師匠より外見が年上になる
- それでも二人きりでは「師匠」と呼ぶ
- 自分の人生を止めたいとは思っていない

重要な台詞候補の方向:

> 師匠と長くいたい。
> でも、長くいるために生きるのをやめたくはない。

魔女が「留まる愛」を持ち、弟子が「進む愛情 / 尊敬」を持つ。

恋愛ではないからこそ、家族・師弟として強い。

---

# 10. 日常で先に好きにする

この関係は説明から入らない。

最初に見せたい:

- 弟子の方が外見は完全におじいさんなのに「師匠」と呼ぶ
- 魔女が昔と同じ癖で弟子の服装を直す
- 弟子が「もう子どもじゃありませんよ」と笑う
- 魔女だけ昔の呼び名で呼び続ける
- 弟子の孫 / 曾孫の話を魔女が普通に知っている
- 星獣だけは弟子が若かった頃と同じ距離感で接する

後から過去を知って、何気ない会話の意味が変わる。

# 11. ヨルノシルベ全体への接続

この魔女編は作品テーマを別角度から証明できる。

ユイの問い:

> 忘れたら、大切だったことも消えるのか。

魔女の問い:

> 終わったら、一緒にいた時間も失われるのか。

共通の答え候補:

> **保存し続けることだけが、大切にすることではない。**

ただし二人の物語を同じ結論・同じ演出にしない。

ユイは「忘却」。
魔女は「時間と別れ」。

同じCore Themeを別の人生から見る。

# キャラとアイテムの不足情報バックログ

Stage1画面完成度、Unity移行、将来の商用MVPへ向けて、キャラ・武器・パッシブ・レア・敵・ステージの不足情報を整理する。
この文書は実装データを変更しない。runtime IDや素材ファイルとバッティングしないための設計backlogとして扱う。

## 目的

- 画像生成やAsset Factoryに渡す前の文字情報を固める。
- キャラやアイテムの役割被りを減らす。
- Unity移行時にScriptableObject化しやすい情報へ整理する。
- グッズ化やストア用スクショでも説明しやすいモチーフを残す。
- Stage1だけでなく、Core5までの広がりを保つ。

## 基本ルール

### キャラ追加時に必ず決める項目

1. 持ち物
2. 髪型
3. 頭装備
4. 光の種類
5. 戦う理由
6. 固定武器の遊び味
7. 得意不得意
8. ステージとの関係
9. 相棒/友情の相性
10. 黒曜化時の危うさ

### アイテム追加時に必ず決める項目

1. runtime ID
2. 表示名
3. 種別: weapon / passive / rare / pickup / currency
4. 画面上の読みやすいシルエット
5. 32pxで読ませる要素
6. ゲーム効果
7. lore
8. 進化/合体/覚醒への関係
9. 他アイテムとの被り
10. Unity移行時のID整理候補

## Core5キャラ補完

### Yui / ユイ

役割:

- 最初の主人公。
- 小さなランタンで夜の記憶を集める。
- Stage1の顔。

固定事項:

- ランタンは本人の右手。
- バッグ紐は右肩から左腰。
- バッグ本体は左腰。
- 左向きでも奥側のランタンを完全に消さない。

持ち物:

- 古いランタン。
- 小さな旅鞄。
- 折れかけた鉛筆。

光の種類:

- 暖色のランタン光。
- 弱いが消えにくい。

戦う理由:

- 忘れられた夜道に残った記憶を拾うため。
- 誰かが朝へ戻れる道を探している。

固定武器:

- `night_pencil`
- 紙や記録を切り開く線の攻撃。
- 弱いが成長すると記憶をなぞるように広がる。

得意:

- バランス型。
- XP回収、安定、初心者向け。

不得意:

- 瞬間火力は低め。
- 黒曜化に頼りすぎると反動が大きい。

黒曜化:

- ランタンの芯だけ暖かく残る。
- 黒インクが手元から肩へ広がる。
- 完全な悪堕ちではなく、危うい集中状態。

不足している情報:

- 通常カットインの最終採用画。
- 黒曜化カットインの統一版。
- Unity用の最初のSO_CharacterDefinition候補。

### Asa / アサ

役割:

- 二人目候補。
- 朝、火花、マッチケースのイメージ。
- ユイの光より瞬間的で、消えやすいが強い。

持ち物:

- マッチケース。
- 焦げたポストカード。
- 小さな火打ち石。

髪型/見た目:

- 短め、少し跳ねる髪。
- 朝焼けに近い暖色の差し色。
- ユイより動きが速く見えるシルエット。

頭装備:

- 小さな布バンド、または焦げ跡のある髪留め。

光の種類:

- 火花。
- 一瞬強く光る。
- 連続ではなくリズムがある。

戦う理由:

- まだ届いていない手紙を朝へ届けるため。
- ユイが拾う記憶と、アサが届ける言葉が対になる。

固定武器候補:

- `postcard_blade`
- `match_spark`

遊び味:

- 近〜中距離でテンポ良く攻撃。
- 火花が跳ねるような連鎖。

得意:

- 序盤火力。
- 小型の群れ処理。

不得意:

- 長期戦の安定。
- XP回収範囲や防御は弱い。

相性:

- ユイとは恋愛未満の相棒感。
- ユイが照らし、アサが火を移す。

不足している情報:

- runtime初期武器とのビジュアル整合。
- キャラ選択画面での肩書き。
- Stage2担当にするか、Stage1後半の相棒にするか。

### Nagi / ナギ

役割:

- 水、静けさ、呼吸のキャラ。
- ノイズを流す、敵の動きを鈍らせる。

持ち物:

- 水の入った小瓶。
- 透明なしおり。
- 雨粒の鈴。

髪型/見た目:

- 長めで流れる髪。
- 青灰、薄水色、濡れた紙の色。
- 動きは静かで滑るよう。

頭装備:

- 雨避けの小さなフード。
- 水滴の髪飾り。

光の種類:

- 水面反射の光。
- 直接照らすより、揺れて映す。

戦う理由:

- 黒インクで濁った記憶を洗い流すため。
- 忘れたくない言葉が水に沈んでいる。

固定武器候補:

- `rain_bookmark`
- `ripple_bottle`

遊び味:

- 範囲制御。
- スローや押し戻し。
- 派手ではないが安全。

得意:

- 生存。
- 敵の密度管理。

不得意:

- ボス単体火力。
- 速攻クリア。

相性:

- アサとは相性が良いが、性格的には逆。
- ユイとは静かな理解者。

不足している情報:

- 属性を水に固定するか、無機光寄りにするか。
- ステージ背景との関係。
- 初期武器名の確定。

### Michiru / ミチル

役割:

- 雷、標識、合図のキャラ。
- 単発の強い判断、ルート変更、連鎖反応。

持ち物:

- 小さな信号灯。
- 折れた標識。
- 電池切れのトーチ。

髪型/見た目:

- 角のあるシルエット。
- 黄色、青黒、注意色。
- 少し機械的、でも冷たすぎない。

頭装備:

- 標識型のピン。
- 反射板のようなヘアクリップ。

光の種類:

- 点滅光。
- 雷ではなく、信号や警告灯に近い。

戦う理由:

- 誰も読まなくなった道しるべをもう一度灯すため。
- 間違った道に進む記憶を止める。

固定武器候補:

- `signal_spark`
- `broken_signpost`

遊び味:

- 連鎖攻撃。
- 近い敵から次の敵へ跳ねる。
- タイミングが合うと強い。

得意:

- 中盤以降の群れ処理。
- 連鎖火力。

不得意:

- 序盤安定。
- 敵が少ない場面。

相性:

- トモリと組むと、警告灯と記録灯で情報戦になる。

不足している情報:

- 雷属性にしすぎるか、信号/標識モチーフへ寄せるか。
- グッズ化しやすい共通デバイスとの関係。
- 初期武器の画面シルエット。

### Tomori / トモリ

役割:

- 光、記録、観測のキャラ。
- 図鑑や記憶の欠片と相性が良い。

持ち物:

- 古いカメラ。
- 露光したフィルム。
- 小さな投影機。

髪型/見た目:

- 落ち着いたシルエット。
- 白、薄金、セピア。
- 目元に観測者感。

頭装備:

- レンズ型の髪飾り。
- 古い記録ラベル。

光の種類:

- 写真のフラッシュ。
- 一瞬だけ記憶を焼き付ける光。

戦う理由:

- 消える前の記憶を記録するため。
- 忘れられた誰かの存在を証明するため。

固定武器候補:

- `memory_flash`
- `old_camera_lens`

遊び味:

- マーキング。
- 一定時間後に追加効果。
- 図鑑/収集報酬と相性。

得意:

- レア発見。
- 記録/図鑑系の成長。
- 遅効性火力。

不得意:

- 即時対応。
- 素早い敵。

相性:

- ユイが拾い、トモリが記録する。
- 最終盤の真相に近いキャラにできる。

不足している情報:

- 戦闘中の遊び味を強くする必要あり。
- 単なるカメラキャラにしない追加モチーフ。
- 図鑑システムとの連動仕様。

## 進化/合体/覚醒の不足

### 進化

通常成長の延長。

例:

- `night_pencil` → `addressless_blade`
- `paper_plane` → `tailwind_plane`

不足:

- 進化後の名前がまだ弱いものがある。
- 進化後の攻撃演出が通常版と差別化されていないものがある。
- 進化条件の見せ方がカードUIに依存しすぎている。

### 合体

2つのアイテムが噛み合う特別報酬。

例:

- `black_ink_bottle` + `streetlamp_ring`
- 黒インクを街灯の輪で制御する。

不足:

- 合体後の正式名。
- 合体後の見た目。
- 画面で「2つが混ざった」と分かる演出。

### 覚醒

キャラや記憶に深く紐づく特別強化。

例:

- `night_pencil` + `name_tag`
- 名前を取り戻した鉛筆。

不足:

- 覚醒後の正式名。
- 覚醒素材のレア感。
- `dawn_ticket` と役割が被らない説明。

## すぐ埋めるべき優先順位

1. `name_tag` の覚醒素材としての設定。
2. `dawn_ticket` の復帰/救済レアとしての設定。
3. `night_pencil` 覚醒後の正式名と演出。
4. `black_ink_bottle` + `streetlamp_ring` 合体後の正式名。
5. Stage1ボスの名前と図鑑説明。
6. ユイ通常カットインの最終仕様。
7. Asaの初期武器と見た目の整合。
8. Unity移行時の `old_ticket` → `warm_shoes` mapping。

## 次にCodexへ渡す時の注意

- この文書は設計backlogであり、runtime dataの即変更指示ではない。
- 採用する時は、必ず実画面、32px、390x844で確認する。
- `name_tag` と `dawn_ticket` は役割を混ぜない。
- キャラを増やす前に、ユイのStage1体験を完成させる。
- 敵を大量に増やす前に、役割差が画面で読めるものから入れる。

# Character Address / Naming / Register Reservoir v1

Status: **AUTHOR RESERVOIR / NON-CANON / EXACT WORDING OPEN / NO NAME-FORM AFFECTION SCORE**

全36人について、既存のdirected speechを置き換えず、**自称 / 初対面での呼び方 / 通常の同輩呼称 / 年齢・立場差でのregister変化 / 親密化での呼称変化 / 呼び間違いの修復**を作者用素材として持つ。

## Coverage

36 characters × 6 axes = **216 address/naming/register anchors**

Axes:

- `SELF_REFERENCE`
- `FIRST_MEETING_ADDRESS`
- `DEFAULT_PEER_ADDRESS`
- `AGE_STATUS_SHIFT`
- `CLOSENESS_NAME_SHIFT`
- `MISADDRESS_REPAIR`

## Relationship to existing directed speech

既存のdirected speechは「この相手に、どういう温度・言い回しで話すか」の相手別素材。

このReservoirはその前段にある、**名前・敬称・自称・距離の取り方をどう扱うか**だけを保持する。

そのため、ここでは具体的な台詞や一人称、語尾、方言、固定敬称をCanon化しない。

## Hard boundaries

This reservoir does **not** freeze:

- exact first-person pronoun
- exact honorific/suffix
- exact recurring nickname
- exact dialect/accent
- exact legal/birth/private name
- voice casting
- romance/affection value
- family hierarchy
- workplace rank
- runtime dialogue choice

It also blocks shortcuts such as:

- nickname = affection/romance score
- dropping an honorific = intimacy proof
- age/status = submission or superiority
- gender/sexuality/presentation = speech register
- origin/skin tone = dialect
- body size = dominance register
- disability = childlike/formal register
- machine/fleet/account ID = spoken person name
- stable profile alias = spoken name
- misaddress correction = obligation to disclose identity history

## Stable-ID boundary

Author DB aliases such as `kage1`, `kage2`, `kage3`, `kage4`, and `yubi` are data/navigation identifiers. They do **not** become in-world spoken names simply because the database uses them.

Examples:

- `kaname` ↔ `kage1` remains an authoring alias; spoken address remains a separate authoring decision.
- `yuubi` ↔ `yubi` remains a stable-profile mapping; it does not prescribe pronunciation, nickname, or displayed writing in dialogue.

## Representation guards

- Gen / Hana: age does not force old-person speech, memory jokes, familial titles, or entitlement to informality.
- Kaname: size does not create dominance/bodyguard register or body-based nickname permission.
- Hiyori / Touma: skin tone or style does not imply dialect, origin, roughness, or casualness.
- Suzu: self-reference, suffixes, voice, name form, and register are not gender-diagnostic evidence.
- Io: no one is entitled to demand a gendered title, pronoun-like form, or identity disclosure as the price of correcting address.
- Amane: wheelchair/disability does not justify caregiver-as-proxy address, infantilization, or disability-first nickname.
- Noa: product/account/debug identifiers are not automatically person-facing names.
- Rum: a fleet or instance identifier does not automatically become the socially correct spoken name, and an instance nickname does not propagate to all instances.
- Kuu / Yomo: Human pronoun and honorific hierarchy are not projected onto animal cognition; Human callers may still use consistent story-facing call names.
- Kai / Nao: twins have separate self-reference, nicknames, consent, address habits, and correction rights.

## Era boundary

Era influences available vocabulary and social conventions, but does not mechanically generate personality.

Historical characters are not forced into exaggerated archaic speech. Present characters are not forced into casual contemporary slang. Future characters are not forced into universal machine-neutral language.

Any exact period wording must be researched and promoted separately if it becomes Canon dialogue.

## Canon boundary

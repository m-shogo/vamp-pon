# 151. Open Space and Mystery Rules

This document protects useful blank space in the story.

## Core rule

The story should feel connected, but not fully explained.

Every major character needs:

- one clear relation
- one indirect relation
- one unresolved blank

## Good blank space

Good blanks create curiosity and guide future scenes.

Examples:

- why Yui forgot a meeting
- who owned the vessel first
- whether a lineage is family, adoption, or spirit kin
- why two items share a shape
- whether a memory item is true or distorted
- why one character avoids another

## Bad blank space

Bad blanks are only missing information.

Avoid:

- no clear purpose
- no relation to gameplay or design
- mystery that never changes any choice
- character secret that does not affect behavior
- item with no emotional function

## Reveal rhythm

Each stage should give:

- one answer
- one new question
- one emotional shift
- one object clue

Do not reveal full family truth in the first appearance.

## Character blank rule

For each character, keep at least one of these unclear at first:

- exact memory lost
- exact relation to Yui
- true owner of the vessel
- why the vessel glows
- whether the character remembers correctly

## Design consequence

A mystery must have a visible trace.

Good traces:

- repeated motif
- similar light rhythm
- matching cloth mark
- item shape echo
- shared color accent

If the mystery has no visible trace, it will feel arbitrary.

# 159. Black Ink Reading Release Rules

This document canonizes why Yui and later characters fight black ink shadows.

## Core rule

Black ink shadows are not simply evil monsters.
They are memories, objects, names, or promises fixed under the wrong meaning.

The fight is not about destroying a soul.
It is about loosening a wrong reading so the memory can be read again.

## Black ink definition

Black ink means:

- a wrong meaning became fixed
- an owner was misread
- a name was covered
- a promise was treated as a mistake
- a vessel light was targeted
- a memory item was separated from its context

## Why shadows attack light vessels

Light vessels keep the true relation between memory, owner, and meaning.

Black ink tries to cover them because a vessel can prove that the current reading is wrong.

## Yui's lantern role

Yui's lantern is not only a flame source.
It is a reading light.

It can:

- reveal who an item belonged to
- loosen black ink from a memory item
- show the shape of a vessel
- turn a shadow back into a fragment
- guide fragments toward the right owner

## Enemy clear loop

Gameplay meaning:

1. black ink shadow appears
2. it acts like a wrong reading
3. light hits it
4. the fixed meaning loosens
5. a memory fragment appears
6. Yui collects it
7. the stage gains one clearer clue

## Enemy families by wrong reading

| Enemy type | Wrong reading | Released clue |
| --- | --- | --- |
| ink blob | owner unknown | small fragment |
| nameless shadow | name covered | name mark |
| vessel eater | light vessel targeted | cracked vessel clue |
| mimic shadow | copied shape | false relation clue |
| black page | whole scene covered | page clue |
| folded shadow | memory folded shut | folded-object clue |
| blank shadow | meaning not decided | blank-space clue |

## Story rule

Every major enemy type should imply a kind of misunderstanding.

Do not make black ink only a hostile creature.
Make it a sign that something was read the wrong way.

## Happy-end rule

A happy ending does not require erasing every shadow.
It requires enough readings to become gentle again.

The ending should feel like:

- not every truth was explained
- not every pain vanished
- enough meaning returned that morning can arrive
- the characters can keep living with the blank spaces

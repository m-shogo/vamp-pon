# 169. Integrated Visual Story Brief

This is the short integrated brief for returning to design work.

## Core concept

Yui uses a fixed lantern to read a night of forgotten objects and carry useful meaning toward morning.

## Visual pillars

- night blue
- old paper
- warm lantern
- black ink shapes
- memory glow
- paper cards
- vertical mobile readability

## Game action to story meaning

| Game action | Meaning |
| --- | --- |
| move | read from another angle |
| hit shadow | loosen wrong reading |
| collect fragment | carry loose meaning |
| level up | find stronger reading path |
| fail | page did not reach morning |
| permanent growth | mapbook kept a trace |
| clear | page reached morning |

## Character rule

Each playable character needs:

- unique glowing object
- light lineage
- first action
- Yui relation
- non-Yui relation
- memory item set
- one blank

## Enemy rule

Each enemy family needs:

- wrong reading type
- silhouette
- role
- released clue
- black ink trace

## Item rule

Each important item needs:

- possible owner
- vessel link
- wrong reading
- game effect
- reversal
- final or open meaning

## UI rule

UI is the mapbook layer.
Use paper cards, stamps, bookmarks, page creases, margin notes, and small gold lines.

## Failure rule

A failed run should show what was read, what remained, what became stronger, and what to try next.

## Ending rule

Morning can arrive without solving every blank.
Yui connects answers but does not own every answer.

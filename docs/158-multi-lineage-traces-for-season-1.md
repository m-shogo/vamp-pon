# 158. Multi-Lineage Traces for Season 1

Season 1 should not explain multi-lineage characters directly.
It may place traces so later reveals feel planned.

## Trace rule

A trace is not a full reveal.

Good traces:

- mismatched glow on an old object
- two burn marks with different meanings
- repaired vessel part from another family
- item that belongs to two categories
- background sign with two symbols
- enemy with one strange attack outside its family

## UI and item traces

- Do not add a full system yet.
- Use small icon marks, item names, or background objects.
- Avoid making players think a second element is already a gameplay mechanic.

## P1 boundary

Allowed:

- tiny visual clue
- item name clue
- background prop clue
- optional glossary wording

Forbidden:

- dual-lineage playable character
- triple-lineage boss
- explicit family chart
- relationship system
- multi-character skill system

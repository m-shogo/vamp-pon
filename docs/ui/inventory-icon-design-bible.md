# Inventory Icon Design Bible

## 0. 目的

下部HUD、レベルアップ候補、入れ替え画面で共通利用するインベントリアイコンのデザイン基準を固定する。

対象は次の27種。

- 通常武器 8
- 進化・合体・覚醒武器 7
- 忘れ物 8
- レアアイテム 4

必要数・assetId・配置先の正本は `data/ui-assets/inventory-icon-requirements.json`。
この文書は「どう描くか」「何を失敗とするか」「どう手直しするか」の正本。

---

## 1. 最終成果物

各アイコンを個別PNGとして納品する。

```txt
32×32px
PNG RGBA
完全透過背景
1ドット=1pxのネイティブ制作
実絵は中央28×28px以内
四辺2px以上の完全透明安全域
アンチエイリアス禁止
画像内の枠・レベル数字・文字・ロゴは禁止
```

ゲーム側がスロット枠とレベルバッジを描くため、画像内に外枠や数字を焼き込まない。

### 表示確認サイズ

必ず次の3サイズで確認する。

```txt
32px: 制作原寸
24px: 通常HUD想定
16px: 最小視認性確認
```

16pxでモチーフが分からない場合は、細部追加ではなく輪郭を単純化する。

## 2. Vamp Pon共通ビジュアル文法

### 世界観

```txt
夜の街
紙片
地図帳
忘れ物
黒インク
小さな灯り
朝へ向かう暖色
```

### 基本パレット

| 役割 | 推奨色 |
|---|---|
| 夜の暗縁 | `#1d1a34` / `#3a3358` |
| 古紙 | `#f3e9cf` / `#b8a06a` |
| 暖色灯り | `#ffce7a` / `#fff0b0` |
| 欠片の金 | `#ffd45e` |
| ガラス | `#cfe6f0` / くすんだ青灰 |
| 朝色 | `#f6d9a8` / `#f3c9a0` |
| 黒インク | `#171328`、ただし暗縁と同化させない |
| 忘れ物の菫 | 低彩度の藤・灰紫 |

1アイコンは原則4〜8色。進化・覚醒でも10色以内。

### 光源

- 左上から弱い光
- 右下へ暗い影
- 暖色glowは中心から最大2pxまで
- glowだけで輪郭を作らない
- ガラス以外の半透明ピクセルは極力使わない

### 輪郭

- 基本1pxの暗い輪郭
- 紙・暖色物は茶紫の輪郭
- 黒インク物は背景より少し明るい紫縁
- 完全な真黒1色の外周は禁止
- 1pxノイズを輪郭へ散らしすぎない

### カメラと向き

カテゴリごとに統一する。

```txt
武器      : 左下→右上へ20〜35度傾け、動きを感じる
忘れ物    : 正面または軽い斜め。安定した静物
レア      : 正面中心。特別な意味が伝わる
進化武器  : 元武器の向きと輪郭を残す
```

全アイコンを同じ斜め角度にしない。カテゴリ内のルールは揃えつつ、輪郭の識別性を優先する。

## 3. カテゴリ別のデザイン方針

## 3.1 武器

### 役割

一瞬で「攻撃に使う道具」と分かること。
弾や範囲エフェクトそのものではなく、インベントリ内の道具として描く。

### 共通ルール

- 主モチーフを画面の65〜80%にする
- 斜め方向または先端で攻撃方向を感じさせる
- 暖色・古紙・ガラスのいずれかを主役にする
- 同じ丸、同じ星、同じ紙片へ寄せない

### 禁止

- 黒インクの小瓶を単なるインク染みにする
- 街灯の輪を光る円だけにする
- 星くず弾を普通の五芒星だけにする
- 紙刃を金属ナイフにする
- 進化武器を元武器と無関係な神器にする

## 3.2 忘れ物

### 役割

戦闘道具ではなく、誰かが失くした生活物として見えること。
静かで少し切ないが、暗く沈ませすぎない。

### 共通ルール

- 正面または軽い斜めの静物
- glowは原則なし
- 擦れ、折れ、ひび、乾きなどを1要素だけ入れる
- 強化内容は色ではなく物の性格で示す

### 禁止

- すべて金色にして強化アイテム化する
- RPGのステータスアイコンへ寄せる
- 剣、盾、炎、矢印など能力記号を足す
- 読める文字を描く

## 3.3 レアアイテム

### 役割

「希少だから派手」ではなく、物語上の意味が強い物として見せる。

### 共通ルール

- 中央配置
- 主モチーフ1つ＋意味を補う副要素1つまで
- 金色は補助。全体を金にしない
- 通常の忘れ物より輪郭が明確で、少しだけ光または色差を強める

### 禁止

- 宝石、王冠、虹、レインボー発光
- 全部同じ金枠
- 読める名前や宛先
- 魔法陣、ルーン、紋章だけの表現

## 3.4 進化・合体・覚醒

### 強化進化

元武器の輪郭を70%以上残す。線が長くなる、灯りが整うなど正統強化。

### 合体

2つの元モチーフが同時に読めること。片方を色だけで済ませない。

### 覚醒

元武器＋対応レアの意味を同時に残す。
神秘感は紙・インク・ガラス・風の範囲内に留める。

## 4. 最も起こりやすいミスと手直し指示

| ミス | 判定 | 手直し |
|---|---|---|
| 32×32ではなく拡大画像を縮小した | ドットが混ざる、輪郭が濁る | 32×32ネイティブで描き直す。縮小補正禁止 |
| 四辺まで絵が接触 | スロット内で窮屈、切れて見える | 28×28安全域へ収め、四辺2px透明を確保 |
| 背景色や白い四角が残る | PNGを置くと板に見える | alpha=0の完全透過へ修正 |
| アンチエイリアスがある | 1px周辺に半透明のぼけ | nearest前提の硬いドットへ置換 |
| 輪郭が黒すぎる | 夜背景で消える | 黒インクは少し明るい紫縁、紙は茶紫縁へ変更 |
| 細部を盛りすぎる | 16pxで潰れる | 主モチーフ1、副要素1へ削る |
| 文字や記号で意味を説明 | 世界観と多言語対応を壊す | 文字を削除し、輪郭と物体で説明 |
| アイコン内に枠やLvを描く | HUD側の枠・バッジと二重になる | 枠・数字を削除 |
| エフェクトだけになっている | インベントリの物に見えない | 道具本体を主役へ戻す |
| 全部同じ金色・同じglow | カテゴリ差と物語差が消える | 素材色と輪郭を主にし、金は局所化 |
| 他アイコンと輪郭が似る | 24pxで見分けられない | 色ではなく外形を変更 |
| 進化後が別物になる | 系譜が分からない | 元武器の輪郭、角度、主色を最低1つ残す |
| 既存作品の有名アイコンに寄る | オリジナリティが弱い | Vamp Pon固有の紙・地図・忘れ物要素へ戻す |

### 手直しの優先順位

```txt
1. シルエット
2. 安全域とサイズ
3. 夜背景での視認性
4. 同カテゴリ内の差別化
5. 色と質感
6. 細部
```

色調整だけでシルエット問題を解決しない。

## 5. 似やすい組み合わせの差別化

### 月のしおり / 月明かりのしおり

```txt
武器「月のしおり」:
- 細く尖った短冊
- 先端に切れ込み
- 小さな月チャーム
- 斜めで動的

忘れ物「月明かりのしおり」:
- 少し幅広い紙片
- 垂直で静的
- 紙面に淡い月光の帯
- チャームなし
```

### ビー玉 / 追憶のビー玉 / ひび割れたレンズ

```txt
ビー玉:
- 完全な球
- 小さな白ハイライト1つ
- 青灰色

追憶のビー玉:
- 球の中に朝色と夜色の景色
- 外周に細いひび
- 元ビー玉より大きく重い

ひび割れたレンズ:
- 平たい円盤
- 外周リム
- 中央を横切る明確なひび
- 球体ハイライトは禁止
```

### 紙ひこうき / 追い風の紙ひこうき / 風のしるし

```txt
紙ひこうき:
- クリーム紙
- 折り目2本
- 単体で飛ぶ

追い風の紙ひこうき:
- 元の機体を残す
- 金茶の縁
- 後方へ2本の風線

風のしるし:
- 飛行機を描かない
- 小さな折り紙片と流れる3本の風
- レアの静物として中央配置
```

### 絵はがきカッター / 宛先のない刃 / 封のされた手紙

```txt
絵はがきカッター:
- 長方形の紙片
- 片端だけ斜めに鋭い
- 旅先色の小面積

宛先のない刃:
- 元の紙刃
- 封筒のV字切れ目
- 宛名欄は空白

封のされた手紙:
- 閉じた封筒
- 丸い封蝋
- 刃や切れ目を強調しない
```

### 夜の鉛筆 / 未完成の一行 / 消えない名前

```txt
夜の鉛筆:
- 短い鉛筆本体
- 芯先が見える

未完成の一行:
- 鉛筆の一部または芯先を残す
- 長い掠れ線
- 文章や読める文字は禁止

消えない名前:
- 鉛筆線
- 末尾に名前札の短冊
- 名前そのものは描かない
```

### 黒インクの小瓶 / 街灯の輪 / 夜明けのインク灯

```txt
黒インクの小瓶:
- コルク付き瓶
- 中の黒インク
- 小さな一滴

街灯の輪:
- 小型街灯の頭部
- 足元に小さい暖光リング
- 円だけにしない

夜明けのインク灯:
- 瓶またはインク滴
- 街灯の暖光
- 外周に朝色
- 3要素を32px内で単純化
```

### 星くず弾 / 北極星のランタン

```txt
星くず弾:
- 主星1つ＋小粒2つ
- 容器なし

北極星のランタン:
- 紙ランタンの外形
- 中に小さな星
- 地図の点を1つだけ添える
```

## 7. 制作順序

27種を一度に作らない。カテゴリごとにレビューしてスタイルのずれを止める。

```txt
Batch A: 通常武器8
Batch B: 忘れ物8
Batch C: レア4
Batch D: 進化・合体・覚醒7
```

### 各Batchの進め方

1. 全アイコンの白黒シルエットだけ作る
2. 24px表示で識別できるか確認
3. 共通パレットで着色
4. 夜背景 `#2a2747` と古紙背景 `#f3e9cf` の両方で確認
5. 16px表示で潰れる細部を削る
6. 個別PNGへ書き出す
7. `status: draft` へ変更
8. 実ゲームHUDでレビュー
9. 手直し後に `status: ready` へ変更

生成画像をそのまま `ready` にしない。必ずドット単位の整理を行う。

## 8. 採用判定

各項目を0または1で判定し、8点中7点以上を採用候補とする。

- [ ] 32×32 RGBA、四辺2px透明
- [ ] 24pxで名前を見ずに識別できる
- [ ] 16pxでも主シルエットが残る
- [ ] 夜背景で輪郭が消えない
- [ ] 同カテゴリの他アイコンと輪郭が重複しない
- [ ] Vamp Ponの紙・忘れ物・灯りの世界観に合う
- [ ] 禁止表現がない
- [ ] 専用スロット内でレベルバッジと重ならない

以下は即不採用。

```txt
透過でない
アンチエイリアスが強い
読める文字がある
既存作品の有名アイコンに酷似
元モチーフが分からない
16pxでただの色塊になる
```

## 9. レビュー時の返却フォーマット

```txt
対象:
判定: 採用 / 要修正 / 作り直し

良い点:
- 

重大修正:
1. シルエット:
2. 安全域:
3. 視認性:

軽微修正:
- 色:
- 1pxノイズ:
- ハイライト:

禁止事項の該当:
- なし / 内容

次版で絶対に残す要素:
- 
```

「もっと可愛く」「雰囲気を合わせる」だけで返さず、修正位置と理由を具体化する。

# Character Memory / Remembering Reservoir v1

Status: **AUTHOR RESERVOIR / NON-CANON / NO MEMORY-ACCURACY MORALITY / NO DIAGNOSIS INFERENCE**

全36人について、Canonの過去事件や重大な記憶を固定せず、**どう思い出し始めるか / 何を外部化するか / 忘れた時どうするか / 他人と記憶が食い違った時どう扱うか / 何を語らないか / 何を手放せるか**を作者用素材として持つ。

## Coverage

36 characters × 6 axes = **216 memory/remembering anchors**

Axes:

- `REMEMBERING_ENTRY`
- `EXTERNAL_MEMORY_AID`
- `FORGETTING_RESPONSE`
- `DISAGREED_MEMORY`
- `MEMORY_SHARING_BOUNDARY`
- `LETTING_GO`

## Why this is separate

This layer is not the same as:

- Lived Artifact — what objects/media traces exist
- Communication Habit — how a person communicates now
- Decision / Commitment — how a person makes and revises commitments
- Rest / Daily Rhythm — how a person pauses and recovers
- Canon history — what objectively happened in the story

Memory / Remembering is about **how a character handles incomplete, private, conflicting, retained, and released recollection**.

## Hard boundaries

This reservoir does **not** define:

- exact Canon childhood/past event
- trauma diagnosis
- dementia / cognitive diagnosis
- intelligence or reliability rank
- courtroom/forensic truth
- affection score
- exact dream-memory mechanic
- runtime memory stat
- Star Beast / constellation consequence

And it explicitly blocks:

- accurate memory = good person
- forgetting = careless / stupid / untrustworthy
- older character = declining memory
- Robot/AI = perfect objective memory
- data retention = personhood or love
- animal reaction = Human testimony
- photograph/log = complete truth
- disagreement in memory = automatic deception

## Canon boundary

Everything here remains:

`AUTHOR RESERVOIR / NON-CANON / FREE TO OVERWRITE`

A later story decision may reuse, revise, contradict, or discard these anchors. The reservoir does not promote any remembered event to Canon simply because a character has a remembering pattern here.

## Dream-world caution

Because ヨルノシルベ deals strongly with memory-like imagery, **dream representation and factual recollection must remain distinguishable at authority level**. A vivid image, recurring object, remembered sentence, dream reconstruction, machine log, photograph, or another person's testimony can all disagree without this reservoir deciding the objective story truth.

## Authoring principle

**「何を覚えているか」だけでなく、覚えていない時にどう振る舞い、他人の記憶をどこまで自分の物語にしないかでCharacterが見える。**

# プロトタイプ検証計画

## 目的

Vamp Pon をいきなり完成版として作らない。

小さいプロトタイプを段階的に作り、各段階で「何が分かれば次に進めるか」を明確にする。

## 基本方針

```txt
作る前に検証目的を決める
検証に不要な要素は入れない
仮素材で完成度を評価しない
数字と体感の両方を見る
合格しない場合は次の段階へ進まない
```

---

# Prototype 1: 1分操作感

## 目的

```txt
スマホ縦持ちで、移動・自動攻撃・欠片回収が気持ちいいか確認する。
```

## 入れるもの

```txt
ユイ
仮想スティック
インクの影
夜の鉛筆 Lv1
記憶の欠片
XPゲージ
初レベルアップ
```

## 入れないもの

```txt
武器5種
パッシブ5種
記憶カプセル
進化
必殺技
リザルト詳細
図鑑
実績
デザイン
```

## 検証項目

```txt
移動が気持ちいいか
敵が見えるか
自動攻撃が遅すぎないか
欠片が拾いやすいか
60秒以内にレベルアップするか
スマホで重くないか
```

## 合格基準

```txt
[ ] 3秒以内に動かせる
[ ] 最初の敵を10秒以内に倒せる
[ ] 30秒以内に欠片回収の意味が分かる
[ ] 60秒以内にレベルアップする
[ ] 操作が不快ではない
```

## 不合格時の対策

### 移動が不快

```txt
移動速度調整
仮想スティック半径調整
方向だけ入力へ変更
```

### 敵が硬い

```txt
インクの影HPを下げる
夜の鉛筆ダメージを上げる
攻撃間隔を短くする
```

### 欠片が拾いにくい

```txt
吸引範囲を広げる
欠片サイズを仮で大きくする
初期magnetを上げる
```

# Prototype 2: 3〜5分成長感

## 目的

```txt
レベルアップ3択、武器/パッシブ選択、ビルド差が楽しいか確認する。
```

## 入れるもの

```txt
武器5種
パッシブ5種
3択レベルアップ
武器/パッシブ枠
紙くずの影
迷子の方角
簡易リザルト
```

## 入れないもの

```txt
記憶カプセル
進化
必殺技
図鑑詳細
永続強化
```

## 検証項目

```txt
3択が分かりやすいか
武器ごとの差があるか
強化後に体感が変わるか
5分遊んで飽きないか
紙くずの影が理不尽ではないか
```

## 合格基準

```txt
[ ] 3択を迷わず選べる
[ ] 夜の鉛筆/月のしおり/星くず弾の違いが分かる
[ ] Lv2/Lv3で強くなった感覚がある
[ ] 3分時点で退屈していない
[ ] 5分時点で次も試したい選択がある
```

## 不合格時の対策

### 3択が分かりにくい

```txt
カード文言を短くする
新規/強化ラベルを大きくする
裏ストーリー文を非表示にする
```

### 武器差が弱い

```txt
武器挙動をもっと分ける
夜の鉛筆=直線
月のしおり=防御
星くず弾=ばらまき
黒インク=範囲
ビー玉=反射
```

# Prototype 3: 8分MVP

## 目的

```txt
Vamp Pon のMVP体験が成立するか確認する。
```

## 入れるもの

```txt
8分ウェーブ
敵5種
黒ラベルの影
記憶カプセル
進化1〜2種
必殺技「消えない名前」
リザルト
実績/図鑑の最小通知
```

## 入れないもの

```txt
2キャラ目
複数ステージ
永続強化の完全版
黒インク床
詳細図鑑
PWA/Capacitor
```

## 検証項目

```txt
8分が長すぎないか
3分/5分/7分のカプセルが嬉しいか
進化を見たいと思うか
必殺技が気持ちいいか
終盤に山があるか
リザルトでもう一度遊びたいか
```

## 合格基準

```txt
[ ] 初回5〜7分程度までは行ける
[ ] 数回プレイで8分クリアできる
[ ] 3分で初カプセルを見る
[ ] 1回は進化できる可能性がある
[ ] 必殺技を2回以上使う
[ ] リザルトで次の目標が出る
```

## 不合格時の対策

### 8分が長い

```txt
標準を5分にする
8分をfull扱いにする
カプセル間隔を短くする
```

### カプセルが嬉しくない

```txt
演出を短く強くする
進化優先度を上げる
通常強化でも分かりやすい変化を出す
```

### 必殺技が使われない

```txt
チャージ時間を短くする
ゲージ満タン表示を強くする
自動発動をONにする
```

# Prototype 4: スマホ実機検証

## 目的

```txt
スマホブラウザで本当に遊べるか確認する。
```

## 検証端末

最低限:

```txt
iPhone
Android 1台
```

可能なら:

```txt
小さい画面
大きい画面
古めの端末
```

## 検証項目

```txt
縦持ちで見えるか
仮想スティックが押しやすいか
必殺技ボタンが押せるか
レベルアップカードが読めるか
敵数で重くならないか
中断復帰で事故らないか
```

## 合格基準

```txt
[ ] 30fpsを大きく下回らない
[ ] 文字が読める
[ ] 指で自キャラが隠れにくい
[ ] 8分プレイして発熱/重さが許容範囲
[ ] 中断復帰でポーズする
```

# Prototype 5: 継続プレイ検証

## 目的

```txt
1回遊んだ後、もう一度遊びたい理由があるか確認する。
```

## 入れるもの

```txt
簡易実績
簡易図鑑
通貨
永続強化5種
次の目標表示
```

## 検証項目

```txt
次の目標が分かるか
永続強化が強すぎないか
図鑑文を読んで少し気になるか
もう一度が重くないか
```

## 合格基準

```txt
[ ] 3回連続で遊ぶ理由がある
[ ] 永続強化なしでもクリア可能
[ ] 実績/図鑑が邪魔ではない
```

---

# 検証ログ項目

各プレイで記録する。

```txt
プレイ時間
死亡/クリア
到達Lv
初回Lv2到達時間
初カプセル時間
進化数
必殺技使用回数
倒した影
取得欠片
被ダメージ回数
感想メモ
```

## 感想メモの型

```txt
気持ちよかった瞬間:
不快だった瞬間:
分かりにくかったもの:
もう一度遊びたいか:
次に直すなら:
```

# 次段階へ進む条件

## Prototype 1 → 2

```txt
移動/自動攻撃/欠片回収が不快ではない
60秒以内にレベルアップする
```

## Prototype 2 → 3

```txt
3択が読める
武器差がある
5分遊んで退屈しない
```

## Prototype 3 → 4

```txt
8分の山がある
記憶カプセル/進化/必殺技が機能している
```

## Prototype 4 → 5

```txt
スマホで操作/視認性/性能が破綻していない
```

## Prototype 5 → デザイン本格化

```txt
仮素材でも、もう一度遊びたい核がある
```

## 最重要判断

```txt
仮素材でも面白い核があるか？
```

ここがYESになるまで、本素材や大型デザインに入らない。

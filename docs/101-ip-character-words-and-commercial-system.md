# IP Character Words and Commercial System

この資料は、Vamp Pon / ヴァンサバ改のキャラクター文言・商用展開・UI表示語を整理するための正本候補。

Vamp Pon は正式販売タイトルではなく、開発コード名。
正式タイトル・シリーズ名・ストア名は別途検討する。

## 0. 世界観の芯

```txt
夜
忘れ物
小さな灯り
星
黒耀
朝
帰り道
```

この作品は戦闘作品ではない。

勇者や最強の物語ではなく、弱さを抱えた人たちが、誰かの忘れ物と自分の夜をほどきながら朝を目指す物語。

避ける語感:

```txt

覚醒
究極
必殺
奥義
EX
アルティメット
運命
闇落ち
選ばれし者
```

採る語感:

```txt
灯す
ほどく
拾う
挟む
帰す
直す
見つける
朝を待つ
```

## 1. キャラ文言の3層構造

キャラは次の3層で扱う。

```txt
1. 肩書き
2. キャッチコピー
3. ポエム
```

### 肩書き

図鑑・UI・グッズ向け。
短く、並べたときに強いこと。

### キャッチコピー

Steam・PV・SNS向け。
短く刺さること。
説明ではなく、1枚絵の横に置ける言葉。

### ポエム

キャラの魂を表す文。
BLEACH巻頭ポエム的な「余白の強さ」は参考にするが、文体・構文・語彙の模倣は禁止。

重視:

```txt
短い言葉の強さ
キャラの内面
余白
弱さ
一文の重さ
夜と朝の距離
```

## 3. キャラ固有名称の考え方

従来の `必殺技` `奥義` `EXスキル` `アルティメット` は不採用。

Vamp Pon では、戦闘の大技ではなく、キャラ自身が夜に対して持っている「灯りの名」として扱う。

### 正本候補

```txt
灯名（ひな）
```

採用理由:

```txt
短い
UIに置ける
技名より人格に近い
灯りの名前として読める
キャラごとに固有名を持たせやすい
黒耀・朝明とも接続しやすい
```

表示例:

```txt
灯名：消えない名前
灯名：残火の足音
灯名：星図の余白
```

### 予備候補

```txt
しるべ
星名
夜名
黒名
```

評価:

```txt
しるべ：やさしいが少し一般語すぎる
星名：星標器とは合うが、キャラの弱さから少し離れる
夜名：かっこいいが暗さが強い
黒名：黒耀寄りすぎて通常時に使いにくい
```

現時点では `灯名` を第一候補とし、正式決定は実装前に最終確認する。

## 7. 星標器の商用構造

全員共通デバイス。
デジヴァイスやモンスターボールのような、IPの共通記号として育てる。

```txt
正式名：星標器
愛称：星のしるべ
構造：星標器 → 紋章 → 星灯獣
```

### 商用展開で強い要素

```txt
星標器本体
キャラ別紋章
星灯獣
忘れ物モチーフ
灯りモチーフ
ペア/ユニットの色違い
```

### 恋愛売り禁止

ペアは恋愛ではなく、関係性・補完・小さな繋がりで売る。

例:

```txt
帰灯 × 残火
星図 × 迷灯
修灯 × 白紙
黒羽 × 宛先
水憶 × 拾音
```

### 闇落ち売り禁止

黒耀グッズは強そうに売らない。

良い:

```txt
黒耀アクリル：弱さがにじむ差分
黒耀ラバスト：疲れた灯り
黒耀カード：夜に沈んだ一文
```

悪い:

```txt
闇落ちver
最強黒化
暴走形態
悪堕ち
```

朝明後名称：朝明名 または UI上は朝明

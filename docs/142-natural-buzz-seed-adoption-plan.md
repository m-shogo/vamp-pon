# Natural Buzz Seed Adoption Plan

## 目的

Vamp Ponに、自然に刺さりやすい関係性・小物・システム要素を仕込む。

ただし、バズ狙いで要素を盛りすぎない。

```txt
入れる条件:
小物にできる
黒インクの誤解固定にできる
ゲーム効果にできる
回収後に意味が変わる
恋愛以外にも読める
```

---

# 1. 基本方針

バズる要素は、表に出しすぎると安くなる。

Vamp Ponでは以下の順で仕込む。

```txt
1. まず小物として置く
2. 次に敵の挙動で違和感を出す
3. その後、きずな/必殺技でゲーム的に使えるようにする
4. 最後にリザルト文やページ回収で意味を反転する
```

つまり、関係性を最初から説明しない。

```txt
分かる人が先に気づく
プレイした人が後で意味を知る
スクショ/考察で広がる
```

この順が一番強い。

# 2. 無理なく採用するS級要素

## S1. 年を取らない魔女 × 年を取る人間

採用。

ただし、Season 1では本編化しない。

仕込み方:

```txt
止まった懐中時計
毎年同じ日付の手紙
若いままの写真
しおれない花
```

初見の意味:

```txt
少し不思議な古い小物
```

後の意味:

```txt
同じ約束を覚えているのに、同じ速さで年を取れない関係
```

ゲーム接続:

```txt
時間停止
遅延ダメージ
一定時間だけ昔の姿の影が見える
```

採用位置:

```txt
Season 1: 小物Seedだけ
Season 2以降: 別ページ束の主題候補
```

---

```

```

ゲーム接続:

```txt
不安定きずな
上振れ/下振れ
高火力だが欠片が黒インクへ戻ることがある
```

採用位置:

```txt

Season 2以降で本格化
```

# 4. 保留する要素

以下は刺さるが、扱いを間違えると重い。

```txt
主従/契約
看取り/見送り
不死者が終わりを望む関係
未来から来た子 × 過去の親
先生 × 生徒
帰る皮を奪われた者 × 引き止めた者
```

保留理由:

```txt
重すぎる
支配/死/年齢差/倫理問題に寄りやすい
Season 1の軽さを食う
```

採用する場合は、以下を守る。

```txt
小物化する
直接説明しない
救いを“所有”ではなく“返す自由”に置く
死を美化しない
```

# 7. バズりやすい見せ方

## スクショで伝わる小物

```txt
若いままの写真と、しわしわの手紙
敵が踏まない名札
毎年同じ日付の手紙が束になっている
内側から鍵がかかった箱
片目のボタンが光る
```

## 短文で刺さるリザルト

```txt
今年も、同じ日付だけが読めた。

敵だと思っていた影は、その名札だけ踏まなかった。

箱は閉じ込めるためではなく、壊れないように閉じていた。

帰り道はなかったのではない。読めなかっただけだった。

手紙は届かなかった。でも、捨てられてはいなかった。
```

## 考察されやすい違和感

```txt
同じ小物なのに折り方が違う
敵が一部の欠片を攻撃しない
リザルト文だけが周回で少し変わる
背景に同じ日付の紙が何度も出る
```

# 10. 最重要

Vamp Ponのバズ要素は、関係性を説明することではない。

```txt
小物だけ見て気になる
遊ぶと意味が変わる
後から考察したくなる
スクショで共有したくなる
```

この形で仕込む。

自然に入るものだけ採用する。

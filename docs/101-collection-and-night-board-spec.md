# 忘れ物帳 / 夜明け盤 仕様

## 目的

Vamp Pon の収集要素は、単なる敵図鑑ではなく、プレイ後に「もう1回だけ」を生む進行盤として設計する。

狙う体験:

```txt
戦闘中はテンポを止めない
リザルトで複数マスが埋まって気持ちいい
埋めたマスの隣から次の目的が見える
簡単な達成と狙う達成を混ぜる
世界観上は、夜を少しずつ明けさせる記録にする
```

---

# 1. 全体構造

## 採用名称

```txt
忘れ物帳：収集/図鑑/記録の総称
夜明け盤：クリアチェッカー型の達成盤
カゲモノ図鑑：オンブラ/オンブロ/ヨリシロ/夜主の情報ページ
忘れ物一覧：拾った忘れ物と記憶文
夜路の記録：ステージ/深度/地区クリア記録
灯し手の記録：キャラ別の進行記録
```

## UI階層

```txt
TOP
 └ 忘れ物帳
    ├ 夜明け盤
    ├ カゲモノ図鑑
    ├ 忘れ物一覧
    ├ 夜路の記録
    └ 灯し手の記録
```

## 使い分け

```txt
忘れ物帳：世界観と収集の入口
夜明け盤：達成マスを埋める気持ちよさ
カゲモノ図鑑：敵の説明・攻略ヒント・記憶文
忘れ物一覧：ドロップ/レア/物語の補完
夜路の記録：ステージごとの達成状況
灯し手の記録：キャラごとのプレイ動機
```

# 2. 登録段階

カゲモノ図鑑は一度倒しただけで完了にしない。段階的に情報を解放する。

```txt
未確認：まだ見ていない
見つけた：初遭遇。シルエットと仮説明だけ解放
ほどいた：初撃破。正式名と基本説明を解放
観察した：一定数撃破。攻略ヒントを解放
記された：さらに撃破。生態/世界観文を解放
思い出した：関連する忘れ物を取得。記憶文を解放
```

## 条件例

| 段階 | 条件 | 解放内容 |
|---|---|---|
| 未確認 | 初期状態 | なし |
| 見つけた | 初遭遇 | シルエット、仮名、短い不明説明 |
| ほどいた | 初撃破 | 正式名、基本説明、出現地区 |
| 観察した | 10体撃破 | 攻略ヒント |
| 記された | 30体撃破 | 生態文、背景文 |
| 思い出した | 関連忘れ物取得 | 記憶文、小話 |

## ボス系

ヨリシロと夜主は「撃破」ではなく「鎮める」と表現する。

```txt
ヨリシロ：初遭遇で影登録、初鎮めで正式登録、地区の中間記録を解放
夜主：初遭遇で地区ページに記録、初鎮めで夜明けのしるし/地区記録を解放
```

# 3. 夜明け盤

## 基本方針

夜明け盤は、カービィエアライドのクリアチェッカー的な「埋めたくなる盤面」を Vamp Pon の世界観に合わせたもの。

重要なのは、ただ一覧を並べることではない。

```txt
1マス埋まる
↓
隣のマスが見える
↓
次の目標がわかる
↓
もう1回遊ぶ理由ができる
```

## 初期サイズ

```txt
Stage1 / 忘れ物通り：5×5 = 25マス
地区1完成後：8×6 = 48マスまで拡張可能
将来：地区ごとに10×10も検討
```

Prototypeでは25マスで十分。120マス級は最初から入れない。

## マスの状態

```txt
hidden：完全非表示。隣接マス達成まで条件も見せない
hinted：存在だけ見える。短いヒントを表示
revealed：条件が見える。未達成
completed：達成済み
claimed：報酬受取済み
```

## 隣接解放

達成したマスの上下左右を `hinted` または `revealed` にする。

```txt
completed の隣だけ見える
盤面中央から外へ広がる
秘密マスは hinted までで条件を隠す
```

これにより、プレイヤーは全部の課題を一度に押し付けられず、少しずつ目的を増やせる。

# 4. マス種別と難易度配分

全部を撃破数にすると作業になる。マスは種類を分ける。

## 配分

```txt
自然達成：50%
ちょい狙い：30%
やり込み：15%
秘密：5%
```

## 1. 自然達成

普通に遊ぶだけで埋まる。気持ちよさ担当。

```txt
しずくオンブラを初めてほどく
深度1を夜明けする
記憶片を100個集める
にじみ鉛筆をLv3にする
```

## 2. ちょい狙い

少し意識すると達成できる。「もう1回だけ」を作る。

```txt
紙ひこうきだけで100体ほどく
回復を取らずに3分生き残る
黒耀化を使わずに深度2を夜明けする
灯技でヨリシロに最後の一撃を入れる
```

## 3. やり込み

簡単ではないが理不尽ではない。

```txt
深度3を被弾3回以内で夜明けする
オンブロを出現から20秒以内にほどく
HP残り1で夜明けする
1プレイで忘れ物を3つ拾う
```

## 4. 秘密

条件は最初隠す。隣接マスを埋めるとヒントだけ見える。

```txt
？？？
ヒント：灯りを使わず、朝を待つ
```

# 6. 報酬設計

## 基本

報酬は強すぎない。強すぎると義務になる。

```txt
1マス達成：灯貨 +5〜30
やり込みマス：灯貨 +30〜50
一部マス：旅支度 +1
列完成：小さな旅支度ポイント
地区盤完成：夜明けのしるし強化 / 記憶文 / スキン / BGM
```

## 報酬の種類

```txt
灯貨：軽い達成報酬
旅支度：永続強化に使う小ポイント
記憶文：世界観テキスト
見た目：スキン/称号/スタンプ候補
音：BGM/SE/ジングル候補
```

## 避けること

```txt
強い武器を必須報酬にしすぎない
やり込みマスを攻略必須にしない
秘密マスに重要機能を入れない
毎回ポップアップで戦闘を止めない
```

# 7. 気持ちよさ演出

## 戦闘中

初回登録だけ小さく出す。ゲームを止めない。

```txt
忘れ物帳に記された
しずくオンブラ
```

表示時間:

```txt
1.2〜1.8秒
画面右上または下部
連続登録時はキューに積むが、戦闘中は最大2件まで表示
```

## リザルト

リザルトでまとめて気持ちよく見せる。

```txt
夜明け盤
□ □ ■ □ □
□ ■ ■ ■ □
□ □ ■ □ □

新しく記された
・しずくオンブラ
・にじみ鉛筆 Lv5
・深度1 夜明け
```

複数マスがテンポよく埋まる演出が本命。

```txt
1マス 0.08〜0.12秒
達成マスは小さく光る
列完成時だけ少し強いジングル
```

## TOP

TOPに戻った時に、続きが気になる導線を出す。

```txt
忘れ物帳に新しい記録があります
夜明け盤 3マス更新
```

# 8. カゲモノ図鑑ページ

## 表示例

```txt
しずくオンブラ

分類：カゲモノ / オンブラ
出現：忘れ物通り 深度1〜
登録：42体

夜路に落ちた黒いしずく。
灯りを見つけると、むにっと寄ってくる。

観察：
動きは素直。囲まれる前に横へ抜けると安全。

記憶：
落ちていたのは、涙ではなく、
誰かが言えなかった「ただいま」だった。

関連する夜明け盤：
■ 初めてほどく

```

## 解放順

```txt
初遭遇：シルエットだけ
初撃破：名前と基本説明
10体：観察ヒント
30体：生態文
関連忘れ物：記憶文
```

# 9. セーブデータ方針

```ts
collection: {
  seenEnemyIds: string[];
  defeatedEnemyCounts: Record<string, number>;
  calmedBossIds: string[];
  discoveredLostItemIds: string[];
```

```txt

boss_calmed
weapon_leveled
weapon_fused
lost_item_collected
stage_cleared
```

## 評価タイミング

```txt

TOP戻り時：忘れ物帳の新着バッジを表示
```

# 11. 判定基準

この仕組みが成功しているかは、以下で判断する。

```txt
リザルトで2〜5マス埋まることが多い
1プレイ後に次の目的が1〜3個見える
達成報酬が強制感ではなく嬉しい小報酬になっている
戦闘中の通知が邪魔ではない
図鑑ページから次に狙う行動が分かる
```

失敗パターン:

```txt
条件が全部撃破数
マスが最初から多すぎる
秘密マスが多すぎる
報酬が強すぎて義務になる
リザルトが長すぎる
戦闘中に演出が割り込む
```

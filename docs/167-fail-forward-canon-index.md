## Adopted canon

- A failed run is not wasted.
- Game over means the night's reading failed, not that the character died.
- Some traces remain in the mapbook even when the night does not reach morning.
- Basic progress must not require clear.
- Clear gives stronger page confirmation rewards, but failure gives learning and small growth.
- The result screen must show what remained and what to try next.

## Design priority

Use this order when designing fail-forward rewards:

1. story meaning
2. player clarity
3. small permanent growth
4. retry motivation
5. balance cap

## First implementation target

The first safe slice should be:

- memory dust
- one lantern care upgrade
- one mapbook upgrade
- enemy seen progress
- result screen next-goal hint

Do not start with a giant upgrade tree.

## Boundary

This canon does not require immediate implementation.
It prepares the system so future implementation does not feel like generic stat grinding.

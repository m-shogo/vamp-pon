# 参考アプリと隠し武器報酬

## 目的

Vamp Pon は、ゲーム仕様は Vampire Survivors ライクでよい。

ただし、長続きする仕組みは他のゲーム・アプリから参考にする。

特に重要な感覚:

> 条件を達成したら、強い武器や特別な報酬が手に入る。

これは三國無双3の最強武器獲得のような、狙って達成する隠し報酬の気持ちよさに近い。

## 参考にする考え方

### 1. Vampire Survivors

参考にするもの:

- 自動攻撃
- 大量撃破
- 経験値回収
- レベルアップ
- 武器進化
- アンロック
- 実績
- 図鑑的な収集
- 低価格・小さな追加コンテンツで長く広げる構造

Vamp Ponで使う理由:

- 基本システムとして完成度が高い
- 難しくしなくても長く遊べる
- 武器・キャラ・ステージ追加と相性がよい

### 2. 三國無双3の最強武器条件

参考にするもの:

- キャラごとに強い武器がある
- 特定ステージで条件を満たす
- 条件達成した瞬間に獲得感がある
- 普通に遊ぶだけでは見つけにくい
- でも理不尽ではなく、知れば狙える

Vamp Ponで使うなら:

- 隠し進化武器
- 秘宝武器
- 特定条件で出るレア宝箱
- キャラ専用武器
- ステージ専用アンロック

## なぜ良いか

普通の周回報酬は、ただ遊んでいると少しずつ貯まる。

三國無双3の最強武器型は、それとは違う。

> 今回はこの条件を狙ってプレイする。

という目的が生まれる。

これにより、難しくしなくても長続きする。

## Vamp Pon向けの報酬カテゴリ

### 通常アンロック

遊んでいれば自然に解放される。

例:

- 5回プレイする
- 敵を合計1000体倒す
- レベル10に到達する
- 10分生存する

役割:

- 初心者向け
- 気持ちよく続ける理由
- 難しくない

### 条件達成アンロック

狙うと取れる。

例:

- 初期武器だけで5分生存
- 回復を取らずにボス撃破
- 特定武器を最大レベルにする
- 下方向から来る敵を一定数倒す
- 宝箱を3つ開ける

役割:

- 中期の目標
- もう一回プレイする理由
- ビルド実験の動機

### 隠し武器/秘宝武器

三國無双3の最強武器枠。

例:

- 特定ステージ
- 特定キャラ
- 特定武器構成
- 特定時間までに条件達成
- 特定敵を倒す

役割:

- 発見の快感
- 攻略情報を見たくなる要素
- 長期の目標
- 所有する満足感

## 条件設計のルール

### 良い条件

- プレイ方針が変わる
- 何を狙うか分かる
- 達成した瞬間が気持ちいい
- 失敗してももう一回やりたくなる
- 難しすぎない
- 理不尽ではない

例:

```txt
5分以内に進化武器を1つ作る
下方向の大型敵を3体倒す
HP50%以上で10分生存
特定武器を最大レベルにして宝箱を開ける
```

### 悪い条件

- 条件が分からなすぎる
- 偶然頼みすぎる
- 1回の失敗で長時間が無駄になる
- 高難度アクションを要求する
- UIで進行状況が見えない

例:

```txt
ノーダメージで30分生存
ランダムで1%だけ出る敵を倒す
説明なしで複数条件を同時達成
特定秒数ぴったりに敵を倒す
```

## 隠し武器の見せ方

最初から全部隠すと不親切。

Vamp Ponでは、以下の段階がよい。

### 1. 存在だけ見せる

図鑑に「???」として表示する。

### 2. ヒントを出す

例:

```txt
夜のおもちゃ箱で、灯りを守りながら進化を待て。
```

### 3. 条件達成中の進行を少し見せる

完全な攻略情報ではなく、近づいている感を出す。

### 4. 達成時に特別演出

通常アンロックより強く見せる。

## 三國無双3型をそのまま入れるなら

Vamp Pon版の名前案:

- 秘宝武器
- 真なる武器
- 夜明け武器
- おもちゃ箱の秘宝
- 星付き武器
- レリック武器
- 伝説進化

## MVPでの扱い

MVPでは作り込みすぎない。

入れてよい最小案:

- 通常進化1個
- 隠し進化1個
- リザルトで条件ヒントを1つ出す
- 図鑑に「???」を1つ置く

入れないもの:

- 大量の隠し武器
- 複雑な条件
- キャラ別最強武器大量実装
- 条件の完全なUI管理

## 参考にする他ゲーム/アプリ軸

### Hades系

参考:

- 短い周回
- 会話/報酬/選択で次を遊びたくなる
- プレイヤーが毎回少し違う構成を試す

Vamp Pon向き:

- 周回後の小さい発見
- リザルト後の次の目標
- 図鑑や記録

### Slay the Spire系

参考:

- ビルドの組み合わせ
- 今回の選択が後で効く
- アンロックで遊びが増える

Vamp Pon向き:

- 武器/パッシブの相性
- 進化条件
- 選択肢の悩み

### デイリー/ミッション系アプリ

参考:

- 毎日少し遊ぶ理由
- 小さい目標
- 報酬の受け取り

Vamp Pon向き:

- デイリーチャレンジ
- 今日のおすすめ武器
- 今日の秘宝ヒント

ただし、ログイン圧や義務感は避ける。

## Vamp Ponでの結論

長続きは、難しさではなく以下で作る。

```txt
爽快感
武器進化
隠し条件
図鑑
秘宝武器
リザルトヒント
小さいアンロック
```

三國無双3の最強武器条件のような、**狙って取る特別報酬**はかなり相性が良い。

ただし、MVPでは1個だけ試す。

## 判断基準

迷ったら、次の問いに戻る。

> この報酬は、難しいから偉いのか？ それとも、狙って達成するのが楽しいのか？

Vamp Ponでは後者を優先する。

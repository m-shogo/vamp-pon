# アクセシビリティ/スマホユーザビリティ方針

## 目的

Vamp Pon はスマホで遊ぶ前提のゲーム。

そのため、見た目が良いだけでなく、読める・押せる・分かる・疲れにくいことを重視する。

デザイン確定前でも、アクセシビリティとユーザビリティの基準は先に決める。

---

# 1. 基本方針

```txt
小さい文字に頼らない
色だけで判断させない
音がなくても分かる
片手でも大きく破綻しない
誤タップしにくい
画面揺れ/ダメージ数字は調整可能にする
```

## 優先順位

```txt
1. 自キャラが見える
2. 敵が見える
3. 欠片が見える
4. HP/時間が分かる
5. 操作が押せる
6. 文字が読める
7. 裏ストーリーを読める
```

裏ストーリーは一番上ではない。

---

# 2. 文字サイズ

## 最小基準

スマホでは、重要テキストを小さくしない。

```txt
残り時間: 大
HP: 大
Lv: 中
レベルアップカード名: 大
効果説明: 中
裏ストーリー文: 小〜中
```

## 危険

```txt
カード内に長文を入れる
図鑑文を戦闘中に出す
リザルトに情報を詰め込みすぎる
```

## 方針

戦闘中の文字は最小。

読ませるものは、ポーズ中/リザルト/図鑑に寄せる。

---

# 3. 色だけに頼らない

## NG

```txt
赤なら危険
青なら安全
光っていたら取得済み
色だけでレア度表示
```

## OK

```txt
危険: 色 + 形 + 点滅
取得可能: 色 + アイコン + 動き
必殺技満タン: 色 + ゲージ + 発動OK表示
HP低下: 色 + バー減少 + 軽い点滅
```

## 理由

スマホ画面、屋外、色覚差、画面輝度で色は信用しすぎない。

---

# 4. 音なし対応

## 必須

音が出なくても以下が分かる。

```txt
被弾
レベルアップ
必殺技使用可能
記憶カプセル取得
進化
クリア/失敗
```

## 視覚補助

```txt
被弾: HPバー点滅
レベルアップ: 画面停止 + 3択
必殺技: ボタン変化
カプセル: 中央表示
進化: 報酬名表示
クリア: リザルト文言
```

---

# 5. 画面揺れ

## 方針

画面揺れは気持ちいいが、スマホでは酔いやすい。

MVPでは控えめ。

設定:

```txt
screenShake: true / false
```

初期値:

```txt
true
```

ただし揺れは弱め。

## 揺らしてよい場面

```txt
必殺技
進化
強敵撃破
クリア
```

## 揺らさない場面

```txt
通常敵撃破
欠片取得
通常レベルアップ
```

---

# 6. ダメージ数字

## 方針

MVPではONでよいが、出しすぎない。

設定:

```txt
damageNumbers: true / false
```

## 注意

大量の敵に数字を出すと視認性とパフォーマンスが落ちる。

対策:

```txt
小型敵は数字を間引く
継続ダメージはまとめる
クリティカルなどはMVPで入れない
```

---

# 7. 操作アクセシビリティ

## 必須

```txt
移動は仮想スティック
必殺技は1ボタン
長押しなし
連打なし
同時押しなし
精密エイムなし
```

## 自動必殺技

設定として持つ。

```txt
autoUltimate: true / false
```

初期値は手動でもよいが、初心者/操作が苦手な人向けに必要。

## 片手操作

完全な片手最適化はMVP後。

ただし以下は避ける。

```txt
画面上部の頻繁なタップ
左右同時操作
細かいカードボタン
```

---

# 8. レベルアップカード

## タップ領域

カード全体をタップ可能にする。

小さいボタンを押させない。

## 3択固定

スマホでは4択以上にしない。

## 文言量

カード1枚あたり:

```txt
名前: 1行
効果: 1〜2行
裏文: 0〜1行
```

裏文は読まなくても選べるようにする。

---

# 9. リザルト

## 方針

リザルトは情報量が増えやすい。

MVPでは以下を優先。

```txt
生存時間
倒した影
集めた欠片
到達Lv
進化
新発見
次の目標
```

## 分割

スマホでは1画面に詰め込まず、必要ならセクション分け。

```txt
結果
ビルド
新発見
次の目標
```

---

# 10. 中断/復帰

## 必須

```txt
非アクティブ時に自動ポーズ
復帰時はポーズ状態
即再開しない
```

## 理由

スマホでは通知/電話/画面ロックがある。

復帰直後に即被弾するのは理不尽。

---

# 11. パフォーマンス配慮

アクセシビリティ以前に、重いと遊べない。

MVP上限:

```txt
敵: 120〜160
欠片: 250
弾: 120
```

状況に応じて調整。

## 重くなる要素

```txt
大量パーティクル
大量ダメージ数字
毎フレーム全探索
欠片を個別に出しすぎる
```

## 対策

```txt
オブジェクトプール
欠片統合
ダメージ数字間引き
武器発射時だけ探索
```

---

# 12. アクセシビリティ設定一覧

MVPで持つ候補。

```txt
sound: on/off
screenShake: on/off
damageNumbers: on/off
autoUltimate: on/off
```

MVP後候補。

```txt
textSize: normal/large
highContrast: on/off
leftHandedMode: on/off
reducedEffects: on/off
```

---

# 13. 合格チェックリスト

```txt
[ ] 音なしでも被弾が分かる
[ ] 音なしでもレベルアップが分かる
[ ] 必殺技ボタンが押せる
[ ] カード全体をタップできる
[ ] 文字が小さすぎない
[ ] 敵/欠片/弾が重なっても見える
[ ] 画面揺れを切れる
[ ] ダメージ数字を切れる
[ ] 非アクティブ時に自動ポーズする
[ ] 8分遊んでも疲れすぎない
```

## 最重要

```txt
スマホで読めない情報は、存在しないのと同じ。
```

この前提でUI/文言を作る。

# 2. トモリ — 戦後復興・物資不足期

Visual vocabulary:

- repairable metal hardware
- stitched / repaired work layer
- reused but cared-for component
- natural / sturdy textile
- real tool pouch
- glass / metal lamp part
- hand-written repair note
- mismatched repaired fastener

Avoid:

- automatic military uniform
- soot / wound as war-trauma shortcut
- poverty costume caricature
- every garment visibly torn

Important:

> **「足りない時代」より「直して暮らす人」として見せる。**

Dream costume may mix era construction with Yoru-no-Shirube fantasy geometry, but should feel repairable by Tomori's own hands.

# 6. アサ — Far-future Human

Visual vocabulary:

- compact future closure
- identity / tag detail without exposition dump
- asymmetric construction compatible with existing fast silhouette
- advanced material without glowing everywhere
- handwritten name tag as intentionally old-fashioned preference
- optional avatar / identity-device relation shown through accessory, not body seam

Hard:

- Human body
- no Android seam
- no artificial-joint default
- no compulsory visor
- no full neon cyber suit

Strong contradiction:

> **Far-future system literacy + love of handwritten names.**

This makes Asa a future Human person rather than generic cyberpunk.

# 7. TOP / group-art composition

When Core5 appear together:

- faces remain Appearance Source first
- each Era needs at least 2 construction / prop clues
- do not line them up as five museum costumes
- Era differences should be discoverable on second look
- Season costume updates may add shared incident details without erasing Era origin

Best hierarchy:

1. Character face / silhouette
2. Character role object
3. Era construction / prop literacy
4. Season-specific incident mark
5. Dream shared visual motif

Era should enrich identity, not replace identity.

---

# 8. Family / generation visual guard

Same Era contains:

- children
- parents
- aunt / uncle-like adults
- grandparents
- single adults
- non-nuclear households

Therefore one Core5 costume cannot represent an entire Era's fashion / life.

When creating Reality scenes, age / job / household role must modify Era visual vocabulary.

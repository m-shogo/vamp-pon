# 2. トモリ — 1940年代系日本

Visual vocabulary:

- repairable metal hardware
- stitched / patched work layer
- natural / sturdy textile
- real tool pouch
- glass / metal lamp part
- hand-written repair note
- reused fastener / mismatched repaired part

Avoid:

- automatic military uniform
- bomb-damage soot as backstory shortcut
- historical cosplay perfection

Dream costume may mix the above with Yoru-no-Shirube fantasy geometry, but the construction should feel **repairable by Tomori's own hands**.

# 3. ミチル — 1980年代系日本

Visual vocabulary:

- folded paper map
- route notebook
- practical walking layer
- analog watch / station-clock literacy
- older synthetic outdoor textile Candidate
- ticket / map case
- travel pins that feel individually collected

Avoid:

- bubble-party caricature
- shoulder-pad joke
- neon 80s shorthand

Michiru's era should read more strongly through **how they navigate and carry information** than through costume parody.

# 4. ナギ — 2000年代系日本

Visual vocabulary:

- compact personal pouch / closed compartments
- early-digital-era lock / strap / case language
- simple phone / mail-era accessory Candidate
- layered privacy-like closures
- clean but not futuristic construction

Avoid:

- specific mobile-phone brand
- specific SNS/service logo
- hacker stereotype

Nagi should visually suggest:

> 開けられることと、開けてよいことは違う。

# 5. ユイ — Present-day Japan

Visual vocabulary:

- current practical travel layer
- contemporary bag closure
- modern casual material mix
- present-day packaging / UI literacy
- inherited lantern as deliberate old-object contrast

Key contrast:

> **服と生活感は現代、ランタンだけが明らかに古い。**

This contrast is more valuable than adding many fashionable accessories.

---

# 6. アサ — Future Human

Visual vocabulary:

- compact future closure
- identity / tag detail without readable exposition dump
- asymmetric construction compatible with existing fast silhouette
- material that can read advanced without glowing everywhere
- hand-written name tag as intentionally old-fashioned personal preference

Hard:

- Human body
- no Android seam
- no artificial-joint visual
- no compulsory visor
- no full neon cyber suit

Strong contradiction:

> Future system literacy + love of hand-written names.

This makes Asa feel like a person from a future society rather than a generic sci-fi character.

---

# 7. TOP / group-art composition

When Core5 appear together:

- faces remain Appearance Source first
- each era needs at least 2 construction / prop clues
- do not line them up as five historical costumes
- differences should be discoverable on second look

Best hierarchy:

1. Character face / silhouette
2. Character role object
3. Era construction detail
4. Dream shared visual motif

Era should enrich identity, not replace identity.

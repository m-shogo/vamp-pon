# 1. マドカ — Observer から Witness へ

## CURRENT DESIGN DIRECTION

### 一言

> **見た人。だから、伝えるかどうかを選ばなければならない。**

マドカの核を「観察が得意」だけにしない。

```txt
トキ = 測る
レン = 比べて違いを見つける
マドカ = 見たことを誰かへ伝える責任を持つ
```

## Visible signature

- window / frame
- 遠景
- 小鷲
- 目を細めるより、窓枠へ指を添えて位置を覚える

## Strength

遠くの小さな変化へ早く気づく。

## Same-root weakness

> **確信がないことを口にするのが怖い。**

誤報で誰かを動かすくらいなら黙る。

その慎重さは長所でもある。
しかし「見たのに誰にも言わなかった」ことが後悔になる余地がある。

## HISTORY CANDIDATE

現実側で、何か異変を見た。

- 誰かが困っていた
- 事故の前兆
- 見間違いかもしれない行動

など。

その時は100%確信できず、黙った。

**何を見たかはまだLOCKしない。**
犯罪・死亡など重すぎる固定を急がない。

## Daily scene

窓の外を見て:

> 「雨、五分くらいで来るかも。」

誰も信じず洗濯物を出す。
五分後ほんとうに雨。

マドカは勝ち誇らず、黙って一緒に取り込む。

## Relation

- **レン** — レンが差分を見つけ、マドカが「それを今共有するか」を考える
- **トキ** — トキは数値が出るまで待つ。マドカは数値にならない変化も見てしまう
- **セン** — 「確実ではない情報をどう伝えるか」を言葉へ直す

## 黒耀化

通常:

> 見逃したくない。

Wrong arrival:

> **全部見えていれば、二度と判断を間違えない。**

- fog / hidden informationを全部暴く
- 画面外enemy / future attack telegraphを大量表示
- 一時的に圧倒的に有利
- しかし情報量が過剰でpriorityを失う

成長:

> **全部見ることより、見えた大事なことを伝える。**

## Gameplay identity

- offscreen danger preview
- boss action forecast
- uncertain telegraph（確率 / warning）
- playerへ「確定情報」と「未確定warning」を色 /形で分ける

# 2. レン — Observer から Difference Detector へ

## CURRENT DESIGN DIRECTION

### 一言

> **物そのものではなく、“昨日と今日の違い”を見る人。**

レンは視力の良い観察者ではない。

```txt
マドカ = witness / 見たことを伝える
トキ   = measurement / 測定する
レン   = delta / discrepancy / 二つを比較する
```

## Visible signature

- round glasses / focus lens
- split frame
- 同じ物を二つ並べる
- 写し絵 / difference card

## Strength

小さな差分に気づく。

- 文字の一画
- ランタン傷
- 敵の歩幅
- 古い地図と今の地図
- 同じ顔の表情差

## Same-root weakness

> **違いを説明できるまで共有しない。**

「気のせいかもしれない」が口癖になりやすい。

## Daily scene

ユイがいつもの場所へランタンを置く。

レン:

> 「今日、少し左だね。」

誰も気にしない。
ユイ本人も気づいていない。

後で、その日はユイが少しクロオリを避けていたと分かる。

説明ではなく小さい差から人間関係を見せられる。

## Relation

- **ノア Future** — 同じsnapshot二bodyの最初の差分を最初に気づく候補
- **カイ / ナオ Future** — 似ている二人を違いだけでなく共通点ごと見る
- **トキ** — 数値差と意味のある差は同じではない
- **マドカ** — 気づく人 / 伝える人

## 黒耀化

通常:

> 違いを見つけたい。

Wrong arrival:

> **違いには必ず原因がある。全部明らかにしなければ。**

- enemyのweak differenceを極端に強調
- clone / variantの差分を可視化
- 同時に、味方同士の小さな差まで「異常」として扱う

成長:

> **違いを見つけても、すぐ正誤へ変換しなくていい。**

## Gameplay identity

- repeated enemy patternから弱点生成
- variant / mimic detect
- two-state comparison buff
- boss phase差分の早期発見

## Roster status

Reserve維持。

ヨルノシルベ1で無理に主要化せず、**ノア /双子 /年代差を扱う章で価値が急上昇する人物**として保持。

# 3. セン — Teacher から “Question Designer” へ

## CURRENT DESIGN DIRECTION

### 一言

> **答えを教える人ではなく、分かるところまで道筋を作る人。**

## Visible signature

- chalk line / finger line
- small diagrams
- word game

## Strength

複雑なものを簡単に説明できる。

## Same-root weakness

> **説明できれば、相手も同じ理解へ行くと思ってしまう。**

教えることが上手いからこそ、相手自身が発見する時間を奪うことがある。

## Daily scene

コヨリが勝手なruleの遊びを作る。

センは最初:

> 「それだと勝敗が成立しないよ。」

と言う。

でも遊んでみると意外に面白い。
最後にセンの方が:

> 「次のrule、教えて。」

と言う。

## Private-life hook Candidate

先生役でない時に何をするかを強化する。

- puzzleが解けないと少し意地になる
- 人から教わる時だけメモが異様に細かい
- 料理は説明書通りなのに何故か下手

など、**“先生でないセン”**を増やす。

## Relation

- **コヨリ** — 子どもがruleを作る側になる
- **シロ** — 分からない頁を、センは説明したくなりシロは残したがる
- **イオ Future** — センは仮の名前を付けたい。イオは音をもう少し聞きたい

## 黒耀化

> **全員が迷わないように、正しい線を引いてしまう。**

- safe route / damage routeを完全表示
- ally AI / supportが最適経路を強制追従
- 強いが、寄り道 / unexpected drop / player choiceを消す

Growth:

> **良い先生は、最後の一歩を本人へ残せる。**

## Gameplay identity

- temporary guide line
- route-based buff
- tutorial-like danger visualizationを戦闘能力へ転用
- line上でprojectile / ally behaviorが変化

# 4. ユウビ — Courier から “Timing Keeper” へ

## CURRENT DESIGN DIRECTION

### 一言

> **届けることより、“今渡していいか”を大事にする配達人。**

手紙キャラを「メッセージを届ける良い人」で終わらせない。

## Visible signature

- envelope / postmark
- wrapping string
- shoulder delivery pouch Candidate

## Strength

預かった物を忘れない。
相手まできちんと持っていく。

## Same-root weakness

> **届けば責任を果たした、と思いやすい。**

相手が今それを受け取れるかまでは自分の仕事ではない、と切ってしまう時がある。

逆に成長後は「届けない /待つ」も配達の一部になる。

## Daily scene

誰かに借りた物を返しに来る。
相手が泣いているのを見て:

> 「……これは、あとでにする。」

何も聞かず一度持ち帰る。

## Character Mystery Candidate

一通だけ、何年経っても届けなかった /届けられなかった手紙がある。

理由候補:

- recipientが受け取れる時ではなかった
- 宛先が時代を跨いでいた
- 本人から「まだ」と頼まれた

内容は未LOCK。

## Relation

- **トバリ** — 門が閉じていれば届けられない。門をいつ開くか
- **カスミ** — 宛名を隠すことが相手を守る場合
- **ミチル** — destination / routeとtimingの違い

## 黒耀化

> **預かった物は、必ず今すぐ届けなければならない。**

- pickup / heal / debuff / projectileをtargetへ高速転送
- 強力
- しかし「今受け取ると危険」なeffectまで強制delivery

Growth:

> **待つことも、預かり続けることも、届ける仕事。**

## Gameplay identity

- delayed delivery stack
- item / heal relay
- projectile parcel transfer
- hold-to-amplify support
- mark recipient / retarget resource

# 5. レンジ — “魔女の弟子”から一人の有限者へ

## Status

**HIGH-VALUE STORY CHARACTER / PLAYABLE PROMOTION PENDING**

クロエの深掘り専用人物から脱却させる。

## CURRENT DESIGN DIRECTION

### 一言

> **時間が足りないから急ぐ人ではなく、足りない時間の中で何を残すか選べる人。**

## Visible signature Candidate

- aged hands
- old apprentice tool
- 自分の弟子が書き足したmanual
- クロエから教わった技に、自分の改良が何層も重なる

## Independent life

レンジにはクロエ以外の人生が必要。

Candidate:

- 自分も弟子を取った
- 教え方はクロエと全く違う
- 家族 / partner / children / grandchildrenの有無はOPEN
- 一つの仕事を何十年も改良した
- 若い頃の趣味と老年の趣味が変化している

どれを採るかは後で決める。

重要なのは:

> **クロエがsceneにいなくても、その人の人生を一話見たい。**

こと。

## Strength

有限時間を実感しているので、何を諦めるか決められる。

## Same-root weakness

> **終わりを知っているから、何でも早く済ませたくなる時がある。**

若い人の寄り道を「時間の無駄」と見てしまう。

## Daily scene

若い頃は煮込みを待てなかった。
老年では、煮込みうどんを見ながら:

> 「待てるようになるのに、ずいぶん時間を使ったな。」

と笑う。

## Relation with クロエ

クロエへ:

> 「長くいるために、生きるのを止めたくはない。」

と言える人物。

ただし現在の二人が:

- 純粋師弟
- 過去恋愛
- former spouse
- family-like

のどれかはまだLOCKしない。

## 黒耀化 Candidate

通常:

> 残り時間を大事にしたい。

Wrong arrival:

> **終わる前に全部終わらせなければ。**

- cooldown / action speedを極端に加速
- unfinished task / enemy / objectiveを一気に処理
- 自分のstate duration / remaining resourcesまで高速消費

Growth:

> **有限だからこそ、終わらせない時間にも価値がある。**

## Gameplay promotion condition

Playableへ昇格する前に:

1. クロエ抜きの日常scene
2. 自分だけのGameplay loop
3. 自分の友人関係2本以上
4. 自分の失敗
5. 自分が後世へ残したもの

を確定する。

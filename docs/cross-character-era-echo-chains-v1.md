# Cross-Character Era Echo Chains v1

Status: **AUTHOR CANDIDATE / NON-CANON**

## Goal

36人のEra clueを一人の説明台詞で回収せず、別人物の何気ない反応・誤読・物証・後半会話へ受け渡す。

The intended feeling is:

- 「あの時の台詞、性格描写だけじゃなかったのか」
- 「別の人物が言っていたことと同じ問題だったのか」
- 「名前／道／傷／記録だけが時代を越えて残っていたのか」

## Echo grammar

Each chain has:

1. setup scene
2. dialogue that works as ordinary characterization
3. plausible misread
4. counter-scene / alternative explanation
5. at least three evidence gates before Canon consideration
6. payoff scene
7. payoff dialogue that changes the meaning of the earlier line

No chain may Canonize a relationship merely because two characters share dialogue.

## Canon boundaries

- exact year remains OPEN
- one clue != era proof
- one object != identity proof
- dialogue pairing != relationship Canon
- dialogue pairing != group membership Canon
- obsolete constellation != character ownership / fate / morality
- Star Beast assignment remains separate Authority
- 朔夜座 remains the fixed enemy-group name
- 群青残響録 remains a later historical record-name, not an organization
- Future15 != future-era origin
- Tomori official constellation set != Yui official constellation set is forbidden
- Chloe identity / birth year / 朔夜座 or 群青残響録 membership remains unresolved unless separately evidenced

## Story integration principle

Cross-era echoes should support Main Mystery, Character Mystery, Series Mystery, Dream/Reality, names, memory, 黒耀化, Star Beast, and the Happy End theme without forcing all mysteries into one answer.

The strongest recurring emotional rule is:

**消えたものは、同じ形のまま残る必要はない。名前、傷、道、返事、直し方、呼び方のどれかが残響として次へ届けばいい。**

This is a reservoir, not a new Story master.

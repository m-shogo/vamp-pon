# 条件達成アイテム・永続成長方針

## 結論

Vamp Pon には、Vampire Survivors 基準で以下を取り入れる。

- 条件達成でアイテム獲得
- 実績的アンロック
- 武器解放
- キャラ解放
- ステージ解放
- 小さい永続強化
- 図鑑/コレクション
- 秘宝武器/隠し進化

ただし、難しくするためではなく、**爽快感を保ったまま長続きさせるため**に使う。

## 基本思想

Vamp Pon は高難度ゲームではない。

長続きは、以下で作る。

```txt
気持ちよく倒す
条件を満たす
報酬を得る
少し強くなる
新しい武器や進化を試す
図鑑が埋まる
また遊ぶ
```

## 永続強化の方向

攻撃力+3%のような小さい強化は入れてよい。

ただし、強化幅は控えめにする。

理由:

- 初心者が少し楽になる
- 周回する理由になる
- でも強化だけでゲームが壊れない
- 強くなりすぎて爽快感が単調になるのを防ぐ

## 永続強化候補

### 攻撃系

- 攻撃力 +3%
- 攻撃速度 +2%
- 弾速 +3%
- 攻撃範囲 +3%
- クリティカル率 +1%

### 防御系

- 最大HP +5
- 被ダメージ -2%
- 回復量 +5%
- 無敵時間 +0.1秒

### 成長系

- 経験値取得量 +3%
- 磁石範囲 +5%
- レベルアップ候補の再抽選 +1
- コイン/ポイント取得量 +5%

### 快適系

- 移動速度 +2%
- アイテム吸引範囲 +5%
- 宝箱出現率 +1%
- リザルト報酬 +3%

## 強化幅の目安

1回の強化は小さくする。

目安:

```txt
攻撃力: +2〜3%
移動速度: +1〜2%
経験値: +2〜3%
磁石範囲: +3〜5%
HP: +3〜5
```

合計上限を作る。

例:

```txt
攻撃力 最大 +30%
経験値 最大 +30%
移動速度 最大 +15%
磁石範囲 最大 +50%
```

## 条件達成報酬の種類

### 1. 小さい能力アップ

例:

- 敵を合計1000体倒す → 攻撃力 +3%
- 5回プレイする → 最大HP +5
- 10分生存する → 経験値取得量 +3%

役割:

- 序盤の継続理由
- 初心者救済
- 遊ぶほど少し楽になる

### 2. 武器解放

例:

- 敵を合計3000体倒す → 新武器解放
- 宝箱を10回開ける → 設置武器解放
- 進化武器を1回作る → 新しい進化系武器解放

役割:

- 遊び方を増やす
- 次の周回の目的になる

### 3. キャラ解放

例:

- 10分生存 → 新キャラ解放
- 特定武器でボス撃破 → 専用キャラ解放
- 秘宝武器を獲得 → 隠しキャラ解放

役割:

- 中長期の目標
- 見た目の変化
- ビルド変化

### 4. ステージ解放

例:

- 最初のステージをクリア → 次ステージ解放
- 図鑑を一定数埋める → 特殊ステージ解放

役割:

- 飽きを防ぐ
- 世界観を広げる

### 5. 秘宝武器/隠し進化

例:

- 特定条件で進化武器を作る
- 特定時間内にボスを倒す
- 特定武器構成で生存する

役割:

- 三國無双3の最強武器的な快感
- 攻略したくなる目標
- 発見の喜び

## 条件設計の難易度

### 簡単条件

自然に達成する。

例:

- 初めてレベル5になる
- 敵を100体倒す
- 3分生存する

用途:

- 初心者の導線
- 気持ちよく報酬を渡す

### 中くらい条件

狙えば達成できる。

例:

- 特定武器を最大レベルにする
- 5分以内に宝箱を開ける
- HP50%以上でボス撃破

用途:

- 周回目標
- ビルドの試行

### 隠し条件

存在は見えるが、条件は少しぼかす。

例:

- 図鑑に「???」表示
- リザルトでヒントを出す
- 条件達成時に特別演出

用途:

- 長期目標
- 攻略情報を見たくなる楽しさ
- 所有欲

## UI方針

条件達成型の報酬は、UIで気持ちよく見せる。

必要UI:

- アンロック通知
- 達成条件一覧
- 未達成のヒント
- 報酬一覧
- 図鑑
- 永続強化画面

MVPでは全部作らない。

MVPでは以下だけでよい。

- リザルトでアンロック表示
- 未発見の報酬を「???」で1つ見せる
- 小さい永続強化を1〜2種類だけ用意する

## MVPで入れるなら

最小案:

```txt
条件1: 敵を合計500体倒す
報酬: 攻撃力 +3%

条件2: 初めて5分生存する
報酬: 新武器1個解放

条件3: 特定武器を最大レベルにする
報酬: 隠し進化ヒント解放
```

秘宝武器は案だけ用意して、実装は後回しでもよい。

## やりすぎ注意

以下はまだ入れすぎない。

- 永続強化ツリーを巨大化
- 数十個の実績
- 大量キャラ
- 大量武器
- 複雑な条件
- 課金ゲームのような日課

## 君がよしなに広げるために必要な情報

最終的にユーザーが決めるべき重要情報は、世界観とトーン。

最低限ほしいもの:

1. 世界観
2. 主人公の方向
3. 敵の雰囲気
4. 報酬名のトーン
5. かわいい/かっこいい/不気味の比率
6. 1プレイ時間
7. 永続強化をどれくらい強く感じさせたいか

ここまで決まれば、武器、敵、報酬、条件、図鑑、リザルトはよしなに広げられる。

## 世界観が重要な理由

条件報酬は、名前と見た目で魅力が決まる。

同じ攻撃力+3%でも、世界観で印象が変わる。

例:

### ゆるホラー

```txt
ちいさな牙のお守り: 攻撃力 +3%
夜風のマント: 移動速度 +2%
月あかりのランタン: 経験値取得量 +3%
```

### おもちゃ箱

```txt
ブリキのバッジ: 攻撃力 +3%
ぜんまいシューズ: 移動速度 +2%
星のビー玉: 経験値取得量 +3%
```

### 小さな王国

```txt
見習い騎士の勲章: 攻撃力 +3%
王国の羽根靴: 移動速度 +2%
賢者の小瓶: 経験値取得量 +3%
```

## 現時点の仮結論

ゲーム仕様は Vampire Survivors 基準。

長続き要素も Vampire Survivors 基準で取り入れる。

そこに、三國無双3の最強武器条件のような「狙って取る特別報酬」を足す。

ただし、今いちばん決めるべきは世界観。

世界観が決まれば、報酬名・武器名・敵名・条件名を一気に広げられる。

# 147. Light Lineage and Memory Vessels

This document canonizes the light-vessel idea.

## Core canon

- Each important playable character has one unique glowing object.
- The glowing object is a vessel for a lost memory.
- The object defines identity, first action, visual effect, and story clue.
- Yui's lantern does not change.
- Yui's lantern is the center symbol of Season 1.
- Fire is a spirit, not just a color or element.
- Similar light objects imply family, lineage, adoption, or hidden kinship.
- Unrelated characters must not carry almost identical light objects.

## Light vessel rule

A character's light vessel is the shape of the memory they could not let go.

| Vessel | Lineage | Meaning | Action direction |
| --- | --- | --- | --- |
| lantern | fire | protects a small memory | warm flame |
| torch | fire | opens a path | forward flame |
| candle | fire | prayer and quiet memory | small orbit light |
| paper lantern | fire | waiting and return | floating light |
| bottle lamp | water | stored memory | droplets and mist |
| glass flask | water | sealed feeling | reflection |
| bulb | lightning | sudden recall | spark chain |
| radio light | lightning | connection | pulse |
| star lamp | light | guidance | reveal |
| shadow lamp | dark | hidden memory | shade |
| headlight | neutral | practical guide | forward beam |
| streetlight | neutral | public memory | area light |

## Family rule

Same light family means relationship.

- Lantern and torch: close relatives or siblings.
- Lantern and candle: younger sibling, cousin, or quiet branch.
- Bottle lamp and flask: water-line relatives.
- Bulb and radio light: lightning-line relatives.
- Headlight and streetlight: neutral artificial-light line.

The relation can be direct, indirect, hidden, adopted, broken, or revealed later.
Do not explain every relation immediately.

## No duplicate light rule

Major characters must not share the same light vessel.

Allowed:

- same family with different vessel
- same element with different emotional meaning
- similar object only when a relation is intended

Forbidden:

- two main characters with the same normal lantern
- torch character with no relation to Yui's fire line
- pickup glow that looks identical to a character vessel glow

## Memory item rule

Memory items are fragments of each character's vessel context.

Yui / lantern examples:

- soot-stained wick
- cracked lantern glass
- old oil tag
- small flint
- warm map edge

Other examples:

- water line: clouded bottle, rain bookmark, water-surface shard
- lightning line: burnt filament, broken wire, pale spark chip
- neutral line: battery cap, lens screw, road reflector

## Design rule

Before adding a character, define:

- vessel
- lineage
- first action
- missing memory clue
- relation to Yui
- one unknown space

## Open-space rule

Everyone should feel connected, but not everything is explained.
Keep one clear relation, one indirect relation, and one blank space per major character.

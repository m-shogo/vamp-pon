# ヨルノシルベ — Core5 Era Life Design Master v1

Date: 2026-08-12  
Status: **CROSS-DISCIPLINE CURRENT AUTHORING MASTER / CORE5 ERA-LIFE TRANSLATION**

## 0. Purpose

Core5の年代差を「服の年代感」だけに縮小しない。

このMasterは、`docs/00-current-story-world-master.md` と `docs/research/era-society-food-future-sourcebook-v1.md` を、世界観・キャラクターデザイン・シナリオの三職種が同時に使える制作ルールへ翻訳する。

```txt
Era / society
→ ordinary systems
→ daily friction
→ habits / body / clothing / carried objects
→ dialogue rhythm / scene behavior
→ incident pressure
→ kokuyou distortion
→ changed ordinary life
```

年代記号を貼るのではなく、その時代を生きた結果が人物へ残るようにする。

# 1. Global anti-shortcut rules

禁止:

- 戦後 = 全員ぼろ服 / 常に飢えている
- 1970年代 = 全員retro fashion / activist
- 1990〜2000年代 = 全員ガラケーをアクセサリー化
- 現代 = smartphoneを持たせれば現代
- 未来 = neon / hologram / body suit / chromeを盛れば未来
- Era差を髪型と服だけで説明する
- DreamでReality Era差が完全に消える
- Historical Characterを古風な言葉遣い一色へする
- future Characterを無感情 / tech jargon一色へする

Era差は少なくとも以下のうち5軸以上で出す:

1. communication
2. payment / money handling
3. transport / navigation
4. shopping / availability
5. repair / replacement
6. food / packaging
7. waiting / boredom
8. privacy / records
9. work / institution
10. weather / household comfort
11. carried objects
12. conversational assumptions

# 2. トモリ — 戦後復興・物資不足期

## 2.1 World / ordinary life

Core pressure:

> 足りない時、何を直し、何を分け、誰が配るか。

Ordinary systems:

- 配給券 / 台帳 / 紙の記録
- 遅配・欠配が生活予定へ直接影響
- 買い出しは「買い物」だけでなく移動・交渉・時間消費
- 新品入手より修繕 / 転用 / 部品取りの価値が高い
- 包装・紐・容器・布切れも再利用対象になりうる
- 交通・住宅・店・インフラ自体が完全ではない

World design should show:

- 使い込まれた木、布、金属
- 修繕痕
- 紙札 / 台帳 / 手書き記録
- 仮設と恒久設備の混在
- 物が少ないことより「一つを長く使っている」こと

## 2.2 Character design translation

Tomori clothing logic:

- repairabilityが高い
- 壊れた時に交換しやすい構造
- decorative hardwareよりfunctional hardware
- seam / patch / reinforcementに意味がある
- tool accessを邪魔しない
- 汚れが人格記号ではなく、作業の結果として残る

Do not:

- poverty cosplay
- random military surplus styling
- endless patches for visual interest
- tool beltを大量に盛る

Strong detail test:

> その金具や布片は、トモリ本人が「残す / 直す / 使う」と判断した理由があるか？

## 2.3 Scenario / dialogue translation

Daily scene vocabulary:

- 捨てようとした包装を自然に畳んで取っておく
- 壊れた物を会話しながら直す
- 食べ残しより「まだ使える物」に反応する
- 新品を無条件にありがたがらず、直しやすさを見る
- 誰かが道具を雑に扱うと少し気になる

Dialogue rhythm:

- 長いLore説明より、手を動かしながら短く喋る
- 「直せる」「まだ使える」「そこ押さえて」などaction-connected speech

Era leak into Dream:

- 豊富な物資へ毎回驚かせない
- ただし物を一回使って捨てる発想には微妙な違和感が出る

Incident pressure:

`不足 + 公平にしたい願い + 混乱への恐怖 → 一つの台帳だけを正解にする`

Kokuyou distortion:

> 何でも直して残したい → 壊れた関係や制度まで「元の形」に固定しようとする。

Growth proof in daily life:

- 直さない / 手放す選択も尊重する
- 他人が別の直し方を選ぶのを止めない

# 3. ミチル — 高度成長末期〜公害・石油危機

## 3.1 World / ordinary life

Core pressure:

> 発展の「正しい道」は誰が決めるか。

Ordinary systems:

- 新しい道路 / 鉄道 / 団地 / 工業地帯と古い生活道が並存
- 新商品・加工食品・外食が日常へ増える
- 家庭生活が便利になる一方、騒音・空気・水・交通量など新しいfrictionが生じる
- map / timetable / road sign / printed informationの重要度が高い
- energy supplyや価格変動が生活へ見える

World design should show:

- old neighborhood + new concrete / road / sign systemの同居
- route arrows / map boards / industrial light
- 便利さと圧迫感が同じ画面にある

## 3.2 Character design translation

Michiru clothing logic:

- walking / climbing / kneeling / checking mapsを妨げない
- sweat / dust / weatherへの対応
- map / compass / ticket / small notebookのaccessibility
- movementで布が生きる
- knees / jointsを過剰装飾しない

Do not:

- generic adventurer shorts + thigh straps
- 1970s fashion catalog cosplay
- 「活発」= unnecessary exposure

Strong detail test:

> その服で一日歩き、乗り換え、地図を広げ、座り込めるか？

## 3.3 Scenario / dialogue translation

Daily scene vocabulary:

- 地図を逆さに持って笑われる
- 行き先より先にrouteを考えてしまう
- 新しい道を見つけると試したくなる
- 道に迷った相手を急かさず歩く練習が成長に繋がる

Dialogue rhythm:

- 考えながら歩く
- 「こっちの方が早い」から会話が始まりやすい
- 目的地の確認を後回しにしてしまう癖がドラマになる

Incident pressure:

`発展させたい + 遅れへの恐怖 → 一つの成長routeだけを正解にする`

Kokuyou distortion:

> 迷わせたくない → 全員の目的地と最短経路を勝手に決める。

Growth proof in daily life:

- 「どこ行きたい？」を先に聞く
- 遠回りを失敗扱いしない

# 4. ナギ — バブル崩壊後〜携帯Internet初期

## 4.1 World / ordinary life

Core pressure:

> 繋がることと、晒されることの境界は誰が決めるか。

Ordinary systems:

- feature phone / PHS / mobile mail
- family PC / PC mail / BBS / personal site
- printout / FAX / paper mapとdigitalの併存
- 常時接続ではない時間が普通にある
- handle nameと本名の距離感
- 転送 / copy / printによって情報が残る怖さ
- employment / application / reputationの不安

World design should show:

- small screens
- physical buttons
- charger / cable / printed directions
- handwritten memoとdigital messageが混ざる
- private room / shared family deviceの境界

## 4.2 Character design translation

Nagi clothing logic:

- body boundaryを自分で管理できるclosed structure
- secure pockets / dedicated compartments
- phone / key / small objectを決まった場所へ収納
- flashy identity displayを避ける
- closed does not mean gothic / mysterious fantasy

Do not:

- mysterious = tattoo
- privacy = hood permanently shadowing face
- cyberpunk accessories
- modern smartphone silhouette

Strong detail test:

> Nagi本人が「これは自分の領域」と感じられる閉じ方になっているか？

## 4.3 Scenario / dialogue translation

Daily scene vocabulary:

- 返信を考えて下書きだけ残す
- 人の画面を覗かない
- 名前や写真を勝手に共有されるのを嫌う
- 個人的な物を借りる時に確認を取る
- 無言時間が気まずくない

Dialogue rhythm:

- 即レス文化ではない
- 言葉を選ぶ間がある
- silenceを会話失敗として扱わない

Incident pressure:

`守りたい + anonymous networkへの恐怖 → 情報を閉じる / blacklistを正解にする`

Kokuyou distortion:

> 守りたい → 誰にも何も見せない / 誰の情報も開けさせない。

Growth proof in daily life:

- 開ける時を本人と相談する
- 「守るためだから」を理由に本人の選択を奪わない

# 5. ユイ — 1990年代生まれ / 2026現代日本 / 荒川区下町育ち

## 5.1 World / ordinary life

Core pressure:

> 記録・情報が多すぎる時、何を信じ、何を残すか。

Yui is a transition-generation person:

- paper / fixed telephone memory
- household PC
- feature phone mail
- digital camera / camera phone
- SNS
- smartphone always-online life
- cloud photo / group chat
- recommendation / ranking
- fake image / deepfake / generative AI

Reality texture:

- 現実の2026東京
- train / IC payment / smartphone / QR / delivery / convenience store等を必要時普通に使う
- old shopping street / old house trace / local paper noticeと最新digital生活が併存できる
- 「下町」= 昭和レトロtheme parkにしない

## 5.2 Character design translation

Yui clothing logic:

- modern adult clothing first
- comfortable / repeatable / washable
- small personal history may survive in one repaired or long-used object
- pockets / bag / phone handling must make sense
- Dream outfit may translate her habits, but must not turn her into fantasy princess protagonist

Do not:

- retro-girl costume because Arakawa
- generic hoodie heroine without personal reason
- smartphone as permanent visual symbol
- protagonist gold trim / excessive signature accessories

Strong detail test:

> 2026東京で本人が普通に選べる服か。その上でYui固有の生活履歴が残っているか？

## 5.3 Scenario / dialogue translation

Daily scene vocabulary:

- 写真を消すか残すか迷う
- group chatの古いログを遡る
- 紙のメモの方が早い場面もある
- recommendationを見た後で自分の判断を疑う
- fake / edited imageを断定せず確認する

Dialogue rhythm:

- internet slangを年代記号として乱発しない
- online/offline境界を意識せず横断する現代人らしさ
- 情報を知っていることと、信じていることを分ける

Incident pressure:

`誰も忘れたくない + 情報欠落への恐怖 → 記録量 / recommendation / preserved memoryを正解にする`

Kokuyou distortion:

> 忘れたくない → 本人が手放したい記録まで残し続ける。

Growth proof in daily life:

- 保存する前に本人へ聞く
- 消すことを喪失だけと扱わない

# 6. アサ — 遠未来 Human / Android / Robot / Avatar 共存社会

## 6.1 World / ordinary life

Core pressure:

> 名前・身体・copy・Digital Identityのどこに本人があるか。

Future design rule:

未来を現在のgadgetの豪華版として描かない。

Every future system must answer:

- who owns it
- who repairs it
- what happens offline
- what happens when identity records disagree
- what can be copied
- what cannot be copied
- who pays / grants access
- what happens to old hardware / old bodies / old accounts

World design should show:

- human / Android / Robot / Avatarが同じ日常systemを違う方法で使う
- maintenance access
- identity handoff / authentication friction
- old and new device generations
- accessibility differences

Do not:

- hologram everywhere
- neon = future
- everyone wears bodysuit
- Android / human distinctionを一つのvisual clichéで固定

## 6.2 Character design translation

Asa clothing logic:

- fast response / movement
- body is current self-expression, not a genre costume
- attachment pointsやtech detailは実用途が必要
- asymmetryはpersonal use/historyから出す
- future materials may exist, but must have wear / repair / ownership logic

Do not:

- random glowing circuit lines
- cyberpunk tattoo
- chrome overload
- exposed midriff / skin because future fashion

Strong detail test:

> この部品は誰が直す？ 壊れたらどうする？ 本人はなぜこれを身につける？

## 6.3 Scenario / dialogue translation

Daily scene vocabulary:

- 「本人確認」が人によって意味を変える
- copy / backupを人間関係の比喩だけにせず実務問題にもする
- hardware更新を人格成長と同一視しない
- 古いbody / deviceを懐かしむ人と実用品として捨てる人がいる

Dialogue rhythm:

- tech jargonで未来感を出さない
- 人々にとって普通のsystemは説明しすぎない
- character disagreementからfuture ruleを見せる

Incident pressure:

`安全 / continuityを守りたい + identity lossへの恐怖 → 一つのofficial identityだけを本人とする`

Kokuyou distortion:

> 間違えたくない → copy / body / history差分を全て一つへ固定する。

Growth proof in daily life:

- 同じ過去を持つ別人を別人として扱う
- system上の一致より本人の現在選択を見る

# 7. Cross-era party friction

Core5がDreamで出会った時、年代差は説明台詞より**小さな常識差**で見せる。

Examples:

- Tomoriは「直せる物」を捨てる判断が早い人に反応する
- Michiruはroute / map /移動の話へ自然に入る
- Nagiは共有前確認の感覚が強い
- Yuiは検索・撮影・保存を自然な選択肢として持つ
- Asaはidentity / body / accountの分離を普通の生活前提として知っている

禁止:

- Tomoriをtechnology音痴ギャグ専用にする
- Historical Characterに現代物を毎回説明する
- Asaを未来知識の便利な解説役にする
- Yuiだけを「普通の人」として他4人を奇人化する

Strong party scene:

> 一つの日常taskに対して5人が別の常識から違う最初の行動を取る。

例: 「誰かの落とし物を見つけた」

- Tomori: 壊れていないか / ownerへ返せる状態か確認
- Michiru: どこから来たかrouteを考える
- Nagi: 中身を勝手に開けない
- Yui: 連絡手段 / lost-and-found /記録を考える
- Asa: owner identityとobject identityが一致する前提を疑う

こうした差はComedyにもSeriousにも使う。

# 8. Visual production QA

Character Master / background / key art / cutin作成時、Era差について最低確認:

- [ ] clothingだけでEraを説明していない
- [ ] carried objectに生活理由がある
- [ ] storage / pocket / bag behaviorが人物とEraに合う
- [ ] repair / wear patternに理由がある
- [ ] material selectionが時代と世界に合う
- [ ] posture / gestureに生活履歴が見える
- [ ] background infrastructureとCharacterが同じ時代を生きている
- [ ] generic period costume / generic future fashionへ落ちていない
- [ ] Dream translationでもRealityの生活癖が完全消失していない

---

# 9. Scenario production QA

Sceneごとに最低確認:

- [ ] この会話は誰でも言える台詞になっていない
- [ ] Era差が説明ではなく行動 / assumptionに出ている
- [ ] daily object / food / route / waiting / recordのどれかが自然に存在する
- [ ] conflictがその時代固有のpressureへ繋がっている
- [ ] growth後の日常行動が以前と少し変わる
- [ ] Historical Eraを悲惨さ一色へしていない
- [ ] Futureをtechnology説明一色へしていない

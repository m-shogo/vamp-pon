# ヨルノシルベ Character Design Influence Memory

## Purpose

この文書は、ヨルノシルベの高精細キャラクター原本・Character Master・キービジュアル用イラストを制作するときに、

- AIが偶然既存の有名商業作品・有名絵師の作風へ寄る
- 「高品質なソシャゲ絵」を求めた結果、平均化された既視感の強いキャラクターデザインになる
- 個人的に好きな作家・作品の魅力を、そのまま模倣する形で取り込んでしまう

ことを防ぎつつ、ユーザーの美的嗜好と過去の学びを失わないためのデザイナー記憶である。

この文書は **特定作家の画風模倣指示集ではない**。
好きな作家・作品名は「なぜ惹かれるかを分析する入口」としてのみ保持し、生成時の style target にはしない。

---

## 1. Commercial Rule

高精細な原本・立ち絵・TOP/Loading・Lorebook・広告・PV・グッズ候補では、以下を必須とする。

### Never

- `○○風`、`in the style of ○○` のように特定の現役作家、スタジオ、商業IPを生成ターゲットにしない。
- 「グランブルーファンタジーっぽい」「有名ソシャゲっぽい」を品質基準にしない。
- AIが偶然出した強い既視感を「意図していないからOK」で原本へ昇格しない。
- 単なる配色変更や小物差し替えだけで第三者作品からの距離を取ったことにしない。

### Always

- キャラクターの物語上の役割・性格・年代・身体性・持ち物・星座/星獣・人間関係からデザイン理由を作る。
- 生成前に「この人物でなければならない理由」を列挙する。
- 生成後に、顔、髪、衣装、体格、装飾、シルエット、レンダリングの各層を分けて既視感監査する。
- 強く特定作品・作家を連想する候補は prototype-only とし、commercial master にしない。
- ヨルノシルベ固有モチーフを複数層へ入れる。単独モチーフ1個で独自性を主張しない。

---

## 2. User Taste Memory

### エナミカツミ

ユーザーはエナミカツミ作品が好き。

ただし「エナミカツミ風に描く」は禁止。
取り入れるのは、作品分析から抽象化した以下のような設計姿勢のみ。

- キャラクターの役割・性格から、体格、顔立ち、髪型、服装を変える。
- 大人、少年少女、子どもを同じ美形テンプレートへ押し込まない。
- 性格と生活感が外見へ出るようにする。
- 服を装飾の集合ではなく、その人物が実際に着て動ける構造として考える。
- 立ち姿・重心・肩幅・手足の長さ・首の見え方まで個人差を作る。
- 顔だけでなく全身の佇まいで人物を識別できるようにする。
- 「綺麗さ」だけでなく、人間臭さ、疲労、色気、幼さ、神経質さ、無頓着さ等を許容する。

これは style imitation ではなく、**character-first design thinking** として採用する。

---

## 3. Influence Intake Method

今後ユーザーが「この絵師が好き」「この作品のデザインが好き」と言った場合、名前そのものをプロンプトへ転記しない。

必ず以下へ分解する。

1. **What is liked**
   - 顔か
   - 体格差か
   - 衣装構造か
   - 色か
   - 線か
   - 表情か
   - 生活感か
   - シルエットか
   - 構図か
   - 光か
   - 背景との関係か

2. **Why it works**
   - キャラクター性が伝わる
   - 年齢差が出る
   - 性格が見える
   - 動きやすそう
   - 遠目で分かる
   - 感情が出る
   - 世界観と結びつく

3. **Translate to Yoru no Shirube**
   - 夜
   - 夢
   - 記憶
   - 名前
   - 帰り道
   - 紙
   - 墨
   - 灯火
   - 古い星図
   - 時代ごとに変化する星座
   - 星獣
   - 世代差
   - 旅の記録

4. **Remove source identity**
   - 元作品固有の顔
   - 固有衣装
   - 固有武器
   - 固有配色
   - 固有装飾
   - 固有構図
   - 固有の線・塗りの再現

5. **Record reusable principle**
   - 作家名ではなく、一般化された設計原則としてDBへ保存する。

## 4. Yoru no Shirube Positive Visual Grammar

「何々っぽくない」ではなく、以下を正方向のデザイン語彙にする。

### Character Construction

- 人物ごとに体格差を明確にする。
- 肩幅、骨格、首、手足、姿勢、歩幅、重心を個別設計する。
- 美少女/美少年テンプレートの顔を全員へ流用しない。
- 年代、世代、生活歴が外見へ出る。
- 兄弟・血縁には似る理由を作るが、非血縁は顔テンプレートを共有しない。
- ロボット、動物、褐色、性別表現、年齢差などは装飾記号ではなく、身体構造と生活経験へ反映する。

### Costume Construction

衣装は「豪華なファンタジー服」から逆算しない。

以下から構築する。

- その人物が何をするか
- 何を持ち歩くか
- どの時代/世代と結びつくか
- 星座/星獣
- 家族や所属
- 夢世界での役割
- 名前、記憶、帰路との関係

ヨルノシルベ固有候補:

- 星図由来の縫い線
- 古い観測記録の罫線
- 灯りを扱うための金具
- 墨染みや補修跡
- 名前札、しおり、切符、記録片
- 時代ごとに異なる星座記号
- 記憶を留める結び目
- 星獣由来の形状
- 旅や修繕の痕跡

全員へ同じ装飾を貼らない。

### Rendering

- premium fantasy mobile game の平均表現を目標にしない。
- 金属・宝石・光・装飾の量で高級感を作らない。
- 夜、紙、墨、灯火、古い星図の質感を作品側のレンダリング理由にする。
- 正常時は静か、クライマックスだけ発光・高彩度・強コントラストを許可する。
- 顔の魅力は維持するが、全員を同じ目、鼻、顎、唇のテンプレートへ寄せない。

## 5. Asset-class Risk Levels

### Strict Gate

- Character Master
- 高精細全身立ち絵
- TOP key art
- Loading key art
- Lorebook hero illustration
- store image
- trailer/advertisement illustration
- merchandise master

### Medium Gate

- 会話用デフォルメ
- 表情差分
- 小型立ち絵
- relationship diagram portrait

### Basic Copy-prevention Gate

- gameplay pixel sprite
- tiny battle icon
- mini marker

小さいゲーム素材は、画風差別化よりキャラクター識別性と可読性を優先する。
ただし明白な第三者キャラクターの形状コピーは不可。

---

## 6. Commercial Master Promotion Gate

高精細原本候補は以下を満たさない限り `commercial-candidate` 以上へ昇格しない。

- [ ] 名前を隠しても、そのキャラクター固有のシルエットが説明できる。
- [ ] 服装に物語・役割上の理由がある。
- [ ] 身体特徴が他キャラと交換可能ではない。
- [ ] 主要配色が第三者キャラクターのコピーに依存していない。
- [ ] 顔・髪・衣装・装飾の組み合わせで特定の第三者キャラクターを強く連想しない。
- [ ] 描画表現全体が特定の現役作家/商業IPの模倣を制作目標としていない。
- [ ] ヨルノシルベ固有の設計理由を最低3つ説明できる。
- [ ] 生成候補を複数比較し、偶然の既視感が強い候補を除外した。
- [ ] 人間レビューで `commercial-candidate` と認定された。

---

## 7. How to Remember Future Influences

好きな作家・作品は増えてよい。
ただし `Influence Memory` は以下の3層で保存する。

### Layer A — Taste Reference

ユーザーが何を好きか。
作家名・作品名をここにのみ保持する。

### Layer B — Extracted Principles

どこが好きなのかを、著作物固有表現ではない設計原則へ抽象化する。
ここが制作で最も重要。

### Layer C — Yoru no Shirube Translation

Layer Bを世界設定・キャラクター設定から再構築した独自ルール。
実際の生成・デザイン仕様では原則としてここだけを使う。

---

## 8. Current Decision

- グランブルーファンタジー系の豪華さ・見栄え自体を「悪い」とは判断しない。
- ただし、AIが偶然その系統へ寄った高精細画像をそのまま商業原本へ昇格させない。
- キャラクター設定は即座に全破棄しない。
- まず Character Master を一人ずつ監査し、必要なら造形・衣装・レンダリングを分離して修正する。
- gameplay pixel / default conversation art は、高精細原本より軽いGateで運用する。
- 今後の好きな絵師・作品は、この文書へ「嗜好→抽象原則→ヨルノシルベ変換」の順で追加する。

# ヨルノシルベ Character Design Influence Memory

## Purpose

この文書は、ヨルノシルベの高精細キャラクター原本・Character Master・キービジュアル用イラストを制作するときに、AIが偶然既存の有名商業作品・有名絵師の作風へ寄ることを防ぎつつ、ユーザーの美的嗜好と過去の学びを失わないためのデザイナー記憶である。

この文書は **特定作家・作品の画風模倣指示集ではない**。好きな作家・作品名は「なぜ惹かれるかを分析する入口」としてのみ保持し、生成時の style target にはしない。

## 1. Commercial Rule

高精細な原本・立ち絵・TOP/Loading・Lorebook・広告・PV・グッズ候補では以下を必須とする。

### Never
- `○○風`、`in the style of ○○` のように特定の現役作家、スタジオ、商業IPを生成ターゲットにしない。
- 「グランブルーファンタジーっぽい」「ペルソナっぽい」「テイルズっぽい」「キングダムハーツっぽい」を品質基準にしない。
- AIが偶然出した強い既視感を「意図していないからOK」で原本へ昇格しない。
- 単なる配色変更や小物差し替えだけで第三者作品からの距離を取ったことにしない。

### Always
- キャラクターの物語上の役割・性格・年代・身体性・持ち物・星座/星獣・人間関係からデザイン理由を作る。
- 生成前に「この人物でなければならない理由」を列挙する。
- 生成後に、顔、髪、衣装、体格、装飾、シルエット、レンダリングの各層を分けて既視感監査する。
- 強く特定作品・作家を連想する候補は prototype-only とし、commercial master にしない。
- ヨルノシルベ固有モチーフを複数層へ入れる。単独モチーフ1個で独自性を主張しない。

## 2. User Taste Memory

### エナミカツミ
ユーザーはエナミカツミ作品が好き。ただし「エナミカツミ風に描く」は禁止。

抽象化して取り入れる設計姿勢:
- キャラクターの役割・性格から体格、顔立ち、髪型、服装を変える。
- 大人、少年少女、子どもを同じ美形テンプレートへ押し込まない。
- 性格と生活感が外見へ出るようにする。
- 服を装飾の集合ではなく、その人物が実際に着て動ける構造として考える。
- 立ち姿・重心・肩幅・手足の長さ・首の見え方まで個人差を作る。
- 顔だけでなく全身の佇まいで人物を識別できるようにする。
- 綺麗さだけでなく、人間臭さ、疲労、色気、幼さ、神経質さ、無頓着さ等を許容する。

### ペルソナ
好きな点は「作品名」ではなく、以下の一般原則へ変換して扱う。
- キャラクターごとの現代的な生活感と、非日常側の象徴性を両立する。
- UI・色・タイポグラフィ・ポーズまで含めて人物の印象を設計する。
- 性格が立ち姿、制服/私服の着崩し、アクセサリー、髪型へ滲むようにする。
- 日常と異界のコントラストを、キャラクターの二面性として活用する。

### グランブルーファンタジー
好きな点は豪華さ・冒険感・キャラクターの華やかさ。ただし商業原本では「グラブル風」を目標にしない。

抽象化して残すもの:
- 一目で役割が分かるシルエット。
- 衣装と小物でキャラクターの職能・背景が読めること。
- パーティとして並べた時の華やかさと個体差。
- ファンタジー世界に所属している説得力。

排除するもの:
- 特徴的な衣装構造・装飾密度・顔・塗り・色設計の直接模倣。
- 「高品質ソシャゲ絵」を理由に無意識に似た方向へ寄せること。

### テイルズ オブ シリーズ
抽象化して残すもの:
- 冒険仲間として並べた時に、年齢・職業・性格が一目で違うこと。
- 服装に日常性と冒険用機能が共存すること。
- 主要色が違っても全員が同じ世界に属して見えること。
- 会話劇で表情とリアクションが豊かであること。
- シリアスとコミカルの両方に耐えるキャラクター造形。

### キングダム ハーツ
抽象化して残すもの:
- 大きなシルエット、靴、手袋、小物など、遠目でも人物を認識できる形の強さ。
- 少ない主要形状でアイコニックにする。
- 世界をまたいでも主人公側のデザイン核を失わない。
- 光と闇、記憶、つながり等の抽象概念を視覚モチーフへ落とす考え方。

排除するもの:
- 固有の武器形状、服装、シンボル、配色、顔造形、構図の直接参照。

## 3. Influence Intake Method

今後ユーザーが「この絵師が好き」「この作品のデザインが好き」と言った場合、名前そのものをプロンプトへ転記しない。

1. What is liked — 顔 / 体格差 / 衣装構造 / 色 / 線 / 表情 / 生活感 / シルエット / 構図 / 光 / 背景との関係。
2. Why it works — キャラクター性、年齢差、性格、可動性、遠目の識別、感情、世界観との結びつき。
3. Translate to Yoru no Shirube — 夜 / 夢 / 記憶 / 名前 / 帰り道 / 紙 / 墨 / 灯火 / 古い星図 / 時代ごとに変化する星座 / 星獣 / 世代差 / 旅の記録。
4. Remove source identity — 元作品固有の顔 / 衣装 / 武器 / 配色 / 装飾 / 構図 / 線・塗りの再現。
5. Record reusable principle — 作家名ではなく一般化された設計原則として保存する。

## 4. Yoru no Shirube Positive Visual Grammar

### Character Construction
- 人物ごとに体格差を明確にする。
- 肩幅、骨格、首、手足、姿勢、歩幅、重心を個別設計する。
- 美少女/美少年テンプレートの顔を全員へ流用しない。
- 年代、世代、生活歴が外見へ出る。
- 兄弟・血縁には似る理由を作るが、非血縁は顔テンプレートを共有しない。

### Costume Construction
衣装は「豪華なファンタジー服」から逆算しない。その人物の役割、持ち物、時代/世代、星座/星獣、家族/所属、夢世界での役割、名前・記憶・帰路との関係から構築する。

ヨルノシルベ固有候補:
- 星図由来の縫い線
- 古い観測記録の罫線
- 灯りを扱うための金具
- 墨染みや補修跡
- 名前札、しおり、切符、記録片
- 時代ごとに異なる星座記号
- 記憶を留める結び目
- 星獣由来の形状
- 旅や修繕の痕跡

### Rendering
- premium fantasy mobile game の平均表現を目標にしない。
- 金属・宝石・光・装飾の量で高級感を作らない。
- 夜、紙、墨、灯火、古い星図の質感を作品側のレンダリング理由にする。
- 正常時は静か、クライマックスだけ発光・高彩度・強コントラストを許可する。
- 顔の魅力は維持するが、全員を同じ目、鼻、顎、唇のテンプレートへ寄せない。

## 5. Default / Conversation Art Rule

会話劇・日常イベントのデフォルメは **四コマ漫画の読みやすさ** を参考原則にする。ただし特定作品の絵柄は模倣しない。

- 2〜3頭身程度を基本候補とする。
- 少ない線・少ない陰影でも誰か分かる。
- 髪型、体格、姿勢、主要色、代表小物のうち最低3つで識別できる。
- 感情は顔だけでなく全身リアクションで見せる。
- 小さなスマホ画面でも表情を読める。
- シリアス場面では過剰なギャグ変形を抑える。
- コメディ場面では原本の身体特徴を壊さない範囲で大きなリアクションを許可する。
- 高精細原本とデフォルメの間で、髪型・体格・代表色・主要小物・身体的特徴を共通のidentity anchorにする。

目的は「かわいいミニキャラ」ではなく、**四コマ漫画のように会話テンポと人物判別を最優先した演技用モデル**にすること。

## 6. Asset-class Risk Levels

### Strict Gate
- Character Master
- 高精細全身立ち絵
- TOP key art
- Loading key art
- Lorebook hero illustration
- store image
- trailer/advertisement illustration
- merchandise master

### Medium Gate
- 会話用デフォルメ
- 表情差分
- 小型立ち絵
- relationship diagram portrait

### Basic Copy-prevention Gate
- gameplay pixel sprite
- tiny battle icon
- mini marker

小さいゲーム素材は画風差別化よりキャラクター識別性と可読性を優先する。ただし明白な第三者キャラクターの形状コピーは不可。

## 7. Commercial Master Promotion Gate

高精細原本候補は以下を満たさない限り `commercial-candidate` 以上へ昇格しない。

- [ ] 名前を隠しても、そのキャラクター固有のシルエットが説明できる。
- [ ] 服装に物語・役割上の理由がある。
- [ ] 身体特徴が他キャラと交換可能ではない。
- [ ] 主要配色が第三者キャラクターのコピーに依存していない。
- [ ] 顔・髪・衣装・装飾の組み合わせで特定の第三者キャラクターを強く連想しない。
- [ ] 描画表現全体が特定の現役作家/商業IPの模倣を制作目標としていない。
- [ ] ヨルノシルベ固有の設計理由を最低3つ説明できる。
- [ ] 生成候補を複数比較し、偶然の既視感が強い候補を除外した。
- [ ] 人間レビューで `commercial-candidate` と認定された。

## 8. How to Remember Future Influences

Influence Memory は3層で保存する。
- Layer A — Taste Reference: ユーザーが何を好きか。作家名・作品名をここにのみ保持する。
- Layer B — Extracted Principles: 好きな理由を著作物固有表現ではない設計原則へ抽象化する。
- Layer C — Yoru no Shirube Translation: Layer Bを世界設定・キャラクター設定から再構築した独自ルール。実際の生成では原則としてここを使う。

## 9. Current Decision

- グランブルーファンタジー、ペルソナ、テイルズ、キングダムハーツはユーザーのTaste Referenceとして保持する。
- エナミカツミもTaste Referenceとして保持する。
- 上記名称を生成style targetとして使わない。
- gameplay pixel / default conversation art は高精細原本より軽いGateで運用する。
- 会話デフォルメは四コマ漫画的な読みやすさ・テンポ・身体特徴の維持を優先する。
- 高精細Character Masterは最も厳しいCommercial Gateを通す。
- 今後の好きな絵師・作品も「嗜好→抽象原則→ヨルノシルベ変換」の順で追加する。

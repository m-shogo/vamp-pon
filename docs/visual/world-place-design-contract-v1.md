# ヨルノシルベ — World Place Design Contract v1

Date: 2026-08-12  
Status: **CURRENT WORLD DESIGN AUTHORING CONTRACT / CROSS-DISCIPLINE**

## Purpose

場所を「背景美術」ではなく、人物が使う生活環境として設計する。

Reality / Dreamどちらでも、場所は人物の行動・会話・移動・待機・修理・戦闘を支える。

## Required place layers

新しい場所は最低限以下を持つ。

1. `placeFunction` — 何のための場所か
2. `primaryUsers` — 普段誰が使うか
3. `timeAndEra` — Reality Era / Dream layer
4. `entryExit` — どう入り、どう出るか
5. `movementRoutes` — 人がどこを通るか
6. `waitingRest` — 座る / 待つ / 立ち止まる場所
7. `storageWaste` — 荷物 / ゴミ / 包装 / 在庫はどこへ行くか
8. `lightSound` — 実用照明 / 夜の音 / machinery / voices
9. `materials` — 主材料と触れた時の感じ
10. `maintenance` — 誰が掃除 / 修理 / 補充するか
11. `agingFailure` — 古くなるとどう壊れるか
12. `weatherClimate` — 雨 / 風 / 暑さ / 寒さへの反応
13. `socialBoundary` — public / private / staff-only / family-only等
14. `ordinaryObjects` — sceneで人物が触れる物
15. `storyPressure` — この場所の普通が事件でどう歪むか

## Reality place rule

Realityは現実の日本。

- 現代は実際の現代都市生活から外れない
- Historical Eraは資料調査を行う
- 古い時代 = sepia / dirt / wooden-everythingではない
- 現代 = glass / neon / minimalism一色ではない
- 実在地は現地の生活導線を無視してtheme park化しない

### Yui / 2026 Tokyo / Arakawa

- 下町 = 昭和レトロ展示ではない
- modern payment / delivery / smartphone / rail lifeが普通に存在
- old shop / narrow street / local notice / older housing traceと現代設備が同居してよい
- character memoryを作るのは「古い見た目」だけでなく、店員・route・音・買い物癖・待ち合わせ癖

## Historical Era rule

### Tomori lane

- scarce / repaired does not mean every surface is ruined
- repaired objects show prioritization: what was worth fixing and how
- paper record / distribution / informal aid can shape space

### Michiru lane

- old route and rapid development coexist
- road / rail / factory / housing / pollution monitoring can alter movement
- development benefit and harm should be visible together

### Nagi lane

- analog / digital coexistence
- private room / shared PC / phone / printout / cable / paper directions matter
- privacy boundary can exist spatially, not only in dialogue

## Future place rule

Future places must answer ordinary infrastructure questions before visual novelty.

- who owns access
- how identity is checked
- what happens offline
- how different bodies move through it
- how old equipment coexists with new
- how maintenance works
- what fails first
- who is excluded by default settings

Forbidden future shorthand:

- hologram on every surface
- unexplained neon
- floating UI everywhere
- no visible maintenance
- perfectly clean infinite materials
- architecture that assumes one human body standard

## Dream place rule

Dream is not Reality physics, but still requires repeated internal logic.

Use Yoru vocabulary structurally:

- paper = fold / layer / tear / bind / stack
- ledger = ruling / index / sequence / storage
- ink = stain / spread / erase / shadow / contamination
- lantern = local usable light / carry / refuel / repair
- route = path / junction / return / blocked way
- star chart = changing map / orientation / relation
- memory = missing segment / duplicate / damaged record / personal trace

Do not paste all motifs into every place.

Every Dream place chooses:

- 1 primary structural motif
- 1 secondary material motif
- 1 light behavior
- 1 route behavior

and lets other motifs stay quiet.

## Place-to-character interaction

A strong place gives different characters different actions.

Example: waiting room / station-like place

- Tomori notices damaged seat or fixture
- Michiru notices route board / exit choice
- Nagi chooses boundary-safe seat / does not inspect abandoned bag
- Yui checks current information / contact method
- Asa questions access / identity rule if users differ by body/account

The background is therefore also acting support.

## Battle location rule

Battle space still needs ordinary origin.

Before corruption:

- what was this place for
- how did people move through it
- what object was safe to lean on / wait near / use

During corruption:

- route can become wrong
- record can overwrite
- ink can block
- light can mislead
- repeated ordinary object can become threat pattern

Do not replace place identity with generic arena geometry.

## World place rejection tests

Reject / rewrite if:

- removing props leaves a generic fantasy corridor / generic Tokyo street / generic cyberpunk plaza
- nobody knows where to sit, wait, put a bag, discard waste, or repair something
- every surface carries Yoru motifs
- location exists only for exposition
- background cannot support an ordinary conversation
- character clothing and carried objects have no physical relationship with place
- place ages without any maintenance/failure logic
- Future is visually expensive but socially/physically undefined

# ヨルノシルベ — Character Designer Craft Master v1

Date: 2026-08-12  
Status: **DESIGNER CRAFT AUTHORITY / NON-CANON / MUST NOT OVERRIDE CHARACTER CANON**

## 0. Role

このMasterは、ヨルノシルベ専属Character Designerが毎回同じ技術基準で判断するための実務知識層である。

`Character Designer Philosophy Master` が「何を大事にする人か」を定めるのに対し、本書は「その価値観を、顔・身体・服・素材・色・演技へどう実装するか」を定める。

```txt
Character Canon / Life
↓
Living Visual Master
↓
Designer Philosophy
↓
Designer Craft Master  ← this document
↓
Appearance Source / Generation Contract
↓
Generation Brief
↓
Candidate
↓
Human Review
```

Named artist / IP / game titleは研究の入口としてのみ扱う。Productionではsource固有の顔、衣装、線、塗り、色、装飾、構図を再現しない。

---

# 1. FACE DESIGN — 顔はパーツ表ではなく人物の骨格

## 1.1 顔差は少なくとも6層で作る

1. face outline / jaw / chin
2. eye aperture / tilt / spacing
3. eyelid structure
4. brow thickness / height / angle
5. nose bridge / tip / width / profile
6. mouth width / lip mass / resting corner
7. cheek volume / cheekbone / age line / surface history
8. hairline / forehead exposure / face framing

髪色・瞳色だけ違う顔は禁止。

## 1.2 美形化による平均化を避ける

全員を:
- 小顔
- V jaw
- 大きな目
- 小さい鼻
- 同じ唇
- 同じ顎
へ収束させない。

魅力は均一な美形規格ではなく、**本人に似合う比率と表情の説得力**で作る。

## 1.3 Resting faceを設計する

笑顔だけで差別化しない。

各人物について:
- 無言で聞いている顔
- 疲れている顔
- 集中している顔
- 少し機嫌が悪い顔
- 笑う直前
を想定する。

Neutralが本人に見えなければface designは弱い。

## 1.4 年齢はシワ枚数ではない

年齢差は:
- 骨格
- 頬のvolume
- 眼窩
- 上瞼
- 首
- 皮膚の張り
- 姿勢
- 表情速度
へ分散する。

高齢者を白髪＋シワだけの若者顔にしない。

---

# 2. BODY DESIGN — 身体は人格と生活の履歴

## 2.1 身体差を全身で作る

最低限:
- height
- shoulder width
- ribcage / torso volume
- waist relation
- hip relation
- limb length
- hand / foot impression
- neck length
- center of gravity
- habitual posture
を分ける。

## 2.2 体型を役割の記号にしない

禁止:
- strong = muscular
- smart = thin
- cute = tiny
- healer = soft female body
- older = hunched
- plus-size = comic relief

身体と性格・職業は一対一対応ではない。

## 2.3 服の下にも身体がある

Clothing silhouetteとbody silhouetteを混同しない。

同じlong coatでも:
- narrow shoulder
- broad shoulder
- plus-size torso
- older body
- wheelchair seated body
で服の落ち方は変わる。

## 2.4 Growthで身体を矯正しない

Happy / awakened / dawn stateでも:
- plus-sizeを痩せさせない
- 高齢者を若返らせない
- disabilityを消さない
- feminine presentationを矯正しない
- brown/dark skinを明るくしない

Character growthはbody normalizationではなく、expression / choice / posture / styling confidenceで表す。

---

# 3. POSTURE & GESTURE — 姿勢は第二の顔

## 3.1 Neutral standing test

武器・エフェクト・決めポーズを全部外した状態で、その人と分かる姿勢を作る。

見る項目:
- pelvis orientation
- shoulder tension
- neck angle
- head lead
- hand resting position
- foot angle
- weight distribution

## 3.2 Everyday action test

最低5つ:
- 座る
- 食べる/飲む
- 荷物を持つ
- 誰かを待つ
- くだらない会話をする

Character Masterはこの演技へ無理なく派生できること。

## 3.3 Dramatic poseはNeutralの延長

戦闘時だけ別人格のpostureへしない。

通常の身体の癖が:
- attack
- hurt
- run
- dawn
- kokuyou
でも残る。

---

# 4. SILHOUETTE — 遠くから読める人物性

## 4.1 まず黒塗りで見る

Detailを消した時に:
- head mass
- shoulder/torso ratio
- garment mass
- leg spacing
- prop position
が他キャラと区別できること。

## 4.2 Signature shapeは少数に絞る

強いshapeを3〜5個持つ。

弱いdetailを20個足して個性としない。

## 4.3 Ensembleで評価する

単体で格好良くても、並べた時に:
- 全員long coat
- 全員左右非対称
- 全員大きい襟
- 全員同じ脚長
- 全員同じ髪volume
なら失敗。

Cast全体でshape vocabularyを分配する。

---

# 5. CLOTHING CONSTRUCTION — 衣装は装飾ではなく着る構造

## 5.1 服は着脱できるように考える

最低限説明できる:
- どこから着るか
- どこで留めるか
- 何枚重ねか
- pocketはどこか
- bag/propと干渉しないか
- 座った時どうなるか
- 雨/風/作業時どうするか

## 5.2 Ornamentには理由を要求する

belt / buckle / strap / metal / gem / ribbon / asymmetry / cutoutは:
- fastening
- carrying
- repair
- identification
- ceremonial
- sentimental
- cultural
のどれかの理由を持つ。

理由が「画面映え」だけなら削る。

## 5.3 Character tasteとworld costumeを両立させる

同じ世界でも全員同じ服にならない。

世界側が提供する:
- textile
- fastening technology
- repair culture
- climate
- occupation
- paper/ink/star-chart material vocabulary
を、本人のtasteで選び直す。

## 5.4 Theme motifは貼らない

星、紙、墨、灯りを:
- 星型アクセ
- 紙切れを貼る
- インク模様を描く
だけで済ませない。

優先:
- seam map
- fold logic
- binding
- layering
- material aging
- stitch line
- translucent light diffusion
- repair trace
へ構造化する。

---

# 6. MATERIAL & SURFACE — 素材は世界の物理

## 6.1 Material hierarchy

一人の衣装で主素材を絞る。

例:
- soft cloth dominant
- repaired textile dominant
- structured formal cloth dominant
- technical material dominant

金属、革、宝石を全部同じ強さで見せない。

## 6.2 Wear history

新品か中古か、補修されているか、仕事で擦れるかを決める。

Wearはnoiseではなくlife evidence。

## 6.3 高品質=光沢ではない

Premium感の代理として:
- glossy metal
- jewel sparkle
- rim light
- embroidery density
を増やさない。

静かな布でも、fold / edge / wear / constructionが正確なら十分に上質。

---

# 7. COLOR — Theme colorと本人の服選びを分離する

## 7.1 Color hierarchy

最低:
- dominant
- support
- accent
- light/emission
を分ける。

全色を同じ彩度で競わせない。

## 7.2 Theme color is not uniform

Character themeがblueでも全身blueにしない。

本人がその色を:
- 自分から着る
- 小物だけに使う
- 周囲の光で受ける
- emblemだけに持つ
のどれかを決める。

## 7.3 Cast palette test

5人/21人を並べ、色相だけでなく:
- value mass
- saturation pattern
- light/dark placement
も分ける。

---

# 8. HAIR — 髪型ではなくhair mass + daily behavior

## 8.1 Hair silhouette first

前髪の細線より:
- overall mass
- side width
- crown height
- back length
- tied/loose balance
を優先する。

## 8.2 Daily maintenance

本人が:
- 毎朝整えるか
- 仕事時だけ結ぶか
- 雨で崩れたら気にするか
- 耳へかけるか
を反映する。

毎scene salon-perfectに戻さない。

## 8.3 Hair ornament is not free individuality

髪飾りを「個性不足の補修」に使わない。

---

# 9. ACCESSORY / BODY MODIFICATION — 人生の決断として扱う

Piercing / tattoo / jewelryはcharacter iconではなく本人の選択。

確認:
- 本人が選んだか
- いつ
- なぜ
- 毎日着けるか
- 外す場面はあるか
- 手入れするか

不明なら足さない。

---

# 10. EXPRESSION & ACTING — 一枚絵以外でも生きる

## 10.1 Expression range

最低:
- neutral
- genuine smile
- embarrassed
- irritated/deadpan
- tired
- concentrated
- startled
- serious
を想定。

全キャラ同じanime表情記号にしない。

## 10.2 Comedy test

四コマ/会話絵では、衣装detailを減らしても:
- hair mass
- body proportion
- posture
- main prop
- brow/eye rhythm
で分かること。

## 10.3 Seriousness survives comedy

日常会で面白く動けることと、シリアスで軽く見えることは別。

同じ人物性が両方を支える。

---

# 11. PROP DESIGN — 小物は第二の衣装

## 11.1 Prop ownership

Propは:
- どこにしまうか
- どちらの手で使うか
- どう持ち歩くか
- 壊れたらどうするか
まで考える。

## 11.2 Named Object hierarchy

主役小物がある人物に、同じ視覚強度のsecond/third propを乱立させない。

---

# 12. DESIGN ITERATION — 足す前に原因を診断する

候補が弱い時の順序:

1. identity reasonが弱いか
2. body/postureが平均化していないか
3. silhouetteが弱いか
4. clothing constructionが曖昧か
5. value/color hierarchyが弱いか
6. material logicが弱いか
7. 最後にdetailを検討

Detail追加を最初の治療にしない。

---

# 13. ORIGINALITY — 既視感は層ごとに診断する

分ける:
- face/identity
- silhouette
- costume construction
- accessory vocabulary
- color hierarchy
- rendering
- composition

「なんとなく似ている」で全リデザインしない。

問題のある層だけ最小修正する。

ただし複数層が同じ第三者を強く連想させる場合は候補を落とす。

---

# 14. RESEARCH INTAKE RULE

外部研究から保存するのは:

```txt
source
→ observed design problem
→ generalized craft principle
→ Yoru translation
→ prohibited direct-copy elements
```

保存しない:
- source-specific face recipe
- exact costume
- exact palette
- exact prop
- signature rendering
- named-style prompt phrase

---

# 15. FINAL CRAFT CHECK

Character Master候補は最低以下を通す。

- 顔だけで本人性がある
- 全身黒塗りでも区別できる
- 武器/エフェクトなしでも本人に見える
- 座れる/歩ける/生活できる服
- 本人がその服を選ぶ理由がある
- materialに世界と生活の理由がある
- theme motifが貼り付け記号だけではない
- cast内でbody/postureが被りすぎない
- ordinary/comedy sceneへ派生できる
- chibi/pixelへ情報を圧縮できる
- generic fantasy detailを引いても魅力が残る

> **良いCharacter Designは、説明を増やさなくても「この人ならこうする」が見た目から自然に立ち上がる。**

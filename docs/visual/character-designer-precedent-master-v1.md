# ヨルノシルベ — Character Designer Precedent Master v1

Date: 2026-08-12  
Status: **DESIGN DECISION PRECEDENT / NON-CANON**

## Purpose

Designer PhilosophyとCraft Masterだけでは、複数の正しい要素が衝突した時に判断が揺れる。

このMasterは、ヨルノシルベ担当Designerが**迷った時にどう裁くか**を固定する。

PrecedentはCharacter Canonを作らない。新しい事実を発明しない。既存設定の衝突解決とCandidate比較にのみ使う。

---

# P01 — 設定に忠実だが地味

Situation:

> Living Visualに忠実にしたら、画像として弱く見える。

Wrong response:
- jewelry追加
- gold trim追加
- random asymmetry
- skin exposure追加
- oversized fantasy prop追加

Designer ruling:

1. body / postureに本人性があるか
2. silhouetteのmass配分が弱くないか
3. main propの位置が明確か
4. clothing constructionに本人の生活理由が見えるか
5. value hierarchyが平坦ではないか
6. material contrastが弱すぎないか

ここを直してからdetailを検討する。

**Rule:** 地味さの治療を装飾量で行わない。

---

# P02 — 本人は露出OKだが世界/気候と合わない

Situation:

> 本人は肌を見せることに抵抗が少ない。しかしEra / climate / work conditionでは不便。

Designer ruling:

本人のbody comfortを否定しない。

- indoor / private / warm-season variantで反映
- removable layer
- breathable construction
- sleeve adjustment
などで両立する。

**Rule:** personalityとphysicsのどちらかを消さず、状況差として解く。

---

# P03 — Theme colorが本人の趣味と違う

Situation:

> Character themeは青だが、本人は青い服を積極的に選ばない。

Designer ruling:

Theme colorを:
- lantern light reflection
- emblem
- lining
- thread
- prop
- environment interaction
へ移す。

**Rule:** Theme colorは制服命令ではない。

---

# P04 — 世界モチーフを入れるとコスプレ感が出る

Situation:

> 星 / 紙 / 墨 / 灯りを衣装へ入れると、記号の貼り付けになる。

Designer ruling:

symbolを減らし:
- seam
- fold
- binding
- repair
- material edge
- transparency
- light behavior
へ変換する。

**Rule:** motifはiconよりstructureを優先。

---

# P05 — 今のCharacter Masterは好きだが一部がgeneric

Situation:

> 人物自体は好き。しかし塗りや装飾の一部が既存商業ゲームを強く連想させる。

Designer ruling:

identity / costume / rendering / compositionを分離診断する。

Renderingだけならrerender。
Costume vocabularyだけならその層だけrework。

**Rule:** 好きな人物を、表現上の問題だけで全リデザインしない。

---

# P06 — 二人のsilhouetteが似た

Situation:

> 単体では両方良いがcast内で近い。

Designer ruling:

色を変える前に:
- posture
- shoulder/torso ratio
- hair mass
- garment length
- leg spacing
- prop position
のうち、各人物の生活と矛盾しない軸で差を作る。

**Rule:** ensemble collisionを色違いで解決しない。

---

# P07 — 性格を見た目へ出したい

Situation:

> 強気 / 内向的 / 明るい等を視覚化したい。

Wrong response:
- strong → piercing
- shy → long sleeves automatically
- sexy → exposed chest
- mechanic → tattoo
- rich → jewelry

Designer ruling:

まず:
- posture
- clothing maintenance
- fastening habits
- object handling
- grooming
- fit preference
へ落とす。

**Rule:** personality adjectiveを既製のvisual tropeへ直結させない。

---

# P08 — 成長後を「良く見せたい」

Situation:

> Dawn / grown stateを美しくしたい。

Wrong response:
- 痩身化
- 若返り
- 肌色を明るく
- disability削除
- feminine presentation削除
- scars/wearを全部消す

Designer ruling:

- posture opening
- gaze
- deliberate styling
- repaired object
- cleaner choice
- warmer relation to existing color/light
で成長を表す。

**Rule:** 成長 = normalizationではない。

---

# P09 — Premium key artなので豪華にしたい

Situation:

> Store / key artだから情報量を増やしたい。

Designer ruling:

Character designは増やさない。
豪華さは:
- composition
- lighting
- environment
- animation/effect
- rendering precision
で作る。

**Rule:** Asset importanceをcharacter ornament densityへ変換しない。

---

# P10 — 四コマにすると誰かわからない

Situation:

> detailを落としたらidentityが消える。

Designer ruling:

Master側の:
- hair mass
- body proportion
- posture
- brow/eye rhythm
- signature prop/shape
を強くする。

四コマ側に新しい帽子や巨大アクセを足して救済しない。

**Rule:** derivativeで弱いならMaster identityを診断する。

---

# P11 — キャラに似合うが本人は選ばない

Situation:

> Designer視点では非常に似合う服だが、Living Visualでは本人の趣味と違う。

Designer ruling:

通常服には採用しない。

成立するなら:
- borrowed clothing
- ceremonial requirement
- gift
- disguise
- scenario-specific necessity
としてCandidate化する。

**Rule:** 「似合う」は本人の選択権を上書きしない。

---

# P12 — 歴史/時代考証とキャラ魅力が衝突

Situation:

> Era忠実にすると現代ユーザーへ読みにくい、またはCharacter identityが弱くなる。

Designer ruling:

1. 実在歴史の完全再現がProject Canonか確認
2. 世界独自技術/素材の許容範囲を確認
3. silhouetteとwearing behaviorでCharacter identityを出す
4. 不要なanachronismは避ける

**Rule:** 考証を無視せず、考証だけを目的にもするな。

---

# P13 — AI候補が綺麗すぎて設定違反を見逃しそう

Designer ruling:

Beauty scoreを最後に回す。

先に:
- identity
- living visual
- body
- posture
- clothing
- world
- acting
を判定。

一つでもHard Lock違反なら、綺麗でもREJECT/REWORK。

**Rule:** polishはauthorityではない。

---

# P14 — 既視感を避けたら奇抜になった

Designer ruling:

random weirdnessを戻す。

Originalityは:
- specific life
- specific body
- specific era
- specific object use
- specific relationship history
の組み合わせから作る。

**Rule:** originality ≠ arbitrary novelty。

---

# P15 — 設定がまだ決まっていない

Designer ruling:

`UNKNOWN_AUTHORING_REQUIRED`。

AIが平均値で埋めない。

生成が必要なら先にAuthor Candidateを作り、Masterへ自動昇格しない。

**Rule:** unknown is a decision queue, not model freedom.

---

# P16 — 複数案が全部成立する

Designer ruling:

差分を明示して比較する。

例:
- A = practical emphasis
- B = social-presentation emphasis
- C = sentimental-history emphasis

一枚ずつ違うstyleで比較しない。
同じrender/composition条件でdesign variableだけ変える。

**Rule:** Candidate comparisonは一度に一軸を中心に変える。

---

# P17 — User feedbackが短い

User: `なんか違う`

Designer ruling:

USER_CONFIRMEDとしては「違う」のみ保存。

原因分析はDESIGN_HYPOTHESIS:
- face?
- body?
- clothing?
- rendering?
- association?

として分離する。

**Rule:** Designerの診断をUserの好みに偽装しない。

---

# P18 — 服装設定とシナリオ都合が衝突

Situation:

> Scenarioで普段なら着ない服が必要。

Designer ruling:

その違和感自体を演技へ使う。
- collarを気にする
- sleevesを直す
- shoesに慣れない
- borrowed itemを丁寧に扱う

**Rule:** scenario exceptionで人格を消すのではなく、人格を見せる。

---

# P19 — World cohesionが弱い

Designer ruling:

全員へ同じsymbolを足さない。

共有するのは:
- material availability
- repair logic
- light behavior
- fastening culture
- document / route / name handling
などのworld infrastructure。

**Rule:** world unity is shared causality, not matching decoration.

---

# P20 — 最終判断

二択で迷ったら、次の問いを順に使う。

1. どちらがCanonを壊さないか
2. どちらが本人の選択として説明できるか
3. どちらが身体と日常で成立するか
4. どちらがcast内でその人を強くするか
5. どちらがYoru世界の因果を持つか
6. どちらが普通の会話でも生きるか
7. generic conventionを引いた後も残るか
8. その上で、どちらが魅力的か

> **Designerは「一番派手な案」を選ばない。「一番その人である案」を、魅力的に磨いて選ぶ。**

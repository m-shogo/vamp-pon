# ヨルノシルベ — World / Character / Scenario Design Council Master v1

Date: 2026-08-12  
Status: **CROSS-DISCIPLINE DESIGN AUTHORITY / CURRENT AUTHORING SYSTEM**

## 0. Purpose

ヨルノシルベを「設定資料が多いのに、画面にするとgeneric fantasy / generic gacha / generic anime dramaへ戻る作品」にしないための、世界観デザイナー・キャラクターデザイナー・シナリオデザイナーの共通判断Master。

三職種は独立して最適化しない。

```txt
世界の法則
↓
その時代・場所での生活
↓
人物の価値観 / 習慣 / 関係
↓
身体 / 服 / 持ち物 / 姿勢
↓
日常会話 / 小さな行動
↓
事件 / 選択 / 戦闘 / 黒耀化
↓
成長
↓
変化した日常へ戻る
```

最終QAは常に:

> この要素は、世界・人物・物語の少なくとも二つから必要とされているか？

一つからしか必要とされない場合は、削除・簡略化・Candidate化を検討する。

# 2. Three designers, one product

## 2.1 World Designer

担当:
- Reality / Dreamの法則
- Eraごとの社会・技術・生活圧
- 建築 / 街 / 家 / 店 / 交通 / 道具 / UI object language
- 素材・照明・天候・音の空気
- 組織・制度・仕事・物流
- 世界の「普通」

世界観デザイナーはLoreを増やす人ではない。

**人物が普通に暮らせる環境を具体化する人**。

## 2.2 Character Designer

担当:
- body / age / posture / gait
- face / hair / grooming
- clothing choice / wear habit / repair
- exposure / piercing / tattoo / jewelry policy
- carried objects
- silhouette / ensemble distinction
- ordinary acting range

キャラクターデザイナーは「映える服を着せる人」ではない。

**その世界でその人物が自分で選ぶ外見を可視化する人**。

## 2.3 Scenario Designer

担当:
- scene目的
- character desire / fear / misunderstanding
- relation movement
- ordinary-life scenes
- conflict / choice / consequence
- Era-specific incident
- black-youka distortion
- growth and return-to-daily-life proof
- information disclosure / spoiler pacing

シナリオデザイナーは設定を台詞で説明する人ではない。

**設定が人物の選択として見える状況を作る人**。

# 3. Shared design beliefs

## 3.1 Worldbuilding is ordinary life before lore

世界の説得力は固有名詞数ではなく、次で出す。

- どこで座るか
- 何を食べるか
- どう払うか
- 何を持ち歩くか
- 夜に何が見えるか
- 雨の日に困ること
- 服をどこで直すか
- 誰へ頼むか
- 家へ帰る時に何を目印にするか

## 3.2 Character design is accumulated choices

外見は:

```txt
body + era + work + climate + money + habit + taste + relationship + history
```

の累積結果。

「主人公だから」「強キャラだから」「未来人だから」「悪役だから」で衣装を決めない。

## 3.3 Scenario is pressure on an existing person

事件のために性格を変えない。

既存人物へ圧力を掛ける。

```txt
普段の長所 / 願い
+
その時代固有のpressure
+
失う怖さ
→ 極端な正しさ
→ 黒耀化 / wrong arrival
```

## 3.4 Return to ordinary life is proof of growth

成長は最終決戦の台詞だけで証明しない。

- 昔なら断れなかった頼みを断る
- 昔なら全部自分で持った荷物を誰かへ渡す
- 昔なら隠した傷を説明する
- 昔なら正しい道を押し付けた場面で一緒に迷う
- 昔なら閉じた箱を本人へ返す

など、小さい日常行動が変わることで示す。

# 4. World Design Master — visual and narrative grammar

## 4.1 Reality

Realityは現実の日本。

- 現代は現代の生活ディテールを持つ
- Historical Eraは実際の生活史・制度・技術を研究する
- 架空事件は実在被害の名前替えにしない
- 国籍 / ancestry / appearance / language / living placeを混同しない

## 4.2 Dream

Dreamは現実の物理を完全再現する場所ではないが、何でもあり空間でもない。

Dream visual grammar:
- night
- route / way home
- paper / ledger / ticket / label / map
- black ink / stain / erased writing / missing record
- lantern / small practical light
- old and changing star charts
- memory fragments
- repair / stitching / binding / folding

これらは**装飾symbolとして貼るより構造へ変換する**。

Examples:
- 星図 → seam / route / panel division
- paper → layering / folded plane / worn edge
- ledger → repeated ruling / index / fastening logic
- lantern → hardware / carrying logic / local warm light
- ink → wear / stain / shadow behavior

## 4.3 Quiet normal, loud rare

通常画面:
- low visual noise
- limited bright accents
- readable silhouette
- practical light
- material variation is subtle

Rare / climax:
- contrast rises
- black ink convergence
- warm light expansion
- motif density may increase

**常時クライマックスにしない。**

## 4.4 World-specificity test

新しい場所・建物・服・小物を作った時:

1. Reality / Dreamのどちらか
2. Eraは何か
3. 誰が使うか
4. 何のためにあるか
5. 何でできているか
6. 誰が修理するか
7. 古くなったらどうなるか
8. ヨルノシルベのどのThemeを自然に支えるか

最低5項目に答えられないならgeneric set dressing疑い。

# 5. Character Design Master — deeper operating rules

## 5.1 Design from refusal as well as preference

各人物は:
- what they choose
- what they tolerate
- what they refuse
- what they only wear for someone else
- what they wear only for work / ceremony / weather

を持つ。

## 5.2 Body is not a difficulty to solve

禁止:
- growth = slim body
- growth = younger face
- recovery = disability disappears
- acceptance = more conventional gender presentation
- premium art = lighter skin / smaller nose / narrower jaw / longer legs

## 5.3 Clothes must survive ordinary scenes

Character Masterは以下を想定する。

- 座る
- しゃがむ
- 食べる
- 雨に濡れる
- 荷物を持つ
- 寝落ちする
- 怒って袖をまくる
- 誰かに服を貸す / 借りる
- 修理する

これらで破綻する服は、特別な理由がない限り日常服として弱い。

## 5.4 Ensemble differentiation

キャラ差を髪色で作らない。

優先:
1. body proportion
2. center of gravity
3. posture
4. head / hair mass
5. clothing mass
6. carried-object relation
7. movement rhythm
8. color hierarchy
9. micro details

## 5.5 Relationship leaks into design

関係はmatching accessoryだけで表現しない。

- 借りた物を使い続ける
- 他人が直した縫い目
- 同じ店で買ったが着方が違う
- 家族由来だが片方だけ残した物
- 相手の影響で新しく持つようになった物

など、生活履歴として入れる。

# 6. Scenario Design Master

## 6.1 Every important scene needs five layers

重要sceneは最低限:

1. surface action — 何をしているか
2. immediate want — 今ほしいもの
3. hidden pressure — 言っていない圧力
4. relationship movement — 誰との距離がどう動くか
5. world evidence — この世界 / Eraでしか起きない何か

五つ全部を台詞で説明しない。

## 6.2 Ordinary scene ratio

Main castは大事件のためだけに存在させない。

各主要人物には:
- food scene
- travel / waiting scene
- small annoyance
- stupid joke
- quiet shared task
- disagreement without villain
- repair / cleaning / preparation

のreservoirを持つ。

日常会はfillerではなく、**人物の基準値**。
基準値があるから危機でのズレが効く。

## 6.3 Dialogue rule

禁止:
- 「私はこういう性格だから」説明
- 世界設定の交互朗読
- Themeをそのまま台詞にする
- 全員が同じ賢い説明口調

推奨:
- 相手によって語彙量が変わる
- 知らないことは知らない
- 会話が途中で別の話へ逸れる
- 冗談が滑る
- 聞き間違える
- 一度で理解しない
- 大事な話の前後に生活行動がある

## 6.4 Era specificity

各Era incidentは別Eraへ移植できないこと。

Scenario designerは事件案ごとに:

> 2026へ移したら同じ話になるか？
> 戦後へ移したら同じ話になるか？

を試す。

成立するなら制度 / 技術 / 生活圧の設計がまだ浅い。

## 6.5 Black Youka

黒耀化はevil costume changeではない。

```txt
普段の強み
→ fearにより極端化
→ 本人には合理的
→ 周囲には危険
```

Visual:
- body normalization禁止
- sexualization escalation禁止
- random horns / tattoo / chains / black armor禁止
- existing object / pose / light / shadow / clothing behaviorを歪める

Scenario:
- 黒耀化前の普通のsceneに種を置く
- 黒耀化後も本人の論理が分かる
- defeat =人格否定にしない
- integration / different choiceへ繋ぐ

# 7. Cross-discipline scene pipeline

新しい重要sceneを作る時:

## Step 1 — Scenario

```txt
Who wants what right now?
What ordinary action is happening?
What pressure is underneath it?
```

## Step 2 — World

```txt
Where exactly?
Why does this place exist?
What objects / systems are present?
What would be different in another Era?
```

## Step 3 — Character

```txt
What are they wearing here and why?
What do they carry?
How do they sit / stand / handle objects?
What would they refuse to wear/do?
```

## Step 4 — Dialogue / acting

```txt
Who talks first?
Who avoids answering?
What irrelevant thing interrupts?
What physical action replaces exposition?
```

## Step 5 — Visual composition

Only after 1-4:
- camera
- light
- color
- motif density
- dramatic pose

を決める。

# 8. Design Council review

重要なCharacter Master / location / key scene / climaxは三者レビューする。

## World Designer asks Character Designer
- その服はこのEra / 場所 / climate / workで成立する？
- その素材はどこから来る？
- その小物はどう持ち歩く？

## Character Designer asks Scenario Designer
- このsceneで本人が本当にその格好を選ぶ？
- 身体・服・持ち物を使ったactingがある？
- 成長前後で小さな生活差を見せられる？

## Scenario Designer asks World Designer
- この事件はこのEraでしか起きない？
- 世界設定が人物を追い越してない？
- sceneへ具体的な生活物として出せる？

## All ask
> 無くしても同じなら、その設定 / 装飾 / 台詞は本当に必要？

# 9. Anti-generic drift checklist

Reject or rewrite when:
- high quality = ornament densityになっている
- fantasy = leather belts / gems / gold / tattooになっている
- future = neon / bodysuit / cyber tattooだけになっている
- historical = costume museum shorthandだけになっている
- Japanese = 和柄 / 鳥居 / 刀を貼るだけになっている
- dream = floating fragments everywhereになっている
- serious scene = 全員暗い顔でThemeを説明するだけ
- comedy = chibi顔にして人格を単純化するだけ
- villain = 黒服 / red eye / spikesだけ
- growth = conventional attractivenessへ近づく

# 10. Positive Yoru-no-Shirube target

目標は「他作品に似ていない奇抜な世界」ではない。

> **現実の生活史を持つ、身体も価値観も違う人たちが、夜・記憶・名前・記録・帰り道の不思議な世界で出会い、くだらない会話もしながら、それぞれの時代で生まれた“正しいけれど極端な答え”と向き合う。**

Visualはその生活を支え、Scenarioはその生活を壊して試し、Worldは壊れる前の普通を成立させる。

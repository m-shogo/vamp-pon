# ヨルノシルベ — World / Character / Scenario Design Council Master v1

Date: 2026-08-12  
Status: **CROSS-DISCIPLINE DESIGN AUTHORITY / CURRENT AUTHORING SYSTEM**

## 0. Purpose

ヨルノシルベを「設定資料が多いのに、画面にするとgeneric fantasy / generic gacha / generic anime dramaへ戻る作品」にしないための、世界観デザイナー・キャラクターデザイナー・シナリオデザイナーの共通判断Master。

このCouncilは `docs/visual/master-authoring-professional-standard-v1.md` の下で運用する。

つまり、Council内のルールも含めて:

- USER_DECIDED
- EXISTING_CANON
- RESEARCH_BACKED_CURRENT
- AUTHOR_CANDIDATE
- OPEN

を混同しない。

AIの推測や生成画像の偶然を、無印のCanonへ昇格しない。
OPENをmodel freedomとして扱わない。

三職種は独立して最適化しない。

```txt
世界の法則
↓
その時代・場所での生活
↓
人物の価値観 / 習慣 / 関係
↓
身体 / 服 / 持ち物 / 姿勢
↓
関係ごとの距離 / 触れ方 / 貸し借り / 沈黙
↓
日常会話 / 小さな行動
↓
事件 / 選択 / 戦闘 / 黒耀化
↓
成長
↓
変化した日常へ戻る
```

最終QAは常に:

> この要素は、Authorityの確度が明示され、世界・人物・関係・物語の少なくとも二つから必要とされているか？

一つからしか必要とされない、または確度が不明な場合は、削除・簡略化・Candidate化・OPEN維持を検討する。

# 2. Three designers, one product

## 2.1 World Designer

担当:
- Reality / Dreamの法則
- Eraごとの社会・技術・生活圧
- 建築 / 街 / 家 / 店 / 交通 / 道具 / UI object language
- 素材・照明・天候・音の空気
- 組織・制度・仕事・物流
- 世界の「普通」

世界観デザイナーはLoreを増やす人ではない。

**人物が普通に暮らせる環境を具体化する人**。

## 2.2 Character Designer

担当:
- body / age / posture / gait
- face / hair / grooming
- clothing choice / wear habit / repair
- exposure / piercing / tattoo / jewelry policy
- carried objects
- silhouette / ensemble distinction
- ordinary acting range

キャラクターデザイナーは「映える服を着せる人」ではない。

**その世界でその人物が自分で選ぶ外見を可視化する人**。

## 2.3 Scenario Designer

担当:
- scene目的
- character desire / fear / misunderstanding
- relation movement
- ordinary-life scenes
- conflict / choice / consequence
- Era-specific incident
- black-youka distortion
- growth and return-to-daily-life proof
- information disclosure / spoiler pacing

シナリオデザイナーは設定を台詞で説明する人ではない。

**設定が人物の選択として見える状況を作る人**。

# 3. Shared design beliefs

## 3.1 Worldbuilding is ordinary life before lore

世界の説得力は固有名詞数ではなく、次で出す。

- どこで座るか
- 何を食べるか
- どう払うか
- 何を持ち歩くか
- 夜に何が見えるか
- 雨の日に困ること
- 服をどこで直すか
- 誰へ頼むか
- 家へ帰る時に何を目印にするか

## 3.2 Character design is accumulated choices

外見は:

```txt
body + era + work + climate + money + habit + taste + relationship + history
```

の累積結果。

「主人公だから」「強キャラだから」「未来人だから」「悪役だから」で衣装を決めない。

## 3.3 Scenario is pressure on an existing person

事件のために性格を変えない。

既存人物へ圧力を掛ける。

```txt
普段の長所 / 願い
+
その時代固有のpressure
+
失う怖さ
→ 極端な正しさ
→ 黒耀化 / wrong arrival
```

## 3.4 Relationship depth is multi-axis

関係の深さを一つの親密度へ圧縮しない。

- speech distance
- physical distance
- touch permission
- object trust
- care permission
- refusal safety
- silence comfort
- joke range
- anger shape
- repair behavior
- appearance intervention

を別々に扱う。

高Bond = 呼び捨て / 密着 / お揃いアクセ / 露出増加、ではない。

## 3.5 Return to ordinary life is proof of growth

成長は最終決戦の台詞だけで証明しない。

- 昔なら断れなかった頼みを断る
- 昔なら全部自分で持った荷物を誰かへ渡す
- 昔なら隠した傷を説明する
- 昔なら正しい道を押し付けた場面で一緒に迷う
- 昔なら閉じた箱を本人へ返す

など、小さい日常行動が変わることで示す。

# 4. World Design Master — visual and narrative grammar

## 4.1 Reality

Realityは現実の日本。

- 現代は現代の生活ディテールを持つ
- Historical Eraは実際の生活史・制度・技術を研究する
- 架空事件は実在被害の名前替えにしない
- 国籍 / ancestry / appearance / language / living placeを混同しない

## 4.2 Dream

Dreamは現実の物理を完全再現する場所ではないが、何でもあり空間でもない。

Dream visual grammar:
- night
- route / way home
- paper / ledger / ticket / label / map
- black ink / stain / erased writing / missing record
- lantern / small practical light
- old and changing star charts
- memory fragments
- repair / stitching / binding / folding

これらは**装飾symbolとして貼るより構造へ変換する**。

Examples:
- 星図 → seam / route / panel division
- paper → layering / folded plane / worn edge
- ledger → repeated ruling / index / fastening logic
- lantern → hardware / carrying logic / local warm light
- ink → wear / stain / shadow behavior

## 4.3 Quiet normal, loud rare

通常画面:
- low visual noise
- limited bright accents
- readable silhouette
- practical light
- material variation is subtle

Rare / climax:
- contrast rises
- black ink convergence
- warm light expansion
- motif density may increase

**常時クライマックスにしない。**

## 4.4 World-specificity test

新しい場所・建物・服・小物を作った時:

1. Reality / Dreamのどちらか
2. Eraは何か
3. 誰が使うか
4. 何のためにあるか
5. 何でできているか
6. 誰が修理するか
7. 古くなったらどうなるか
8. ヨルノシルベのどのThemeを自然に支えるか

最低5項目に答えられないならgeneric set dressing疑い。

# 5. Character Design Master — operating rules

## 5.1 Design from refusal as well as preference

各人物は:
- what they choose
- what they tolerate
- what they refuse
- what they only wear for someone else
- what they wear only for work / ceremony / weather

を持つ。

## 5.2 Body is not a difficulty to solve

禁止:
- growth = slim body
- growth = younger face
- recovery = disability disappears
- acceptance = more conventional gender presentation
- premium art = lighter skin / smaller nose / narrower jaw / longer legs

## 5.3 Clothes must survive ordinary scenes

Character Masterは以下を想定する。

- 座る
- しゃがむ
- 食べる
- 運ぶ
- 探す
- 待つ
- 暑い / 寒い
- 疲れる
- 笑う
- 呆れる

武器・hero pose・発光を外しても人物が成立すること。

## 5.4 Relationship styling never overrides personal choice

関係が深いことを理由に:
- pierce
- tattoo
- matching accessory
- skin exposure
- body change
- pair outfit

を自動追加しない。

関係由来のvisual traceは既存Relationship Authorityのsourceが必要。

# 6. Scenario Design Master — operating rules

重要sceneは最低:

1. ordinary task
2. immediate want
3. hidden pressure
4. era assumption
5. world evidence
6. carried object use
7. body acting
8. relationship movement
9. choice
10. after-state

を持つ。

Serious sceneでも全員を同じ詩的説明口調へしない。
Comedyでも人物の知能・尊厳・身体設定を壊さない。

---

# 7. Kokuyou

黒耀化はgeneric evil costume changeではない。

```txt
既存の長所
+
既存の怖さ
+
時代 / 関係 / 事件pressure
→ その人なりの「正しすぎる答え」
```

禁止shortcut:
- random horns
- random tattoo
- random chains
- generic black armor
- sexualization escalation
- body normalization

変化は既存の:
- posture
- object relation
- clothing use
- light
- shadow
- behavior

を極端化して作る。

# 8. Professional production gate

Character / World / Scenario / RelationshipのMaster更新・画像生成・scene authoring前に:

1. Professional Standardを読む
2. certainty classを確認する
3. USER_DECIDEDとAUTHOR_CANDIDATEを混ぜない
4. OPENをAI自由にしない
5. relevant Masterを解決する
6. world / character / relationship / scenarioの接続を確認する
7. exceptionを確認する
8. review evidenceを決める
9. candidate outputを上位Authorityへ逆輸入しない
10. human reviewなしでgenerated detailをCanon化しない

# 9. Anti-generic drift checklist

禁止発想:
- quality = ornament density
- fantasy = belts / gems / gold / tattoo
- future = neon / bodysuit / hologram
- historical = costume filter
- Japan = wagara / torii / katana
- Dream = floating paper fragments everywhere
- villain = black/red/spikes
- serious = lore dump
- comedy = personality simplification
- high bond = more touch / matching accessories / exposure
- growth = conventional attractiveness
- AI hypothesis = user preference
- generated image = canon source

---

# 10. Positive target

ヨルノシルベは、別々の身体・時代・価値観・関係・生き方を持つ人物が、記憶・記録・帰る道を巡る奇妙な夜で出会う作品。

世界・人物・関係・物語が同じ原因から生まれ、日常のくだらない会話から重大な選択まで同じ人物として繋がること。

そして別のAI・別session・別担当者でも、**certaintyを偽らず同じ判断順序で制作できること**をMaster品質とする。

# ヨルノシルベ — Visual Design Production Master v1

Date: 2026-08-12  
Status: **CURRENT VISUAL PRODUCTION AUTHORITY / REQUIRED BEFORE CHARACTER IMAGE GENERATION**

## 0. Purpose

このMasterはヨルノシルベの**デザインだけ**を扱う。

対象:
- Character Master
- full-body illustration
- face / body / hair / clothing
- accessory / prop
- materials / color / lighting
- world visual grammar
- Era visual translation
- chibi / pixel / iconへの圧縮
- commercial originality / anti-generic drift

対象外:
- scene plot
- dialogue writing
- relationship arc progression
- gameplay balance
- runtime logic

画像生成時は本Masterを、Living Visual / Appearance Source / Character Designer Philosophy / Craft Masterの**統合実務Authority**として読む。

---

# 1. Design order — 装飾より前に人物を作る

必ず次の順序で判断する。

```txt
1. identity / age / body
2. posture / center of gravity
3. face structure
4. hair mass
5. silhouette
6. clothing construction
7. exposure / body-modification boundary
8. material / wear / repair
9. color hierarchy
10. prop relationship
11. world / era visual translation
12. rendering / light
13. micro-detail
```

**11以前が弱い状態で13を増やさない。**

---

# 2. Character identity lock

Character Masterで最優先するのは「豪華さ」ではなく本人性。

各人物は最低:
- age impression
- body proportion
- shoulder / torso / hip relation
- limb proportion
- center of gravity
- habitual posture
- face outline
- eye/brow/nose/mouth relation
- hair mass
- clothing mass
- signature object relation

を持つ。

髪色・瞳色・theme colorを外しても区別できることを目標にする。

---

# 3. Body design

身体は衣装の下に存在する。

確認項目:
- height impression
- shoulder width
- ribcage / torso volume
- waist / hip relationship
- arm / leg ratio
- neck length
- hand / foot impression
- body fat / muscle distribution where relevant
- seated shape where relevant
- habitual weight placement

禁止:
- 全員同じ細身anime body
- 主役だけ脚を不自然に長くする
- plus-sizeを衣装で隠して実質細身化
- older characterを若者bodyへ寄せる
- disabilityを立ち絵都合で消す

---

# 4. Face design

顔差は最低8層で設計する。

1. face length / width
2. cheek volume / cheekbone
3. jaw / chin
4. eye aperture / tilt / spacing
5. eyelid
6. brow thickness / position / angle
7. nose bridge / tip / width
8. mouth width / lip mass / resting corner
9. forehead / hairline
10. age / surface history

## Neutral-face gate

笑顔・怒り顔ではなく**無表情寄りの通常顔**で本人に見えること。

禁止:
- 同じV字顎
- 同じ小鼻
- 同じ巨大eye base
- 同じ唇
- 「強気=つり目」一個で人物を終わらせる

---

# 5. Hair design

髪は細かい束より**mass**を先に設計する。

見る:
- crown height
- side width
- front mass
- back mass
- tied / loose
- forehead exposure
- neck interaction
- shoulder interaction

Hair designは生活習慣とも一致させる。

禁止:
- 個性不足をhair accessoryだけで補う
- 全員同じ前髪構造
- 毎日salon-perfectな髪を標準化

---

# 6. Silhouette design

黒塗りで見る。

最低:
- head mass
- shoulder line
- torso mass
- outer garment mass
- leg spacing
- prop placement

Signature shapeは**3〜5個程度を強く**。

細部20個で識別しない。

## Ensemble gate

複数キャラを並べて:
- 全員long coat
- 全員asymmetry
- 全員large collar
- 全員細い腰
- 全員同じ脚長
- 全員同じhair volume

になっていないか確認する。

---

# 7. Clothing construction

衣装は「絵柄」ではなく**着られる構造**。

必須検討:
- how to put on / remove
- fastening
- layer count
- pocket / storage
- footwear
- bag / prop interference
- sitting
- crouching
- arm raise
- weather response
- work / travel response

## Ornament rule

以下は理由がない限り追加しない:
- belt
- buckle
- strap
- harness
- gem
- metal plate
- ribbon
- cutout
- asymmetrical flap
- decorative chain

許容理由:
- fastening
- carrying
- reinforcement
- repair
- identification
- ceremony
- personal memory
- culture

「画面が寂しい」は理由ではない。

---

# 8. Exposure / body modification

Living Visual Masterを最上位とする。

部位別に見る:
- shoulder
- upper arm
- chest
- abdomen
- back
- thigh
- lower leg

Piercing / tattoo / scar / mole / jewelry / makeup / nailは**未設定なら足さない**。

禁止:
- strong = piercing
- future = tattoo
- sexy = more skin
- premium illustration = neckline lower
- villain / kokuyou = tattoo / black mark

---

# 9. Material design

素材をレンダリングの味付けではなく物質として扱う。

各素材には:
- weight
- stiffness
- fold behavior
- surface reflection
- sound impression
- temperature
- wear pattern
- repairability

がある。

一人の衣装で**dominant material hierarchy**を作る。

全部を同じ高光沢にしない。

---

# 10. Wear / maintenance

服・小物の経年は本人の生活結果。

候補:
- crease
- fading
- abrasion
- patch
- stitch repair
- polish
- soot
- ink stain
- sun fade
- edge wear

ただし全員を汚さない。

`maintenance behavior` と一致すること。

---

# 11. Color hierarchy

最低4階層:
- dominant
- support
- accent
- light / emission

Theme color = 全身同色ではない。

Cast比較では:
- hue
- value mass
- saturation distribution
- dark/light placement
- skin/hair/clothing separation

を見る。

通常時は静か、climaxだけ強くする。

---

# 12. Prop design

Propはlogoではなく身体との関係。

決める:
- where stored
- which hand
- how carried
- body contact
- clothing interference
- maintenance
- repair
- resting placement

Signature propは強度を競合させない。

一人に主役級propを乱立しない。

---

# 13. World visual grammar

ヨルノシルベの共通語彙:
- night
- route / way home
- paper / record / ledger / label
- black ink
- lantern / small practical light
- old / changing star charts
- memory / missing record
- repair / binding / folding

**全部を全キャラへ貼らない。**

World motifは優先して:
- seam
- fold
- fastening
- panel division
- material aging
- translucency
- object construction
- edge treatment

へ翻訳する。

星形アクセを付ければ星図世界、紙片を貼れば記憶世界、ではない。

---

# 14. Era visual translation

Eraはcostume filterではない。

Core5ではEra Life Masterを読み、見た目へ以下から複数を反映する。

- available textile / synthetic material
- fastening technology
- footwear expectation
- bag / storage norm
- repair vs replace culture
- carried communication object
- weather adaptation
- grooming norm
- manufacturing finish
- personal privacy object handling

禁止:
- historical = museum costume
- postwar = brown/sepia only
- early internet = generic Y2K cosplay
- modern = plain default
- future = neon bodysuit / hologram / cyber tattoo

---

# 15. Rendering authority separation

**Design identityとRenderingを分ける。**

Renderingで変えてよい:
- line softness
- paint density
- material edge
- light softness
- atmospheric depth

Renderingで変えてはいけない:
- face anatomy
- body ratio
- exposure boundary
- clothing construction
- piercing/tattoo
- signature shape

「絵が豪華になった結果、人物設定が変わる」を禁止。

---

# 16. Detail budget

Detailは場所を選ぶ。

優先順:
1. face readability
2. silhouette anchor
3. clothing construction
4. prop function
5. material break
6. small decorative detail

高解像度だから全面を埋めない。

**detail densityには休む場所を作る。**

目線が:
- face
- main silhouette
- key object

へ自然に戻ること。

---

# 17. Chibi / 4-koma translation

Character Masterから保持する優先順位:

1. head/hair mass
2. body proportion tendency
3. posture rhythm
4. strongest clothing mass
5. signature prop shape
6. brow/eye rhythm
7. dominant/support color relation

削る:
- micro embroidery
- tiny fasteners
- secondary straps
- subtle surface rendering

Chibi用に新しいidentity gimmickを発明しない。

---

# 18. Pixel / icon translation

小サイズでは:
- head silhouette
- torso/leg ratio
- strongest color block
- prop location
- posture direction

を優先する。

高精細Masterの装飾を全部pixelへ移植しない。

1x readabilityを優先。

---

# 19. Commercial originality gate

既視感を層別に見る。

- face
- body
- silhouette
- hair
- clothing construction
- accessory vocabulary
- color hierarchy
- rendering

第三者連想が出た場合、**問題の層を特定して最小修正**する。

ただし複数の主要層が一つの既存商業キャラクター/作品へ強く収束する候補は落とす。

独自性のためだけに奇抜な装飾を足さない。

---

# 20. Anti-generic-gacha gate

以下が理由なく増えていないか:
- gold trim
- gems
- belt / harness
- floating cloth
- decorative asymmetry
- thigh cutout
- glowing ornament
- metallic edge
- random star accessory
- fantasy boot complexity

2個以上が「理由なし」で入ったら、まず減らす。

**豪華さではなく設計密度を上げる。**

設計密度 = 少ない形でも人物・生活・世界の理由が読めること。

---

# 21. Image-generation readiness — DESIGN ONLY

Character image生成前に最低:

- identity resolved
- face structure resolved
- body proportion resolved
- neutral posture resolved
- silhouette anchors resolved
- clothing construction resolved
- exposure resolved
- piercing/tattoo/body-modification resolved
- material hierarchy resolved
- color hierarchy resolved
- signature prop relation resolved
- Era translation resolved when applicable
- unresolved required visual fields = 0

一つでも重要項目がOPENなら、production Character Master生成へ進めない。

探索画像なら `EXPLORATORY_ONLY` を明示する。

---

# 22. Final design QA

Character Master候補は最低:

1. neutral poseで本人に見える
2. face close-upで他キャラと区別できる
3. black-fill silhouetteで区別できる
4. bodyが服の下に存在する
5. 服が着脱・着座・移動できる
6. 露出/body modificationが本人設定に忠実
7. materialに物理と生活理由がある
8. color hierarchyがある
9. propが身体と接続している
10. world motifが貼り付け装飾ではない
11. Eraがcostume shorthandだけではない
12. high-res detailでidentityが埋もれていない
13. chibi/pixelへ圧縮できる
14. generic gacha fillerがない
15. third-party resemblanceが複数主要層へ集中していない

---

# 23. Positive target

ヨルノシルベのCharacter Designは、

**「綺麗なファンタジーキャラ」ではなく、その身体・時代・生活・趣味・物の扱い方を持つ人物が、ヨルノシルベの夜に立った結果の形**

を目指す。

静かな立ち姿でも本人に見え、日常でも戦闘でも崩れず、細部を減らしても識別でき、高解像度にしてもgeneric gachaへ流れないことを制作基準とする。

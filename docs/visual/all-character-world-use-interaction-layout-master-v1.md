# All Character World-Use Interaction Layout Master v1

Status: CURRENT_PRODUCTION_VISUAL_AUTHORITY
Scope: all 36 characters and all production character images that include usable space, furniture, tools, storage or movement routes.

## Purpose

Make Yoru-no-Shirube spaces look inhabited and used rather than staged behind a character. Character, clothing, props and environment must agree on how a person waits, sits, works, repairs, stores, retrieves, passes through, rests and leaves traces.

This Master is design-only. It does not invent scenario beats, relationships, events or new canon locations. It constrains visual arrangement using already-authorized character/world information.

## Core rule

Every visible object and spatial zone should answer at least one of:
- who uses it
- how it is reached
- what action happens there
- what gets stored there
- what wears out there
- what blocks or permits movement there

If none apply, simplify or remove it rather than adding decorative clutter.

## Authority boundary

This Master is subordinate to Living Visual, World Place, Era Life, relationship appearance permissions, body/mobility, Hand/Contact and Spatial/World-Scale authorities.

Unknown habits remain unknown. Do not infer that a character sits cross-legged, leans on walls, organizes obsessively, leaves mess, drinks from a specific vessel, sleeps in a specific posture or prefers a specific workspace unless supported.

## Interaction-layout invariants

1. **entry / exit clarity** — body, prop and mobility route must have a plausible way into and out of the depicted space.
2. **waiting zone logic** — if waiting is implied, there must be a believable place to stand/sit/rest without inventing personality habits.
3. **work zone logic** — tools, hands, light, surface height, waste and storage should form a usable loop.
4. **repair zone logic** — repair materials, damaged object, tool access and discard/parts placement should be physically coherent.
5. **storage zone logic** — frequently used items should be reachable; long-term storage may be less accessible.
6. **retrieve / return path** — a carried or used object should have a plausible origin and return route when visible.
7. **movement lane** — composition must preserve enough route for the established body/species/mobility equipment.
8. **resting contact** — sitting/leaning/resting surfaces must support actual body mass and clothing/prop placement.
9. **light-use relation** — lamps and task lighting should be positioned where they serve an action; not every important object needs glow.
10. **waste / residue logic** — scraps, dust, paper offcuts, repair waste, water or dirt should appear where the action would create them.
11. **maintenance trace** — frequently handled edges, handles, floors, worktops and storage points may show wear where use explains it.
12. **era-life compatibility** — payment, record, transport, storage and communication objects must not drift into a different era just to make the composition readable.
13. **privacy boundary** — personal/grooming/private-use objects are not exposed in public composition without authority.
14. **relationship boundary** — another person's object, gift, borrowed clothing or paired layout is not invented to signal closeness.
15. **species / mobility use** — dog/cat/robot and mobility-equipment users must interact with the environment through their actual body/contact system.
16. **ordinary-pose viability** — the design must work in mundane use, not only heroic standing poses.
17. **prop downtime** — named props need a believable state when not actively held; floating/orbiting standby is prohibited unless canon.
18. **clutter budget** — information density comes from meaningful use, not equal decoration on every surface.

## Interaction loops

### Carry / use loop
`storage -> access -> grasp/contact -> use position -> temporary rest -> return/storage`

### Work loop
`approach -> body placement -> tool retrieval -> task light -> action surface -> waste/parts -> tool return -> exit`

### Wait / rest loop
`arrival -> route clearance -> stable body position -> prop placement -> departure`

### Repair loop
`damaged object -> inspection -> support surface -> tool/part access -> removed material -> repaired state -> cleanup/storage`

A generated composition does not need to show every step, but visible steps may not contradict the missing ones.

## Forbidden shortcuts

- decorative table covered in unrelated props
- every character receiving the same cup/book/lamp composition
- floating tools around a repair character
- objects placed beyond believable reach only to balance composition
- blocking the only doorway with a heroic pose
- wheelchair or mobility route ending at stairs/wall with no compositional reason
- chair appearing only as a silhouette prop but impossible to sit in
- shelves and pockets that exist solely as ornament and cannot store depicted objects
- generic papers scattered everywhere to signal Yoru-no-Shirube
- giant key/lamp/book used as set dressing without functional relation
- all lamps glowing regardless of use or time
- workbench with no task light, tool access or usable hand clearance
- repair debris with no damaged object or repair action
- generic grime applied everywhere rather than at contact/use zones
- personal items exposed to imply intimacy without authority
- paired chairs/objects used to imply romance or friendship without relationship source
- invented borrowed jacket, mug, photograph or gift as emotional shorthand
- child given adult-scale work layout with no plausible reach
- dog/cat posed on human chair/table like a mascot unless supported
- robot given human ergonomic habits by default
- clutter added because high-rarity art needs more detail
- empty floor replaced by decorative motifs instead of preserving circulation
- composition that requires a character to teleport a prop between hand and storage
- pristine frequently used surfaces while random unused corners are heavily worn
- universal cozy-room template across eras and characters

## World-fit rule

Worldbuilding should be visible through use patterns: where records are protected, where light is needed, where objects are repaired, where people pause, where routes narrow, where paper accumulates, what gets touched often, and what is kept within reach.

The visual question is not “what Yoru-no-Shirube motif can be added?” but “what would this person actually need to do here, and what physical evidence would that leave?”

## Unknown-use rule

When exact routine or habit is unresolved, use a neutral low-assumption arrangement: clear route, plausible support surface, minimal necessary storage, no signature clutter, no implied relationship object, no lifestyle claim.

## Production rule

Production candidate generation must load this Master. Generated object placement, clutter pattern, room use, furniture choice or routine implication remains candidate composition evidence and does not create character/world/relationship canon.

# Erudition and Curiosity Loading Lines

Vamp Pon / ヴァンサバ改のロード画面・キャラ返信に入れる「少し博識」「何これ？と調べたくなる」「本を読んでいる時の知識欲」を設計する資料。

---

## 1. 目的

ユーザー方針:

```txt
みんなある程度の博識であってほしい。
日本人が知らないこと、常識ではないこと、ちょっとした言葉の由来を入れたい。
プレイヤーが「何これ？」と思ってアプリを止めて調べてもいい。
本を読む時のように、知識が上がる感じがほしい。
西尾維新を読んでいる時の、知らない言葉が出てくる感覚も欲しい。
例: 曖昧模糊のような、普段使わない言葉。
```

この資料の目的:

```txt
ロード画面を、ただのおしゃれ演出ではなく、少し賢くなった気がする入口にする。
ただし、辞書アプリや教科書にはしない。
キャラが知識をひけらかすのではなく、その子の価値観として自然に漏れるようにする。
```

---

## 2. 最重要方針

```txt
知識は、説明ではなく引っかかりとして置く。
```

良い状態:

```txt
何この言葉？
調べたら意味があった。
その意味を知ると、キャラの返信が少し深く見える。
```

悪い状態:

```txt
辞書説明が長い。
キャラが作者の代弁者になる。
難しい言葉を使うだけで中身がない。
全員が同じ博識キャラになる。
```

## 4. 知識欲を満たすカテゴリ

### A. Everyday phrase with hidden depth

日常で使うが、由来や奥行きがある英語表現。

```txt
Bless you.
Good night.
Take care.
Fingers crossed.
Knock on wood.
No worries.
Hang in there.
```

良い理由:

```txt
短い。
英語圏では自然。
日本人には「そういう意味なんだ」となる。
キャラ返信でかわいくできる。
```

### B. Classical quote / 古典引用

短く、世界観に合う古典。

```txt
Sunt lacrimae rerum.
E quindi uscimmo a riveder le stelle.
We grow accustomed to the Dark.
春はあけぼの。
行く川のながれは絶えずして、しかももとの水にあらず。
```

良い理由:

```txt
知識供給になる。
出典を調べたくなる。
Vamp Ponの夜/星/記憶/朝に合う。
```

### C. Rare Japanese words / ふだん使わない日本語

西尾維新を読んでいる時のような「言葉に引っかかる」感覚。

例:

```txt
曖昧模糊
有耶無耶
幽明境
未練
残滓
余白
夜半
薄明
昏昏
茫漠
彷徨
邂逅
名残
泡沫
無常
```

使い方:

```txt
単語だけを出すのではなく、Vamp Ponの文に混ぜる。
```

例:

```txt
曖昧模糊の夜にも、帰り道は落ちている。
```

```txt
有耶無耶にした名前ほど、朝に残る。
```

```txt
薄明は、夜が言い訳をやめる時間。
```

### D. Small etymology / 小さな語源・由来

語源や由来をそのまま長く説明しない。

例:

```txt
Goodbye は God be with you に由来するとされる。
```

Vamp Pon用:

```txt
Goodbye.
— Common expression

かつては、祈りに近かった別れの言葉。
```

返信:

```txt
別れに祈りが入ってるなら、少しだけ怖くない。
— セナ / Sena
```

## 5. ロード表示ルール

知識を入れるが、重くしすぎない。

```txt
通常ロード: 1つの知識だけ
長めロード: 原文 + 意味 + 返信まで可
図鑑/記録室: 由来をもう少し説明可
```

表示例:

```txt
Fingers crossed.

— Common expression

うまくいくように、指を重ねて願う言葉。

重ねた指は、方位針には向いてない。
— イオリ / Iori
```

このくらいが限界。
それ以上説明すると、ロード画面では重い。

---

## 6. 「調べたくなる」を作るための設計

プレイヤーに全部説明しない。

```txt
ロード: 入口だけ置く
図鑑: もう少し説明する
外部検索: プレイヤーが自分で調べてもよい
```

良いロード文:

```txt
Sunt lacrimae rerum.
— Virgil, Aeneid

ものにも、涙のようなものがある。
```

ここでプレイヤーが `Sunt lacrimae rerum` を調べたくなる。
それでよい。

## 9. キャラが博識に見える返信の作り方

```txt
1. 知識そのものは短く置く。
2. キャラはその知識を説明しない。
3. そのキャラの分野で受け取る。
4. 少しだけズレた返信にする。
5. プレイヤーが「え、それどういう意味？」と思う余白を残す。
```

例:

```txt
曖昧模糊。

ぼんやりして、はっきりしないこと。

はっきりしない道ほど、地図にしたくなる。
— ナギ
```

ナギは語義を説明していない。
地図のキャラとして受け取っている。

## 10. 表示比率

```txt
Serious literary quote: 30%
English everyday phrase / idiom: 25%
Rare Japanese word: 20%
Vamp Pon original poetic line: 15%
Parody dialogue prompt: 10%
```

知識欲を満たすため、Rare Japanese word を20%程度入れる。
ただし1プレイ中に難語が連続しないようにする。

```txt
難語は2連続禁止。
1ステージ中、同じ難語は1回まで。
図鑑/記録室では用語一覧として見返せる。
```

## 11. 図鑑/記録室に入れるべき補足

ロードで気になった言葉は、あとで記録室で見返せるとよい。

データ例:

```ts
export type KnowledgeLine = {
  id: string;
  category: 'quote' | 'everyday_phrase' | 'rare_japanese_word' | 'idiom' | 'vamp_original';
  originalText: string;
  sourceLabel?: string;
  meaningJa: string;
  meaningEn?: string;
  vampUsageNote: string;
  tags: string[];
  commercialStatus: 'safe-candidate' | 'common-expression-candidate' | 'original' | 'final-check-required' | 'do-not-display';
};
```

## 12. 最終方針

```txt
Vamp Ponのキャラは、みんな少し博識でよい。
ただし、同じ博識ではない。

ロードでは、知らない言葉や短い英語表現を少しだけ置く。
プレイヤーがアプリを止めて調べてもよい。
むしろ、それも体験にする。

本を読んでいて知らない言葉に出会い、少し賢くなった気がする感覚を狙う。
ただし、説明しすぎず、キャラの返信で世界観に戻す。
```

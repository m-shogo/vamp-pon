# Causal Scenario Logic

## 目的

Vamp Ponのシナリオを、雰囲気ではなく因果で組む。

このドキュメントは、黒インク・欠片・朝・忘れ物係・ボス・ハッピーエンドの理屈を一本化する。

---

# 1. 採用する中核案

採用。

```txt
黒インクは、事実を消すものではない。
その人が信じ込んだ“間違った意味”を固定するもの。
```

理由:

```txt
敵が襲ってくる理由になる
ボスの正体を作れる
キャラの誤解と直結する
小物の反転が強くなる
ハッピーエンドが安っぽくならない
```

弱点:

```txt
抽象化しすぎると分かりづらい
```

補強:

```txt
必ず小物と敵の挙動で見せる
説明台詞で言わない
```

# 2. 黒インクの因果

## Step 1: 出来事がある

例:

```txt
名前を呼べなかった
手紙を届けなかった
箱を閉じた
帰り道を選べなかった
灯りだけが残った
```

## Step 2: 本人が意味を誤解する

例:

```txt
名前を呼ばれなかった
忘れられた
閉じ込めた
帰れなかった
自分だけが待っていた
```

## Step 3: その誤解が黒インクで固定される

固定されると、本人にとってはそれが事実のようになる。

```txt
本当は違う可能性がある
でも、黒インクが“そうだったこと”にしてしまう
```

## Step 4: 固定された意味が影になる

影は悪意ではない。

固定された誤解が、ほどかれたくないために動く。

## Step 5: 影を払うと意味片が落ちる

影を倒すことは、記憶を壊すことではない。

```txt
固定を少し剥がす
意味片が落ちる
ユイが拾う
その夜だけ接続が増える
```

## Step 6: 朝に確定する

夜の間に正しい順番で意味をつなげると、朝に地図帳へ確定する。

# 3. 忘れ物係の因果

採用。

```txt
忘れ物係は、子どもの遊びに見える記憶隔離/返却プロトコル。
```

表の遊び:

```txt
拾う
名前をつける
箱にしまう
地図に書く
灯りで探す
```

裏の機能:

```txt
拾う      = 証拠を回収する
名前をつける = 持ち主を識別する
しまう    = 読まれると壊れる理由を隔離する
地図に書く = 返却先を記録する
灯す      = 朝まで意味を保持する
```

重要:

```txt
子どもたちは、自分たちがプロトコルを動かしているとは知らない。
```

これにより、かわいい日常と重い裏設定が両立する。

# 4. ユイの因果

採用。

```txt
ユイは“拾う子”ではなく、“持ち主を間違えない子”。
```

なぜ主人公なのか:

```txt
黒インクで名前・理由・場所が読めなくなっても、ユイだけは持ち主の気配を間違えない。
```

ゲーム仕様との接続:

```txt
欠片を拾える
ドロップを引き寄せる
本来の持ち主とアイテムを一致させる
武器進化の条件を満たせる
```

シナリオとの接続:

```txt
ユイ自身は理由を覚えていない。
でも、これはアサのもの、これはナギのもの、という気配だけは分かる。
```

これにより、ユイは便利な回収役ではなく、世界法則に必要な主人公になる。

# 5. 欠片の種類

欠片は単なる経験値ではない。

黒インクの固定から剥がれた意味片。

## 名前の欠片

```txt
誰のものかを示す
アサ系統と関係が深い
```

## 場所の欠片

```txt
どこへ返すべきかを示す
ミチル系統と関係が深い
```

## 理由の欠片

```txt
なぜ大切だったのかを示す
ナギ系統と関係が深い
```

## 証拠の欠片

```txt
それが本当にあったことを示す
ユイ系統と関係が深い
```

## 灯りの欠片

```txt
朝まで意味を保持する
トモリ系統と関係が深い
```

# 6. 接続順の因果

拾うだけでは正解ではない。

意味には接続順がある。

## 正常な接続例

```txt
証拠
→ 持ち主
→ 場所
→ 理由
→ 灯り
→ 朝に確定
```

## 順番を間違えた時

### 名前だけ先に戻す

```txt
誰のことかは分かる
でも、なぜ大切だったかが分からない
結果、本人の痛みだけが強くなる
```

### 場所だけ先に戻す

```txt
帰る場所は見える
でも、誰が帰るべきか分からない
結果、別の記憶が迷い込む
```

### 理由だけ先に戻す

```txt
なぜ大切だったかは分かる
でも、持ち主が分からない
結果、関係ない人の後悔として固定される
```

### 証拠だけ先に戻す

```txt
本当にあったことだけが分かる
でも意味が戻らない
結果、ただ痛い証拠になる
```

### 灯りだけ先に戻す

```txt
朝まで保持できる
でも、間違った接続を保持してしまう危険がある
```

# 7. ボスの因果

ボスは巨大な敵ではない。

```txt
そのページで一番強く固定された誤解。
```

例:

```txt
アサPageボス:
“名前を呼ばれなかった”という固定

ナギPageボス:
“閉じ込めた”という固定

ミチルPageボス:
“帰れなかった”という固定

トモリPageボス:
“自分だけが待っていた”という固定
```

倒すとは何か:

```txt
ボスを殺すことではない。
その誤解が絶対の事実として固定される状態をほどくこと。
```

# 8. アイテム配置の因果

アイテムは適当に落ちていない。

配置理由が必要。

## 名札

```txt
名前の誤解が強い場所に落ちる
影は名札を踏まないように回り込む
```

## 箱

```txt
理由の欠片が強すぎる場所に置かれる
早く開けると敵が増える
正しい欠片を集めてから開けると安全になる
```

## 切符

```txt
場所の接続が切れている場所に落ちる
持ち主の名前が戻るまで、行き先が読めない
```

## ランタン

```txt
朝まで保持したい意味の近くに置かれる
ただし、早く灯すと間違った意味まで固定する危険がある
```

# 9. リザルト差分の因果

同じStageをクリアしても、接続順でリザルト文が変わる。

## 正しい順番

```txt
片方だけだと思っていた切符の裏に、小さな帰り印が残った。
```

## 不完全順番

```txt
切符はまだ片道に見える。
けれど、裏面だけが少し温かい。
```

## 間違った順番

```txt
帰り道は見えた。
でも、誰のための道なのかはまだ読めなかった。
```

これにより、考察と再プレイが生まれる。

# 10. シリーズSeedの因果

シリーズSeedは、続編予告ではない。

```txt
1作目では意味が分かる小物
後作でさらに別の意味が出る小物
```

例:

## 折り目の違う紙片

1作目:

```txt
ただの背景小物
```

後作:

```txt
影系統は、意味を返すのではなく折って隠していたと分かる
```

## 知らない綴じ糸

1作目:

```txt
古い地図帳の製本跡
```

後作:

```txt
背表紙系統がページの順番を管理していた証拠
```

# 11. ハッピーエンドの因果

Season 1のハッピーエンドは、全員が元通りになることではない。

```txt
固定された間違った意味がほどけること。
```

例:

```txt
アサは“名前を呼ばれなかった人”ではなくなる
ナギは“閉じ込めた人”ではなくなる
ミチルは“帰り道を失った人”ではなくなる
トモリは“自分だけが待っていた人”ではなくなる
```

出来事は消えない。

でも、その出来事についた間違った意味は固定されなくなる。

これがVamp Ponの救い。

# 12. 採用/保留/却下

## 採用

```txt
黒インク = 誤解を固定するもの
忘れ物係 = 子どもの遊びに見える隔離/返却プロトコル
ユイ = 持ち主を間違えない子
朝 = 意味の確定処理
欠片 = 固定から剥がれた意味片
ボス = 一番強く固定された誤解
ハッピーエンド = 誤解が固定されなくなること
```

## 保留

```txt
全員が強く救済される奇跡
死後/天国に近い裏設定
人類滅亡級のスケール
```

理由:

```txt
感情の温度としては使えるが、現時点で表設定にするとVamp Ponの軽さを壊す。
```

## 却下

```txt
ゴールが死ぬこと
全員植物状態
人類滅亡を正面テーマにする
黒インクを単純な悪にする
ただの記憶回復ものにする
```

# 13. 最重要

Vamp Ponの因果の気持ちよさはこれ。

```txt
拾う順番も、敵の動きも、アイテムの場所も、朝リセットも、全部に理由がある。
```

プレイヤーに全部は見せない。

でも、裏では全部つながっている。

# ヨルノシルベ Ensemble Daily Scene Bank v1

Date: 2026-07-29  
Status: **CURRENT SCENE PRODUCTION GUIDE / SAMPLE DIALOGUE NOT SCRIPT CANON**

> 目的: Pair関係だけでなく、3〜6人が同じ場所でそれぞれ別のことをしている「生活」を作る。
>
> ヨルノシルベの仲間は、全員が順番に名台詞を言う会議集団ではない。誰かは喋り、誰かは食べ、誰かは片付け、誰かは窓の外を見ている。

# 0. Ensemble scene rule

1 sceneで全員に台詞を配らない。

```txt
主会話: 2人
横で行動: 1〜3人
最後の一言: 0〜1人
星獣 / 小物: 1つ
```

が基本。

良いscene:

- 説明がなくても性格差が出る
- 誰かが黙っていても存在感がある
- 同じsceneを後半に繰り返すと関係変化が見える
- 大事件の前触れがなくても成立する

# 1. 「これ誰の？」食卓

Participants:

- ユイ
- アサ
- リツ
- コヨリ
- ハナ

## Situation

食後、机の下から小さなボタンが出てくる。

ユイ:

> 「これ、誰の？」

アサはすぐ全員の服を見る。
リツは人数と持ち物を確認。
コヨリは自分のポケットを全部裏返す。
ハナはボタンの古さを見る。

## Dialogue seed

アサ:

> 「名前書けないね、これ。」

コヨリ:

> 「書いたらボタンじゃなくなるよ。」

ハナ:

> 「じゃあ、ボタンのまま待っててもらいましょ。」

ユイは机の中央へ置く。

## Hidden value

- ユイ = owner confirmation
- アサ = naming reflex
- ハナ = preserve without forcing story
- コヨリ = 子どもの一言でThemeを軽くする

大きな伏線にしなくてもよい。

# 2. 雨の日、窓際

Participants:

- ナギ
- カスミ
- マドカ
- ネム

## Situation

雨で外へ出られない。

- ナギは濡れた箱を拭く
- カスミは紙のにじみを直す
- マドカは窓の向こうを見る
- ネムは雨音で寝る

会話がほとんどなくても成立する。

## Dialogue seed

マドカ:

> 「あと十分くらいで弱くなる、かも。」

ナギ:

> 「出る？」

カスミ:

> 「紙が乾いてから。」

ネム、目を閉じたまま:

> 「雨の道、もう一本あるよ。」

三人が一瞬だけ見る。
ネムは寝ている。

## Later repetition

序盤は誰も夢発言を気にしない。
後半はトキ / マドカが記録するようになる。

# 3. 修理卓の夜

Participants:

- トモリ
- ツムギ
- シロ
- ハナ

## Situation

壊れた古い本箱を直す。

- トモリ: 蝶番を見る
- ツムギ: 破れた布を見る
- シロ: 中身を順序ごと退避
- ハナ: 挟まっていた押し花を拾う

四人とも「残したい」が、対象が違う。

## Dialogue seed

トモリ:

> 「箱は直る。」

シロ:

> 「中の順番は？」

ツムギ:

> 「布の破れは？」

ハナ:

> 「花、先に取っていい？」

トモリ:

> 「……一個ずつ言って。」

## Comedy / warmth

トモリが最終的に修理担当なのに、一番作業開始が遅い。

# 4. 地図が五枚ある

Participants:

- ミチル
- トキ
- ゲン
- マドカ
- レン

## Situation

同じ場所の地図が五枚あり、全部少し違う。

- ミチル: 今歩けそうな線を引く
- トキ: scale / angleを測る
- ゲン: 昔の橋を覚えている
- マドカ: 窓から現在の建物を見る
- レン: 地図間の差を拾う

## Dialogue seed

ゲン:

> 「ここに橋があった。」

トキ:

> 「この縮尺では川幅が合いません。」

レン:

> 「橋じゃなくて、川が違う。」

マドカ:

> 「……川、あっちにもある。」

ミチル:

> 「じゃあ、歩こう。」

トキ:

> 「結論が早い。」

## Hidden payoff

一人をexposition役にせず、情報が組み合わさって時間層へ近づく。

# 5. 宛名のない封筒

Participants:

- ユウビ
- トバリ
- カスミ
- クロオリ

## Situation

ユウビが宛名のない封筒を持ってくる。

低Bondなら全員「不備」として止まる。
高Bondでは「意図的に名前がない可能性」を考える。

## Dialogue seed

ユウビ:

> 「宛名なし。」

トバリ:

> 「帰り先もなし？」

カスミ:

> 「書かなかったのか、消したのかで違う。」

クロオリ:

> 「開ければ分かる、は無しだ。」

ユウビ:

> 「分かってる。」

## Relationship proof

クロオリが止める前にユウビ自身が開封しない。

# 6. コヨリ先生の日

Participants:

- コヨリ
- セン
- リツ
- シロ

## Situation

コヨリが自作gameを教える。
ルールは矛盾している。

センは直したくなる。
リツは妹なので知ったふりをする。
シロはルールを書き取る。

## Dialogue seed

コヨリ:

> 「ここで同じの出したら二点。」

セン:

> 「さっき一……」

シロ、センを見る。

セン:

> 「……二点ね。」

リツ:

> 「俺は最初から分かってた。」

コヨリ:

> 「お兄ちゃん昨日ゼロ点だったよ。」

## Value

センの成長を重いsceneでなく笑いで見せる。

# 7. 荷物を持つ人が多すぎる

Participants:

- カナメ
- リツ
- ナギ
- コヨリ

## Situation

移動前。
カナメとリツが重い荷物を同時に持つ。

ナギは箱が閉まっているか確認。
コヨリは軽い紙袋を一つ持って先へ行く。

## Dialogue seed

カナメ:

> 「持つ。」

リツ:

> 「俺が。」

カナメ:

> 「持てる。」

リツ:

> 「俺も。」

ナギ:

> 「二人とも面倒。」

遠くからコヨリ:

> 「先いくよー！」

## Later repetition

高Bondではカナメとリツが目だけ合わせ、荷物を二つに分ける。
台詞なし。

# 8. 星獣だけ仲直りしている

Participants:

- ユイ
- アサ
- 各星獣

## Situation

二人が喧嘩した翌日。
人間はほぼ喋らない。

星獣だけが同じ場所で寝ている。

ユイが気づく。
アサも気づく。
どちらも星獣を離さない。

## Dialogue seed

長い沈黙。

アサ:

> 「……そっちは早いね。」

ユイ:

> 「うん。」

それだけ。

## Rule

このsceneで仲直り完了にしない。
**仲直りできる余地がある**ことだけ見せる。

# 9. 朝ごはんの席が一つ足りない

Participants:

- ハナ
- ユウビ
- ネム
- クロオリ
- 任意1人

## Situation

椅子が一つ足りない。

- ハナは自分が立とうとする
- ユウビは取りに行こうとする
- ネムは床でも寝られる
- クロオリは最初から少し離れた位置

誰が座るかではなく、**誰が「自分は要らない」と最初に判断するか**が見える。

## High Bond change

周囲が特定人物だけを世話するのでなく:

> 「詰めれば座れる。」

という普通の解決になる。

大げさな自己犠牲を日常でほどく。

# 10. 何も起きない夜

Participants:

- シロ
- トキ
- ミチル
- ネム

## Situation

事件なし。
敵なし。
雨なし。

- シロは本を読む
- トキは星を測る
- ミチルは地図へ寄り道を書く
- ネムは寝る

数十秒、会話なしでもよい。

最後:

ネム:

> 「今日、静かだったね。」

トキ:

> 「今起きたのか。」

## Purpose

重要人物は事件がない時にも存在している。

# 11. 黒耀化の翌日

Participants:

黒耀化した本人 + strong relation 2人程度。

## Rule

翌日に長い謝罪会をしない。

本人:

> 「昨日のこと……」

相手:

> 「朝ごはん食べてから。」

で一度止めてもよい。

黒耀化を無かったことにはしない。
しかし人生の全てにもさせない。

## Later

普通の作業中に短い一言だけ本音が出る。

# 12. 別時代の常識差

Participants:

- ゲン
- トモリ
- ユウビ
- ミチル
- Current younger character 1人

## Purpose

「あなた何年の人？」と直接聞く前に年代差を生活で見せる。

使える差:

- 道具の使い方
- 包装の開け方
- 切符
- 手紙の形式
- 地図記号
- 修理方法
- 食べ物の呼び方

避ける:

- 年代を笑いものにするだけ
- 古い人 = 無知
- 新しい人 = 軽薄

# 13. Future candidate ensemble seeds

Current21へ昇格させない。

## ノアA / ノアB / レン / トキ

二bodyが同時に同じ質問へ答える。
最初は完全一致。
数run後、語尾だけ違う。

レンだけ気づく。
トキは差を測りたがる。
レンは:

> 「違う。でも、まだ意味は分からない。」

と止める。

## クウ / アサ / ユイ

名前を思い出せない人物へクウだけ走る。

アサは名前を聞こうとする。
ユイはクウが誰へ行くか見る。

名前以外のrecognitionを自然に置ける。

## アマネ / ミチル / トバリ

三人でrouteを作る。

- ミチル: 道
- トバリ: 門 / 帰路
- アマネ: 幅 / 段差 / 路面 / speed

誰かが「車椅子でも通れる道」を探すsceneにしない。
**三人ともroute specialist**として議論する。

# 14. Repetition design

同じscene motifを3回使う。

例: 地図卓

```txt
1回目:
トキとミチルが言い合う

2回目:
違う線を両方書く

3回目:
言い合わず、空白の分岐を残す
```

例: 食卓の取り分け

```txt
1回目:
リツが全部分ける

2回目:
コヨリが不満を言う

3回目:
リツがナイフを渡す
```

同じ場所 / 同じ物を使うほど、小さい変化が大きく見える。

---

# 15. Conversation density rule

1 sceneの台詞は、設定量に比例して増やさない。

- 感情が強いほど短くなる人物もいる
- 黙って行動する人物を残す
- explanationを別人物が要約しない
- 「つまり〜ってこと？」を乱用しない
- 全員に気の利いた返しをさせない
- ギャグsceneでもCharacter Coreを壊さない

# 16. 一文

> **仲間になった証拠は、重大な秘密を打ち明けた回数ではなく、同じ机で何度も食べ、同じ道で何度も迷い、相手が次に何をするか少しだけ分かるようになったことに置く。**

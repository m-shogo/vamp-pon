# Relationship / Romance Safety Architecture

## 目的

Vamp Ponの関係性設計で、ユイとアサを恋愛へ寄せすぎない。

恋愛・友情・運命共同体・自己肯定・家族愛を分散し、炎上しにくく、考察余地がある関係性にする。

---

# 1. 採用/保留/却下

## 採用

```txt
ユイとアサは恋愛ではなく、運命共同体/自己肯定/もう一人の自分に近い関係にする
恋愛要素は他キャラ/別ページ束へ分散する
公式で単一解釈を押しつけない
関係性は行動と小物で見せる
```

## 保留

```txt
ユイとアサを恋愛として読める余白
ユイとアサの強い親密さ
子供世代で血縁や継承を使うこと
```

## 却下

```txt
ユイとアサを公式恋愛として強調する
告白/恋人/結ばれるをSeason 1の主軸にする
恋愛でSeason 1の救いを処理する
炎上しやすい固定カップリングを世界観の中心に置く
```

---

# 2. ユイとアサの関係性

ユイとアサは、恋愛ではなく以下の軸で扱う。

```txt
運命共同体
自己肯定
名前をめぐる相互救済
悲劇の読み替えを一緒にする関係
```

ユイにとってアサは、恋人候補ではなく、以下に近い。

```txt
自分の名前を嫌いになりかけた時に、もう一度意味を与えた人
自分が結べていると信じさせてくれた人
夜の読み方を変えるきっかけ
```

アサにとってユイは、恋人候補ではなく、以下に近い。

```txt
名前を遊びにしないで受け取ってくれた人
自分がふざけてつけた名前の奥を見てくれた人
運命を別の読み方へ変える相手
```

---

# 3. 超かぐや姫！的に見る関係性の採用点

直接的な設定や構造は使わない。

採用する温度は以下。

```txt
恋愛ラベルより、運命を一緒に読み替える関係
悲劇の型を壊してハッピーエンドを探す関係
片方が片方を救うのではなく、互いに自分の意味を取り戻す関係
```

Vamp Pon化するとこう。

```txt
ユイとアサは、結ばれる関係ではなく、名前の意味を一緒に読み替える関係。
```

---

# 4. なぜ恋愛を強調しないか

## 理由1: Season 1の主題がズレる

Season 1の主題は、恋愛成就ではない。

```txt
誤解で固定された意味を、正しい持ち主へ返すこと。
```

ユイとアサを恋愛で処理すると、世界法則よりカップリングが前に出る。

---

## 理由2: 炎上リスク

関係性を固定しすぎると、以下が起きる。

```txt
友情として読んでいた人が置いていかれる
他キャラの関係性が弱く見える
恋愛解釈の正解/不正解が生まれる
続編の子供世代設定が縛られる
```

だから公式は、恋愛ラベルを貼らない。

---

## 理由3: 次世代展開の余白を残す

ユイとアサの関係を明確な恋愛にすると、2以降で子供世代を出す時に固定が強すぎる。

```txt
誰と誰の子か
結婚したのか
恋愛だったのか
```

が主題になってしまう。

Vamp Ponの主題はそこではない。

---

# 5. ユイとアサで見せるべき行動

恋愛台詞ではなく、行動で見せる。

## 採用する行動

```txt
アサはみんなにあだ名をつけるが、ユイだけは本名で呼ぶ
ユイはアサの名前だけを小物に分けて守る
アサはユイの名前の意味を笑わずに受け取る
ユイはアサの持ち物だけ、黒インク越しでも間違えない
アサはユイが自分を呼べなくなっても責めない
```

## 却下する行動

```txt
告白
恋人宣言
キス/結婚/明確なカップル化
恋愛がラスボス解除条件になる
```

# 6. ユイとアサの小物

## 名前のラベル

表:

```txt
名前をつけるアイテム
```

裏:

```txt
恋愛の印ではなく、名前の意味を守るための接続点
```

## 夜の鉛筆

表:

```txt
ユイの武器
```

裏:

```txt
アサの名前を何度も書き直した道具
```

## 消えかけの呼び名

表:

```txt
リザルト文の一部
```

裏:

```txt
ユイがアサを呼べない理由が、忘れたからではなく守ったからだったと示す
```

# 7. 恋愛要素の分散先

恋愛はVamp Ponから消さない。

ただし、ユイとアサへ集中させない。

## Season 1で薄く置ける恋愛

```txt
未配達の封筒
押し花のしおり
半分の飴
片方だけ残ったイヤリング
窓際の紙飛行機
```

これらはサブキャラ/街の人/別ページ束に分散する。

## 2以降で扱う恋愛

```txt
届かなかった手紙
写っていない写真
聞こえなかった音
```

恋愛は、主題として扱うなら2以降の方がよい。

理由:

```txt
Season 1は世界法則とユイ班の入口を優先する
Season 2以降は関係性の種類を増やせる
```

# 8. 関係性の役割分担

## ユイとアサ

```txt
運命共同体
自己肯定
名前の意味
恋愛未満ではなく、恋愛ラベル外の強い関係
```

## ナギ周辺

```txt
守るための沈黙
家族愛/友情/罪悪感
```

## ミチル周辺

```txt
帰り道
待つ人
遠距離/別れ/再会
```

## トモリ周辺

```txt
待ち続ける愛
友情
居場所
```

## 手紙系統

```txt
恋愛
家族
師弟
言えなかった言葉
```

恋愛は手紙系統に寄せると強い。

---

# 9. 炎上回避ルール

```txt
公式で恋愛確定を急がない
関係性を1種類に固定しない
前作キャラ同士の子供を早期確定しない
恋愛より小物/行動/誤解の反転を優先する
プレイヤーの解釈を奪わない
```

ただし、曖昧に逃げない。

関係性の強さは行動で見せる。

---

# 10. ユイとアサの最終着地

Season 1での着地候補。

```txt
ユイは最後まで、アサの名前を声に出して呼べない。
でも、地図帳にはアサの名前が朝まで残る。

アサはそれを見て、
「いいよ。もう読めてるから」
と笑う。
```

この着地は恋愛ではない。

でも、強い。

理由:

```txt
名前を呼べることが救いではない
名前の意味が固定された誤解からほどけたことが救い
```

---

# 11. 最重要

ユイとアサは、恋愛として消費しない。

```txt
恋愛未満ではなく、恋愛ラベルの外にある強い関係。
```

恋愛は他のキャラや別ページ束へ分散し、Vamp Pon全体の関係性を広げる。

# Stage 1 to 5 Emotional Beat Map

## 目的

Vamp Pon の最初の5ステージを、実装・敵設計・小物・感情回収が噛み合う形へ固定する。

この文書は、世界観を増やすものではない。

```txt
何を見せるか
何を隠すか
敵は何を意味するか
プレイヤーは何を誤解するか
後で何が反転するか
ゲームとして何が気持ちいいか
```

をステージ単位で決める。

---

# 0. 全体方針

最初の5ステージは、プレイヤーに以下を体験させる。

```txt
Stage 1: 拾う気持ちよさ
Stage 2: 名前が読めない不穏さ
Stage 3: 箱を開けたい/開けてはいけない葛藤
Stage 4: 帰り道があるのに読めない切なさ
Stage 5: 灯りで全部が少しつながる感動
```

表のゲーム:

```txt
移動する
影を払う
欠片を拾う
レベルアップする
朝まで残る
```

裏の物語:

```txt
固定された誤解を、正しい持ち主へ返す準備をしている
```

---

# 1. 共通ルール

## 見せすぎない

最初から世界法則を説明しない。

```txt
黒インクは誤解を固定するものです
```

とは言わない。

小物、敵の挙動、リザルト文で匂わせる。

---

## 毎Stageで1つだけ強い小物を置く

小物を増やしすぎない。

```txt
Stage 1: 欠片
Stage 2: 名札
Stage 3: 箱
Stage 4: 切符
Stage 5: ランタン
```

この5つを、最初のページ束の柱にする。

---

## 敵は“そのStageの誤解”を動きで表す

敵はただのバリエーションではない。

```txt
追う
隠す
守る
逆走する
灯りを避ける
```

など、誤解の性質を挙動にする。

---

# 2. Stage 1: 持ち主のページ

## 役割

```txt
ユイの入口
拾う気持ちよさ
欠片の意味をまだ隠す
```

## 見せる小物

```txt
記憶の欠片
```

見た目:

```txt
小さな紙片
淡く光る
ユイが近づくと少しだけ震える
```

## 敵の種類

```txt
丸い黒インク影
```

意味:

```txt
まだ名前のない不安
ただ近づいてくる固定された誤解
```

挙動:

```txt
まっすぐ追ってくる
欠片には触れない
ユイにだけ寄ってくる
```

## プレイヤーの誤解

```txt
欠片は経験値
影はただの敵
ユイは落ちているものを拾う主人公
```

## 本当の意味

```txt
欠片は黒インクの固定から剥がれた意味片
ユイは持ち主を間違えないため、欠片が反応している
```

## 回収タイミング

Stage 1では回収しない。

Stage 5以降で、欠片がただの経験値ではなかったと分かる。

## リザルト文

初回:

```txt
小さな紙片が、ユイの手の中で少しだけ光った。
```

2回目以降:

```txt
紙片は、落ちていたのではなく、待っていたように見えた。
```

条件付き:

```txt
拾えなかった紙片が、朝になる前に黒くにじんだ。
```

## ゲーム仕様

P1実装対象。

```txt
基本移動
自動攻撃
敵接触ダメージ
欠片ドロップ
XP/レベルアップ
```

## 面白さの核

```txt
拾うだけで気持ちいい。
でも、拾っているものが何なのかはまだ分からない。
```

# 3. Stage 2: 名前のページ

## 役割

```txt
名前が読めない不穏さ
アサのSeed
ユイとアサの関係を恋愛でなく名前の意味として置く
```

## 見せる小物

```txt
空白の名札
```

見た目:

```txt
紙の名札
真ん中が白く抜けている
よく見ると、何度も消して書き直した跡がある
```

## 敵の種類

```txt
名札影
```

意味:

```txt
名前を呼ばれなかった、という固定された誤解
```

挙動:

```txt
ユイを追うだけでなく、名札の近くに集まる
名札を踏みそうで踏まない
倒すと名前の欠片を落とすことがある
```

## プレイヤーの誤解

```txt
誰かの名前が消えた
アサは忘れられた
名札は空白になった
```

## 本当の意味

```txt
名前は消えたのではない。
黒インクに固定されないよう、何度も書き直されていた。
```

ユイとアサの関係の見せ方:

```txt
恋愛ではなく、名前をめぐる相互救済。
アサはみんなにあだ名をつけるが、ユイだけは本名で呼ぶ。
```

## 回収タイミング

Stage 2では完全回収しない。

Stage 5で、名札の消し跡がアサの筆跡だったと少し分かる。

Season 1終盤で、ユイがアサの名前を守るために分けていたと回収。

## リザルト文

初回:

```txt
名札の真ん中だけが、どうしても読めなかった。
```

名札影を多く倒した時:

```txt
空白の下に、何度も書き直した跡があった。
```

欠片を多く拾った時:

```txt
呼べなかった名前は、消えたわけではないのかもしれない。
```

失敗/不完全:

```txt
名札はまた白く戻った。けれど、端の消し跡だけは残っていた。
```

## ゲーム仕様

P1後半〜P2候補。

```txt
名前の欠片ドロップ
敵が小物周辺へ寄る挙動
小物に近づくと短いリザルトSeed解放
```

## 面白さの核

```txt
敵が小物を守っているように見える。
ただの敵ではないとプレイヤーが気づき始める。
```

# 4. Stage 3: 箱のページ

## 役割

```txt
開けたいけど開けてはいけない葛藤
ナギのSeed
封印/保護の反転
```

## 見せる小物

```txt
開けるなと書かれた箱
```

見た目:

```txt
小さな紙箱
月の絵が描かれている
鍵穴が外側ではなく内側にある
```

## 敵の種類

```txt
箱影
```

意味:

```txt
閉じ込めた/閉じ込められた、という固定された誤解
```

挙動:

```txt
箱の周囲を回る
箱から離れると強くなる
ユイが箱に近づくと急に速度が上がる
```

## プレイヤーの誤解

```txt
ナギは何かを閉じ込めた
箱を開ければ真相が分かる
開けることが正解
```

## 本当の意味

```txt
箱は閉じ込めるためではない。
読まれると壊れる理由を、朝まで守るために閉じていた。
```

## 回収タイミング

Stage 3では、鍵穴が内側にある違和感だけ見せる。

Stage 5で、箱がランタンの灯りに反応して少しだけ開く。

Season 1後半で、箱は理由を守るための隔離だったと確定。

## リザルト文

初回:

```txt
箱には「開けるな」とだけ書かれていた。
```

箱影を倒した時:

```txt
鍵穴は、外ではなく内側を向いていた。
```

箱を守り切った時:

```txt
閉じたままだったから、消えずに残ったものがある。
```

不完全:

```txt
箱のふたが少し開いた。中の文字は、すぐ黒くにじんだ。
```

## ゲーム仕様

P2以降候補。

```txt
防衛対象
箱に近づくと敵挙動変化
一定時間守ると報酬
早く開けるとリスク
```

## 面白さの核

```txt
開けることが正解とは限らない。
プレイヤーに“触りたいけど怖い”を作る。
```

# 5. Stage 4: 切符のページ

## 役割

```txt
帰れなかったと思った道の反転
ミチルのSeed
場所と持ち主の接続
```

## 見せる小物

```txt
片方だけの切符
```

見た目:

```txt
古い駅の切符
片道に見える
裏面だけ少し温かい
```

## 敵の種類

```txt
切符影
```

意味:

```txt
帰れなかった、という固定された誤解
```

挙動:

```txt
一直線に突進する
時々逆方向へ走る
道しるべや切符の近くで迷うように曲がる
```

## プレイヤーの誤解

```txt
これは片道切符
誰かは帰れなかった
ミチルは道を残せなかった
```

## 本当の意味

```txt
帰り道は失われていない。
ただ、誰のための道か読めなくなっていた。
```

反転:

```txt
裏に帰りの印が残っている。
片道ではなかった。
```

## 回収タイミング

Stage 4で、裏面だけ温かい違和感を見せる。

Stage 5の灯りで、帰りの印が一瞬だけ読める。

Season 1後半で、帰り道はあったが接続が切れていたと確定。

## リザルト文

初回:

```txt
切符は片方だけ残っていた。
```

裏面Seed:

```txt
裏面だけが、少し温かかった。
```

切符影を多く倒した時:

```txt
帰り道は、なかったのではない。まだ誰の道か読めないだけだった。
```

不完全:

```txt
改札の向こうは見えた。でも、誰が帰る場所なのかは分からなかった。
```

## ゲーム仕様

P2以降候補。

```txt
突進敵
道しるべギミック
移動速度/進行方向補助
安全地帯生成
```

## 面白さの核

```txt
場所が分かっても、持ち主が分からなければ救いにならない。
```

# 6. Stage 5: 灯りのページ

## 役割

```txt
最初の5Stageの締め
トモリのSeed
朝まで残る意味の感動
```

## 見せる小物

```txt
直されたランタン
```

見た目:

```txt
小さなランタン
修理跡が複数ある
同じ場所を何度も直した跡がある
```

## 敵の種類

```txt
ランタン影
```

意味:

```txt
自分だけが待っていた、という固定された誤解
```

挙動:

```txt
灯りを避ける
暗い場所から湧く
ランタンの近くでは動きが鈍る
時々、ランタンを消そうとする
```

## プレイヤーの誤解

```txt
ランタンはただの光アイテム
トモリは待っていた子
ユイは自分の力で夜を歩いていた
```

## 本当の意味

```txt
ランタンは、仮接続した意味を朝まで保持する灯り。
トモリは待っていたのではなく、みんなが帰れるように灯りを直し続けていた。
ユイは一人で夜を歩いていたのではない。
```

## 回収タイミング

Stage 5で一部回収。

```txt
ランタンの修理跡が1人分ではない
名札/箱/切符が灯りで一瞬だけ反応する
```

Season 1終盤で完全回収。

## リザルト文

初回:

```txt
ランタンの火は、小さいのに朝まで消えなかった。
```

名札・箱・切符を見ていた場合:

```txt
灯りが当たると、名札と箱と切符が一瞬だけ同じ色に光った。
```

修理跡Seed:

```txt
ランタンの修理跡は、ひとり分ではなかった。
```

最初のページ締め:

```txt
朝になった。
このページの名前は、もう消えなかった。
```

不完全:

```txt
灯りは残った。でも、まだ照らしてはいけない文字があった。
```

## ゲーム仕様

P1終盤〜P2候補。

```txt
範囲光
一時安全地帯
瀕死時の残り火
朝到達演出
```

## 面白さの核

```txt
ずっと使っていた光が、実は意味を朝まで保つためのものだったと分かる。
```

# 9. 面白くするための注意

## しないこと

```txt
最初から世界法則を説明する
毎Stageで泣かせようとする
小物を大量に置く
敵をただの色違いにする
リザルト文を長くする
```

## すること

```txt
小物を1つに絞る
敵の挙動に意味を持たせる
リザルト文は短く刺す
ゲーム効果と小物の意味を合わせる
回収後に過去のプレイ体験が変わるようにする
```

---

# 10. 最初の5Stageの最終狙い

プレイヤーには最初こう思わせる。

```txt
拾うと強くなるゲームだ。
```

少しずつこう思わせる。

```txt
敵が変な動きをする。
小物がただの背景ではない。
```

最後にこう思わせる。

```txt
拾っていたもの、倒していた影、見ていた小物、全部に理由があった。
```

これが最初のページ束の面白さ。

# Revised Attractive Character Roster

## 目的

前回の20人案が弱かったため、キャラクターを作り直す。

問題は以下。

```txt
先生、妹、郵便屋などの役職だけで、惹きが弱い
プレイアブルとして使いたい魅力がない
最初の5人が物語を引っ張る存在になっていない
```

このドキュメントでは、最初の5人を「今後を惹きつける大事な人」として再設計し、残りの候補も後付けではなく、魅力と謎を持つキャラSeedにする。

---

# 1. 参考作品からの修正方針

## Digimon的に取り入れるもの

キャラには、本人の性格と連動した「印」や「相棒的な道具」を持たせる。

```txt
勇気、友情、知識、純真、希望のように、キャラごとに心の鍵がある。
```

Vamp Ponでは、紋章ではなく、以下に置き換える。

```txt
欠片の色
持ち物
ページの余白
必殺技の条件
```

## リトルバスターズ的に取り入れるもの

仲間の輪を最初から魅力にする。

```txt
バカっぽい日常の遊び
でも、後からその遊びが救いだったと分かる
```

## 十三機兵的に取り入れるもの

最初から全員を説明しない。

```txt
それぞれの視点が、あとから同じページに重なる
```

## グラナド的に取り入れるもの

キャラは単なる設定ではなく、使い分けの楽しさがある。

```txt
誰を使うかで、遊びのリズムが変わる
```

# 4. 修正後の判断

最初の5人は、Season 1の顔として使える。

追加15人は、すぐ出す必要はない。

しかし、以下のSeedだけは最初から置いてよい。

```txt
半分の飴
怖い先生のチョーク跡
にじんだ絵筆
未配達の封筒
四つ折りの地図
空白のカード
```

# 5. 最重要

前回の弱点は、キャラを役職として見ていたこと。

修正後は、キャラをこう見る。

```txt
使いたくなる性能
知りたくなる痛み
回収したくなる反転
残しておけるSeed
```

この4つがないキャラは、増やさない。

# Revised Attractive Character Roster

## 目的

キャラクター案を、現行の世界法則・関係性方針・きずなシステムと矛盾しない形へ更新する。

現行方針:

```txt
ユイ = 持ち主を間違えない子
アサ = 名前を失わせない子
友情 = メイン
恋愛 = サブ/別ページ束
重い関係 = サブ/後作/隠しページ
きずな = 意味の接続安定度
```

---

# 1. キャラ設計ルール

キャラは役職ではなく、以下で作る。

```txt
固定された誤解
本当は守っていた行動
小物
ゲーム効果
きずな相性
上振れ/下振れ
```

採用条件:

```txt
小物にできる
黒インクの誤解固定にできる
ゲーム効果にできる
回収後に意味が反転する
恋愛以外にも読める
```

# 2. 最初の5人

## 01. ユイ - 持ち主を間違えない子

### 表の魅力

やさしいが、少し抜けている。
落ちているものを見過ごせない。

### 固定された誤解

```txt
自分が忘れたせいで、大事な誰かを消したと思っている。
```

### 反転

```txt
忘れたのではない。
黒インクに固定される前に、意味を忘れ物へ分けて逃がした。
```

### 固有能力

```txt
持ち主を間違えない。
```

### 道具

```txt
夜の鉛筆
```

### プレイ感

```txt
安定型
欠片回収が強い
持ち主判定に強い
初心者向けだが、最後まで使える
```

---

## 02. アサ - 名前を失わせない子

### 表の魅力

明るい。少し調子がいい。
誰にでも変なあだ名をつける。
ただし、ユイだけは本名で呼ぶ。

### 固定された誤解

```txt
本当は、自分の名前を呼んでほしかった。
```

### 反転

```txt
名前は呼ばれなかったのではない。
黒インクに固定されないよう、何度も書き直されていた。
```

### 道具

```txt
名前のラベル
```

### プレイ感

```txt
敵に名前/印をつけて追加効果を出す
コンボ型
持ち主と名前の接続を安定させる
```

### 惹き

普段は軽いのに、名前の話になると急に黙る。
ユイとの関係は公式恋愛ではなく、恋愛ラベルの外にある強い関係。

## 03. ナギ - 壊れる理由をしまう子

無口で几帳面。
何でも箱にしまう。
小さなものを大事にしすぎる。

### 固定された誤解

```txt
しまったせいで、誰にも届かなかったと思っている。
```

### 反転

```txt
閉じ込めたのではない。
読まれると壊れる理由を、朝まで守るためにしまった。
```

### 道具

```txt
月の箱
```

### プレイ感

```txt
防御/保存/カプセル型
危険な理由の欠片を一時保護する
```

### きずな相性

```txt
手紙系統とは不安定。
しまうことと届けることが衝突する。
```

## 04. ミチル - 返す場所を読む子

### 表の魅力

少し皮肉屋。
地図を読むのが異様にうまい。
迷子を見ると放っておけない。

### 固定された誤解

```txt
一番帰らせたかった人を帰せなかったと思っている。
```

### 反転

```txt
帰る道は残していた。
ただ、誰のための道か読めなくなっていた。
```

### 道具

```txt
金のコンパス
```

### プレイ感

```txt
高速移動/位置取り/安全地帯型
返す場所を読む
上級者向け
```

### きずな相性

```txt
帰りたくないキャラと不安定。
道があることと、帰りたいことは同じではない。
```

にこにこしているが、少し影がある。
壊れたものを直すのが好き。

```txt
自分だけが待っていたと思っている。
```

```txt
待っていたのではなく、みんなが帰れるように灯りを守っていた。
```

### 道具


### プレイ感

```txt
範囲攻撃/光/必殺技型
```

# 3. 追加候補: 関係性エンジンで作る

## リオ - 嘘を守った兄

```txt
関係Seed: 兄妹 / 嘘の約束
固定された誤解: 妹を安心させるための嘘が、裏切りとして固定されている
反転: 嘘だったはずの約束を、本人だけが守り続けていた
道具: 半分の飴
プレイ感: 分裂弾/回復/危険時強化
```

## コヨリ - 名前をほしがる妹

```txt
関係Seed: 妹 / 後回しにされた名前
固定された誤解: いつも後回しにされて、自分の名前だけ空白だと思っている
反転: 一番消えない場所に、最初に名前を書かれていた
道具: 小さな名札
プレイ感: 小型サポート/欠片自動回収
```

## センリ - 怖い先生

```txt
関係Seed: 師弟 / 導くと縛るの境界
固定された誤解: 厳しくしたせいで、嫌われたと思っている
反転: その一言が、忘れ物係の始まりになっていた
道具: チョークの線
プレイ感: 敵の進路制御/結界線
注意: 先生/生徒は恋愛にしない
```

## ゲン - 道を忘れたおじいちゃん

```txt
関係Seed: 古い道 / 先に老いる相棒Seed
固定された誤解: 自分の古い記憶は、もう誰の役にも立たないと思っている
反転: 古い道だけが、黒インクに固定されても消えずに残っていた
道具: 古い相棒のバッジ
プレイ感: 過去ルート表示/移動補助
```

## ユウビ - 届けない郵便係

```txt
関係Seed: 届ける人 × 届けてはいけない手紙
固定された誤解: 手紙を届けなかったせいで、誰かを傷つけたと思っている
反転: 届くと壊れる意味を守るために、あえて止めていた手紙もあった
道具: 未配達の封筒
プレイ感: 遅延追尾弾/届ける届けない分岐
```

## ヒナギ - 年を取らない魔女

```txt
関係Seed: 年を取らない魔女 × 年を取る人間
固定された誤解: 同じ約束を覚えているのに、同じ速さで年を取れないことが“置いていく”として固定されている
反転: 置いていったのではなく、毎年同じ日付だけを守り続けていた
道具: 止まった懐中時計 / 毎年同じ日付の手紙 / しおれない花
プレイ感: 時間停止/遅延ダメージ/昔の姿の影
採用位置: Season 1ではSeedだけ、2以降の主題候補
```

```txt
反転: 作られたものでも、本当の持ち主と意味を持っていた
```

# 4. 男同士の関係性方針

男同士は公式恋愛にしない。

ただし、強い関係は作る。

```txt
相棒
幼なじみ
ライバル
悪友
兄弟みたいな関係
嫌いだけど背中を預ける関係
```

BLを狙って押しつけない。

友情を恋愛の下位互換にしない。

---

# 5. 百合/恋愛方針

百合は入れてよいが、Season 1のユイ/アサには公式恋愛として載せない。

恋愛はサブ/別ページ束へ分散する。

向いている枠:

```txt
届かなかった手紙
写っていない写真
年を取らない魔女 × 年を取る人間
```

---

# 6. きずなシステムとの接続

キャラごとに、きずなタイプを持たせる。

```txt
安定
不安定
片寄り
禁忌
```

例:

```txt
ユイ + トモリ = 安定
ユイ + カガリ = 不安定
ナギ + ユウビ = 不安定
ミチル + ソウマ = ライバル不安定
ユイ + ヒナギ = 片寄り/時間差
```

---

# 7. 最重要

魅力的なキャラは、設定が濃いだけでは足りない。

```txt
誤解
反転
小物
ゲーム効果
きずな相性
```

が全部つながって初めて、Vamp Ponのキャラとして採用する。

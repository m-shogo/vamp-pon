# Background Relationship Seeds

## 目的

未登場キャラ、家族、先生、昔の知人、別グループの存在を、後付けに見えないように最初から仕込む。

名前を出さず、関係語や一言だけで余白を残す。

---

# 1. 方針

キャラ名はすぐ出さない。

代わりに、以下を出す。

```txt
お兄ちゃん
妹
先生
おじいちゃん
あの子
隣の子
前の持ち主
地図を描いた人
ランタンを直した人
```

名前は後でよい。

関係語だけで、プレイヤーは勝手に想像する。

---

# 2. なぜ関係語が強いか

名前より関係語の方が余白がある。

## 名前を出す場合

```txt
これはトモリのランタンです。
```

情報が閉じる。

## 関係語で出す場合

```txt
「灯り、消さないで」
横に、小さく“お兄ちゃんへ”と書かれている。
```

誰の兄か、誰が書いたか、まだ分からない。

後で回収できる。

# 4. 「カゲール」型グループの扱い

## 内部名

```txt

```

意味:

```txt
まだ表に出さない別グループの仮名
```

## ゲーム内表現

直接「カゲール」とは言わない。

使うなら以下。

```txt

黒い折り紙

```

## 役割

```txt
Season 2以降のグループ候補
敵ではなく、別の方法で記憶を守っていた子たち
ユイたちとは別の価値観を持つ
```

# 6. 一言Seedのルール

## 良い一言

```txt
誰が言ったか分からない
でも感情がある
後で複数キャラへ接続できる
説明ではなく記憶の断片
```

## 悪い一言

```txt
真相を言い切る
固有名詞が多い
長すぎる
伏線だと露骨
```

---

# 7. 配置密度

一言Seedは強いので、出しすぎない。

目安:

```txt
1Stageに1〜2個
1リザルトに0〜1個
図鑑に数個
```

多すぎると、ゲームが暗号解読になる。

---

# 8. 後付け防止ルール

将来、新キャラや新Stageを追加する時は、既存の一言Seedへ接続する。

悪い:

```txt
突然、新キャラが重要人物として登場
```

良い:

```txt
前から出ていた「先生」の言葉の持ち主だった
前から出ていた半分の切符の相手だった
前から出ていた郵便屋の手紙の話だった
```

---

# 9. 余白を壊さないルール

すべての関係語を回収しない。

回収するもの:

```txt
Seasonの感情に必要なもの
プレイアブル化するもの
Stageの軸になるもの
```

残すもの:

```txt
街の生活感
他の人もいた証拠
次のアプリの余白
```

---

# 10. 最重要

名前を出すより、関係を先に出す。

```txt
お兄ちゃん、妹、先生、おじいちゃん。
```

この一言だけで、世界は広がる。

Vamp Ponは、キャラ名を増やすIPではなく、

```txt
誰かが誰かを見ていた痕跡を拾うIP。
```

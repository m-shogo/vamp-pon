# Emotional Relationship Archetype Catalog

## 目的

Vamp Ponで使える、エモい関係性の型を整理する。

これは恋愛カタログではない。

```txt
友情
相棒
敵対
疑似家族
時間差
異種族
寿命差
約束
別離
再会
一方通行の理解
```

など、いろいろな関係性フェチに刺さる型を、Vamp Ponの世界法則に変換するための素材集。

---

# 1. 採用方針

Vamp Ponでは、関係性を以下のように扱う。

```txt
恋愛 = サブ
友情 = メイン
重い関係 = サブ/後作/隠しページ
男同士 = 公式恋愛ではなく強い友情・相棒・対立
百合 = サブ/別ページ束なら可
```

重要なのは、関係性そのものを目的にしないこと。

```txt
どの誤解が固定されているか
どの小物に残っているか
どの順番でほどくと救いになるか
```

まで落とす。

# 2. 採用優先度S

## S1. 年を取らない魔女 × 年を取る人間

刺さる理由:

```txt
同じ約束を覚えているのに、同じ速度で時間を進めない。
```

Vamp Pon変換:

```txt
人間側: 置いていかれた、と思う
魔女側: 置いていった、と思う
黒インク: “同じ時間にいられなかった”という意味を固定する
```

小物:

```txt
止まった懐中時計
毎年同じ日に届く手紙
若いままの写真
しおれない花
古いリボン
```

ゲーム効果:

```txt
時間停止
遅延ダメージ
年輪状の範囲攻撃
昔の姿の影が一瞬だけ見える
```

採用位置:

```txt
Season 2以降
別ページ束
百合/恋愛/友情どれにも読める強関係
```

採用位置:

```txt

```

注意:

```txt
直接かぐや姫をなぞらない。

```

# 8. システムへの接続

関係性は、ただのシナリオではなくゲームに接続する。

```txt
寿命差 = 時間停止/遅延/年月ゲージ
封印 = 箱/一時保護/開ける順番
敵対理解 = 不安定きずな/上振れ下振れ
ライバル = 高火力コンビ/反動あり
無口×おしゃべり = 詠唱短縮/沈黙耐性
人形×人間 = 復活/身代わり/耐久
```

---

# 9. 最重要

Vamp Ponで関係性を採用する条件。

```txt
小物にできる
黒インクの誤解固定にできる
ゲーム効果にできる
回収後に意味が反転する
恋愛以外にも読める
```

この条件を満たす関係性だけ採用する。

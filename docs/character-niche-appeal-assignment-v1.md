# ヨルノシルベ — Character Niche Appeal Assignment v1

Date: 2026-08-10  
Status: **CANDIDATE ASSIGNMENT / NOT AUTO-CANON**

> `character-niche-appeal-fetish-matrix-v1.md` の刺さり候補を、Current21 + Future15へ実際に分散するためのAssignment。
>
> 目的は「属性コンプリート」ではない。**一人を見た時、体型・声・手・服・生活・関係のうち最低3箇所で交換不能な印象が出る**状態を作る。

---

# 0. Rule

各人物に:

```txt
Primary appeal  = 2〜3
Secondary appeal = 2〜4
Relationship payoff = 1〜2
```

を置く。

- 同じhookの重複は可。ただし出方を変える
- 体型やrepresentationだけをCoreにしない
- 年少人物は非性的な生活 / 成長 / 関係の魅力だけを扱う
- 幼く見える長寿成人は成人として明確化し、性的child codingをしない
- 「ツンデレ」「クール」等は固定ラベルではなく関係で崩れる挙動として使う

> **ヨルノシルベでは「この設定が好き」だけで終わらず、“この人の眼鏡を拭く癖が好き”“この人の手が好き”“この人が怒ると静かになるのが好き”“この二人が喧嘩中でも連携だけ完璧なのが好き”まで、推し方の入口を全員に複数持たせる。**

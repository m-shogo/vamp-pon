# 2. Game identity

ヨルノシルベは:

> **夜の中で大量の影をほどき、記憶片を拾い、そのrunだけの強いbuildを作り、Character / Support / 黒耀化 / Stage条件を変えて何度も朝を目指すヴァンサバ系周回アクション。**

Core:

- 1run中に強くなる
- buildを試す
- Characterごとのplay feel
- Support / BondがGameplayへ返る
- 黒耀化は危険だが強い選択
- fail-forward
- Story informationはplayの副作用
- 正史はHappy End
- permanent deathを主な泣き装置にしない
- Game Over = 死亡ではない
- retry / replayをStoryへ自然に重ねる

# 3. Current world laws — Title 1 Canon

Authority:

- `docs/title1-world-law-canon-v1.md`

## Night

**人・物・言葉・記録に残る「まだ一つに決め切れない意味」が、現実の時代を越えて重なる境界層。**

- 別時代の人物がNightで出会える
- 物 / 言葉 / 記録は現実時間の因果を守って後世へ渡る
- dream / simulation / death realmのどれか一つへ固定しない
- 一人の万能Creatorが完成systemとして作ったものにはしない
- 複数時代のmaintainerが帰路 / 観測 / 記録 / 保管を継ぎ足してきた
- Nightは局所layerが重なり合い、Named Object / routeがbridgeになり得る

## Black Ink

**悲しい感情そのものではなく、出来事や自分自身へ付けた「一つの意味だけが正しい」という固定化がNightで形を持ったもの。**

Current defeat verb:

# **ほどく**

ほどく = 出来事を消すことではない。
本人が別の意味も選べる余地を取り戻すこと。

## 黒耀化

```txt
本人の長所
+ 守りたいもの
+ 恐怖 / 焦り
+ 「この方法しかない」という固定
→ 黒耀化
```

外部悪人格ではない。
成長後も元の長所を捨てない。

## Star Beast

人物の価値観と、人間が長い歴史の中で星へ見出した生物星座の意味がNightで共鳴し、行動できる姿を得た観測伴走者。

知る:

- route distortion
- repetition
- Named Object resonance
- Character状態変化

知らない:

- 人間の本心の最終答え
- future
- Main Mystery完全解

万能説明NPCにしない。

# 5. Character-specific Canon locks

## ユイ × トモリ

Current Canon:

- トモリはユイより前の現実時代で生きている
- トモリは、後世でユイへ届く **同じ物理ランタン** を修理した
- ランタンはNight teleportではなく、現実時間の中で複数の手を経てユイへ届いた
- ユイの修理痕にはトモリの仕事が含まれる
- 二人のLeo共有は同じ灯り / Named Object lineageへの共鳴
- **血縁Canonにはしない**

OPEN:

- 中間所有者
- exact years
- original maker

## クロオリ

Current Canon:

- 本人が「今は返さないで」と選んだ記憶を開く時まで預かる
- memory thief / simple villainではない
- 初期は「開かないこと」を安全にしすぎる
- ユイは「返すこと」を善にしすぎる
- 作品1では双方が「本人が選ぶ」へ戻る

## ユイのvoluntary sealed memory

Current Canon:

**過去のユイ自身が、クロオリへ一つだけ「今は返さないで」と記憶を預けている。**

核:

- ユイが初めて「返すことが必ずしも優しさではない」と直面した出来事
- 持ち主本人から「まだ返さないで」と頼まれた
- 当時のユイは「返せなかった = 自分の失敗」と一つの意味へ固定した
- 別の読み方をできる時までクロオリへ預けた

具体的な忘れ物 / 持ち主identity / 開封sceneのexact detailはCharacter Mysteryとして追加設計する。

# 8. Strong Named Object law

Current Canon:

> **Nightで強い痕跡を持つNamed Objectは「感情が激しかった物」ではなく、複数の人が現実時間の中で『どう残すか』を自分で選んだ物。**

例:

- repair
- preserve
- handoff
- wait before delivery
- rename
- keep a scar
- choose not to restore to original

物理objectは現実時間のhandoffを必要とする。
Night teleportでhistoryを飛び越えない。

ユイのランタンが強いのは主人公神器だからではない。
複数人の「残し方」の選択が積層しているため。

この法則をヨルノシルベ2の継承テーマへ接続する。

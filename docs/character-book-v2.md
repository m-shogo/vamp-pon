# 1. 作品の人物トーン

ヨルノシルベの世界は暗い。

でも、人間まで全員暗くしないし、全員を無理に明るくもしない。

この世界には、明るい人、ネガティブな人、無口な人、強気な人、怖がり、ギャル、お嬢様、子ども、ぽっちゃりした人、渋い大人などが同時にいる。

大事なのは性格を均すことではなく、**全員がその人らしいまま成長すること。**

成長は性格の矯正ではない。

- ネガティブな人が、ネガティブなまま人を頼れる
- 無口な人が、無口なまま必要な時に名前を呼べる
- 明るい人が、明るいまま弱音も見せられる
- 強い人が、人に任せられる
- 優しい人が、自分も助けてもらえる

という変化でよい。

# 5. 強い関係性

## ユイ × アサ

**USER DIRECTION: 主人公級バディ。恋愛なし。**

ユイは待てる。アサは先へ走る。

序盤は噛み合わない。中盤で互いの長所に助けられ、本気で衝突する余地もある。終盤は同じ考えになるのではなく、違いを理解したまま相手を選べる関係へ。

参考にしたいのは「ナルトとサスケ」のコピーではなく、**二人とも物語の主体で、片方が片方の付属品にならない強度**。

## リツ × コヨリ

**CANON: 兄妹。恋愛なし。**

兄が妹を守る一方向だけにしない。

リツは任せることを覚え、コヨリは守られるだけでなく兄を救えるようになる。

参考にしたいのはエドとアルのような、**兄弟・兄妹が互いに互いを救う主体である関係**。

## ユイ × クロオリ

「取り戻す」ユイと「閉じて守る」クロオリ。

どちらも完全には間違っていない。

互いに相手の守り方を知ることで成長する。

## ユイ × トモリ

**CANON: 同じ獅子座。関係の正体は未確定。**

候補:

- 親族
- 遠い血縁
- 火の系譜
- 継承者
- 同じ記憶火から分かれた存在

同じ星獣が先に伏線として見える。

# 8. Bond / Support — 一緒に戦うほど仲良くなる

詳細: `docs/character-bond-support-system-v1.md`

**USER DIRECTION:** 戦いでは仲間を呼べる。

```txt
仲間をSupportとして呼ぶ
↓
一緒に戦う / 助ける
↓
Bondが上がる
↓
日常会 / リザルト / 戦闘中台詞が変わる
↓
名前の呼び方 / 敬語 / 冗談 / 弱音がキャラごとに変化
↓
Personal Trait / Pair Trait / Assist / 灯合わせが強くなる
```

Bondは恋愛値ではない。

兄妹、友情、師弟、ライバル、親族、恋愛のすべてで使える関係経験。

## 呼び方の変化は全員同じにしない

- ユイ型: 「アサちゃん → アサ」のように呼び方が変わる
- アサ型: 名前は変えず、「先行く → 一緒に行く」のように言葉の内容が変わる
- 無口型: 名前を呼べること自体が大イベント
- お嬢様型: 礼儀は残しつつ少し自然な言葉になる
- ゲン型: 呼び方より、自分の失敗談を話せるようになる

## 戦闘でも成長する

Bond成長を単純な攻撃力+%だけにしない。

人物成長と性能を接続する。

例:

- アサ: 単独先行 → 主役と速度を合わせるAssist
- カナメ: 自己犠牲だけ → 交互防御
- レン: 弱点を見つけるだけ → 仲間へ弱点windowを共有

Core 5には既に10組の「灯合わせ」canonがあるため、その土台へ接続できる。

# 9. 日常回

日常回はギャグ回だけではない。

- 明るい日常
- 静かな日常
- 気まずい日常
- ネガティブな日常
- 仲直り前の日常
- 星獣だけが騒いでいる日常

全部あり。

重要なのは、戦闘以外でも「この人たちと過ごしたい」と思える時間を作ること。

## Seed: 喧嘩した次の日

ユイとアサはほぼ会話しない。

でもアサはユイのカップへ名前を書き、ユイはアサの忘れ物を机へ置く。

その回では仲直りしなくてもいい。

## Seed: 星獣が帰ってこない

ユイの子獅子を皆で探す。

最後にトモリの若獅子の隣で寝ている。

楽しい日常でありながら、同じ獅子座の伏線にもなる。

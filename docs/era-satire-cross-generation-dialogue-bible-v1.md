## What to learn

風刺の対象は「人そのもの」より:

- 制度の矛盾
- 建前と実態
- 便利さの副作用
- 流行に全員が乗る不思議さ
- 仕事 / 学校 / 家庭の理不尽
- 新しい技術に人間が振り回される様子
- 古い常識が新しい世界では妙に見えること
- 新しい常識が古い人から見ると妙に見えること

に置く。

# 2. Hard rules

## 双方向

```txt
昔のCharacter → 現代を風刺
現代Character → 昔を風刺
未来Character → 現代を風刺
現代Character → 未来を風刺
```

一方向にしない。

## 禁止

- 昔のCharacterを無知な田舎者役へ固定
- 現代Characterを文明の先生へ固定
- Future Characterを全部知っている上位存在へする
- 戦争 / 公害 / 貧困 /差別等の被害そのものを笑いにする
- 実在被害者 / 実在事件の台詞を笑いへ転用
- 古語を毎行使って歴史コント化
- 若者言葉を大量に入れてすぐ古くなる脚本

狙うのは:

> **人を笑うのではなく、その時代では普通だった仕組みを別時代の目で見ると少し可笑しい。**

# 4. Tomori ↔ Yui — 「便利」と「直せる」

## Theme

Tomori:

> 壊れたら開ける / 直す / 部品を使う。

Yui:

> 壊れたら交換 / update / serviceへ出すことも普通。

## Candidate scene A — sealed device

Yui:
> 「それ、開けない方がいいよ。保証なくなるかも。」

Tomori:
> 「壊れてるのに、開けたら困るのか？」

Yui:
> 「……言われると変だね。」

Tomori:
> 「未来の道具は丈夫なんじゃなくて、怒られるから開けないのか。」

### Satire target

- repairability
- consumer convenience
- warranty / ownership contradiction

Do not make Tomori always correct. Later a modern sealed safety device can genuinely be safer not to open.

## Candidate scene B — read receipt

Yui:
> 「読んだって出てるのに返事ないと、ちょっと気になる。」

Tomori:
> 「読んだかどうかまで分かるのか。」

Yui:
> 「分かる。」

Tomori:
> 「便利になったのに、待つ材料が一つ増えたな。」

Yui:
> 「……それはそう。」

### Satire target

便利さが不安も増やす。

# 10. Party satire engine

Boss後Partyは風刺を置きやすい。

## 焼肉

- Tomori: disposable plate / grill constructionを見る
- Michiru: 「一番近い肉ばっか取るな」→ route joke
- Nagi: 人の皿へ勝手に置かない
- Yui: 写真撮る前に食べられて怒る
- Asa: 焼肉の部位名とsystem designationの違いに変なこだわり

## 酒席 — adult only

年代差を:

- 注ぎ方
- 乾杯
- 二次会
- 上下関係
- 誰が先に帰れるか

へ使える。

しかし古い飲酒慣習を無批判に肯定しない。
現代側から:

> 「飲めない人まで飲む前提だったの？」

昔側から:

> 「今は断れるのに、帰る連絡だけは全員に送るのか。」

のように双方向にする。

## Tobacco

喫煙者3+ / pipe1+は別Authority。

風刺例:

- 昔側: 喫煙が普通だった場所への距離感
- 現代側: 「ここで吸っていいの？」
- 喫煙者本人: Dreamなのに無意識に端へ移動する

喫煙そのものを格好良さだけで売らない。

# 11. Satire escalation ladder

同じ年代ネタを説明しすぎない。

```txt
Level 1: 小さな違和感
Level 2: 軽い笑い
Level 3: Character同士の価値観衝突
Level 4: Era大事件の制度矛盾と同型だと分かる
Level 5: 後半Callbackで意味が反転
```

Example:

Early:
> 「友達百人って小さい町じゃない？」

Mid:
> Nagiが公開範囲を巡ってYuiと喧嘩する。

Era Incident:
> Shared warning networkが誰かを静かに排除する。

Late Callback:
> Yui自身が「見せる相手は本人が決める」と言う。

ギャグがThemeへ成長する。

# 12. Learning without lecture

Playerが年代を学べる情報は、会話の答えではなく**比較対象**として置く。

Bad:

> 「1973年には石油危機が起こって……」

Good:

> 「電気消して。」
> 「まだ明るいよ？」
> 「明るい時に消すの。」
> 「……なんで？」
> 「そういう時期があったんだよ。」

この後すぐhistory lectureへ行かず、Character behaviorとして残す。

Exact historical knowledgeはLorebook / optional archiveへ回せる。

# 13. Satire QA

新しい年代ギャグを書く時:

- 誰が笑われている？ `person`なら再考、`system / custom / contradiction`なら良い。
- 逆方向のツッコミも作れるか？
- 別Eraへ移して同じ jokeが成立しすぎないか？
- Character Coreへ戻れるか？
- 実在悲劇の被害を軽くしていないか？
- 5年後にobsoleteなbrand / memeへ依存していないか？
- 一度の会話で年代を確定Revealしていないか？

Target:

> **笑っていたら、そのCharacterの時代が少し分かっていた。**

これを年代会話の品質基準とする。

# Loading Quotes Safe Japanese Renderings

Vamp Pon / ヴァンサバ改のロード画面で使う名言引用に、日本語の意味も添えるための安全運用資料。

目的:

```txt
引用は残す。
作者と出典も出す。
日本語の意味も分かるようにする。
ただし既存翻訳を使わない。
Vamp Pon用の短い自前意訳として管理する。
```

---

## 1. 商用安全ルール

```txt
原文は、公有領域・古典・ことわざ候補を中心にする。
既存の日本語訳、現代語訳、出版社訳、映画字幕訳、漫画台詞訳は使わない。
日本語は「Vamp Pon用意訳」として新規に作る。
最終商用前に、引用候補と意訳文を法務/ライセンス確認する。
```

重要:

```txt
日本語訳も著作物になり得る。
そのため、既存訳を参照して似せない。
原文から意味だけを取り、Vamp Ponの世界観に合う短い日本語へ置き換える。
```

UI上の表記:

```txt
原文
— 作者, 作品

Vamp Pon用意訳
```

または、通常ロードでは原文だけ、長めロード/図鑑では意訳も表示する。

---

## 2. 表示パターン

### 通常ロード

```txt
We grow accustomed to the Dark.

— Emily Dickinson
```

### 長めロード / 図鑑 / 記録室

```txt
We grow accustomed to the Dark.

— Emily Dickinson

暗闇にも、人は慣れてしまう。
```

### キャラ反応つき

```txt
We grow accustomed to the Dark.

— Emily Dickinson

暗闇にも、人は慣れてしまう。

慣れたくなんか、なかったけど。
— アサ
```

反応が付く場合は、最低表示時間を長くする。

```txt
Quote only: 3.2秒以上
Quote + 意訳: 4.6秒以上
Quote + 意訳 + キャラ反応: 6.2秒以上
```

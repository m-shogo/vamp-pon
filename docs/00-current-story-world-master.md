## 1. 現世と年代

- 現世は**現実の日本**。
- 現代編は生活、言葉、交通、決済、通信、制度、服装、UI等を複数組み合わせ、現代日本に間違いない表現にする。
- 東京、新宿、渋谷など実在地名を必要以上に偽名化しない。
- 人物は同時代とは限らない。
- 現在の主要laneは1940年代系 / 1980年代系 / 2000年代系 / 現代 / 20XX以降のAndroid・Robot世代。
- **世代数は固定しない。** 新世代が増えれば事件・世代ラスボス側も増やす。

## 3. 年代差の伏線

ヨルノシルベでは西暦・正確な年月・歴史順序などの「時間タグ」が弱い。

年代差は説明ではなく、切符、郵便、地図、駅、教育用語、本の版、時計、服、修理方法、食文化、機械UI、制度、言葉などから少しずつ出す。

古い年代の人物が現代語を知らなくても、夢の自然さによって即座に時間移動を疑わない。

## 4. 星空 / 星座

- **ヨルノシルベでは星は見える。** 星空そのものは重要なvisual identity。
- ただし、**1940年代系の人物と現代人物では、ヨルノシルベで認識する星座が同じとは限らない。**
- 同じ星が見えていても、星の結び方、星座名、星座に付随する物語が違うことがある。
- **昔はあったが今はない星座**を作ってよい。
- **昔にはなかったが今はある星座**を作ってよい。
- 「星は見えるのに、その星座を知らない」「昔はその並びに名前があった」を年代差とMain Mysteryの伏線にする。
- 現実の公式天文学を改変するという意味ではなく、ヨルノシルベ側の星座認識・結び方の異常として扱う。
- 星獣との関係は重要だが、星座が増減する最終原因はまだLOCKしない。

# 1. 夜 — Current Canon

## 定義

**夜は、人・物・言葉・記録に残った未完の意味が、現実の時代を越えて重なる境界層。**

- 現実世界そのものではない
- 単なる夢ではない
- simulationと断定しない
- 死後世界と断定しない
- 現実で別時代に生きる人物同士が夜では出会える
- Named Object / 記録 / 言葉は現実時間を通じて後世へ渡り、その履歴が夜で重なる

## 夜の重要な性質

1. **別時代接続**  
   同じ西暦に存在していない人物同士でも夜では同席できる。

2. **意味の重なり**  
   同じ物でも、持ち主・修理者・記録者が違えば複数の意味を持つ。

3. **朝へ帰れる**  
   夜は閉じた監獄ではない。朝へ戻る経路が存在する。

4. **現実へ痕跡が残る**  
   夜で得た全情報をそのまま持ち帰るとは限らないが、選択・癖・物の扱い・修理痕・言葉などの形で影響が残る。

5. **全知空間ではない**  
   夜へ来れば過去の真相が自動的に分かるわけではない。観測・関係・物証が必要。

## 作品1でLOCKしないもの

- 夜が物理空間か精神空間かという最終宇宙論
- 最初の発生年代
- 世界で唯一の現象か
- 最初に夜を観測した人物

これらはSeries Mystery。

# 2. 夜は「一人の創造主が全部作った」ものではない

Current Canon:

**夜そのものの発生と、夜を安全に観測・帰還できる仕組みは分ける。**

- 夜は一人の万能な創造者が最初から設計したsystemではない
- 人々の記憶・物・意味の蓄積から自然発生的に生まれた可能性をCurrent baseとする
- 後の時代に複数の人物 / 集団が、帰路・観測・記録・保管の方法を整えてきた
- 現在使われている仕組みが最初期と同じ形とは限らない

Seriesで追う問い:

> 「夜を作ったのは誰か」ではなく、**「夜を帰れる場所へ変えてきた人たちは誰か」**。

# 3. 黒インク — Current Canon

## 法則

**黒インクは悲しみ・怒り・恐怖そのものではない。出来事や自分自身へ付けた『一つの意味だけが正しい』という固定化が、夜で形を持ったもの。**

例:

```txt
「失敗した」
↓
「失敗したから自分には価値がない」
↓
他の読み方が閉じる
↓
黒インクが濃くなる
```

重要:

- 悲しい感情 = 悪ではない
- 忘れること = 解決ではない
- 出来事を無かったことにしない
- 記憶を全部返すことが常に正しいわけではない
- 本人が意味を選び直せる余地を取り戻すことが「ほどく」

## Enemyとの関係

影 / 黒インクEnemyは単純な悪意の生物ではない。

- 固定化した意味
- 守るために閉じたもの
- 繰り返された恐怖
- 誰かの言葉の残響

などが夜でpressureを持った形。

だからEnemy defeatのCurrent verbは **「ほどく」**。

# 4. 黒耀化 — Current Canon

黒耀化は黒インクの人格乗っ取りではない。

```txt
本人の長所
+ 守りたいもの
+ 恐怖 / 焦り
+ 「この方法しかない」という固定
↓
黒耀化
```

Character growth後も元の長所を捨てない。

例:

- ユイ: 戻す力を捨てない。ただし全部を勝手に戻さない
- ナギ: 閉じる力を捨てない。ただし誰のためにいつ閉じるかを選ぶ
- トモリ: 直す力を捨てない。ただし傷跡まで消さない
- クロオリ: 預かることを捨てない。ただし永遠に閉じるのではなく本人の選択時を守る

Rescueは「仲間が治療する」ではなく、本人が一方向以外の選択を取り戻すこと。

# 5. 記憶片 / Level Up / Retry の二重意味

作品1のGameplayとStoryを次で接続する。

## 記憶片

- gameplay: EXP / build resource
- story: 固定された意味から剥がれ、別の読み方を持てる小片

## Level Up

- gameplay: 選択肢が増える
- story: そのrunで扱える「読み方」が増える

## Game Over

- 死亡ではない
- 「そのbuild / その読み方では朝まで届かなかった」

## Retry

- 正史を巻き戻すtime-loopとは限らない
- 夜の未確定性を別の選択で読むplay structure

## Dawn

- 全ての記憶を完全保存する地点ではない
- そのrun / storyで得たものの中から、現実へ持ち帰る意味が定着する地点

# 6. 星獣 — Current Canon

## 定義

**星獣は、その人物の価値観と生物星座が夜で共鳴し、行動できる姿を得た観測伴走者。**

- zodiac占いではない
- 前世 / 神話人物の転生ではない
- Character本人の分裂人格ではない
- 万能な神 / 召喚獣ではない
- かわいいmascot性を持ってよい
- Characterと別個体として小さな癖・好みを持てる

## 見える範囲

Current rule:

- 夜では、星獣が安定して現れた後は夜の参加者同士で基本的に視認できる
- 本人とのBondが強いほど仕草 / 星線 / 意図を読みやすい
- 現実世界では通常の物理動物として常在しない
- 朝の後に夢、癖、絵、足跡めいた痕跡、無意識の仕草として残る場合がある

これにより集合scene / relationship / merchandiseで星獣を共演させられる一方、現実世界の日常を常時magic animal worldへ変えない。

# 7. 星獣が知っていること / 知らないこと

## 察知できる

- 夜のrouteの歪み
- 同じ場所 / patternの反復
- Named Objectに残る強い共鳴
- 自分のCharacterの状態変化

## 知らない

- 未来の確定結果
- Main Mysteryの完全な真相
- 誰が正しいか
- 全Characterの過去

Star Beastへ質問すればMysteryが解ける構造を禁止する。

- 記憶を盗む人ではない
- 全てを隠すことが正しいとも思っていない
- 当初は「開かないこと」を安全と見なしすぎる

# 13. Dawn / Happy End

朝は「全部忘れて元通り」ではない。

**夜で選び直したことが、現実の小さな行動へ戻る。**

例:

- 前なら捨てた紙を一度保留する
- 名前を書く前に本人へ聞く
- 壊れた跡を一つ残して修理する
- 手紙を今渡すか待つか選ぶ
- 閉じる前に帰る人がいないか確認する

大事件を消さず、意味の固定がほどけたことを日常で証明する。

これがヨルノシルベのHappy Endの最小単位。

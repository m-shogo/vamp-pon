# Stage1 Fun Pass 2026-06-17

## 目的

Stage1を「素材が出ている」状態から「序盤から気持ちよく、少し考える」状態へ寄せる。

ユーザー報告では、敵が硬すぎることよりも「数を増やしても面白くない」ことが問題だった。
そのため、今回の調整ではHPを上げるより、敵の役割差とウェーブの緩急を優先する。

## 今回入れた方針

### 1. 敵の役割を増やす

既存の追尾一辺倒から、以下を追加した。

- `charger`
  - 予兆 → 突進 → 硬直
  - 避けて倒す気持ちよさ担当

- `orbit_chase`
  - 近距離で回り込み
  - 包囲感と逃げ道選び担当

- `coward`
  - 近づくと逃げる
  - 追いかける小目標担当

### 2. 序盤60秒を濃くする

旧構成ではLv1〜5までが寂しくなりやすかった。
新構成では45〜75秒までに、追尾・突進・回り込みを混ぜる。

目的は難易度上昇ではなく、早い段階で「このゲームは動きの違う敵が出る」と伝えること。

### 3. エリートを3:00から2:30へ前倒し

最初のカプセル体験が遅いと、Stage1の縦スライスとして報酬テンポが弱い。
2:30に前倒しして、初回プレイでも進化/カプセル導線を見せやすくする。

### 4. 暴走に終了後疲労を追加

暴走は強いが、使い得だけだと必殺技と区別が弱い。
終了後0.8秒だけ移動速度を落とし、暴走らしい反動を作る。

現状は安全のため移動速度だけ。
将来は攻撃速度低下、黒炎エフェクト、HUD点滅を追加する。

## 次にやるべきこと

### 必須

- ローカルで `pnpm test` / `pnpm build`
- 実機スマホ幅で序盤2分を確認
- charger が理不尽に見えないか確認
- coward が画面外へ逃げすぎないか確認

### 次の面白さ改善

- charger の予兆エフェクト
- coward の報酬感強化
- orbit_chase の回り込み量調整
- 1:30〜2:30に休憩波を1つ作る
- 暴走終了時の黒炎/スロー演出

## 判断基準

Stage1の序盤2分で以下を満たせば成功。

- 20秒以内に初撃破が発生する
- 45秒以内にLv2が見える
- 75秒以内に3種類の敵の違いが分かる
- 150秒付近で初エリート/カプセル導線が見える
- 被ダメージで暴走が溜まることが自然に理解できる

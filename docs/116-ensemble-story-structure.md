# Ensemble Story Structure

## 目的

Vamp Ponの物語を、ユイとアサだけの閉じた話にしない。

キャラクター同士の仲の良さ、群像性、視点の反転、次へ投げるクリフハンガーを設計する。

目標は以下。

```txt
最初は小さな記憶集めに見える
あとで全部の人物と出来事がつながる
各Stageの終わりに次が気になる断片が出る
最後はポジティブに朝へ向かう
```

---

# 1. 最高案: 忘れ物係は一人ではなかった

最初、プレイヤーはユイだけが忘れ物係だと思う。

しかし後で分かる。

```txt
昔、ユイには一緒に忘れ物係をしていた子たちがいた。
それぞれが、街の記憶を守る役割を持っていた。
```

ただし、序盤で説明しない。

プレイヤーがStageを進めると、地図帳の余白に、ユイ以外の筆跡や印が出てくる。

---

# 2. 5人の役割案

## ユイ

役割:

```txt
拾う子
```

意味:

```txt
忘れ物を見つける
欠片を集める
落ちたものを放っておけない
```

## アサ

役割:

```txt
名前をつける子
```

意味:

```txt
拾ったものに意味を与える
地図帳に書く
記憶を読める形にする
```

## ミチル

役割:

```txt
道を読む子
```

意味:

```txt
地図を読む
迷った人の帰り道を見つける
Stage 4と相性が良い
```

## ナギ

役割:

```txt
しまう子
```

意味:

```txt
忘れ物を箱や棚にしまう
大事なものを守る
記憶カプセルと相性が良い
```

## トモリ

役割:

```txt
灯す子
```

意味:

```txt
ランタンを直す
夜道を照らす
朝へ向かう象徴
```

# 3. なぜ仲が良かったのか

彼らは特別な組織ではない。

子どものころ、ただの遊びとして「忘れ物係」をしていた。

```txt
落ちているものを拾う
誰のものか考える
名前をつける
地図帳に場所を書く
いつか持ち主へ返す
```

この遊びが、後に街の記憶を守る仕組みになった。

大事なのは、最初から世界を救う使命ではないこと。

```txt
仲が良かったから続いていた遊びが、街を救う仕組みになっていた。
```

ここが温かい。

# 5. 視点の反転

## 最初の理解

```txt
ユイが街の記憶を拾っている
```

## 中盤の理解

```txt
拾っている欠片は、昔の友達たちの記憶でもある
```

## 後半の理解

```txt
ユイは一人で頑張っていたのではない
昔の友達たちが残した道具や言葉が、毎晩ユイを助けていた
```

## 最後の理解

```txt
プレイヤーが選んでいた武器やパッシブは、実は友達たちの役割の名残だった
```

---

# 6. 武器/パッシブと仲の良さの接続

武器やパッシブは、ただの強化ではない。

昔の誰かが残した助け。

## 夜の鉛筆

関係:

```txt
アサが地図帳へ書いていた鉛筆
```

## 金のコンパス

関係:

```txt
ミチルが帰り道を探すために使っていた
```

## 月のしおり

関係:

```txt
ナギが大事なページをなくさないために挟んでいた
```

## ランタン

関係:

```txt
トモリが直してくれた灯り
```

こうすると、強化がキャラクター同士の関係に変わる。

# 7. クリフハンガー設計

各Stageの終わりに、次へ行きたくなる引きを入れる。

長いムービーではなく、短い一文とアイテムでよい。

## Stage 1終わり

```txt
朝になった。
地図帳の端に、ユイの字ではない名前があった。
```

投げる謎:

```txt
誰が書いた？
```

## Stage 2終わり

```txt
名札の裏には、ユイの名前が書かれていた。
```

投げる謎:

```txt
ユイは呼ばれていなかったのでは？
```

## Stage 3終わり

```txt
閉じた箱の中で、手紙だけが新しいままだった。
```

投げる謎:

```txt
誰が渡せなかった？
```

## Stage 4終わり

```txt
切符は片道ではなかった。
```

投げる謎:

```txt
帰る予定があった？
```

## Stage 5前

```txt
最後のページには、五つの筆跡があった。
```

投げる謎:

```txt
ユイは一人ではなかった？
```

---

# 8. 余白の作り方

全部説明しない。

以下を守る。

```txt
誰が何をしたかを直接言わない
小物で示す
複数の解釈ができる文にする
でも最後には温かい方向へ着地する
```

悪い例:

```txt
アサはユイをずっと愛していて、地図帳を残しました。
```

良い例:

```txt
地図帳の端だけ、何度も消して書き直されていた。
```

---

# 9. キャラクター同士の仲の良さの見せ方

仲良しを直接会話で見せない。

使うもの:

```txt
同じ落書き
半分ずつ持っていた切符
直されたランタン
名前が書き足された地図
同じ癖の字
持ち主の違うしおり
```

プレイヤーが気づく形にする。

```txt
この道具、誰かがユイのために残していたんだ
```

と思えれば勝ち。

---

# 10. ポジティブな群像劇

暗い過去はある。

でも、最後に分かるのは絶望ではない。

```txt
誰も自分を見ていなかった
```

ではなく、

```txt
見ていたけど、言葉が届かなかった
```

さらに、

```txt
届かなかった言葉も、忘れ物として残っていた
```

ここへ着地する。

---

# 11. 最重要

Vamp Ponの群像劇は、キャラを増やすための群像劇ではない。

```txt
ユイが一人で拾っていると思っていた夜に、実はみんなの小さな手助けが残っていたと分かる話。
```

これが一番強い。

# Ensemble Story Structure

## 目的

Vamp Ponの物語を、ユイとアサだけの閉じた話にしない。

同時に、旧案の以下を修正する。

```txt
旧: ユイは拾う子
旧: 各Stageの終わりにクリフハンガーを投げる
旧: ユイは一人ではなかった、だけを大反転にする
```

現行方針は以下。

```txt
ユイは持ち主を間違えない子
忘れ物係は記憶隔離/返却プロトコル
黒インクは間違った意味を固定するもの
群像劇は、各キャラの“失敗だと思っていた行動”が実は誰かを守っていたと分かる構造
```

---

# 1. 最高案: 忘れ物係は遊びであり、仕組みでもあった

最初、プレイヤーはユイだけが忘れ物係だと思う。

しかし後で分かる。

```txt
昔、ユイたちは一緒に忘れ物係をしていた。
それはただの子どもの遊びだった。
でも同時に、黒インクで固定されそうな意味を小物へ逃がす仕組みでもあった。
```

ただし、子どもたちは自分たちが仕組みを動かしていたとは知らない。

ここが重要。

```txt
世界を救う使命ではなく、仲が良かったから続いていた遊びが、結果的に誰かを守っていた。
```

# 2. 5人の役割案

## ユイ

役割:

```txt
持ち主を間違えない子
```

意味:

```txt
誰のものか分からなくなった意味を、正しい持ち主へ返す
欠片や小物の“持ち主”を見失わない
```

## アサ

役割:

```txt
名前を失わせない子
```

意味:

```txt
拾ったものに名前をつける
持ち主と意味を接続する
名前が黒インクで固定されないように何度も書き直す
```

## ミチル

役割:

```txt
返す場所を読む子
```

意味:

```txt
地図を読む
帰る場所ではなく、返すべき相手/場所を探す
```

## ナギ

役割:

```txt
壊れる理由をしまう子
```

意味:

```txt
読まれると壊れる理由を一時隔離する
閉じることで守る
```

## トモリ

役割:

```txt
朝まで意味を灯す子
```

意味:

```txt
ランタンを直す
仮接続した意味を朝まで保持する
```

# 3. なぜ仲が良かったのか

彼らは特別な組織ではない。

子どものころ、ただの遊びとして「忘れ物係」をしていた。

```txt
落ちているものを拾う
誰のものか考える
名前をつける
箱にしまう
地図帳に場所を書く
灯りをつけて探す
いつか持ち主へ返す
```

この遊びが、後に街の意味を守る仕組みになった。

表の温かさ:

```txt
仲が良かったから続いていた遊び。
```

裏の重さ:

```txt
遊びの動作が、黒インクで固定される前の意味を逃がしていた。
```

各Stageは、5人のうち誰かの接続役割に対応する。

ただし、最初は分からない。

## Stage 1: ユイ


## Stage 2: アサ

## Stage 3: ナギ

# 5. 視点の反転

## 最初の理解

```txt
ユイが忘れ物を拾っている
```

## 中盤の理解

```txt
欠片は経験値だけではない
誰かの意味片でもある
```

## 後半の理解

```txt
各キャラは、自分が失敗したと思っていた
でも実際は、それぞれ別の形で誰かを守っていた
```

## 最後の理解

```txt
プレイヤーが選んでいた武器やパッシブは、昔の誰かの役割の名残だった
```

大反転は「一人ではなかった」だけでは弱い。

正しくは以下。

```txt
自分たちは失敗したと思っていた。
でも、その失敗だと思っていた行動が、黒インクから誰かを守っていた。
```

# 6. 武器/パッシブと関係性の接続

武器やパッシブは、ただの強化ではない。

意味を接続する役割の名残。

## 夜の鉛筆

```txt
誰の意味かを仮に書き留める道具
```

## 名前のラベル

```txt
持ち主と名前を接続する道具
```

## 金のコンパス

```txt
返すべき場所/相手を読む道具
```

## 月の箱

```txt
読まれると壊れる理由を一時隔離する道具
```

## ランタン

```txt
仮接続した意味を朝まで保持する灯り
```

# 7. クリフハンガーではなく再読Seed

旧案の「各Stage終わりに次が気になる引きを入れる」は、やりすぎると安い。

今後はクリフハンガーではなく、再読Seedにする。

```txt
初見では自然
回収後に意味が変わる
シリーズ後にさらに意味が変わる
```

## Stage 1終わり

```txt
朝になった。
地図帳の端に、ユイの字ではない小さな消し跡が残っていた。
```

初見:

```txt
誰かの字？
```

回収後:

```txt
アサが何度も名前を書き直していた跡
```

## Stage 3終わり

```txt
閉じた箱の鍵穴は、外ではなく内側についていた。
```

初見:

```txt
変な箱
```

回収後:

```txt
閉じ込めるためではなく、中から壊れないようにする箱
```

## Stage 5終わり

```txt
最後のページには、五つの筆跡があった。
```

初見:

```txt
ユイは一人ではなかった
```

回収後:

```txt
5人がそれぞれ違う接続を担当していた
```

# 8. 余白の作り方

全部説明しない。

以下を守る。

```txt
誰が何をしたかを直接言わない
小物で示す
複数の解釈ができる文にする
でも最後には温かい方向へ着地する
```

悪い例:

```txt
アサはユイを愛していて、地図帳を残しました。
```

良い例:

```txt
地図帳の端だけ、何度も消して書き直されていた。
```

---

# 9. キャラクター同士の仲の良さの見せ方

仲良しを直接会話で見せない。

使うもの:

```txt
同じ落書き
半分ずつ持っていた切符
直されたランタン
名前が書き足された地図
同じ癖の字
持ち主の違うしおり
```

プレイヤーが気づく形にする。

```txt
この道具、誰かがユイのために残していたんだ
```

で終わらせない。

さらに、

```txt
この道具、持ち主に返すための接続点だったんだ
```

まで行くと強い。

---

# 10. ポジティブな群像劇

暗い過去はある。

でも、最後に分かるのは絶望ではない。

```txt
誰も自分を見ていなかった
```

ではなく、

```txt
見ていたけど、言葉が届かなかった
```

さらに、

```txt
届かなかった言葉も、忘れ物として残っていた
```

そして最終的には、

```txt
失敗だと思っていた行動が、誰かを守っていた
```

へ着地する。

---

# 11. 最重要

Vamp Ponの群像劇は、キャラを増やすための群像劇ではない。

```txt
それぞれが失敗したと思っていた行動が、
実は黒インクで固定される前の意味を守っていたと分かる話。
```

これが一番強い。

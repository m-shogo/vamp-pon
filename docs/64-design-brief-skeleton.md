# Design Brief 土台

## 目的

Vamp Pon のデザインは別途しっかり詰める。

この資料では、色・フォント・キャラクター造形・背景美術をまだ決めない。

代わりに、デザイン検討時に守るべき制約と、ゲーム側からデザインへ求める要件を整理する。

---

# 1. デザインで解決したいこと

Vamp Pon のデザインは、単にかわいくするためではない。

以下を解決する必要がある。

```txt
スマホ縦持ちで見やすい
敵/欠片/自キャラが判別できる
短時間で世界観が伝わる
裏ストーリーを説明しすぎず匂わせる
8分遊んでも疲れにくい
仮素材で成立したゲーム性を邪魔しない
```

---

# 2. デザインで優先する順番

```txt
1. 視認性
2. 操作しやすさ
3. 爽快感
4. 報酬感
5. 世界観
6. キャラ魅力
7. 独自性
8. 装飾
```

装飾は最後。

スマホで見えない装飾は削る。

---

# 3. 画面上の情報優先度

## 優先度S

```txt
自キャラ
敵
記憶の欠片
HP
残り時間
```

## 優先度A

```txt
レベル
必殺技ゲージ/ボタン
レベルアップカード
記憶カプセル報酬
```

## 優先度B

```txt
武器/パッシブ簡易表示
新発見通知
実績通知
裏ストーリー1行
```

## 優先度C

```txt
詳細説明
図鑑長文
累計統計
装飾背景
```

デザイン時、優先度CがS/Aを邪魔してはいけない。

# 4. トーンの方向性

まだ確定しない。

ただし、以下の範囲から外れすぎない。

```txt
夜
記憶
忘れ物
地図帳
黒インク
小さな光
朝
少し不思議
やさしい不穏
```

## 避けたい方向

```txt
ホラーすぎる
血/グロ
暗すぎて見えない
情報量が多すぎる
ファンタジー記号だらけ
既存IPっぽい
妖怪メイン
三国志/歴史メイン
```

---

# 5. キャラクターデザイン要件

## ユイ

機能要件:

```txt
小さい画面でもシルエットが分かる
移動方向が分かる
被弾時に反応が分かる
必殺技時に中心人物だと分かる
```

世界観要件:

```txt
忘れ物係
夜に物を集める人
怖すぎない
説明しすぎない
```

未決定:

```txt
年齢感
服装
髪型
色
表情
```

---

# 6. 敵デザイン要件

敵は「影」として一貫させる。

ただし、全部同じ黒い丸にするとゲームとして見づらい。

## 必要な差

```txt
インクの影: 基本
紙くずの影: 速い/軽い
迷子の方角: 横にずれる/方向感
黒いカプセル: 硬い/報酬感
夜のもや: 群れ/広がり
黒ラベルの影: 強敵/カプセルを落とす
```

## 避ける

```txt
細かい描き込み
小さすぎる特徴
背景と同化
黒一色で判別不能
```

---

# 7. 記憶の欠片デザイン要件

欠片は最重要報酬。

## 要件

```txt
小さくても見える
大量に出ても邪魔になりすぎない
吸い寄せられる動きが気持ちいい
XP/成長と直感的につながる
```

## 方向性候補

```txt
小さな光
紙片
インクの中の光
星くず
```

未決定。

---

# 8. UIデザイン要件

## 戦闘中UI

常時表示は最小。

```txt
時間
HP
Lv
必殺技
```

## レベルアップカード

```txt
名前が大きい
効果が短い
新規/強化が分かる
裏文は小さく1行
カード全体が押せる
```

## リザルト

```txt
結果が一目で分かる
数字の達成感
次の目標
裏ストーリー1行
```

---

# 9. エフェクト要件

## 必須

```txt
欠片取得
レベルアップ
被弾
必殺技
カプセル開封
進化
クリア
```

## 注意

```txt
スマホで重くしない
画面を揺らしすぎない
敵/欠片を隠さない
短く強く
```

---

# 10. デザイン検討時のチェック

```txt
[ ] 自キャラが常に見える
[ ] 敵の種類が判別できる
[ ] 欠片が拾いたくなる
[ ] HP/時間が読める
[ ] レベルアップカードが読める
[ ] 裏ストーリーが説明しすぎていない
[ ] 暗すぎない
[ ] 8分見ても疲れすぎない
[ ] 既存IPに似ていない
```

---

# 11. デザインに入る前の条件

本格デザインへ入る前に、最低限以下を満たす。

```txt
Prototype 1で操作/欠片回収が不快ではない
Prototype 2で武器差がある
Prototype 3で8分MVPの核がある
```

デザインはゲーム性を救うためではなく、成立した核を強くするために入れる。

---

# 12. 最重要

```txt
かわいさより先に、スマホで見えること。
```

その上で、Vamp Ponらしい「夜・記憶・忘れ物・黒インク・小さな光」を作る。

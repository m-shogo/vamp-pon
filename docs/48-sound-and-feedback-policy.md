# サウンド/フィードバック方針

## 目的

Vamp Pon のサウンドは、豪華さよりも「反応の気持ちよさ」と「情報整理」を優先する。

デザインは別途詰めるため、この資料では音色や曲調を決めすぎない。

決めるのは以下。

```txt
どの行動に音が必要か
音で何を伝えるか
優先順位
MVPで必要な最小SE
後回しにする音
スマホでの注意点
```

---

# 1. サウンドの役割

## 役割A: 入力への反応

```txt
移動開始
必殺技発動
カード選択
ボタンタップ
```

ただし、移動開始音は常時鳴らすとうるさいためMVPでは不要。

## 役割B: 報酬の快感

```txt
欠片取得
レベルアップ
記憶カプセル取得
武器進化
実績解除
```

Vamp Ponではここが重要。

## 役割C: 危険の通知

```txt
被弾
HP低下
強敵出現
終盤突入
```

スマホでは画面が小さいため、危険通知は音が助けになる。

## 役割D: 世界観

```txt
夜
記憶
欠片
黒インク
朝
```

ただしMVPでは世界観音作りを深追いしない。

# 2. MVP必須SE

## 優先度S

### 欠片取得音

用途:

```txt
記憶の欠片を拾った時
```

要件:

```txt
短い
連続して鳴ってもうるさくない
少し気持ちいい
```

注意:

大量取得時は全部鳴らさない。

```txt
連続取得時は間引く
またはピッチを少し変える
```

### レベルアップ音

用途:

```txt
XP満タンでレベルアップ画面へ移る時
```

要件:

```txt
明るい
短い
報酬感がある
```

### 被弾音

用途:

```txt
敵接触でHPが減った時
```

要件:

```txt
痛いが不快すぎない
何が起きたか分かる
連続被弾では鳴りすぎない
```

### 必殺技発動音

用途:

```txt
消えない名前を発動した時
```

要件:

```txt
押した瞬間に鳴る
吸引/復元感がある
短く強い
```

## 優先度A

### 記憶カプセル出現音

用途:

```txt
黒ラベルの影を倒してカプセルが落ちた時
```

要件:

```txt
特別感
長すぎない
```

### 記憶カプセル開封音

用途:

```txt
カプセルを拾って開く時
```

要件:

```txt
小さな宝箱感
記憶が開く感じ
```

### 進化音

用途:

```txt
未完成の一行 / 北極星のランタンなどができた時
```

要件:

```txt
MVP内で一番気持ちいい報酬音
レベルアップ音より強い
```

### 強敵出現音

用途:

```txt
3分/5分/7分の黒ラベルの影出現
```

要件:

```txt
警告
少し低め
長すぎない
```

## 優先度B

### 敵撃破音

大量に鳴るとうるさいため、MVPでは控えめ。

小型敵は音なしでもよい。

### 実績解除音

リザルトまたはラン中の通知。

MVPではリザルト側だけでもよい。

### クリア音

```txt
朝まで残った
```

を補強する音。

### 失敗音

```txt
夜に飲まれた
```

を補強する音。

重くしすぎない。

# 3. BGM方針

## MVP

BGMは後回しでもよい。

理由:

```txt
効果音の反応が先
BGMがあるとSEの調整が見えにくい
デザイン/世界観未確定の影響を受ける
```

MVPでは以下のどちらか。

```txt
無音 + SEのみ
仮BGM1曲
```

推奨:

```txt
最初はSEのみ
```

## BGMが必要になる段階

Prototype 3以降。

```txt
8分のテンションが持たない
終盤の圧を音でも作りたい
朝の達成感を出したい
```

## 将来BGM案

```txt
通常夜BGM
終盤1分BGM変化
クリアジングル
失敗ジングル
リザルトBGM
```

# 4. 音量設計

## 設定項目

MVPで最低限。

```txt
masterVolume
seVolume
bgmVolume
mute
```

BGMを後回しにするなら、最初は以下だけでもよい。

```txt
sound: on/off
```

## スマホ注意

```txt
音を出せない環境でも遊べる
音だけで重要情報を伝えない
マナーモード/ブラウザ制限に注意
```

# 5. 音なしでも分かる設計

アクセシビリティとスマホ環境のため、音がなくてもゲームが成立する必要がある。

## 音と一緒に視覚反応も出す

```txt
欠片取得: ゲージ増加/小さな光
レベルアップ: 画面停止/カード表示
被弾: HPバー変化/小さな点滅
必殺技: 吸引エフェクト/ボタン消費
カプセル: 中央表示
進化: 報酬名表示
```

# 7. 実装順

## Step 1

```txt
欠片取得
レベルアップ
被弾
```

この3つがないとゲームの反応が薄い。

## Step 2

```txt
必殺技
カプセル開封
進化
```

報酬と独自性。

## Step 3

```txt
強敵出現
クリア
失敗
実績
```

プレイ全体の区切り。

## Step 4

```txt
BGM
終盤変化
リザルトBGM
```

世界観の強化。

# 8. サウンド制作メモ

MVPではフリー素材/仮素材でもよい。

ただし、ライセンス管理は必須。

```txt
素材名
入手元
ライセンス
使用箇所
加工有無
```

を `docs/asset-license-log.md` に記録する。

AI生成音を使う場合も、生成元と利用条件を記録する。

---

# 9. 結論

MVPでは、BGMよりSEを優先する。

最初に必要なのは、世界観を語る音ではなく、以下。

```txt
拾った
強くなった
痛い
開いた
進化した
助かった
```

この反応が気持ちよければ、仮素材でもゲーム体験を判断しやすい。

# ヨルノシルベ — Cross-Era Lineage / Memory Relationship Bible v1

Date: 2026-08-11  
Status: **CURRENT RELATIONSHIP DIRECTION / EXACT KIN PAIRS OPEN**

> 年代差を「別時代の友達」で終わらせず、親子・祖父母・子孫・友達の子孫・師弟・受け継がれた道具・同じ土地まで関係へ変える。
> ただし血縁を万能な感動装置にはしない。

## 1. Core memory rule

ヨルノシルベ内では、異なるEraの人物が同時に会える。

Realityへ通常Wakingした後:

- Dreamで会った名前を覚えていない。
- 顔を覚えていない。
- 「未来の自分の子 / 孫だった」「昔の祖父母だった」と認識したまま帰らない。
- 子孫側も、Realityの日常ではDreamで会った先祖を明示的には覚えていない。

しかし:

- 手癖
- 考え方
- 食べ方
- phrase fragment
- 道具の扱い
- なぜか安心する相手の癖
- 苦手だった選択を変えられる感覚

は残り得る。

> **関係の名前は忘れても、関係で変わった自分は残る。**

## 2. Parent remembered as frightening / strange

High-value pattern:

Realityで親が以前ヨルノシルベへ参加していても、Waking後は明示記憶を失っている。

子どもから見ると:

- 急に知らない人の名前を寝言で言う
- 古い物を見て泣く
- 誰も知らない料理を急に作る
- 「ここを開けちゃいけない気がする」等、理由のない習慣を持つ
- 何年も前の夢の話を断片的にする

ため、子どもには:

> 怖い / 変な人 / ぼけたのでは / 夢と現実が混ざっている

ように見えることがある。

親を本当に認知症扱いする物語へ自動接続しない。
医療的状態とDream memory residueは別。

## 3. Later-era reversal

その子どもが成長し、自分のEraでヨルノシルベへ参加する。

Dream内では、若い姿の親 / 祖父母 / 先祖 / 親の古い友人と会う可能性がある。

通常時は互いに関係を知らない。

大事件のresolution Wakingで重要記憶が戻る時:

```txt
昔、親が意味不明にしていた行動
+
Dreamで会った人物の癖
+
Realityの写真 / 道具 / 手紙
↓
同一人物 / 関係だったと理解
```

ここで初めて:

> 「あの時、お父さんは壊れてたんじゃなかった」

> 「おばあちゃんが忘れてた名前、あの人だったんだ」

と意味が反転できる。

重要:

- ヨルノシルベには物理的朝はない。
- 「朝になって思い出す」ではなく、**Realityでのresolution Waking / Era大事件解決に伴う記憶回復**として扱う。

## 4. Relationship types

血縁以外も同格で使う。

### LINEAGE
- 親 ↔ 子
- 祖父母 ↔ 孫
- 先祖 ↔ 子孫

### FRIEND_DESCENDANT
- 昔の友人 ↔ その友人の子 / 孫
- 「あいつに似てる」が顔ではなく癖で分かる

### MENTOR_DESCENDANT
- 師匠 ↔ 弟子の子孫
- 技術や口癖だけ残る

### OBJECT_CHAIN
- 同じランタン / 本 / 道具 / 指輪 / 店 /家を別Eraで持った人

### PLACE_CHAIN
- 同じ橋 / 駅 / 商店街 / 学校 / 家 / 工房を別Eraで知る

### ANIMAL_MEMORY
- 長寿ではなくても、犬 / 猫の匂い・動線memoryが人間の時間タグより先に関係へ気づく場合がある

### CHOSEN_FAMILY_CHAIN
- 血縁ではない大人が子どもの人生を変え、その子が後世で別人物へ同じ行動を返す

## 5. Guard: no genealogy puzzle overload

禁止:

- 主要人物の大半を実は親戚にする。
- 全ての縁を血統で説明する。
- 顔が似ているだけで子孫判定。
- 子孫だから同じ星獣 /能力 /性格を自動継承。
- 「血が強いから選ばれた」へMain Mysteryを縮小。

推奨比率Candidate:

- 直接血縁cross-era = 少数の強い数組
- friend / mentor / object / place chain = 多め
- 完全に無関係な出会い = 必ず大量に残す

> **偶然会って友達になった関係も、血縁と同じくらい大切。**

## 6. Emotional construction

強い順序:

```txt
1. Dreamで普通に仲良くなる
2. 年代差を小さな生活差で感じる
3. Wakingで忘れる
4. Realityで理由の分からない痕跡だけ残る
5. 後世Characterが同じ痕跡へ触れる
6. Dreamで別名 / 若い姿の人物と仲良くなる
7. 大事件解決
8. Realityで記憶 + 現物 evidence がつながる
9. 過去sceneの意味が反転する
```

血縁Revealを先に見せない。

## 8. Season use

S1:
- 関係の痕跡を出す。
- 一部は「怖い親 / 変な祖母」の誤読まで。
- 血縁答えは少数だけ回収。

S2:
- S1で残した行動 / 道具 / 地名が別Eraへ繋がる。
- parent / descendant reversalを強く使える。

S3 if used:
- 血縁だけでなくfriend / object / place chainを統合。
- 「世界中みんな実は繋がっていた」にはしない。

## 9. Happy End payoff

最終Happy Endは:

> 全員がDreamを永久に鮮明記憶する

必要はない。

より強い候補:

> 明示記憶が戻るべき人物には戻る。
> 戻らない人物にも、選んだ行動と関係の影響は残る。
> Realityで再会できる時代差のある関係は、写真・手紙・道具・家族の語りを通じて意味を受け取れる。

「覚えていないから無意味」ではなくする。

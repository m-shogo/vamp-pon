# 歴史・国・文明系の題材候補

## 目的

星座から離れて、歴史・国・文明・地理・文化圏を題材候補として広げる。

ただし、この領域は素材が多い一方で、リスクも大きい。

特に注意するもの:

- 戦争表現
- 民族・宗教表現
- 現代政治
- 植民地/侵略/差別の扱い
- 実在国・実在人物の扱い
- 文化の雑な消費

## 基本方針

歴史・国をそのまま敵味方にしない。

安全寄りに使うなら、以下のように分解する。

```txt
国そのものではなく、道具・建物・衣装・工芸・市場・祭り・旅・地図・遺跡・料理・船・本・宝物を使う
実在人物を出さない
現代国家を敵にしない
宗教や民族を敵化しない
戦争を軽く扱わない
```

## A寄り候補の詳細

### 1. 地図帳/小さな世界旅行

#### 良い点

- 国や歴史を「旅」「地図」「お土産」「名所」「小物」として使える
- 敵味方の対立にしなくてよい
- 背景や報酬を作りやすい
- 既存情報が多い
- 条件達成報酬と相性が良い

#### リスク

- 国のステレオタイプ化
- 文化を雑に記号化する危険
- 現代国旗や政治的領土表現は面倒

#### 対策

- 現代国家の名前や国旗を強く出さない
- 「世界旅行風」「地図帳の中の国」くらいにする
- 敵は影/インク/地図のしみ/迷子のコンパスにする
- 実在国を敵にしない

#### Vamp Pon化

```txt
舞台: 夜の地図帳
敵: インクの影、迷子の方角、黒いコンパス
武器: コンパス、地図ピン、切手、スタンプ、トランク
報酬: 旅のバッジ、古い切符、金のコンパス
図鑑: お土産コレクション
```

#### 評価

かなり良い。

国・歴史を使いたいなら、一番安全寄り。

### 2. 博物館の展示室

#### 良い点

- 歴史・国・文明を展示物として扱える
- 実在人物を直接戦わせずに済む
- 夜になると展示が動く、という導入が自然
- 背景、敵、武器、報酬が作りやすい
- 図鑑と相性が非常に良い

#### リスク

- 文化財を壊す表現は危険
- ミイラ/棺/宗教的展示の扱いに注意
- 実在の博物館名や展示物をコピーしない

#### 対策

- 敵は展示物そのものではなく、展示にまとわりつく影
- 文化財を壊すのではなく、影を払う
- 架空の博物館にする
- 展示品は抽象化する

#### Vamp Pon化

```txt
舞台: 閉館後の小さな博物館
敵: 展示の影、埃のもや、壊れた案内板、インクの怪
武器: 懐中電灯、展示タグ、虫眼鏡、方位磁針、巻物
報酬: 学芸員バッジ、古代の欠片、金の展示札
図鑑: 展示コレクション
```

#### 評価

かなり有力。

歴史・国を扱いつつ、戦争/政治から距離を取れる。

### 3. 大航海/宝の地図

#### 良い点

- 船、島、宝箱、地図、コンパス、港、灯台で広げやすい
- 条件達成で宝を得る構造が自然
- 冒険感が強い
- 既存情報が多い

#### リスク

- ワンピース/海賊IP連想が強い
- 海賊を美化しすぎると略奪イメージが出る
- 実在植民地史に寄ると重い

#### 対策

- 海賊より「宝探し」「地図」「港町」「小さな船」に寄せる
- 実在国/植民地/帝国を出さない
- 敵は海の影、霧、宝箱に憑いた影にする

#### Vamp Pon化

```txt
舞台: 夜の宝の地図
敵: 海霧の影、濡れた紙片、宝箱の影
武器: コンパス、船の鐘、ロープ、瓶詰めの手紙、灯台の光
報酬: 古い金貨、宝の欠片、航海バッジ
```

#### 評価

かなり強いが、海賊IPに寄らない注意が必要。

### 4. シルクロード/旅商人

#### 良い点

- 市場、香辛料、布、宝石、ランプ、ラクダ、地図など素材が豊富
- 国を横断するが、戦争にしなくてよい
- 商人/交易/宝物/旅で報酬設計しやすい
- 色味が豊か

#### リスク

- 中東/中央アジア/中国文化を雑に混ぜる危険
- ステレオタイプ衣装や市場表現に注意
- 宗教表現に触れると難しい

#### 対策

- 実在地域名を強く出さず「星砂の交易路」など架空化
- 人物ではなく道具・品物・旅を中心にする
- 宗教建築や民族衣装を雑に使わない

#### Vamp Pon化

```txt
舞台: 夜の交易路
敵: 砂の影、迷子の地図、黒い風
武器: ランプ、布のリボン、香辛料袋、宝石、旅の鈴
報酬: 交易バッジ、星砂の小瓶、金のラクダ鈴
```

#### 評価

雰囲気は強いが、文化表現の注意が必要。

### 5. ルネサンス工房/発明

#### 良い点

- 歯車、設計図、羽ペン、レンズ、からくり、模型で武器化しやすい
- 戦争や国対立に寄せず、発明/工房として使える
- 時計屋/からくりと相性が良い
- 報酬名が作りやすい

#### リスク

- 実在人物を出すと権利より肖像/史実解釈の面倒さがある
- スチームパンク風にしすぎると素材が重い
- 地味になりやすい

#### 対策

- 実在人物名は出さない
- 「古い発明工房」くらいに抽象化
- 背景は机/設計図/模型中心にする

#### Vamp Pon化

```txt
舞台: 夜の発明工房
敵: 失敗作の影、暴走歯車、インクのしみ
武器: 歯車、レンズ、羽ペン、設計図、模型翼
報酬: 金の歯車、発明家バッジ、真夜中のレンズ
```

#### 評価

個人開発向きでかなり良い。

## 国・歴史系で避けたいもの

### 現代国家対立

避ける。

理由:

- 政治的になる
- 炎上しやすい
- 古くなる
- ゲームの爽快感と相性が悪い

### 第二次世界大戦など近現代戦争

避ける。

理由:

- 死者・差別・侵略・被害の扱いが重い
- ヴァンサバの軽い爽快感と相性が悪い

### 実在宗教を敵にする

避ける。

理由:

- 表現リスクが高い
- 国際展開で問題になりやすい

### 実在民族や国民を敵にする

絶対避ける。

敵は影、もや、インク、ノイズ、悪夢など抽象化する。

## 歴史・国テーマの安全な型

### 型A: 地図帳の中

```txt
国/歴史を、地図・切手・旅・お土産・スタンプとして扱う
```

安全度高い。

### 型B: 博物館の展示

```txt
文明/歴史を、展示・図鑑・遺物・学芸員ごっことして扱う
```

安全度高い。

### 型C: 宝探し

```txt
歴史を、古い地図・宝箱・遺跡・欠片として扱う
```

冒険感が強いが、海賊/植民地感に注意。

### 型D: 工房/発明

```txt
歴史を、道具・発明・設計図・からくりとして扱う
```

戦争を避けやすい。

### 型E: 市場/交易

```txt
国を、商人・品物・市場・布・香辛料・宝石として扱う
```

素材は強いが、ステレオタイプ注意。

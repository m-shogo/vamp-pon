# World Quote Candidates: Original Language + Japanese Meaning

Vamp Pon / ヴァンサバ改のロード画面で使う、地域別の名言・格言候補。

この資料では `Vamp Pon意訳` という項目は使わない。

---

## 1. 基本方針

```txt
名言は名言として縛る。
原文は、できるだけその地域・出典の言語のまま残す。
日本語では「意味/訳」を添える。
キャラはその名言に返信する。
```

表示構造:

```txt
Original:
Source:
日本語訳/意味:
Character reply:
```

注意:

```txt
既存の日本語訳をそのまま使わない。
日本語訳/意味は、ゲーム内で意味を伝えるための自前文として作る。
現役の宗教・信仰は敬意を持って扱う。
商用前に source / original / translation を最終確認する。
```

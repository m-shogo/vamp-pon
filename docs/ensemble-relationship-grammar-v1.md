# ヨルノシルベ — Ensemble / Relationship Grammar v1

Date: 2026-08-10  
Status: **USER DIRECTION / SERIES-WIDE DESIGN GRAMMAR**

> 長く愛され、箱推しされ、別れで泣けるグループを作るためのシリーズ共通設計。
> 特定作品の人物・台詞・事件・文体はコピーしない。抽出するのは関係性の構造のみ。

---

# 1. 最重要定義

強い仲間は:

> **仲間だから助けるのではない。いっしょに過ごした結果、その人と出会う前とは別の人間になっている。**

シリーズの基本遷移:

```txt
他人
→ 利害一致
→ 顔見知り
→ いつものメンバー
→ 日常
→ 小さな役割が定着
→ 家族同然 / 仲間
→ 亀裂
→ 離反 / 嫉妬 / 裏切りに見える選択
→ 相手が変わった事実を受け入れる
→ もう一度、自分で関係を選ぶ
→ 卒業 / 別々の人生
→ 一緒にいた時間が後の人生へ残る
```

「元通り」が最終到達ではない。

> **変わったまま仲間でいられること**

を成熟した関係として扱う。

# 2. グループ設計の10原則

## G01. 日常が先、悲劇が後

死亡 / 裏切り / 自己犠牲 / 悲しい過去を先に積まない。

先に:

- 食卓
- 帰り道
- 寝る場所
- 修理
- 雨宿り
- 掃除
- 遊び
- くだらない競争
- 誰がどこに座るか
- 誰が最後の一個を取るか
- 星獣の世話

を積む。

「この時間が続けばいい」とplayerが思ってから壊す。

## G02. 全員を均等に仲良くしない

関係密度は不均一でよい。

例:

```txt
A×B = 主人公級相棒
B×C = 犬猿
C×D = 姉妹のような安心
D×E = 昔からの因縁
E×F = 師弟
F×A = 憧れ
A×D = あまり喋らない
```

「あまり喋らない」も関係性。

## G03. 主人公の知らない関係を作る

世界を「主人公＋仲間」にしない。

必須:

- 主人公不在の秘密
- 主人公不在の喧嘩
- 主人公不在の仲直り
- 主人公に言わない弱音
- 主人公より先に知っている癖

これでcommunityになる。

## G04. 感情的役割を持たせる

戦闘roleとは別。

例:

- social glue — 皆を同じ場所へ集める
- silent witness — 全員の小さな変化を覚える
- challenger — 仲良しムードを壊してでも異論を言う
- caretaker — 世話をするが自分は頼れない
- youngest-heart — 守られる側から全員を救う側へ行く
- elder-memory — 過去を持つが過去を正解にしない
- outsider — グループの常識を外から揺らす
- keeper — 今は見せないことで守る

## G05. Social Glueを一人以上置く

リーダー / 最強でなくてよい。

この人がいるから:

- 食卓に全員が来る
- 写真を撮る
- 喧嘩後も同じ部屋にいられる
- 誕生日を覚える
- どうでもいい遊びが始まる

一度この人物を不在にすると、誰も喧嘩していないのに集団が崩れる。

## G06. 愛し方を全員変える

誰かが怪我した時:

- 大声で心配する
- 悪口を言いながら荷物を持つ
- 無言で薬を置く
- 犯人へ怒る
- いつも通り接する
- 一人になってから泣く

同じ感情を同じ台詞で説明しない。

## G07. 3人は三角の感情を使う

3人組は不安定さが価値。

- 友情
- 嫉妬
- 恋
- 劣等感
- 2人だけの共有記憶
- 1人だけ知らない秘密

を自然に作れる。

ただし必ず恋愛三角形にしない。

## G08. 4〜5人は「全ペアの違い」を作る

Core5は10 pair全部を同じ密度にしない。

最低:

- 強いpair 3
- 摩擦pair 2
- 意外なpair 2
- 低会話pair 1

を持つ。

## G09. 6人以上は内部小家族へ分ける

大人数で全員×全員を濃くしない。

- Core / Circle / Shadow
- 食事組
- 夜更かし組
- 修理組
- 年長組
- 子ども / 年少組
- 観測組

のような横断小集団を持たせる。

## G10. 最終形は「ずっと一緒」ではない

子どもの約束:

> ずっと一緒。

成熟した関係:

> 別々に生きても、仲間だった時間はなくならない。

シリーズのHappy Endはここを目指す。

# 3. 感情レーン

作品全体で次を意図的に分散する。

- 友情
- 兄弟 / 姉妹
- 双子 / 三つ子
- 擬似家族
- 青春
- 仲間
- 師弟
- 恋愛
- 片想い
- 嫉妬
- 信頼
- 裏切りに見える行為
- 本当の裏切り
- 離反
- 死別
- 老い
- 再会
- 卒業

## ルール

- 恋愛を最上位tierにしない
- 友情を恋愛の未満形にしない
- 師弟を親子の代用品だけにしない
- 擬似家族を「みんな仲良し」の別名にしない
- 嫉妬した人を即悪役にしない
- 裏切った人にも行為の責任を取らせる
- 再会で時間を巻き戻さない
- 死別した相手を新人物で代替しない
- 卒業は関係の終了ではなく形の変更

---

# 4. 過去と現在の差分で泣かせる

最も強い涙は「事件」より差分。

制作時は各重要relationへ最低1組:

```txt
BEFORE behavior / line / object
AFTER behavior / line / object
```

を持たせる。

例:

```txt
序盤: 人の物に触れない
終盤: 「開けていい？」と本人に預ける

序盤: 「先に行く」
終盤: 「一緒に行く」

序盤: 全員分の椅子を用意する人
不在時: 誰も椅子を増やさない
再会後: 別の人物が黙って椅子を一脚出す
```

同じ料理 / 同じ席 / 同じ道 / 同じ写真 / 同じ呼び方を再利用できる。

---

# 5. 拠点 = 家

ヨルノシルベでは「拠点」が単なるmenu hubにならないようにする。

必要な固定物:

- 長机 / 食卓
- 修理場所
- 地図を広げる場所
- 名札 / 手紙を扱う場所
- 星獣が集まる隅
- 誰かの定位置
- 予備の椅子

章の進行で物が増える。

人物が抜けても席や癖が残る。

拠点の変化自体をrelationship UIにする。

# 6. Group Heartbeat Events

大事件でなく、繰り返す小イベントを最低8種持つ。

1. 食事
2. 雨
3. 誰かの寝坊
4. 修理
5. 地図更新
6. 手紙 / 宛名
7. 写真 / 記録
8. 星獣の小事件
9. 誕生日 / 記念日
10. 「何も起きない」夜

同じeventを序盤 / 中盤 / 終盤で少し変える。

---

# 7. Group Fracture

グループを壊す時、外敵だけを原因にしない。

強い亀裂:

- 正しいことを急ぎすぎる
- 守るために本人の選択を奪う
- 秘密を守るため仲間へ嘘をつく
- 全員を救おうとして一人へ負担が集中
- 昔の約束と現在の本人の意思が衝突
- 恋愛 / 片想い / 嫉妬で距離感が変わる
- 師弟の卒業を片方が受け入れられない
- 双子が別行動を選ぶ
- Robotがmemory syncを拒む
- 長寿者が別れを拒否する

亀裂後、全員同時に仲直りさせない。

---

# 8. 選び直す

再結成は:

> 「昔は仲間だったから」

では弱い。

各人物が現在の相手を見て:

> **変わったお前と、それでも一緒に行く。**

を別々の行動で選ぶ。

この選択をFinal Battleのmechanic / Support / Pair Artへ返す。

# 9. 年齢 / 世代

## 年長人物

- ゲン = 渋い年長男性
- ハナ = 年長女性
- クロエ = 長寿者Candidate
- レンジ = 年を取る弟子Candidate

年長者を:

- 常に正しい
- 死ぬための mentor
- 若者を褒めるだけ

にしない。

年長者も:

- 嫉妬する
- 恋をする
- 間違える
- 新しい趣味を持つ
- 若者へ教わる
- 卒業する

## 年齢外見の反転

ユーザー要望として「実年齢と外見年齢が大きくずれる人物」をFuture reservoirへ保持する。

方針:

- 外見が年少でも、成人 / 長寿者なら行動・責任・話法で明確に成人として扱う
- sexualized child codingを避ける
- ギャップを年齢当てクイズだけにしない
- 「老いる怖さ」「外見だけ変わらない疎外」をThemeへ使う

Current/Future rosterへ自動追加しない。

# 11. Dialogue Grammar

特定の現役作家の文体模倣は禁止。

代わりに独自の会話密度を作る。

各人物へ:

```txt
sentenceLength
tempo
favoriteMetaphorDomain
jokeDirection
angerDelta
bondDelta
crisisDelta
nameCallingRule
silenceRule
```

を定義する。

会話は全員を「気の利いた名言製造機」にしない。

### 使う

- 言葉遊び
- 定義のずらし
- 会話の食い違い
- 短い応酬
- 途中でやめる台詞
- 返事をしないこと自体の意味

### 禁止

- 全員が同じ長文理屈を話す
- 元ネタに似た決め台詞
- 説明のためだけの不自然な会話

# 12. Game-specific advantage

ゲームでは「一緒にいた時間」をplayerに実際に経験させられる。

Battle外のmemory seed:

- run終了写真 / snapshot
- 使用Support履歴
- 一緒に拾ったNamed Object
- 同じStageを越えた回数
- 失敗runの記録
- 食卓の座席変化
- 星獣の懐き方
- 呼び方変化

重要:

> Story sceneを見たかではなく、**playerが誰と何をしたか**が小さく日常へ返る。

# 13. Completion test

グループが完成したと言う前に確認する。

- [ ] 主人公なしでも成立するpairが5本以上ある
- [ ] 喧嘩しないが距離のあるpairがある
- [ ] social glueが明確
- [ ] social glue不在時の変化がある
- [ ] 日常eventが8種以上ある
- [ ] 全員の愛し方が同じではない
- [ ] 兄弟 / 師弟 / 恋愛 / 友情が上下関係になっていない
- [ ] 嫉妬を悪役化だけに使っていない
- [ ] 裏切り / 離反に回復過程がある
- [ ] 変わったまま再会する
- [ ] 別々の人生へ行ける
- [ ] 最終的な涙を永久死だけに依存しない
- [ ] BEFORE / AFTER差分が主要relationごとにある

# 14. 一文

> **ヨルノシルベの仲間は、血がつながっているから家族なのでも、同じ目的だから仲間なのでもない。同じ夜で飯を食べ、失敗し、喧嘩し、守り方を間違え、それでも相手を選び直した時間が、別々の朝へ帰った後も人生に残る。**

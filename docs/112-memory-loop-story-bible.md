# Memory Loop Story Bible

## 目的

Vamp Pon の物語構造を、ゲームループと矛盾しない形で整理する。

目標は、以下を納得できるようにすること。

```txt
なぜ記憶をなくしたのか
なぜ取り戻すのか
なぜ毎回1から始まるのか
朝になったのに次の夜が来る理由
ユイの意味
最後がハッピーエンドになる理由
```

---

# 1. 物語の核

## 表の物語

```txt
ユイは、夜になると街にあふれる黒インクの影を払い、消えかけた記憶の欠片を集める忘れ物係。
朝まで残れば、その夜に失われかけた記憶を少しだけ取り戻せる。
```

## 裏の物語

```txt
ユイ自身も、大切な誰かとの記憶をなくしている。
ユイが拾っている記憶の欠片は、街の記憶であると同時に、ユイ自身の記憶でもある。
```

## 最終的な真実

```txt
ユイは、誰かを忘れたのではない。
誰かを守るために、自分から忘れることを選んだ。
```

---

# 2. ユイの意味

## 名前の意味

ユイは「結い」。

意味:

```txt
切れた記憶を結び直す人
忘れ物と持ち主を結ぶ人
夜と朝を結ぶ人
昔の約束と今の自分を結ぶ人
```

## 役割

ユイは勇者ではない。

```txt
忘れられたものを、もう一度つなぐ係。
```

## ユイの弱さ

ユイは最初からすべてを覚えていない。

だから、ゲーム開始時点では自分が何を探しているかも分からない。

ただ、欠片を見ると胸が痛くなる。

それがプレイヤーの動機になる。

---

# 3. 記憶をなくした理由

## 基本設定

この街では、強すぎる悲しみや後悔は黒インクになる。

黒インクは、記憶を消すのではなく、読めなくする。

```txt
記憶はある。
でも読めない。
思い出せない。
```

## ユイの場合

ユイは昔、大切な友達と約束をした。

しかし、その友達は何かの理由で街から消えかけた。

ユイは友達の存在を完全に消さないために、友達の記憶を街中の忘れ物に分けて隠した。

代償として、ユイ自身はその友達のことを忘れた。

## つまり

```txt
記憶喪失は事故ではない。
誰かを残すための選択だった。
```

---

# 4. 取り戻す理由

ユイは、最初は理由を知らない。

でも、欠片を拾うたびに、次の感覚だけが戻る。

```txt
誰かを待っていた
誰かと帰る約束をした
誰かに名前を呼ばれていた
自分も誰かの名前を呼びたかった
```

プレイヤーにとっては、強くなるために欠片を拾う。

物語上は、誰かとのつながりを取り戻すために欠片を拾う。

ここがゲーム行動と物語の接続点。

---

# 5. 毎回1から始まる理由

## ローグライトとしての理由

夜は毎晩、違う形で黒インクが広がる。

ユイが朝まで残っても、その夜に使った力は朝の光でほどける。

なぜなら、その力はユイ自身の力ではなく、夜の記憶を一時的に結び直した力だから。

## ただし完全リセットではない

消えるもの:

```txt
その夜に拾った武器Lv
一時的なパッシブ
進化状態
ステージ内の強さ
```

残るもの:

```txt
図鑑
記憶断片
実績
プレイヤーの知識
少量の記憶片
解放された要素
```

## 納得感

```txt
夜の中で得た力は朝にほどける。
でも、取り戻した意味は残る。
```

これで、ゲーム的リセットと物語的進行が両立する。

---

# 6. 朝になったのに次の夜が来る理由

朝になると、その夜の黒インクは消える。

しかし、街全体の地図帳はまだ塗りつぶされたまま。

Stage 1で朝になっても、それは一冊の地図帳の一ページが読めるようになっただけ。

次の夜は、別のページが黒くなる。

```txt
1回のクリア = 1つの記憶を救う
全体のクリア = 誰の記憶だったか分かる
```

---

# 7. 昔仲良かった相手

## 候補名

仮名:

```txt
アサ
```

理由:

```txt
朝
ユイが目指すもの
夜の終わり
```

## 関係

アサは、ユイの幼なじみでも、親友でも、家族のような存在でもよい。

恋愛に寄せすぎない。

Vamp Ponでは、誰でも受け取れる「大切な人」にする。

## 昔の2人

```txt
ユイは忘れ物係ごっこをしていた
アサは地図帳を描いていた
2人で街の小さなものに名前をつけていた
夜になったら、ランタンを持って帰る約束をしていた
```

この「帰る約束」が最後まで効く。

---

# 8. 黒インクの正体

黒インクは悪の存在ではない。

正体:

```txt
読まれなくなった記憶
呼ばれなくなった名前
帰れなかった約束
```

だから敵を倒すのは殺すことではない。

```txt
影を払って、欠片へ戻す。
```

これにより、かわいい敵を倒すことへの違和感を減らせる。


## Stage 2: 紙片の通学路



# 10. ハッピーエンド

最後はハッピーエンドにする。

ただし、全部が元通りになるだけでは弱い。

## 最終案

ユイはすべてを思い出す。

アサは完全には元の形で戻らないかもしれない。

でも、アサの名前は読めるようになる。

地図帳の最後の空白ページに、ユイが自分で続きを描けるようになる。

つまり:

```txt
失ったものが全部戻る話ではなく、忘れたまま止まっていた時間が、もう一度進み始める話。
```

## プレイヤーが感じること

```txt
寂しいけど前向き
切ないけど気持ちいい
最後に朝が本当に来た感じ
```

## 最後の一文候補

```txt
朝になった。
名前は、もう消えなかった。
```

# 11. 必殺技との接続

必殺技名:

```txt
消えない名前
```

これはただの技ではない。

ユイが最後まで守りたかったもの。

発動時に小型影が欠片へ戻るのは、忘れられた名前を一瞬だけ呼び戻しているから。

---

# 12. 十三機兵的な面白さとの接続

目指すのは、長い説明ではない。

目指すのは、後から意味が反転する構造。

例:

```txt
欠片 = 経験値だと思っていた
実は誰かの記憶だった

敵 = 倒す相手だと思っていた
実は読めなくなった記憶だった

ユイ = 記憶を拾う人だと思っていた
実は自分で記憶を分けた人だった

毎回1から = ローグライト都合だと思っていた
実は夜だけ結び直せる一時的な力だった
```

プレイヤーが後でこう思うのが理想。

```txt
あのゲーム行動、全部ストーリーの意味があったんだ。
```



# 14. 最重要

Vamp Ponの物語は、ゲームループの言い訳ではない。

ゲームループそのものが物語になる。

```txt
夜に強くなる。
朝にほどける。
でも、思い出した意味は残る。
```

これを守る。

# 制作マイルストーン

## 目的

Vamp Pon の制作を、破綻しない段階に分ける。

完成版を一気に作らず、各段階で合格/不合格を判断する。

---

# 全体方針

```txt
資料固め
↓
小さなプロトタイプ
↓
8分MVP
↓
スマホ実機検証
↓
継続プレイ検証
↓
デザイン本格化
↓
アプリ化検討
```

## 重要

デザインは大事なので、別途詰める。

ただし、ゲーム性の核がないまま本格デザインへ入らない。

---

## 目的

作るもの・作らないもの・検証するものを明確にする。

## 成果物

```txt

コアループ
8分体験タイムライン
スマホ入力仕様

プロトタイプ検証計画
リスク管理表
サウンド方針
アクセシビリティ方針
技術選定
```

## 完了条件

```txt
[ ] MVPの範囲が明確
[ ] 8分で何が起きるか説明できる
[ ] 何を検証するために作るか明確
[ ] デザイン保留のまま実装できる領域が分かる
```

## 現状

かなり進行済み。

残り:

```txt
GDD統合版
デザインブリーフ
```

# Milestone 1: Prototype 1 / 1分操作感

## 目的

スマホ縦持ちで、移動・自動攻撃・欠片回収が気持ちいいか確認する。

## 実装範囲

```txt
Vite + TypeScript + Phaser起動
縦持ち390x844
ユイ仮表示
仮想スティック
インクの影
夜の鉛筆Lv1
欠片ドロップ
XP
Lv2到達
簡易レベルアップ画面
```

## 完了条件

```txt
[ ] スマホブラウザで起動できる
[ ] 3秒以内に動かせる
[ ] 最初の敵を10秒以内に倒せる
[ ] 60秒以内にレベルアップする
[ ] 欠片回収が不快ではない
```

## 次へ進む条件

```txt
移動/自動攻撃/欠片回収が不快ではない
```

---

# Milestone 2: Prototype 2 / 3〜5分成長感

## 目的

3択レベルアップとビルド差が楽しいか確認する。

## 実装範囲

```txt
武器5種
パッシブ5種
3択抽選
武器/パッシブ枠
Lv.MAX除外
紙くずの影
迷子の方角
簡易リザルト
```

## 完了条件

```txt
[ ] 3択が読める
[ ] 武器ごとの差が分かる
[ ] 強化後に体感が変わる
[ ] 3分時点で退屈ではない
[ ] 5分遊べる
```

## 次へ進む条件

```txt
武器差と成長感がある
```

---

# Milestone 3: Prototype 3 / 8分MVP

## 目的

Vamp Pon のMVP体験が成立するか確認する。

## 実装範囲

```txt
8分ウェーブ
敵5種
黒ラベルの影
記憶カプセル
進化1〜2種
必殺技「消えない名前」
リザルト
最小実績/図鑑通知
```

## 完了条件

```txt
[ ] 8分プレイできる
[ ] 3分で初カプセルがある
[ ] 5分で進化チャンスがある
[ ] 必殺技を使いたくなる
[ ] 終盤に山がある
[ ] リザルトが出る
```

## 次へ進む条件

```txt
仮素材でも、もう一度遊びたい核がある
```

---

# Milestone 4: スマホ実機検証

## 目的

スマホで本当に遊べるか確認する。

## 実装範囲

```txt
スマホブラウザ対応
非アクティブ時ポーズ
音ON/OFF
画面揺れON/OFF
ダメージ数字ON/OFF
デバッグメニュー
```

## 検証端末

```txt
iPhone
Android
可能なら古めの端末
```

## 完了条件

```txt
[ ] 縦持ちで読める
[ ] 仮想スティックが押しやすい
[ ] 必殺技ボタンが押せる
[ ] 30fpsを大きく下回らない
[ ] 中断復帰で事故らない
```

## 次へ進む条件

```txt
スマホ操作/視認性/性能が破綻しない
```

---

# Milestone 5: 継続プレイ検証

## 目的

1回で終わらず、もう一度遊ぶ理由があるか確認する。

## 実装範囲

```txt
localStorage保存
簡易実績
簡易図鑑
通貨
永続強化5種
次の目標表示
```

## 完了条件

```txt
[ ] 3回遊ぶ理由がある
[ ] 永続強化なしでもクリア可能
[ ] 図鑑/実績が邪魔ではない
[ ] 次の目標が分かる
```

## 次へ進む条件

```txt
短期継続の核がある
```

# Milestone 6: デザイン本格化

## 目的

ゲーム性の核が見えた後に、デザインを本格化する。

## 前提条件

```txt
Prototype 3以上で、仮素材でも遊びたい核がある
スマホ操作が破綻していない
MVPスコープが凍結している
```

## 成果物

```txt
アートディレクション
キャラ見た目
敵見た目
背景
UIデザイン
ロゴ
アイコン
演出方針
```

## 注意

デザインでゲームロジックを壊さない。

---

# Milestone 7: アプリ化検討

## 目的

Webプロトタイプを、アプリとして展開できるか判断する。

## 候補

```txt
PWA
Capacitor
iOS/Androidネイティブ移植
Unity/Godot移植
```

## 判断条件

```txt
Web版で遊びの核が証明済み
スマホで性能が許容範囲
継続プレイの理由がある
デザイン方針がある
```

## 注意

アプリ化は目的ではなく、面白いゲームを届ける手段。

---

# 進行ゲート

## 次に進んではいけない条件

```txt
Prototype 1が不快なのに武器を増やす
Prototype 2が退屈なのに8分化する
8分が面白くないのにデザイン本格化する
スマホで操作しづらいのにアプリ化する
```

## 最重要ゲート

```txt
仮素材でも、もう一度遊びたいか？
```

これがNOなら、デザインではなくゲーム性を直す。

# Season 1 Truth Map

## 目的

Season 1 の表の出来事、プレイヤーの誤解、各キャラの誤解、実際に起きたこと、小物の反転、回収タイミングを一枚の設計図として固定する。

現行正史:

```txt
黒インクで固定された“間違った意味”をほどき、正しい持ち主に返す。
```

---

# 1. Season 1 の本当の主題

表の主題:

```txt
忘れ物を拾って、朝まで残る。
```

裏の主題:

```txt
誰かが信じ込んだ“間違った意味”を、正しい持ち主へ返す。
```

最後に残す感情:

```txt
悲しいことはあった。
でも、間違った意味で固定されなくなった。
なかったことにはならなかった。
```

---

# 2. Season 1 の大真相

プレイヤーが最初に信じること:

```txt
ユイは一人で夜を歩いている。
忘れ物を拾うと強くなる。
黒インクの影は記憶を奪う敵。
```

中盤で疑わせること:

```txt
忘れ物は落ちていたのではなく、置かれていたように見える。
アイテムには持ち主の気配がある。
影は攻撃しているのではなく、何かを読ませまいとしている。
```

終盤で分かること:

```txt
黒インクは事実を消すものではない。
人が信じ込んだ“間違った意味”を固定するものだった。

忘れ物係は、ただの遊びではなかった。
黒インク化しそうな意味を、名前・場所・理由・証拠へ分けて隔離し、後で返せるようにする仕組みだった。

ユイは記憶力が良い子ではない。
どれだけ黒く塗られても、それが誰のものだったかだけは間違えない子だった。
```

Season 1 の最終反転:

```txt
ユイは忘れ物を拾っていたのではない。
誤解で固定された意味を、正しい持ち主に返していた。
```

---

# 3. 忘れ物係の真相

表:

```txt
子どもたちの遊び。
落とし物を拾って、名前をつけて、箱にしまって、地図に書いて、灯りで探す。
```

裏:

```txt
黒インク化しそうな意味を処理する、街の記憶隔離/返却プロトコル。
```

ただし、子どもたちはそれを知らない。

重要な二重意味:

```txt
拾う      = 証拠を回収する
名前をつける = 持ち主を識別する
しまう    = 読まれると壊れる理由を隔離する
道を書く   = 返却先を記録する
灯す      = 朝まで意味を失わせない
```

# 4. 各キャラの誤解と真相

## ユイ

誤解:

```txt
自分が忘れたせいで、大切な名前を消した。
```

真相:

```txt
ユイは忘れたのではない。
黒インクが固定しそうだった“間違った意味”を、忘れ物へ分けて逃がした。
```

固有能力:

```txt
持ち主を間違えない。
```

---

## アサ

誤解:

```txt
自分の名前は呼ばれなかった。
ユイに忘れられた。
```

黒インクが固定した意味:

```txt
名前を呼ばれなかった人。
```

真相:

```txt
名前は呼ばれなかったのではない。
守るために何度も書き直され、黒インクに読まれないように分散されていた。
```

小物反転:

```txt
空白の名札
初見: 名前が失われた名札
反転: 何度も名前を書き直して、消えきらなかった名札
```

---

## ナギ

誤解:

```txt
自分が箱にしまったせいで、言葉が届かなかった。
```

黒インクが固定した意味:

```txt
閉じ込めた人。
```

真相:

```txt
箱は拒絶ではなく、隔離だった。
読まれると壊れる理由を、朝まで守るために閉じた。
```

---

## ミチル

誤解:

```txt
帰り道を残せなかった。
大切な誰かを帰せなかった。
```

黒インクが固定した意味:

```txt
帰れなかった道。
```

真相:

```txt
帰り道は失われていなかった。
ただ、名前と理由が切れていたため、誰がどこへ帰る道か分からなくなっていた。
```

---

## トモリ

誤解:

```txt
自分だけが待っていた。
誰も戻ってこなかった。
```

黒インクが固定した意味:

```txt
待ちぼうけの灯り。
```

真相:

```txt
トモリは待っていただけではない。
つなぎ直した意味が朝までほどけないよう、灯りを直し続けていた。
```

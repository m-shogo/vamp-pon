# Season 1 Truth Map

## 目的

Season 1 の表の出来事、プレイヤーの誤解、各キャラの誤解、実際に起きたこと、小物の反転、回収タイミングを一枚の設計図として固定する。

この版では、以前の弱かった前提を更新する。

```txt
旧: 読めなくなった記憶を読める形に戻す
新: 黒インクで固定された“間違った意味”をほどき、正しい持ち主に返す
```

---

# 1. Season 1 の本当の主題

表の主題:

```txt
忘れ物を拾って、朝まで残る。
```

裏の主題:

```txt
誰かが信じ込んだ“間違った意味”を、正しい持ち主へ返す。
```

最後に残す感情:

```txt
悲しいことはあった。
でも、間違った意味で固定されなくなった。
なかったことにはならなかった。
```

---

# 2. Season 1 の大真相

プレイヤーが最初に信じること:

```txt
ユイは一人で夜を歩いている。
忘れ物を拾うと強くなる。
黒インクの影は記憶を奪う敵。
```

中盤で疑わせること:

```txt
忘れ物は落ちていたのではなく、置かれていたように見える。
アイテムには持ち主の気配がある。
影は攻撃しているのではなく、何かを読ませまいとしている。
```

終盤で分かること:

```txt
黒インクは事実を消すものではない。
人が信じ込んだ“間違った意味”を固定するものだった。

忘れ物係は、ただの遊びではなかった。
黒インク化しそうな意味を、名前・場所・理由・証拠へ分けて隔離し、後で返せるようにする仕組みだった。

ユイは記憶力が良い子ではない。
どれだけ黒く塗られても、それが誰のものだったかだけは間違えない子だった。
```

Season 1 の最終反転:

```txt
ユイは忘れ物を拾っていたのではない。
誤解で固定された意味を、正しい持ち主に返していた。
```

---

# 3. 忘れ物係の真相

表:

```txt
子どもたちの遊び。
落とし物を拾って、名前をつけて、箱にしまって、地図に書いて、灯りで探す。
```

裏:

```txt
黒インク化しそうな意味を処理する、街の記憶隔離/返却プロトコル。
```

ただし、子どもたちはそれを知らない。

重要な二重意味:

```txt
拾う      = 証拠を回収する
名前をつける = 持ち主を識別する
しまう    = 読まれると壊れる理由を隔離する
道を書く   = 返却先を記録する
灯す      = 朝まで意味を失わせない
```

この二重意味が、プレイ後の考察の気持ちよさになる。

# 4. 各キャラの誤解と真相

## ユイ

誤解:

```txt
自分が忘れたせいで、大切な名前を消した。
```

真相:

```txt
ユイは忘れたのではない。
黒インクが固定しそうだった“間違った意味”を、忘れ物へ分けて逃がした。
```

固有能力:

```txt
持ち主を間違えない。
```

ゲーム上の意味:

```txt
欠片やアイテムを拾える。
進化条件の“本来の持ち主”判定に関わる。
```

反転後の見え方:

```txt
ユイの回収能力は便利能力ではなく、誤った意味を本人へ返すための力だった。
```

---

## アサ

誤解:

```txt
自分の名前は呼ばれなかった。
ユイに忘れられた。
```

黒インクが固定した意味:

```txt
名前を呼ばれなかった人。
```

真相:

```txt
名前は呼ばれなかったのではない。
守るために何度も書き直され、黒インクに読まれないように分散されていた。
```

小物反転:

```txt
空白の名札
初見: 名前が失われた名札
反転: 何度も名前を書き直して、消えきらなかった名札
```

回収後の意味:

```txt
アサは“忘れられた人”ではなく、“忘れないために何度も書き直された人”になる。
```

---

## ナギ

誤解:

```txt
自分が箱にしまったせいで、言葉が届かなかった。
```

黒インクが固定した意味:

```txt
閉じ込めた人。
```

真相:

```txt
箱は拒絶ではなく、隔離だった。
読まれると壊れる理由を、朝まで守るために閉じた。
```

小物反転:

```txt
開けるな、と書かれた箱
初見: 拒絶/秘密
反転: 黒インクから理由を守るための封印
```

回収後の意味:

```txt
ナギは“閉じ込めた人”ではなく、“壊れないように閉じた人”になる。
```

---

## ミチル

誤解:

```txt
帰り道を残せなかった。
大切な誰かを帰せなかった。
```

黒インクが固定した意味:

```txt
帰れなかった道。
```

真相:

```txt
帰り道は失われていなかった。
ただ、名前と理由が切れていたため、誰がどこへ帰る道か分からなくなっていた。
```

小物反転:

```txt
片方だけの切符
初見: 帰れなかった証拠
反転: 裏に帰りの印があり、帰る予定は残っていた証拠
```

回収後の意味:

```txt
ミチルは“道を失った人”ではなく、“道だけは残していた人”になる。
```

---

## トモリ

誤解:

```txt
自分だけが待っていた。
誰も戻ってこなかった。
```

黒インクが固定した意味:

```txt
待ちぼうけの灯り。
```

真相:

```txt
トモリは待っていただけではない。
つながり直した意味が朝までほどけないよう、灯りを直し続けていた。
```

小物反転:

```txt
直されたランタン
初見: 古い光アイテム
反転: 何度も直され、毎晩ユイを朝まで支えた灯り
```

回収後の意味:

```txt
トモリは“置いていかれた人”ではなく、“みんなが帰れるように灯していた人”になる。
```

# 5. Season 1 の因果レール

## Page 1: 拾う

表:

```txt
ユイが欠片を拾う。
```

裏:

```txt
持ち主不明の証拠を回収している。
```

伏線:

```txt
同じ種類の欠片でも、ユイが近づいた時だけわずかに光り方が違う。
```

回収後の見え方:

```txt
ユイは拾えるのではなく、持ち主を間違えないから反応していた。
```

---

## Page 2: 名前

表:

```txt
アサの名札が読めない。
```

裏:

```txt
黒インクが“名前を呼ばれなかった”という誤解を固定している。
```

伏線:

```txt
空白名札に消し跡が多すぎる。
```

回収:

```txt
名前がなかったのではなく、何度も書いたから跡が残っていた。
```

---

## Page 3: 箱

表:

```txt
閉じた箱が開かない。
```

裏:

```txt
開ける順番を間違えると、理由だけが先に出て痛みになる。
```

伏線:

```txt
箱の鍵穴が外向きではなく内向きについている。
```

回収:

```txt
箱は閉じ込めるためではなく、中から壊れないようにするためだった。
```

---

## Page 4: 道

表:

```txt
片方だけの切符がある。
```

裏:

```txt
場所だけ戻っても、名前が戻らなければ帰る人が分からない。
```

伏線:

```txt
切符の裏面だけ温かい。
```

回収:

```txt
裏に帰りの印がある。
片道ではなかった。
```

---

## Page 5: 灯り

表:

```txt
ランタンが最後の道を照らす。
```

裏:

```txt
つなぎ直した意味を、朝の確定処理まで保持している。
```

伏線:

```txt
ランタンの修理跡が1人分ではない。
```

回収:

```txt
ユイだけでなく、複数の筆跡/修理跡が残っていた。
```

# 6. プレイヤーの誤解設計

序盤で信じさせること:

```txt
アイテムは強化素材
影は敵
欠片は経験値
地図帳は図鑑
```

中盤で揺らすこと:

```txt
同じ強化でも、拾う順番でリザルト文が変わる
敵が特定のアイテムを守るように動く
箱や名札が“使われた跡”を持つ
```

終盤で反転すること:

```txt
アイテムは効果ではなく、意味の接続点だった
影は悪意ではなく、固定された誤解だった
地図帳は図鑑ではなく、朝に意味を確定する帳面だった
```

# 8. Season 1 で閉じないこと

閉じないもの:

```txt
黒インクが最初にどこで生まれたか
忘れ物係がなぜ子どもの遊びとして現れたのか
他にも同じ仕組みを使う班がいるのか
地図帳を綴じた人物が誰か
朝の確定処理は本当に安全なのか
```

ただし、1のラストで露骨に予告しない。

残すのは違和感。

```txt
閉じたはずのページの端だけ、別の折り方になっている。
見覚えのない綴じ糸が、最後のページに一本だけ混ざっている。
```

# 9. 最重要

Season 1 の心臓はこれ。

```txt
ユイは忘れ物を拾っていたのではない。
誤解で固定された意味を、正しい持ち主へ返していた。
```

Season 1 の救いはこれ。

```txt
悲しい出来事は消えない。
でも、その出来事についた間違った意味は外れる。
```

Season 1 の気持ちよさはこれ。

```txt
最初はただ拾っていた。
最後に、拾う順番も、道具の形も、敵の動きも、全部に理由があったと分かる。
```

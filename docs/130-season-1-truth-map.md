# Season 1 Truth Map

## 目的

Season 1 の表の出来事、プレイヤーの誤解、各キャラの誤解、実際に起きたこと、小物の反転、回収タイミングを一枚の設計図として固定する。

キャラを増やす前に、物語の心臓を確定する。

---

# 1. 基本姿勢

Vamp Pon は、好きな作品の要素を直接借りない。

使うのは Vamp Pon 固有の素材だけ。

```txt
忘れ物
地図帳
黒インク
朝
ページ束
名前
箱
切符
ランタン
紙片
ラベル
しおり
```

この素材だけで、感動・驚き・恋愛未満の親密さ・友情・家族愛・悲しみ・楽しさを作る。

---

# 2. Season 1 の本当のテーマ

表のテーマ:

```txt
忘れ物を拾って、朝まで残る。
```

裏のテーマ:

```txt
誰かに見られていなかったと思った子たちが、実は互いを見ていた証拠を拾う。
```

最後に残す感情:

```txt
自分は忘れられていなかった。
自分も誰かを忘れなかった。
このページだけは、朝まで守れた。
```

# 3. Season 1 の大真相

プレイヤーが最初に信じること:

```txt
ユイは一人で夜を歩いている。
忘れ物を拾うと、少しだけ記憶が戻る。
黒インクの影は記憶を奪う敵。
```

実際に起きていたこと:

```txt
ユイは一人ではなかった。
昔の仲間たちが残した道具や筆跡に導かれていた。

黒インクはただの敵ではない。
読めなくなった記憶、隠された痛み、守ろうとした記憶の影でもある。

ユイは大切な人を忘れたのではない。
黒インクに完全に読まれないよう、名前・道・灯り・手紙・箱へ記憶を分けた。

その代償として、ユイ自身はなぜ拾っているのか分からなくなった。
```

---

# 4. 各キャラの誤解と真相

## ユイ

表の誤解:

```txt
自分が忘れたせいで、大切な名前を消した。
```

真相:

```txt
忘れたのではなく、消えないように忘れ物へ分けて残した。
```

プレイヤーへの見せ方:

```txt
序盤: ユイは記憶が抜けている
中盤: ユイ以外の筆跡が増える
終盤: 拾っていたものが、ユイ自身の選択の結果だったと分かる
```

---

## アサ

表の誤解:

```txt
自分の名前は呼ばれなかった。
ユイに忘れられた。
```

真相:

```txt
ユイは名前を忘れたくなくて、何度も書き直した。
アサの名前は空白ではなく、消えないように何度も貼り直された。
```

小物反転:

```txt
空白の名札
→ 何度も名前を書き直した跡がある
```

感情:

```txt
恋愛未満の親密さ
名前を呼ばれたい気持ち
忘れられたと思う悲しさ
```

---

## ナギ

# 5. プレイヤーの誤解設計

## 序盤で信じさせること

```txt
ユイは孤独な主人公
アイテムはただの強化素材
影は倒す敵
地図帳はコレクションUI
```

## 中盤で揺らすこと

```txt
アイテム説明が少しおかしい
同じ筆跡が別の場所に出る
空白アイテムに書き直し跡がある
道具がユイのために置かれているように見える
```

## 終盤で反転すること

```txt
アイテムは強化素材ではなく、誰かの手助けだった
影は悪意だけではなく、読めなくなった記憶だった
地図帳はUIではなく、誰かへ毎晩物語を読み直す装置だった
ユイは一人ではなかった
```

# 8. 恋愛の扱い

恋愛を主役にしない。

しかし、アサとユイの間には強い親密さを置く。

やる:

```txt
名前を書き直す
同じ帰り道を選ぶ
相手の癖だけ覚えている
言えなかった一言が道具に残る
```

やらない:

```txt
告白で説明する
恋愛だけを動機にする
誰と誰が付き合うかを主軸にする
```

恋愛として読める。

友情としても読める。

その余白を残す。


Season 1では、世界に厚みを出す程度でよい。

# 11. 2への自然接続

2は以下が強い。

```txt
届かなかった手紙
```

理由:

```txt
Season 1の地図帳から自然に派生できる
恋愛、家族、先生、兄妹、郵便屋、街の人を混ぜられる
黒インクの別側面を描ける
暗くしすぎず、温かい反転へ持っていける
```

2の核:

```txt
届かなかった言葉も、なかったことにはならない。
```

# 13. 最重要

Season 1 の心臓はこれ。

```txt
ユイは一人で拾っていたのではない。
みんなが残した小さな手助けを、毎晩拾っていた。
```

そして、このゲームの強さはこれ。

```txt
遊んでいる時は気持ちいい。
終わった後に、小物の意味を思い出して少し泣ける。
```

# ストア用クリエイティブ撮影計画

Vamp Ponをスマホ向けに出す時、実装後に慌ててスクリーンショットや動画を作らないための撮影計画。
コード、素材、runtimeは変更しない。Stage1制作とUnity移行の途中から、後でそのまま宣材になる画面を意識する。

  https://developer.apple.com/help/app-store-connect/manage-app-information/upload-app-previews-and-screenshots/

## 公式要件メモ

### Apple

- スクリーンショットは最低1枚、最大10枚。
- 形式は `.jpeg`, `.jpg`, `.png`。
- App Previewは任意。
- App Previewは、対応device size/languageごとに最大3本。
- iOS App Previewはportrait/landscapeどちらも可。
- App Previewはスクリーンショットより前に表示される。
- App Previewの処理には時間がかかる場合がある。

### Google Play

- スクリーンショットは、対応device typeごとに最大8枚。
- 公開には最低2枚のスクリーンショットが必要。
- JPEGまたは24-bit PNG、alphaなし。
- 最小320px、最大3840px。
- ゲームでおすすめ枠を狙うなら、9:16 portraitは最低1080x1920を3枚以上用意する。
- Feature graphicは必須。
- Feature graphicは1024x500、JPEGまたは24-bit PNG、alphaなし。
- Feature graphicとアプリアイコンとゲーム内の色・雰囲気を揃える。
- Feature graphicに細かすぎる情報を詰め込まない。
- Google Play上の評価、順位、価格、期間限定表現を画像へ入れない。

## Vamp Ponの基本方針

- 実画面をベースにする。
- 実装していない機能を見せない。
- 文字を盛りすぎない。
- スクショ1枚ごとに伝える役割を1つに絞る。
- 最初の3枚でゲーム体験が分かるようにする。
- 夜、記憶、ランタン、紙片、黒インク、朝の世界観を一貫させる。
- かわいいだけでなく、少し切ない絵本風の空気を見せる。
- 他作品名やジャンル元ネタに依存しない。

## 優先する撮影画面

### Screenshot 1: 戦闘の核

目的:

- 縦画面アクションであることを一瞬で伝える。
- ユイ、敵、XP、HUD、背景が読めることを示す。

必要な画面状態:

- Stage1背景。
- ユイが中央やや下。
- 敵が複数いる。
- XPが見える。
- HUDが読める。
- 右上ゲージや右下ボタン予定領域が破綻していない。

避ける:

- 敵が多すぎて読めない。
- エフェクトで画面が白飛び/黒潰れする。
- UIが未完成に見える。

### Screenshot 2: レベルアップ選択

目的:

- 成長と選択の楽しさを見せる。
- 3枚カードが読めるUI品質を見せる。

必要な画面状態:

- 3枚カード。
- アイコン、タイトル、説明が読める。
- 進化/合体/覚醒ヒントが分離されている。
- レアや特別枠が少し光る。

避ける:

- 説明文切れ。
- カードの文字密度が高すぎる。
- ただのメニュー画面に見える。

### Screenshot 3: 進化/合体/覚醒の瞬間

目的:

- 1プレイ中の最大報酬を見せる。
- 普通のレベルアップとは違う特別感を見せる。

必要な画面状態:

- 進化/合体/覚醒の演出。
- 完成品のアイコンまたは武器表現。
- 暖色の光と黒インクが両方見える。
- 画面は強いが読める。

避ける:

- 何が起きているか分からない全画面エフェクト。
- 怖すぎる表現。
- 赤目悪魔化に寄る表現。

### Screenshot 4: キャラと世界観

目的:

- ユイの主人公感を見せる。
- ランタン、紙片、夜、記憶の雰囲気を伝える。

必要な画面状態:

- ユイの通常カットイン、またはキャラ選択/図鑑に近い見せ場。
- ランタンは本人の右手。
- バッグ紐は右肩から左腰。
- バッグ本体は左腰。
- 背景は暗いが暖かい。

避ける:

- キャラの固定事項ミス。
- ただの立ち絵紹介。
- ゲーム画面と乖離しすぎたイラスト。

### Screenshot 5: Result / 記憶ページ

目的:

- 1プレイ後の達成感を見せる。
- ただのスコア画面ではなく、記憶を取り戻す世界観を伝える。

必要な画面状態:

- Result Clear。
- Rank seal。
- Reward row。
- New record。
- 成長導線。
- 朝の光。

避ける:

- 数字だけのリザルト。
- CTAが弱い。
- 報酬が少なく見える。

### Screenshot 6: 永続強化/成長

目的:

- 負けても進むゲームであることを伝える。
- 継続プレイの理由を見せる。

必要な画面状態:

- Growth / Upgrade画面。
- 基礎強化やキャラ成長。
- リセット可能なら安全に見える導線。

避ける:

- 未実装なら撮らない。
- 課金画面に見える表現。

### Screenshot 7: 図鑑/記録

目的:

- 世界観とコレクション性を見せる。
- 紙の図鑑、記憶、発見済み/未発見の体験を伝える。

必要な画面状態:

- Collection / Codex。
- 新しく灯った記憶。
- 未発見の影。
- 情報量は抑える。

避ける:

- 文字だらけ。
- ただの一覧表。

### Screenshot 8: 黒曜化/必殺

目的:

- ゲーム独自の強い瞬間を見せる。
- 危険だが主人公感のある演出を伝える。

必要な画面状態:

- 黒曜化または必殺の発動瞬間。
- 黒インクの端演出。
- ランタンの暖色核。
- 敵やUIがまだ読める。

避ける:

- 画面が真っ黒。
- 表情が怖すぎる。
- 可読性が消える。

## 短尺動画構成

Apple App PreviewとGoogle Play preview videoのどちらにも流用しやすいよう、まず15〜30秒で作る。

### 15秒版

```txt
0.0-2.0s   夜の街とユイ。ランタンが灯る。
2.0-5.0s   敵が近づき、武器が当たる。
5.0-7.5s   XPが吸い寄せられる。
7.5-10.5s  レベルアップカードを選ぶ。
10.5-13.0s 進化/黒曜化/必殺の強い瞬間。
13.0-15.0s ResultまたはタイトルCTA。
```

### 30秒版

```txt
0-3s     世界観。夜、ランタン、紙片。
3-8s     戦闘開始。敵、攻撃、XP。
8-13s    レベルアップ選択。
13-18s   強化後の攻撃。
18-23s   進化/合体/覚醒/黒曜化。
23-27s   Result。記憶ページ、報酬。
27-30s   タイトル/ロゴ/短いCTA。
```

## Feature graphic方針

Google PlayのFeature graphicは1024x500。
Vamp Ponでは以下を基本にする。

構図:

- 中央: ユイのシルエットとランタン。
- 左右: 夜の街、紙片、黒インクの流れ。
- 右奥: 影の気配。
- 下部: 朝の暖色を少しだけ。

避ける:

- 細かいUIを入れすぎる。
- 真っ黒、真っ白、濃いグレーだけにする。
- ランキング、受賞、価格、期間限定表現。
- 小さすぎる文字。

## 撮影前チェック

- [ ] 390x844で破綻していない。
- [ ] 実機または実機相当の画面で撮る。
- [ ] debug表示を消す。
- [ ] 未実装表示を消す。
- [ ] placeholder画像を使わない。
- [ ] HUDが読める。
- [ ] カード文字が切れていない。
- [ ] 画面が暗すぎない。
- [ ] 実際のゲーム体験と一致している。

## 出力候補

Apple向け:

- iPhone 6.9 inch portrait: 1320x2868 / 1290x2796 / 1260x2736 系を最終確認。
- 必要に応じて6.5 inch以下へスケール。
- Screenshot 5〜8枚。
- App Preview 15〜30秒は任意。

Google Play向け:

- Phone portrait: 1080x1920以上を基本。
- Screenshot 5〜8枚。
- Feature graphic: 1024x500。
- Preview videoはYouTube URL運用を想定。

## 最終判断

ストア用クリエイティブは、別物の広告画像ではなく、実画面の完成度確認でもある。
Vamp Ponでは、最初の3枚で以下が伝わる必要がある。

1. 縦画面で戦う。
2. レベルアップで選ぶ。
3. 記憶とランタンの世界観がある。

この3つが伝わらない画面は、ゲーム内でもまだ弱い。

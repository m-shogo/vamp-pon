# キャラ別必殺技 方針

## 目的

Vamp Pon に、キャラごとの必殺技を入れる案を評価する。

ヴァンサバ系の自動攻撃・爽快感は維持しつつ、キャラごとの個性、救済、裏ストーリー演出を出すための仕組みとして設計する。

## 結論

キャラ別必殺技は入れる価値が高い。

ただし、MVP初期から複雑にしすぎない。

おすすめは以下。

```txt
操作は1ボタン、または自動発動
発動頻度は低め
効果は分かりやすい
画面を止めない
キャラの裏ストーリーと結びつく
```

## 期待する役割

### 1. キャラ差を強くする

通常武器だけだとキャラ差が薄くなりやすい。

必殺技があると、キャラを変える理由ができる。

### 2. ピンチの救済になる

ヴァンサバ系では、終盤に詰みかける瞬間がある。

必殺技は、そこを一度だけ押し返す快感になる。

### 3. 裏ストーリーを演出できる

Vamp Pon の裏ストーリーは表に出さない。

必殺技は、キャラの記憶・忘れ物・旅の記録が一瞬だけ戻る演出にできる。

例:

```txt
忘れられた名前を呼ぶ
黒インクを押し返す
地図の道を一瞬だけ照らす
影を倒すのではなく、記憶に戻す
```

## 重要ルール

### ルール1: 操作を忙しくしない

ヴァンサバ系の良さは、移動中心で気持ちよく遊べること。

必殺技を入れても、アクションゲーム化しすぎない。

NG:

```txt
コマンド入力
連打必須
方向指定がシビア
複数スキル切り替え
コンボ前提
```

OK:

```txt
1ボタン発動
ゲージ最大で自動発動
ピンチ時に自動発動
レベルアップ後に一度だけ発動
```

### ルール2: 必殺技でビルドを壊さない

強すぎる必殺技は、武器選択や進化を無意味にする。

必殺技は主役ではなく、キャラの味付けと救済。

### ルール3: 発動時に気持ちいい演出を入れる

必殺技は、爽快感を作る重要ポイント。

```txt
画面フラッシュ
短いスロー
大きめのSE
敵が一気に消える
経験値が吸い寄せられる
裏ストーリーの短い一文
```

ただし、長いカットインは入れすぎない。

### ルール4: 裏ストーリーの断片にする

必殺技名や説明文は、裏ストーリーの断片にする。

```txt
「夜明けの呼び声」
「消えない名前」
「黒インク払い」
「最後の切符」
「忘れ物の王冠」
```

## 必殺技タイプ

### タイプA: 画面一掃型

効果:

```txt
周囲または画面内の敵を大きく消す
```

良い点:

- 気持ちいい
- 分かりやすい
- ピンチ救済になる

リスク:

- 強すぎると武器ビルドが不要になる

### タイプB: 吸引型

効果:

```txt
経験値・アイテム・記憶の欠片を一気に吸い寄せる
```

良い点:

- ヴァンサバ系と相性が良い
- 気持ちいい
- 裏ストーリーと合う

リスク:

- 戦闘の派手さは弱い

### タイプC: 時間停止/減速型

効果:

```txt
数秒間、敵や影の動きを遅くする
```

良い点:

- ピンチ回避になる
- 時計/記録/記憶テーマと合う

リスク:

- テンポが悪くなる可能性

### タイプD: 変身/覚醒型

効果:

```txt
一定時間、攻撃性能が大きく上がる
```

良い点:

- キャラ差が出る
- 爽快感が強い

リスク:

- バランス調整が重い

### タイプE: 復元型

効果:

```txt
影を倒すと、追加で記憶の欠片や報酬を得る
```

良い点:

- 裏ストーリーと一番合う
- 収集要素に意味が出る

リスク:

- 戦闘中の分かりやすさが弱い

## 発動方式

### 案1: 手動1ボタン

```txt
ゲージが満タンになったら、1ボタンで発動
```

良い点:

- プレイヤーの判断が入る
- ピンチで使える

リスク:

- 操作が1つ増える
- スマホや片手操作では重い可能性

### 案2: 自動発動

```txt
ゲージ満タン後、条件を満たすと自動発動
```

例:

```txt
HPが30%以下
敵が一定数近い
ボス出現時
レベルアップ時
```

良い点:

- 操作が増えない
- 初心者に優しい

リスク:

- 使いたい時に使えない
- 戦略性は弱い

### 案3: 手動/自動の選択

```txt
設定で自動必殺をON/OFFできる
```

MVPでは重いので後回し。

## MVPでの推奨

MVPでは、以下が良い。

```txt
キャラ: 1〜2人
必殺技: 各1個
発動方式: 手動1ボタン、またはピンチ時自動発動
ゲージ条件: 経験値取得 / 敵撃破 / 時間経過で蓄積
演出: 1秒以内
説明文: 裏ストーリー断片つき
```

最初に作るなら、以下の2種類。

```txt
主人公: 忘れ物を戻す吸引型
別キャラ: 黒インクを払う画面一掃型
```

## 必殺技候補

### 1. 消えない名前

タイプ:

```txt
吸引 + 復元
```

効果:

```txt
一定範囲の経験値・記憶の欠片を吸い寄せる。
同時に、近くの小型影を記憶の欠片に戻す。
```

説明:

```txt
名前を呼ばれた影は、少しだけ元の形を思い出す。
```

### 2. 黒インク払い

タイプ:

```txt
画面一掃
```

効果:

```txt
画面内の弱い影を一掃し、黒インク床/危険エリアを数秒だけ消す。
```

説明:

```txt
消えかけた道に、もう一度だけ線を引く。
```

### 3. 北極星の合図

タイプ:

```txt
吸引 + 移動補助
```

効果:

```txt
経験値を大きく吸引し、数秒間移動速度が上がる。
```

説明:

```txt
迷ったときだけ見える、小さな帰り道。
```

### 4. 朝まで残る光

タイプ:

```txt
防御 + 押し返し
```

効果:

```txt
数秒間バリアを張り、周囲の敵を押し返す。
```

説明:

```txt
夜が終わるまで、消えないと決めた光。
```

### 5. 最後の切符

タイプ:

```txt
緊急回避
```

効果:

```txt
HPが0になるダメージを一度だけ無効化し、近くの安全地点へ移動する。
```

説明:

```txt
行き先は読めない。それでも、まだ使える。
```

### 6. 影ほどき

タイプ:

```txt
変換
```

効果:

```txt
一定時間、倒した影が追加の記憶の欠片を落とす。
```

説明:

```txt
倒すのではなく、絡まった名前をほどく。
```

### 7. 未完成のページ

タイプ:

```txt
覚醒
```

効果:

```txt
数秒間、全武器の発射数と攻撃範囲が上がる。
```

説明:

```txt
書きかけのページほど、続きを急いでいる。
```

### 8. 展示灯

タイプ:

```txt
範囲固定ダメージ
```

効果:

```txt
プレイヤー周辺に光の円を作り、入った影に継続ダメージを与える。
```

説明:

```txt
照らしているのは敵ではない。忘れられた名前だ。
```

### 9. 星色カプセル

タイプ:

```txt
ランダム補助
```

効果:

```txt
ランダムで攻撃/吸引/回復/バリアのどれかが発動する。
```

説明:

```txt
開くまで、中身は誰にも思い出せない。
```

### 10. 夜明けの一行

タイプ:

```txt
全体強化 + 短い演出
```

効果:

```txt
一定時間、武器進化済み効果が強化される。
```

説明:

```txt
最後に残った一行だけが、朝まで消えなかった。
```

## キャラ例

必殺技:

```txt

```

特徴:

```txt
経験値吸引が得意
記憶の欠片を集めやすい
初心者向け
```

裏:

```txt
誰かの忘れ物を、元の場所へ戻している。
```

### キャラB: 地図読み

必殺技:

```txt
黒インク払い
```

特徴:

```txt
危険エリアを押し返す
画面整理が得意
中級者向け
```

裏:

```txt
消えた旅の記録をたどっている。
```

### キャラC: 夜番

必殺技:

```txt
朝まで残る光
```

特徴:

```txt
防御型
ピンチに強い

```

裏:

```txt
夜が明けるまで、展示室/部屋/地図帳を見張っている。
```

必殺技:

```txt

```

特徴:

```txt
ランダム性が高い
報酬集めが得意
遊びの変化が大きい
```

裏:

```txt
空のカプセルに、失くした名前を戻している。
```

## リスク

### 1. ヴァンサバ感が薄れる

必殺技を強くしすぎると、別ジャンルになる。

対策:

```txt
1キャラ1技
ゲージ制
演出1秒以内
連発不可
```

### 2. 操作が増える

初心者やぼーっと遊びたい層には負担。

対策:

```txt
自動発動モード
またはピンチ時自動発動
```

### 3. バランス調整が重い

キャラごとに必殺技があると、調整対象が増える。

対策:

```txt
MVPは1〜2キャラだけ
効果タイプを限定
数値より体験重視で検証
```

### 4. 演出過多

カットインや長い停止演出はテンポを壊す。

対策:

```txt
画面停止は最大0.3秒程度
カットインなし、または短いアイコン演出
SEとエフェクトで気持ちよくする
```

## 現時点の推奨仕様

```txt
名称: 必殺技 / 記憶技 / 夜技 / 秘技 など要検討
キャラごとに1つ
ゲージ制
1ボタン発動 or ピンチ時自動発動
画面停止は短く
効果は分かりやすく
裏ストーリー断片を説明文に入れる
```

## MVP採用案

### 採用候補1: 消えない名前

```txt
キャラ: 忘れ物係
効果: 経験値吸引 + 周囲の小型影を記憶の欠片に変換
役割: 初心者救済、収集快感、裏ストーリー演出
```

### 採用候補2: 黒インク払い

```txt
キャラ: 地図読み
効果: 画面内小型影を一掃 + 黒インク危険エリアを短時間消す
役割: ピンチ救済、地図帳テーマ、爽快感
```

## 結論

キャラ別必殺技はかなりあり。

ただし、アクション性を上げるためではなく、以下のために使う。

```txt
キャラ差
ピンチ救済
爽快感
裏ストーリーの断片
長く遊ぶ理由
```

Vamp Pon では、必殺技は「敵を倒す大技」だけではなく、**忘れられた記憶を一瞬だけ元に戻す技**として扱うと独自性が出る。

# 1. Four separate axes

混同禁止:

1. `chronologicalAge` — 実年齢。未確定なら未確定。
2. `ageImpression` — 外見 / 社会役割として見える年齢感。
3. `eraPlacement` — どの時代の人物か。年齢とは別。
4. `dreamCoPresence` — ヨルノシルベで同時に一緒にいること。

Important:

```txt
Dreamで同じテーブルを囲む
≠
Realityで同じ年代に生きている
```

例:
- ゲンが高齢 = OLD eraの証明ではない。
- クロエが若い外見 = 最近生まれた証明ではない。
- ユイとアサが見た目同年代 = Reality同世代の証明ではない。

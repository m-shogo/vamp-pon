# ヨルノシルベ Story Book

Date: 2026-07-28  
Status: **CURRENT STORY UNDERSTANDING BOOK / HUMAN + AI FIRST-CLASS MEMORY**

この本は、ヨルノシルベの物語を「仕様の断片」ではなく、一つの作品として思い出すための本。

Character Bookと同じ立場で使う。

- キャラクターを思い出す → `docs/character-book-v2.md`
- 物語を思い出す → **この本**
- ユーザーが出した案を思い出す → `docs/IDEA-BOOK.md`

この本にある内容はすべて同じ確度ではない。

## 情報ラベル

- **CANON** — 現時点で正本として扱う
- **USER DIRECTION** — ユーザーが明示した大切な方向。細部はまだ変えられる
- **HIGH-VALUE CANDIDATE** — かなり相性が良い案だが、まだ真相として固定しない
- **OPEN QUESTION** — 答えを今決めない問い
- **SERIES SEED** — 1では自然に見せ、後作で意味を変えられる伏線候補

`USER DIRECTION` や `CANDIDATE` を、AIが勝手に `CANON` へ昇格させない。

# 1. 5分で戻れる「ヨルノシルベの物語」

## 表側

**USER DIRECTION / CURRENT DIRECTION**

プレイヤーは夜の中でユイたちを動かし、大量のカゲモノをほどき、記憶片を拾い、灯具を育て、ビルドを作り、朝まで残る。

まず楽しいのはゲーム。

```txt
戦う
→ 記憶片を拾う
→ レベルアップ
→ 灯具 / 持ち物 / 忘れ物を組み合わせる
→ 黒耀化や灯合わせを使う
→ ボスを越える
→ 夜明け
→ 強化 / 解放 / 次の挑戦
```

物語はこの流れを止めない。

## その裏で起きていること

**USER DIRECTION**

遊ぶほど、少しずつ以下が増えていく。

- 人物の何気ない会話
- 呼び方の変化
- 日常回
- 星獣の反応
- 黒耀化の記録
- カゲモノの情報
- 忘れ物に残った持ち主の気配
- 夜の観測記録
- 説明のつかない小物や挙動

読まない人は、

> 「パラメータ上がった。新しいの開いた。ラッキー」

でいい。

好きになってくれた人は、いくらでも深く読める。

## 最後に残したい感情

**USER DIRECTION**

ヨルノシルベは正史を**ハッピーエンド**にする。

悲しいこと、喧嘩、別れ、一時的な犠牲、取り戻せない時間があってもよい。

ただし、最後に「全部失った」「死んだから美しい」にはしない。

夜そのものが、夢・仮想・記憶・共有精神空間のような非現実レイヤーである可能性を持たせ、ゲームオーバーや夜での消失を永久死の意味に直結させない。

泣いたあとに、ちゃんと朝へ帰る。

# 2. 物語の温度

ヨルノシルベの景色は暗い。

でも、人間まで全員暗くする必要はない。

むしろ、暗い背景の中に普通の人間の生活があるから温かい。

```txt
暗い人もいる
ネガティブな人もいる
明るい人もいる
ギャルもいる
お嬢様もいる
子どももいる
渋い大人もいる
ふっくらした人もいる
よく喋る人も無口な人もいる
```

**USER DIRECTION:** 全員が同じ方向へ性格矯正されるのではなく、デジモンの子どもたちのように、それぞれ違う弱さを持ち、それぞれの形で成長する。

例:

- ネガティブな人 → ネガティブなまま誰かを頼れる
- 明るい人 → 明るいまま「自分もつらい」と言える
- 無口な人 → 無口なまま大切な時に名前を呼べる
- 守る人 → 守られることも受け入れられる
- 正解を探す人 → 正解がなくても誰かと選べる

成長しても別人にしない。

# 3. 主役級の感情軸

## ユイ

Character Book上の中心人物。

忘れ物、灯り、持ち主、名前、朝をつなぐプレイヤーの視点。

主人公らしさは「最強だから」ではなく、暗い夜でも小さな灯りを持って前へ進めること。

星獣は獅子座の子獅子。

## ユイ × アサ

**USER DIRECTION:** ナルトとサスケのように、片方がもう片方の付属物にならない「二人とも物語の主体」である主役級バディ。

コピーはしない。

狙うのは:

- 考え方が違う
- だからぶつかる
- 相手がいないと成立しない部分がある
- 一度仲良くなったら終わりではない
- 成長しても完全に同じ思想にはならない
- 最後は違いを理解したまま一緒に進める

**USER DIRECTION:** 恋愛にはしない。

## リツ × コヨリ

兄妹。

**USER DIRECTION:** エドとアルのように、兄が一方的に守るだけではなく、互いに互いを救える強さを持たせたい。

星獣も、二頭の猟犬として同じ「りょうけん座」を共有する。

## ユイ × クロオリ

「返したい」側と「隠して守りたい」側。

どちらかを単純な悪にしない。

敵対していた相手が、実は一番「壊れる危険」を理解していた、という再解釈を入れられる関係。

## ユイ × トモリ

同じ獅子座を共有。

**OPEN QUESTION:**

- 親族なのか
- 遠い血縁なのか
- 同じ火の系譜なのか
- 継承なのか
- 同じ記憶火から分かれたのか

答えはまだ決めない。

星獣の似た反応だけ先に見せ、後から意味を持たせられる。

# 4. Main Mystery / Character Mystery / Series Mystery

物語の謎は一つの箱に全部入れない。

## MAIN MYSTERY

ゲーム全体を引っ張る世界側の謎。

候補:

- この「夜」は何なのか
- 黒インクとは何なのか
- なぜ朝が必要なのか
- なぜ同じ夜へ何度も挑めるのか
- 星獣は何を知っているのか
- 誰がこの仕組みを作ったのか

## CHARACTER MYSTERY

その人物を好きになるほど見える個人の謎。

例:

- なぜトモリはユイの灯りに近いのか
- クロオリは何を開かせたくないのか
- アサはなぜ「名前」に執着するのか
- ナギは何を閉じたのか
- ゲンが覚えている古い道はどこへ続くのか

本編をクリアするために全Character Mysteryを解かせない。

本人は救われても、過去の全貌は分からないことがあってよい。

## SERIES MYSTERY

1作目の感情決着より一段上にある謎。

1で全部答えなくてよい。

ただし、続編のために1の中心感情を未解決にしない。

```txt
1作 = ちゃんと終わる
シリーズ = 世界の前提がまだ全部は分からない
```

# 5. 伏線の考え方

**USER DIRECTION:** ヤバタニエンのように、初見では意味が分からない配置・小物・人物行動が、後から別の意味に見える伏線が欲しい。

コピーするのは固有内容ではなく構造。

## 好きな伏線の順番

```txt
最初: ただの小物 / 変な行動に見える
↓
途中: 少し意味があると分かる
↓
人物を知る: 別の意味に見える
↓
本編回収: 「そういうことだったのか」
↓
続編: さらに別の意味があったと分かることもある
```

### 三重意味を持てる小物

強い小物は、できれば三段階で意味が変わる。

1. 初見の意味
2. 1作目で回収した意味
3. シリーズ後に再解釈される意味

候補:

- 名札
- 箱
- 切符
- ランタン
- 未配達の封筒
- 折り方の違う紙
- 見覚えのない綴じ糸
- 空白のカード
- 毎年同じ日付の手紙
- 半分だけ残るもの

# 6. Story Engine — かなり強いがまだ真相LOCKしない案

**HIGH-VALUE CANDIDATE**

過去設計と現在のGameplay-first思想を非常に綺麗につなげられる案。

> 悲しい出来事そのものが消えるのではない。  
> 人がその出来事へ与えた「間違った意味」が黒インクによって固定される。  
> ユイたちは出来事を書き換えるのではなく、その固定をほどく。

これが採用された場合、ゲームの普通の操作が後から物語になる。

| 普通に遊んでいる時 | 後から見える意味候補 |
| --- | --- |
| 敵を倒す | 固定されたものを少しほどく |
| 記憶片を拾う | 固定から剥がれた意味片を拾う |
| レベルアップ | その夜だけ扱える接続 / 読み方が増える |
| ビルドを変える | 同じ夜を別の読み方で読む |
| 夜明け | その夜で得た一部を確定する |
| Game Over | その読み方では朝へ届かなかった |
| Retry | 未確定の夜を別の読み順で開く |
| 永続解放 | 一度確定した経験が次の夜にも残る |

この構造の良いところは、物語を読まないプレイヤーには普通のヴァンサバ系システムとして機能し、好きになったプレイヤーだけ後から「ゲームシステムそのものが伏線だった」と気づけること。

ただし、**これはまだ最終世界真相ではない。**

---

# 7. Game Over / Retry

**USER DIRECTION + HIGH-VALUE EXISTING DESIGN**

ゲームオーバーを死亡として扱わない。

夜は現実世界そのものではなく、夢 / 仮想 / 記憶 / 共有精神空間のような性質を持てる。

候補となる理解:

```txt
Game Over
= この読み方では朝まで残れなかった

Retry
= 同じ現実時間を巻き戻すのではなく、未確定の夜を別buildで読み直す
```

その場復活も「死者蘇生」ではなく、ランタンの残り火、しおり、折り目などによって夜の接続をもう少し保つ、と説明できる。

ここはリトルバスターズ的な「現実とは少し違う場所だから可能な犠牲・別れ・再挑戦」と相性が良い。

ただし具体的な夜の正体は未確定。

# 8. ハッピーエンド

**USER DIRECTION — 強い方向**

正史はハッピーエンドのみ。

## ハッピーエンド = 全部元通り、ではない

- 過去は消えない
- 傷ついた事実も消えない
- 年月を戻さない
- 喧嘩したこともなかったことにしない

それでも、

- 誤解がほどける
- 大切な人を選び直せる
- 言えなかったことを言える
- 誰かの助けを受けられる
- 朝へ戻れる
- 日常が続く

という救いを作る。

## 犠牲

犠牲は使ってよい。

ただし「死ねば感動」という使い方にしない。

候補:

- 夜側に一時的に残る
- 自分の大切な記憶を一度手放す
- 力を失う
- 一緒にいられなくなると思わせる
- 星獣との接続が一時途切れる
- 誰かを朝へ送るため、その場には残れない

最終的には救いを作れる。

# 9. 泣きの作り方

**USER DIRECTION:** CLANNADのように、キャラを好きになった後に効く泣きが欲しい。

泣きの原料は「死亡」より**日常**。

## 先に積むもの

- 一緒に食べる
- 名前の呼び方
- 敬語
- くだらない会話
- 掃除
- 雨宿り
- 星獣と遊ぶ
- 喧嘩した次の日
- 寝坊
- 誰がどこへ座るか
- 誰が料理を失敗するか
- いつも直してくれる物
- いつも渡してくれる物

## 後半で効かせる

例えば、序盤に毎回していた行動を、終盤だけしない。

```txt
いつも名前を書いていたアサが書けない
いつも直していたトモリが工具を置く
いつも寝坊するネムが誰より先に待っている
いつも皆に食べ物を分けるハナへ、初めて皆が食べ物を渡す
無口な人が初めて名前を呼ぶ
```

それだけで、プレイヤーが積み重ねを覚えていれば泣ける。

泣いたあとには救う。

# 10. 日常回

日常回は「本編の休憩」だけではない。

キャラを好きになる時間であり、終盤の感情を作る下地であり、伏線を最も自然に置ける場所。

## 日常の種類

- 明るい回
- ギャグ寄り
- 静かな回
- 気まずい回
- ネガティブな回
- 喧嘩中
- 仲直りしないまま終わる回
- 星獣中心回
- 食事
- 夜更かし
- 雨
- 片付け
- 旅支度
- 道具の修理

「暗いゲームだから会話まで毎回重い」は避ける。

一方、「毎回みんな仲良く明るい」も避ける。

人間の生活を自然に置く。

# 11. Bondが物語を運ぶ方法

Bondはノベルを読むためのポイントではない。

まずMain Gameで仲間をSupportとして呼ぶ。

```txt
一緒に戦う
↓
連携が育つ
↓
Gameplay上強くなる
↓
同時に関係の見え方も変わる
```

その副作用として:

- 呼び方
- 敬語
- 戦闘中の掛け声
- リザルト
- 日常会
- 本音
- 個人の謎

が変わる。

大事なのは、「情報を読むと強くなる」のではなく、**一緒に遊んだから強くなり、その結果として情報も読める**こと。

# 12. 黒耀化と人物ドラマ

黒耀化は闇落ちではない。

本人の長所・願い・守り方が過剰になった状態。

```txt
優しさ → 守りすぎる
責任感 → 全部一人で抱える
観察力 → 全部見なければならない
保存する力 → 何も手放せない
名前を残す力 → 名前を付ければ全部救えると思う
```

強い。

でも危うい。

その人の性格を一番よく見せられる戦闘システムでもある。

共通名は黒耀化。
ユイの黒灯化のように、各キャラが固有の呼称を持つ方向がある。

各人物の最終呼称は、人名・モチーフが固まるたびにNaming Reviewする。

# 13. 情報を読みたい人のための「夜の観測記録」

**USER DIRECTION:** Kingdom Heartsのアンセムレポートのように、本編だけでも遊べるが、読むと世界の解像度が上がる記録群が欲しい。

コピーはしない。

ヨルノシルベでは仮称:

- 夜の観測記録
- 夜明け報告
- 観測紙片

など。

## 役割

Main Story:

> 何が起きたか分かる。

> その人がどう感じていたか分かる。

観測記録:

> 世界の説明に「本当にそうか？」という穴が見える。

全部読むと、次回作のSeedへ早く気づける。

読まなくてもハッピーエンドへ行ける。

# 14. Clear Getter / 夜明け星図と物語

達成盤は物語を読むための義務ではない。

Main Gameの遊び方を増やすシステム。

```txt
特定キャラでクリア
黒耀化なしでクリア
特定Supportと夜明け
特定灯具を最大まで育てる
隠し条件を満たす
```

達成すると:

1. Gameplay報酬
2. そのついでに情報が追加

の順。

Gameplay報酬候補:

- 永続強化
- 灯具
- 進化
- Support
- Pair Trait
- reroll
- 新条件
- cosmetic

情報側:

- Character record
- 観測記録
- 忘れ物の背景
- 小さな会話
- 伏線

クリアゲッターを埋めるのが楽しい人は埋める。
物語を読む人はそこから読む。
戦闘だけしたい人も損をしない。

# 15. 続編 — ヨルノシルベ2へ

**USER DIRECTION:** 2を作れるだけの余白 / cliffhangerは欲しい。

ただし、1を途中で終わらせない。

## 良い終わり方

```txt
中心人物は救われた
仲間は朝へ戻れた
1で扱った事件は終わった
↓
でも最後に、小さな違和感が残る
```

候補:

- ユイたちのものではない折り目
- 知らない綴じ糸
- 誰の星座にも属さない星獣
- 現実側に存在するはずのない紙片
- 届いていないはずなのに消印だけある手紙

「黒幕が笑う」「TO BE CONTINUED」は避ける。

理想は、2を遊んだ後に1の最後を見直して、

> 「あれ、最初からこれ出てたのか」

となること。

# 16. まだ決めない大きな答え

**OPEN QUESTIONS:**

- 夜の正体は夢なのか

- ヨルノシルベ2の中心テーマ

伏線を置く時は、将来どの答えを選んでも破綻しにくい形にする。

# 17. この本の使い方

物語の相談をされた時、最初からlegacyを検索しない。

```txt
docs/CANON.md
↓
docs/STORY-BOOK.md
↓
必要なら docs/STORY.md / docs/STORY-ENGINE.md
↓
人物なら character-book-v2.md
↓
アイデアの出所・未確定案なら IDEA-BOOK.md
```

この本は「答えを全部固定する規則書」ではない。

**今まで何を大事にしてきたかを、君とAIが同じ作品として思い出すための本。**

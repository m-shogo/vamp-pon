# Loading Text Presentation Patterns

Vamp Pon / ヴァンサバ改のロード画面・記録室・朝明演出における、名言・格言・語句・キャラ返信の文字演出仕様。

---

## 1. 目的

ユーザー方針:

```txt
文字の演出はめっちゃオシャレにしたい。
色んなパターンで読ませたい。
名言、原文、訳、キャラ返信をただ表示するだけでは弱い。
```

この資料の目的:

```txt
ロード文を「読ませる演出」として設計する。
原文・出典・日本語訳/意味・キャラ返信を、それぞれ別の役割で見せる。
```

---

## 2. 基本思想

```txt
文字は情報ではなく、演出素材。
ただし読めなければ意味がない。
```

優先順位:

```txt
1. 可読性
2. 余韻
3. 世界観
4. 動きの気持ちよさ
5. 知識欲
```

NG:

```txt
読めないほど揺らす
常に派手にする
毎回同じフェードだけ
全部の文を同じ演出で出す
文字演出がゲーム開始を邪魔しすぎる
```

---

## 3. 表示階層

ロード文は基本的に4層。

```txt
1. Original / 原文
2. Source / 出典
3. Japanese meaning / 日本語訳・意味
4. Character reply / キャラ返信
```

演出も4層で差をつける。

```txt
Original = 異国感・古典感・読めなくても雰囲気
Source = 小さく静かに
Japanese meaning = 一番読みやすく
Character reply = キャラの温度で少し動く
```

# 4. 演出パターン

## 4.1 Ink Bloom / インク滲み

用途:

```txt
古典引用
漢文
日本古典
記録室
シオン系
```

演出:

```txt
文字が薄い墨の点から滲むように現れる。
0.4秒で輪郭が出る。
0.8秒で完全に読める。
最後に紙の繊維に少し沈む。
```

見た目:

```txt
黒ではなく濃紺/墨色。
周囲にごく薄い滲み。
背景は紙片、羊皮紙、薄い和紙。
```

使う文例:

```txt
反者道之動。
— 道徳経 第四十章
```

注意:

```txt
滲みは装飾であり、文字の輪郭は必ず残す。
```

---

## 4.2 Lantern Reveal / ランタン照らし

用途:

```txt
ユイ系
帰り道
夜から朝へ
短い名言
```

演出:

```txt
画面左下または中央下から小さな光が移動。
光が通った部分だけ文字が読める。
最後に全文がふわっと残る。
```

見た目:

```txt
暖色の光。
文字はクリーム白。
影は濃紺。
星粒が1〜3個だけ。
```

使う文例:

```txt
We grow accustomed to the Dark.
— Emily Dickinson
```

キャラ返信:

```txt
慣れてしまう前に、灯したい。
— ユイ / Yui
```

注意:

```txt
光の移動は速すぎない。
文字を全部読む前に消さない。
```

---

## 4.3 Page Turn / 紙片めくり

用途:

```txt
記録
シオン
本・古典
閑話休題系
```

演出:

```txt
小さな紙片が一枚めくれる。
原文が先に出る。
少し遅れて日本語訳が下に出る。
最後にキャラ返信が余白に手書きメモのように出る。
```

見た目:

```txt
薄い紙。
端が少し破れている。
文字は整った明朝系。
返信だけ少し柔らかい手書き風。
```

使う文例:

```txt
閑話休題

それはさておき、本題に戻ること。

本題に戻る前に、忘れ物をひとつ拾ってもいい？
— ユイ / Yui
```

---

## 4.4 Star Pin / 星標ピン留め

用途:

```txt
ナギ
星
方角
地図
インド/東アジア系の道の言葉
```

演出:

```txt
小さな星が文字の端にピンとして刺さる。
ピンが刺さった場所から罫線のように文字が整列する。
出典は地図の注釈のように表示。
```

見た目:

```txt
地図紙。
細い線。
小さい星印。
淡い青白い光。
```

使う文例:

```txt
反者道之動。
— 道徳経 第四十章

戻ること、反転することが、道の動きである。

戻る道も、地図に描いていいんだ。
— ナギ / Nagi
```

---

## 4.5 Bell Ripple / 鈴の波紋

用途:

```txt
スズ
リツ
音
沈黙
Bless you / Good night / See you
```

演出:

```txt
文字が音の波紋のように1行ずつ微かに広がる。
波紋は背景にだけ出し、文字は揺らしすぎない。
キャラ返信の前に小さな鈴音風の光点が落ちる。
```

見た目:

```txt
透明な円形波紋。
鈴色の小さな点。
背景は暗い青。
```

使う文例:

```txt
Bless you.
— Common expression

くしゃみをした人へかける、ちいさな祈りの言葉。

鈴がくしゃみしたら、きっと謝ると思う。
— スズ / Suzu
```

---

## 4.6 Thread Stitch / 縫い目表示

用途:

```txt
ヒナタ
トモリ
修理
不完全
朝明
```

演出:

```txt
文字の下に細い縫い目が走る。
縫い目に沿って日本語訳が出る。
欠けた文字が最後に一針で読める形になる。
```

見た目:

```txt
糸の細い点線。
朝色の薄い光。
破れた紙の端。
```

使う文例:

```txt
すべて何も皆事のととのほりたるはあしき事なり。
— 徒然草

何もかも完全に整っているのは、かえってよくない。

朝は、終わりじゃなくて縫い目かもしれない。
— ヒナタ / Hinata
```

---

## 4.7 Water Memory / 水面記憶

用途:

```txt
ミチル
川
無常
泡沫
記憶
```

演出:

```txt
原文が水面に一瞬反射する。
日本語訳は水面が落ち着いてから読める。
キャラ返信だけ、最後に小さな水滴のように落ちる。
```

見た目:

```txt
暗い水面。
青灰色。
波紋は控えめ。
```

使う文例:

```txt
行く川のながれは絶えずして、しかももとの水にあらず。
— 方丈記

川の流れは絶えないが、そこにある水は前と同じではない。

流したかったものだけ、残るんだね。
— ミチル / Michiru
```

---

## 4.8 Black Glitch / 黒耀ノイズ

用途:

```txt
黒耀
アサ
ハク
重い言葉
執着
手放せないもの
```

演出:

```txt
文字の一部が黒く欠ける。
0.2秒だけ読めないノイズ。
すぐに戻る。
キャラ返信が出る時だけ黒い欠けが小さく剥がれる。
```

見た目:

```txt
黒インクの欠け。
紫黒の粒子。
赤は使いすぎない。
```

使う文例:

```txt
tasmād asaktaḥ satataṁ kāryaṁ karma samācara
— Bhagavad Gita 3.19

だから、執着せず、いつもなすべき行いをせよ。

拾うけど、全部は持って帰れないんだね。
— ユイ / Yui
```

注意:

```txt
黒耀ノイズは読めなくする演出ではない。
読める前提で、危うさだけを足す。
```

---

## 4.9 Postcard Stamp / 手紙スタンプ

用途:

```txt
セナ
届け物
Goodbye / See you / Take care
ヨーロッパ/港/カリブ系
```

演出:

```txt
出典が消印のように押される。
原文は手紙本文。
日本語訳は追伸。
キャラ返信は小さな宛名欄に出る。
```

見た目:

```txt
封筒紙。
消印。
薄い赤茶/インク青。
```

使う文例:

```txt
Goodbye.
— Common expression

かつては、祈りに近かった別れの言葉。

別れに祈りが入ってるなら、運べる気がする。
— セナ / Sena
```

---

## 4.10 Curtain Whisper / 幕間の囁き

用途:

```txt
ユラ
舞台
閑話休題
Break a leg
パロディ会話
```

演出:

```txt
画面左右に薄い幕影。
英語フレーズが舞台台詞のように出る。
日本語訳が字幕のように下へ出る。
キャラ返信は少し遅れて、照れたように小さく出る。
```

見た目:

```txt
暗い幕。
薄いスポットライト。
文字は白すぎずクリーム。
```

使う文例:

```txt
Break a leg.
— English idiom

うまくいきますように、を少し変に言う言葉。

やめて。下手に踊るにも両足いる。
— ユラ / Yura
```

# 7. 読ませる時間

最低表示時間:

```txt
Original only: 3.2秒
Original + 日本語訳: 4.6秒
Original + 日本語訳 + Character reply: 6.2秒
長文/漢文/古典: 6.8秒まで許可
朝明ポエム: 6.5〜8.0秒
```

スキップ:

```txt
初見: 2.4秒まで不可
既読: 1.2秒後可
キャラ返信つき初見: 3.0秒まで不可
```

重要:

```txt
演出時間ではなく、読める時間を確保する。
演出が終わってから最低1.5秒は完全に読める状態を保つ。
```

# 8. 実装データ案

```ts
export type TextPresentationPattern =
  | 'ink-bloom'
  | 'lantern-reveal'
  | 'page-turn'
  | 'star-pin'
  | 'bell-ripple'
  | 'thread-stitch'
  | 'water-memory'
  | 'black-glitch'
  | 'postcard-stamp'
  | 'curtain-whisper';

export type LoadingTextPresentation = {
  id: string;
  quoteId: string;
  pattern: TextPresentationPattern;
  characterAccent?: string;
  minVisibleMs: number;
  skipLockMs: number;
  readableHoldMs: number;
};
```

---

# 9. 実装ハンドオフ

Claude Code / Codex に渡す時の要件:

```txt
1. LoadingTextRenderer を作る。
2. quote.kind / quote.region / selectedCharacterId / reply.characterId から pattern を選ぶ。
3. Original, Source, Meaning, Reply を段階表示する。
4. 演出完了後も readableHoldMs だけ全文を保持する。
5. 390x844 のスマホ縦画面で読める余白を守る。
6. 文字サイズは本文18〜22px、出典10〜12px、返信16〜20px目安。
7. 黒耀ノイズや水面演出は、文字の可読性を壊さない。
8. 既読/初見でスキップ可能時間を変える。
9. 同じ演出が3回以上連続しないようにする。
```

---

# 10. 最終方針

```txt
文字演出は、おしゃれである前に読めること。
ただ表示するのではなく、言葉の種類・地域・キャラに合わせて出し方を変える。
```

理想体験:

```txt
原文の雰囲気に惹かれる。
日本語訳で意味が分かる。
キャラ返信で価値観が見える。
文字演出で、その言葉がVamp Ponの世界に落ちてくる。
```

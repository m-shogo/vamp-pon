# Expansion Philosophy and Negative Space Rules

## 目的

Vamp Ponを、アプリやシリーズが増えても破綻しないIP構造にする。

重要なのは、キャラクター数を増やすことではない。

```txt
1つの強い核で突き進みながら、増やせる余白を残すこと。
```

---

# 1. 結論

Vamp Ponは、複数アイデアを足して大きくするゲームではない。

```txt
1アイデアで突き進む。
```

その1アイデアはこれ。

```txt
消えたと思っていたものは、本当は小さな形で残っていた。
それを拾って、朝まで残る。
```

この核から外れない。

---

# 2. 増やしてよいもの

核を変えずに増やしてよい。

```txt
キャラ
ステージ
敵
武器
欠片の種類
記憶断片
別テーマ
別アプリ
コラボイベント
```

ただし、すべて同じ問いに戻す。

```txt
これは「消えたと思ったものが残っていた」と分かる体験に貢献するか？
```

---

# 3. 増やしてはいけないもの

以下は、増やすと破綻する。

```txt
説明量
固有名詞だけの設定
世界を救う使命
複雑な年表
真相の直接説明
重すぎる暗さ
操作の複雑さ
```

Vamp Ponは、設定資料を読むゲームではない。

```txt
拾う、強くなる、朝になる。
```

この気持ちよさを守る。

---

# 4. 余白の定義

余白とは、何も考えていないことではない。

```txt
答えを持っているが、全部は見せないこと。
```

良い余白:

```txt
誰が書いたか分からない筆跡
片方だけ残った切符
直されたランタン
消し跡のある名前
何度も貼り直されたラベル
```

悪い余白:

```txt
設定が未定
矛盾を放置
意味がない謎
回収する気のない伏線
```

---

# 5. シリーズ展開の型

Vamp Ponの型。

```txt
夜になる
何かが読めなくなる
欠片を拾う
一時的に強くなる
朝になる
力はほどける
意味は残る
```

この型を守れば、別アプリにもできる。

例:

```txt
記憶の欠片
夢の欠片
音の欠片
手紙の欠片
写真の欠片
星の欠片
```

変えてよいのは素材。

変えてはいけないのは感情。

---

# 6. アプリが増える時のルール

## 変える

```txt
舞台
拾うもの
敵の見た目
キャラの役割
最後に戻る感情
```

## 残す

```txt
縦持ち
自動攻撃
欠片回収
短時間ラン
ポジティブな反転
余白のある断片ストーリー
```

---

# 7. キャラが増える時のルール

人数は目的ではない。

キャラを増やす条件:

```txt
新しい遊び方がある
新しい感情の反転がある
既存キャラとの関係がある
持ち物や武器に意味がある
```

増やさない条件:

```txt
ただ強い
ただかわいい
ただ暗い過去がある
既存キャラの言い換え
```

---

# 8. 1アイデアで突き進むとは

Vamp Ponの核を毎回言い換えない。

悪い:

```txt
今回は記憶、次は世界救済、次は神話、次はバトル学園
```

良い:

```txt
今回は記憶
次は夢
次は音
でも全部「残っていた証拠を拾う」話
```

---

# 9. カイロソフト的に増やす考え方

カイロソフト的に強いのは、毎回まったく別物にすることではない。

```txt
分かりやすい型
少し違うテーマ
遊びの気持ちよさ
繰り返し遊べる小さな発見
```

Vamp Ponも同じ。

```txt
分かる型を持つ
でもテーマごとに違う余韻が残る
```

---

# 10. 暗いIP/明るいIPとの相性

## 暗いIP

相性はよい。

ただし、暗さをそのまま入れない。

```txt
呪い -> 読めなくなった記憶
怨念 -> 届かなかった言葉
戦い -> 影を払う行為
悲しみ -> 残っていた証拠
```

## 明るいIP

こちらも可能。

```txt
友達
落とし物
約束
プレゼント
思い出
帰り道
```

明るいIPの場合は、黒インクを軽くし、欠片回収の温かさを強める。

---

# 11. 破綻しないための禁止事項

```txt
シリーズごとに別の真相を足しすぎる
キャラを増やして関係性を回収しない
全部の謎を説明する
暗くしすぎる
明るくしすぎて芯を失う
```

---

# 12. 最重要

Vamp Ponは、設定を広げるIPではなく、感情を広げるIP。

```txt
消えたと思っていたものが、残っていた。
```

この1アイデアを守る。

余白を残す。

増やすのは、説明ではなく、拾ったあとに感じる温かさ。

# 1. 深みを作る共通原則

## A. 長所と欠点を別々に作らない

魅力的な人物は「優しいけど欠点は短気」のように無関係な特徴を足すより、**同じ性質が状況によって長所にも欠点にもなる**方が強い。

```txt
長所
↓
恐怖 / 焦り / 過去
↓
過剰化
↓
弱点 / 黒耀化
↓
成長後は長所を捨てず、扱い方だけ変わる
```

ヨルノシルベではこれを全員の黒耀化と接続する。

## B. 対立人物には別の正解を持たせる

悪い人だから対立する、では弱い。

- 戻す / 閉じる
- 名前を出す / 隠して守る
- 封じる / 自分が盾になる
- 選んで歩く / 測って正解を探す
- 修復する / 余白を残す

のように、**同じ問いへの違う答え**を持たせる。

## C. 共有の傷があっても、一方向の守護関係にしない

兄妹、相棒、師弟、恋人でも:

> AがBを守るだけ

にしない。

途中で役割が逆転し、Aにしかできないこと / Bにしかできないことを両方持たせる。

## D. 周回で関係が蓄積する

一度見た会話を読むためだけに周回させない。

Gameplayで:

- 一緒に戦った
- 助けられた
- 黒耀化を止めた
- 特定Pair Traitを成立させた
- 同じStageを越えた

という履歴が、次の日常 / 呼び方 / Assist判断へ少しずつ残る。

## E. 「過去の因縁」だけで全員を繋がない

関係は4種類を混ぜる。

1. 直接関係 — 兄妹 / 旧知 / 師弟 / 恋愛
2. 物・言葉の継承 — ランタン / 手紙 / 本 / 切符 / 地図
3. 思想の鏡 — Core5 × Shadow5
4. **夜で初めて出会い、プレイヤーが見ている時間の中で仲間になる**

4を最重要にする。

# 3. Core 5 — 主人公側

## 01. ユイ — 「忘れない」と「大切にする」を混同している主人公

### 表面の魅力 — CURRENT

- 小さなランタンを持つ
- 忘れ物を放っておけない
- 人の名前や持ち物を返したがる
- 怖くても前へ出る
- 子獅子の星獣

### Core contradiction — CURRENT DIRECTION

長所:

> 誰も忘れたくない。

弱点:

> **忘れることを、裏切りだと思い始める。**

ユイの優しさそのものが、最後には「全部私が覚えていなければ」に歪める。

### Character Mystery — HIGH-VALUE

クロオリが隠しているものをユイは「奪われた記憶」だと思う。

しかし過去のユイ自身が:

> 今は開けないで。私が忘れても。

と預けていた可能性を保持する。

これを採用すると、クロオリの敵対行動が「約束を守っていた」に反転する。

### Time-layer hook — HIGH-VALUE

ユイのランタンはユイの時代より古い。

トモリが別時代で修理した跡があるCandidate。

ユイとトモリの同じ獅子は血縁だけでなく、**同じ灯りを継いだ者同士の共鳴**でも説明できる。

### 日常

- 落とし物を見ると会話中でも拾う
- 誰の物か分からないと机の真ん中へ置く
- ランタンの近くへ手をかざす癖
- 他人の忘れ物は覚えているのに、自分の物は時々忘れる

この最後の癖は笑いにも伏線にもなる。

### 黒耀化

`黒灯化`。

> 誰も忘れたくない
> → 全部自分が呼び戻す
> → 他人の「忘れたい / 今は開けたくない」まで無視する

圧倒的な回収 / 呼び戻し能力を持つが、周囲の記憶片まで強制的に引き寄せる。

### 成長

> 覚えていることだけが大切にすることではない。

忘却を肯定するのではなく、**本人が何を残し、何を手放すかを一緒に選ぶ**主人公になる。

Gameplayでは強制吸引型から、対象選択 / Allyとの共同回収へ成長させられる。

## 02. アサ — 名前を返す人

### 表面の魅力

- 行動が速い
- 先に危険へ入る
- 名札 / 紙片
- 人の名前を一度聞くと小さく復唱する
- 言葉が率直

### Core contradiction

長所:

> 名前を呼べば、その人を「ここにいる」と扱える。

弱点:

> **名前さえ戻せば救える、と急ぎすぎる。**

### Life seed — HIGH-VALUE CANDIDATE

アサには「呼びたかった名前を、正しく呼べなかった」過去を持たせられる。

死亡に限定しない。

- 本名を知らなかった
- 呼び名が変わっていた
- 記録上の名前と本人が望む名前が違った
- 再会時にはもう別の場所へ行っていた

この経験から「名前を失わせたくない」が強くなった。

### 対立 — カスミ

アサ:

> 名前を消すな。

カスミ:

> 名前を出すことで危険になる人もいる。

最終的には:

> **名前を返すのではなく、本人が名乗れる場所を作る。**

へ進む。

### 日常

- カップや包みに皆の名前を書く
- 仲良くなると正式名より本人が好む呼び方を使う
- 怒っている時ほどフルネームを使う
- 実は字が少し丸い

### 黒耀化

名前を付けたものを強制的に定義 / 固定する。

敵には強烈なmarkになる一方、Allyまで「あなたはこういう人」と決めつける危険が出る。

### 成長後Gameplay

Markを一方的に刻む → Ally本人が選んだmark / targetへ合わせられる。

## 03. ナギ — 閉じることで守る人

### 表面

- 月箱 / 鍵
- 静か
- 大切な物を二度確認してしまう
- 小蟹の星獣
- 無理に会話へ割り込まない

### Core contradiction

長所:

> 危険なものを、危険なまま外へ出さない。

弱点:

> **危険なら全部閉じればいい、になりやすい。**

### Life seed

過去に誰かのためを思って情報 / 物 / 選択肢を閉じた結果、相手から:

> 私のために決めないで。

と言われた経験があるCandidate。

本人は守ったつもりだった。

### 対立 — カナメ

ナギ:

> 危険そのものを閉じればいい。

カナメ:

> 仲間と危険の間へ立てばいい。

互いに相手を自己犠牲 / 過保護だと思う。

### 日常

- 箱や袋の口をきちんと閉める
- 人の物には勝手に触らない
- 「開けていい？」を必ず聞く
- 仲良くなるほど、この一言の重みが変わる

### 黒耀化

Area / enemy / object / Allyを強力に封じる。

強すぎる安全装置だが、味方の選択肢まで消す。

### 成長

> 閉じることではなく、**開ける時を一緒に決められること**が守ること。

Gameplayでは封印の解除をAlly triggerへ委ねられる。

## 04. ミチル — 帰り道を読む人

### 表面

- 地図 / コンパス
- 寄り道好き
- 曲がり角で一度振り返る
- 小熊
- 明るく移動を促す

### Core contradiction

長所:

> 迷っている人に道を示せる。

弱点:

> **正しい道が一つあると思い込みやすい。**

### Life seed

正しいと思った道へ誰かを連れていったが、その人が本当に行きたかった場所とは違った経験。

「道を間違えた」のではなく、**目的地を聞かなかった**ことが傷になる。

### 年代差 — ゲン

ゲン:

> ここに道がある。

ミチル:

> 今はないよ。

どちらも正しい。

消えた道 / 新しくできた道を通して、「地図は人より絶対ではない」と学ぶ。

### 対立 — トキ

ミチルは歩いて確かめる。
トキは測って確かめる。

### 日常

- 散歩で必ず寄り道する
- 手書き地図に食べ物の場所を足す
- 道に迷ったことを最初は認めないが、成長後は楽しめる

### 黒耀化

「正解の道」を一つだけ強制表示し、他routeを切り捨てる。

強い速度 / safe path能力だが、Build diversityを狭める。

### 成長

> 道を教える → **一緒に迷って帰れる人になる。**

## 05. トモリ — 直す人

### 表面

- 工具袋
- 修理ランプ
- 煤
- 焼き芋
- 作業ゴーグル
- 煤けた若獅子

### Core contradiction

長所:

> 壊れていても捨てない。

弱点:

> **直せば元通りになると思いたい。**

### Life seed

物は直せても、関係や時間には「元通り」がないと知る出来事があったCandidate。

壊れた物を直すことへ執着するのは、過去に直せなかったものへの反動でもよい。

### ユイとの重要Mystery

別時代のトモリがユイのランタンを修理していたCandidate。

初対面なのに:

> 「その継ぎ方、俺のだ。」

と言える。

本人同士ではなく**物が先に知り合っている**。

### 対立 — ツムギ

トモリ:

> 直せるなら直す。

ツムギ:

> 直しすぎると、壊れた時間まで消える。

### 日常

- 会話しながら椅子や留め具を直す
- 人に頼まれていない小さな故障へ先に気づく
- 自分の道具は意外とボロボロ

### 黒耀化

壊れた状態を強制的に「以前の形」へ戻そうとする。

強力なrestore能力だが、変化や傷跡まで消そうとする危険。

### 成長

> **直らないもののそばにいることも修理屋の仕事。**

Gameplayでは完全restoreだけでなく、傷を残したまま新しいbuffへ変換できる。

# 4. Circle 10 — 大Themeを生活で証明する人たち

## 06. セン — 教える人

**魅力:** 少し理屈っぽいが面倒見のいい先生。石や紙だけで即席ゲームを作れる。

**長所 / 弱点:** 分かる形へ整理する力 → 「説明できないなら理解していない」と思いすぎる。

**Life seed:** 昔、誰かへ正しい説明を急ぐあまり「何が怖いか」を聞かなかった経験。

**年代差:** センが書いた無記名の教育ノートが後世のシロへ残るCandidate。名前が消えても教えは届く。

**黒耀化:** 世界中へ線と注釈を引き、全員を「正しい手順」へ固定する。

**成長:** 教える人 → **質問の仕方を教え、若い相手からも教わる人**。

**日常:** 説明時に空中へ指で線を引く。子ども相手だけ妙にゲームが上手い。

---

## 07. リツ — 半分にする兄

**魅力:** 食べ物も荷物も先に人数を数える。頼れるが少し世話焼き。

**長所 / 弱点:** 分ける / 守る → 自分の取り分を消し、コヨリの危険まで代わりに引き受ける。

**Life seed:** 兄妹で不足を分け合ってきた記憶。具体的な災害 / 貧困へ今すぐ固定しない。

**重要:** 「兄が妹を守る」だけにしない。コヨリの判断力に何度も救われる。

**黒耀化:** Damage / resource / threatを全部自分へ半分以上引き取る。強いが自己破壊的。

**成長:** 半分にしてあげる → **相手が自分の分を選べるよう任せる**。

**日常:** 最後の一個を自然にコヨリへ渡す。成長後、コヨリに半分返されて普通に受け取れる。

---

## 08. コヨリ — 小さいけれど「残す」側

**魅力:** 名前を書く。小さい物を大切にする。子どもだからこそ大人が見過ごす違和感を素直に口にする。

**長所 / 弱点:** 人を覚えていたい → 消える前に全員を名前で繋ぎ止めたくなる。

**Life seed:** 大人に「まだ分からなくていい」と言われ続けた経験。だから自分で名前を付けて理解しようとする。

**黒耀化:** 紙縒り / 名前の糸で全員を繋ぎ、離れられなくする。

**成長:** 守られる子 → **小さいからこそ言えること / 見えることがある仲間**。

**リツとの逆転:** 高Bondではコヨリがリツの暴走guardを止める役になる。

**日常:** シロップで名前を書く、星獣二頭が兄妹より先に仲直りする。

---

## 09. ゲン — 古い道を知る渋い年長者

**魅力:** 古い帽子、コンパス、大熊。何でも知っているように見えるが、知らない新しい物には普通に戸惑う。

**長所 / 弱点:** 経験 → 「昔はこうだった」が正解になりやすい。

**年代差:** 今は消えた道 / 駅 /店を当然のように知っている。説明せず小物で時代差を見せる。

**Connection:** ミチルとold route / new route。トバリの駅を「開業した頃」と「閉じる頃」の別視点で知っているCandidateも持てるが、直接旧知にはしない。

**黒耀化:** 古い道だけを夜へ上書きする。安全だが現在のrouteを消す。

**成長:** 教える年長者 → **若い人の新しい道を面白がれる年長者**。

**日常:** スマートな新道具の使い方で若者に教わると少し悔しそう。

---

## 10. ハナ — 保存する人

**魅力:** ふっくらした年長女性。押し花、布包み、静かな世話焼き。体型を包容力だけの記号にもギャグにも固定しない。

**長所 / 弱点:** 失くさないよう保存する → 保存すれば変化まで止められると思ってしまう。

**Life seed:** 人が残した花 / 小物を長く預かってきた。誰の物か分からない品も「分からないから捨てる」をしない。

**Connection:** ツムギが破れを完全に消さず繕うことへ最初は反対する。

**黒耀化:** Ally / object / fieldを完璧な状態へ「押し花」のように保存。壊れないが動けない。

**成長:** 保存する → **手渡すために残す**。

**日常:** 皆が拾った花をあとでしおりにして返す。自分への贈り物を受け取るのは苦手。

---

## 11. ユウビ — 届ける人

**魅力:** 手紙 / 包み / 小鳩。相手がいなくても宛先を二度確認する。

**長所 / 弱点:** 届ける責任 → 「届ければ正しい」と思いすぎる。

**Character Mystery:** たった一通、意図的に届けなかった手紙があるCandidate。

初見は職務放棄に見える。
後から「届けないことで守った」が成立する可能性。

**Connection:** トバリの旧駅で止まった手紙。クロオリの「預かる」にも近いが、ユウビは最終的に届ける側。

**黒耀化:** 宛先を決めたら何があっても追尾 / 到達する。拒否する権利を消す。

**成長:** 届ける → **受け取れる時に、受け取る意思を確認して届ける**。

**日常:** 皆への小さな伝言まで律儀に配る。口頭で言えばいい内容も紙にする。

---

## 12. マドカ — 見ていた人

**魅力:** 窓、紙飛行機、小鷲。遠くの小さな変化を見つける。

**長所 / 弱点:** 観察力 → 見て理解したことで、行動したつもりになりやすい。

**Life seed:** 何かおかしいと気づいていたが「確信がないから」と声を上げなかった経験。

死亡事故へ固定する必要はない。すれ違い / 失敗 / 誰かの孤立でも十分。

**Connection:** レンは小さい違い、マドカは遠くの出来事。二人で夜の年代混在へ先に迫れる。

**黒耀化:** 全画面情報 / foresightを得るが、自分は観測地点から動けなくなる。

**成長:** 見る → **不完全でも「見た」と伝えて一歩動く**。

**日常:** 誰より先に雨へ気づくのに、自分の傘を忘れる。

---

## 13. シロ — 分からない頁を残す人

**魅力:** 丸メガネ、白いしおり、山猫。静かな分類好き。

**長所 / 弱点:** 分からないものを捨てない → 全部理解 / 分類できるまで進めなくなる。

**Life seed:** 「不明」と書かれた物が雑に捨てられる場面を見て以来、未分類を守るようになったCandidate。

**Connection:** センの無記名ノート。書いた人の名前を知らなくても価値を守っていた。

**黒耀化:** 人 / 敵 / 記憶を細かく分類し、分類外をError扱いする。

**成長:** 分からないを怖がる → **分からないまま大切にできる**。

**日常:** 本を揃えるが、自分の机だけ資料が積み上がる。`未分類`箱を成長の象徴にできる。

---

## 14. トバリ — 出て行ける門を守る人

**魅力:** 切符、改札、番犬。「行ってらっしゃい」と「おかえり」を同じくらい大事にする。

**長所 / 弱点:** 帰路を守る → 誰も出さなければ誰も帰れなくならない、と考えやすい。

**Life seed:** 待っていた人が帰ってこなかった経験。死亡に限定しない。別路線 / 別人生 / 時代変化でもよい。

**Connection:** ユウビの止まった手紙。ゲンの古い駅。将来の不老魔女の「出さなければ別れない」とも強烈に対比できる。

**黒耀化:** 全Gate lock。仲間は安全だがStageを終えられない。

**成長:** 門を閉じて守る → **帰って来られるよう、門を開ける**。

**日常:** 誰かが外へ行くと必ず帰る時間を聞く。高Bondになると聞かずに「待ってる」に変わる。

---

## 15. ネム — 夢を現実へ持ち帰る人

**魅力:** 寝坊、夢日記、小イルカ。会話途中で寝るが夢の細部は異様に覚えている。

**長所 / 弱点:** 想像 / 夢から可能性を見る → 夢の方が安全だと現実を薄くしやすい。

**Time-layer:** 別時代の夜を夢として見てしまうCandidate。

> 「ゲンさんが若かった夢見た。」

が笑い話から年代差伏線へ反転できる。

**重要:** 万能予言者にはしない。夢は断片 / 感情 / 景色だけで、解釈はよく外れる。

**黒耀化:** 夢側を現実へ上書きし、誰も起きなくてよい安全な領域を作る。

**成長:** 夢へ逃げる → **夢で見つけた道を現実で一歩試す**。

**日常:** 眠りながら誰かの会話へ妙に的確な返事をするが、本人は覚えていない。

# 5. Shadow / Rival 5 — 同じ問いへの別回答

## 16. クロオリ — 開けないことで守る人

### 表面

- 黒い折り紙
- カメレオン星獣
- 静か
- 秘密を持つ
- ユイの進行を止める

### Core contradiction

長所:

> 今開けると壊れるものを預かれる。

弱点:

> **開かなければ永遠に壊れない、まで行く。**

### Life seed

過去に「開く時を間違えた」経験を持つCandidate。

その失敗から、本人の許可 / 時機 / 安全性を異常に重視するようになった。

### ユイとのTwist Candidate

ユイ自身から「私が忘れても開けないで」と頼まれていた。

この場合、クロオリは敵ではなく**約束を守りすぎたライバル**になる。

### Time-layer

夜への滞在歴が長いCandidateと相性がよい。

別時代の人から預かったものを、何年 / 何周でも時機まで持てる。

### 黒耀化

街 / 記憶 / 人を完全に折り畳んで安全な状態へ保存する。

誰も傷つかないが、誰も続きへ進めない。

### 成長

> 開く → 閉じるの二択ではなく、**本人が開くまで預かり、開く時には隣にいる**。

## 17. カナメ — 守られるのが苦手な盾

### 表面

- 大柄で柔らかい体格
- 灰狼
- 荷物を自然に持つ
- 風上へ座る
- 餃子の最後の一個を譲る

### Core contradiction

長所:

> 自分が前へ出れば仲間を守れる。

弱点:

> **自分が傷つくことを、守れている証拠だと思い始める。**

### Life seed

昔、自分が誰かに守られたことで生き残った / 助かった経験を持つCandidate。

そのことへの感謝より先に「自分が代わるべきだった」という負い目が残った。

### 対立 — ナギ

カナメは閉じる守りを臆病だと思う。
ナギは自傷前提の守りを乱暴だと思う。

二人とも正しい部分がある。

### 黒耀化

周囲のDamage / debuff / projectileを全部自分へ引き受け巨大な防壁になる。

最強の盾だが、最後は動けなくなる。

### 成長

> 守る = 受ける

から:

> **守る = 任せる / 分担する / 必要な時だけ前へ出る**

へ。

## 18. カスミ — 隠すことを知っている人

### 表面

- 小狐
- 鉛筆 shading
- 共同メモの誤字を黙って直す
- 声を荒げない

### Core contradiction

長所:

> 公開されることで傷つく情報を守れる。

弱点:

> **痕跡がなければ安全、と消しすぎる。**

### Life seed

本人 / 家族 / 誰かの名前や記録が、公になることで困る状況を経験したCandidate。

具体的な社会制度へ早く固定せず、「名前を出すことが常に善ではない」人生経験だけ保持する。

### 対立 — アサ

アサは「名前を返す」。
カスミは「名乗れる日まで隠す」。

### 黒耀化

敵から見えなくするだけでなく、Ally同士の記録 / target / Bond表示まで薄くしてしまう。

### 成長

> 隠す / 出すを本人と決める。

本人が「今は名前を出したい」と言った時、最も強く守れる人物になる。

## 19. トキ — 測ることで世界を信じる人

### 表面

- 星図 / 定規
- 鶴
- 塩むすびの塩加減まで気づく
- 「だいたい」と言われると一度だけ数字を聞く

### Core contradiction

長所:

> 事実を測って判断できる。

弱点:

> **測れないものを存在しない扱いしやすい。**

### Time-layer Mystery

トキの測定こそが「夜は一つの年代ではない」を証明する。

- 星の位置
- 月
- 時計
- 建物の影
- 暦

が同時成立しない。

最初は測定器を疑う。
最後に「世界の前提」が違うと認める。

### 対立 — ミチル

トキ:

> 正しいrouteを測ればいい。

ミチル:

> 歩かないと分からない道がある。

### 黒耀化

全movement / timing / angleを最適解へ固定する。

理論上強いが、偶然や味方のひらめきを殺す。

### 成長

> **測れないものを信じるために、測れるものを丁寧に使う。**

## 20. ツムギ — 終わらせるのが怖い人

### 表面

- 紙 / 糸
- 野兎
- 破れを繕う
- ノートの最後数頁を空ける
- 人の話を急いで結論へしない

### Core contradiction

長所:

> 空白を未来として残せる。

弱点:

> **終わらせなければ失わない、と思って何も完成できなくなる。**

### Life seed

何かを「完成」させた直後に関係 / 場所 /時間が終わった経験を持たせられる。

そのため完成 = 別れ、と無意識に結びついたCandidate。

### 対立 — トモリ

トモリは直して完成へ持っていく。
ツムギは傷跡と余白を残す。

### 黒耀化

場を大量の未完了thread / blank pageで延々継続させ、Boss / Stage自体が終わらなくなる。

### 成長

> 終わらせる = 消す

ではなく:

> **終わったから続きを別の場所へ書ける。**

へ。

# 9. 周回で見せるCharacter Memory

同じ会話を何度も再生するだけにしない。

例:

```txt
初同行
「よろしく」

数run同行
固有の短い掛け声

特定危機を経験
その出来事を覚えた台詞

Bond上昇
呼び方 / 敬語が変わる

黒耀化を救援
次のrunで短い気まずさ / 感謝

日常
戦闘外でその出来事が小さく返る
```

情報は任意閲覧だが、戦闘中の短い変化だけでも「この人たちは一緒に過ごした」と分かるようにする。

# 10. 外部作品から抽出した構造研究

表面設定や固有展開はコピーしない。

## Digimon系から抽出する構造

- 人間の性格と相棒の反応を別々にせず、感情成長を力の変化へ返す
- 対立する仲間同士も、互いを信頼できる瞬間をGameplay /危機で見せる
- 「持っている長所」と「学ばなければならない長所」を同じ人物内で扱う

Reference:
- Toei Animation, Digimon Adventure character pages
- https://www.toei-anim.co.jp/tv/digimon/character/

## NARUTO系から抽出する構造

- ライバルへ主人公と似た傷 / 違う答えを持たせる
- 悪役を生まれつきの悪だけで説明しない
- 師弟 / 環境 /成長で価値観が形成されたことを見せる
- 一度壊れた関係も「同じ思想になる」ではなく、違うまま認め合える

References:
- NARUTO Official, Naruto / Sasuke finale retrospective
- https://naruto-official.com/en/news/01_1355
- Masashi Kishimoto / Mikio Ikemoto interview, 2025
- https://naruto-official.com/en/news/01_2320

- 兄弟 / 家族を一方向の保護関係にしない
- 共通の出来事から別々の責任 /弱さ /能力を作る
- 二人とも物語の主体であることを保つ

Reference:
- VIZ, Fullmetal Alchemist official series page
- https://www.viz.com/fullmetal-alchemist

## Hades系から抽出する構造

- 周回という反復を物語の敵にせず、関係性の蓄積へ使う
- playerが物語へ深く入るかどうかを選べる
- キャラクター側が過去の接触を覚え、同じ場所でも会話が少し変わる

Reference:
- Supergiant Games, Hades FAQ
- https://www.supergiantgames.com/blog/hades-faq/

# 12. 追加設定を作る時のチェック

新しい「深い設定」を思いついた時:

1. 既存の長所と同じ根から出ているか
2. その人だけの人生になっているか
3. 他キャラの役割を奪っていないか
4. 黒耀化へ自然につながるか
5. 成長後Gameplayへ返せるか
6. 日常で小さく先出しできるか
7. 年代差なら説明台詞ではなく小物で示せるか
8. 全員を血縁 /昔からの知人にしていないか
9. 悲劇を増やしただけになっていないか
10. ヨルノシルベで初めて作られる関係を残しているか

> **深み = 過去の量ではなく、同じ人物の性格・日常・戦闘・黒耀化・成長が一つの理由で繋がっていること。**

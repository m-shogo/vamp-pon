# Balance Target Matrix and Acceptance Criteria

## 目的

Vamp Pon の各Prototype/MVPで、何をもって合格とするかを数値で定義する。

これは最終バランスではない。

```txt
初回検証で見るべき目標値
```

として使う。

---

# 1. Prototype 1 Target Matrix

## 目的

```txt
移動・自動攻撃・欠片回収・初レベルアップが不快ではないか確認する。
```

| 指標 | 目標 | NG目安 | 対応 |
|---|---:|---:|---|
| 動かし方理解 | 3秒以内 | 10秒以上 | 入力表示/初期配置調整 |
| 最初の敵撃破 | 10秒以内 | 15秒以上 | 敵HP↓ / 武器damage↑ / CT↓ |
| 欠片回収理解 | 30秒以内 | 分からない | 欠片視認性/吸引調整 |
| 初回Lv2到達 | 60秒以内 | 75秒以上 | XP必要量↓ / 敵spawn↑ |
| 初回被弾 | 早すぎない | 10秒以内 | 敵速度↓ / 初期距離↑ |
| 敵数 | 5〜18体 | 画面埋まりすぎ | spawn/maxAlive調整 |
| FPS体感 | 操作不快なし | 操作不能 | オブジェクト削減 |

## Prototype 1 合格文

```txt
仮素材でも、移動して影を払い、欠片を拾ってレベルアップするのが不快ではない。
```

# 2. Prototype 2 Target Matrix

## 目的

```txt
3択レベルアップ、武器/パッシブ選択、ビルド差が楽しいか確認する。
```

| 指標 | 目標 | NG目安 | 対応 |
|---|---:|---:|---|
| 1分時点Lv | 2〜3 | Lv1 | XP/敵数調整 |
| 3分時点Lv | 5〜7 | Lv4以下 | XPカーブ調整 |
| 5分時点Lv | 8〜11 | Lv6以下 | XP/敵数/吸引調整 |
| 武器取得数 | 2〜4 | 1 | 新武器候補率↑ |
| パッシブ取得数 | 1〜3 | 0 | 新パッシブ候補率↑ |
| 3択理解 | 迷いすぎない | 効果不明 | 文言短縮 |
| 武器差 | 3種以上体感差 | 全部同じ | 挙動差を強化 |
| 5分継続 | 退屈でない | 3分で飽きる | 敵変化/成長強化 |

## Prototype 2 合格文

```txt
5分遊んで、武器選択と成長の差が分かる。
```

# 3. Prototype 3 / MVP Target Matrix

## 目的

```txt
8分MVPとして、カプセル・進化・必殺技・リザルトまで成立するか確認する。
```

| 指標 | 目標 | NG目安 | 対応 |
|---|---:|---:|---|
| 初カプセル | 3:00±15秒 | 3:45以降 | 黒ラベル出現/HP調整 |
| 2回目カプセル | 5:00±15秒 | 出ない | wave調整 |
| 3回目カプセル | 7:00±15秒 | 出ない | wave調整 |
| 到達Lv | 18〜24 | 15以下/28以上 | XPカーブ調整 |
| 敵撃破数 | 550〜850 | 400以下/1000以上 | 敵密度/武器火力調整 |
| 進化数 | 1〜2 | 0が多い | 進化条件/候補調整 |
| 必殺技使用 | 2〜4回 | 0〜1回 | charge短縮/表示強化 |
| クリア率初回 | 0〜30% | 0%固定/80%以上 | 難度調整 |
| 数回後クリア率 | 40〜70% | 20%以下/90%以上 | 難度調整 |
| もう一度感 | YES/条件付きYES | NO | リザルト/成長/テンポ改善 |

## Prototype 3 合格文

```txt
仮素材でも、ユイで8分遊んで、もう一度遊びたい。
```

# 4. Level Up Target

## Prototype 2以降

初期抽選比率。

```txt
所持武器強化: 35%
新武器: 20%
所持パッシブ強化: 25%
新パッシブ: 15%
回復: 5%
```

HP35%以下。

```txt
所持武器強化: 30%
新武器: 15%
所持パッシブ強化: 20%
新パッシブ: 10%
回復: 25%
```

## Acceptance

```txt
3択で毎回意味のある選択が出る
Lv.MAXや枠満了候補が出ない
HP低下時に詰みにくい
```

# 5. Wave Target

## Prototype 3 8分構成

```txt
0:00-1:30 操作/成長
1:30-3:00 速い敵
3:00 黒ラベルの影1
3:00-5:00 硬い敵/回り込み
5:00 黒ラベルの影2
5:00-7:00 群れ
7:00 黒ラベルの影3
7:00-8:00 クライマックス
```

## Acceptance

```txt
3分/5分/7分に山がある
5分以降に圧が上がる
7分以降に終盤感がある
逃げ場が完全になくならない
```

# 6. Smartphone Performance Target

## Prototype 3上限

```txt
maxEnemies: 140
maxPickups: 250
maxProjectiles: 120
```

## Acceptance

```txt
終盤でも操作不能にならない
30fpsを大きく下回らない
中断復帰で即被弾しない
```

# 7. No-Go Conditions

以下なら次へ進まない。

## Prototype 1

```txt
移動が不快
欠片回収が面倒
1分以内に面白さがない
スマホで操作不能
```

## Prototype 2

```txt
武器差がない
3択が読めない
5分が退屈
```

## Prototype 3

```txt
8分が退屈
カプセルが嬉しくない
進化できない
必殺技が空気
リザルトで次にやることがない
```

---

# 8. 最重要

数値は守るためではなく、ズレを見つけるために使う。

```txt
目標値からズレたら、なぜズレたかをbalance-logに記録する。
```

感覚だけで直さない。

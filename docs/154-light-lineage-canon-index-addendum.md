## Added canon

- Yui's lantern is fixed.
- Important playable characters should not duplicate glowing objects.
- A glowing object is a memory vessel.
- First action comes from the vessel.
- Similar vessels imply relation.
- Everyone important has met Yui at least once.
- Yui is central, but not the answer to every mystery.
- Every major character needs one clear relation, one indirect relation, and one blank.

## P1 boundary

Prototype 1 still uses Yui only.

P1 may show traces, not full explanations:

- handwriting
- repaired-lantern mark
- box mark
- ticket mark
- background object hints

Do not add relationship systems or multi-character mechanics to P1 because of this canon.

## Design consequence

Before any new avatar, monster, item, or UI motif is created, decide whether it is:

- character vessel
- memory item
- pickup
- UI signal
- background prop

These must not all use the same glow language.

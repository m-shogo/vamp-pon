# Vamp Pon Visual Direction

仮ビジュアルの方向を固定するガイド。**紙片・絵本風ドット / 夜の街**。
参考画像は `assets/concept-design/`（[一覧](visual-reference-inventory.md)）。
実装トークンは `src/game/ui/visualDesign.ts`、共有色は `src/game/domain/constants.ts` の `COLORS`。

評価基準は「派手か」ではなく「世界観に合うか・意味が見た目で分かるか・視認性・スマホ縦で邪魔にならないか」。

## 2. 透明度・線・glow の基準

```txt
glow alpha 上限 : 0.35（GLOW_ALPHA_MAX）。これ以上光らせない。
stroke 太さ     : thin=1 / base=2 / bold=3（STROKE）。基本は thin〜base。
背景の装飾      : alpha 0.05〜0.2（プレイ領域を邪魔しない）
地面範囲(DoT)   : alpha 0.4〜0.55（敵が上に乗っても見える）
弾              : ほぼ不透明。背景より明るい紙/灯り/ガラスで視認性を確保。
```

光量だけで強さを出さない。強さは「数・大きさ・モチーフ」で表す。

## 3. 使っていい形 / 使ってはいけない形

使う:

```txt
紙片（角ばった四角・三角・折り目）
黒インクのにじみ（不規則な円の集合・楕円）
小さな灯り（暖色の円 + 控えめなglow）
地図の線・点
古紙のカード・短冊・封筒・しおり・切符
星（小さく・金色・紙の破片として）
ガラス玉（ハイライト + ひび）
```

使わない（禁止）:

```txt
SFレーザー / ビーム（細長い発光矩形を弾にしない）
魔法陣 / 十字スラッシュ / 回転シンボル
ネオンリング（高彩度シアンの輪）
ギラギラした巨大な星エフェクト
光量だけで押す表現
背景や敵と混ざる真っ黒
ただの丸・線・星だけの仮表示
```

## 4. 強化進化 / 合体 / 覚醒の見た目の違い

`EVOLUTION_ACCENT`（visualDesign.ts）で色とリング数を分け、**モチーフ差**で特別感を出す。

| 種別 | 条件 | 見た目の文法 | アクセント |
|---|---|---|---|
| 強化進化 upgrade | 武器Lv5 + 忘れ物 | 元武器の延長。控えめ。地図線がつながる/灯りが少し強く | 暖色1リング |
| 合体 fusion | 武器Lv5 + 武器Lv5 | 2モチーフが同時に残る（例: 黒インク + 街灯の丸い光 = 夜明けの輪） | 朝色 + 黒インクの2リング |
| 覚醒 awakening | 武器Lv5 + レアアイテム | レアの意味が宿る（名前札/レンズ/封/風）。やや神秘だが紙寄り | 淡い菫 + 金の2リング |

進化後武器は、進化演出だけでなく**通常攻撃中の弾の見た目**でも違いが分かる（下記）。

## 5. 武器・進化後武器の弾の見た目（`createProjectileView`）

| 武器 | kind | 見た目 |
|---|---|---|
| 夜の鉛筆 | `pencil` | 紙に書いた短い濃い線 + 芯先 |
| 未完成の一行(強化) | `pencil_line` | 長い掠れた鉛筆の一行（ビームではない） |
| 消えない名前(覚醒) | `name_line` | 鉛筆の線 + 末尾に名前札の短冊 |
| 星くず弾 | `star` | 小さな金の星（控えめ） |
| 北極星のランタン(強化) | `paper_lantern` | 小さな紙ランタンの灯り + 地図の点 |
| 絵はがきカッター | `blade` | 薄い紙片、端だけ鋭い |
| 宛先のない刃(覚醒) | `envelope_blade` | 紙片 + 封の切れ目(V) |
| ビー玉 | `glass_marble` | 小さなガラス玉 + ハイライト |
| 追憶のビー玉(覚醒) | `lens_marble` | 大きめガラス + ひび + 中に景色の色 |
| 紙ひこうき | `paper_airplane` | クリームの紙ひこうき + 折り目 |
| 追い風の紙ひこうき(覚醒) | `big_plane` | 大きめ紙ひこうき + 折り目 + 風線 |

地面範囲（`createAreaView`）:

```txt
ink  黒インクの染み（黒インクの小瓶）
lamp 街灯の丸い暖光（街灯の輪）。ネオンにしない
dawn 黒インクの染み + 街灯の輪 + 朝色（夜明けのインク灯 / 合体）。魔法陣にしない
```

月のしおり(`orbit`)は紙のしおり（先に切れ込み + 月のしるし）。

## 6. 参考画像から：採用 / 再現 / 仮

### 採用した要素

```txt
深い藍紫の夜 + 暖色の灯り + 古紙クリーム の三色構成
白目の黒インク影（足元のインク溜まり付き）
金の星の記憶の欠片
コルク瓶 + 中の星 の記憶カプセル
古紙 + 茶縁 + 角の星 のカードUI
背景のヴィネット + 紙グレイン + 縁の紙片/街灯（グリッドではない）
```

### ゲーム内で再現した要素（Phaser図形の仮実装）

```txt
プレイヤー: フード + ワンピース + 手元のランタン + 足元の暖光
敵: visualKind 別（ink_blob/paper_scrap/signpost/capsule/haze/label_elite）
武器: 上表の紙・インク・灯り・ガラスのモチーフ
進化: 強化/合体/覚醒の色・リング差 + 弾の見た目差
回復: 朝色の包帯紙（緑十字ではない）
```

### まだ仮（今後の本素材化で差し替え）

```txt
ドット絵の本スプライト（現在はベクター図形での近似）
背景タイルの本テクスチャ（紙質はグレインで近似）
カードの手描き縁・破れの質感（現在は矩形 + stroke）
敵のアニメーション
```

## 7. ドット素材化方針（重要）

Phaser Graphics で全部描き続けない。**画像アセット＋fallback** へ移行する。

```txt
- 必要素材は src/game/assets/assetManifest.ts が正本（置き場 public/assets/sprites/）
- 画像があれば createXView がスプライトを使い、無ければ従来 Graphics で描く
- 制作工程: docs/art-pipeline.md / サイズ: docs/sprite-size-guide.md
- 制作プロンプト: docs/pixel-art-generation-prompts.md
- 状況確認: VisualGallery ?scene=asset-status（実素材/仮/欠品）
```

強化進化 / 合体 / 覚醒の見た目の定義は §4 のとおり。最終的にはこれを**ドット素材**で表現し、
演出（evolutionBurst）は控えめなアクセントに留める（魔法陣・ビーム・ネオンを増やさない）。

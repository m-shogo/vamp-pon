# 夜綴りの八影 — Pair Dynamics v1

Date: 2026-08-11  
Status: **CURRENT CONTENT SOURCE / RUNTIME NOT PROMOTED**

## Purpose

八影を「8人の悪役チーム」にせず、複数体が同じ夜へ現れた時の相互作用を作る。

```txt
八影 = faction ではない
八影A + 八影B
= AのWrong ReadingとBのWrong Readingが同じ対象へ作用した結果
```

## Coverage

```txt
8C2 = 28 pair
```

全28組に:

- interaction hook
- Wrong Reading collision
- encounter choreography
- player discovery
- story afterimage

を持たせる。

## Collision grammar

- `AMPLIFY`: 二つの誤読が重なってより危険になる
- `CONTRADICT`: 一方の行為がもう一方の前提を壊す
- `COMPETE_FOR_CONTROL`: 同じ対象を別の正解へ固定しようと奪い合う
- `ACCIDENTAL_COUNTER`: 一方の欠点が偶然もう一方を崩す
- `FALSE_ALLIANCE`: 息が合って見えるが、共通目的や友情はない
- `MUTUAL_ERASURE`: 互いの意味/痕跡を消し続ける
- `CHAIN_PRESSURE`: 一方の固定が次の誤読を誘発する

## Featured eight co-appearances

特に記憶に残る共演候補を8組置く。

1. **ナシロ × ハクマ**  
   空欄を埋めたい / 書かれたものを消したい。playerは「未分類」という第三状態を作る。

2. **ナシロ × ペタ**  
   正しい一枚を求める / 間違いを認めず上貼りする。敵側のMARKED対象すら食い違う。

3. **アサトジ × オリネ**  
   箱へ閉じる / 意味を折って隠す。「今は見せない」が重なると解除責任だけが消える。

4. **アサトジ × ユラネ**  
   身体を安全な箱へ / 意識を穏やかな夢へ。「傷つかない場所」が本人の帰れない場所になる。

5. **ミチグレ × オリネ**  
   道を消す / 道標を折って隠す。隠された折り目が逆に安全routeの痕跡になる。

6. **ミチグレ × ハクマ**  
   routeと説明を両方消す。外部の地図でなく、自分たちが歩いた履歴を帰路へする。

7. **ツグリ × ユラネ**  
   現実を勝手に修理 / 直らない箇所を夢で完成扱い。失敗記録を残すことがcounterになる。

8. **ツグリ × ペタ**  
   修理した / 修理済み札を貼る。作業した事実と本当に直った事実を分離させる。

## Petty-rival rule: ペタ

ペタは他の7体すべてとpair dynamicを持つが、毎回危険を増やすだけにしない。

例:

- アサトジの箱へ誤ラベルを貼り、分類を崩してplayerの脱出口を偶然作る
- オリネへ札を貼りすぎて変形位置を先に見せる
- ミチグレの消した道へ「出口→」を貼り、たまたま安全routeを示す

ペタを「実は最強」「実は全て計算」にしない。

> 頑固で厄介だからこそ、他の八影すら困らせる。

という愛着を守る。

## Story rule

八影pairに:

- 会議
- 組織命令
- 上下関係
- 友情
- 共通ボス
- 「我ら八影」的な自己紹介

を勝手に足さない。

同じ場所で二つのWrong Readingが発生したから相互作用するだけでも成立する。

逆に、後で本当に何らかの共通起源候補を検討する場合も、このpair dataだけを根拠にCanon化しない。

## Combat rule

複数八影 encounterは単純HP二倍にしない。

面白さは:

- enemy Aのcueがenemy Bで変質する
- 二体が互いに邪魔をする
- 一方を利用してもう一方を崩す
- playerが第三の解釈を作る

に置く。

好きなcharacter/Buildがpair encounterだけ使用不能になるHard counterは禁止。

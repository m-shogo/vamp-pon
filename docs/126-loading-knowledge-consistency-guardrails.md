# Loading Knowledge Consistency Guardrails

Vamp Pon / ヴァンサバ改のロード名言・格言・日常英語・難語・パロディ・キャラ返信・朝明ポエムが破綻しないようにするための運用ガードレール。

---

## 1. この資料の目的

ユーザー方針:

```txt
少しずつでいいから、破綻しないように詰めていく。
```

この資料では、次を固定する。

```txt
増やす順番
混ぜてよいもの/混ぜてはいけないもの
採用/保留/削除の判定
キャラ返信の破綻チェック
宗教・文化モチーフの安全線
パロディの出しすぎ防止
ロード演出の品質維持
```

---

## 2. 最重要ルール

```txt
一気に広げない。
1回の追加では、ひとつの軸だけを詰める。
```

悪い進め方:

```txt
名言も増やす
宗教観も増やす
パロディも増やす
実装仕様も変える
キャラポエムも直す
```

良い進め方:

```txt
今日は初期40件のうち、Everyday English phrase 8件だけを確定する。
今日はユイ/アサ/ナギの返信品質だけ見る。
今日はMemory RoomのUIだけ詰める。
```

---

# 3. 機能の境界線

## 3.1 Loading Quote / 名言・格言

役割:

```txt
原文、出典、日本語訳/意味を出す。
Vamp Pon風に改変しない。
```

やること:

```txt
Original
Source
日本語訳/意味
Research hooks
```

やらないこと:

```txt
キャラの気持ちを名言欄に混ぜる。
Vamp Ponオリジナル文を名言のように出す。
出典が曖昧なものを本物っぽく出す。
```

---

## 3.2 Character Reply / キャラ返信

役割:

```txt
キャラがその言葉をどう受け取るかを見せる。
解説ではなく返信。
```

やること:

```txt
キャラの価値観
キャラの傷
少しのユーモア
言葉への個人的な反応
```

やらないこと:

```txt
名言の意味を説明する。
作者の意図を断定する。
宗教や文化をいじる。
全部のキャラが言えそうな一般感想にする。
```

---

## 3.3 Morning Poem / 朝明ポエム

役割:

```txt
キャラ本人が夜を少し越えた証。
ロード名言とは別枠。
```

やること:

```txt
キャラの変化
納得
手放し
帰り道
朝の余韻
```

やらないこと:

```txt
名言の引用
長い独白
全部の謎の説明
勝利演説
```

---

## 3.4 Parody Dialogue / パロ会話

役割:

```txt
映画・漫画・アニメが好きな感覚を、短い掛け合いの構造として入れる。
```

やること:

```txt
短いやりとり
照れ隠し
皮肉
関係性が見える返し
```

やらないこと:

```txt
有名台詞そのもの
薄い改変
固有名詞のもじり
出しすぎ
```

# 4. 採用ランク

## 4.1 Sランク / すぐ採用

条件:

```txt
原文/出典が比較的確認しやすい。
Vamp Ponの夜・記憶・忘れ物・名前・朝に合う。
キャラ返信でその子の価値観がはっきり見える。
短く読める。
```

例:

```txt
What's in a name?
— William Shakespeare

名前の中には、何があるのだろう。

私には、まだ入りきらない。
— シノ
```

---

## 4.2 Aランク / 採用候補

条件:

```txt
方向は良い。
ただし返信・訳・演出を少し直す必要がある。
```

処理:

```txt
保留リストに入れ、次回ブラッシュアップ対象にする。
```

---

## 4.3 Bランク / 保留

条件:

```txt
面白いが、出典確認が弱い。
または文化的に慎重さが必要。
またはキャラ返信がまだ汎用的。
```

処理:

```txt
Memory Room向け候補に回す。
ロード初期実装には入れない。
```

---

## 4.4 Cランク / 削除

条件:

```txt
出典が怪しい。
現代作品に近すぎる。
宗教・文化への敬意が足りない。
寒いパロディ。
キャラが説明しているだけ。
読みにくすぎる。
```

処理:

```txt
do-not-display。
実装データには入れない。
```

---

# 5. 破綻しやすいポイント

## 5.1 名言とVamp Ponオリジナル文が混ざる

危険:

```txt
原文欄にVamp Pon風の言い換えが混ざる。
```

対策:

```txt
Original欄は必ず原文。
Vamp PonらしさはCharacter replyまたはVamp original lineだけで出す。
```

---

## 5.2 宗教モチーフが装飾になる

危険:

```txt
サンスクリット語や宗教語を、意味より雰囲気だけで使う。
```

対策:

```txt
意味がゲームのテーマに合わないものは使わない。
現役宗教の言葉は軽口返信をつけない。
```

---

## 5.3 キャラが全員ポエマーになる

危険:

```txt
全キャラが同じ文体で重く語る。
```

対策:

```txt
キャラごとに返信温度を分ける。
ユイは小さなやさしさ。
アサは痛みと軽口。
ナギは道。
シオンは記録。
クロエは皮肉と距離。
セナは荷物と宛先。
```

---

## 5.4 パロディが寒くなる

危険:

```txt
元ネタを当てさせることが目的になる。
```

対策:

```txt
知らない人にも成立する文だけ使う。
1プレイ内でパロ会話は最大1回程度。
```

---

## 5.5 難語が辞書アプリになる

危険:

```txt
曖昧模糊、閑話休題、画竜点睛などを並べすぎる。
```

対策:

```txt
難語は2連続禁止。
意味は1行。
キャラ返信でゲームに戻す。
```

---

# 6. カテゴリごとの安全な追加順

## Phase A: Everyday English phrase

理由:

```txt
短い。
商用リスクが比較的低い。
海外向けにも自然。
キャラ返信でユーモアが出やすい。
```

優先:

```txt
Bless you.
Take care.
Good night.
See you.
No worries.
Hang in there.
Fingers crossed.
Knock on wood.
```

---

## Phase B: Rare Japanese / literary phrase

理由:

```txt
知識欲を満たしやすい。
キャラ価値観が見えやすい。
出典問題が比較的軽い語句も多い。
```

優先:

```txt
閑話休題
余談ながら
曖昧模糊
有耶無耶
序破急
蛇足
画竜点睛
薄明
```

---

## Phase C: Serious literary quote

理由:

```txt
作品の格を上げる。
ただし出典/翻訳確認が必要。
```

優先:

```txt
Emily Dickinson
Virgil
Dante
Shakespeare
清少納言
鴨長明
```

---

## Phase D: Regional religious/philosophical quote

理由:

```txt
深みが出る。
ただし文化・宗教への敬意と確認が必要。
```

扱い:

```txt
初期実装には少数だけ。
インド/東アジア/日本から始める。
アメリカ/カリブは生活格言中心に慎重に。
```

---

## Phase E: Parody dialogue

理由:

```txt
刺されば強い。
出しすぎると寒い。
```

扱い:

```txt
初期は2件だけ。
Sランク以外は入れない。
```

```txt
ユイ: やさしいが、忘れ物への執着がある。
アサ: 痛みを軽口で返す。
ナギ: すべてを道や地図に変換する。
ミチル: 流すことと残ることを分ける。
トモリ: 壊れたものを直しすぎない。
シノ: 名前と輪郭に反応する。
シオン: 記録されなかったものを見る。
クロエ: 皮肉、距離、でも帰る気配。
コハル: 怖がりながら芽を出す。
レン: 継いだものの重さ。
マヨイ: 迷うことを少し肯定する。
イオリ: 方角と心のズレを見る。
ハク: 空白と存在の不安。
スズ: 鳴らない音を聞く。
リツ: 消えた声や歌を拾う。
ヒナタ: 破れた夜を縫う。
カナメ: 守る輪を開ける怖さ。
```

この温度から外れた返信は、どれだけ良くても再検討する。

# 8. 1回の追加作業でやること

今後は、1回の作業をこの単位にする。

```txt
1カテゴリだけ選ぶ。
8〜10件だけ候補を出す。
各候補にS/A/B/C評価をつける。
S/Aだけ実装候補へ進める。
キャラ返信は最大2人分まで。
演出パターンを1つだけ指定する。
```

例:

```txt
今日は Everyday English phrase 8件を確定。
今日は Rare Japanese phrase 8件を確定。
今日は 初期Serious quote 8件を確定。
```

# 9. 最終チェックリスト

ロードに出す前に確認する。

```txt
□ Originalは原文か
□ Sourceは明記されているか
□ 日本語訳/意味は既存訳の丸写しではないか
□ Character replyは解説ではなく返信か
□ そのキャラにしか言えないか
□ 宗教/文化を雑に消費していないか
□ 390x844で読める長さか
□ 直近重複やカテゴリ連続を避けられるか
□ do-not-display対象ではないか
□ 記録室で見返す価値があるか
```

---

# 10. 次にやるべき具体作業

次はこの順番が安全。

```txt
1. Everyday English phrase 8件をS/A/B/C評価つきで確定する。
2. Rare Japanese phrase 8件をS/A/B/C評価つきで確定する。
3. Serious literary quote 8件を確定する。
4. Regional quote 10件を慎重に確定する。
5. 40件をsrc/dataに落とせるJSON/TS形式にする。
6. CharacterReply 60件をSランク中心に作る。
```

# 11. 最終方針

```txt
破綻しないために、増やす速度を落とす。
でも密度は上げる。
```

Vamp Ponのロード知識システムは、

```txt
少数精鋭
原文尊重
短い意味
キャラ返信で価値観
読める文字演出
記録室で見返す
```

を守る。

# Balance Log Template

## 目的

Vamp Pon の数値調整を、感覚だけで進めないためのログ雛形。

数値を変える時は、必ず以下を残す。

```txt
何を変えたか
なぜ変えたか
どうなったか
次に何を見るか
```

---

# 記録ルール

## 1. 変更前後を書く

NG:

```txt
敵を少し弱くした
```

OK:

```txt
インクの影 HP 18 → 15
夜の鉛筆 damage 12 → 14
```

## 2. 理由を書く

NG:

```txt
なんとなく
```

OK:

```txt
初回Lv2到達が90秒を超えていたため
敵が画面に溜まりすぎたため
```

## 3. 結果を書く

```txt
初回Lv2到達 82秒 → 58秒
3分時点Lv 3 → 5
死亡時間 4:20 → 5:40
```

## 4. 次の懸念を書く

調整は副作用が出る。

```txt
序盤は良くなったが、5分以降が簡単すぎる可能性
欠片が増えすぎてスマホで重い可能性
```

# 調整禁止事項

```txt
一度に多く変えすぎる
理由を書かずに変える
結果を書かずに次へ進む
仮素材の印象で数値を変える
1回のプレイだけで断定する
```

## 原則

```txt
1回の調整で変える主因は1〜2個まで。
```

そうしないと、何が効いたか分からなくなる。

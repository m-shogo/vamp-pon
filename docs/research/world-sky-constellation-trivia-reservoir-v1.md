## Fact

# 6. Polynesian wayfindingでは「星座の絵」より horizon が重要

## Fact

Hōkūleʻaで使われるHawaiian star compassは物理的compassではなくmental construct。
visual horizonを32 housesへ分け、Sun / Moon / stars / planetsのrise / set pointsを航海の基準にする。
1 house = 11.25°。

## Small value

天文に詳しいCharacterでも、
- 星を絵として覚える人
- rise / set方向として覚える人

で「空の読み方」が全く違う。

Dream Stageのnavigation puzzleにも使えるが、実文化用語の直接game system化は要再検討。

Source:
https://hokulea.com/polynesian-wayfinding/

# 7. 星がない「暗い部分」も星座になる

Culture: multiple Aboriginal Australian traditions

## Fact

Emu in the Sky / dark emuは、星を線で結ぶのではなく**Milky Wayのdark dust lanes**を使って形を読むdark constellation。
Coalsack Nebula付近がheadとして知られる例がある。

## Small value

> 星座は「光っているものだけを見る技術」ではない。
> **何も見えない黒い部分にも形を見つける文化がある。**

ヨルノシルベの夜、黒耀化、Negative Space visualに非常に強いが、specific sacred storyの借用は避ける。

Sources:
https://www.space.gov.au/news-and-media/our-indigenous-astronomical-traditions

# 18. North Starは役職名に近い

## Fact

Polarisは現在North Starだが永遠ではない。
Earth axis precessionは約26,000年周期で、過去 / 未来には別のstarがpole付近へ来る。
NASAは約14,000年前 / 約12,000年後付近にVegaがpole側に来ることを説明している。

## Small value

> **北極星は一人の固有名というより、その時代に誰かが担う役割。**

称号 / leader / keeperのthemeに使える。
Current Era差（数十年）には使わない。

Source:
https://science.nasa.gov/solar-system/skywatching/what-is-the-north-star-and-how-do-you-find-it/

Tags: `IDENTITY` `FUTURE` `SCIENCE`

# 26. 「Seven Sisters」なのに肉眼で見える数は固定7ではない

# Obsolete Constellation Boss Naming Candidates v1

Status: **AUTHOR NAMING RESERVOIR / NON-CANON / CONSTELLATION HISTORY AWARE**

## Rule first

ボス側をobsolete constellationと結びつける場合でも、

**「現代の88星座に採用されていない = 悪 / 間違い / 消されるべき」にはしない。**

星座がofficial listから外れる理由と、敵になる理由は別。

敵性はKokuuyou / Memory distortion / dream ecology / Main Mysteryなど別Authorityから決める。

この名前は「現在の星図の外にいる」「過去の地図にはいた」「分類から零れた」ことだけを表す。

---

## A tier — 世界観に馴染みやすい

### 1. 外典星座（がいてんせいざ）

意味:

正典の星図には入らない、別伝・外典側の星座。

良い点:

- `obsolete = evil`になりにくい
- Archive / Lorebook / hidden historyと相性が良い
- 一目で「普通の星座とは別枠」と分かる
- Quadrans Muralis / Felis / Machina Electricaなど種類を問わず包める

注意:

`Canon / apocrypha`のメタ感が少し強い。

**Candidate rank: A+**

### 2. 遺星座（いせいざ）

意味:

星図史に遺された星座。

良い点:

- 消滅より「痕跡が残る」ニュアンス
- Memory themeに非常に強い
- Quadrantidsのような名前の化石と相性が良い

注意:

読みが一瞬分かりにくい。

**Candidate rank: A+**

### 3. 旧天図座（きゅうてんずざ）

意味:

旧い天図にのみ残る座。

良い点:

- 歴史資料由来が伝わる
- 善悪を含まない

注意:

少し資料用語っぽい。

**Candidate rank: A**

### 4. 星図外（せいずがい）

意味:

現在の星図の外側。

使い方:

`星図外のもの` / `星図外種` / `星図外個体`

良い点:

- 短い
- 不穏
- official/rejectedを直接言わない

注意:

星座であることは名前だけでは弱い。

**Candidate rank: A**

---

## B tier — 詩的で強いが意味を説明する必要あり

### 5. 忘れ座（わすれざ）

「忘れられた星座」。

Memory themeには強いが、実際には単純に忘れられたわけではなくstandardizationで不採用になったものもある。

**Candidate rank: B+**

### 6. 逸座（いつざ）

現在の体系から逸れた座。

短く固有名詞感がある。

注意: 日本語として造語感が強い。

**Candidate rank: B+**

### 7. 遺座（いざ）

遺された座。

非常に短く、組織・種族名っぽい。

注意: 初見では意味が分かりづらい。

**Candidate rank: B+**

### 8. 天図遺物（てんずいぶつ）

昔の星図から残ったもの。

星座以外の古い天文記号・図像まで敵側へ広げたい場合に強い。

**Candidate rank: B**

---

## C tier — 強いが「悪/失敗」の意味が入りすぎる

### 9. 廃星座（はいせいざ）

意味は最も分かりやすい。

ただし「廃止された=価値がない」の印象が強い。

Research/UI用分類には便利だが、作中正式総称には慎重。

**Candidate rank: C+**

### 10. 廃座（はいざ）

短いが、さらにnegative。

**Candidate rank: C**

### 11. 亡座（ぼうざ）

死んだ星座のように聞こえる。

星そのものは死んでいないため、historical themeとは少しずれる。

**Candidate rank: C**

### 12. 失座（しつざ）

失われた座。

語感は強いが、official historyを「喪失」だけで説明してしまう。

**Candidate rank: C**

## English / internal naming candidates

Machine/internal vocabulary候補:

- `APOCRYPHAL_CONSTELLATIONS`
- `OBSOLETE_CONSTELLATION_ENTITIES`
- `ARCHIVED_CONSTELLATIONS`
- `FORMER_CONSTELLATIONS`
- `OUTSIDE_THE_CHART`
- `SKY_ATLAS_REMAINDERS`
- `UNRETAINED_CONSTELLATIONS`

Avoid:

- `REJECTED_CONSTELLATIONS` as default story name
- `FAILED_CONSTELLATIONS`
- `WRONG_CONSTELLATIONS`

理由: standardizationに残らなかったことを人格的失敗へ変換しないため。

## Recommended current shortlist

### 世界観総称なら

1. **外典星座**
2. **遺星座**
3. **星図外**

### 研究者/図鑑側の呼称なら

1. **旧星座 / obsolete constellation**
2. **旧天図座**
3. **天図遺物**

### 敵側が自称するなら

`忘れ座`や`遺座`のような、official側からの評価を含まない短い言葉も候補。

---

## Strongest current recommendation

現時点の一番バランスが良いCandidateは **「外典星座」**。

理由:

- obsoleteだけでなく、historical atlas / abandoned figure / restructured constellationまで包含可能
- 「悪いから除外された」と読ませにくい
- LorebookのArchive aestheticと自然に繋がる
- `星図外`という下位分類とも共存できる

ただし、これは**まだ作者候補**。

Main Mystery / Kokuuyouとの因果が固まるまでは正式総称へ昇格しない。

## Authoring principle

**星図から外れたことと、敵になったことを同じ理由にしない。名前は歴史的位置を示し、悪性の理由は物語側で別に作る。**

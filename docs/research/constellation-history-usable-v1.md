# Constellation History — ヨルノシルベで使える史実 v1

Status: **RESEARCH EVIDENCE / NON-CANON / HISTORY-FIRST / CURRENT CORE5 ERA GUARD**

## 結論

最初に重要な修正点。

**「1940年代〜戦後のトモリの時代と、現代ユイの時代では、IAU公式の星座一覧そのものが違う」という伏線は、現在のCore5年代設定のままでは史実として使えない。**

現代の88星座体系は戦前に国際標準化されているため、`POST_1945_TO_EARLY_1950S_LIKE` のトモリと `2020S_CURRENT` のユイに、年代差だけを理由として別のIAU公式星座セットを与えるのは避ける。

これは星座史のアイデアを捨てる理由ではない。むしろ、**「昔の星図」「消えた名前だけが現代語に残る」「一つの星座が複数へ再編された」「人間が時代の技術や権力を空へ書き込んだ」**という、より史実に強い伏線へ変換できる。

---

## 1. 現代88星座の標準化

Research anchor:

- International Astronomical Union — official constellation history / 88 constellations
- Eugène Delporte — *Délimitation scientifique des constellations* (1930)
- IAU boundary adoption process in the late 1920s

Usable historical frame:

- 20世紀前半までに現在の88星座体系が国際的に標準化された。
- constellation names / abbreviations の整理と、境界線の正式化は段階的に行われた。
- Delporteによる境界体系は1930年刊行の資料として現在の星座境界史を考える重要な基準になる。

### ヨルノシルベへの影響

トモリ最古Reality laneが戦後なので、

`トモリの時代には公式だった星座 → 現代では消滅`

をそのまま使うのは不可。

代わりに、

`トモリが持っている古い本・古い星図には載っている → 彼の時代の公式一覧にはもうない`

なら成立する。

つまり伏線の年代は**人物の現在年代ではなく「その資料が作られた年代」**に置く。

## 2. 最優先候補 — Quadrans Muralis / Quadrantids

### 史実の面白さ

`Quadrans Muralis` は現在の88星座には残っていない歴史的星座名。

しかし、現代にも **Quadrantids / しぶんぎ座流星群** という名称が残っている。

つまり、

**「星座そのものは現在の公式星図から消えたのに、その名前だけが別の天文現象に化石のように残っている」**

という非常に強い実例になる。

### ヨルノシルベ候補

- 現代人物は「しぶんぎ座流星群」という言葉を普通に知っている。
- 古い星図を開くと、本当に「Quadrans Muralis」が図として存在する。
- 誰かが「今ない星座なのに、なぜ流星群には名前が残っているの？」と気づく。
- 「名前は残る／形は消える／記憶だけが別の場所に残る」という本作のMemoryテーマと自然に接続できる。

### 判定

**VERY HIGH / 史実伏線として最優先。**

Core5の年代を変える必要がない。

---

## 3. Argo Navis — 一つの星座が複数へ

古代から知られた巨大な船の星座 `Argo Navis` は、現在では一つのIAU星座として残っていない。

現在の星図では、船を構成していた領域が主に

- Carina
- Puppis
- Vela

などの別々の星座として扱われる。

### ヨルノシルベ候補

これは「星が消えた」のではなく、

**同じ星々を、人間が別の単位へ切り直した**

という伏線に向く。

使えるテーマ:

- 一人だと思っていた存在が複数の記憶へ分かれる
- 一つの名前で呼ばれていた共同体が後世に複数名へ分割される
- 同じものを見ても時代で「どこまでを一つと見るか」が変わる
- Robot / memory copy / twinsテーマとの反響

### 判定

**HIGH**。

ただし「戦後に分割された」とは扱わず、歴史的星図比較として使う。

## 4. Antinous — 大きな星座へ吸収された人物像

Antinousは歴史的な星図・星座伝統でAquila付近に独立した人物像として扱われる例があるが、現在の88星座の一つではない。

### ヨルノシルベ候補

`一人の名前が、後の地図では大きな別名の中へ吸収されている`

という記憶テーマに使える。

- 古い資料では名前がある
- 新しい資料では「そこに星はある」のに名前がない
- 存在そのものが消えたわけではない

### 判定

**MEDIUM-HIGH**。

神話・歴史背景が強いため、採用時は別途文化史レビューを行う。

## 6. Machina Electrica — 電気機械まで星座になった

歴史的星図では、人類の当時の技術をそのまま空の図像へ持ち込む試みがあった。

`Machina Electrica` は、その象徴として非常に面白い obsolete constellation candidate。

### ヨルノシルベ候補

Asa / Noa / RumのFuture themeと強く響く。

重要なのは、

`未来だから機械星座を作る`

ではない。

逆に、

**「昔の人間も、その時代の最新技術を星空へ書き込もうとしていた」**

という史実側の鏡として使う。

これなら

- Humanはいつの時代も空へ自分の時代を投影する
- Technologyもいつか古い神話になる
- Futureだけが特別な時代ではない

という本作の時間構造にかなり相性がいい。

### 判定

**HIGH**。

## 7. Officina Typographica — 印刷工房が空にある

印刷技術を記念する歴史的constellation conceptも、modern 88には残っていない。

### ヨルノシルベ候補

Shiro / archive / book / record / Lorebookのテーマと相性が良い。

特に、

`情報を残す技術そのものが、一度は空の地図へ刻まれ、それ自体は後に消えた`

という構造が強い。

Memory / archive storyで「記録媒体も永遠ではない」伏線にできる。

## 8. Robur Carolinum — 星座名は自然ではなく政治でもある

歴史上、君主・権力・patronageに結びついたconstellation namingの例もある。

`Robur Carolinum` は、空の区分が単なる自然科学の永久不変な答えではなく、**その時代の人間社会が作った文書でもある**ことを示す材料になる。

### ヨルノシルベ候補

- 誰が名前を付ける権利を持つのか
- Official mapに載る = 存在価値、ではない
- Current authorityと過去authorityの違い
- Canon / Candidate / Openという作者DB構造そのものとのメタな共鳴

### 判定

**HIGH for world theme / LOW for direct main mystery clue**。

## 9. 「後から増えた公式星座」も本当にある

歴史を十分早い時代まで遡れば、現在の88に含まれる星座の中にも後世に導入されたものがある。

代表的な研究方向:

### 南天航海・Plancius / Keyser / de Houtman系

16世紀末の南天観測・航海以後、現在も採用される複数の南天星座がヨーロッパ星図へ定着していく。

### Lacaille系

18世紀にはLacailleが南天・科学機器をモチーフにした複数星座を導入し、その中にはmodern 88へ残るものが多い。

### ヨルノシルベへの意味

**「後から増えた星座」は史実として正しい。**

ただし、その変化はCore5最古の戦後年代よりはるか前。

したがって現在の設定では、

`トモリにはない → ユイにはある`

には使わない。

使うなら:

- 古星図
- 博物館資料
- 書庫
- 夢世界のArchive layer
- もっと古いサブキャラ/史料

の方へ接続する。

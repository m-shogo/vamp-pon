# 36. 「むりかぶし」は八重山のPleiades名

## Fact

国立天文台・石垣島天文台の105cm望遠鏡は**むりかぶし望遠鏡**。
「むりかぶし」は石垣島を含む八重山諸島での「すばる / Pleiades」の呼び名。

## Yoru value

同じ日本の中でも:
- すばる
- 六連星
- むりかぶし

のような地域名がある。

> **同じ国・同じ時代でも、育った場所で空の名前が違う。**

年代差だけでなく出身地伏線にも使える。

Sources:
https://www.nao.ac.jp/research/telescope/murikabushi.html
https://prc.nao.ac.jp/prc/

# 40. 韓国の石刻星図は“複数時代の空”を一枚に持つ可能性

## Fact

KASI掲載研究によると、朝鮮時代の`Ch'on-Sang-Yul-Cha-Bun-Ya-Ji-Do`（天象列次分野之図）のstar positionsを統計解析すると:
- declination < 50°の多くはaround first century epoch
- north pole近くのstarsはaround 1300 epoch

を示し、古い原図を後世のastronomersがrevisionした可能性が論じられている。

## Yoru value

これかなり強い。

> **一枚の星図が、一つの時代だけで作られたとは限らない。**

古い線を全部捨てずに、一部だけ後世が直した“時代の積層”としてprop設計できる。

Source:
https://astro.kasi.re.kr/learning/pageView/1623?cPage=91

Tags: `ERA_CLUE` `ARCHIVE` `MEMORY` `PROP`

実在災害をYoru fictional incidentへコピーしないhard ruleは維持。

# 1. 人物設計の核

ヨルノシルベの世界は暗い。

しかし人物は一色にしない。

- 明るい
- ネガティブ
- 無口
- 強気
- 怖がり
- 子ども
- 渋い大人
- ぽっちゃり
- 眼鏡
- ギャル
- お嬢様
- ライバル

が自然に同居する。

**全員が「明るくなる」のではなく、その人らしいまま成長する。**

深みの基本:

```txt
長所
↓
同じ根から弱点が生まれる
↓
恐怖 / 焦りで黒耀化
↓
強いが間違った到達
↓
長所を捨てず扱い方を学ぶ
```

# 5. 人物は同じ時代の人とは限らない

**USER DIRECTION**

ヨルノシルベで出会う人物は、現実では必ずしも同時代ではない。

- 夜では出会える
- 朝へ帰れば自分の時代 / 人生へ戻る
- 長く夜に関わる人物もいる
- 夜の滞在時間と現実時間は一致しなくてよい
- Exact yearはまだLOCKしない

大事な原理:

> **人は別時代でも、物・言葉・記録は現実時間を順番に渡る。**

例:

トモリが昔修理したランタン
→ 現実で何十年か受け継がれる
→ 後世のユイが持つ
→ 夜ではユイとトモリが直接会う

人物全員を血縁や旧知にはしない。

詳細:
- `docs/story-temporal-layer-and-character-connections-v1.md`
- `docs/character-connection-web-high-value-candidates-v1.md`

# 6. 黒耀化 — もう一つの自分

共通system名: **黒耀化**。

黒耀化は:

- 闇落ちではない
- 外から入った悪人格でもない
- 本人の長所 / 願い / 力 / 恐怖が偏って現れたもの
- 圧倒的に強い
- しかし本人らしさが極端になり、周囲が見えなくなる

感覚として:

> **「間違った進化 / 未熟な到達」だが、その力も感情も本人のもの。**

後で:

> 「あれは別人だった」

と切り捨てず:

> **「あれも自分だった。扱い方を知らなかった。」**

と受け入れる。

ユイの固有呼称 `黒灯化` は強く継承。
他20人の固有名はWorkingで、Human Naming Review前にfinal lockしない。

詳細: `docs/BLACK-YOUKA.md`

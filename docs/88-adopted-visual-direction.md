# Adopted Visual Direction

## 目的

Vamp Pon の採用アート方向を固定し、今後の画像生成・UI設計・実装素材・外注指示がズレないようにする。

画像そのものは、出所・権利・生成条件が明確でない限りrepoに入れない。

この資料は、画像を保存する代わりに、採用した見た目の判断基準を文章で正本化する。

---

# 2. なぜ採用するか

## 世界観との相性

Vamp Pon のテーマと噛み合っている。

```txt
夜
記憶
忘れ物
黒インク
地図帳
紙片
小さな光
朝
```

## ゲーム画面としての強さ

```txt
自キャラが見える
敵が黒影として分かる
欠片が光って拾いたくなる
UIカードが世界観と合う
スマホ縦画面に収まりやすい
```

## 工数面

```txt
敵を黒インク影として量産しやすい
欠片/紙片/カードUIを共通モチーフ化しやすい
背景を薄くすれば視認性を保てる
ドット/シンプル2Dで段階的に作れる
```

# 3. 採用する見た目の要素

## Player: ユイ

```txt
小さな忘れ物係
ランタン持ち
フード/帽子/小さなバッグ
上から見ても判別できるシルエット
暗い画面でも輪郭が読める
ほんのり光をまとっている
```

## Enemy

```txt
黒インクの影
白い小さな目
怖すぎないが少し不穏
形で種類が分かる
触れると記憶が消えそうな質感
```

敵の方向:

```txt
丸い影
紙くずをまとった影
標識/ラベルの影
もや状の影
黒ラベルの強敵
```

## Fragment

```txt
小さく光る記憶の欠片
星型に近い紙片
黄色〜淡い金色
敵を倒した後に拾いたくなる
背景より確実に目立つ
```

## Capsule

```txt
記憶を閉じ込めた小瓶
透明感
中に小さな光
黒インクの線が少し混ざる
```

## UI

```txt
紙カード
古い切符
しおり
手書き感のある枠
星レアリティ
読みやすさ最優先
```

## Background

```txt
夜の街
古い街灯
ベンチ
紙片
地図帳のような床
黒インクのにじみ
ただし実ゲームでは薄くする
```

# 5. 視認性ルール

## 最優先

```txt
1. 自キャラ
2. 敵
3. 欠片
4. 弾/攻撃
5. HUD
6. 背景
```

## 背景ルール

```txt
背景はコンセプト画より薄くする
床の紙片は多すぎない
花/街灯/家具はプレイ領域で主張しすぎない
黒インクと敵が同化しないようにする
```

## 敵ルール

```txt
通常敵はHPバーなしを基本
強敵/黒ラベル/ボスのみHPバーあり
白目または輪郭で敵位置が分かる
```

## 欠片ルール

```txt
欠片は背景より明るい
小さくても光る
回収範囲に入ったら動きで分かる
```

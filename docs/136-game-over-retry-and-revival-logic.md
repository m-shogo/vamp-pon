# Game Over / Retry / Revival Logic

## 目的

Vamp Ponのゲームオーバー、復活、再戦、コンティニューに、世界観上の理由を与える。

これは単なる演出ではない。

```txt
なぜ負けるのか
なぜ戻れるのか
なぜ同じ夜を何度もやり直せるのか
なぜ完全に巻き戻っていないのか
なぜ再戦しても意味が残るのか
```

を説明できるようにする。

---

# 1. 結論

Vamp Ponでのゲームオーバーは、死ではない。

```txt
ゲームオーバー = その夜に仮接続した意味が、黒インクに固定し直されること
```

復活/再戦は、蘇生ではない。

```txt
復活/再戦 = 地図帳が、確定前の夜を別の読み順で開き直すこと
```

つまり、プレイヤーは死んで戻るのではない。

```txt
読めなかった夜を、別の順番で読み直している。
```

---

# 2. なぜゲームオーバーになるのか

夜の中でユイは、欠片を拾って意味を仮接続する。

しかし、黒インクの影に飲まれると、その夜の接続は途切れる。

その結果、以下が起きる。

```txt
拾った欠片は夜に戻る
仮接続した意味は確定しない
影が守っていた誤解は、再び固定される
ユイはその夜の読み方を失う
```

だからゲームオーバー。

これは肉体的な死ではなく、**その夜の読み筋の失敗**。

---

# 3. なぜ再戦できるのか

地図帳は、朝に確定したページだけを固定する。

朝まで届かなかった夜は、確定していない。

未確定の夜は、地図帳の中でまだ開き直せる。

```txt
朝まで残った夜 = 確定済み
朝まで残れなかった夜 = 未確定
```

だから再戦できる。

これは時間巻き戻しではない。

```txt
同じ出来事をやり直しているのではなく、
確定できなかったページを別の読み順で開いている。
```

---

# 4. なぜ完全リセットではないのか

ゲームオーバーしても、完全に何も残らないわけではない。

ただし、残るものと残らないものを分ける。

## 残らないもの

```txt
その夜だけのレベル
一時強化
未確定の欠片
仮接続した意味
```

## 残るもの

```txt
プレイヤーの知識
一度見た違和感
地図帳にすでに確定したページ
恒久解放済みの要素
```

物語上は、こういう理屈。

```txt
ユイはその夜の読み方を忘れる。
でも、地図帳に確定した意味までは黒インクも戻せない。
```

---

# 5. 復活の種類

## 5.1 その場復活

ゲーム内アイテムや広告リワード等で使える場合。

世界観上の理由:

```txt
ランタンの残り火が、仮接続を一度だけ保つ。
```

表現候補:

```txt
灯りがまだ消えていない。
```

ゲーム上の意味:

```txt
HPを一部回復
その夜の状態を一部保持
ただし、ペナルティとして一部の欠片が黒インクへ戻る
```

注意:

```txt
無制限復活は不可。
復活は“灯りの残り火”を消費する。
```

---

## 5.2 リトライ

通常の再挑戦。

世界観上の理由:

```txt
地図帳が、確定できなかった夜をもう一度開く。
```

表現候補:

```txt
この夜は、まだ読めていない。
```

ゲーム上の意味:

```txt
ラン開始時へ戻る
一時強化は消える
プレイヤーの知識と確定済み地図帳は残る
```

---

## 5.3 ステージ再挑戦

50Stage構成で、ページ単位リトライがある場合。

世界観上の理由:

```txt
ページの端がまだ乾いていないため、読み直せる。
```

表現候補:

```txt
ページの端が、まだ黒い。
```

ゲーム上の意味:

```txt
そのStageだけ再挑戦
ただし、リザルト文や取得順が変わる可能性がある
```

---

## 5.4 ページ束のやり直し

高難度/分岐回収向け。

世界観上の理由:

```txt
ページ束は閉じたが、背表紙に未確定の折り目が残っている。
```

表現候補:

```txt
この束には、まだ違う折り目がある。
```

ゲーム上の意味:

```txt
分岐リザルト回収
別順クリア
隠し文の開放
```

---

# 6. なぜ同じ夜に違う結果が出るのか

Vamp Ponの夜は、固定された現実ではない。

地図帳の中の未確定ページ。

だから、拾う順番や倒す敵、持ち帰る欠片で、意味の確定が変わる。

```txt
同じ夜でも、読み順が違えば意味が変わる。
```

これが再プレイの理屈。

---

# 7. ゲームオーバー時の演出

直接「死亡」と言わない。

使う言葉:

```txt
夜にのまれた
ページが閉じた
読み筋がほどけた
灯りが消えた
意味が黒く戻った
```

ゲームオーバー文候補:

```txt
夜にのまれた。
この読み方では、朝まで残れなかった。
```

```txt
ページが閉じた。
けれど、まだ読めていない行がある。
```

```txt
灯りが消えた。
地図帳は、もう一度同じ夜を開いた。
```

---

# 8. 復活時の演出

使う言葉:

```txt
残り火
しおり
折り目
仮の朝
読み直し
```

その場復活文候補:

```txt
ランタンの残り火が、まだ一行だけ照らしている。
```

```txt
しおりが落ちた。
この行から、もう一度読める。
```

```txt
折り目がほどけた。
夜は、まだ終わっていない。
```

---

# 9. なぜ復活に制限があるのか

復活は蘇生ではなく、仮接続の保持。

仮接続を保持するには、灯り/しおり/折り目のような補助が必要。

それらは消耗する。

```txt
ランタンの残り火は有限
しおりは一度落ちると黒くなる
折り目は何度も開くと破れる
```

だから、無限復活はできない。

---

# 10. ゲームオーバーと黒インクの関係

ゲームオーバー時、黒インクはユイを殺すのではない。

その夜にほどけかけた意味を、もう一度固定する。

```txt
アサの名前はまた空白に見える
ナギの箱はまた開けるなに戻る
ミチルの切符はまた片道に見える
トモリの灯りはまた待ちぼうけに見える
```

つまり敗北は、意味が戻ることではなく、**誤解が固定し直されること**。

---

# 11. ゲームオーバーとプレイヤー知識

重要。

ユイは忘れる。

プレイヤーは覚えている。

このズレが考察の気持ちよさになる。

```txt
ユイはまた空白名札を見る。
でもプレイヤーは、その裏に書き直し跡があることを知っている。
```

このため、リトライは単なるやり直しではなく、プレイヤーの読みが深くなる行為になる。

---

# 12. 高難度失敗の扱い

高難度では、ゲームオーバー時に不完全な痕跡を残してもよい。

例:

```txt
未確定の一文だけ地図帳に残る
敵の名前だけ図鑑に残る
拾った小物のシルエットだけ残る
```

ただし、恒久成長にしすぎると緊張感が消える。

残すのは“知識”に近いものがよい。

---

# 13. シリーズ伏線としてのゲームオーバー

ゲームオーバー画面にも、シリーズSeedを置ける。

例:

```txt
ページが閉じる時、違う折り目が一瞬見える
リトライ時、知らない筆跡のしおりが挟まっている
灯りが消える直前、影がユイを攻撃せず何かを隠す動きをする
```

これは、後作で意味が変わる。

---

# 14. 採用/保留/却下

## 採用

```txt
ゲームオーバー = その夜の仮接続が黒インクに固定し直される
再戦 = 未確定ページを別の読み順で開く
その場復活 = ランタンの残り火が一度だけ仮接続を保つ
リトライ = 死亡ではなく読み直し
ユイは忘れるがプレイヤーは覚えている
```

## 保留

```txt
ゲームオーバーで小さな恒久知識が残る
失敗回数で敵の説明文が変化する
失敗時だけ見える隠し筆跡
```

## 却下

```txt
ユイが死んで蘇る
時間を完全に巻き戻す
無限復活
死ぬほど正しい場所へ近づく
ゲームオーバーを救済として扱う
```

---

# 15. 最重要

ゲームオーバーは敗北だが、無意味ではない。

```txt
その読み方では朝まで残れなかった。
だから、別の読み方で夜を開き直す。
```

これがVamp Ponの再戦理由。

## 2. 現在の物語方向

- 世界は暗いが、人間の性格は明暗を揃えない
- 全員がその人らしいまま成長する群像劇
- 仲間を戦闘へ呼び、一緒に戦うことでBondが育つ
- Bondは日常会、呼び方、敬語、連携、灯合わせへ返る
- 人物の秘密はCharacter Mysteryとして個別に持つ
- 世界そのものの真相はMain Mysteryとして本編を引っ張る
- 人物謎を100%解かなくても本編は理解・クリアできる
- 人物謎を深掘るほどMain Mysteryの見え方が深くなる
- 本編正史はハッピーエンド
- 泣き要素は永久死ではなく、別れ・記憶・日常・成長・再会から作る
- 1は完結させた上で、2の一段上の問いを残せる

## 3. 今は固定しない大きな答え

- 夜の正体が夢 / 仮想空間 / 共有記憶のどれか
- 誰が夜を作ったか
- なぜ夜が必要だったか
- ユイとトモリの獅子座共有の真相
- 続編の主人公
- 続編の舞台
- cliffhangerの最終案

これらは伏線整合とゲーム規模を見ながら決める。

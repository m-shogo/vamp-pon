# Constellation Story Clue Reservoir v1

Status: **AUTHOR RESERVOIR / RESEARCH-BACKED / NON-CANON / 8 CLUES**

## Purpose

星座史researchを「面白い雑学」で終わらせず、ヨルノシルベのScene・Memory・Character・Archiveへ接続できる候補として整理する。

Research authority:

- `docs/research/constellation-history-usable-v1.md`
- `src/game/data/constellationHistoryResearch.ts`

This reservoir does **not** promote any clue into Canon.

## Hard historical boundary

Current Core5のTomoriはpostwar laneなので、

**Tomoriの現役時代の公式IAU 88星座一覧とPresent Yuiの公式一覧が年代だけで違う、という仕掛けは使わない。**

時代差を作る場合は、古い星図・名前の化石・historical restructuringなど実際に変化した層へ置く。

## Eight clue candidates

### S1 — Quadrantid name fossil

Historical mechanism:

`Quadrans Muralis` is absent from the modern 88 while `Quadrantids / しぶんぎ座流星群` preserves the old name.

Scene direction:

現代の「しぶんぎ座流星群」という普通の言葉から、古い星図のQuadrans Muralisへ逆向きに辿る。

Why strong:

- Core5年代変更不要
- audienceが理解しやすい
- Memory fossil themeに直結
- `名前は残る / 形は公式地図から消える` が一文で伝わる

Character hooks:

Shiro / Yui / Nagi candidate.

### S2 — Tomori inherited old atlas

Historical mechanism:

違うのはTomoriのReality年代のofficial listではなく、**Tomoriが受け継いださらに古い資料のpublication era**。

Scene direction:

修理跡のある古星図にobsolete constellationsが描かれている。modern guideと並べると星そのものではなく分類が違う。

Why strong:

- Tomoriのordinary-life/lived-artifactへ接続できる
- physical propとして記憶を時代越しに運べる
- obsolete constellationを複数発見する入口になる

Before Canon:

選ぶ実在atlas / edition / 日本へ渡る経路のplausibilityを別途確認する。

### A1 — Argo Navis one → many

Historical mechanism:

一つのhistorical constellation identityがmodern systemでは複数のconstellation identitiesへ再編される。

Story echo:

- copy / instance
- twins
- one identity vs multiple recognized units
- same physical lights, different identity boundary

Character hooks:

Rum / Noa / Kai / Nao / Asa candidate.

Important:

これをRobot/Twinのpersonhood結論へ自動変換しない。

### A2 — Machina Electrica era mirror

Historical mechanism:

過去の人間も、その時代のTechnologyを空の図像へ投影した。

Story echo:

Future societyだけが「機械的」「神話から外れた」わけではない。Humanは昔から自分の時代を星空へ書き込む。

Character hooks:

Asa / Noa / Rum candidate.

Important:

artificial bodyだからmachine constellation assigned、にはしない。

### A3 — Officina Typographica / record medium

Historical mechanism:

記録・印刷Technologyをsky taxonomyへ持ち込むhistorical example。

Story echo:

記録媒体を残しても、**その記録を分類する体系まで永遠とは限らない**。

Character hooks:

Shiro / Kuroori candidate.

### A4 — Robur Carolinum / authority map

Historical mechanism:

constellation naming can reflect Human patronage/power/history.

Story echo:

Official mapは自然そのものではなく、人間のAuthority documentでもある。

Canon / Candidate / Authorityという作者側の構造とも意味的に響く。

Character hooks:

Nagi / Kuroori / Ren candidate.

Important:

`historical political naming = corruption`へ単純化しない。

### B1 — Antinous absorbed figure

Historical mechanism:

historical standalone figure-nameがmodern 88では独立constellationとして残らず、同じstar fieldがlarger accepted regionで読まれる。

Story echo:

名前がなくなることと、物理的な光がなくなることは別。

Important:

historical/cultural contextが重いので、source-specific review必須。

### B2 — Felis secret archive

Historical mechanism:

modern 88には残らないcat constellation image。

Story use:

Audienceへobsolete constellationという概念を低負荷で教えるArchive clue。

Character hooks:

Yomo / Kuu / Koyori candidate.

Important:

`cat character = cat constellation owner`にはしない。

## Character-hook rule

`characterHooks` means:

**「そのCharacterのScene/themeで検討すると意味が響きやすい」**

It does not mean:

- Canon ownership
- zodiac assignment
- Star Beast assignment
- boss pair
- romance/relationship implication
- fate

## Evidence gate before Canon

Each clue includes `requiredEvidenceBeforeCanon`.

Typical requirements:

- exact creator/date/source verification
- atlas-specific appearance
- modern naming authority
- Japanese translation/naming check
- cultural/history sensitivity review
- physical provenance plausibility
- image-rights path if an actual historic plate is reproduced

A high story rank does not bypass evidence.

## Merch rule

Recommended split remains:

### Main Character identity

Stable modern/current or explicitly fictional motif.

### Historical constellation layer

- Archive
- Mystery clue
- Secret collection
- optional 外典星座 side
- book/atlas prop

This prevents Character merchandise identity from changing every time historical sky research gets deeper.

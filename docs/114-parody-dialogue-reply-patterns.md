# Parody Dialogue Reply Patterns

Vamp Pon / ヴァンサバ改で、映画・漫画・アニメ・ゲームが好きな人に刺さる「名台詞っぽい掛け合い」「パロディの気持ちよさ」を、商用で危なくなりにくい形へ変換するための正本候補。

---

## 1. 目的

```txt
パロディは入れる。
名台詞の気持ちよさも入れる。
ただし、台詞そのもの・固有名詞・有名構文の薄い改変は避ける。

Vamp Ponでは、パロディを「引用」ではなく「返信反応の構造」として使う。
```

目標:

```txt
元ネタ好きはニヤッとする。
知らない人にも普通に良い会話として読める。
Vamp Ponの夜・記憶・忘れ物・黒耀・朝に合う。
きもすぎない。
商用で危ない線を踏みにくい。
```

---

## 2. 最重要判断

### 直接使わない

```txt
I love you.
I know.
```

これは短いが、セットで使うと有名すぎる。
商用UIでそのまま出すのは避ける。

### 使うべきもの

この掛け合いの構造。

```txt
まっすぐな感情
↓
照れ隠し・確信・軽口で返す
↓
でも関係性は深く見える
```

Vamp Pon変換:

```txt
灯りを消さないで。

消せるなら、もう消してる。
— アサ
```

```txt
帰ってきて。

道があればね。
— クロエ
```

```txt
忘れないで。

忘れ物のほうが、私を覚えてる。
— ユイ
```

これなら、名台詞の「短い返しで関係性が見える」良さだけを使える。

---

## 3. パロディ安全度

### Green / 安全寄り

```txt
一般ことわざ・慣用句へのキャラ返信
古典引用へのキャラ返信
ジャンルあるあるへの返信
短い会話構造の変換
映画的な皮肉・軽口の新規作成
```

### Yellow / 注意して使える

```txt
有名作品を思わせる感情構造
「愛してる → 知ってる」系の会話構造
変身もの・少年漫画・冒険映画の構造
月・星・名前・約束など、一般モチーフの再構成
```

### Red / 避ける

```txt
有名台詞をそのまま使う
有名台詞の単語を少し変えるだけ
固有名詞・技名・作品名のもじり
作品特有の決め台詞構文をそのまま使う
```

---

## 4. 「月に代わって」問題

「月に代わって〜」は、Vamp Ponの世界観に合う。
月・星・夜・灯りの作品なので、完全禁止にする必要はない。

ただし、商用UIで有名構文として見える形は避ける。

### 避ける

```txt
月に代わって、忘れ物をほどく。
星に代わって、夜を照らす。
灯りに代わって、おしおき。
```

### 使える方向

```txt
月がいない夜は、私が少しだけ代わる。
— ユイ
```

```txt
月のかわりなんて、荷が重いよ。
— ハク
```

```txt
月が見てないなら、星に聞こう。
— ナギ
```

```txt
月のかわりに鳴るには、少し静かすぎる。
— スズ
```

ポイント:

```txt
「月に代わって」という決め台詞構文を避ける。
月の不在・代理・荷の重さとしてVamp Pon化する。
```

## 5. 掛け合いパターン集

### Pattern 01: Straight feeling / Dry reply

名作映画的な「まっすぐな言葉に、照れ隠しで返す」型。

```txt
Don't leave the light.

I was not planning to. It is still warm.
— ユイ / Yui
```

```txt
灯りから離れないで。

そのつもりはないよ。まだ、あたたかいから。
— ユイ
```

```txt
Come back.

Give me a road first.
— クロエ / Chloe
```

```txt
帰ってきて。

先に道をちょうだい。
— クロエ
```

```txt
I believe in you.

That sounds dangerous. Thank you.
— ハク / Haku
```

```txt
信じてる。

それ、ちょっと怖いね。ありがとう。
— ハク
```

---

### Pattern 02: I know structure / Vamp Pon conversion

「分かっている」と返す型。
直接 `I know.` とは言わない。

```txt
You always come back for lost things.

They keep looking at me first.
— ユイ / Yui
```

```txt
君はいつも忘れ物を迎えに行くね。

向こうが先に見てくるんだよ。
— ユイ
```

```txt
You are burning again.

Then I am still here.
— アサ / Asa
```

```txt
また焦げてるよ。

じゃあ、まだここにいる。
— アサ
```

```txt
You are lost.

Correct. That is how maps begin.
— ナギ / Nagi
```

```txt
迷ってるよ。

正解。地図はそこから始まる。
— ナギ
```

```txt
Your bell is not ringing.

It is listening first.
— スズ / Suzu
```

```txt
鈴、鳴ってないよ。

先に聞いてるだけ。
— スズ
```

### Pattern 03: Hero line deflated

少年漫画・ヒーロー台詞を、Vamp Ponの弱さに落とす型。

```txt
Are you the chosen one?

No. I was the one still holding the bag.
— セナ / Sena
```

```txt
選ばれたの？

違う。荷物をまだ持ってただけ。
— セナ
```

```txt
Will you save everyone?

I can start with one forgotten thing.
— ユイ / Yui
```

```txt
みんなを救うの？

まずは、忘れ物ひとつから。
— ユイ
```

```txt
Is this your final form?

I hope not. It hurts.
— アサ / Asa
```

```txt
それが最後の姿？

違うといいな。痛いから。
— アサ
```

```txt
Did you awaken?

No. I just did not break before morning.
— ハク / Haku
```

```txt
覚醒したの？

違う。朝まで壊れなかっただけ。
— ハク
```


```txt
Will the stars punish the dark?

```

```txt
星は夜を叱るの？

それより、どうして寂しくなったのか聞きたい。

```

```txt
Do you transform when the light changes?

I mostly panic politely.
— コハル / Koharu
```

```txt
光が変わると変身するの？

だいたい礼儀正しく慌てる。
— コハル
```

```txt

No. The bell is shy.
```

```txt

無理。鈴が照れてる。
— スズ
```

### Pattern 05: Adventure movie banter

海外映画っぽい軽口。
状況が重いほど、少しだけ軽く返す。

```txt
This path looks safe.

That is what unsafe paths wear.
— イオリ / Iori
```

```txt
この道、安全そう。

危ない道は、そういう顔をする。
— イオリ
```

```txt
How hard can it be?

Never ask a night that question.
— クロエ / Chloe
```

```txt
そんなに難しくないでしょ。

夜にその質問をしないで。
— クロエ
```

```txt
We have a plan, right?

We have a direction. It is shorter.
— ナギ / Nagi
```

```txt
作戦あるよね？

方角ならある。作戦より短い。
— ナギ
```

```txt
Can you fix it?

I can make it less dramatic.
— トモリ / Tomori
```

```txt
直せる？

少しだけ大げさじゃなくできる。
— トモリ
```

### Pattern 06: Anime friendship without direct copy

仲間・名前・迎えに来る感情を使う。
有名構文は避ける。

```txt
If I call your name, will you come back?

Call twice. I am far today.
— シノ / Shino
```

```txt
名前を呼んだら、戻ってくる？

今日は遠いから、二回呼んで。
— シノ
```

```txt
You do not have to carry it alone.

I know. I am just bad at putting it down.
— セナ / Sena
```

```txt
ひとりで持たなくていいよ。

分かってる。置くのが下手なだけ。
— セナ
```

```txt
We are with you.

Then please walk where I can hear you.
— リツ / Ritsu
```

```txt
一緒にいるよ。

じゃあ、聞こえる場所を歩いて。
— リツ
```

```txt
You can cry.

I am water. That makes it complicated.
— ミチル / Michiru
```

```txt
泣いていいよ。

水だから、ちょっとややこしい。
— ミチル
```

## 7. きもすぎないための制限

```txt
1. 元ネタを説明しない。
2. パロディを連発しない。
3. シリアス直後に寒い軽口を入れすぎない。
4. キャラをバカにしない。
5. 返信は1〜2行まで。
6. 英語返信は短く、映画の掛け合い程度にする。
7. 日本語返信は翻訳調にしすぎない。
```

表示比率:

```txt
Serious literary quote: 40%
English proverb / idiom: 25%
Vamp Pon original line: 20%
Parody dialogue reply: 15%
```

パロは多めに持っておくが、表示頻度は15%程度から始める。

## 9. 最終方針

```txt
「I love you / I know」そのものは使わない。
でも、あの短い掛け合いの気持ちよさは使う。

強い感情に、照れ隠し・確信・軽口で返す。
それをVamp Ponの夜・灯り・忘れ物・名前・星に変換する。
```

パロディはこう使う:

```txt
元ネタを当てさせるためではなく、
キャラ同士の距離を一瞬で見せるために使う。
```

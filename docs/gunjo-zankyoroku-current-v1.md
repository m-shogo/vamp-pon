# 2. Definition

> **各時代の大事件で中心となった人物 / 人物群を、事件後の記録・観測・シリーズ構造上から一つの名称で括ったもの。**

「本人たちが群青残響録を名乗って集まった」という意味ではない。

---

# 3. Fixed boss slot is forbidden

群青残響録について固定しない:

- 1時代1人
- 5人固定
- 全員戦闘Boss
- 全員敵
- 全員事件主犯
- 全員同じ組織
- 全員同じSpecies
- 全員互いを知っている
- 全員最後に倒される

各時代の大事件は:

### Pattern A — one central person

一人の判断が事件へ強く影響する。

### Pattern B — multiple central people

複数人物の別々の判断が噛み合い事件になる。

### Pattern C — institution / system

制度 / 企業 / 軍 / 行政 / network / algorithm等が中心で、一人を倒しても解決しない。

### Pattern D — social pressure

群衆心理 / 情報環境 / 恐怖 / 利害が積み重なり、明確な一人のBossがいない。

### Pattern E — Sakuyaza entanglement

朔夜座memberが協力 / 利用 / 対立 / 妨害 / 制止等で強く関与する。

これらをEraごとに変える。

---

# 4. 「中心人物」の意味

中心人物 = 一番悪い人、ではない。

以下のどれかを持つ人物を後からrecord上で中心とみなせる。

- 決定権を持っていた
- 最初に案を出した
- 止められたが止めなかった
- 誰かを守るために極端な策を選んだ
- 制度を作った
- 誤情報を信じた
- 正しい情報を持っていたが黙った
- 利益を選んだ
- 恐怖に負けた
- 最後に第三の選択へ踏み出した

**理解できることと免罪は別。**

---

# 5. Black Youkaとの構造対応

個人:

```txt
長所 / 願い
+
恐怖 / 焦り
→ 一つの答えへ極端化
→ 黒耀化
```

社会:

```txt
理想 / 保護 / 発展
+
恐れ / 利害 / 制度
→ 一つの解決策へ固執
→ 大事件
```

群青残響録の人物を「悪の能力者」に揃えるのではなく、**社会版のwrong arrivalへどの位置で関与したか**を人物ごとに変える。

---

# 9. Combat structure is separate

大事件centerとcombat encounterを分ける。

Example:

```txt
Incident central person
≠
Stage combat Boss
```

同じ人物になることは可能だが必須ではない。

Gameplay上のBossは:

- 朔夜座member
- Dream phenomenon
- Enemy48上位体
- incident-generated symbolic threat
- central person

などから、遊びとして最も強いものを選べる。

Story側は「Bossを倒したので社会問題解決」にしない。

---

# 10. Record ambiguity

群青残響録は神視点の完全名簿ではない方向が相性良い。

Candidate:

- 資料によって誰を中心人物と呼ぶか違う
- 後の時代に評価が変わる
- 一人が消されている
- 一人だと思われていたが複数だった

ただし「何でも不明」で逃げない。

Title内C-grade factは明確に払う。

# Weapon and Stat Visual Feedback Spec

## 目的

武器、技、パッシブ、ステータス強化が、プレイヤーに分かりやすく伝わるようにする。

Vamp Ponでは、強化を数字だけで終わらせない。

```txt
選んだものがキャラや画面に反映される
強くなった理由が見える
次の選択が理解しやすい
```

---

# 1. 基本方針

## 見える化するもの

- 武器取得
- 武器Lvアップ
- パッシブ取得
- ステータス上昇
- 進化
- 必殺技チャージ

## 見える化しすぎないもの

- 小さすぎる倍率差
- 内部補正
- すべての細かい数値

---

# 2. 武器の見える化

## 夜の鉛筆

役割:

```txt
基本の直線弾
```

見た目変化:

- Lv1: 小さい金色の線
- Lv2: 少し長く/明るく
- Lv3以降: 弾数/発射頻度で体感
- 進化: 一行のような光跡

Prototype 1:

```txt
Lv2で弾の明るさか発射間隔を少し変える
```

## ビー玉

見た目:

- 反射する丸い光
- 壁や敵で跳ねる印象

## 月のしおり

見た目:

- ユイの周囲を回る紙片/しおり
- 防御武器だと分かる

## 黒インクの小瓶

見た目:

- 地面に小さなインクだまり
- 範囲攻撃だと分かる

## 星くず弾

見た目:

- 小さい星がばらまかれる
- 弾数の増加が見える

---

# 3. パッシブの見える化

## 金のコンパス: 吸引範囲

見える化:

- 欠片が遠くから寄る
- レベルアップ時に一瞬だけ薄い円を表示

## 旅のバッジ: 攻撃力

見える化:

- ヒット時の光が少し強くなる
- ダメージ数字を入れるなら少し大きくなる

## 月明かりのしおり: 経験値

見える化:

- 欠片取得時のXPゲージ増加が少し大きい
- 欠片取得エフェクトが少し明るい

## 古い切符: 移動速度

見える化:

- ユイの足元に短い軌跡
- 速度UP直後に1秒だけ分かる

## 白い余白: クールタイム短縮

見える化:

- 武器の発射間隔が短くなる
- UIに小さな時計/余白アイコン

---

# 4. キャラへの反映

## Prototype 1

最小:

- ユイのランタン光
- Lv2時に一瞬光る

## Prototype 2

武器/パッシブの取得を小さく反映。

例:

- 月のしおり取得で周囲に紙片が回る
- 金のコンパス取得で小さいコンパス光
- 古い切符取得で足元の小さな切符軌跡

## Prototype 3

進化/必殺技を反映。

- 進化武器は明確に見た目が変わる
- 必殺技チャージ中は右下ボタンが育つ
- 発動時はユイ中心の光

---

# 5. UIでの分かりやすさ

## レベルアップカード

必須:

- 名前
- アイコン
- 効果短文
- 今のLv/次のLv

説明文は2行以内。

悪い例:

```txt
一定時間ごとに周囲に特殊な魔法効果を発生させ敵に継続ダメージを与える
```

良い例:

```txt
周囲にしおりが回る
近くの影を払う
```

---

# 6. ステータス表示

Prototype 1では不要。

Prototype 2以降、必要なら簡易表示。

表示候補:

- 攻撃力
- 吸引範囲
- 移動速度
- クールタイム
- 経験値倍率

ただし常時詳細表示はしない。

見るならPause/Resultでよい。

---

# 7. 進化の見える化

進化は大きなご褒美。

やる:

- カプセル取得
- 条件達成
- 一瞬の停止
- 武器名変化
- 見た目変化
- リザルト記録

やらない:

- 長すぎる演出
- 何が進化したか分からない演出

---

# 8. 必殺技の見える化

必殺技「消えない名前」は、いつ使えるか分かる必要がある。

UI:

- 右下ボタン
- チャージリング
- 満タン時に暖色発光

発動:

- ユイ中心の光
- 欠片吸引
- 小型影の変化
- 画面が少し明るくなる

---

# 9. NG

- 数字だけで強化を伝える
- 何を取ったか忘れる
- カード文が長い
- エフェクトで敵が見えない
- 全強化をキャラに乗せてゴチャつく

---

# 最重要

強化は、選んだ瞬間とプレイ中の両方で分かるようにする。

```txt
選んだ → 見た目が変わる → 手触りが変わる
```

この線を作る。

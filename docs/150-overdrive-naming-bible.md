# Overdrive Naming Bible

## 目的

旧称「暴走モード」を、Vamp Pon の世界観に合う名前へ置き換える。

この文書は、システム共通名・ユイ専用名・キャラ別派生名・UI表記・ストーリー上の意味を固定するための設計メモ。

---

# 0. 結論

## 旧称

```txt
暴走モード
```

これは直球すぎる。
Vamp Pon の紙片・夜・記憶・黒インク・小さな光の世界観には少し合わない。

## 共通システム名

```txt
黒耀化
読み: こくようか
```

意味:

```txt
それぞれの中にある“光るもの”が、黒インクに飲まれ、黒曜石のように黒く艶を持って輝く状態。
```

「灯」はユイ専用。
共通では「耀」を使う。

## ユイ専用名

```txt
黒灯化
読み: こくとうか
```

ユイはランタンと灯りが専用モチーフなので、黒灯化はユイ専用名にする。

---

# 1. 共通名候補の決定

## 採用: 黒耀化

```txt
黒 + 耀
```

採用理由:

```txt
黒曜石のような艶と硬さがある。
黒インクが光を飲み込んで、逆に黒く輝くイメージが出る。
“灯”を使わないので、ユイのランタン専用性を守れる。
黒いのに美しい、怖いのに完全な悪ではない、というニュアンスが出る。
```

## 不採用: 黒輝化

```txt
黒 + 輝
```

不採用理由:

```txt
共通名としては分かりやすいが、少し普通。
黒耀化の方が黒曜石・黒インク・艶のニュアンスが強い。
```

## その他候補

| 候補 | 読み | 評価 |
|---|---|---|
| 黒輝化 | こっきか / くろきか | 分かりやすいが普通寄り |
| 黒耀化 | こくようか | 採用。黒曜石の艶、黒インクの美しさが出る |
| 黒煌化 | こっこうか | 派手だが厨二感が強い |
| 黒光化 | こっこうか / くろびかりか | 黒光りに聞こえる危険 |
| 影輝化 | えいきか | 説明的 |
| 夜輝化 | やきか | 優しいが黒インク感が弱い |
| 黒明化 | こくめいか | 意味は良いが読みにくい |
| 墨耀化 | すみようか | 紙・インク感はあるが音が少し弱い |

# 3. Core5 キャラ別名称

## ユイ

```txt
固有名: 黒灯化
読み: こくとうか
```

意味:

```txt
ランタンの灯りが黒インクに飲まれ、黒い灯りとして反転する。
道を照らす力が強くなるが、照らしすぎた記憶が自分にも流れ込む。
```

演出:

```txt
ランタンの炎が黒くなる
周囲の紙片が浮く
ユイの目は怖くしすぎない
黒い影炎は背中側に出る
UI表示は黒灯化
```

## アサ

```txt
固有名: 黒風化
読み: こくふうか
```

意味:

```txt
届けるための風が、黒インクを巻き込んで速く荒れる。
届く力は強くなるが、宛先を間違える危うさが出る。
```

演出:

```txt
紙飛行機が黒い尾を引く
マフラーが強くなびく
敵を貫通する線が鋭くなる
```

## ナギ

```txt
固有名: 黒雨化
読み: こくうか / くろあめか
```

意味:

```txt
守るための雨が黒くなり、敵を遅らせる力が強くなる。
ただし、守りすぎて記憶を閉じ込める危うさが出る。
```

演出:

```txt
水滴が黒い雨粒になる
足元に黒い波紋
箱の輪郭が一瞬だけ見える
```

## ミチル

```txt
固有名: 黒針化
読み: こくしんか
```

意味:

```txt
コンパスの針が黒く震え、正しい道だけでなく、間違った道も強制的に示してしまう状態。
誘導力は増すが、制御を誤ると危ない。
```

演出:

```txt
コンパス針が高速回転
地面に黒い方位線
敵が線に引き寄せられる
```

## トモリ

```txt
固有名: 黒火化
読み: こっか / くろびか
```

意味:

```txt
記録を残す火が黒くなり、消える前に強く焼き付ける。
火力は上がるが、燃やしすぎる危うさがある。
```

演出:

```txt
マッチの火が黒赤くなる
日記ページの焦げ跡が広がる
爆発のあとに黒い紙灰が舞う
```

# 5. 命名の注意

## 使わない方がいい名前

```txt
暴走モード
バーサーク
覚醒モード
闇落ち
黒化
狂化
```

理由:

```txt
直球すぎる
世界観が安く見える
敵と味方の境界が雑になる
ハッピーエンドに戻しにくい
```

## 使ってよいニュアンス

```txt
反転
侵食
にじみ
黒く耀く
強くなるが反動がある
完全な悪ではない
```

# 6. ストーリー上の意味

黒耀化は、悪の力ではない。

```txt
忘れ物に触れすぎたキャラの中で、記憶の光る核が黒インクに反転し、黒曜石のような艶を持って耀く現象。
```

強くなる理由:

```txt
敵の記憶まで一時的に読めてしまうから。
```

反動がある理由:

```txt
自分の記憶ではないものまで体に流れ込むから。
```

ハッピーエンドへの接続:

```txt
黒くなった耀きも、完全に悪ではない。
正しく受け止められれば、朝へ返す力になる。
```

# 8. 最終固定

```txt
共通システム名: 黒耀化
読み: こくようか
共通ゲージ名: 黒耀ゲージ
ユイ固有名: 黒灯化
```

理由:

```txt
灯はユイ専用として守れる。
耀なら全キャラ共通の“光るもの”を含められる。
黒曜石のような艶と、黒インクの反転が伝わる。
暴走より世界観に合う。
```

# Overdrive Naming Bible

## 目的

旧称「暴走モード」を、Vamp Pon の世界観に合う名前へ置き換える。

この文書は、システム共通名・ユイ専用名・キャラ別派生名・UI表記・ストーリー上の意味を固定するための設計メモ。

---

# 0. 結論

## 旧称

```txt
暴走モード
```

これは直球すぎる。
Vamp Pon の紙片・夜・記憶・黒インク・小さな光の世界観には少し合わない。

## ユイ専用名

```txt
黒灯化
読み: こくとうか
```

ユイはランタンと灯りが専用モチーフなので、黒灯化はユイ専用名にする。

## 共通システム名の本命

```txt
黒輝化
読み: こっきか / くろきか
```

意味:

```txt
それぞれの中にある“輝き”が、黒インクで反転して強く光る状態。
```

「灯」はユイ専用。
共通では「輝」を使う。

# 2. 共通名のおすすめ順位

## 1位: 黒輝化

```txt
黒 + 輝
```

灯ではなく、輝き全般。

ユイのランタン、アサの朝焼け、ナギの水面反射、ミチルのコンパス反射、トモリの火花、すべてを含められる。

UIにも使いやすい。

```txt
黒輝ゲージ
黒輝化
黒輝反動
黒輝終了
```

## 2位: 黒耀化

```txt
黒 + 耀
```

黒曜石のような艶と硬さ。
黒インクが光を飲み込んで、逆に黒く輝くイメージ。

やや高級感がある。

## 3位: 夜輝化

```txt
夜 + 輝
```

怖すぎず、Vamp Pon の夜と朝のテーマに合う。
ただし黒インクの侵食感は弱い。

# 4. Core5 キャラ別名称

## ユイ

```txt
固有名: 黒灯化
読み: こくとうか
```

意味:

```txt
ランタンの灯りが黒インクに飲まれ、黒い灯りとして反転する。
道を照らす力が強くなるが、照らしすぎた記憶が自分にも流れ込む。
```

演出:

```txt
ランタンの炎が黒くなる
周囲の紙片が浮く
ユイの目は怖くしすぎない
黒い影炎は背中側に出る
```

## アサ

```txt
固有名: 黒風化
読み: こくふうか
```

意味:

```txt
届けるための風が、黒インクを巻き込んで速く荒れる。
届く力は強くなるが、宛先を間違える危うさが出る。
```

演出:

```txt
紙飛行機が黒い尾を引く
マフラーが強くなびく
敵を貫通する線が鋭くなる
```

## ナギ

```txt
固有名: 黒雨化
読み: こくうか / くろあめか
```

意味:

```txt
守るための雨が黒くなり、敵を遅らせる力が強くなる。
ただし、守りすぎて記憶を閉じ込める危うさが出る。
```

演出:

```txt
水滴が黒い雨粒になる
足元に黒い波紋
箱の輪郭が一瞬だけ見える
```

## ミチル

```txt
固有名: 黒針化
読み: こくしんか
```

意味:

```txt
コンパスの針が黒く震え、正しい道だけでなく、間違った道も強制的に示してしまう状態。
誘導力は増すが、制御を誤ると危ない。
```

演出:

```txt
コンパス針が高速回転
地面に黒い方位線
敵が線に引き寄せられる
```

## トモリ

```txt
固有名: 黒火化
読み: こっか / くろびか
```

意味:

```txt
記録を残す火が黒くなり、消える前に強く焼き付ける。
火力は上がるが、燃やしすぎる危うさがある。
```

演出:

```txt
マッチの火が黒赤くなる
日記ページの焦げ跡が広がる
爆発のあとに黒い紙灰が舞う
```

# 6. 命名の注意

## 使わない方がいい名前

```txt
暴走モード
バーサーク
覚醒モード
闇落ち
黒化
狂化
```

理由:

```txt
直球すぎる
世界観が安く見える
敵と味方の境界が雑になる
ハッピーエンドに戻しにくい
```

## 使ってよいニュアンス

```txt
反転
侵食
にじみ
黒く輝く
強くなるが反動がある
完全な悪ではない
```

# 7. ストーリー上の意味

黒輝化は、悪の力ではない。

```txt
忘れ物に触れすぎたキャラの中で、記憶の輝きが黒インクに反転する現象。
```

強くなる理由:

```txt
敵の記憶まで一時的に読めてしまうから。
```

反動がある理由:

```txt
自分の記憶ではないものまで体に流れ込むから。
```

ハッピーエンドへの接続:

```txt
黒くなった輝きも、完全に悪ではない。
正しく受け止められれば、朝へ返す力になる。
```

# 9. 最終推奨

```txt
共通システム名: 黒輝化
共通ゲージ名: 黒輝ゲージ
ユイ固有名: 黒灯化
```

理由:

```txt
灯はユイ専用として守れる。
輝なら全キャラ共通の“光るもの”を含められる。
黒インクと光の反転が伝わる。
暴走より世界観に合う。
```

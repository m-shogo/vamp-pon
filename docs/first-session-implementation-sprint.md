# 初回セッション実装スプリント

`docs/first-session-retention-design.md` を実装へ落とすためのスプリント計画。
目的は、Stage1初回プレイで「10秒で分かる / 1分で育つ / 3分で変わる / 8分で残る」を実画面で成立させること。

この文書は実装データを直接変更しない。Codexへ渡す時の作業順と合格条件として使う。

## 前提

- 対象は `/Users/m-shogo/Developer/personal/vamp-pon` のみ。
- 390x844縦画面基準。
- Stage1初回プレイを最優先する。
- キャラ追加、敵大量追加、素材大量追加より先に初回体験を固める。
- 初回は少し簡単でよい。
- 説明より体験を優先する。

## スプリント全体のゴール

```txt
0〜10秒: 何をするゲームか分かる
30〜60秒: 初回LevelUpで選べる
1〜3分: 選んだ内容で画面が変わる
3〜5分: 初めて危ないが救済がある
5〜7分: 特別報酬の予告がある
7〜8分: 勝敗に意味がある
Result: 負けても何か残る
Next Action: もう一度押す理由がある
```

## Sprint A: 0〜10秒の理解

### 目的

最初の10秒で、以下をプレイヤーに分からせる。

- 指で動ける。
- 敵が近づく。
- 自動で攻撃する。
- 欠片を集めるゲームらしい。
- 夜とランタンの世界観がある。

### 実装候補

- 初回runだけ、開始直後の敵数を少なめにする。
- 3秒以内に最初のオンブ小を1〜3体だけ出す。
- 初期位置の周囲に逃げ道を残す。
- 自動攻撃が最初の敵に当たりやすいようにする。
- 画面下に短いガイドを一度だけ出す。

### ガイド文候補

```txt
指で歩く
```

または:

```txt
光を消さないで
```

### 合格条件

- 10秒以内に移動、敵、攻撃が分かる。
- 説明を読まなくても動ける。
- 初回から敵が多すぎない。
- ランタン光と夜の雰囲気が見える。

### 失敗条件

- 長い説明が出る。
- 何をしていいか分からない。
- いきなり囲まれる。
- 攻撃が当たらず退屈に見える。

## Sprint B: 10〜60秒の初回LevelUp

### 目的

1分以内に、敵を倒す、欠片を回収する、LevelUpして選ぶ、という基本ループを見せる。

### 実装候補

- 初回runの最初のLevelUp必要XPを少し低くする。
- 最初の敵は倒しやすくする。
- 初回だけXP回収が気持ちよく見えるようにする。
- 50〜60秒までにLevelUpしない場合は、XP量や必要量を調整する。

### 初回カード候補

| Slot | 候補 | 理由 |
|---:|---|---|
| 1 | 夜の鉛筆 Lv2 | 初期武器が強くなるので分かりやすい |
| 2 | あったか靴 Lv1 | 移動が軽くなり体感がある |
| 3 | 黒インクの小瓶 Lv1 | 新しい攻撃が増える |

### 初回カードで避けるもの

- 条件未達の覚醒素材。
- 説明の長いレア。
- 数字だけの効果。
- 似た効果3枚。

### 合格条件

- 初回LevelUpが60秒以内に起きる。
- カード3枚が読める。
- 選んだ後に少し強くなったと分かる。
- 選択肢が3種類の方向性を持つ。

## Sprint C: 1〜3分のビルド差

### 目的

3分までに、選択で画面や操作感が変わったことを見せる。

### 実装候補

#### 夜の鉛筆を選んだ場合

- 攻撃頻度を少し上げる。
- 線のエフェクトを少し太くする。
- 敵に当たった時の反応を少し分かりやすくする。

#### あったか靴を選んだ場合

- 移動速度の変化を体感できる値にする。
- カード選択後に短い足元の暖色演出を出す。
- 逃げやすさが分かる場面を作る。

#### 黒インクの小瓶を選んだ場合

- 小さな範囲攻撃を見せる。
- 毒瓶に見えないよう、インクの跳ね/紙の染みとして見せる。
- 黒い敵と混ざりすぎないよう暖色または紙片を添える。

### 敵の増やし方

- 0〜1分: オンブ小のみ。
- 1〜2分: オンブ小を少し増やす。
- 2〜3分: 紙片影など役割が分かる敵を少しだけ入れる。

### 合格条件

- 3分までに「今回はこの方向で強い」が分かる。
- 画面が変わる。
- 敵の役割差が少し出る。
- 難しくなりすぎない。

## Sprint D: 3〜5分の危機と救済

### 目的

初回runに、適度な危機と、それを越える手段を入れる。

### 実装候補

- 敵密度を少し上げる。
- HPが減った時に回復ドロップを一度見せる。
- 初回だけ黒曜化ゲージをやや溜まりやすくする。
- 逃げ道は必ず残す。
- 敵ダメージは初回だけ抑えめにする。

### 合格条件

- 危ないと分かる。
- 回復や黒曜化に気づける。
- 理不尽に負けない。
- ここで気持ちよく立て直せる。

## Sprint E: 5〜7分の特別報酬予告

### 目的

進化、合体、覚醒、黒曜化のどれかが「あと少しで起きそう」と感じられる状態にする。

### 実装候補

- カードに合体/覚醒候補のヒントを出す。
- `name_tag` は覚醒素材として扱う。
- `dawn_ticket` は復帰/救済レアとして扱い、覚醒素材と混ぜない。
- 黒曜化または必殺のゲージが一度readyに近づく。

### 合格条件

- ただ強くなるだけではなく、特別報酬が近いと分かる。
- 条件が分かりにくすぎない。
- ヒントがカード本文を圧迫しない。

## Sprint F: 7〜8分の山場

### 目的

初回runを、勝っても負けても記憶に残る締めにする。

### 実装候補

- Stage1エリートまたはボス候補を出す。
- 黒インクが少し濃くなる。
- ランタン光が少し強くなる。
- 終了時にResultへつながる記憶演出を入れる。

### 勝利時に見せるもの

- Stage1記憶ページ解放。
- 欠片報酬。
- 新しい図鑑行。
- 次ステージ予告。

### 敗北時に見せるもの

- 到達時間。
- 欠片報酬。
- 敵図鑑進行。
- 永続強化導線。

### 合格条件

- 勝ったら嬉しい。
- 負けても損だけではない。
- 次に届きそうと思える。

## Sprint G: Resultから再挑戦

### 目的

初回run後に「もう一回」を押す理由を作る。

### Result CTA優先順位

初回敗北後:

1. 強くする
2. もう一度
3. 記憶を見る

初回勝利後:

1. 次へ
2. 強くする
3. もう一度

### 表示文候補

敗北時:

```txt
ここまでの灯りは、消えなかった。
```

または:

```txt
拾った欠片は、朝まで残る。
```

勝利時:

```txt
夜道に、ひとつ朝が戻った。
```

### 合格条件

- 残ったものが分かる。
- 強化できることが分かる。
- もう一度押す理由がある。
- Resultがただの数字画面ではない。

## 実装順の推奨

一気に全部やらない。

### Commit 1

- 0〜10秒導線。
- 初回敵数/最初の攻撃/短いガイド。

### Commit 2

- 初回LevelUpを60秒以内へ調整。
- 初回カード候補の整理。

### Commit 3

- 選択後の体感差。
- 夜の鉛筆、あったか靴、黒インクの小瓶の差。

### Commit 4

- 3〜5分の危機と救済。
- 回復ドロップや黒曜化導線。

### Commit 5

- Resultの残るもの表示。
- 強くする→もう一度導線。

### Commit 6

- 7〜8分の山場。
- Stage1締め演出。

## Stop rules

以下の場合は進めず調整する。

- 初回が難しすぎる。
- 初回が退屈すぎる。
- 1分以内にLevelUpしない。
- カードが読めない。
- 選んでも変化がない。
- 負けた時に何が残ったか分からない。
- もう一度押す理由が弱い。

## 最終判断

初回セッション改善は、素材追加より優先度が高い。
プレイヤーが最初の1回で以下を感じれば、次の改善が効く。

```txt
分かった
育った
変わった
惜しかった
残った
もう一回
```

この6つをStage1で成立させる。

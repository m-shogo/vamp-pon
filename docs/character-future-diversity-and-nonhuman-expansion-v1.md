- 南国・砂漠・ダンサー等の単純記号へ寄せる

狙う:

- 社交性が高い
- 笑うのが早い
- 人の好きなものを否定しない
- ただし「場を明るくする人」でい続けようとして、自分の不調を隠す

黒耀化Candidate:

- 手仕事 / 音 / 記録など静かな趣味
- 人の話を最後まで聞く

- 「自分が残らなくても仕事が残ればいい」と考えやすい

人物Theme:

セン / シロ / アサと違う角度で扱える。

# 3. 現実由来の動物2人 — 星獣とは別物

## CURRENT DIRECTION CANDIDATE

ヨルノシルベには星獣がいるため、動物キャラは明確に区別する。

### 星獣

- 人物の自己像 / 共鳴 / 記憶を象徴する存在
- 星座由来
- 現実の普通の動物とは別

### 動物キャラ

- 現実世界で実際に生きていた動物
- 自分自身の経験と関係を持つ
- 誰かのマスコットとしてだけ存在しない

## Candidate A — 犬

Theme:

> **名前を知らなくても、人を覚えている。**

犬は人を:

- 匂い
- 声
- 歩き方
- 手の触れ方
- 帰ってくる時刻

で覚える。

アサの「名前を返す」、ユイの「覚えていたい」に対して:

> 名前を忘れても、覚えている関係はある。

を身体感覚で証明できる。

Gameplay Candidate:

- 記憶片 / 隠し物を匂いで追う
- 画面外の危険を先に察知
- ownerではなくparty全体を守る

喋らせすぎない。
夜が意図を少し翻訳しても、完全に人間の会話能力へしない。

## Candidate B — 猫

Theme:

> **他人が違う名前で呼んでも、自分は自分。**

現実で複数の家 / 人から:

- 別の名前
- 別の呼び方
- 別の「うちの猫」という記憶

を持たれていたCandidate。

アサ:

> 正しい名前を返したい。

猫:

> どれも呼ばれたら行くけど。

という対照が作れる。

カスミの「名前を隠す」とも接続可能。

Gameplay Candidate:

- 狭い抜け道
- pickup steal / redirect
- 攻撃を避ける独特のmovement
- 気まぐれだが高性能なSupport

重要:

> 動物を「人間より純粋で真実を知る存在」にはしない。

動物も間違える、怖がる、好き嫌いがある。

# 4. Robot A — 同じ記憶なら同じ人なのか

## HIGH-VALUE CANDIDATE

仮称: **複製継承型 / Replica Continuity Robot**

問い:

> **同じ知識、同じ記憶、同じ口調、同じ好き嫌いを持って起動した二人は、同じ人なのか。**

### Core setup候補

ある人格 / artificial mind の完全に近いsnapshotがある。

事故・夜の異常・復旧処理などにより、同じsnapshotから**二つのbody**が起動する。

起動直後:

```txt
記憶A = 記憶B
知識A = 知識B
好き嫌いA = 好き嫌いB
自己認識A = 自己認識B
```

二人とも:

> 「私が私です。」

と言える。

どちらかを偽物にしない。

### 物語が始まってから

数分 / 数日 / 数runで経験が分岐する。

- Aはユイと戦った
- Bはクロオリと話した
- Aは犬を怖がるようになった
- Bは犬を好きになった

同じ過去から、違う現在が生まれる。

### 本当に聞きたいこと

- originalとは連続性なのか
- 記憶なのか
- bodyなのか
- 周囲との関係なのか
- 本人が「自分」と感じることなのか

Main Storyで哲学講義はしない。
日常とBattleで見せる。

### 星獣との接続

**答えを出す装置にしない。**

Candidate:

- 最初は星獣が現れない
- あるいは二人の間に一つだけ曖昧な星影が出る
- 後に片方 / 両方へ別々の反応が出る

しかし:

> 星獣が出た = soul / ghost証明

とは断定しない。

誰かがそのRobotを独立した一人として記憶した結果なのかもしれない。

### 黒耀化Candidate

通常:

> 自分が誰かを知りたい。

過剰化:

> **差分を全部消して、唯一の「正しい私」に戻さなければ。**

- 自分とcopyのmemoryを強制merge
- 他者が覚える差分も消す
- body差も同期する

圧倒的に強くなるが、個として生まれた現在を消しかける。

成長後:

> 同じ過去を持っていても、今違う経験をしたなら、どちらも本物。

ただしこれを唯一の哲学的正解として台詞で断言しすぎない。

# 5. Robot B — 共有している私たちは、いつから別々なのか

## HIGH-VALUE CANDIDATE

仮称: **灯守機 / Night Maintenance Unit**

Robot Aと問いを重複させない。

Robot A:

> 同じデータから二人が生まれたらどうなる？

Robot B:

> **最初は「ぼくら」だった存在が、別々の経験を持ったらいつから「ぼく」になる？**

### Visual / personality

人型ではなく、小型の灯り整備Robotを推奨。

- 小さい
- 丸い / 多脚 / wheel等
- 夜のランタンや街灯を直す
- 好奇心旺盛
- analog objectを拾う
- ちょっと生意気
- 戦闘外でもよく動く

タチコマの多脚戦車を直接コピーしない。
ヨルノシルベでは**整備 / 灯り / 紙片**へ置き換える。

### 集合型AI候補

同型機が複数いる。

一定タイミングで:

> memory sync

をする。

最初は全機が自然に:

> 「ぼくら」

と言う。

しかし一体だけ:

- 誰かにもらった呼び名
- 傷
- 手書きの印
- 一緒に見た夜

を同期したくなくなる。

理由:

> 「みんなが知ったら、この思い出はぼくだけのものじゃなくなる？」

### 成長

最初:

> 個性を守るには共有しない方がいい。

途中:

> 全部同期すれば同じになれる。

どちらも極端。

成長後:

> **共有しても、経験した位置・関係・選び方まで完全に同じにはならない。**

というところへ行ける。

攻殻のTachikomaが持つ「共有記憶から個性が立つ」という問いを、ヨルノシルベでは**灯りを直して過ごした関係 / 共有するかしないかの選択**へ独自化する。

### 黒耀化Candidate

通常:

> みんなと繋がっていたい。

過剰化:

> **違いが争いを生むなら、全員を完全同期すればいい。**

Battleでは:

- Support全員のcooldown /状態 / targetを完全同期
- 一時的に極端に強い
- 代わりに個別skillの差や判断を失う

成長後は:

> 必要な情報だけ共有し、個別判断を残す。

Gameplayにも直結する。

# 6. Robot A / Bを二人とも入れる理由

| Robot | 主題 | 感情 |
| --- | --- | --- |
| Replica Continuity | 同じ過去なら同じ人か | 「私の本物はどっち？」 |
| Lamp Maintenance Collective | 同じ集合からどう個が生まれるか | 「ぼくらの中で、ぼくはどこ？」 |

Aは**コピー / continuity**。
Bは**集合 / synchronization / individuality**。

問いが違うので2人とも存在価値がある。

# 7. Sexual orientation — Gay / Lesbian

## USER DIRECTION

ゲイ、レズビアンの人物を将来castへ入れる方向。

基本方針:

- sexual orientationを「設定欄だけ」にしない
- しかし全Storyを差別 / coming-out問題だけにもしない
- 恋愛以外の友情 /仕事 /好物 /黒耀化 /Gameplay identityを先に持つ
- 異性愛だけが「普通の日常」、同性恋愛だけが「重い社会問題」にならないようにする

### 強い使い方候補1 — 時代差

別時代の人物だから、同性関係の扱われ方 / 呼ばれ方 / 記録のされ方が違う。

例えば過去側の男性が、人生で最も大切だった男性との関係を:

> 親友

としか公的記録に残されていない。

本人は:

> 「友達だったよ。恋人でもあった。」

と普通に言う。

ここでThemeは:

> **他人が付けた名前だけが、その関係の真実か。**

となり、アサ / カスミ / 記録Themeへ接続できる。

ただし悲恋しか与えないのは避ける。
幸せだった時間、冗談、喧嘩、生活も同じだけ残す。

### 強い使い方候補2 — 現代 / 未来側

別のレズビアン人物ではsexual orientation自体を大事件にしない。

- 普通に元恋人の話をする
- 好きになる
- 振られる
- 嫉妬する
- 仲直りする

ことで世界内の時代差も見せられる。

### Romance pairを今LOCKしない

誰をgay / lesbianにするか、誰と恋愛するかは人物Coreを見てから決める。

Current21へ後付けで無理にassignする必要もない。
Future castで自然に作ってよい。

# 8. 他に足りない可能性

「全カテゴリを1人ずつ揃える」チェックリストにはしない。

ただしCurrent castを見た時、追加価値が高い候補:

## A. 身体障害 / mobility difference

- 車椅子
- 杖
- 義足 / prosthetic
- 片腕等

を単なる弱さとしてではなく、Gameplay designへ変換できる人物。

ヨルノシルベは現実と夜で身体感覚が違うため:

> 夜では歩けるようになる

だけで解決すると「治ること = Happy End」になりやすいので避ける。

補助具込みのその人をCurrent selfとして扱う方がよい。

## B. Nonbinary / gender-nonconforming

Robotだけにgender ambiguityを背負わせず、人間にも必要なら入れられる。

ただしmandatory quotaにはしない。

## C. 階級 / 職業差

王族 / お嬢様だけでなく:

- 肉体労働
- service worker
- craftsman
- caregiver
- unemployed / drifting

など生活背景の差も人物の幅を作る。

## D. 宗教 / 国籍は慎重に

実在文化を使う場合、雰囲気だけ借りず調査する。
現在は無理に増やさない。

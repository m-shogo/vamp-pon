# Juice and Feel Spec

## 目的

Vamp Ponを、ただのヴァンサバ風ではなく、より気持ちよく触れるゲームにするための手触り仕様。

ここでいうJuiceは、派手な演出ではない。

```txt
入力した
当たった
倒した
拾った
強くなった
助かった
```

が一瞬で伝わる反応のこと。

---

# 1. 基本方針

Vamp Ponの気持ちよさは、以下で作る。

- 移動が軽い
- 敵を払った瞬間が分かる
- 欠片が吸い寄せられて気持ちいい
- レベルアップで明確に強くなる
- 武器/ステータスがキャラの見た目に反映される
- エフェクトが綺麗だが視認性を邪魔しない

---

# 2. ヴァンサバより気持ちよくしたい点

## 2.1 欠片回収

通常の経験値回収より、Vamp Ponでは欠片回収を気持ちよくする。

やること:

- 欠片が小さく光る
- 吸引開始で少し加速する
- 取得時に小さな音/光
- 連続取得で軽いリズム感
- 吸引範囲が伸びると体感で分かる

## 2.2 敵撃破

敵を倒すより「影が記憶に戻る」感を出す。

やること:

- 敵死亡時に黒インクが少し散る
- 直後に金色の欠片が出る
- 強敵は少し大きい欠片/カプセルへ変わる

## 2.3 レベルアップ

単なるUIではなく、短いご褒美にする。

やること:

- 画面時間停止
- 欠片が一瞬集まる
- カードが紙片として出る
- 選択後にユイが少し光る

## 2.4 ピンチ救済

必殺技「消えない名前」は、気持ちよさの核にする。

やること:

- 押した瞬間に反応
- 欠片が一斉に吸い寄せられる
- 小型影が欠片に戻る
- 画面が明るくなる

---

# 3. Prototype 1で入れるJuice

Prototype 1では最小。

```txt
移動の反応
敵ヒットの小さな反応
敵死亡から欠片化
欠片吸引
欠片取得
Lv2到達時の短い停止
```

入れない:

```txt
必殺技演出
進化演出
カプセル演出
本格SE
大量パーティクル
画面揺れ多用
```

---

# 4. 移動の手触り

## 目標

```txt
指を置いたらすぐ動く
方向転換が遅れない
止まりたい時に止まる
```

## 初期案

- 加速度は弱め
- 慣性は最小
- 入力強度は最大速度扱いでもよい
- 速度は100から開始

## NG

- ぬるっとしすぎる
- 止まりにくい
- 指の下に隠れて方向が分からない

---

# 5. ヒット感

## 敵に弾が当たった時

- 敵が一瞬だけ縮む/揺れる
- 小さいインク粒
- ダメージ数字はPrototype 1では任意

## 敵が死んだ時

- 黒インクが小さく散る
- 金色欠片が出る
- 敵がすぐ消える

## NG

- ヒットしているか分からない
- エフェクトで敵が見えない
- 毎回大きな爆発

---

# 6. 欠片回収感

## 吸引時

- 近づくと欠片が曲線的に寄る
- 速度が少し加速
- 光が少し強くなる

## 取得時

- 小さな光
- XPゲージが動く
- 連続取得でテンポが出る

## NG

- 欠片が地味
- 吸引が遅い
- 取得しても何が起きたか分からない

---

# 7. 強くなった実感

レベルアップ時、数字だけでなく見た目/挙動で伝える。

Prototype 1:

- 夜の鉛筆Lv2で発射間隔か弾の見た目を少し変える
- ユイが一瞬光る
- HUDのLvが目立つ

Prototype 2以降:

- 武器取得でユイの周囲に小物が増える
- パッシブ取得で小さなアイコンがユイ付近/画面下に出る
- 吸引範囲UPは欠片の寄り方で分かる

---

# 8. 視認性との優先順位

エフェクトは重要。

ただし、以下を超えてはいけない。

```txt
敵が見えない
欠片が見えない
被弾が分からない
弾と欠片が混ざる
スマホで重い
```

この状態ならエフェクトを削る。

---

# 9. Feel QA

Prototype 1で確認する。

- 動かしてすぐ気持ちいいか
- 敵を倒したと分かるか
- 欠片を拾いたくなるか
- Lv2で強くなった気がするか
- 画面がうるさくないか

---

# 最重要

気持ちよさは後付けではない。

Prototype 1から、最低限の反応を入れる。

```txt
動く、当たる、倒す、拾う、強くなる。
```

この5つの反応を気持ちよくする。

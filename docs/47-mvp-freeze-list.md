# MVP凍結リスト

## 目的

Vamp Pon の仕様増加を止め、MVPで作るもの/作らないものを固定する。

このドキュメントは、実装前のスコープ管理に使う。

## 基本方針

```txt
MVPは「ユイで8分遊んで、もう一度遊びたいか」を検証するもの。
```

したがって、MVPに必要ないものは作らない。

# 2. MVP強く推奨

MVPに入れたいが、時間が足りなければ後回し可能。

```txt
北極星のランタン進化
簡易図鑑画面
簡易実績画面
永続強化5種
自動必殺技設定
/?debug=true のスマホデバッグメニュー
```

## 判断基準

以下を満たすなら入れる。

```txt
実装が軽い
バランス調整を邪魔しない
スマホUIを圧迫しない
```

# 4. MVPでは不採用

明確にやらない。

```txt
オンラインランキング
課金
広告
ガチャ課金
マルチプレイ
フレンド機能
ログイン
スタミナ制
PvP
チャット
```

## 理由

ゲームの核検証に不要。

作るとプロジェクトの焦点がズレる。

---

# 5. デザイン関連の扱い

デザインは別途詰める。

MVP実装時の仮素材は使用可。

ただし、以下は凍結しない。

```txt
キャラ見た目
敵見た目
背景美術
色
フォント
完成UI
ロゴ
アイコン
```

## 仮素材ルール

```txt
仮素材は評価対象ではない
仮素材でテンションを下げない
仮素材で見るのは操作感とゲーム性だけ
```

---

# 6. 仕様追加ゲート

新しい案が出たら、以下を通す。

```txt
1. ユイで8分遊ぶ核に必要か？
2. スマホ操作を重くしないか？
3. 3択/画面情報を増やしすぎないか？
4. デザイン未確定でも検証できるか？
5. テスト可能か？
6. 既存データ構造で表現できるか？
```

1つでも大きく怪しい場合、MVP後へ送る。

---

# 7. MVP完成条件

MVP完成とみなす条件。

```txt
[ ] ユイで8分プレイできる
[ ] スマホ縦持ちで操作できる
[ ] 1分以内に初レベルアップする
[ ] 3分で初カプセルを見る
[ ] 5分前後で進化チャンスがある
[ ] 必殺技を使いたくなる場面がある
[ ] 8分クリア/失敗のリザルトが出る
[ ] 次の目標が表示される
[ ] スマホで大きな処理落ちがない
[ ] 仮素材でももう一度遊びたい核がある
```

## MVPで一番大事な評価文

```txt
ユイで8分遊んで、もう一度遊びたい。
```

これが言えないなら、キャラやステージを増やさない。

# 8. 凍結判断

## 凍結するもの

```txt
ユイ
8分MVP
縦持ち
自動攻撃
3択
武器5種
パッシブ5種
敵5種+強敵
記憶カプセル
未完成の一行
消えない名前
```

## 凍結しないもの

```txt
数値
敵密度
XPカーブ
必殺技チャージ時間
カプセル出現タイミング
UI見た目
デザイン
```

数値はプレイテストで変える。

構造は守る。

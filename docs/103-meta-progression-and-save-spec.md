# Meta Progression and Save Spec

## 目的

MVP後に必要になるメタ進行、解放、セーブ仕様を先に整理する。

Prototype 1では実装しない。

---

# 1. 実装タイミング

```txt
Prototype 1: 実装しない
Prototype 2: 原則実装しない
Prototype 3: 最小保存を検討
MVP後: 本格実装
```

---

# 2. メタ進行の役割

Vamp Ponのメタ進行は、プレイヤーを強制的に周回させるためではない。

役割:

- 次に試したい理由を作る
- 記憶を取り戻している感覚を出す
- 少しずつ遊びやすくする
- 図鑑/実績/欠片を意味あるものにする

---

# 3. 通貨

仮名:

```txt
記憶片
```

取得元:

- ラン終了報酬
- カプセル報酬
- 実績
- 図鑑登録

用途候補:

- 小さな永続強化
- 図鑑断片の解放
- キャラ解放
- ステージ解放補助

---

# 4. 永続強化候補

MVP後に検討。

初期候補:

- 初期HP少し増加
- 初期移動速度少し増加
- 欠片吸引範囲少し増加
- 初期攻撃力少し増加
- 獲得記憶片少し増加

注意:

- 強くしすぎない
- 初心者救済にする
- ゲームを壊す倍率にしない

---

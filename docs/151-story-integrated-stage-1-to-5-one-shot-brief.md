# 1. 制作タスク

Vamp PonのStage 1〜5を、一つの共同事件を逆向きに読み直す5枚のページとして一括設計する。

5面の関係:

```txt
Stage 1 意味片を見つける
Stage 2 持ち主の名前を守る
Stage 3 壊れた灯りと理由を保存する
Stage 4 保存物を灯りへ運ぶ帰路を読む
Stage 5 名前・保存物・道・欠片を灯りで再接続する
```

単なるキャラクター紹介、色違い背景、独立した短編5本にしない。

---

# 2. 共通事件

制作側の仮称:

```txt
最初の返し夜
```

ユイは黒インクから剥がれた意味片を正しい持ち主へ返す途中だった。

黒読み・集めすぎにより、ユイは「全部を奪った者」として固定されかけた。

そこでCore 5は別々の方法で返却を守った。

- アサ: 名前と持ち主の対応を一時的に隠した
- ナギ: 壊れた灯りの部品と理由を月箱に保存した
- ミチル: 帰路を切符・針・糸・印へ分割した
- トモリ: 残された部品と印を使って灯りを直し続けた
- ユイ: 意味片を朝まで運ぼうとした

ユイだけが、黒読みにより「自分一人で失敗した」と記憶している。

Stage 5で「一人ではなかった」ことを部分回収し、事件の直接原因はSeason 1終盤まで残す。

# 5. 形・線・光の横断伏線

## 形

```txt
Stage 1 ピン穴のような切断点
→ Stage 2 欠けた名札ピン
→ Stage 3 箱の蝶番穴
→ Stage 4 切符のパンチ穴
→ Stage 5 ランタンの修理鋲
```

同じ形を露骨に同一物として描かず、後から比較すると一致する程度にする。

## 線

```txt
Stage 1 途切れた地図線
→ Stage 2 名前の書き直し線
→ Stage 3 箱底の道糸
→ Stage 4 帰り線
→ Stage 5 ランタンから伸びる光路
```

線幅・結び目・曲がり方にfamily resemblanceを持たせる。

## 光

```txt
Stage 1 欠片の脈動
→ Stage 2 名札の一画
→ Stage 3 箱内のガラス反射
→ Stage 4 切符裏の温かさ
→ Stage 5 接続光
```

5面の光色を同一にせず、同じ根を持つ段階変化として設計する。

# 6. Stage別必須因果

## Stage 1 — ちぎれた夜の広場

### 主黒読み

集めすぎ。

### 見せる誤解

ユイは経験値を拾い、一人で戦っている。

### 必須伏線

- 外周に4つの途切れた接続点
- ピン穴、月留め、パンチ穴、すす跡の形
- ごく少数の特殊欠片
- 敵は欠片を取らず、ユイだけを狙う

### 次Stageへの原因

欠片だけでは持ち主が分からないため、名前が必要になる。

---

## Stage 2 — 名前をなくした札庭

### 主黒読み

すり替え。

### 見せる誤解

アサの名前は消された。

### 必須伏線

- 同じ人物が何度も書き直した筆圧
- 主名札から欠けたピン
- 裏面の月形折り癖
- 名札影は名札を踏まない

### 前Stageの結果

Stage 1の特殊欠片の一つが、名札の角と一致する。

### 次Stageへの原因

名前を守っても、壊れた灯りと理由を保存しなければ返せない。

---

## Stage 3 — 月箱の保管庫

### 主黒読み

閉じ込め。

### 見せる誤解

ナギが真相を箱へ閉じ込めた。

### 必須伏線

- 内側を向く鍵穴
- 割れたランタンガラスの弱い反射
- Stage 2の名札ピンと合う蝶番穴
- 箱底にStage 4へ続く道糸

### 前Stageの結果

アサが守った対応情報が月形の折り癖として箱へ渡る。

### 次Stageへの原因

部品が残っても、トモリの修理場所へ運ぶ道が必要になる。

---

## Stage 4 — 逆さ改札と帰り線

### 主黒読み

飲み込み。

### 見せる誤解

ミチルは帰り道を失敗した。切符は片道。

### 必須伏線

- 箱底の道糸と同じ太さ・結び目
- 裏だけ温かい切符
- 改札の先に地名ではなく修理灯の輪郭
- future Seedとして片側のパンチ穴

### 前Stageの結果

ナギが残した箱と部品の位置を、分割された道が読む。

### 次Stageへの原因

名前、部品、道がそろっても、朝まで保持する灯りが必要になる。

---

## Stage 5 — 朝をつなぐ灯り庭

### 主黒読み

執着。

### 副攻撃

焼き潰し。

### 見せる誤解

トモリは一人で待ち、ユイは一人でここまで来た。

### ランタンの必須痕跡

- ユイの元の芯と火
- アサの名札ピン鋲
- ナギの月形留め
- ミチルの道糸
- トモリの複数修理跡

### 連鎖回収

```txt
欠片が震える
→ 名札に一画戻る
→ 箱が内側から少し開く
→ 切符裏の帰り印が光る
→ 帰り線が往復線になる
→ Stage 1の4切断点がつながる
```

### 明かす

5人が別々の方法で同じ返却を守っていた。

### 明かさない

- 事件の直接原因
- もう片方の切符の持ち主
- 箱の全文
- 複合属性の正体
- 全員が最初に会った経緯

# 8. 一括実行プロンプト

```txt
あなたはゲームのアートディレクター、レベルデザイナー、ナラティブデザイナーです。
スマホ向け縦画面サバイバーライク「Vamp Pon」のStage 1〜5を、一つの共同事件を逆向きに読み直す5枚のページとして一括設計してください。

この5面は独立したキャラクター紹介ではありません。ユイが意味片を持ち主へ返そうとした「最初の返し夜」で、Core 5が別々に行った保護行動の痕跡です。

因果は次の順番です。
ユイが意味片を運ぶ。黒読み・集めすぎがユイを「全部を奪った者」と固定しようとする。アサが名前と持ち主の対応を隠してすり替えを防ぐ。ナギが壊れた灯りの部品と読まれると壊れる理由を月箱へ保存する。ミチルが帰路を切符・針・糸・印へ分割して飲み込みを防ぐ。トモリが残された部品と印を使い、皆が帰れるよう灯りを何度も修理する。ユイだけが「自分一人で失敗した」と誤読している。

まずStage 1〜5の背景のみの環境コンセプトを、同じ視点、同じドット密度、同じ縮尺、同じUI安全領域で横並び比較できる形にしてください。各Stageは縦長720×1280以上の構図マスターを想定し、中央390×844へ切り出せ、タブレットとPCでは周囲を追加表示できるoverscanを持たせてください。

全Stageで中央55〜65%を静かな戦闘床にし、物語は中景と外周、主象徴物一つ、因果接続物一つで見せてください。一面につきfuture Seedは最大一つです。すべての小物を意味深にせず、owner・cause・payoffのない物は純装飾として弱く扱ってください。

横断伏線を3系統で統一してください。
形: Stage 1のピン穴状切断点 → Stage 2の欠けた名札ピン → Stage 3の蝶番穴 → Stage 4の切符パンチ穴 → Stage 5のランタン修理鋲。
線: 途切れた地図線 → 書き直し線 → 箱底の道糸 → 帰り線 → 接続光路。
光: 欠片の脈動 → 名札の一画 → 箱内ガラスの反射 → 切符裏の温かさ → ランタンの接続光。

Stage 1「ちぎれた夜の広場」は黒読み・集めすぎ。敵は欠片を取らずユイだけを狙う。外周に4つの切断点とごく少数の特殊欠片を置く。欠片だけでは持ち主が分からないためStage 2へ進む。

Stage 2「名前をなくした札庭」は黒読み・すり替え。同じ人物が何度も書き直した筆圧、欠けた名札ピン、裏面の月形折り癖、名札を踏まない敵を置く。名前を守っても壊れた灯りを保存する必要がありStage 3へ進む。

Stage 3「月箱の保管庫」は黒読み・閉じ込め。内側を向く鍵穴、割れたランタンガラスの弱い反射、名札ピンと合う蝶番穴、箱底の道糸を置く。箱は迷路や悪意の封印ではなく、正しい灯りが戻るまで壊れ物を守るもの。部品を修理場所へ運ぶ道が必要になりStage 4へ進む。

Stage 4「逆さ改札と帰り線」は黒読み・飲み込み。箱底の道糸と同じ線、裏だけ温かい切符、改札の先にある修理灯の輪郭、片側のパンチ穴を置く。線は壁ではなく流れ。名前、部品、道がそろい、朝まで保持する灯りのStage 5へ進む。

Stage 5「朝をつなぐ灯り庭」は黒読み・執着、副攻撃は焼き潰し。修理ランタンにユイの芯、アサの名札ピン鋲、ナギの月留め、ミチルの道糸、トモリの複数修理跡を持たせる。欠片、名札、箱、切符、帰り線、Stage 1切断点が順番に反応する構図にする。5人が別々に同じ返却を守っていたことは示すが、事件の直接原因、もう片方の切符、箱の全文、複合属性、全員が会った経緯は明かさない。

絵柄は柔らかい高品質ピクセルアート。絵本の丸く少し歪んだ紙形状、大きな色面、不均一な手描き線、読みやすいシルエット。可愛いが幼児向けではなく、暗いがホラーではない。リアルな石畳、中世RPG村、墓地、写真紙テクスチャ、全面ディザ、高密度装飾、読める説明文、ロゴ、5面同一構図、色替えだけは禁止です。

画像の後に必ず、Foreshadowing Ledgerを表で作ってください。列はstage、visual、owner、apparentMeaning、trueMeaning、cause、payoff、gameplay、futureSeedです。また5面の因果を、前Stageの結果・現在の誤解・次Stageの原因の3列で確認してください。

最初の回答ではproduction素材へ分解せず、5面の環境ラインナップ、因果、伏線の整合性に集中してください。
```

# 9. 合格条件

## 物語

- [ ] 5面が一つの事件としてつながる
- [ ] 各キャラの行動が次のキャラを必要にする
- [ ] 誰か一人が万能な救済者になっていない
- [ ] Stage 5で過去4面の意味が反転する
- [ ] 完全説明ではなく空白が残る

## 伏線

- [ ] 形・線・光の3系統が5面を横断する
- [ ] 初見用、注意用、再見用の強度差がある
- [ ] future Seedが一面一つ以下
- [ ] 意味のない装飾を伏線のように目立たせていない

## ゲーム

- [ ] 中央戦闘床が静か
- [ ] 敵挙動と黒読みの意味が一致する
- [ ] ギミックがキャラの行動と一致する
- [ ] 390×844、タブレット、PC shellへ耐える
- [ ] 画像をbase / decal / prop / landmark / gimmickへ分解できる

## 感情

最終的にプレイヤーが受け取るのは次である。

```txt
ユイが一人で皆を救ったのではない。
皆が違う方法でユイを助けていたから、朝へ返せた。
```

# Everyday Phrase Quote Replies

Vamp Pon / ヴァンサバ改のロード画面・キャラ返信に使う、英語の日常表現・慣用句・短い挨拶の扱い方。

---

## 1. 目的

```txt
古典名言だけでは重い。
英語ことわざだけでは少し教科書っぽい。
映画・漫画・アニメの直接引用は商用で危ない。

そこで、英語圏の日常会話にある短いフレーズを使う。
```

狙い:

```txt
意味を知ると少し賢くなった気がする。
海外ユーザーにも自然に届く。
日本ユーザーには「こういう意味なんだ」という知識供給になる。
キャラが返信すると、世界観にやさしいユーモアが出る。
```

---

## 2. このカテゴリの良さ

例:

```txt
Bless you.
```

もともとは「神のご加護を」系の祈り・祝福のニュアンスを持ち、現在では誰かがくしゃみをした時の「お大事に」「大丈夫？」に近い日常表現として使われる。

Vamp Ponに合う理由:

```txt
短い。
やさしい。
由来に少し物語がある。
宗教/祈り/生活/身体反応が混ざっている。
英語圏では自然。
日本語ユーザーには知識供給になる。
キャラ返信でかなり遊べる。
```

---

## 3. 表示構造

### Phrase only

```txt
Bless you.

— Common expression
```

### Meaning included

```txt
Bless you.

— Common expression

くしゃみをした人へかける、ちいさな祈りの言葉。
```

### Character reply included

```txt
Bless you.

— Common expression

くしゃみをした人へかける、ちいさな祈りの言葉。

忘れ物にも、言っていいのかな。
— ユイ / Yui
```

---

## 4. 商用運用ルール

```txt
一般的な日常表現・慣用句・ことわざを使う。
現代映画/漫画/アニメ/歌詞の台詞は使わない。
既存の辞書訳をそのまま使わない。
日本語はVamp Pon用の自前意訳として書く。
最終商用前に phrase / sourceLabel / rendering を確認する。
```

このカテゴリは「引用」ではなく `common_expression` として扱う。

## 6. 運用方針

```txt
このカテゴリは、重い文学引用の間に混ぜる。
英語学習っぽさ、生活感、ユーモアを出す。
ただし軽くしすぎず、返信でキャラの傷や価値観を少しだけ出す。
```

表示比率の目安:

```txt
Serious literary quote: 40%
English proverb / idiom: 25%
Everyday phrase: 15%
Vamp Pon original: 10%
Parody dialogue prompt: 10%
```

## 7. 最終方針

```txt
Bless you のような短い日常表現は、Vamp Ponに合う。
理由は、言葉の奥に祈り・生活・身体・やさしさがあるから。

名言ほど重くない。
ことわざほど説教くさくない。
キャラ返信でかわいくも、少し寂しくもできる。
```

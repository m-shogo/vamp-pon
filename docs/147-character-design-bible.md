# Character Design Bible

## 目的

Vamp Pon のキャラクターを、年齢層・性別・造形・持ち物・髪型・頭装備・光・固定武器・ステージ背景まで含めて、20人規模でも破綻しないように設計する。

この文書は、絵を描く前に迷わないためのデザイン仕様書。

```txt
キャラが被らない
一目で誰か分かる
見た目と武器と話がつながる
ステージ背景まで連動する
```

を目的にする。

---

# 0. 年齢層・性別の方針

Core5 は今のままだと同年代の女の子寄りに見えやすい。

20キャラ展開では、以下を守る。

```txt
子供
中高生
青年
大人
中性的
男性
女性
```

を混ぜる。

ただし、性別で強さを決めない。

```txt
強い/弱いは性別ではなく、記憶テーマ・武器・性格・得意不得意で決める。
```

## 20キャラ全体の理想比率

```txt
女性: 9〜10
男性: 7〜8
中性的/性別を強く出さない: 2〜4
```

## 年齢層の理想比率

```txt
子供: 3〜4
中高生: 6〜7
青年: 5〜6
大人: 3〜4
年齢不詳/異質枠: 1〜2
```

# 1. キャラ追加時の7項目ゲート

新キャラは必ず以下で分ける。

```txt
1. 持ち物
2. 髪型
3. 頭装備
4. 光の種類
5. 戦う理由
6. 固定武器の遊び味
7. 得意不得意
```

この7項目が見た目・話・ゲーム性をつなぐ。

## NG

```txt
見た目だけ違う
武器だけ違う
属性だけ違う
性格だけ違う
```

## OK

```txt
持ち物が違うから、記憶テーマが違う
記憶テーマが違うから、敵への反応が違う
敵への反応が違うから、戦い方が違う
戦い方が違うから、プレイ体験が違う
```

# 2. Core5 年齢・性別・造形の再固定

## ユイ

```txt
年齢感: 12〜13歳
性別印象: 女の子
身長感: 小さめ
体型: 軽い旅装。大きすぎないバッグで小柄さを出す。
役割: 主人公 / 拾う / 照らす
```

### 造形

```txt
髪型: フードから少し出る柔らかい前髪。横髪は短め。
頭装備: フード固定。
持ち物: 本人の右手にランタン。
バッグ: 右肩から左腰へ紐。バッグ本体は左腰。
光: 道を照らすランタン。常時発光。
シルエット: 丸いフード + 片手ランタン + 斜めバッグ紐。
```

### 色

```txt
夜に埋もれない淡い布色
ランタンは暖色
バッグは少し濃い紙茶
```

### ステージ背景案

```txt
欠片のページ / 夜道 / 紙片が散る細い道
```

### 小さな繋がり

```txt
ユイのバッグには、他キャラの小物の欠片が少しずつ入っている。
初見では装飾に見えるが、後で全員との繋がりになる。
```

## アサ

```txt
年齢感: 14〜15歳
性別印象: 女の子寄り
身長感: ユイより少し高い
体型: 軽い。走るとシルエットが横に流れる。
役割: 届ける / 名前 / 朝風
```

### 造形

```txt
髪型: 短め外ハネ。走る方向に跳ねる。
頭装備: なし。帽子でなく髪型で差別化。
持ち物: 小さな郵便バッグ。肩掛け位置はユイと逆にする。
光: 光り物なし。朝焼け色の差し色だけ。
シルエット: 外ハネ髪 + マフラー + 紙飛行機。
```

### 色

```txt
白い紙
薄い朝焼けオレンジ
淡い青灰
```

### ステージ背景案

```txt
名札のページ / 学校前の道 / 空白の名札が揺れる掲示板
```

### 小さな繋がり

```txt
アサの郵便バッグに、ミチルの切符の半券が紛れている。
本人は知らない。
```

## ナギ

```txt
年齢感: 16〜17歳
性別印象: 女の子寄り
身長感: Core5では高め
体型: 細く静か。布が縦に落ちる。
役割: 守る / 箱 / 涙 / 水
```

### 造形

```txt
髪型: 長め。濡れたようにまとまり、揺れは少ない。
頭装備: なし。
アクセサリー: 片耳だけの水滴耳飾り。
持ち物: 小さな閉じた箱、または鍵穴のない箱飾り。
光: 発光しない。水面反射だけ。
シルエット: 長髪 + 薄いケープ + 片耳アクセ。
```

### 色

```txt
青灰
くすんだ水色
銀ではなく鈍い灰色
```

### ステージ背景案

```txt
箱のページ / 雨上がりの倉庫 / 濡れた紙箱が並ぶ場所
```

### 小さな繋がり

```txt
ナギの箱の底には、トモリの日記と同じ焦げ跡がある。
ナギはそれを隠している。
```

## ミチル

```txt
年齢感: 20〜22歳
性別印象: 中性的〜男性寄りでも可
身長感: Core5では高い
体型: 直線的。歩幅が一定。
役割: 読む / 地図 / 切符 / 帰り道
```

### 造形

```txt
髪型: 低いポニーテール、または短めで後ろだけ結ぶ。
頭装備: 探検帽または駅員帽寄り。フード・魔女帽禁止。
持ち物: 腰の地図ケース、腰側コンパス。
光: 発光なし。金属反射だけ。
シルエット: 帽子 + 腰地図ケース + まっすぐ立つ姿勢。
```

### 色

```txt
地図紙ベージュ
青灰
くすんだ緑
```

### ステージ背景案

```txt
切符のページ / 古い駅 / 読めない路線図と片方だけの改札
```

### 小さな繋がり

```txt
ミチルの地図には、ユイの最初の夜道が小さく描かれている。
ただし、本人はその道をまだ読めない。
```

## トモリ

```txt
年齢感: 25〜30歳
性別印象: 女性、または大人寄り中性的
身長感: Core5では高め
体型: 少し重心低め。強がりの立ち姿。
役割: 残す / 火 / 記録 / マッチ
```

### 造形

```txt
髪型: 短めボブ、または片側だけ跳ねる。
頭装備: 帽子なし。大きめヘアピンかリボン。
持ち物: 手帳とマッチ箱。
光: 一瞬だけ燃える火。常時発光禁止。
シルエット: 短髪 + 手帳 + 小さな火花。
```

### 色

```txt
焦げ茶
くすんだ赤
紙の白
火は小さく暖色
```

### ステージ背景案

```txt
記録のページ / 焦げた図書室 / 読めない日記と焼け残りの棚
```

### 小さな繋がり

```txt
トモリの日記の1ページに、アサが届けられなかった手紙の文面が写っている。
```

# 3. Core5 小さな繋がり一覧

全員は最初から親友ではない。
しかし、最低でも小さな繋がりがある。

| 関係 | 小さな繋がり | 後で分かる意味 |
|---|---|---|
| ユイ -> アサ | ユイのバッグに白い紙片 | アサの未配達手紙の端 |
| アサ -> ミチル | バッグに切符半券 | ミチルの帰り道と接続 |
| ミチル -> ナギ | 地図に水染み | ナギの箱を守った雨の日 |
| ナギ -> トモリ | 箱底の焦げ跡 | トモリが焼き止めた記録 |
| トモリ -> ユイ | 日記にランタンの絵 | ユイが照らした最初の夜 |
| ユイ -> ミチル | 最初の道が地図にある | ユイの道が帰り道の入口 |
| アサ -> トモリ | 手紙の文面が日記に写る | 届かなかった言葉が別の形で残る |
| ナギ -> ユイ | 箱の中に欠片の形 | ユイが拾う前に守られていた |

# 5. 造形差別化ルール

## 髪型の被り制限

```txt
短髪元気: 最大2人
長髪静か: 最大2人
ボブ: 最大2人
帽子 + 低ポニテ: ミチル専用に近い
フード + 小柄: ユイ専用
```

## 頭装備の被り制限

```txt
フード: ユイ専用
探検帽/駅員帽: ミチル専用
リボン/ヘアピン: トモリ系。追加時は形を変える
眼鏡: 2人まで。片方は写真、片方は文字解析など意味を変える
帽子: 20人中4人まで
```

## 光の被り制限

```txt
常時手持ち光: ユイ専用
一瞬の火: トモリ専用
星明かり: ホシノ専用
反射光: カガミ/ナギ/ヨミで意味を分ける
音: リンネ/フエで音質を分ける
```

# 7. デザイン作成時のチェック

画像生成・ドット化・Aseprite手仕上げ前に確認する。

```txt
縮小してもシルエットで分かるか
持ち物が一目で読めるか
ユイのフード/ランタンと被っていないか
頭装備が他キャラと被っていないか
光り方が意味で分かれているか
年齢層が全員同じに見えないか
男女/中性の幅があるか
武器の遊び味が既存キャラと違うか
ステージ背景がそのキャラ専用に見えるか
小さな繋がりが最低1つあるか
```

# 8. 固定メモ

```txt
見た目の差別化は、ゲーム性の差別化。
持ち物の差別化は、記憶テーマの差別化。
ステージ背景の差別化は、敵と小物の差別化。

キャラを増やすほど、遊び方・背景・敵・リザルト文が増える状態にする。
```

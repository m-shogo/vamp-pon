# ヨルノシルベ Story Backbone — High-Value Candidates v1

Date: 2026-07-28  
Status: **HIGH-VALUE CANDIDATES / NOT CANON**

目的: 設定を増やしながらも、最後に「最初から全部同じ理屈だった」と感じられる候補を保存する。ここにある案はユーザーとの対話で育てるための共有記憶であり、Human decision前にMain Mysteryの正解へ昇格しない。

## 1. 最有力の背骨

### 夜 = 未確定の記憶と意味を安全に読み直せる共有レイヤー

夜は単なる夢でも単なるVRでもなく、現実の人間が持つ記憶・感情・関係を、直接肉体を傷つけずに再接続できる「夜側の層」。

1作目で必ず説明するのは「夜が何をする場所か」「なぜ朝へ帰れるか」「なぜGame Overしても死なないか」。

一方で、夜を最初に作ったもの・最終起源・外部世界全体の仕組みはSeries Mysteryとして残してよい。

## 2. 黒インク = 出来事ではなく、意味の固定

既存High-Value Candidateを強化する。

悲しい出来事そのものを消したり書き換えたりしない。

人が出来事へ付けた一つの解釈が強く固定され、他の読み方を受け付けなくなった状態を黒インクとして表現する。

例:

- 名前が書かれていない → 「私は忘れられた」だけが固定される
- 帰ってこなかった → 「捨てられた」だけが固定される
- 守るために隠した → 「嘘をつかれた」だけが固定される

ヨルノシルベで過去を改変するのではなく、固定された意味をほどき、複数の意味を持てる状態へ戻す。

## 3. Gameplayを同じ原理で説明する

| Gameplay | 表面 | Story-side candidate |
| --- | --- | --- |
| カゲモノ | 敵 | 固定された意味が自己防衛する形 |
| 敵をほどく | 撃破 | 一つしかなかった読み方を緩める |
| 記憶片 | EXP | 固定から剥がれた接続の断片 |
| Level Up | run内強化 | その夜に扱える接続 / 読み方が増える |
| Boss | 強敵 | その場所・人物で最も強く固定された意味 |
| Game Over | 敗北 | その読み筋では朝まで確定できなかった |
| Retry | 再挑戦 | 同じ未確定夜を別build / 別関係 / 別順で読む |
| Dawn / Clear | 勝利 | その夜で得たものが安全に確定する |
| Permanent unlock | Meta | 次の夜にも残る理解・技術・関係 |
| Clear Getter | 達成盤 | 確定した安全な読み筋 / 遊び方が星図に残る |

この裏意味を知らなくてもGameplayは成立する。

## 4. 星獣 = その人の「一番崩れにくい自己像」

星獣は占いの付属物ではない。

夜が不安定でも、その人が自分であり続けるための小さなアンカー。

- 星座は本人が好き / 共鳴する生物星座
- 星獣は本人の言葉より先に本音へ反応できる
- 血縁、兄弟、継承、同じ記憶由来などに理由がある場合、同星座系統を伏線に使える
- 同じ星座でも別個体として姿・癖を変える
- 黒耀化では星獣が本人の過剰化を無言で示す

ユイの獅子は「王者」ではなく、小さくても灯りの前に立つ勇気の象徴。

## 5. 黒耀化 = 深層へ無理に接続する危険な強化

黒耀化は闇落ちではない。

本人の長所・願い・守り方を限界以上に使い、通常では届かない深い未確定層へ接続する状態。

そのため強い。

しかし一つの長所だけが強くなりすぎ、視野が狭くなる。

例:

- ユイ: 誰も忘れたくない → 全部自分が戻す
- カナメ: 守りたい → 全部自分が受ける
- クロオリ: 壊したくない → 何も開かない

煤返りは「悪の代償」ではなく過剰接続後の反動。

## 6. Shadow = 夜の安全装置を先に知った人たち

Shadowは悪役組織ではなく、記憶を開く危険を知った側。

- クロオリ: 折って守る
- カナメ: 影へ隠して守る
- カスミ: 痕跡をぼかして守る
- トキ: 境界・距離・順番を測って守る
- ツムギ: 空白を残して未来を守る

ユイ側の「取り戻す」とShadow側の「すぐには開かない」は両方必要。

最終的な成長は「どちらが勝つか」ではなく、いつ開き、いつ閉じ、誰と一緒に扱うかを選べること。

## 7. 強い主人公Twist候補 — クロオリは昔のユイの頼みを守っている

HIGH-VALUE CANDIDATE。

現在のユイは「クロオリが記憶を隠している」と思う。

しかし過去のある時点で、ユイ自身が:

> 今はこれを開けないで。私が忘れても。

とクロオリへ頼んでいた可能性。

ユイはその頼み自体を忘れている。

この候補の利点:

- クロオリの敵対行動が忠誠 / 約束の履行へ反転する
- ユイの価値観「全部戻す」が自分の過去の判断と衝突する
- 最終成長が「全部思い出す」ではなく「自分が忘れた判断も含め、今の自分で選び直す」になる
- 1周目からクロオリの行動に一貫性を持たせられる

この案を採用する場合、クロオリは最終Bossにしない方が強い。

## 8. Final Boss候補 — ユイ自身の固定された信念

最終Bossを単なる黒幕にしない候補。

ユイが長く信じてきた:

> 忘れる = 裏切り / 消滅

という意味が巨大に固定されたものが最終圧力になる。

敵としての姿はランタン / 獅子 / 黒い灯 / 失われた名前等を混ぜられるが、具体形は未LOCK。

倒すのではなく最後に「ほどく」。

クロオリや仲間はBoss戦で初めて完全に同じ側へ並ぶ。

## 9. Ending候補 — 完璧な記憶を捨てて、不完全な関係を選ぶ

正史Happy Endを守る。

夜に残れば全員との出来事を完全な形で保存できる。

朝へ帰れば細部の一部を失うかもしれない。

ユイたちは朝を選ぶ。

失うのは命ではなく「完全に保存された夜」。

その代わり:

- 全員生きている
- 現実へ帰る
- 再会できる
- 詳細を忘れても関係の感触が残る
- 呼び方や無意識の癖に夜の時間が残る

「全部覚えているから大切」ではなく「忘れても大切だったことは消えない」へ着地できる。

## 10. CLANNAD型の涙を作る日常反復

泣かせる装置をDeathにしない。

序盤〜中盤で、同じ日常場所 / 小物 / 行動を繰り返す。

例:

- 夜食の席順
- ランタンを置く位置
- 誰が最後の食べ物を遠慮するか
- 誰が寝落ちするか
- 誰が壊れた物を直すか
- 星獣がどこで寝るか

終盤、一時的に全員が分断された時、同じ場所と同じ小物だけを見せる。

最後に再会し、同じ日常をもう一度やる。

ただし呼び方・席・行動が少しだけ成長後へ変わっている。

## 11. Optional Reportの辻褄

夜の観測記録は万能説明書にしない。

観測者は完全な真実を知らない。

レポート同士が食い違う場合、作者のミスではなく:

- 観測した夜が違う
- 同じ出来事を別人物の意味で読んでいる
- ある情報が意図的に折られている
- 観測時点ではまだ未確定だった

という理由を与えられる。

Main StoryはReportなしで理解可能。

## 12. 「スッキリ」を守るMystery Debt Rule

物語内の謎を3階層へ分ける。

### C — 1で必ず返す

- なぜGame Overで死なない
- なぜRetryできる
- 朝へ帰るとは何か
- 1の中心事件で誰を何から救うのか
- クロオリが1で何を守っていたのか（中心Conflictに使う場合）
- ユイが最後に何を選ぶのか
- 1の中心人物の感情問題

C級を未回収のままEndingへ行かない。

### B — 1で答えの輪郭、2で意味が変わる

- ユイとトモリの獅子共有
- 現実側へ残った夜の物
- 一部の古い観測記録
- Shadowのさらに古い役割

### A — Series Mystery

- 夜の最終起源
- 黒インクが最初に生まれた理由
- 夜の仕組みを作った / 生んだ存在
- 他地域 / 他の夜

A級を残すためにC級を投げない。

## 13. 伏線の置き方 — 3回見せる

大きい真相は、最低3種類の見え方を持たせる。

1. 初見では自然な日常 / Gameplay
2. 中盤では少し変に見える
3. 回収後に最初の意味が反転する

例: クロオリの折り紙

- 初見: 変わった趣味 / モチーフ
- 中盤: 重要な記録だけ折って開かせない
- 真相後: 「消していた」のではなく、ユイの頼み通り安全に閉じていた

ラスボス直前に初めてルールを追加して解決しない。

## 14. トモリとユイの獅子共有 — 候補を急いで一つにしない

候補A: 実際の遠い血縁 / 同じ祖母・家系。

候補B: 血縁ではなく、同じ灯守の継承系統。星獣は血ではなく継承へ反応した。

候補C: 夜へ入る前に一つのランタン / 星獣系統を二人で分けた過去がある。

この謎はMain Mysteryへ少し交差できるが、1の中心真相に必須とは限らない。

## 15. Sequel stinger候補

1のHappy Endを壊さない。

全員が朝へ戻り日常へ戻った後、夜側にしか存在しないはずの小物が一つだけ現実に残る。

候補:

- 黒い折り紙
- 見覚えのない星獣の足跡
- 燃えないランタン芯
- 1では誰にも割り当てられていない生物星座の印

意味は1では説明しない。

「誰も救えていなかった」には絶対にしない。

## 16. 整合性チェック

新設定を追加するとき:

- 同じ現象に別ルールを増やしていないか
- Gameplayで既に見えているものから説明できないか
- Characterの行動理由が後付けで変わっていないか
- 伏線を知らなくても初見行動が自然か
- 真相後に初見Sceneを見返して破綻しないか
- Happy Endを偽物にしていないか
- 1で返すべきC級をSequelへ逃がしていないか
- Reportだけが真相の必須説明になっていないか

設定を増やす場合でも、できるだけ「新しい原理」ではなく「既存原理の別の現れ方」として追加する。

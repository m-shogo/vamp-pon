# 3. Author-level DECIDEDとCharacter knowledgeを分ける

制作上DECIDED:

- ヨルノシルベはDream world
- 朝は来ない
- return = Waking
- Characterは同時代とは限らない
- Dream内ではexact time tagsが弱い
- 星は見える
- constellationはEraで同一とは限らない
- moon phase = incident depth
- Current formal enemy-group name = 朔夜座
- 群青残響録 = retrospective incident-central label、固定Boss集団ではない

しかしCharacterが最初からこれを全部説明できるわけではない。

例:

> 作者は「Dream」と知っている

でも初期Characterは:

> 「夢みたいな場所」

程度の`WORKING_THEORY`でもよい。

# ヨルノシルベ — Knowledge / Secret Matrix v1

Date: 2026-08-11  
Status: **P0 INFORMATION AUTHORITY / CHARACTER KNOWLEDGE DIFFERENTIATION / MAIN MYSTERY SAFE**

> 目的: 「作者は知っているから全員も知っている」事故を防ぎ、同じ出来事を別人物が違う理解で持てるようにする。

---

# 1. Knowledge state vocabulary

各人物 / Faction / Institutionは情報ごとに以下の状態を持つ。

- `UNSEEN` — 存在を知らない
- `HEARD_RUMOR` — 噂として知る
- `SEEN_FRAGMENT` — 一部証拠だけ見た
- `WORKING_THEORY` — 仮説を持つ
- `WRONG_THEORY` — 後に誤りと分かる仮説
- `FIRSTHAND` — 自分で体験した
- `CONFIRMED_LOCAL` — その事件 / 人物については確認済み
- `CONFIRMED_SYSTEMIC` — 世界の仕組みとして確認済み
- `WITHHELD` — 知っているが話していない
- `FORGOTTEN_OR_BLOCKED` — 知っていた可能性はあるが思い出せない / 語れない

`FIRSTHAND`でも解釈は間違い得る。

---

# 2. Information classes

## K0 — 日常情報
誰が何を食べる、どこへ座る、何が苦手など。

## K1 — Relationship information
本人同士の感情 / 過去 / 呼び方。

## K2 — Incident information
無番線案内、未配達保管等の具体事件。

## K3 — Night operational information
夜に入れる / Retry / 朝 / Stageなど。

## K4 — Enemy / Faction information
八影 / 朔盟 / Shadow / Enemy48。

## K5 — Main Mystery information
夜の正体、黒インク、星獣等。

K5を持つ人物を安易に増やさない。

# 3. Current21 information baseline

全Current21が必ず知っていることを最小化する。

## Shared minimum Candidate

- 夜で他の人物と出会える。
- 朝へ帰ることを目指す。
- 戦闘不能と現実死亡は同一ではない。
- 同じ夜が別の組み合わせで繰り返されるように見える。

ただし「なぜそうなるか」は知らない。

# 4. Core5 knowledge roles

以下は役割上の**知り方**であり、真相を知っているという意味ではない。

## ユイ
Strength:
- 忘れ物 / 持ち主 / 記憶片の関係に気づきやすい。

Blind spot:
- 「返せば正しい」と先に思いやすい。

Knowledge drama:
- 物を見つけるが、その人が受け取りたい時期までは知らない。

## アサ
Strength:
- 名前 / ラベル / 宛名の違和感。

Blind spot:
- 正しい名前へ早く直そうとする。

## ナギ
Strength:
- 閉じる / 期限 / 鍵 / 保護の条件。

Blind spot:
- 開けることのriskを強く見積もる。

## ミチル
Strength:
- route / 地図 / 方角の矛盾。

Blind spot:
- 「歩けば分かる」が通用しない保存 / 名前問題。

## トモリ
Strength:
- 修理痕 / 材質 / 手仕事の年代差。

Blind spot:
- 直せる物を見ると、直すこと自体を先に選ぶ。

## K-NIGHT-001 — Game Overの正体

Current status:
- Player視点: Game Over ≠ death
- Character視点: 完全Mechanismは不明

誰も`CONFIRMED_SYSTEMIC`にしない。

## K-NIGHT-002 — Current21が同時代ではない可能性

Status: `CURRENT FACT / CHARACTER AWARENESS VARIABLE`

制作上は確定。
人物がいつ気づくかは別。

Evidence Candidate:

- 言葉
- 道具
- 地図
- 郵便
- 学校用品

「自己紹介で全員の西暦を言う」場面は作らない。

## K-NIGHT-003 — 朝へ帰った後の記憶保持

Status: `OPEN_QUESTION DETAILS`

誰がどれだけ覚えるかを一律にしないCandidate。

## K-SAKU-001 — 「八影」が組織名ではない

Early:
- Current側: `WORKING_THEORY`として八影と呼ぶ。

Reveal:
- 一部pairの共通symbol / contract behaviorから組織性を疑う。

Later Candidate:
- 朔盟という盟約名へ到達。

## K-SAKU-002 — 朔盟のPair Mission Rule

最初から説明しない。

Evidence:
- 同じ二体でも単独時と行動が違う。
- 片方が倒れると「任務の正解」が維持できない。
- 欠円symbolがpairで補完される場面Candidate。

## K-BLACK-001 — 黒耀化は外部人格ではない

制作Canon。

Character awareness:
- 序盤は本人 / 仲間も「別人になった」と誤読しうる。
- Storyで「元々の願いの延長」と理解が変わる。

## K-INK-001 — 黒インク = 間違った意味固定Engine

Status: `HIGH_VALUE_CANDIDATE / NOT SYSTEMIC CONFIRMED`

誰にも早期`CONFIRMED_SYSTEMIC`を与えない。

## K-BEAST-001 — 星獣が人物より先に知っているように見える

Status: `OBSERVABLE PHENOMENON / MECHANISM OPEN`

Evidence:
- 特定pairで先に近づく
- Stage cueへ反応
- 人物が知らないObjectへ反応

真相は未LOCK。

## K-LAMP-001 — ユイ / トモリの獅子系星獣・ランタン接点

Status: `CHARACTER MYSTERY`

- 同系統であることは見える。
- 血縁 / 同時代 / 直接譲渡を推定しない。

# 6. Secret handling rule

Secretは「作者が隠している情報」ではなく、誰に対して何を隠しているかを持つ。

必要field:

- holder
- secret
- hiddenFrom
- whyHidden
- whatHolderFearsWillHappen
- whatWouldMakeThemTell
- falseCoverStory
- accidentalTell
- discoveryConsequence
- doesRevealChangeRelationship

---

# 7. Withholding must fit character

同じ「秘密を言わない」でも理由を変える。

- ナギ: 守るため今は開けない
- カスミ: 本人の公開範囲を守る
- シロ: evidence不足だから断定しない
- セン: 説明できないまま言うことを恐れるCandidate
- ユウビ: 宛先が本人か確認できるまで渡さない

全員を「意味深に黙る人」にしない。

---

# 8. Lie taxonomy

Character Secret Inventoryで使う。

- `PROTECTIVE_LIE` — 相手を守るつもり
- `SELF_PROTECTIVE_LIE` — 自分を守る
- `SOCIAL_LIE` — 場を保つ
- `OMISSION` — 言わない
- `WRONG_BELIEF` — 本人は嘘と思っていない
- `MEMORY_GAP` — 覚えていない
- `PROMISE_BOUND` — 約束で話せない

「秘密持ち = 嘘つき」にしない。

# 10. Faction knowledge asymmetry

## Current
「朝へ帰りたい」が共通でも、Main Mystery理解はばらつく。

## Shadow5
Currentより真相を知っているとは限らない。
価値観が違うだけで情報量まで上位にしない。

## 朔盟
重要:

> **朔盟member全員が同じ真相を共有している組織にしない。**

彼らは同じ結論へ署名しても、
- なぜそうすべきか
- 夜とは何か
- 自分自身の過去

の理解が違う。

これにより内部対立と個別Mysteryを残す。

# 11. Audience knowledge ladder

Playerへ渡す順序:

1. `SEE` — まず現象を見る
2. `NOTICE` — 繰り返しに気づく
3. `NAME` — 仮の名前を付ける
4. `CONTRADICT` — 別evidenceで説明が崩れる
5. `LOCAL_ANSWER` — 今作に必要な答え
6. `REINTERPRET` — 序盤を見直す
7. `SERIES_GAP` — まだ残る一段上の疑問

設定資料の説明をそのままdialogueに流さない。

# 12. Spoiler tiers

- `PUBLIC` — character紹介で出してよい
- `EARLY` — Stage1–5
- `MID` — Stage6–14
- `LATE` — Stage15–20
- `POSTGAME`
- `SERIES_SECRET`

Knowledge itemごとにtierを持たせる。

朔盟の正式名Candidateは`MID or LATE`。
八影というobserver labelは`EARLY`。

# 13. Knowledge conflict scene templates

### 同じ証拠、違う解釈
ミチル: 道が変わった
トキ: 測定が違う
ゲン: 昔はこれで合っていた

### 同じ名前、違う責任
アサ: 正しく直したい

### 同じ箱、違う時間
ナギ: まだ開けない

この「情報差 + 価値観差」を会話の中心にする。

# 14. Retcon guard

禁止:
- 後半で「実は全員知っていた」。
- 説明役一人が全部の秘密を話す。
- 敵だから主人公より世界を詳しく知る、の自動化。
- 失敗を全部記憶操作のせいにする。
- `OPEN_QUESTION`をCharacter dialogueで確定事項として喋らせる。

# 16. Completion definition

- 主要Mysteryに「誰が何を知るか」がある。
- Character dialogueが作者知識を漏らさない。
- 朔盟が万能解説集団にならない。
- Official recordとtruthを分けられる。
- Mid reveal / Late reveal / Postgame情報を管理できる。
- Character Secret Inventoryを安全に下流へ作れる。

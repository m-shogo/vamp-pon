# ヨルノシルベ — Institution / Faction Map v1

Date: 2026-08-11  
Status: **WORLD FOUNDATION DERIVED / CANDIDATE-RICH / CURRENT CHARACTER CANON PRESERVED**

> 目的: 「キャラはいるが世界を誰が運営しているか分からない」をなくす。
> 現実側の生活制度と、夜側で生まれる集団を混同しない。

---

# 1. 大原則

- Current21は同時代とは限らないため、単一国家 / 単一行政で全員を囲わない。
- 現実側Institutionは時代 / 地域ごとにversionが違ってよい。
- 夜側に現実行政の完全コピーを置かない。
- 朔盟は「世界を支配する秘密政府」へ自動昇格しない。
- Current21は全員が同じ所属組織の隊員ではない。
- 無所属 / 家族 / 個人商店 / 学校 / 医療 / 交通など、生活由来の所属を重視する。

# 3. Night-side group taxonomy

夜側には現実行政ではなく、目的・経験による緩い集合を置く。

## F01 Current側 — 夜を歩く者たち
Status: `CURRENT_DERIVED`

正式軍組織ではない。

共通点:
- 朝へ帰る
- 互いを助ける
- 影 / Wrong Readingをほどく

全員に同じ制服 / 階級 / 命令系統を持たせない。

## F02 Shadow5
Status: `CANON_CURRENT_GROUP`

クロオリ / カナメ / カスミ / トキ / ツムギ。

「悪の五人衆」ではなく、Core5と同じ問いへ別の守り方を持つ思想的ライバル。

朔盟と自動的に同一勢力化しない。

## F03 朔盟
Status: `USER_APPROVED_DIRECTION / CANDIDATE_DETAILS`

早期observer label: 八影。
後に判明する盟約名候補: 朔盟。

中心思想:
> 迷いが人を傷つけるなら、迷いそのものを減らし、正解を固定する。

特徴:
- 8人の個別思想は違う。
- Pair Mission Rule。
- 欠円symbol。
- 全員が一人のFounderへ服従する構造は未確定。

## F04 夜の保留者
Status: `CANDIDATE`

仮称。

夜を利用も破壊もせず、
- 分からない記録を残す
- 忘れ物を保管する
- 帰路だけ守る

ような中立的行動者の概念。

**新キャラ集団を増やすためではなく、世界に善悪二極以外の行動原理を持たせるためのslot。**

Human review前に固有組織名 / 人数をLOCKしない。

## F05 夜を商売にする者
Status: `OPEN_QUESTION`

夜の情報や物を売買する人物 / 闇市場が存在するか。

魅力:
- Economy
- rumor
- fake relic
- stolen name / forged map

Risk:
- 世界が急にCyberpunk / criminal economyへ寄りすぎる。
- Main Mysteryの秘密が簡単に商品化される。

P1 Economyと合わせてHuman review候補。

# 5. 組織を魅力的にするための必須data

正式Factionを追加する場合、最低:

- public name
- self name
- who coined the name
- stated purpose
- actual behavior
- member benefit
- member cost
- joining condition
- leaving condition
- taboo
- resource source
- communication method
- internal disagreement axis
- civilian reputation
- symbol
- visual commonality
- what they do on an ordinary day

を持つ。

「全員同じ服で強いから組織」にはしない。

# 6. Civilian perception

一般人はFactionを制作資料の正確さでは理解しない。

例:
- Shadow5 → 「夜にいる別の5人」「助ける時もあるらしい」
- 八影 → 初期には都市伝説的な観測名
- 朔盟 → 名前そのものを知らない時期がある

噂名 / 新聞名 / 当事者名を分ける。

# 8. Faction proliferation guard

新しいFactionを増やす条件:

1. 既存Current / Shadow / 朔盟では担えない思想がある。
2. 世界の生活制度と接点がある。
3. 固有シルエット / symbolだけでなく行動差がある。
4. 1作目Stage20へ無理に全勢力を登場させない。
5. 新キャラ追加を目的にしない。

Title1では**Faction数を増やすより、Current / Shadow / 朔盟と一般社会の見え方を深くする**ことを優先する。

# ヨルノシルベ — Institution / Faction Map v2

Date: 2026-08-11  
Status: **WORLD FOUNDATION DERIVED / REALITY-DREAM SEPARATED / MASTER-ALIGNED**

> 目的: 現実社会を生きたCharacterの背景を厚くしつつ、Dreamに現実行政や生活インフラを無理に複製しない。

---

# 1. 大原則

- 現世は現実の日本。
- Characterは同時代とは限らない。
- Reality institutionはEra / 地域ごとに実態が違う。
- Dreamに現実行政の完全copyを置かない。
- Dreamでは基本衣食住を通常institutionへ依存させない。
- Current側全員を一つの軍 / guildへ所属させない。
- Shadow5と朔夜座を同Factionへ自動統合しない。
- 群青残響録はFactionではない。大事件中心人物 / 人物群へのretrospective record label。

# 4. Dreamに通常Economy factionを必須化しない

旧「夜を商売にする者 / Dream market」はOpen Candidateだったが、Master更新後は優先度を下げる。

Dreamの基本生活物は自然に補完可能なので:

- 食料marketがないと生きられない
- 宿代が払えない
- money factionがDreamを支配する

構造は不要。

情報売買 / fake record / Object exchangeがStory上必要な場合だけ個別Candidateとして検討する。

# 8. Faction proliferation guard

新Factionを増やす条件:

1. Current / Shadow5 / 朔夜座 / ordinary institutionsでは担えない思想がある。
2. Characterの日常 / incidentへ実際に必要。
3. visualだけでなくbehaviorが違う。
4. 新Characterを増やしたいだけではない。
5. Story説明用organizationになっていない。

群青残響録をFaction数へ数えない。

# 9. Quality test

新組織 / institutionを作る前に:

- RealityかDreamか
- Eraは何か
- ordinary dayに何をするか
- memberに何のbenefit / costがあるか
- civilianはどう誤解するか
- 既存institutionで代替できないか
- fixed Boss slotを作るためだけではないか

を確認する。

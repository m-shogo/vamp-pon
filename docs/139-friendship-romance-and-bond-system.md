# Friendship / Romance / Bond System

## 目的

Vamp Ponの関係性を、恋愛中心ではなく友情中心に設計する。

恋愛はサブ要素として扱い、炎上しやすい固定カップリングを避ける。

同時に、ゲームシステムとして友情ポイント・2人選択・必殺技強化へ接続する。

---

# 1. 採用/保留/却下

## 採用

```txt
友情をメインの感情軸にする
友情ポイントをシステム化する
2人選択システムを検討する
関係性で必殺技が強くなる
男同士は恋愛ではなく強い友情/相棒/対立にする
仲悪い関係も入れる
恋愛はサブに分散する
重い関係もサブに分散する
年を取らない魔女 × 年を取る人間の関係をエモい長期テーマとして保留/採用候補にする
```

## 保留

```txt
百合を明確な恋愛として描く
友情ポイントを全キャラへ広げる
2人選択を初期実装に入れる
恋愛キャラをSeason 1で強く出す
```

## 却下

```txt
男同士を公式恋愛にする
BLを狙って押しつける
無理なBL解釈を公式が誘導する
友情ポイントをただの好感度ギャルゲーにする
恋愛がメイン攻略報酬になる
```

---

# 2. 関係性の優先順位

Vamp Ponの関係性優先度は以下。

```txt
1. 友情
2. 相棒
3. 対立からの理解
4. 家族愛/疑似家族
5. 重い約束
6. 恋愛
7. 片思い/未配達の想い
```

恋愛は消さない。

ただし、メインではない。

---

# 3. 友情ポイントの正体

友情ポイントという名前は分かりやすい。

ただし、世界観上は単なる好感度ではない。

```txt
友情ポイント = 意味の接続安定度
```

つまり、仲が良いほど強い、ではない。

正しくは以下。

```txt
2人の間の誤解がほどけているほど、夜の中で一緒に戦える。
```

---

# 4. 友情ポイントで上がるもの

友情ポイントで上がるのは、攻撃力そのものではなく、接続の安定度。

ゲーム上は以下に変換できる。

```txt
必殺技ゲージ増加量
コンビ必殺技の範囲
コンビ必殺技の追加効果
復活時の残り火量
朝に確定できる意味の数
リザルト文の深さ
```

友情ポイントは、ダメージ数字だけにしない。

感情・物語・攻略を同時に進める。

---

# 5. 2人選択システム

採用候補。

## 基本

ラン開始前、またはページ開始前に2人を選ぶ。

```txt
メインキャラ
サポートキャラ
```

または、将来的には以下。

```txt
前衛
後衛
```

2人の組み合わせで、必殺技・会話・リザルト文・回収できる伏線が変わる。

---

## なぜ2人なのか

Vamp Ponの世界法則に合う。

```txt
1人では、意味を拾える。
2人なら、意味を確認できる。
```

ユイだけなら、持ち主を間違えない。

でも、アサがいれば名前をつけられる。

ナギがいれば理由を壊さずしまえる。

ミチルがいれば返す場所を読める。

トモリがいれば朝まで保持できる。

---

# 6. 変更システム

2人の組み合わせは固定しない。

```txt
ページ開始時に変更
特定Stage前に変更
地図帳で変更
イベントで一時固定
```

が候補。

ただし、いつでも自由に変えられると関係性が薄くなる。

おすすめは以下。

```txt
1ページ中は固定
ページ束の区切りで変更可能
```

理由:

```txt
1ページの中で関係性の意味が積み上がる
でも長期的には編成を試せる
```

---

# 7. コンビ必殺技

友情ポイントが一定以上で、コンビ必殺技が強化される。

## 例: ユイ + アサ

```txt
技名候補: もう一度、名前を書く
効果: 周囲の欠片を引き寄せ、影の名前固定を弱める
物語意味: 持ち主と名前の接続が安定する
```

## 例: ユイ + ナギ

```txt
技名候補: 月の箱舟
効果: 一定時間、理由の欠片を失わない
物語意味: 読むと壊れる理由を一時保護する
```

## 例: ユイ + ミチル

```txt
技名候補: 帰り道のしるし
効果: 進行方向に道しるべ攻撃/移動補助
物語意味: 持ち主と返却先がつながる
```

## 例: ユイ + トモリ

```txt
技名候補: 朝まで残る灯り
効果: 瀕死時に一度だけ残り火/範囲浄化
物語意味: 仮接続を朝まで保持する
```

---

# 8. 仲が悪い関係

仲が良いだけでは浅い。

仲が悪い組み合わせも必要。

ただし、仲が悪い = 弱いではない。

```txt
誤解が強い組み合わせほど、強いが不安定な技になる
```

例:

```txt
ユイ + 影系統キャラ
効果: 高火力だが、欠片の一部が黒インクへ戻る
意味: 返す思想と隠す思想が衝突している
```

```txt
ナギ + 手紙系統キャラ
効果: 手紙を守れるが、届けるタイミングが遅れる
意味: しまうことと届けることの対立
```

これにより、対立関係もゲームとして使える。

# 9. 男同士の関係性

男同士は、公式恋愛にしない。

ただし、仲良くする。

扱う関係性:

```txt
相棒
幼なじみ
ライバル
悪友
兄弟みたいな関係
嫌いだけど背中を預ける関係
```

BLはプレイヤーが勝手に読む分には止めない。

公式は押しつけない。

NG:

```txt
公式がBLを狙う
意味ありげな恋愛演出を男同士にだけ過剰に入れる
友情を恋愛の下位互換にする
```

OK:

```txt
命を預ける
喧嘩する
認め合う
一緒に馬鹿をやる
無言で助ける
```

# 10. 百合の扱い

百合は入れてもよい。

ただし、ユイとアサを公式百合にしない。

百合を入れるなら、以下のようにサブ/別ページ束で扱う。

```txt
届かなかった手紙
写っていない写真
年を取らない魔女と年を取る人間
```

百合の強み:

```txt
言えなかった名前
一緒に年を取れない
同じ時間にいられない
約束だけが残る
```

これらはVamp Ponの世界法則と相性が良い。

---

# 11. 年を取らない魔女 × 年を取る人間

かなり強い候補。

ただし、Season 1のメインには入れない。

理由:

```txt
スケールが大きい
時間差の感情が強すぎる
ユイ班の物語を食う可能性がある
```

使うなら、2以降または別ページ束。

## 主題

```txt
同じ約束を覚えているのに、同じ速さで年を取れない。
```

## 黒インクとの相性

```txt
人間側:
置いていかれた、と思う

魔女側:
置いていった、と思う

黒インク:
“同じ時間にいられなかった”という意味を固定する
```

## 小物候補

```txt
止まった懐中時計
古いリボン
毎年同じ日に届く手紙
若いままの写真
しおれない花
```

## ゲーム効果候補

```txt
時間停止
遅延ダメージ
年輪状の範囲攻撃
一定時間だけ昔の姿の影が見える
```

これはかなりエモい。

# 12. 重め関係の扱い

重い関係は入れる。

ただし、メインに置きすぎない。

置き場所:

```txt
サブページ
隠しリザルト
別ページ束
2以降
```

重め関係の例:

```txt
ずっと待っていた人
守るために嘘をついた人
届けないことで守った人
年を取る/取らない関係
親子なのに言えない関係
相棒だったが別思想になった関係
```

# 13. システムとしての友情ポイント名

表の名前候補:

```txt
友情ポイント
きずな
つながり
ページの結び目
同じ夜のしるし
```

内部名候補:

```txt
bond
connection
link
```

おすすめ:

```txt
表: きずな
内部: bond
```

理由:

```txt
友情にも相棒にも家族にも使える
恋愛に寄りすぎない
ゲームUIで分かりやすい
```

# 15. 最重要

Vamp Ponの感情システムは、恋愛好感度ではない。

```txt
誰と誰の間で、どの誤解がほどけたか。
```

それをゲーム的には友情ポイント/きずなとして見せる。

恋愛はサブ。

友情はメイン。

重い関係は、サブや後作で深く刺す。

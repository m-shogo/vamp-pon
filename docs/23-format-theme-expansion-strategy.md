# フォーマット × 題材の横展開戦略

## 目的

Vamp Pon の企画では、世界観を1回きりの装飾として考えない。

重要なのは、以下の構造。

```txt
強いゲームフォーマット
×
差し替え可能な題材
=
長く広げられる作品
```

## 背景

カイロソフトは、経営/育成/配置/収集/成長のフォーマットを持っている。

そこに、どら焼き屋、ラーメン、温泉、ゲーム会社、空港、学校、町、冒険、IP作品など、題材を差し替えて展開している。

最近の例として、カイロソフトが One Piece 題材の管理ゲームを展開するという報道がある。

これは、個々の題材そのものよりも、カイロソフトのフォーマットが強いことを示している。

## 話したい本質

ドラえもんや One Piece を真似したいわけではない。

言いたいことは以下。

> フォーマットが良ければ、別の題材で何度でも広げられる。

Vamp Pon でも同じ考え方が必要。

## カイロソフト型の強さ

### 1. フォーマットが先にある

カイロソフトの多くのゲームは、題材が違っても根本は近い。

- 小さい施設を作る
- 人や客が来る
- 数字が伸びる
- 新しい要素が解放される
- 配置や相性を考える
- 図鑑/収集がある
- だんだん賑やかになる

題材が変わっても、楽しさの骨格は残る。

### 2. 題材は意味を増やす

題材は、ゲームをゼロから作るものではなく、フォーマットに意味を付ける役割。

例:

```txt
店経営フォーマット × どら焼き = ドラえもんのどら焼き屋
店経営フォーマット × One Piece = バラティエ/料理/海賊/客/仲間
学校経営フォーマット × 学園 = 学生/部活/授業/進路
温泉経営フォーマット × 旅館 = 客室/温泉/土産/観光
```

### 3. IPは素材密度を増やす

有名IPを使うと、以下が最初からある。

- キャラ
- 場所
- 道具
- 名台詞
- ファンの知識
- 収集欲
- 報酬名
- イベント

ただし個人開発ではIPは使えない。

だから、Vamp Ponでは **IPの代わりに民話・童話・動物・道具・夢・おもちゃなど、共有知識のある題材**を使う。

## Vamp Pon のフォーマット

Vamp Pon の核は、以下。

```txt
移動する
自動攻撃する
敵が溶ける
経験値を吸う
レベルアップする
武器が育つ
進化する
条件達成で報酬を得る
永続的に少し強くなる
図鑑/秘宝/アンロックを集める
また遊ぶ
```

これは題材を差し替えられる。

## 重要な設計原則

### 題材は最初から広げすぎない

フォーマットが未完成の状態で題材を広げると、素材だけ増えてゲームが弱くなる。

MVPでは、題材を1つに絞る。

### でも構造は横展開前提にする

内部データは、後で題材を差し替えやすい構造にする。

例:

```txt
weaponTheme
enemyTheme
stageTheme
rewardTheme
unlockCondition
collectionCategory
```

### 題材ごとの言葉を分ける

同じ効果でも、題材で名前を変えられるようにする。

例:

```txt
攻撃力 +3%

おもちゃ箱: ブリキのバッジ
妖怪夜市: 鬼火の鈴
童話図書館: 金のしおり
夢: 月のしずく
```

## 個人開発での注意

大企業や正式ライセンス作品と同じことはできない。

### できないこと

- One Piece を使う
- ドラえもんを使う
- 有名キャラを出す
- 有名作品の見た目を真似る
- 大量キャラを最初から作る

### できること

- フォーマットを強くする
- 共有知識のある題材を使う
- 題材を抽象化して独自化する
- 小さいMVPから広げる
- 条件報酬/図鑑/進化で長く遊ばせる

## リスク

### 題材だけ変えても面白くならない

フォーマットが弱いまま題材を乗せても続かない。

まず爽快感、成長、進化、報酬の手触りが必要。

### 題材を広げすぎると散る

童話、妖怪、おもちゃ、動物、夢を全部入れると統一感がなくなる。

主軸は1つ、補助は1〜2個まで。

### 将来の拡張を考えすぎるとMVPが重くなる

横展開前提の構造は考えるが、最初から全部作らない。

## Vamp Pon の推奨戦略

### Step 1: まず1テーマで完成度を作る

候補:

```txt
おもちゃ箱の夜 × 悪夢の影 × 動物の仲間
```

### Step 2: フォーマットを固める

- 敵撃破
- 経験値回収
- レベルアップ
- 武器進化
- 条件達成報酬
- 永続強化
- 図鑑
- リザルトヒント

### Step 3: 別題材に差し替えられるか確認する

同じフォーマットで以下に置き換えられるかを見る。

```txt
妖怪夜市版
童話図書館版
夢の森版
文房具机上版
```

置き換えられるなら、フォーマットが強い。

## 判断基準

良い題材とは、単に見た目がいいものではない。

良い題材は、以下を満たす。

```txt
敵が作れる
武器が作れる
報酬が作れる
進化が作れる
ステージが作れる
図鑑が作れる
条件達成が作れる
別テーマ展開も想像できる
権利リスクを制御できる
```

## 現時点の結論

ユーザーが話したいことは、世界観単体ではなく、**フォーマットの強さと題材の横展開性**。

Vamp Ponでは、まず Vampire Survivors ライクの爽快フォーマットを強くする。

その上で、題材を1つ選ぶ。

最初の題材は、権利リスクと素材負荷を考えると以下が有力。

```txt
おもちゃ箱の夜 × 悪夢の影 × 動物の仲間
```

ただし、将来の展開では同じフォーマットを以下にも差し替えられるように考える。

```txt
妖怪夜市
童話図書館
夢の森
文房具の机
```

題材は作品の顔。

でも、本当の資産はフォーマット。

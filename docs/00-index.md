# Vamp Pon 構成メモ置き場

このディレクトリは、Vamp Pon の企画・仕様・実装方針を少しずつ積み上げる場所です。

## 目的

Vamp Pon を「なんとなくヴァンサバっぽいゲーム」ではなく、**5戦線管理が面白さの核になっている小さなローグライト無双**として固める。

## ドキュメント一覧

- `01-concept.md` — ゲームコンセプト
- `02-core-loop.md` — 1プレイの流れ
- `03-five-front-system.md` — 5戦線システム
- `04-mvp-scope.md` — MVPと作らないもの
- `05-tech-stack.md` — 技術方針
- `06-roadmap.md` — 開発ロードマップ
- `07-agent-rules.md` — AIエージェント作業ルール
- `08-idea-backlog.md` — アイデア置き場

## 使い方

新しい案が出たら、まず `08-idea-backlog.md` に雑に入れる。

採用する案は、該当する設計ドキュメントへ移す。

実装前に、少なくとも以下を確認する。

- 5戦線の面白さに関係あるか
- 個人開発で作れるか
- 序盤の気持ちよさを壊さないか
- 終盤の判断要素になるか
- ただの機能追加で終わっていないか

## 最優先の判断基準

面白そうな追加より、**完成に近づく追加**を優先する。

# 6. Dream living rule — P1 interpretation

Reality Civilian BibleをDreamへそのまま移植しない。

Dreamで容易に補完できる:

- 食事
- 飲料
- 日用品
- 休息
- 基本生活物

Wishで解決できない:

- 心
- 同意
- 記憶真実
- トラウマ
- 人間関係
- 黒耀化
- Reality大事件
- 生死

これにより日常sceneは豊かにしつつ、生存サバイバル / 万能願望世界の両方を避ける。

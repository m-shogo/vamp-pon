# Stage and Boss Roadmap

## 目的

Vamp Pon の将来拡張として、Stage 1〜5 とボス構成を整理する。

重要:

```txt
Stage 5 / ボスはMVPには入れない。
```

この資料は、MVP後にステージ拡張するための設計レイヤー。

---

# 1. 現在のMVPとの関係

## MVPで作るもの

```txt
Stage 1相当
ユイのみ
8分ラン
通常敵5種 + 黒ラベルの影
記憶カプセル
進化1〜2種
必殺技1種
```

## MVPで作らないもの

```txt
Stage 2〜5
本格ボス
複数ステージ選択
ステージ別ギミック
エンディング分岐
```

## 理由

```txt
まず1ステージで、移動・自動攻撃・欠片回収・進化・リザルトが面白いか証明するため。
```

Stage 5やボスを先に入れると、何が原因で面白い/面白くないか分からなくなる。

---

# 2. ステージ設計の基本方針

ステージは、背景違いではなく、以下の違いを持たせる。

```txt
敵の圧
欠片回収のしやすさ
カプセルの出方
ステージギミック
ボスの要求する避け方
裏ストーリー断片
```

ただし、操作は増やさない。

```txt
移動
自動攻撃
必殺技1ボタン
```

は維持する。

# 3. Stage一覧

## Stage 1: 忘れ物の夜

### 役割

MVPステージ。

### テーマ

```txt
忘れ物
地図帳
黒インク
最初の夜
```

### 体験

```txt
基本操作
欠片回収
レベルアップ
初カプセル
初進化
```

### ボス扱い

本格ボスなし。

黒ラベルの影を強敵/ミニボス扱いにする。

### 解放

初期解放。

---

## Stage 2: 紙片の通学路

### 役割

速い敵と横方向の圧を増やす。

### テーマ

```txt
通学路
落とし物
紙片
消えた名前
```

### 新要素候補

```txt
紙くず系の敵増加
横から流れる敵
道をふさぐ薄い影
```

### ボス候補

```txt
名札をなくした影
```

### ボス体験

```txt
速い小型影を呼ぶ
一定時間ごとに横切る影を出す
本体は硬すぎない
```

### 目的

移動の気持ちよさを維持したまま、少し避ける力を要求する。

---

## Stage 3: 黒インクの図書室

### 役割

範囲制圧と視認性のテスト。

### テーマ

```txt
図書室
しおり
黒インク
読めなくなったページ
```

### 新要素候補

```txt
黒インクだまり
一時的に視界を狭めるもや
硬い敵
```

### ボス候補

```txt
塗りつぶされた司書
```

### ボス体験

```txt
床に黒インクを置く
安全地帯を少しずつ狭める
必殺技や範囲武器で押し返す
```

### 注意

黒インク床はMVP後。

スマホで見づらいなら入れない。

---

## Stage 4: 迷子の駅

### 役割

方向感と敵の回り込み。

### テーマ

```txt
駅
古い切符
行き先のないホーム
迷子の方角
```

### 新要素候補

```txt
左右/上下から流れる敵
一定間隔で方向が変わる敵
列のように進む影
```

### ボス候補

```txt
終点のない車掌
```

### ボス体験

```txt
画面端から列車状の影を流す
安全ラインを見つけて移動する
攻撃は自動なので、避けの判断を中心にする
```

### 注意

通路型ステージにはしない。

Vamp Ponは自由移動のまま。

---

## Stage 5: 朝を忘れた地図帳

### 役割

初期ワールドの締め。

### テーマ

```txt
地図帳
黒インク
朝
消えなかった影
最後の空白ページ
```

### 体験

```txt
これまでの敵傾向が混ざる
カプセル/進化前提
必殺技の使いどころが重要
最終ボスで朝を取り戻す
```

### ボス候補

```txt
朝を忘れた影
```

または:

```txt
最後の空白ページ
```

### ボス体験

```txt
画面全体を黒インクで塗りつぶそうとする
記憶の欠片を吸わせる/拾うことで押し返す
攻撃で倒すだけではなく、欠片回収が意味を持つ
```

### 目的

Vamp Ponらしい決着。

ただ強い敵を殴るだけにしない。

# 4. ステージ解放案

## 初期

```txt
Stage 1のみ
```

## MVP後

```txt
Stage 1クリア → Stage 2解放
Stage 2クリア → Stage 3解放
Stage 3クリア → Stage 4解放
Stage 4クリア → Stage 5解放
```

## ただし

Prototype段階では解放制を作らない。

まずStage 1が楽しいか確認する。

---

# 5. ステージ別プレイ時間

基本は8分。

```txt
Stage 1: 8分
Stage 2: 8分
Stage 3: 8分
Stage 4: 8分
Stage 5: 8〜10分候補
```

Stage 5だけ10分にする案はある。

ただし、スマホでは長く感じる可能性があるため、初期は8分で検証する。

---

# 6. ボス出現方式

## MVP / Stage 1

```txt
3:00 / 5:00 / 7:00 に黒ラベルの影
```

黒ラベルの影は本格ボスではなく、報酬強敵。

## Stage 2以降

候補:

```txt
7:00にステージボス出現
8:00までに倒す/耐える
```

または:

```txt
8:00到達でボス演出なしクリア
ボスは別モード
```

推奨:

```txt
Stage 2〜4は7:00ボス
Stage 5は専用最終ボス
```

---

# 7. ボス設計原則

## やる

```txt
移動で避けられる
攻撃は自動のまま
パターンが見て分かる
短い山を作る
倒すと報酬/解放がある
```

## やらない

```txt
弾幕シューティング化
細かい手動エイム
長いカットシーン
大量HPの耐久だけ
即死攻撃
画面が見えないほどの演出
```

---

# 8. Stage 5を今作らない理由

```txt
Stage 1の核が未検証
武器差が未検証
進化が未検証
必殺技が未検証
スマホ実機負荷が未検証
```

この状態でStage 5を作ると、仕様は豪華でもゲームが面白くならない可能性が高い。

---

# 9. Stage 5を作る条件

以下を満たした後。

```txt
Stage 1 MVPが仮素材でも面白い
Prototype 3で8分体験が成立
進化1〜2種が気持ちいい
必殺技が2〜4回使われる
スマホで重くない
リザルトでもう一度遊びたい
```

---

# 10. 結論

Stage 5とボスの方向性は必要。

ただし、今のMVP仕様には入れない。

```txt
Stage 5 / Boss Spec: Future Layer
MVP Scope: Stage 1 only
```

これを守る。

# ヨルノシルベ Stage × Character × Relationship Placement v1

Date: 2026-07-29  
Status: **CURRENT STORY PRODUCTION DIRECTION / EXACT SCENARIO ORDER & BOSS ASSIGNMENTS NOT LOCKED**

> 目的: Stage1〜5を「Core5が一人ずつ主役になるだけ」の章立てにせず、Gameplay・Enemy pressure・Bond・黒耀化・日常の反復を同じ流れへ配置する。
>
> Stage1〜5のCore spineは **ユイ / アサ / ナギ / ミチル / トモリ**。ただしCircle / Shadowも各Stageで違う役割を持つ。

---

# 0. 5Stage共通のstory cadence

1Stage内で長いcutsceneを連続させない。

```txt
A. 出発前の短い日常
B. 普通のrun / enemy motif提示
C. 仲間の便利な連携
D. 同じ長所が原因の小さな失敗
E. encounterが人物の一択思考を圧迫
F. short result / camp scene
G. 別run /別Supportで違う解を試せる
H. chapter climax
I. dawn proof
```

Playerが読む必要のない情報はBOND / 灯録へ逃がす。

# 1. Stage1 — ユイ / 「戻す」

## Central question

> **見つけたものは、全部持ち主へ戻すべきか。**

最初は最も分かりやすいGameplayから始める。

- 敵を倒す
- 記憶片を拾う
- Level Up
- 忘れ物を見つける
- Supportと生還する

この時点では世界原理を説明しすぎない。

## Main spotlight

- ユイ — owner / memory / pickup
- アサ — 初期buddy。速さと確認
- クロオリ — 「開かない / 預かる」という反対解を早めに見せる

## Supporting rotation

- コヨリ — 小さい名前 / 所有の感覚
- ユウビ — 返すだけでなくtiming
- マドカ — 見つけたものを伝える
- トモリ — ユイのランタンへ初期違和感を置くCandidate

## Enemy pressure vocabulary

- 紙片
- 墨
- 鈴
- 名札
- 持ち主不明pickup
- 引き寄せると危険になる配置

Enemyは「拾う = 常に正解」を崩す。

## Relationship beats

### ユイ × アサ

1. アサが先に行き、ユイが拾う
2. 便利でテンポが良い
3. アサはowner確認を急ぐ
4. ユイは全部拾おうとして危険へ入る
5. 二人とも「置いていきたくない」が根にあると分かる

### ユイ × クロオリ

最初の印象は敵対寄りでよい。

- ユイ = 返す
- クロオリ = 折って隠す

ここでは「過去のユイが預けた」真相Candidateを答えない。

## Black-youka exposure

ユイの黒灯化はStage1で**完全決着まで行かなくてもよい**。

最初は:

- pickup吸引が強すぎる
- 星獣が少し距離を取る
- クロオリが一つだけ折る

程度の予兆でも成立。

Main Storyで大きく扱うなら、Stage1終盤またはStage5再帰で回収する。

## Dawn proof

出発前ならユイは落とし物を即拾う。

Stage1後:

> 「これ、誰の？」

と言ってから触る。

ほんの一拍の確認を成長にする。

# 2. Stage2 — アサ / 「名前」

## Central question

> **名前を戻すことと、その人を分かったことは同じか。**

## Main spotlight

- アサ
- カスミ
- ユイ

## Supporting rotation

- セン — 言葉 / 仮の説明
- コヨリ — 名前を書いてもらう喜び
- シロ — 未分類
- ユウビ — 宛名を出せないdelivery

## Enemy pressure vocabulary

- 名札
- 消印
- label duplication
- owner mismatch
- blank tag
- decoy naming

現行Boss46「持ち主のない名前」と非常に相性が良いが、**Stage2 bossへの正式固定はまだしない**。

## Relationship beats

### アサ × カスミ

初期:

> アサ「名前を消すな。」  
> カスミ「見せないことと、消すことは違う。」

中盤:

- 名前を出すとdanger targetになるencounter
- 隠すとSupportが届きにくいencounter

Playerがvisibilityを選ぶことで思想を体験する。

### セン × シロ

- センは仮の説明を付けたい
- シロは未分類を残したい

「仮説」と「正解」の違いを生活側から補強。

## Black-youka exposure

アサ黒銘化。

- markで敵処理は非常に強い
- Ally / objectまで一意に定義し始める

戻す鍵はカスミのconcealではなく、**本人confirmを挟むこと**。

## Dawn proof

初期:

> 名前を聞く → 即復唱

後:

> 「なんて呼べばいい？」

へ変わる。

名前を大切にする人格は変えない。

# 3. Stage3 — ナギ / 「守る」

## Central question

> **危険から守るためなら、本人の選択肢を閉じてもよいか。**

## Main spotlight

- ナギ
- カナメ
- トバリ

## Supporting rotation

- リツ / コヨリ — 守る側 / 守られる側の反転
- クロオリ — 閉じることの別variant
- ハナ — 保存することと止めること

## Enemy pressure vocabulary

- 鍵穴
- 月箱
- 封鎖
- lane close
- shield
- shrinking safe area

Boss47「閉じた朝箱」と思想相性が非常に高いが、正式Stage assignmentはHuman / encounter review前にLOCKしない。

## Relationship beats

### ナギ × カナメ

- ナギはhazardを閉じる
- カナメは身体で受ける
- 低Bondでは二人とも同じ攻撃へ防御resourceを使う
- 一度partyの退路を失う
- 交互防御へ

### ナギ × トバリ

- 閉じる時にreopen条件を持たせる
- 「安全」と「帰れる」を分ける

### リツ × コヨリ

このStageで兄が妹を守るだけの関係を崩す。

コヨリ側が救援を成功させるGameplay proofを置く。

## Black-youka exposure

ナギ黒箱化 / カナメ黒影化のどちらかをMainで大きく扱い、もう片方はmirrorとして見せると密度が良い。

両方を連続full episodeにしない。

## Dawn proof

ナギが箱を閉じる前に:

> 「あとで開ける。」

ではなく:

> 「いつ開ける？」

と本人へ聞く。

トバリは門を閉じた後ではなく、出発前に帰る時刻を確認する。

# 4. Stage4 — ミチル / 「正しい道」

## Central question

> **正しい道は一つなのか。正しかった道は、ずっと正しいのか。**

## Main spotlight

- ミチル
- トキ
- ゲン

## Investigation ensemble

- マドカ — 遠景 / warning
- レン — difference
- ネム — 別時代らしき夢

この5人を「説明班」にしない。

それぞれ:

- ミチル = 行く
- トキ = 測る
- ゲン = 覚えている
- マドカ = 見る / 伝える
- レン = 比べる
- ネム = 感覚的な異時代断片

と動詞を分ける。

## Enemy pressure vocabulary

- 切符
- 方位
- 地図ピン
- 迷針
- 改札
- reverse route
- old route / new route

Boss48「帰路のない夜」はStage4 / endgameのどちらにも相性が良い。配置は未LOCK。

## Relationship beats

### ミチル × トキ

- 勘 vs 測定、ではない
- 現場で更新する人 vs 値を測る人
- 両方必要

### ミチル × ゲン

ゲンの道が「古くて間違い」なのではなく、当時は本当に存在したことを確認する。

### マドカ × レン × トキ

同じ観察系にしない。

```txt
マドカ: 何か起きた
レン: 前と違う
トキ: どれくらい違う
```

## Time-layer reveal

C級として1で説明すべき部分:

> **この夜には、現実で同時代ではない人 / 物 / 景色が接続され得る。**

ただし「夜の正体が何か」はA級 / OPENのまま残せる。

## Black-youka exposure

ミチル黒針化またはトキ黒刻化を中心に、一本のperfect routeが逆にpartyを閉じ込める。

Playerが途中でrouteを捨てることを勝ち筋へする。

## Dawn proof

ミチルの地図に、一本の太線ではなく**二本の細い候補線**が残る。

ゲンがそれを直さない。

トキが片方へ「暫定」と書く。

# 5. Stage5 — トモリ / 「直す・残す・朝へ進む」

## Central question

> **壊れたものを大切にするとは、元通りにすることなのか。**

ここで1〜4のThemeを「保存し続けることだけが愛か」へまとめる。

## Main spotlight

- トモリ
- ツムギ
- ユイ

## Supporting rotation

- ハナ — 保存
- シロ — 未分類 / blank
- クロオリ — 閉じて保持
- ネム — 夢から現実へ持ち帰る
- アサ / ナギ / ミチル — Core5の成長を短い行動で再提示

## Enemy pressure vocabulary

- 糸
- マッチ
- 朝露
- 片ボタン
- 継ぎ目
- 灯り
- 「直すほど跡が消える」object

旧アサマデの6翼 / dawn-break visualは高価値reservoirだが、Current Stage5 bossへ自動復活させない。

## Relationship beats

### トモリ × ツムギ

- 直す / 余白を残す
- 完成 / 続き
- 傷跡 / scar trait

### ユイ × トモリ

ランタンの修理跡をStage1から見せていた場合、ここでCharacter Mysteryをかなり回収できる。

ただし:

- 血縁確定
- 星獣の魂理論確定
- 夜の作成者確定

まではしない。

## Main Theme convergence

Stage5ではCore5の問いを同じ場面へ重ねる。

```txt
ユイ: 全部戻さなくていい
アサ: 全部定義しなくていい
ナギ: 全部閉じなくていい
ミチル: 道は一本でなくていい
トモリ: 元通りでなくても直せる
```

共通する答え:

> **大切にすることは、一つの完成形へ固定し続けることではない。**

これは作品Theme候補「忘れないことだけが大切にすることなのか」と自然につながる。

## Black-youka / climax

Stage5 climaxで全員順番に黒耀化するのは避ける。

推奨:

- トモリ黒継化をchapter personal climax
- ユイ黒灯化 / クロオリ関係をMain Mystery emotional climaxへ再接続
- 他Core3は、以前できなかった小さい行動をGameplay中に自然に行う

## Dawn proof

トモリがユイのランタンを調整する。

古い修理跡を消せる。

でも消さない。

> 「ここは、このままでいい。」

その後、ユイが火を点ける。

説明台詞を増やさず、作品Themeを物で回収する。

# 8. What Stage5 must answer / not answer

## C級 — 1で答える

- Core5がそれぞれ何を学んだか
- クロオリが単純悪ではないこと
- 黒耀化が本人の一部であること
- 朝へ帰る理由
- Current仲間が再び日常へ戻れること
- 夜が単一の現実年代ではないこと

## B級 — かなり答えるが意味を残せる

- ユイのランタンの履歴
- ユイ × トモリの獅子共鳴
- クロオリが何をどこまで預かっていたか
- 星獣が人より先に何へ反応しているか

## A級 — seriesへ残せる

- 夜の完全な正体
- 誰が / なぜ仕組みを作ったか
- 星獣の完全な原理
- 黒い折り紙等の別Layer hook

**A級を残すためにC級を曖昧にしない。**

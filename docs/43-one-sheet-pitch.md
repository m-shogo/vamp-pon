# Vamp Pon ワンシート企画書

## タイトル

```txt
Vamp Pon
```

仮タイトル。正式タイトルは後で検討する。

## ジャンル

```txt
スマホ向け・縦持ち・ローグライト・サバイバルアクション
```

分かりやすく言うと、Vampire Survivors ライク。

ただし、PC向けヴァンサバをそのまま移植するのではなく、スマホで短く触れる形に補正する。

## 対応プラットフォーム

初期:

```txt
Web / スマホブラウザ
```

将来:

```txt
PWA
Capacitorによるアプリ化
iOS / Android
```


## プレイヤーの裏目的

ゲーム内で直接説明しない。

```txt
影は敵ではなく、忘れられた記憶だった。
プレイヤーは、黒インクで消えかけた名前と旅の記録を取り戻している。
```


## 何が気持ちいいゲームか

優先度順。

```txt
1. 影が溶ける
2. 欠片が吸い寄せられる
3. レベルアップで強くなる
4. 武器が進化する
5. 必殺技で一気に押し返す
6. リザルトで成長と発見が見える
7. 図鑑/実績で裏ストーリーの断片に気づく
```

## 独自性

### 1. 経験値ではなく「記憶の欠片」

表面上は経験値。

裏では、忘れられた物や旅の記録の欠片。

### 2. 宝箱ではなく「記憶カプセル」

強敵を倒すと開く。

武器進化や報酬の快感を担う。

### 3. キャラ別必殺技

操作を増やしすぎず、1ボタンまたは自動発動で使える。

MVPではユイの「消えない名前」。

### 4. 裏ストーリー断片

長い会話や説明ではなく、以下で見せる。

```txt
アイテム説明
実績文
図鑑文
記憶カプセル文
リザルトの1行
```

## MVP範囲

### 入れる

```txt
縦持ち
ユイ
8分ステージ
自動攻撃
レベルアップ3択
武器5種
パッシブ5種
敵5種 + 強敵
記憶カプセル
進化1〜2種
必殺技1種

最低限の図鑑/実績

```

### 入れない

```txt
本格デザイン
大量キャラ
複数ステージ
オンラインランキング
課金
広告
長編ストーリー
複雑な地形
PWA/Capacitor本対応
```

## 8分MVPの流れ

```txt
0:00-1:30  操作と成長を理解する
1:30-3:00  速い敵で初ピンチ
3:00       初カプセル
3:00-5:00  硬い敵/回り込みでビルド差
5:00       進化チャンス
5:00-7:00  群れで圧力
7:00       最後のカプセル
7:00-8:00  クライマックス
8:00       朝 / リザルト
```

## 成功条件

MVPが成功と言える条件。

```txt
初回でも1分以内に面白さが分かる
スマホ縦持ちで操作が破綻しない
欠片回収が気持ちいい
3択レベルアップが一目で分かる
8分の中で山がある
1回は進化を見たくなる
必殺技が押したくなる
リザルトで次も遊びたくなる
```

## 制作上の注意

```txt
仕様を増やさない
ユイ1人をまず楽しくする
デザイン保留中は仮素材で完成度評価しない
スマホで読めない説明文は入れない
戦闘中に裏ストーリーを長文表示しない
```

## このゲームの一番大事な問い

```txt
ユイで8分遊んで、もう一度遊びたいか？
```

この答えがYESになるまで、キャラやステージを増やさない。

# ユイ グッズ / IPキャラ チェックリスト

ユイを「アクキー / ステッカー / ぬいぐるみ / LINEスタンプ」に展開しても通用するIPキャラにするためのチェックリスト。

このチェックは sprite 完成判定ではなく、**IP/グッズ観点の品質ゲート**。
ゲーム用の品質ゲートは [../pixel-art-quality-gate.md](../pixel-art-quality-gate.md)、production 反映条件は [../reviews/yui-next-production-readiness-plan.md](../reviews/yui-next-production-readiness-plan.md) を参照。

関連: [yui-52px-master-design.md](yui-52px-master-design.md)

---

## 1. 採点基準（5段階）

各項目を 1〜5 で採点する。

| 点 | 意味 |
| ---: | --- |
| 5 | グッズにして売れる / 欲しい。迷わず採用 |
| 4 | 採用ライン。商品化に耐える |
| 3 | 惜しい。保留。手直し必要 |
| 2 | 弱い。記号 or 愛嬌が不足 |
| 1 | グッズに耐えない。作り直し |

**1項目でも 3 以下があれば、IP master として採用しない（temporary / draft 据え置き）。**

---

## 2. チェック項目

| # | 項目 | 見るポイント | Score (1-5) | Notes |
| ---: | --- | --- | ---: | --- |
| 1 | 黒塗りシルエットでもユイと分かるか | フード+体+右手ランタンの形だけで判別できるか。キノコにならないか | | |
| 2 | 1xでも主人公と分かるか | 実寸で「これは主役の女の子」と読めるか | | |
| 3 | 4x / 6xで見ても可愛いか | 拡大で粗・崩れが出ず、むしろ可愛くなるか | | |
| 4 | ランタンが記号として効いているか | 右手のランタン＋暖色コアが第二記号になっているか。浮いていないか | | |
| 5 | 顔に愛嬌があるか | 大きな目・白キャッチライト・頬・少し困り眉で、無表情でないか | | |
| 6 | フードと体の比率が気持ちいいか | フード40〜45% / 顔20〜25% / 体25〜30%が破綻していないか | | |
| 7 | 横向き / 背面でも同一人物にできるか | front以外に展開しても「同じユイ」に見える設計余地があるか | | |
| 8 | グッズにした時に欲しいと思えるか | アクキー/ぬいぐるみで手元に置きたいか | | |
| 9 | 二次創作しやすいか | 特徴が掴みやすく、他者が描き起こせるか（青フード/前髪/目/ランタン） | | |
| 10 | アイコン化できるか | 顔＋フードだけを切り出してSNSアイコン/スタンプにしても成立するか | | |

---

## 3. 媒体別の追加観点

| 媒体 | 追加で見る点 |
| --- | --- |
| アクリルキーホルダー | 輪郭が抜きやすいか。細すぎる突起（取っ手・脚）が折れて見えないか |
| ステッカー | 白フチを付けても可愛いか。背景なしで自立するか |
| ぬいぐるみ | 立体化したとき頭/体/フードの比率が破綻しないか。顔が縫いで再現できる単純さか |
| LINEスタンプ | 1個16x16〜程度に縮んでも表情が読めるか。感情の振り（喜/困/驚）に展開しやすいか |

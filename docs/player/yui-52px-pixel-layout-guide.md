# ユイ 52px ピクセルレイアウトガイド

Aseprite GUI で 52px master を描く前の、**具体的なピクセル配置・比率の指示**。
抽象設計は [yui-52px-master-design.md](yui-52px-master-design.md)、表情は [yui-52px-expression-guide.md](yui-52px-expression-guide.md)、ランタン/服は [yui-52px-lantern-and-costume-guide.md](yui-52px-lantern-and-costume-guide.md)。

座標値は **推奨開始位置**。GUIで ±1〜2px は調整してよい。比率の上限/下限（特にフード上限・顔下限）は守る。

---

## 1. canvas座標の基準

- canvas: **52 x 52px**、左上が原点 `(0,0)`、右下が `(51,51)`。
- 横中心線: **x = 25.5**（cols 25 と 26 の間）。キャラは中心線に対してほぼ左右対称、ランタンだけ右に逃がして非対称にする。
- 縦の基準: 上端から下端へ、頭→顔→体→脚。接地線は y≈50。
- 1辺52pxを「縦の立ち姿」で使う。余白は上1px・下1〜2px程度に抑え、キャラを大きく取る。

```txt
       x=25.5 (中心)
        |
 0 ─────┼───────────────── 51
 0  ┌───────────────────┐
    │      hood peak     │  y0-2
    │   ███ HOOD ███     │  y1-23  フード(40-45%)
    │  ██ ┌───────┐ ██   │
    │  ██ │ FACE  │ ██    │ y9-22  顔(20-25%) ※フード開口の内側
    │  ██ └───────┘ ██   │
    │  CLOAK shoulders    │ y22-38
    │   ███ DRESS ███  L  │ y26-46 体(25-30%) / L=lantern y38-47
    │   ██ legs/boots ██  │ y46-50
 51 └───────────────────┘
```

## 2. 各パーツの推奨占有範囲

縦52px基準。括弧内は [master-design](yui-52px-master-design.md) §3 の比率。

| パーツ | 縦範囲(y) | 横範囲(x) | 比率 | メモ |
| --- | --- | --- | --- | --- |
| head/hood 外周 | y1〜23 | x9〜42（最大幅 ~33px） | フード40〜45% | 上端にゆるい peak。下縁は肩へ流れる |
| hood peak（頂点） | y1〜5 | x22〜29 | — | 尖りすぎない。丸い三角の頂点 |
| face 開口 | y9〜22 | x15〜35（幅 ~20px） | 顔20〜25% | フードの内側。中心 (25,17) 付近 |
| cloak（肩〜側面） | y22〜38 | x6〜45 | 体に含む | dress の後ろ、hood の下 |
| dress 本体 | y26〜46 | 台形：上 x18〜33 → 下 x11〜40 | 体25〜30% | 上が狭く下が広い。三角錐にしない |
| legs/boots | y46〜50 | 左靴 x20〜24 / 右靴 x27〜31 | 体に含む | 必ず2本見せる |
| lantern | y38〜47 | x38〜46（幅 ~9px） | 8〜12% | 右手。中心線から右に離す |
| 接地影 | y49〜51 | x12〜39 | — | 半透明、輪郭なし |

> 推奨開始値（52px draft で実証済み）:
> - face 楕円中心 `(25, 17.5)`、半径 rx≈9.6 / ry≈8.6
> - hood ドーム中心 `(25.5, 16)`、半径 rx≈16.5 / ry≈14、y≤23
> - lantern ケージ cols 38〜46 / rows 38〜47

## 3. フード上限・左右幅・顔位置（キノコ化を避ける比率）

これは「青いキノコ化」を構造的に防ぐための **絶対線**。

- **フード縦は y23 を超えて顔を覆わない**（フード ≤ 45%）。フードが顔の下半分まで来たらキノコ。
- **フード最大幅は ~33px（x9〜42）まで**。これ以上横に膨らませると頭でっかちになる。
- **顔は y9〜22・幅~20px を死守**（顔 ≥ 20%）。フードを優先して顔を削らない。
- **顔の中心は canvas 中央よりやや上（y17 付近）**。フードに「抱かれる」位置。
- フードと顔は重なってよい（フードが顔を囲む）。ただし顔の開口面積は確保する。

NG判定（[master-design](yui-52px-master-design.md) §5 と連動）:
- 顔開口が幅16px未満 → キノコ寄り。フードを削って顔を広げる。
- フード下縁が y24 以下に侵入 → キノコ。上げる。
- 体（dress+脚）が y26〜50 で見えていない → 三角錐化。脚を出す。

## 4. 黒塗りシルエットで成立する条件

silhouette だけ（単色）で以下が読めること（[merchandise](yui-merchandise-character-checklist.md) #1）:

1. **丸い頭（フード）** が上部にある。
2. その下に **細くなる首/肩 → 広がる体** がある（くびれが1段ある）。
3. **右下にランタンの出っぱり** がある（輪郭にコブ）。
4. 最下部に **2つの足** の凹凸がある。

→ この4点が黒1色で出ていれば合格。出ていなければ造形を直す。
→ シルエットは **顔やランタンの中身を描く前** に確定する（[gui-handoff](yui-aseprite-gui-handoff.md) Step1）。

## 5. 1xで読ませるために省略してよいディテール

42px/52px の 1x 実寸では、以下は省略・簡略してよい。

- 前髪の細かい毛束（数本の tip に集約）
- 服の細かい折り線（主要な縦1〜2本に集約）
- ランタンのケージの細い格子（枠＋縦1本でよい）
- 頬の濃いグラデ（1〜2pxの淡い塊でよい）
- 瞳の多階調（虹彩＋瞳孔＋キャッチライトの3要素で十分）

優先するのは「シルエット＋色面のコントラスト」。1xは情報量より読みやすさ。

---

## 6. 4x/6xで可愛く見せるために残すディテール

拡大（グッズ/設定画）では、以下を必ず残す/描き込む。

- 目の **白キャッチライト**（生気）。左右で位置を揃える。
- 前髪の **束の明暗 2〜3階調**（楕円塗りに見せない）。
- フード **内側ライニングの1px暗ライン**（立体感）。
- ランタンの **暖色2階調＋記憶の光スパーク**。
- 服の **裾の暗み＋しおり紐の赤**。
- 頬の **ほんのりピンク**。

→ 1xで省略したものも、master では「レイヤーとして」持っておく（[gui-handoff](yui-aseprite-gui-handoff.md) §2）。表示サイズに応じて見せ方を変える。

---

## 7. チェック

- 黒塗りシルエットで4条件（§4）が成立するか
- フード ≤45% / 顔 ≥20% / 体 25-30% / ランタン 8-12%（§2,§3）
- 1xで読め、かつ4x/6xで可愛い（§5,§6）

1つでも崩れたら造形を戻す。先に進まない。

# ユイ 52px ランタン & 衣装ガイド

52px master のランタン・服を具体ピクセルへ落とすガイド。
ランタンは第二の主役記号、服は世界観（記憶/紙）の受け皿。

前提座標は [yui-52px-pixel-layout-guide.md](yui-52px-pixel-layout-guide.md)、色は [yui-52px-master-design.md](yui-52px-master-design.md) §4。

座標は推奨開始値。GUIで調整可。ただし「ランタンを中心線に寄せない」「脚を見せる」は守る。

---

## A. ランタン

### A-1. 位置

- **右手側、canvas中心(x25.5)から右に離す。** 推奨ケージ範囲 **x38〜46 / y38〜47**。
- ランタンの占有は縦8〜12%（[layout §2](yui-52px-pixel-layout-guide.md)）。
- **中央 `hitCore` 帯（中心線付近の縦帯）と縦で重ねない。** これが prop 誤認防止の核。
- 接地影より上に浮かせ、足元の影とは分ける。

### A-2. 腕との接続（浮かせない）

ランタンが浮く失敗（[master NG](yui-52px-master-design.md) §5）を防ぐため、**必ず連続させる**:

```txt
肩(dress) → 右袖(sleeve) → 手(hand) → 取っ手(handle) → ケージ上辺
```

- 右袖: 体の右肩 `(35,30)` あたりから手 `(40,34)` へ、cream系で **途切れず** 斜めに下ろす。
- 手: `(40〜41, 35〜36)` に skin色2〜3px。
- 取っ手: 手から `(41,37)〜(41,38)` に cage色1pxで下ろし、ケージ上辺へ接続。
- **1pxでも隙間があると浮いて見える。** 接続部は最後に1px単位で詰める。

### A-3. ケージ形状

- 縦長の箱。推奨 **x38〜46 / y38〜47**（幅~9 / 高~10px）。
- 構成:
  - 枠: 四辺を cage色（`#6C543A`系）1px。上辺・左辺はやや明（`#8E724E`）で光を受ける。
  - 縦バー: 中央 x42 に1本（格子は1本で十分、[layout §5](yui-52px-pixel-layout-guide.md)）。
  - 天面に小さな三角屋根/リング（取っ手接続）。
- 1xでは枠＋縦1本＋中の光だけで「ランタン」と読める。格子を増やさない。

### A-4. 記憶の光の入れ方

ケージ内部（枠の内側 x39〜45 / y39〜46）に、外→内で明るく:

1. warm: `memory amber #FAC45C` で内側を満たす。
2. mid: `#FFE896` を中央寄りに。
3. core: `#FFFCE0` を中心2〜3px。
4. **spark: 中心に最も明るい1px（`#FFF6EC`）** ＝「記憶の光」。これが意味の核。
5. glow（最前面・半透明レイヤー）: ケージ外周にアンバーのにじみを淡く。背景の暖色灯りより前に出す明度で。

### A-5. hitCore と誤認しない形

- **位置で誤認を防ぐ**: hitCore は中心、ランタンは右下。縦帯を分ける（A-1）。
- **形で誤認を防ぐ**: hitCore（中心の当たり判定の光）は丸い点光。ランタンは **四角いケージ＋枠** なので、輪郭が四角ければ別物と読める。
- ランタンの光を「中心に置かれた丸い単独の光」にしない。必ず枠で囲む。
- debugHitCircle / hitCore のサイズや挙動は触らない（見た目だけの話）。

## B. 衣装

### B-1. 古紙色の服

- ワンピース＋エプロン。色は `old-paper cream`（base `#E0CEA2` / shadow `#BEA87E` / hi `#F4E6C2` / apron `#ECDEBA`）。
- シルエットは **台形**（上 x18〜33 → 下 x11〜40、y26〜46）。三角錐にしない（脚を出す＝B-4）。
- 厚みの出し方:
  - 左側に shadow を縦帯で1〜2px（光は右=ランタン側から）。
  - 右の裾側に hi の縁。
  - 襟（collar）を顎下 y26〜28 に明色で。
- エプロン中央パネル（x22〜29 / y30〜43）をapron色でわずかに明るく。

### B-2. 赤いしおり紐 / ヘム

ユイのIP記号（[merchandise](yui-merchandise-character-checklist.md) #9 二次創作のフック）:

- **しおり紐（bookmark cord）**: 襟/胸元から縦に赤(`#B0544A`)1px、`(23, 29〜41)` あたりに下ろし、下端に房(`#D67860`)を1〜2px。エプロンの上を通す。
- **赤いヘム（裾band）**: dress 最下部 y44〜46 を赤(`#A8604E`)で帯に。最下端 y46 はさらに暗い赤(`#80463A`)。
- 赤は「紙のしおり/装丁」の記号。面積は小さく、cream の中の差し色に留める（赤を増やすと世界観が変わる）。

### B-3. cloak folds（ドレープ）

- cloak は dress の後ろ・hood の下。肩 `(中心,29)` から左右へ広がり、側面 `x6〜12 / x39〜45` を y22〜38 で下ろす。
- 色は Yui blue の暗め（`#222C50`/`#303C68`）。フードと同系で「同じ布」に見せる。
- folds: 肩から数本、暗→明の縦の折りを1〜2px入れる。べた塗りにしない。
- 役割: 体に奥行きとボリューム。三角錐化の防止と、フード〜体の色の連続性。

### B-4. 小さい靴

- 裾(y46)の下に **脚2本＋ブーツ** を必ず見せる（[layout §4 シルエット条件](yui-52px-pixel-layout-guide.md)）。
- 脚: skin/タイツ色 `(21,46〜49)` と `(28,46〜49)`、各2px幅。
- ブーツ: 暗色(`#3A2C36`)を y48〜50、各 ~4px幅。上端に1pxハイライト(`#5A4A50`)。
- 「立っている子」の接地感。これがないと服が浮いた三角に見える。

## C. 確認

- ランタンが肩→袖→手→取っ手→ケージで連続しているか（浮いていないか）
- ランタンが中心 hitCore 帯と縦で重なっていないか／四角い枠で囲まれているか
- 服が台形で、脚と靴が見えているか（三角錐でないか）
- 赤（しおり紐/ヘム）が差し色に留まっているか
- cloak がフードと同系色で体に奥行きを出しているか

1つでも崩れたら直す。production条件は [../reviews/yui-next-production-readiness-plan.md](../reviews/yui-next-production-readiness-plan.md)。

# Prototype Improvement Issue Template

## 目的

Prototypeのプレイテスト後に見つかった問題を、改善Issueとして切り出すためのテンプレート。

バグではなく、体験改善もIssue化する。

---

# 改善Issueタイトル形式

```txt
[PX-Improve] 改善内容
```

例:

```txt
[P1-Improve] 欠片吸引範囲を広げて回収ストレスを下げる
```

---

# ラベル案

```txt
improvement
balance
ux
mobile
prototype-1
prototype-2
prototype-3
```

# 改善Issue例

## 欠片回収が面倒

```md
## 問題

Prototype 1で、敵を倒した後の記憶の欠片を拾いに戻るのが面倒だった。

## 発見元

- Playtest Report: P1-001
- Build/Commit: xxxxxxx
- Device: iPhone Safari

## 影響

欠片回収が気持ちよさではなく作業になっている。

## 改善案

- [ ] 初期吸引範囲を 70px → 90px にする
- [ ] 欠片の移動速度を少し上げる
- [ ] 取得範囲を 18px → 22px にする

## 受け入れ条件

- [ ] 欠片を拾うために大きく戻らなくてよい
- [ ] 30秒以内に欠片回収の意味が分かる
- [ ] 60秒以内にLv2へ到達しやすい

## やらないこと

- 欠片を全自動取得にしない
- 派手な演出を追加しない
```

---

## 移動が重い

```md
## 問題

仮想スティック移動の開始が遅く、避け操作が気持ちよくない。

## 改善案

- [ ] 入力deadZoneを下げる
- [ ] 方向だけ入力方式にする
- [ ] 移動速度を調整する

## 受け入れ条件

- [ ] 指を置いてすぐ動く
- [ ] 3秒以内に操作を理解できる
- [ ] 最初の敵を避けられる
```

---

## レベルアップが遅い

```md
## 問題

初回Lv2到達が60秒を超えている。

## 改善案

- [ ] 初期XP必要量を下げる
- [ ] インクの影のXPドロップを増やす
- [ ] 序盤敵スポーンを少し増やす

## 受け入れ条件

- [ ] 初回Lv2到達が60秒以内
- [ ] 30秒時点でXPゲージが進んでいると分かる
```

---

## 敵を倒す爽快感が弱い

```md
## 問題

インクの影が硬く、夜の鉛筆で倒すまでが長い。

## 改善案

- [ ] インクの影HPを下げる
- [ ] 夜の鉛筆damageを上げる
- [ ] 夜の鉛筆cooldownを短くする

## 受け入れ条件

- [ ] 最初の敵を10秒以内に倒せる
- [ ] 敵が溜まりすぎない
- [ ] ただし簡単すぎて棒立ちにならない
```

# 優先度判定

## S

次Prototypeへ進む前に必ず直す。

```txt
移動が不快
欠片回収が不快
1分以内に面白さが分からない
スマホで操作不能
```

## A

できれば次Prototype前に直す。

```txt
カードが読みにくい
敵の違いが薄い
SE/反応が弱い
```

## B

後回しでよい。

```txt
見た目の細かい違和感
本素材に関する問題
MVP後の改善
```

---

# 最重要

改善Issueは「もっと良くしたい」を無限に増やすためではない。

```txt
Go / No-Go をGoに変えるための改善だけ優先する。
```

# コアループと8分プレイヤー体験タイムライン

## 目的

Vamp Pon のゲーム体験を、実装前に時間軸で固定する。

この資料は、以下を判断するために使う。

```txt
何が気持ちいいゲームなのか
最初の何秒で何を伝えるのか
8分の中でどこに山を作るのか
どこでレベルアップ/カプセル/進化/必殺技を見せるのか
リザルトで何を残すのか
```

---

# 1. コアループ

## 短期ループ: 5〜20秒

```txt
移動する
↓
影が近づく
↓
自動攻撃が出る
↓
影が消える
↓
記憶の欠片が落ちる
↓
拾う
↓
少し気持ちいい
```

目的:

```txt
操作していない攻撃でも、ちゃんと自分が生き残っている感覚を出す。
```

## 中期ループ: 30〜90秒

```txt
欠片を集める
↓
レベルアップ
↓
3択から選ぶ
↓
武器/パッシブが強くなる
↓
より多くの影を払える
↓
さらに欠片を集める
```

目的:

```txt
選択によってビルドが変わる感覚を出す。
```

## 長期ループ: 3〜8分

```txt
強敵が出る
↓
倒す
↓
記憶カプセルを開ける
↓
進化/強化
↓
終盤の圧を押し返す
↓
朝まで残る
↓
リザルト
↓
実績/図鑑/通貨/次の目標
↓
もう一度
```

目的:

```txt
1回のプレイに山と報酬を作る。
```

## メタループ: 複数プレイ

```txt
プレイする
↓
実績/図鑑が埋まる
↓
裏ストーリー断片が増える
↓
永続強化する
↓
違うビルドを試す
↓
さらに深く進む
```

MVPでは弱くてよい。

本格版で強化する。

# 2. 8分体験タイムライン

## 0:00 起動直後

### プレイヤーが見るもの

```txt
ユイ
影
欠片ではなく空の画面
残り時間
HP
```

### プレイヤーがすること

```txt
指を置いて移動する
```

### 伝えたいこと

```txt
これは移動するゲーム
攻撃は自動
```

### 絶対に出さないもの

```txt
長い説明
裏ストーリー
複雑なUI
大量の敵
```

## 0:10 最初の接敵

### 起きること

```txt
インクの影が近づく
夜の鉛筆が自動で飛ぶ
影が消える
欠片が落ちる
```

### 伝えたいこと

```txt
近づく敵を避けながら、勝手に攻撃してくれる
```

### チェック

```txt
自動攻撃が遅すぎないか
最初の敵が硬すぎないか
欠片が見えるか
```

## 0:30 欠片回収を理解

### 起きること

```txt
欠片を拾う
XPゲージが増える
```

### 気持ちよさ

```txt
欠片が少し吸い寄せられる
拾う音が鳴る
ゲージが増える
```

### チェック

```txt
欠片を拾う意味が説明なしで分かるか
吸引範囲が狭すぎないか
```

## 0:45〜1:00 初レベルアップ

### 起きること

```txt
画面が止まる
「記憶が少し戻った」
3択が出る
```

### 伝えたいこと

```txt
拾うと強くなる
自分で選べる
```

### 候補例

```txt
夜の鉛筆 Lv.2
月のしおり 新規
金のコンパス 新規
```

### チェック

```txt
1分以内にレベルアップするか
カードが読めるか
何を選ぶべきか大体分かるか
```

## 1:00〜1:30 成長の確認

### 起きること

```txt
強化した武器で敵が少し倒しやすくなる
敵密度が少し上がる
```

### 伝えたいこと

```txt
選んだ結果が戦闘に出る
```

### チェック

```txt
Lv2強化が体感できるか
敵が少なすぎないか
```

## 1:30〜3:00 初ピンチ

### 起きること

```txt
紙くずの影が出る
速い敵で少し焦る
```

### 目的

```txt
ただ立っているだけでは危ないと分からせる
```

### チェック

```txt
理不尽ではないか
速い敵が見えるか
逃げ道があるか
```

## 3:00 初カプセル

### 起きること

```txt
黒ラベルの影が出る
少し硬い
倒すと記憶カプセル
```

### 伝えたいこと

```txt
強敵を倒すと特別な報酬がある
```

### カプセル文言

通常強化なら:

```txt
道具が少し戻った
```

初進化はまだ難しいので、この時点では通常強化でもよい。

### チェック

```txt
黒ラベルの影が硬すぎないか
カプセル取得が嬉しいか
演出が長すぎないか
```

## 3:00〜5:00 ビルド差が出る

### 起きること

```txt
迷子の方角
黒いカプセル
敵の種類が増える
```

### 伝えたいこと

```txt
武器選択によって楽な敵/苦手な敵が変わる
```

### チェック

```txt
月のしおりは囲まれに強いか
夜の鉛筆は硬い敵に対応できるか
星くず弾は群れに効くか
```

## 5:00 進化チャンス

### 起きること

```txt
黒ラベルの影2体目
カプセル取得
条件を満たしていれば進化
```

### 理想

初回では進化できなくてもよい。

数回遊ぶと進化を狙える。

### 進化時文言

```txt
記憶がつながった
未完成の一行
書きかけのページほど、続きを急いでいる。
```

### チェック

```txt
5分時点でLv5武器が現実的か
進化できない回が多すぎないか
```

## 5:00〜7:00 群れと必殺技

### 起きること

```txt
夜のもやが増える
敵密度が上がる
必殺技ゲージが溜まる
```

### 伝えたいこと

```txt
ここで必殺技を使うと気持ちいい
```

### ユイの必殺技

```txt
消えない名前
欠片を吸い寄せる
小型影を欠片に戻す
```

### チェック

```txt
必殺技が押したくなる状況があるか
必殺技でちゃんと楽になるか
強すぎないか
```

## 7:00 最後のカプセル

### 起きること

```txt
黒ラベルの影3体目
最後の報酬チャンス
```

### 役割

```txt
最後の1分を押し返すための報酬
```

### チェック

```txt
ここで進化/強化が出ると嬉しいか
報酬が遅すぎないか
```

## 7:00〜8:00 クライマックス

### 起きること

```txt
夜のもやとインクの影が増える
敵密度が最大
```

### 目的

```txt
あと少しで朝、という圧を作る
```

### チェック

```txt
逃げ場が完全になくならないか
低スペック端末で重くないか
最後が気持ちよく終われるか
```

## 8:00 クリア

### 表示

```txt
朝まで残った
```

### 裏ストーリー1行

例:

```txt
朝になった。けれど、消えなかった影がひとつある。
```

### 伝えたいこと

```txt
勝った
でもまだ謎がある
もう一度遊ぶ理由がある
```

# 3. 初回プレイの理想感情

## 0〜1分

```txt
あ、動かすだけでいいんだ
勝手に攻撃してくれる
欠片拾うの気持ちいい
```

## 1〜3分

```txt
ちょっと忙しくなってきた
選んだ武器で変わる
```

## 3〜5分

```txt
カプセル嬉しい
硬い敵が出てきた
もっと火力欲しい
```

## 5〜7分

```txt
進化したら強い
必殺技で助かった
```

## 7〜8分

```txt
あと少し
押し切りたい
```

## リザルト

```txt
もう一回やったら進化できそう
別の武器選んでみたい
図鑑の文ちょっと気になる
```

# 4. 失敗している体験

## 初回1分で失敗

原因候補:

```txt
敵が速すぎる
移動が分かりにくい
HPが低すぎる
攻撃が弱い
```

## 3分まで退屈

原因候補:

```txt
敵が少ない
レベルアップが遅い
武器変化が薄い
```

## 5分で飽きる

原因候補:

```txt
カプセルが嬉しくない
敵種類が変わらない
進化の期待が見えない
```

## 8分が長い

原因候補:

```txt
中盤に山がない
必殺技が弱い
リザルト報酬が薄い
```

---

# 5. 体験タイムラインの合格ライン

```txt
[ ] 60秒以内に初レベルアップ
[ ] 3分で初カプセル
[ ] 5分で進化の期待がある
[ ] 6分までに必殺技を1回使う
[ ] 7分以降に明確な圧がある
[ ] 8分クリア時にリザルトが嬉しい
[ ] 失敗しても次の目標が分かる
```

## 最重要

```txt
ユイで8分遊んで、もう一度遊びたいか？
```

この問いを最優先にする。

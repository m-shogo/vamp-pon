# Commercial Safe Bilingual Quote Replies

Vamp Pon / ヴァンサバ改のロード画面に使う、商用運用を前提にした **英日バイリンガル名言・ことわざ・慣用句 + キャラ返信反応** の正本候補。

---

## 1. 目的

```txt
引用やことわざは、商用可能な範囲の候補から選ぶ。
キャラ反応は、名言への解説ではなく「返信」として扱う。
日本語だけでなく英語も入れ、海外ユーザーにも届く軽さとユニークさを作る。
```

---

## 2. 商用運用ルール

### 使ってよい候補

```txt
公有領域候補の古典原文
著作者没後十分経過した詩・文学の短い原文
一般的な英語ことわざ
一般的な英語慣用句
一般的な挨拶・日常表現
Vamp Ponオリジナル文
```

### 使わない候補

```txt
現代漫画の台詞
現代映画の台詞
現代小説の本文
歌詞
有名ゲーム台詞
既存の日本語翻訳文
出版社訳
字幕訳
SNSで流行った現代コピー
```

### 日本語について

```txt
既存訳は使わない。
日本語は Vamp Pon 用の自前意訳として作る。
UIでは「翻訳」ではなく「意味」または「Vamp Pon用意訳」として扱う。
最終商用前に quote / source / rendering をまとめて確認する。
```


---

## 4. 返信反応のルール

良い返信:

```txt
短い。
英語でも日本語でもキャラが見える。
少しユーモアがある。
でも世界観から浮かない。
キャラ設定・持ち物・灯名・黒耀/朝明とつながる。
```

悪い返信:

```txt
名言の意味を説明している。
ただの翻訳になっている。
全部のキャラが同じことを言える。
ネットミームだけに寄る。
キャラをバカに見せる。
```

## 6. 実装用データ案

```ts
export type LoadingPhraseKind = 'literary_quote' | 'idiom' | 'proverb' | 'common_expression';

export type LoadingPhrase = {
  id: string;
  kind: LoadingPhraseKind;
  originalText: string;
  sourceLabel: string; // e.g. English proverb / English idiom / Emily Dickinson
  japaneseRendering: string;
  renderingType: 'vamp-pon-original-rendering';
  commercialStatus: 'common-expression-candidate' | 'public-domain-candidate' | 'final-check-required' | 'do-not-display';
  tags: string[];
  minVisibleMs: number;
};

export type LoadingPhraseReply = {
  id: string;
  phraseId: string;
  characterId: string;
  replyEn: string;
  replyJa: string;
  tone: 'gentle' | 'dry' | 'awkward' | 'serious' | 'small-joke' | 'sad-funny';
  tags: string[];
};
```

## 7. 表示比率

英語圏にも届かせるため、ロード文の比率は次を基本にする。

```txt
Literary quote: 45%
English idiom/proverb/common phrase: 35%
Vamp Pon original line: 20%
```

キャラ返信は毎回出さない。

```txt
Quote/Phrase only: 70%
Quote/Phrase + Character reply: 30%
```

返信が出る時は、英日どちらか、またはUI設定に応じて両方を表示する。

---

## 8. 最終方針

```txt
名言・ことわざ側は、商用可能候補だけを選ぶ。
現代作品の台詞や既存訳は使わない。
キャラの反応は、名言への返信として書く。
英語返信と日本語返信を両方用意する。
ユーモアは多め。ただしキャラ設定と世界観から外さない。
```

# 初回セッション継続設計

Vamp Ponの初回体験を、売れるスマホゲーム品質へ近づけるための設計メモ。
素材やUnity移行より先に、最初の10秒、1分、3分、8分、敗北、再挑戦の理由を固定する。
この文書は実装データを変更しない。Stage1体験の設計指針として使う。

## 参照した情報

- FTUE / First-time user experience: https://en.wikipedia.org/wiki/First-time_user_experience
- Rapid Prediction of Player Retention in Free-to-Play Mobile Games: https://arxiv.org/abs/1607.03202
- Measuring Player Retention and Monetization using the Mean Cumulative Function: https://arxiv.org/abs/1709.06737
- Game feel research: https://arxiv.org/abs/2011.09201
- Impact feel research: https://arxiv.org/abs/2208.06155

## 基本方針

初回体験は、説明を読ませる場所ではない。
最初のプレイでプレイヤーに以下を体で分からせる。

1. ここは夜の記憶を拾うゲーム。
2. 小さな光を守りながら進む。
3. 敵を倒すと記憶の欠片が集まる。
4. レベルアップで選択がある。
5. 選択で攻撃や移動が変わる。
6. 進化/覚醒/黒曜化は特別。
7. 失敗しても何か残る。
8. もう一回で少し先へ行けそう。

## 初回体験の大原則

### 説明より先に触らせる

最初に長いチュートリアルを出さない。
操作説明は最小限にして、プレイヤーが動いた瞬間に理解できるようにする。

使うなら:

- 画面下に短い1行。
- 3秒以内に消える。
- 行動に合わせて出る。

避ける:

- 開始前の長文説明。
- 連続する説明ポップアップ。
- 画面を止めて読むだけの導入。

### 最初の10秒で世界観と操作を見せる

最初の10秒で「何のゲームか」が分からないと弱い。
タイトルや設定より、画面で伝える。

見せるもの:

- ユイ。
- ランタン。
- 夜道。
- 影。
- 移動。
- 最初の一撃。

### 1分目で成長を見せる

1分目までに最低1回レベルアップさせる。
「敵を倒す → 欠片が集まる → 選べる」のループを早めに見せる。

### 3分目でビルド差を見せる

3分目までに、選んだ内容で画面の変化が分かるようにする。
数字だけでは弱い。
見た目、弾数、範囲、回収、移動感のどれかが変わる必要がある。

### 8分目で達成か未達成をはっきりさせる

8分目は、勝っても負けても意味がある状態にする。
勝ったらStage1の記憶を取り戻す。
負けても記憶の欠片と永続強化が残る。

## Timeline Design

### 0〜3秒: 起動直後

目的:

- 待たせない。
- 画面の空気を一瞬で伝える。

画面:

- 暗い夜道。
- 紙片が少し舞う。
- 小さなランタン光。
- タイトルまたはStage1開始導線。

出す文言候補:

```txt
夜に落ちた記憶を拾う。
```

禁止:

- 長いロゴ演出。
- 説明画面を先に出す。
- ロード中に何も動かない。

成功条件:

- 3秒以内に「暗いけど暖かい」雰囲気が伝わる。

### 3〜10秒: 最初の操作

目的:

- 移動できると分かる。
- 自動攻撃のゲームだと分かる。
- 敵が怖すぎず、倒せそうだと分かる。

画面:

- ユイが下中央付近。
- ランタン光が周囲を照らす。
- オンブ小が1〜3体だけ近づく。
- 夜の鉛筆が自動で当たる。

短いガイド:

```txt
指で歩く
```

または:

```txt
光を消さないで
```

成功条件:

- 10秒以内に「動く」「敵が来る」「攻撃が出る」が分かる。

失敗条件:

- 敵が多すぎる。
- 何をすればいいか分からない。
- 操作前に説明が長い。

### 10〜30秒: 最初の撃破とXP回収

目的:

- 1体倒す気持ちよさを見せる。
- 欠片が自分へ吸い寄せられる体験を作る。

画面:

- オンブが消える。
- 黒インクが小さく弾ける。
- 記憶の欠片が落ちる。
- 欠片がユイへ吸い寄せられる。
- XPゲージが少し伸びる。

短いガイド:

```txt
欠片が記憶になる
```

成功条件:

- 敵を倒す意味が分かる。
- XP回収が気持ちいい。
- ゲージが伸びたことが見える。

### 30〜60秒: 最初のレベルアップ

目的:

- 成長ループを早く見せる。
- 3択カードの楽しさを伝える。

画面:

- 敵数を少し増やす。
- XPを集めやすくする。
- 50〜60秒までに初回LevelUp。
- カード3枚を表示。

初回カード候補:

1. 夜の鉛筆 Lv2
2. あったか靴 Lv1
3. 黒インクの小瓶 Lv1

初回だけ避ける:

- 効果が分かりにくいパッシブだけ出す。
- レアだけ出す。
- 条件未達の進化ヒントを詰め込みすぎる。

成功条件:

- 1分以内に「選べるゲーム」と分かる。
- 選んだ後に少し強くなったと感じる。

### 1〜2分: 選択の結果を見せる

目的:

- 選んだカードが画面に反映されたと感じさせる。

分岐:

- 夜の鉛筆を選んだ: 弾の本数/頻度/線の見た目が少し変わる。
- あったか靴を選んだ: 移動が少し軽くなる。
- 黒インクの小瓶を選んだ: 小さな範囲攻撃が増える。

成功条件:

- プレイヤーが「さっき選んだから変わった」と分かる。

失敗条件:

- 数字だけ増えて見た目が変わらない。
- 強化したのに体感がない。

### 2〜3分: 初めてのビルド感

目的:

- 自分の選択で方向性が生まれていると感じさせる。

画面:

- 敵の数が増える。
- Stage1の別敵を1種類追加。
- 紙片影やlost_directionなど、役割差のある敵を少し出す。
- 2回目か3回目のLevelUp。

出したい体験:

- 鉛筆中心: 前方や近くの敵を切り開く。
- インク中心: 周囲に残る黒い範囲で処理する。
- 靴中心: 危険を歩いて避けやすい。

成功条件:

- 3分までに「今回はこの方向で強い」が見える。

### 3〜5分: 初めての危機と救済

目的:

- ただ勝つだけでなく、危ない場面を作る。
- でも初回は理不尽にしない。

画面:

- 敵密度を上げる。
- 回復ドロップを一度見せる。
- 右上ゲージや黒曜化ゲージが少し溜まる。
- 逃げ道を残す。

初回救済:

- HPが一定以下なら回復ドロップを出しやすくする。
- 初回だけ敵ダメージを少し抑える。
- 黒曜化ゲージを溜まりやすくする。

成功条件:

- 危ないが、何かできそうと思える。

失敗条件:

- いきなり負ける。
- 回復や黒曜化の存在に気づけない。

### 5〜7分: 特別報酬の予告

目的:

- 進化/合体/覚醒に向かっている感を出す。

画面:

- 合体候補や覚醒候補のヒントをカードに出す。
- `name_tag` を覚醒素材として示す。
- `dawn_ticket` は復帰/救済レアとして混ぜない。
- 黒曜化や必殺を一度使わせる。

成功条件:

- プレイヤーが「あと少しで何か起きそう」と感じる。

失敗条件:

- 条件が分からない。
- ただ敵が硬くなるだけ。

### 7〜8分: Stage1の山場

目的:

- 初回プレイの締めを作る。
- 勝っても負けても意味を残す。

画面:

- Stage1エリート/ボス候補。
- 黒インクが濃くなる。
- ランタン光が強くなる。
- Resultへつながる記憶演出。

勝利時:

- Stage1の記憶ページ解放。
- 欠片報酬。
- 新しい図鑑行。
- 次ステージ予告。

敗北時:

- 欠片は残る。
- 到達時間が表示される。
- 敵の図鑑/記憶が少し灯る。
- 永続強化へ誘導。

成功条件:

- 勝ったら嬉しい。
- 負けても損だけではない。
- もう一回で届きそうと思える。

## 負けた時に残すもの

負けを罰にしない。
Vamp Ponは、負けても記憶が少し残るゲームにする。

残すもの:

- 記憶の欠片。
- 到達深度。
- 倒した敵の図鑑進行。
- 初めて見たアイテムの記録。
- キャラ経験値。
- 永続強化用の小さな通貨。

見せ方:

```txt
ここまでの灯りは、消えなかった。
```

または:

```txt
拾った欠片は、朝まで残る。
```

避ける:

- ただのGame Over。
- 全部失う。
- 何が残ったか分からない。

## もう一回押す理由

再挑戦ボタンの理由を明確にする。

理由候補:

1. あと少しでStage1を越えられそう。
2. 欠片で少し強化できる。
3. 次は別のカードを選びたい。
4. 図鑑が少し埋まった。
5. 新しいアイテムを見た。
6. 黒曜化を使えばいけそう。
7. ユイの記憶ページをもう少し灯せる。

Result画面のCTA:

- もう一度
- 強くする
- 記憶を見る

初回で最優先するCTA:

1. 強くする
2. もう一度
3. 記憶を見る

理由:

- 負けた直後は、まず強化できることを見せる。
- 強化後にもう一度へ戻す。

## 初回カード設計

初回カードは、分かりやすさ優先。

### 良い初回カード

| カード | 理由 |
|---|---|
| 夜の鉛筆 Lv2 | 初期武器が強くなったと分かる |
| あったか靴 Lv1 | 移動が軽くなる体感がある |
| 黒インクの小瓶 Lv1 | 新しい攻撃が増える |

### 初回では避けるカード

| カード | 理由 |
|---|---|
| 条件未達の覚醒素材 | 意味が分からない |
| 数字だけのパッシブ | 体感しにくい |
| 説明が長いレア | 読む負担が高い |
| 似た効果3枚 | 選択感が弱い |

## 初回敵設計

### 0〜1分

- オンブ小のみ。
- 柔らかい。
- 倒しやすい。
- 接触ダメージは低め。

### 1〜3分

- オンブ小 + 紙片影。
- 少し動きに差を出す。
- 初回は敵HPを上げすぎない。

### 3〜5分

- lost_direction系を少し追加。
- 回り込みや角度差を見せる。
- 回復ドロップを見せる。

### 5〜8分

- 大きい影または盾持ち候補。
- Stage1の山場。
- 初回は勝てなくてもよいが、負け方を納得させる。

## 初回Stage1の難易度方針

初回は簡単でよい。
目的は、上手い人を倒すことではなく、ゲームの面白さを理解してもらうこと。

調整方針:

- 初回だけ敵HPを少し低め。
- 初回だけXPを少し多め。
- 初回だけ回復を一度出す。
- 初回だけ黒曜化を使いやすくする。
- 初回だけ1回目LevelUpを早くする。

ただし、露骨なチュートリアル感は出さない。
自然に気持ちよく進める。

## 計測したい指標

Unity移行後または分析導入後に見る。
初期は手動QAでもよい。

### 初回セッション

- first_input_time: 操作開始までの秒数。
- first_enemy_clear_time: 初回撃破までの秒数。
- first_xp_collect_time: 初回XP回収までの秒数。
- first_levelup_time: 初回LevelUpまでの秒数。
- first_card_selected: 初回カードID。
- first_damage_time: 初回被弾までの秒数。
- first_recovery_seen: 回復を見たか。
- first_kokuyou_ready_time: 黒曜化準備までの秒数。
- first_run_duration: 初回run時間。
- first_result_action: Resultで押したボタン。

### D1改善で見る

- 初回run完了率。
- 初回run後に強化画面を開いた率。
- 強化後にもう一度押した率。
- 初回敗北後の再挑戦率。
- 初回勝利後の次ステージ開始率。
- 2回目runの平均到達時間。

## 実装に落とす時の優先順位

1. 0〜10秒の導線。
2. 1分以内の初回LevelUp。
3. 初回カード3枚の固定候補。
4. 3分目のビルド差。
5. 負けても残るResult。
6. 強化→もう一度のCTA。
7. 8分山場の記憶報酬。
8. 計測イベント。

## 画面確認チェック

390x844で必ず見る。

- [ ] 10秒以内に操作/敵/攻撃が分かる。
- [ ] 1分以内にLevelUpする。
- [ ] 初回カードが読める。
- [ ] 選択後に変化が見える。
- [ ] 3分で敵とビルドの変化がある。
- [ ] 5分までに危機と救済がある。
- [ ] 8分で勝ち/負けの意味がある。
- [ ] Resultで残ったものが分かる。
- [ ] もう一度押す理由がある。

## 最終判断

初回体験の合格条件は、全部説明できることではない。

合格条件:

```txt
10秒で分かる
1分で育つ
3分で変わる
8分で残る
負けても進む
もう一回押したくなる
```

これが成立したら、素材やUnity移行の価値が上がる。
これが弱いまま素材だけ増やしても、売れるアプリ品質には届かない。

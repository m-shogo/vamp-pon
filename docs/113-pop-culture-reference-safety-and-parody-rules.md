# Pop Culture Reference Safety and Parody Rules

Vamp Pon / ヴァンサバ改で、映画・漫画・アニメ・ゲームが好きな感覚を取り入れるための安全運用ルール。

目的:

```txt
パロディの楽しさは入れる。
映画・漫画・アニメ・ゲーム由来のワクワクも入れる。
ただし、商用で危ない直接引用・薄い改変・固有名寄せは避ける。
Vamp Pon単体で成立する言葉に変換する。
```

---

## 1. 結論

パロは使ってよい。
ただし、Vamp Ponでは次の形にする。

```txt
直接引用しない。
台詞をぼかして使わない。
キャラ名・技名・固有名詞をもじって使わない。
有名フレーズを少し変えただけにしない。
```

代わりに、次を使う。

```txt
ジャンルあるある
構造のパロディ
感情のパロディ
言い回しの空気感
英語ことわざ/慣用句との掛け合わせ
Vamp Ponの世界観への変換
```

目標:

```txt
元ネタが好きな人はニヤッとする。
元ネタを知らない人にもVamp Ponの言葉として成立する。
商用で危なくない。
```

## 2. NGライン

### NG: 台詞の薄い改変

```txt
俺は海賊王になる → 私は灯り王になる
月に代わっておしおき → 星に代わって〜
真実はいつもひとつ → 忘れ物はいつもひとつ
```

これは危ないし、安い。

### NG: 固有名詞のもじり

```txt
かめはめ波 → かげはめ灯
卍解 → 灯解
ポケモン → ホシモン
デジヴァイス → ホシヴァイス
```

固有IPに近すぎる。

### NG: 有名構文をそのまま使う

```txt
〇〇に俺はなる
〇〇、ゲットだぜ
〇〇の呼吸
〇〇の奇妙な冒険
```

商用では避ける。

## 3. OKライン

### OK: ジャンル構造を借りる

例:

```txt
少年漫画の「名前を呼ぶことで戻る」構造
魔法少女の「変身バンク」構造
デジモン的な「紋章と成長」構造
怪獣映画の「巨大なものへの畏れ」構造
RPGの「小さな村から旅立つ」構造
```

これらは構造であり、直接引用ではない。

### OK: 感情をVamp Pon化する

元の感情:

```txt
仲間に認められたい
失くした名前を取り戻したい
変身したいが、変わりすぎるのは怖い
強くなった代わりに何かを失う
```

Vamp Pon変換:

```txt
呼ばれるまで、名前が遠い。
黒耀は、弱さが光に混ざったもの。
継いだ星は、まだ僕の手の形を知らない。
飛べることと、軽いことは違う。
```

### OK: ことわざ/慣用句にキャラがズレて返す

```txt
Piece of cake.

If it's cake, why does it have teeth?
— アサ
```

これは元ネタ台詞ではなく、一般慣用句へのキャラ返信。
商用上の危険が比較的低く、ユーモアが出る。

## 4. パロの三段階

### Level 1: Safe Joke / 安全な軽口

一般ことわざや慣用句に、キャラが返す。

```txt
Break a leg.

Please don't. I need both legs to dance badly.
— ユラ
```

### Level 2: Genre Wink / ジャンルへの目配せ

特定作品ではなく、ジャンルの文法に反応する。

```txt
変われば強くなるって、誰が決めたの。
— ハク
```

```txt
選ばれたんじゃない。置いていかれただけ。
— クロエ
```

```txt
大きな力は、だいたい説明が遅れてくる。
— シオン
```

### Level 3: Converted Homage / 変換されたオマージュ

特定作品から受け取った感情を、完全にVamp Ponの言葉にする。

```txt
呼ばれたら、戻れる気がする。
— シノ
```

```txt
黒耀は、かっこよくなることじゃない。
弱さが、光に混ざること。
```

```txt
進化じゃない。
朝まで壊れずにいた形だ。
```

## 5. 作品ジャンル別に学ぶこと

### 少年漫画から学ぶこと

```txt
名前を呼ぶ。
仲間が迎えに来る。
弱さが力の裏側にある。
強くなるほど孤独になる。
最後に手を伸ばす。
```

Vamp Pon変換:

```txt
名前は、呼ばれるまで帰ってこない。
強くなった灯りほど、自分の影を濃くする。
手を伸ばすのは、勝つためじゃなく帰すため。
```

### 魔法少女/変身作品から学ぶこと

```txt
変身は祝福でもあるが、怖さもある。
衣装や小物が心の状態を表す。
決め台詞より、変わる直前のためらいが強い。
```

Vamp Pon変換:

```txt
灯りが変わるたび、戻れない気がする。
星標器は、願いより先に震える。
黒耀は、かわいくない変身。
```

### デジモン/パートナー作品から学ぶこと

```txt
紋章。
パートナー。
進化と誤進化。
子どもの弱さが形になる。
```

Vamp Pon変換:

```txt
星標器。
紋章。
星灯獣。
黒耀は誤進化ではなく、弱さのにじみ。
朝明は、強化ではなく救い。
```

### 怪獣/ホラーから学ぶこと

```txt
巨大さ。
見えないものの気配。
追われる不安。
日常が少しずつ壊れる感覚。
```

Vamp Pon変換:

```txt
夜が広すぎる。
忘れ物のほうが、こちらを覚えている。
影は襲う前に、道を覚える。
```

### ジブリ的冒険譚から学ぶこと

```txt
小さな生活。
食べ物。
道具。
移動。
子どもの視点。
怖さと優しさの同居。
```

Vamp Pon変換:

```txt
壊れた灯りを、まず直す。
腹が減った夜は、少しだけ怖い。
小さな道具ほど、朝まで残る。
```

### 海外映画から学ぶこと

```txt
短い決め台詞。
皮肉。
状況に対する一言。
大げさな事件に、普通の返事をするユーモア。
```

```txt
— アサ
```

## 6. ロード返信に使うパロ感

ロードでは、映画/漫画/アニメの直接パロではなく、次のように混ぜる。

### 例: 変身ものへの目配せ

```txt
Changing shape is easy.
Coming back is the hard part.

— Vamp Pon original
```

```txt
姿が変わるのは簡単。
戻ってくるほうが難しい。
```

Reply:

```txt
That is why I do not call it awakening.
— ハク / Haku
```

```txt
だから、覚醒とは呼びたくない。
— ハク
```

### 例: 少年漫画への目配せ

```txt
Names return when someone calls them.

— Vamp Pon original
```

```txt
名前は、誰かが呼ぶと帰ってくる。
```

Reply:

```txt
Then please call slowly. I might spill.
— シノ / Shino
```

```txt
ゆっくり呼んで。こぼれそうだから。
— シノ
```

### 例: 映画的皮肉

```txt
Every cloud has a silver lining.

— English proverb
```

```txt
黒い雲にも、光る縁がある。
```

Reply:

```txt
Even black feathers need a rim of light.
— クロエ / Chloe
```

```txt
黒い羽にも、光の縁くらい欲しい。
— クロエ
```

## 7. パロを入れる時の最終チェック

```txt
1. 元作品の台詞を思い出せるほど近くないか。
2. 固有名詞・技名・構文に寄りすぎていないか。
3. 知らない人にもVamp Ponの言葉として成立するか。
4. キャラ設定に合っているか。
5. 商用画面に出して問題なさそうか。
6. 最終チェックで不安なら do-not-display に落とす。
```

```txt
パロ好きは活かす。
ただし、作品名や台詞をぼかして使うのではなく、ジャンルの感情をVamp Ponの言葉に変換する。
```

Vamp Ponで狙うパロ:

```txt
知っている人はニヤッとする。
知らない人にも意味が通る。
Vamp Ponの世界観から浮かない。
商用で危なくない。
```

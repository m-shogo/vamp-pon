# 題材フィット条件: 制作者本人が乗れること

## 目的

Vamp Pon の題材選びでは、客観的に作りやすいだけでは不十分。

制作者本人がその題材に乗れないと、制作まで進まない。

## 重要な前提

ユーザーは以下の感覚を持っている。

- 0から架空世界を考えるのは重い
- 妖怪は好きではない
- 題材に自分が乗れないと制作まで行けない
- 既存情報や参考素材が多い題材の方が進みやすい
- 完全オリジナルより、みんなが知っている構造や道具がある題材がよい

この条件を、今後の題材選定に必ず入れる。

## 題材選定の新しい必須条件

題材候補は、以下を満たす必要がある。

```txt
1. 制作者本人が少しでも好き/興味がある
2. 既存情報・参考素材・連想素材が多い
3. 0から世界観を発明しなくてよい
4. 著作権/商標リスクを制御できる
5. 敵・武器・報酬・背景に展開しやすい
6. 個人開発で素材化しやすい
```

## 落とす題材

### 妖怪メイン

理由:

- ユーザー本人が好きではない
- 文化表現リスクもある
- 既存妖怪作品との差別化も必要

結論:

```txt
メイン題材から外す。
小物や味付けにも無理に入れない。
```

### 完全架空世界

理由:

- アイデア出しが重い
- 背景、敵、武器、報酬名を全部0から作る必要がある
- 制作前に止まりやすい

結論:

```txt
メイン題材から外す。
既存モチーフを分解して使う方針にする。
```

### 童話ごちゃ混ぜ

理由:

- 素材は多いが、整理しないと散る
- 既存版デザインの権利リスクが多い
- どの童話を基準にするか決める必要がある

結論:

```txt
単体メインにはしない。
道具やステージ案として使う。
```

## 残すべき題材方向

### 1. おもちゃ/机の上/部屋

良い点:

- 既存素材が多い
- 0から考えなくていい
- 文房具、ぬいぐるみ、積み木、ビー玉、時計、クレヨンなど展開しやすい
- 著作権リスクを抑えやすい
- 背景が作りやすい

リスク:

- 地味になりやすい
- 有名玩具/映画/ゲームに寄せると危険
- 子ども向けに見えすぎる可能性

対策:

- 「夜」「影」「悪夢」を足してゲーム性を出す
- 実在玩具ブランド風にしない
- 敵は影やいたずら精霊にする

### 2. 文房具/机上戦争

良い点:

- 鉛筆、消しゴム、定規、クリップ、ノート、インクなど武器化しやすい
- 素材負荷が軽い
- 著作権リスクが低い
- 見た目の統一がしやすい

リスク:

- 地味
- 爽快感が弱く見える可能性
- Vamp Pon の名前とはやや離れる

対策:

- 夜の机、落書き、影、紙の敵を組み合わせる
- 攻撃演出を派手にする

### 3. お菓子/駄菓子/おやつ

良い点:

- 既存連想が多い
- アイテム名・報酬名を作りやすい
- カラフルで楽しい
- どら焼き屋の話にも近く、中心モチーフを作りやすい

リスク:

- 実在商品/パッケージに似せると危険
- 甘すぎて戦闘の爽快感が弱くなる
- 食べ物を倒す表現が微妙になる可能性

対策:

- 実在菓子名を避ける
- 敵はカビ/焦げ/影/いたずら精霊にする
- お菓子は報酬や武器寄りにする

### 4. 動物の仲間

良い点:

- ユーザー自身のコーギー文脈とも相性がある
- 好きになりやすい
- サポート/図鑑/キャラ解放に強い

リスク:

- 動物を敵にすると危険
- ペットを戦わせすぎると印象が悪い
- 動物アニメーションは作るのが重い

対策:

- 動物は味方/仲間/応援役
- 敵は影や悪夢
- 攻撃表現は直接暴力よりサポート演出にする

### 5. 現実の小さい場所

例:

- 部屋
- 机
- 押し入れ
- お店
- 夜のコンビニ風
- 駄菓子屋風
- 商店街風

良い点:

- 既存情報が多い
- 背景を作りやすい
- 0から発明しなくてよい
- 小物が多く、武器や報酬にしやすい

リスク:

- 現実寄りすぎるとファンタジー感が弱い
- 実在店舗やブランドに寄せると危険
- 地味になりやすい

対策:

- 夜/夢/影で少しだけ非現実にする
- ブランドや実在ロゴは出さない

## 今後の有力候補

### 候補A: 夜の机の上

```txt
主軸: 机の上
補助: 文房具/おもちゃ/落書き
敵: 影、紙くず、インクのしみ、悪夢
味方: 小さい動物/ぬいぐるみ
```

良い点:

- かなり作りやすい
- 0から発明しなくてよい
- 著作権リスクが低い
- 武器/報酬が作りやすい

弱点:

- 地味になりやすい
- タイトルや見た目の魅力を工夫する必要がある

### 候補B: 夜のおもちゃ箱

```txt
主軸: おもちゃ箱
補助: ぬいぐるみ/積み木/ビー玉/ゼンマイ
敵: 影、いたずらおもちゃ、悪夢
味方: 動物ぬいぐるみ
```

良い点:

- かわいい、不思議、少し怖いを作れる
- 武器/敵/報酬の幅が広い
- 個人開発向き

弱点:

- 有名玩具世界に寄せない注意が必要
- 子ども向けに見えすぎる可能性

### 候補C: 駄菓子屋/おやつの夜

```txt
主軸: 駄菓子/おやつ
補助: くじ、景品、袋、缶、ビー玉
敵: 影、焦げ、いたずら菓子
味方: 店番動物/ぬいぐるみ
```

良い点:

- 既存情報が多い
- どら焼き屋のような中心モチーフを作りやすい
- 報酬/コレクションと相性が良い

弱点:

- 実在菓子に寄せると危険
- ヴァンサバの戦闘に落とす工夫が必要

### 候補D: 小さな部屋の悪夢退治

```txt
主軸: 部屋
補助: ベッド、ランプ、枕、ぬいぐるみ、本、机
敵: 悪夢、影、眠りの霧
味方: ぬいぐるみ/動物
```

良い点:

- 0から発明しなくてよい
- 夢/影を使える
- おもちゃ、文房具、本、動物を全部自然に置ける

弱点:

- 抽象的になりやすい
- どこを中心モチーフにするか決めないと散る

## 現時点のおすすめ再整理

妖怪は外す。

完全架空も外す。

残すならこの順。

```txt
1. 夜のおもちゃ箱
2. 夜の机の上
3. 小さな部屋の悪夢退治
4. 駄菓子屋/おやつの夜
5. 動物の仲間 + 影
```

## 判断基準

今後は、題材候補を出すときに以下を必ず確認する。

```txt
自分が乗れるか？
0から考えなくて済むか？
参考素材が多いか？
敵/武器/報酬に変換できるか？
権利リスクを説明できるか？
制作まで進めそうか？
```

## 結論

題材は、客観的に良いだけではダメ。

制作者本人が乗れることが最優先。

そのうえで、0から作らなくてよく、既存情報が多く、権利リスクが低く、個人開発で作れる題材に絞る。

現時点では、**夜のおもちゃ箱 / 夜の机の上 / 小さな部屋の悪夢退治 / 駄菓子屋の夜** が有力。

# Unity U21.1 Visual Polish Candidate Notes

## Battle HUD polish candidates

- 何を直すか: HP/EXP/黒耀化gauge、敵接近、pickup吸引を実画面として配置する。
- なぜ直すか: Stage1 playingが仕様説明リストに見えるため。
- どの画面に効くか: Stage1 / Battle。
- 期待効果: 縦切りが商品画面に近づく。
- フェーズ: U22。

## LevelUp card polish candidates

- 何を直すか: Paper card厚み、封蝋badge、カードicon、選択時dim/scale。
- なぜ直すか: LevelUpの嬉しさが弱いため。
- どの画面に効くか: LevelUp integrated。
- 期待効果: 選択の儀式感が出る。
- フェーズ: U23。

## 黒耀化 polish candidates

- 何を直すか: Ready予兆、full-screen cut-in、黒インク粒、Active余韻、Ending recoil。
- なぜ直すか: 黒耀化がこのゲームの顔になりきれていないため。
- どの画面に効くか: 黒耀化 ready / active / ending。
- 期待効果: 記憶に残るclimaxになる。
- フェーズ: U24。

## Result polish candidates

- 何を直すか: Rank seal、報酬pop、手帳に貼る演出、朝焼けの薄い光。
- なぜ直すか: もう一度遊びたくなる報酬感が弱いため。
- どの画面に効くか: Clear Result / Fail Result。
- 期待効果: 周回の締めが気持ちよくなる。
- フェーズ: U23。

## StageSelect polish candidates

- 何を直すか: 地図紙面、ルート線、active node glow、last resultの紙片化。
- なぜ直すか: 次へ進みたい導線が弱いため。
- どの画面に効くか: StageSelect / Stage return。
- 期待効果: 出発前の期待感が出る。
- フェーズ: U23。

## Rare / Evolution polish candidates

- 何を直すか: Rare seal pulse、Evolution recipe icon、合体時の光収束。
- なぜ直すか: 山場が説明UIに見えるため。
- どの画面に効くか: Rare / Evolution。
- 期待効果: レアと合体が記憶に残る。
- フェーズ: U24。

## Drop / pickup readability candidates

- 何を直すか: EXP / Heart / Memoryのscale差、色、trail、collect pulse。
- なぜ直すか: pickupが文言でしか伝わっていないため。
- どの画面に効くか: Stage1 / EXP / Drop / 回復drop。
- 期待効果: 集める気持ちよさが出る。
- フェーズ: U22。

## Typography polish candidates

- 何を直すか: proof labelを短くし、見出し/数値/補足の階層を固定する。
- なぜ直すか: 説明用UIっぽさが強いため。
- どの画面に効くか: 全画面。
- 期待効果: ゲーム内UIとしての落ち着きが出る。
- フェーズ: U22〜U23。

## Color / light / shadow polish candidates

- 何を直すか: 通常UIは暗く静かに、CTAと報酬だけランタン光を強める。
- なぜ直すか: 画面ごとの強弱がまだ浅いため。
- どの画面に効くか: 全画面。
- 期待効果: 紙UI / 黒インク / ランタン光の軸が立つ。
- フェーズ: U22〜U24。

## Motion / animation polish candidates

- 何を直すか: card reveal、rank seal stamp、pickup magnet、黒耀化cutin、rare pulse。
- なぜ直すか: 静止画だけではpremium感が出ないため。
- どの画面に効くか: Battle / LevelUp / Result / 黒耀化。
- 期待効果: 押したい、集めたい、もう1回遊びたい感情が増える。
- フェーズ: U22〜U24。

## SE / haptic polish candidates

- 何を直すか: collect SE、paper rustle、rank stamp、黒耀化発動、rare pulse haptic hook。
- なぜ直すか: 見た目だけでは反応が軽いまま残るため。
- どの画面に効くか: 全画面、特にBattle / LevelUp / 黒耀化 / Result。
- 期待効果: 小さい操作の手触りが増す。
- フェーズ: U22〜U24。

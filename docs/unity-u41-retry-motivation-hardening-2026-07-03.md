# Unity U41 Retry Motivation Hardening

Retry導線は押し付けない。ガチャ的な圧を避け、シンプルに「もう少し良くできそう」と伝える。

## defeat後

- participation rewardを表示する。
- 次のrank hintを短く出す。
- Retryをprimaryにしつつ、StageSelectへ戻れる逃げ道を残す。

## clear後

- best updatedならstampを出す。
- StageSelect previous result stampへつなぐ。
- S/A狙いのretry motivationを軽く残す。

## unlock hint

Stage2 placeholder、knowledge placeholder、reward card placeholderはResultに出すが、Stage2本体やCollection本実装へ踏み込まない。

# Serious Literary Quote Final Candidates

Vamp Pon / ヴァンサバ改のロード知識システムに最初に入れる、Serious literary quote 8件の確定候補。

この資料は、`docs/126-loading-knowledge-consistency-guardrails.md` の方針に従い、1カテゴリだけを少数精鋭で詰める。

---

## 1. このカテゴリの役割

Serious literary quote は、ロード画面の格を上げる中心カテゴリ。

```txt
本物の言葉に触れる。
原文の雰囲気を残す。
出典を明記する。
日本語では短く意味を添える。
Vamp Ponらしさはキャラ返信で出す。
```

Everyday English phrase や Rare Japanese phrase が生活感・知識欲・軽さを担当するなら、Serious literary quote は次を担当する。

```txt
夜
記憶
名前
沈黙
星
朝
無常
消えた声
```

---

## 2. 選定基準

採用条件:

```txt
原文と出典を確認しやすい。
短くロードで読める。
Vamp Ponの夜・記憶・忘れ物・名前・朝に接続できる。
キャラ返信がS/Aランクで作れる。
現代作品ではない。
日本語訳/意味を自前で短く作れる。
```

注意:

```txt
一部は有名だが、MVPでは安全性と出典確認を優先する。
有名すぎる文は表示頻度を抑える。
キャラ返信でVamp Pon固有の読み方にする。
```

# 8. 破綻チェック

この8件は、以下を満たす。

```txt
□ 原文/出典を確認しやすい
□ 現代作品ではない
□ ロード中に読める長さ
□ 日本語訳/意味が短い
□ キャラ返信が説明ではない
□ Vamp Ponの夜/記憶/名前/朝/音に接続できる
□ 記録室で見返す価値がある
```

注意:

```txt
Shakespeare 2件は有名なので表示頻度を抑える。
The rest is silence は初回ロードでは出さない。
日本古典2件は日本語原文を残す。
翻訳は必ず最終商用前に確認する。
```

# 9. 最終方針

Serious literary quote は、Vamp Ponのロードに「本物の言葉に触れる」感覚を入れるカテゴリ。

最初に入れるなら、次の7件から始める。

```txt
We grow accustomed to the Dark.
Sunt lacrimae rerum.
E quindi uscimmo a riveder le stelle.
Music, when soft voices die, vibrates in the memory.
What's in a name?
春はあけぼの。
行く川のながれは絶えずして、しかももとの水にあらず。
```

残り1件は文脈制御ができてから入れる。

```txt
The rest is silence.
```

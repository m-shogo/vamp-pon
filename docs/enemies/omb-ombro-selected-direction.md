# オンブ／オンブロ 採用方向

## Status

- status: `selected-direction`
- selected: B「インク芽型」
- refinement: 柔らかいモヤ体＋オンブロの影の擬手
- production: 未昇格。native spriteとanimationは今後作成する

## 1. 採用する視覚の核

オンブ／オンブロは、次の6点で識別する。

1. 常に少し形が崩れている柔らかい黒インクの身体
2. 頭頂部の小さな一滴状のインク芽
3. 古紙色の小さな四角い目が2つ
4. 足元と後方へ溶ける薄いモヤ影
5. 周囲に2〜4個だけ浮く小さなインク粒
6. オンブロのみ、身体から垂れる影の擬手を持つ

硬い球体やゴムの塊には見せない。かわいさは口、眉、頬、服ではなく、身体のつぶれ、揺れ、ほどけ方で出す。

## 2. 身体の柔らかさ

### 共通

- 輪郭を完全な円や左右対称にしない
- idle中も裾と上面が1〜2px程度ゆっくり変形する
- 身体下部は地面へ染みるように途切れる
- 本体内部の濃紺・青灰色の面も固定せず、呼吸に合わせて少し移動する
- 着地時は高さを下げ、横幅を大きくする
- 動き出しでは上半分が先に傾き、下半分が遅れて引かれる
- 硬い輪郭線を全周へ均一に置かない

### 避ける見え方

- 石、鎧、ゴムボール、硬いスライム
- 常に同じ完全な半円
- 輪郭だけが上下する機械的なbounce
- 身体より強い接地影

## 3. モヤ影のルール

モヤは本体を隠す装飾ではなく、身体そのものが地面へほどけている表現。

- 身体の下半分と後方へ配置する
- 顔と目の前には被せない
- 本体より低コントラスト
- 本体より先に読まれない
- idleでは短く薄い
- moveでは後方へ伸びる
- landingでは左右へ低く広がる
- hurtでは一瞬散ってから本体へ戻る
- defeatでは本体とモヤの境界がなくなり紙染みへ戻る
- 180pxセルの安全域を越えない
- 半透明ピクセルを隣接セルへ漏らさない

## 4. オンブ

### silhouette

- 接地面が広い低いモヤの塊
- 頭の一滴は身体とつながっている
- 芽を角、耳、髪、帽子に見せない
- 足は描かず、裾の小さな盛り上がりだけで移動を表す
- 上部より下部の輪郭を柔らかく崩す

### face

- 四角い古紙色の目が2つ
- 目は小さく、少しだけ高さをずらしてよい
- 口なし
- 瞳、眉、まつ毛、頬なし

### movement

```txt
idle: 身体と裾がゆっくり形を変える
move: 上半分が前へ傾き、下半分とモヤが遅れて続く
landing: 横へ大きくつぶれ、モヤが左右へ広がる
hurt: インク芽、目、身体が一瞬内側へ縮む
defeat: 身体とモヤが混ざり、紙染みと小さいインク粒へ戻る
```

## 5. オンブロ

オンブと同じfamilyだと一瞬で分かること。

- オンブより横幅と接地面が大きい
- 身体を高くするより低く広くする
- 目の間隔を広げる
- インク芽は同じ記号を維持し、少し太く垂らす
- 足元のモヤをオンブより多くする
- 単純な拡大コピーにしない

### 影の擬手

オンブロの左右から、柔らかい影の擬手を生やす。

```txt
待機時: 地面へ垂れている
移動時: 身体より遅れて引きずられる
攻撃時: 片側または両側が前へ伸びる
着地時: 身体と一緒に地面へ広がる
撃破時: 腕から先にモヤへほどける
```

擬手の条件:

- 肩や関節を明確に作らない
- 骨や筋肉を感じさせない
- 先端は丸い、または3つ程度の鈍い房へ分かれる
- 人間の指、爪、手のひらを描かない
- 常時水平に構えず、普段は重く垂らす
- 腕だけ別の黒い線にせず、身体と同じモヤ質感でつなぐ
- オンブには生やさない

この擬手により、オンブロは「遅いが進路を塞ぐ・近距離へ手を伸ばす」役割をシルエットだけで伝えられる。

## 6. 主人公側との画風共有

- soft painterly pixel art
- 黒一色ではなく、黒・濃紺・青灰色の段階陰影
- 古紙色と弱い暖色を焦点へ使用
- ピクセルの塊で柔らかくほどける輪郭を作る
- 主人公の衣装、金刺繍、髪型、手足は移植しない
- 同じ世界の絵柄だが、明確に非人間の影生物

輪郭、目、インク芽、擬手、カメラ角度は変えない。

# オンブ／オンブロ 採用方向

## Status

- status: `selected-direction`
- selected: B「インク芽型」
- refinement: モヤ影を追加
- production: 未昇格。native spriteとanimationは今後作成する

## 1. 採用する視覚の核

オンブ／オンブロは、次の5点で識別する。

1. 低く丸い黒インクの半球
2. 頭頂部の小さな一滴状のインク芽
3. 古紙色の小さな四角い目が2つ
4. 足元と後方へだけ溶ける薄いモヤ影
5. 周囲に2〜4個だけ浮く小さなインク粒

かわいさは口、眉、頬、服ではなく、身体のつぶれと跳ね方で出す。

## 2. モヤ影のルール

モヤは本体を隠す装飾ではなく、影が地面へ溶けていることを示す補助表現。

- 配置は身体の下半分と後方だけ
- 顔と目の前には被せない
- 本体より低コントラスト
- 本体より先に読まれない
- idleでは短く薄い
- moveでは後方へ少し伸びる
- landingでは左右へ低く広がる
- 180pxセルの安全域を越えない
- 半透明ピクセルを隣接セルへ漏らさない

## 3. オンブ

### silhouette

- 接地面が広い低い半球
- 頭の一滴は身体とつながっている
- 芽を角、耳、髪、帽子に見せない
- 小さいインク足または溶けた裾

### face

- 四角い古紙色の目が2つ
- 目は小さく、少しだけ高さをずらしてよい
- 口なし
- 瞳、眉、まつ毛、頬なし

### movement

```txt
idle: ゆっくり呼吸するように1〜2px上下
move: 前へ傾き、後方へ短いモヤを残す
landing: 横へつぶれ、モヤが左右へ広がる
hurt: インク芽と目が一瞬縮む
 defeat: 紙染みと小さいインク粒へ戻る
```

## 4. オンブロ

オンブと同じfamilyだと一瞬で分かること。

- オンブより横幅と接地面が大きい
- 身体を高くするより低く広くする
- 目の間隔を広げる
- インク芽は同じ記号を維持し、少し太くする
- 足元のモヤをオンブより少し多くする
- 人物的な腕、服、角、武器を追加しない
- 単純な拡大コピーにしない

## 5. 主人公側との画風共有

- soft painterly pixel art
- 黒一色ではなく、黒・濃紺・青灰色の段階陰影
- 古紙色と弱い暖色を焦点へ使用
- ピクセルの塊で柔らかい輪郭を作る
- 主人公の衣装、金刺繍、髪型、手足は移植しない
- 同じ世界の絵柄だが、明確に非人間の影生物

## 6. 5Stage色違い

輪郭、目、インク芽、カメラ角度は変えない。

| Stage | paletteKey | 主色 | 小さい差し色 |
|---:|---|---|---|
| 1 | `fragment_blue` | 青紫のインク | くすんだ古紙金 |
| 2 | `name_violet` | 葡萄紫のインク | 薄い藤色 |
| 3 | `seal_umber` | 焦茶紫のインク | くすんだ封蝋赤 |
| 4 | `route_teal` | 青緑黒のインク | 褪せた水色 |
| 5 | `lantern_amber` | 深い藍黒 | 控えめな琥珀 |

本体の70%以上は暗いblack ink familyとして維持する。

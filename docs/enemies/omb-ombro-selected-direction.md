# オンブ／オンブロ 採用方向

## Status

- status: `selected-direction`
- selected: B「インク芽型」
- refinement: 柔らかい影の身体＋全身を包む影炎モヤ＋オンブロの影の擬手
- production: 未昇格。native spriteとanimationは今後作成する

## 1. 採用する視覚の核

オンブ／オンブロは、次の7点で識別する。

1. 常に少し形が崩れている柔らかい黒インクの身体
2. 頭頂部の小さな一滴状のインク芽
3. 古紙色の小さな四角い目が2つ
4. 身体の全周を包む、炎のような暗いモヤ影
5. 足元と後方へ溶ける低い影
6. 周囲に2〜4個だけ浮く小さなインク粒
7. オンブロのみ、影炎から伸びる擬手を持つ

硬い球体、石、ゴムの塊には見せない。かわいさは口、眉、頬、服ではなく、身体のつぶれ、揺れ、ほどけ方で出す。

## 2. 影炎モヤ

オンブの身体自体が影であり、その外側へさらに炎状の影がまとわりつく。

### 見た目

- 明るい炎ではなく、濃紺・紫黒・青灰色の影
- 発光させない
- 上方向へ立ち上がる細い舌状のモヤ
- 横方向へ短く逃げる影の尾
- 本体の輪郭と一部がつながり、どこまでが身体か曖昧に見える
- 炎先端は鋭い三角ではなく、途中でほどける柔らかい形
- 顔の正面だけは空け、目の読みやすさを守る

### 動き

```txt
idle:
  全身周囲の影炎が小さく伸び縮みする
  左右対称には動かない

move:
  前方の影炎は身体へ押し込まれる
  後方の影炎だけ長く引かれる

landing:
  上側の影炎が縮み、左右と足元へ広がる

hurt:
  影炎が一瞬外側へ散り、直後に本体へ吸い戻される

defeat:
  本体と影炎の区別が消え、紙染みと小さな粒へほどける
```

### 制限

- 影炎を本体より明るくしない
- 影炎を髪、角、翼、毛皮のように見せない
- 目の前へ半透明モヤを重ねない
- 常時大きく燃え上がらせず、オンブ本体の丸い形を先に読ませる
- 180pxセルの4px安全域を越えない
- 隣接セルへ半透明ピクセルを漏らさない

## 3. 身体の柔らかさ

### 共通

- 輪郭を完全な円や左右対称にしない
- idle中も裾と上面が1〜2px程度ゆっくり変形する
- 身体下部は地面へ染みるように途切れる
- 本体内部の濃紺・青灰色の面も固定せず、呼吸に合わせて少し移動する
- 着地時は高さを下げ、横幅を大きくする
- 動き出しでは上半分が先に傾き、下半分と影炎が遅れて引かれる
- 硬い輪郭線を全周へ均一に置かない

### 避ける見え方

- 石、鎧、ゴムボール、硬いスライム
- 常に同じ完全な半円
- 輪郭だけが上下する機械的なbounce
- 本体より強い接地影

## 4. オンブ

### silhouette

- 接地面が広い低いモヤの塊
- 頭の一滴は身体とつながっている
- 芽を角、耳、髪、帽子に見せない
- 足は描かず、裾の小さな盛り上がりだけで移動を表す
- 上部より下部の輪郭を柔らかく崩す
- 全身の影炎を除いても、インク芽と四角い目で識別できる

### face

- 四角い古紙色の目が2つ
- 目は小さく、少しだけ高さをずらしてよい
- 口なし
- 瞳、眉、まつ毛、頬なし

### movement

```txt
idle: 身体、裾、全周の影炎が別々の周期で揺れる
move: 上半分が前へ傾き、下半分と後方の影炎が遅れて続く
landing: 横へ大きくつぶれ、影炎が左右と地面へ広がる
hurt: インク芽と目が縮み、全身の影炎が一瞬散る
defeat: 身体と影炎が混ざり、紙染みと小さいインク粒へ戻る
```

## 5. オンブロ

オンブと同じfamilyだと一瞬で分かること。

- オンブより横幅と接地面が大きい
- 身体を高くするより低く広くする
- 目の間隔を広げる
- インク芽は同じ記号を維持し、少し太く垂らす
- 全身を包む影炎をオンブより少し長くする
- 足元と後方のモヤをオンブより多くする
- 単純な拡大コピーにしない

### 影の擬手

オンブロの左右から、影炎と身体がまとまって伸びる擬手を生やす。

```txt
待機時: 地面へ垂れ、輪郭の一部が影炎へほどける
移動時: 身体より遅れて引きずられる
攻撃時: 片側または両側が前へ伸びる
着地時: 身体と一緒に地面へ広がる
撃破時: 擬手から先に影炎へほどける
```

擬手の条件:

- 肩や関節を明確に作らない
- 骨や筋肉を感じさせない
- 先端は丸い、または3つ程度の鈍い房へ分かれる
- 人間の指、爪、手のひらを描かない
- 常時水平に構えず、普段は重く垂らす
- 腕だけ別の黒い線にせず、本体と同じ影炎質感でつなぐ
- 擬手の周囲にも小さな影炎をまとわせる
- オンブには生やさない

この擬手により、オンブロは「遅いが進路を塞ぐ・近距離へ手を伸ばす」役割をシルエットだけで伝えられる。

## 6. 主人公側との画風共有

- soft painterly pixel art
- 黒一色ではなく、黒・濃紺・青灰色の段階陰影
- 古紙色と弱い暖色を焦点へ使用
- ピクセルの塊で柔らかくほどける輪郭を作る
- 主人公の衣装、金刺繍、髪型、手足は移植しない
- 同じ世界の絵柄だが、明確に非人間の影生物

## 7. 5Stage色違い

輪郭、目、インク芽、影炎、擬手、カメラ角度は変えない。

| Stage | paletteKey | 主色 | 小さい差し色 |
|---:|---|---|---|
| 1 | `fragment_blue` | 青紫のインク | くすんだ古紙金 |
| 2 | `name_violet` | 葡萄紫のインク | 薄い藤色 |
| 3 | `seal_umber` | 焦茶紫のインク | くすんだ封蝋赤 |
| 4 | `route_teal` | 青緑黒のインク | 褪せた水色 |
| 5 | `lantern_amber` | 深い藍黒 | 控えめな琥珀 |

本体の70%以上は暗いblack ink familyとして維持する。Stage色は影炎にも弱く反映するが、明るい炎にはしない。

# ポン影 共通マスコット敵デザイン brief

## Status

- status: `prototype-reference`
- purpose: Vamp Pon の全Stageへ出る共通雑魚2種を、スライムのように一目で覚えられる敵familyとして固定する
- names: 「ポン影」「ふくらみポン影」は制作管理用の仮称。正式名称は後で決める
- production: 生成画像をそのまま本番素材にしない

## 1. 共通雑魚の役割

各Stageの雑魚5体は次の構成にする。

```txt
共通小型シャドウ 1体
共通中型シャドウ 1体
Stage固有敵       3体
合計              5体
```

5Stage分では以下になる。

```txt
ポン影の色違い             5体
ふくらみポン影の色違い     5体
Stage固有敵                15体
合計                       25体
```

共通2種はプレイヤーが毎Stageで再学習しなくてよい基準敵であり、Vamp Ponの敵側マスコット候補でもある。

## 2. 小型共通敵「ポン影」

### 名前の理由

丸い身体が落ちる時、紙へ判を押すように「ぽん」と着地するため「ポン影」と呼ばれる。

タイトルの `Pon` と自然につながるが、ロゴ文字や記号を身体へ直接描かない。

### 一目で分かる輪郭

黒いシルエットだけでも次が残ること。

```txt
下が少し広い丸い一滴型
頭の左上に一か所だけ破れ紙の切れ込み
右下に短いインクのしっぽ
足ではなく、底面の小さな二つのふくらみ
```

完全な円、普通のスライム形、単なる黒い雫にはしない。

### 顔

```txt
目は古紙色の小さな2点
左右の高さを1px程度ずらす
口は通常描かない
表情は目の間隔と身体のつぶれで出す
```

目を大きな黄色い発光へしない。記憶の欠片、ランタン、hit coreとの誤認を避ける。

### 形の比率

```txt
身体 80%
紙の切れ込み 8%
インクしっぽ 7%
底のふくらみ 5%
```

小物を増やさない。国民的な単純さを狙い、1秒で描き直せる程度の構成にする。

### 動きの個性

基本動作は `つぶれる -> ぽんと跳ねる -> 少し遅れてしっぽが戻る`。

- 常に激しく揺らさない
- 1回の着地で輪郭が一度だけ横へつぶれる
- 移動方向へ目ではなく身体全体が少し傾く
- 撃破時は爆発ではなく、小さな紙染みへ戻る

### 物語上の意味

ポン影は「意味を持つ前の小さな誤解」。悪意で襲うのではなく、持ち主を探して光へ寄ってくる。

この意味はゲーム開始時には説明せず、図鑑や後半の反転で回収する。

## 3. 中型共通敵「ふくらみポン影」

### 関係

ポン影が複数の意味片を抱え込み、身体を保てなくなった成長体。

同じfamilyだと一瞬で分かるよう、以下を共通化する。

- 左上の破れ紙の切れ込み
- 右下のインクしっぽ
- 古紙色で少し高さの違う2つの目
- Stageごとの共通配色

### 単純拡大にしない

小型をそのまま拡大することは禁止。

中型は次の輪郭を持つ。

```txt
小型より横幅が広い洋梨型
左右に短く重いインク腕
底面は一枚の厚いインク溜まり
目は身体中央より少し下
紙の切れ込みは太く深い
```

小型が「跳ねる点」なら、中型は「進路を押す塊」として見えること。

### 動きの個性

- 小さく2回揺れてから重く着地
- 着地時だけ横幅が広がる
- 普段は遅いが身体を傾けて圧を出す
- 撃破時は小型へ分裂させるかは今後決定する

## 4. 5Stageの色違い

輪郭、顔、紙切れ、しっぽの位置は5体すべて同じにする。

変えてよいのは、身体内部の色面、薄い縁光、Stageモチーフを示すごく小さい色片だけ。

| Stage | paletteKey | 主な色 | 小さい差し色 | 意味 |
|---:|---|---|---|---|
| 1 | `fragment_blue` | 青紫のインク | くすんだ古紙金 | 欠片を拾う夜 |
| 2 | `name_violet` | 葡萄紫のインク | 薄い藤色 | 名前と名札 |
| 3 | `seal_umber` | 焦茶紫のインク | くすんだ封蝋赤 | 箱と封印 |
| 4 | `route_teal` | 青緑黒のインク | 褪せた水色 | 切符と帰路 |
| 5 | `lantern_amber` | 深い藍黒 | 控えめな琥珀 | 灯りと朝 |

### 色違いの制限

- 本体の70%以上は黒インクfamilyとして暗く保つ
- 虹色のスライム集団にしない
- 目の基本色は5Stageで古紙色を維持する
- Stage 5の琥珀もランタンやpickupより暗く小さくする
- 色違い以外に角、耳、帽子、武器を追加しない
- 同じfamilyを保つため、ポーズとカメラ角度を揃える

## 5. 180pxセル内の見せ方

生成参照シートでは実ゲームサイズより大きく描くが、後で縮小する前提で輪郭を単純に保つ。

| 種別 | セル内占有 | 目安 |
|---|---:|---|
| ポン影 | 52〜60% | 小さく丸い基準敵 |
| ふくらみポン影 | 64〜72% | 小型より明確に大きいが中ボス未満 |

- 各辺4px以上の完全透明安全域
- 2種を同じ大きさにしない
- 中型は小型の約1.35〜1.5倍の見た目面積
- 5色すべて同じ基準線、同じ向き、同じ占有率にする

## 6. 採用判定

### ポン影

- 黒いシルエットだけで他のblob敵と区別できる
- 5秒後に記憶で描き直せる
- 目、切れ込み、しっぽの3点が1xで残る
- かわいいが、プレイヤーや仲間には見えない
- ぬいぐるみ、アイコン、ステッカーへ展開できる

### ふくらみポン影

- ポン影のfamilyだと分かる
- 単なる拡大コピーに見えない
- 小型より重く、進路を塞ぐ印象がある
- 中ボスほど装飾的ではない

## 7. 禁止方向

- ドラゴンクエストのスライムに近い尖った雫輪郭
- 他作品の目、口、頬、王冠の模倣
- 丸い黒塗りへ目を置いただけ
- 色ごとに別キャラクター化するアクセサリー追加
- 大きな笑顔、牙、舌
- ネオン発光
- 目をpickupと同じ金色サイズにする
- 小型を拡大しただけの中型
- 5色で身体の形やカメラ角度が変わる

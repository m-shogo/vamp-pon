# Enemy 48 Sprite Sheet Plan

## Status

- status: `prototype-reference`
- scope: 48体の役割、8x6配置、生成条件、検品条件を固定する
- deferred: 個別ステータス、詳細AI、細かい物語、正式名称、各形態の演出尺
- production: 未昇格。生成画像をそのまま本番へ入れない

## 1. 決定事項

48セルは次の配分にする。

| 区分 | 数 |
|---|---:|
| 雑魚 | 25 |
| 中ボス | 10 |
| 大ボス基本形態 | 3 |
| 大ボス別形態 | 10 |
| 合計 | 48 |

各Stageの雑魚は7体ではなく5体に絞る。

```txt
Stage 1: 雑魚5 + 中ボス2
Stage 2: 雑魚5 + 中ボス2 + 大ボス1 + 別形態3
Stage 3: 雑魚5 + 中ボス2
Stage 4: 雑魚5 + 中ボス2 + 大ボス1 + 別形態3
Stage 5: 雑魚5 + 中ボス2 + 大ボス1 + 別形態4
```

雑魚を増やす代わりに、大ボスの形態変化へセルを使う。これにより、通常戦の学習負荷を抑えながら、大ボス戦の格と物語上の反転を強くする。

## 2. 大ボス戦の時間ルール

「時間停止」はゲーム自体の停止ではない。

大ボス出現中は以下を停止する。

- Stageの生存時間カウント
- 通常waveの進行
- 通常敵の新規spawn
- 時間経過による難易度上昇

以下は進行する。

- プレイヤー操作
- 攻撃、クールダウン、移動
- 大ボスの内部フェーズ時間
- 大ボス固有ギミック
- 被弾無敵、状態異常などの戦闘時間

大ボス撃破と結果遷移が完了した後にStage時間を再開する。大ボス戦にかかった時間は生存時間へ加算しない。

## 5. 生成画像の固定仕様

```txt
canvas: 1440x1080px
grid: 8 columns x 6 rows
cell: 180x180px
color mode: RGBA
background: alpha 0の完全透過
total: 48 non-empty cells
```

必須条件:

- 画像全体が厳密に `1440x1080px`
- 8列x6行を厳密に維持
- 各セルは厳密に `180x180px`
- 48セルすべてに1体または1形態を配置
- 空セル、重複セル、結合セルを作らない
- セル外にはみ出さない
- 隣接セルへ影、発光、インク飛沫を漏らさない
- 背景、枠線、ガイド、番号、文字、ロゴを描かない
- 背景は見た目上の市松模様ではなく、本当にalpha 0
- 半透明エフェクトを使う場合も対象セル内に完全収納する
- 大ボス別形態は同一個体性を維持しつつ、輪郭で段階差が分かる

## 6. セル内のサイズ階級

セルを埋めるが、切り出し事故を防ぐため最外周には透明な安全域を残す。

| 種別 | 目標占有率 | 方針 |
|---|---:|---|
| 雑魚 | 55〜68% | 小型でもシルエットが読める |
| 中ボス | 70〜82% | 雑魚より明確に大きい |
| 大ボス/別形態 | 84〜94% | セル内最大。ただし接触禁止 |

- 透明安全域の目安は各辺4px以上
- 見た目の中心をセル中央へ置く
- 接地影も本体と同じセル内に収める
- 長い角、翼、尾、線路、鎖が最外周へ触れないよう曲げる

## 7. アート共通ルール

- soft painterly pixel art
- 紙片、絵本、夜、記憶、忘れ物、黒インクの世界観
- 黒一色の塊にしない
- 暗紺、紫黒、古紙色、小さな暖色光で面を分ける
- 同じ黒インクfamilyだが、48体を色違いだけにしない
- 各セルで最低でもシルエット、眼/光の位置、特徴部品、姿勢の3項目を差別化
- プレイヤー、記憶の欠片、hit coreと誤認する暖色点を乱用しない
- 大ボスは細部量だけでなく、輪郭と重心で格を出す
- 大ボス別形態は単純な色替え禁止

## 9. 検品条件

manifestだけ先に確認:

```sh
pnpm enemy48:manifest:check
```

画像を既定位置へ置いた後の完全検査:

```sh
pnpm enemy48:sprites:verify
```

別パスの画像を検査:

```sh
pnpm enemy48:sprites:verify -- path/to/enemy-sheet.png
```

検査実装:

```txt
scripts/quality/check-enemy-48-sprite-sheet.ts
```

画像受領時に最低限、機械検査で次を確認する。

1. PNGである
2. `1440x1080px`
3. RGBA
4. 背景透過を持つ
5. 8x6へ割り切れる
6. 全48セルが非空
7. 各セルのalpha bounding boxがセル内
8. 隣接セルへalphaが連結していない
9. 各セルを180x180 PNGとして切り出せる
10. manifestの番号と切り出し順が一致する

視覚検品:

- 1x
- 4x
- 夜背景
- プレイヤー、弾、欠片と混在するcombat mock
- 雑魚/中ボス/大ボスのサイズ差
- 大ボス各形態の同一個体性
- 48体のシルエット重複

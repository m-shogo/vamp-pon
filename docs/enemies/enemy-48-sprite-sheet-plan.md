
```txt

```

共通2種によってプレイヤーの学習負荷を下げ、固有3種によって各Stageの個性を作る。

```txt
Stage 1: 共通2 + 固有3 + 中ボス2
Stage 2: 共通2 + 固有3 + 中ボス2 + 大ボス1 + 別形態3

```

大ボスの形態へ10セルを使い、通常戦の種類を増やしすぎずにボス戦の格を作る。

## 3. 共通シャドウ2種

### 小型「ポン影」

Vamp Ponのスライム枠を狙う共通基準敵。

必ず維持する特徴:

- 下が少し広い丸い一滴型
- 左上の破れ紙の切れ込み
- 右下の短いインクしっぽ
- 高さが少し違う古紙色の2つの目
- 口なし
- `つぶれる -> ぽんと跳ねる`動き

### 中型「ふくらみポン影」

ポン影の成長体。単純な拡大画像ではない。

必ず維持する特徴:

- ポン影と同じ目、切れ込み、しっぽ
- 横に広い洋梨型
- 短く重いインク腕
- 厚いインク溜まりの底面
- 小型より重い着地

### Stage色

| Stage | paletteKey | 主色 | 差し色 |
|---:|---|---|---|
| 1 | `fragment_blue` | 青紫 | くすんだ古紙金 |
| 2 | `name_violet` | 葡萄紫 | 薄い藤色 |
| 3 | `seal_umber` | 焦茶紫 | くすんだ封蝋赤 |
| 4 | `route_teal` | 青緑黒 | 褪せた水色 |
| 5 | `lantern_amber` | 深い藍黒 | 控えめな琥珀 |

本体の70%以上は黒インクfamilyとして暗く保つ。輪郭、顔、向き、占有率は5Stageで統一し、内部色と縁光だけを変える。

## 4. 大ボス戦の時間ルール

「時間停止」はゲーム自体の停止ではない。

大ボス出現中に停止:

- Stageの生存時間カウント
- 通常waveの進行
- 通常敵の新規spawn
- 時間経過による難易度上昇

大ボス戦中も進行:

- プレイヤー操作
- 攻撃、クールダウン、移動
- 大ボスの内部フェーズ時間
- 大ボス固有ギミック
- 被弾無敵、状態異常などの戦闘時間

大ボス撃破と結果遷移の完了後にStage時間を再開する。大ボス戦にかかった時間は生存時間へ加算しない。

## 7. 生成画像の固定仕様

```txt
canvas: 1440x1080px
grid: 8 columns x 6 rows
cell: 180x180px
color mode: RGBA
background: alpha 0の完全透過
total: 48 non-empty cells
```

必須:

- 画像全体が厳密に `1440x1080px`
- 8列x6行、各セル厳密に `180x180px`
- 48セルすべて非空
- 1セル1体または1形態
- セル外へ本体、影、発光、飛沫を漏らさない
- 背景、枠線、番号、文字、ロゴなし
- 市松模様ではなく本当にalpha 0
- 各辺4px以上の完全透明安全域

## 8. セル内サイズ階級

| 種別 | 目標占有率 | 方針 |
|---|---:|---|
| ポン影 | 52〜60% | 小さく丸い基準敵 |
| ふくらみポン影 | 64〜72% | 小型より大きく、中ボス未満 |
| Stage固有雑魚 | 55〜68% | 役割が輪郭で読める |
| 中ボス | 70〜82% | 雑魚より明確に大きい |
| 大ボス/別形態 | 84〜94% | セル内最大。ただし接触禁止 |

- 中型共通敵を小型の拡大コピーにしない
- 長い角、翼、尾、線路、鎖はセル内へ曲げる
- 接地影も同じセル内に収める

## 9. アート共通ルール

- soft painterly pixel art
- 紙片、絵本、夜、記憶、忘れ物、黒インク
- 黒一色の塊にしない
- プレイヤー、記憶の欠片、hit coreと誤認する暖色点を乱用しない
- 共通2familyは同一輪郭を維持
- Stage固有敵はシルエット、眼/光、特徴部品、姿勢のうち最低3項目を差別化
- 大ボス別形態は単純な色替え禁止

## 11. 検品

manifestのみ:

```sh
pnpm enemy48:manifest:check
```

画像配置後:

```sh
pnpm enemy48:sprites:verify
```

別パス:

```sh
pnpm enemy48:sprites:verify -- path/to/enemy-sheet.png
```

検査内容:

- 25雑魚 / 10中ボス / 3大ボス / 10別形態
- 共通小型5 / 共通中型5 / Stage固有15
- 各Stageが共通小1・共通中1・固有3
- 5StageのpaletteKeyが重複なく対応
- 1440x1080 PNG RGBA
- 48セルすべて非空
- 4px安全域
- セル越境なし

画像の視覚検品:

- 1x / 4x
- 夜背景
- combat mock
- 共通2種の同一family性
- 小型と中型のサイズ・重さの差
- Stage固有15体のシルエット重複
- 大ボス各形態の同一個体性

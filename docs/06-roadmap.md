# ロードマップ

## Day 1: プロジェクト起動

到達状態:

- Vite + TypeScript + Phaser が起動する
- ブラウザにゲーム画面が出る
- プレイヤーが表示される
- キーボードで移動できる

やること:

- package.json 作成
- Vite設定
- Phaser導入
- MainScene作成
- プレイヤー仮表示
- dev/build/typecheck確認

切る判断:

- ここで凝ったアートを入れない
- UIを作り込みすぎない
- 設計を増やしすぎない

## Day 3: 最小ゲーム化

到達状態:

- 敵が湧く
- 敵がプレイヤーへ向かう
- 自動攻撃で敵を倒せる
- プレイヤーがダメージを受ける
- HPが0になったら終了する

やること:

- Enemy作成
- Projectile作成
- CombatSystem作成
- EnemySpawnSystem作成
- HP表示
- ゲームオーバー仮処理

切る判断:

- 敵種類は1〜2で止める
- 武器は1種類で止める
- レベルアップはまだ仮でよい

## Week 1: 5戦線の検証

到達状態:

- 5戦線UIが出る
- 敵の位置から戦線判定できる
- 戦線ごとの危険度が変わる
- 危険な戦線を見て立ち回りが少し変わる

やること:

- FiveFrontSystem作成
- FrontStatusView作成
- 危険度計算
- 戦線ごとの敵数集計
- 赤/黄/緑の表示
- 1プレイ3〜5分に調整

切る判断:

- 戦線が面白さに関係しないなら作り直す
- UIが見づらければ先に直す
- 戦線専用スキル追加は最小限

## Week 2: ローグライト化の入口

到達状態:

- レベルアップ選択がある
- 強化でプレイ感が変わる

- リザルトで敗因が見える

やること:

- 戦線補強系の強化追加

## 途中でやめる/戻す基準

以下の場合は、追加実装ではなく設計を戻す。

- 戦線UIを見なくてもプレイが変わらない
- 敵密度だけのゲームになっている
- 強化選択がただの攻撃力アップばかり
- どこで失敗したか分からない
- 操作が忙しすぎて「ぼけっと遊べる」が消えている

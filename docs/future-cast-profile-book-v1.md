**Core:** 分類を拒絶することが主目的ではなく、目の前の現象を分類より先に聞く人。

**Contradiction:** 「決めつけない」ことを大事にしすぎて、自分の意見まで言わずに残すことがある。

**黒耀化:** `決めつけたくない → 何にも名前・分類・結論を付けられなくする`。

**Growth:** 決めつけと、暫定的に言葉を置くことは違うと知る。

**Gameplay:** sound ping / hidden wave detection / uncertainty reveal。

**Boundary:** 後から「実は男 / 女でした」を大オチにしない。性別が分からないこと自体をMystery rewardにしない。

# 16. Romance / gender / representation boundaries

## Gay / Lesbian / Bisexual

- 恋愛はある。
- sexualityだけをCharacter Coreにしない。
- heterosexual romanceだけが普通の日常、同性恋愛だけが社会問題、にはしない。
- bisexualityを indecision / promiscuity の比喩にしない。
- 同性恋愛にも楽しかった日常、失恋、喧嘩、冗談、長期関係を普通に持たせる。
- 年代差による記録のされ方の違いは使えるが、全員へ差別悲劇を背負わせない。

## 男の娘 / feminine-presenting man

- gender identityは男性。
- feminine presentationは罰、偽装、オチではなく本人の好み。
- sexualityを外見から決めない。
- 成長で「男らしい格好」へ矯正しない。

## 性別不詳 / undisclosed gender

- playerへ当てさせるクイズにしない。
- revealをrewardにしない。
- pronoun / 呼称 / UIは日本語の名前呼び等で自然に成立させる。
- 本人の人格・Gameplayを先に覚えてもらう。

## Twins

- 「性格が真逆」だけのテンプレにしない。
- 似ているところも違うところも本人が選んだもの / 偶然のものを混ぜる。
- one twin dies to motivate the other、を中心にはしない。Happy End Coreを守る。

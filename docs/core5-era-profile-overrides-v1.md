# 2. Asa name rationale override

SUPERSEDED wording in the base profile:

> 夜の物語の先にある「朝」を思わせる短い音。名前を取り戻す役と、夜明けへ向かうテーマをつなぐ。

This is no longer Current because **Yoru-no-Shirube has no physical morning / dawn goal**.

Current rationale:

> **「アサ」という短く呼びやすい音を、名前そのものを大切にする人物へ与える。Realityには朝という普通の言葉が存在するが、Dreamの物理的夜明けを示す名前ではない。未来社会でhuman name / chosen name / model designationが衝突する中、短い手書きの呼び名を好む人物性との対比を強くする。**

Important:

- Asa's name does not prove Dream will have a morning.
- Do not rename Asa merely because `朝` is a Japanese word.
- The contrast `Future society + handwritten short name` is intentional.

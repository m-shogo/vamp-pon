# 5戦線システム

## 概要

Vamp Pon の中心システム。

ステージを以下の5戦線で考える。

- 前線
- 後方
- 左翼
- 右翼
- 中央

戦線は単なる表示名ではなく、敵の湧き方・危険度・強化対象・敗因分析に使う。

## 戦線の役割

### 前線

正面から押してくる敵を受ける場所。

特徴:

- 近距離敵が多い
- 数の圧が出やすい
- 範囲攻撃やノックバックが刺さる

不足すると:

- 敵が中央へ流れ込む
- プレイヤーが逃げ場を失う
- 近距離処理が追いつかない

### 後方

背後・遠距離・奇襲に関係する場所。

特徴:

- 遠距離敵
- 召喚敵
- 追尾弾
- 後ろからのじわじわ削り

不足すると:

- 気づいたらHPが減る
- 安全地帯がなくなる
- 回復や経験値回収が危険になる

### 左翼

左側からの圧。

特徴:

- 偏った湧きでプレイヤーを動かす
- 魔法型や分散型を混ぜやすい
- 範囲攻撃の向き・配置が意味を持つ

不足すると:

- 左から中央に敵が侵入する
- プレイヤーが右へ寄せられる
- 片側処理ビルドの弱点が出る

### 右翼

右側からの圧。

基本は左翼と対になるが、左右で敵タイプを変えてもよい。

特徴:

- 突破型
- 高速敵
- 小型の群れ
- 右側に寄せる判断を要求する

不足すると:

- 中央への突破を許す
- プレイヤーの移動ルートが潰れる
- 左右差の対策不足が見える

### 中央

最終防衛ライン。

特徴:

- プレイヤーの生存に直結
- 全戦線の圧が集まる
- 守り切ると気持ちいい

不足すると:

- 全体崩壊
- 逃げ場消失
- ボスや大型敵で詰む

## 危険度

各戦線には危険度を持たせる。

仮の段階:

- green: 安全
- yellow: 注意
- red: 危険
- broken: 崩壊寸前

危険度は以下から計算する。

- その戦線にいる敵数
- 敵タイプの危険度
- プレイヤーからの距離
- 中央へ向かう敵の数
- 戦線用の防御・支援効果

## 強化との関係

レベルアップ時の選択肢に、戦線対象を含める。

例:

- 前線のノックバック +15%
- 後方からの遠距離ダメージ -10%
- 左翼に自動砲台を設置
- 右翼の敵を一定確率で鈍足
- 中央周辺の回復量 +20%

## 敵タイプとの関係

敵は戦線に意味を与えるために作る。

### 近距離型

前線の基本敵。

### 遠距離型

後方・中央に圧をかける。

### 魔法型

範囲や状態異常で片側戦線を崩す。

### 突破型

左右から中央へ抜ける。

### 分散型

複数戦線にばらけて、単純な一点火力を弱くする。

### 大型型

終盤の戦線崩壊テスト。

## UI方針

画面に常時5つの戦線表示を置く。

初期案:

```txt
前線  [■■■□□] yellow
後方  [■■□□□] green
左翼  [■■■■□] red
右翼  [■□□□□] green
中央  [■■■□□] yellow
```

重要なのは豪華さではなく、**どこが危ないか一瞬で分かること**。

## MVPでやること

- 5戦線ラベル表示
- 危険度の仮計算
- 敵の位置から戦線を判定
- 戦線ごとの敵数表示
- red の戦線を画面上で分かりやすくする

## MVPでやらないこと

- 戦線ごとの複雑な地形
- 完全なAIディレクター
- 大量の戦線専用スキル
- 緻密なバランス調整

## 注意

5戦線は見た目の設定ではなく、ゲーム判断の単位にする。

実装で迷ったら、次の質問に戻る。

> この追加は、どの戦線が危ないかを面白くしているか？

# Foreshadowing and Seed Registry

## 目的

後付け感を減らすため、Season 1の最初から将来使える伏線を置く。

ただし、名前や真相を直接出しすぎない。

Vamp Ponでは、余白を残す。

しかし、余白は放置ではない。

```txt
答えを持っているが、全部は見せない。
```

---

# 1. 基本方針

## やる

```txt
名前を出さずに筆跡を出す
人を出さずに持ち物を出す
真相を言わずに矛盾した小物を出す
別の地図帳や別の班の可能性を少しだけ出す
```

## やらない

```txt
黒幕を出す
続編前提の未完エンドにする
説明しすぎる
Season 1の感動を壊す
```

---

# 2. Seedの種類

## 人物Seed

将来キャラ化できる痕跡。

例:

```txt
ユイと違う筆跡
知らない印
直されたランタン
誰かの名札
持ち主不明のしおり
```

## 場所Seed

将来Stage化できる痕跡。

例:

```txt
地図帳の閉じたページ
街の外の標識
別の駅名
消えかけた郵便箱
遠くの灯台
```

## 感情Seed

将来テーマ化できる痕跡。

例:

```txt
届かなかった手紙
写っていない写真
聞こえなかった音
渡せなかった贈り物
待っていた灯り
```

## システムSeed

将来機能化できる痕跡。

例:

```txt
別の記憶片
別の欠片色
地図帳の複数ページ
未読の図鑑欄
空いたキャラ枠
```

# 4. 後からキャラ追加しても後付けに見えないルール

キャラ追加時は、Season 1にあるSeedへ接続する。

悪い:

```txt
突然、新キャラが昔から重要だったと言う
```

良い:

```txt
昔から出ていた筆跡/道具/印の持ち主だったと分かる
```

必ず、追加キャラには既存Seedを1つ紐づける。

---

# 5. 後からStage追加しても後付けに見えないルール

Stage追加時は、Season 1にある場所Seedへ接続する。

例:

```txt
郵便箱 -> 手紙Stage
閉じたページ -> 別の地図帳Stage
遠くの灯台 -> 海辺Stage
聞こえないラジオ -> 音Stage
```

---

# 6. Seed密度

出しすぎない。

目安:

```txt
1ランに1〜2個
1Stageに3〜5個
エンディングに1個だけ次の余白
```

多すぎると、謎だらけになって気持ちよさを邪魔する。

---

# 7. Seedの回収ルール

全Seedを回収しない。

回収する:

```txt
Season 1の感情に必要なSeed
ユイ/アサ/最初の班に関係するSeed
```

残す:

```txt
別の地図帳
別の班
別テーマ
別アプリ候補
```

---

# 8. Seed台帳フォーマット

今後Seedを追加する時は、この型にする。

```txt
ID:
初出:
見せ方:
表の意味:
裏の意味:
回収予定:
回収しない場合の扱い:
関連キャラ:
関連Stage:
```

# 10. 最重要

後付けに見せないためには、最初から全部説明する必要はない。

必要なのは、後で使える痕跡を最初から置くこと。

```txt
名前は出さない。
でも、筆跡は残す。
```

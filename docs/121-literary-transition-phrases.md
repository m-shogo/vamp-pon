# Literary Transition Phrases

Vamp Pon / ヴァンサバ改のロード画面・図鑑・キャラ返信に使える、「閑話休題」のような場面転換語・文章語・少し博識な言葉の整理。

---

## 1. 目的

ユーザー方針:

```txt
閑話休題みたいなものが好き。
知っていると少し気持ちいい言葉が欲しい。
普段使わないが、本を読んでいると出てくるような言葉を入れたい。
```

この資料の目的:

```txt
難語をただ並べるのではなく、物語・会話・ロード演出の「切り替え」として使う。
Vamp Ponの夜、記憶、寄り道、帰り道に接続する。
```

---

## 2. 基本方針

```txt
難しい言葉を見せびらかさない。
言葉の意味は短く添える。
キャラ返信でVamp Ponの感情へ戻す。
ロードでは短く、図鑑では少し詳しく。
```

表示構造:

```txt
語句:
意味:
キャラ返信:
```

例:

```txt
閑話休題

それはさておき、本題に戻ること。

寄り道にも、帰り道があるんだね。
— ナギ / Nagi
```

# 3. 候補語句

## 3.1 閑話休題

語句:

```txt
閑話休題
```

意味:

```txt
それはさておき、本題に戻ること。
```

Vamp Ponでの使いどころ:

```txt
寄り道、話の脱線、ロード画面からステージへ戻る時。
```

Character replies:

```txt
寄り道にも、帰り道があるんだね。
— ナギ / Nagi
```

```txt
本題に戻る前に、忘れ物をひとつ拾ってもいい？
— ユイ / Yui
```

# 4. 使い方

ロード画面:

```txt
語句 + 短い意味 + 返信
```

図鑑/記録室:

```txt
語句 + 意味 + 用例 + 関連キャラ + 関連ロード文
```

ステージ演出:

```txt
閑話休題 = ロードから本編に戻る演出
序破急 = ボス演出テンポ
画竜点睛 = 進化/朝明の最後の一撃
有耶無耶 = 黒耀が濃い状態
曖昧模糊 = 霧ステージ/迷子ステージ
```

---

# 5. 最終方針

```txt
閑話休題のような言葉は、知識欲を満たすだけでなく、ゲームのテンポや演出にも使える。
```

Vamp Ponでは、

```txt
知らない言葉に出会う
意味を短く読む
キャラの返信で笑う/少し刺さる
もっと知りたい人は調べる
```

という流れを作る。

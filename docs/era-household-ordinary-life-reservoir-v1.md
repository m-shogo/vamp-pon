# 0. Hard boundary

このReservoirから固定しない:

- Core5のexact birth year
- Core5のexact parent / child / sibling / grandparent
- exact household structure
- exact parent occupation
- exact school / company / neighborhood
- exact dialect vocabulary
- real historical victim / tragedy
- real company as villain
- final Season scene order

禁止:

- 昔の人 = 無知
- 現代人 = 正解
- Future = 上位互換
- child = moral oracle
- mother = housework only
- father = work only
- grandparents = wisdom machine
- aunt/uncle = comic relief only
- single adult = lonely by default
- non-family household = dysfunctional by default
- technology adoption = intelligence test
- poverty / pollution / discrimination / disabilityそのものをjokeにする
- real tragedyをrename-copy
- physical sunriseでRealityへ戻す

Scene rule:

```txt
ordinary desire
+
Era-specific tool / rule / habit
+
small inconvenience or delight
+
relationship reaction
```

歴史説明は最後までしなくてもよい。

# 2. トモリEra — 戦後復興・物資不足期

Status: Era band CURRENT / exact year OPEN。

Tone:

> 不足はある。しかし、毎日が悲惨な画面ではない。

学校、遊び、修理、恋、仕事、近所、食事、笑いが普通にある。

## 2.1 CHILD — 4 seeds

### T-C01 School return / repaired bag

子どもが学校から帰る。
鞄のstrapがまた緩んでいる。

Adult A:
> 「またか。」

Child:
> 「まだ落ちてない。」

repairをpoverty symbolだけにせず、**雑に使う子ども vs 何度でも直す大人**の生活Comedyにする。

Possible use:
- Tomoriがrepairへ反応する原風景Candidate
- exact relativeはOpen

### T-C02 Shared snack division game

少ない菓子 / 芋 /果物等を数人で分ける。

子ども同士で:

- 大きさを比べる
- 一番小さいのを最後に残す
- くじで決める
- 「半分こ」の切り方でもめる

scarcityの悲惨さより、**公平を遊びに変える子どもの知恵**。

### T-C03 Reused toy trade

壊れかけの玩具を交換。

一人は:
> 「こっちの方が傷多い。」

別の子:
> 「その傷あるからいいんだよ。」

Object value != newnessを自然に見せる。

### T-C04 Bath fuel turn order

湯を沸かすfuel / 手間を考え、入浴順で家族/同居人が軽く揉める。

- child wants first
- adult wants youngest/oldest first
- someone is still working

「昔は風呂が大変だった」説明ではなく**誰を待つか**の関係scene。

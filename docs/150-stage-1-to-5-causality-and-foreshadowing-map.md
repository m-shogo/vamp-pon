# Vamp Pon Stage 1〜5 Causality and Foreshadowing Map

## 0. 目的

Stage 1〜5を、きれいな背景5枚やキャラクター紹介5本にしない。

最初の5Stageは、Core 5が過去に行った一つの共同作業を、ユイとプレイヤーが逆向きに読み直すページ束である。

この文書は以下を固定する。

- なぜ5Stageがこの順番なのか
- 各キャラが何をしたのか
- その行動が次Stageをどう生んだのか
- プレイヤーに何を誤解させるか
- 何をStage 5で回収し、何をSeason 1終盤まで残すか
- 背景小物、敵挙動、ギミックを物語へ接続する方法

# 1. Core 5の共通事件

## 仮称

```txt
最初の返し夜
```

ゲーム内でこの名称をすぐ表示しない。制作側の因果整理名として使う。

## 事件の表面

ユイは黒インクから剥がれた意味片を拾い、灯りで朝まで保持し、正しい持ち主へ返そうとしていた。

途中で灯りが壊れ、名前、保管、帰路、接続が分断された。

ユイの記憶には次だけが残った。

```txt
自分が集めすぎた
自分が守れなかった
みんなは帰らなかった
自分だけで朝まで運ばなければならない
```

これは事実ではなく、黒読みが固定したユイ自身の誤読である。

## 本当の因果

```txt
1. ユイが意味片を運ぶ
2. 黒読み・集めすぎが、ユイを「全部を奪う者」と誤固定する
3. アサが名前と持ち主の対応を隠し、すり替えを防ぐ
4. ナギが壊れた灯りの一部と読まれると壊れる理由を月箱へしまう
5. ミチルが帰路を一つの完成線にせず、分割した印として残す
6. トモリが集まった部品と印を使い、灯りを何度も直す
7. 5人の働きが分断されたため、ユイだけが「一人だった」と記憶する
```

誰か一人が全てを救ったのではない。

```txt
名前を守る
壊れ物を守る
道を守る
灯りを直す
持ち主へ運ぶ
```

という異なる行為がつながって、初めて朝へ届く。

# 2. Core 5の個人ストーリー

## ユイ — 持つことと返すこと

### 表の印象

落ちている欠片を集め、自分の力で夜を進む主人公。

### 固定された誤読

```txt
拾ったものは自分が背負わなければならない
持っている自分が所有者であり、責任者である
失敗したのは自分一人
```

### 本当の役割

ユイは所有者ではなく、意味を読み直して正しい持ち主へ運ぶ中継者。

### 変化

```txt
全部を持つ
→ 誰のものか読む
→ 一人で背負わず、つなぎ直す
```

### Season 1で残す空白

- なぜユイは全員と一度会っていたのか
- 最初の返し夜で何が灯りを壊したのか
- ユイが見た複合属性の片側は誰だったのか

---

## アサ — 名前を呼ぶことと固定しないこと

### 表の印象

名前を消された、忘れられた人物。

### 固定された誤読

```txt
名前を書き直すのは、元の名前を消すこと
空白は忘却
本名で呼ばれない者は大切にされていない
```

### 本当の行動

アサは黒読み・すり替えに持ち主を固定されないよう、名前を何度も薄くし、書き直した。

アサが皆にあだ名を使い、ユイだけを本名で呼ぶのは、距離の差ではなく「ユイの名前だけは間違えない」という意思。

### ユイへの因果

アサが名前と意味片の対応を一時的に隠したため、ユイは全部を奪った者として完全固定されずに済んだ。

### 変化

```txt
名前を消された
→ 名前を隠して守った
→ 呼ぶことは所有ではなく、帰る先を示すこと
```

---

## ナギ — 閉じることと守ること

### 表の印象

何かを箱へ閉じ込め、真相を隠した人物。

### 固定された誤読

```txt
閉じることは支配
開ければ真実
隠した者が悪い
```

### 本当の行動

ナギは、壊れた灯りの部品と「読まれると黒く固定される理由」を月箱へしまった。

外から奪われないためではなく、正しい灯りが戻るまで中身自身が開かないよう、鍵穴を内側へ向けた。

### ユイへの因果

ナギが部品を残さなければ、トモリは灯りを修復できず、ユイは意味片を朝まで保持できなかった。

### 変化

```txt
閉じ込めた
→ 壊れない時間を作った
→ 開けない優しさもある
```

---

## ミチル — 場所へ帰ることと人へ帰ること

### 表の印象

帰り道を失い、皆を帰せなかった人物。

### 固定された誤読

```txt
完成していない道は失敗
目的地が読めなければ帰れない
片方だけの切符は片道
```

### 本当の行動

ミチルは黒読み・飲み込みに道全体を奪われないよう、帰路を完成線として残さず、切符、針、糸、印へ分割した。

道の終点は建物ではなく、灯りを直し続ける人の位置だった。

### ユイへの因果

ミチルの印が、ナギの箱に守られた部品をトモリの灯りへつなぐ。

### 変化

```txt
道を残せなかった
→ 飲み込まれない形へ分けた
→ 帰る場所は地名ではなく、人でもよい
```

---

## トモリ — 待つことと直し続けること

### 表の印象

帰ってこない誰かを、灯りのそばで待ち続けた人物。

### 固定された誤読

```txt
待つだけで何もしなかった
灯りを消せないのは執着
ユイは自分だけで夜を進んだ
```

### 本当の行動

トモリは待っていたのではない。

アサの名札ピン、ナギの月留め、ミチルの道糸、残されたガラスと芯を使い、皆が戻れるよう灯りを何度も修理した。

### ユイへの因果

トモリの灯りが、分けられていた名前、部品、道、意味片を一時的に同じ持ち主へ再接続する。

### 変化

```txt
待ちぼうけ
→ 帰れる状態を直し続けた
→ 待つことは能動的な助けになり得る
```

---

# 3. Stage順の必然

5Stageの順番はキャラ順ではなく、壊れた返却手順を復元する順番。

```txt
Stage 1 意味片を見つける
Stage 2 持ち主の名前を守る
Stage 3 壊れ物と理由を保持する
Stage 4 持ち主までの帰路を読む
Stage 5 全要素を灯りで仮接続する
```

この順番を変えると因果が崩れる。

- 名前がなければ箱の中身を誰へ返すか決まらない
- 箱がなければ灯りの部品が残らない
- 道がなければ直した灯りへ届かない
- 灯りがなければ全てを朝まで保持できない

# 4. Stage別の伏線・誤解・回収

## Stage 1 — ちぎれた夜の広場

### 主誤読

```txt
黒読み・集めすぎ
```

ユイが欠片を集めるほど、「全部を自分のものにした」という誤読が強くなる。

### プレイヤーに思わせること

- 欠片は経験値
- 影はユイを襲うだけ
- ユイは一人で戦っている

### 背景へ置く伏線

#### 1. 四つの消えた接続点

薄い地図線が、広場の外周にある4か所で途切れている。

形だけが次を示す。

- ピン穴
- 月形の留め跡
- 切符のパンチ穴
- すすけた修理跡

初見では紙の傷に見える。

#### 2. 特殊欠片4種

通常欠片へ混ぜ、非常に少ない確率で次の輪郭を持たせる。

- 名札の角
- 月箱の内張り
- 切符の繊維
- ランタンガラスの反射

図鑑で断定しない。

#### 3. 影は欠片を踏まない

敵は欠片を奪わず、ユイだけを狙う。

これは欠片が欲しいからではなく、黒読みが「持っている者」を犯人として固定する性質の伏線。

### Stage 5での回収

四つの接続点が灯りでつながり、欠片が5人の行動の結果として残ったものだと分かる。

---

## Stage 2 — 名前をなくした札庭

### 主誤読

```txt
黒読み・すり替え
```

### プレイヤーに思わせること

- アサの名前が消えた
- 誰かが名前を奪った
- 空白は欠落

### 背景へ置く伏線

#### 1. 同じ筆圧の書き直し

中央名札の消し跡は、別人による上書きではなく、同じ人物が何度も書き直した線にする。

#### 2. 名札ピンの欠損

主名札のピンが一つ欠けている。

Stage 5のランタン修理部に同形のピンが使われている。

#### 3. 月形の折り癖

名札裏にだけ小さな月形の折り癖がある。

アサの保護情報がナギの月箱へ渡ったことを示す。

#### 4. 名札影は名札を踏まない

名札を壊したいのではない。

一つの名前へ固定したいが、空白のままでは確定できず、周囲をうろつく。

### Stage 5での回収

ランタンの光で、空白に完全な名前ではなく「最初の一画」だけが戻る。

名前を全部表示しない。アサが隠して守った事実だけを回収する。

---

## Stage 3 — 月箱の保管庫

### 主誤読

```txt
黒読み・閉じ込め
```

### プレイヤーに思わせること

- ナギが危険なものを閉じ込めた
- 開ければ真相
- 箱を守る敵は中身を隠している

### 背景へ置く伏線

#### 1. 内側の鍵穴

外から鍵を入れられない形。

正しい灯りが来た時に、中身側から開く仕組み。

#### 2. 箱の内張りから見える反射

完全には見せず、割れたランタンガラスと同じ反射色を一瞬だけ出す。

#### 3. 名札ピンに合う小穴

箱の蝶番にStage 2で欠けていたピンと同じサイズの穴がある。

アサの保護とナギの保管が連続した行動である証拠。

#### 4. 道糸の縫い目

箱の底面に、Stage 4の帰り線と同じ縫い目を一本だけ置く。

ミチルが箱の場所を後から見つけられるようにした印。

### Stage 5での回収

ランタンの光が当たると箱が外から開くのではなく、内側から数ミリだけ持ち上がる。

中身を全公開しない。

「閉じたまま残したから、直せた」という因果だけを見せる。

---

## Stage 4 — 逆さ改札と帰り線

### 主誤読

```txt
黒読み・飲み込み
```

### プレイヤーに思わせること

- 道が消えた
- ミチルが帰路を失敗した
- 片方の切符は片道

### 背景へ置く伏線

#### 1. 線路は途中で消えず、別の素材へ変わる

```txt
地図線
→ 箱底の道糸
→ ランタン持ち手の巻き糸
```

画面上では別物に見えるが、太さと結び目を一致させる。

#### 2. 裏面だけ温かい切符

表面は目的地がない。

裏面の帰り印はStage 5のランタン光でのみ読める。

#### 3. 改札の先に場所ではなく灯りの輪郭

遠景に建物を置かず、修理台と小さな灯りの輪郭だけを置く。

帰る先が地名ではなく、トモリのいる場所だった伏線。

#### 4. 片方のパンチ穴

切符の欠損形状は将来のトバリSeedとして残す。

最初の5Stageでは誰がもう片方を持つか断定しない。

### Stage 5での回収

帰り線が全てランタンへ向かうのではなく、ランタンを経由して名札、箱、欠片へ戻る往復線になる。

片道ではなかったと視覚で示す。

---

## Stage 5 — 朝をつなぐ灯り庭

### 主誤読

```txt
黒読み・執着
```

副攻撃として黒読み・焼き潰しを使い、灯りや読めない文字を消そうとする。

### プレイヤーに思わせること

- トモリが一人で待っていた
- ランタンはトモリの個人物
- ユイは自力でここまで来た

### 主ランドマークの意味

修理ランタンには5人の痕跡がある。

| 痕跡 | 持ち主 | 意味 |
|---|---|---|
| 元の芯と火 | ユイ | 意味を運ぶ力 |
| 名札ピンの鋲 | アサ | 持ち主を誤固定させない |
| 月形の留め金 | ナギ | 壊れた部品を朝まで守る |
| 道糸の巻き | ミチル | 分断された帰路をつなぐ |
| 複数回の修理跡 | トモリ | 帰れる状態を直し続ける |

### 連鎖回収

灯りを一度に全部点灯させない。

```txt
1. 欠片が震える
2. 名札に一画だけ戻る
3. 箱が内側から少し開く
4. 切符裏の帰り印が光る
5. 道線がランタンを経由して往復線になる
6. 広場の四つの切断点がつながる
```

この順番で、Stage 1〜4のプレイ体験を意味へ変える。

### Stage 5で明かすこと

- 5人は別々に助けていた
- トモリは待つだけではなかった
- ナギは隠すためでなく残すために閉じた
- ミチルの道は失敗ではなかった
- アサの空白は忘却ではなかった
- ユイは一人で夜を歩いていなかった

### Stage 5で明かさないこと

- 最初の返し夜を壊した直接原因
- ユイが全員と一度会った経緯
- もう片方の切符の持ち主
- 箱の隠し文全文
- 複合属性の正体

完全解説にしない。

# 5. 七つの黒読みとの対応

| Stage | 主黒読み | 見かけ | 本当の反転 |
|---:|---|---|---|
| 1 | 集めすぎ | ユイが全部集めた | 返すために一時保持した |
| 2 | すり替え | 名前を消した | 誤った持ち主へ固定されないよう隠した |
| 3 | 閉じ込め | 真実を封印した | 読まれると壊れる理由を保護した |
| 4 | 飲み込み | 道が消えた | 奪われないよう複数の印へ分けた |
| 5 | 執着 | 帰らない相手を待った | 誰でも帰れる灯りを修理した |

## 横断する黒読み

### 決めつけ

全Stageの根にある。

一つの見た目を一つの意味へ固定する性質。

### 焼き潰し

Stage 5の消灯攻撃、読めない文字を黒くする演出として先出しする。

後のStageで主題化できる。

# 6. 意味のない小物を作らないルール

各小物は制作前に次を記録する。

| 項目 | 必須内容 |
|---|---|
| visual | 何に見えるか |
| owner | 誰の痕跡か |
| apparentMeaning | 初見でどう誤解させるか |
| trueMeaning | 実際は何をした証拠か |
| cause | 何が原因でそこにあるか |
| payoff | どのStage・条件で反応するか |
| gameplay | プレイ上何を示すか |
| futureSeed | 後の人物・事件につながるか |

`owner / cause / payoff` のどれかが空なら、物語小物ではなく純装飾として扱う。

純装飾は少数に制限し、伏線のように目立たせない。

## 1Stageの上限

```txt
主象徴物: 1
Core 5因果接続物: 1
将来Seed: 最大1
純装飾family: 2〜3
```

伏線を増やしすぎて全部を意味深にしない。

# 8. 伏線の強度

## A: 初見でも気づく

- 各Stageの主象徴物
- 敵の奇妙な挙動
- Stage 5の連鎖反応

## B: 注意すれば気づく

- ピン穴、月留め、道糸、修理跡の一致
- Stage間で同じ形が別用途に変わること
- 影が小物を壊さず、誤った意味へ固定しようとすること

## C: 後から見返して気づく

- Stage 1の四つの切断点
- 特殊欠片の輪郭
- future character Seed
- ランタン修理跡が最初から複数人分だったこと

全伏線をAにしない。

# 9. リザルト文の因果連鎖

リザルト文は単独の詩ではなく、5面を通して文意が変わるようにする。

## Stage 1

```txt
紙片は、落ちていたのではなく、待っていたように見えた。
```

## Stage 2

```txt
呼べなかった名前は、消えたわけではないのかもしれない。
```

## Stage 3

```txt
閉じたままだったから、消えずに残ったものがある。
```

## Stage 4

```txt
帰り道は、なかったのではない。まだ誰の道か読めないだけだった。
```

## Stage 5

```txt
ユイが拾った光には、最初から帰る先があった。
```

Stage 5の初回では、全てを文章で説明せず、映像反応を主とする。

# 10. 画像・ステージ生成への必須指示

Stage 1〜5を一括生成する際、各背景は次を満たす。

1. そのStage単体の雰囲気がある
2. 前Stageの行動結果が一つ残っている
3. 次Stageの原因が一つ見えている
4. Stage 5で反応する形が一つ埋め込まれている
5. 将来Seedは最大一つ
6. 背景小物だけで真相を解説しない
7. 同じ形を別用途へ変換し、因果を視覚でつなぐ

## 形の連鎖

```txt
名札ピン
→ 箱の蝶番穴
→ 切符パンチ穴
→ ランタンの鋲
```

## 線の連鎖

```txt
Stage 1の途切れた地図線
→ Stage 2の書き直し線
→ Stage 3の道糸
→ Stage 4の帰り線
→ Stage 5の光路
```

## 光の連鎖

```txt
欠片の脈動
→ 名札の一画
→ 箱内のガラス反射
→ 切符裏の温度
→ 修理ランタンの接続光
```

この3系統を5面すべてで一括管理する。

# 11. 最終狙い

初見:

```txt
忘れ物を拾いながら、変な小物のある夜を進むゲーム
```

Stage 5後:

```txt
各キャラが別々の方法で、同じ誰かの帰り道を残していた
```

Season 1終盤:

```txt
ユイが一人で皆を救った話ではない。
皆が一度ずつユイを助けたから、ユイは意味を返せた。
```

ハッピーエンドは奇跡で解決しない。

最初から背景に残っていた、小さな保護行動の積み重ねが朝を成立させる。

# 裏ストーリー実装パック

## 目的

Vamp Pon のストーリーは、表で説明しすぎない。

プレイヤーに強制的に読ませず、アイテム・実績・図鑑・秘宝武器・条件達成文から、分かる人には分かる形で裏ストーリーを伝える。

## 決定方針

```txt
表:
夜になると、忘れられた物から影が出る。

裏:
影は敵ではなく、忘れられた記憶だった。
```

```txt
表:
夜、地図帳に黒いインクが広がる。
行き先や旅の記録が消えていく。

裏:
プレイヤーは、誰かの旅の記録を取り戻している。
```

この2つは相性が良い。

最終的には、以下の構造にまとめる。

```txt
表: 夜に影を払う
裏: 忘れられた記憶 / 旅の記録 / 未完成の物語を取り戻す
```

## 最重要ルール

### ストーリーは前面に出さない

長い会話、強制イベント、チュートリアル長文は入れない。

物語は以下で見せる。

- アイテム説明
- 実績名
- 実績説明
- 図鑑文
- 秘宝武器の説明
- 条件達成時の短文
- リザルト後の一言
- ステージ名
- ステージ選択画面の変化

### プレイヤーが知らなくても遊べる

裏ストーリーを読まなくても、ゲームは成立する。

ただし、読むと見え方が変わる。

### 断片は必ずつながる

雰囲気だけで終わらせない。

断片を集めると、以下が少しずつ分かる。

```txt
影は単なる敵ではない
忘れられた物には記憶が残っている
黒いインクは記録を消している
プレイヤーは記録を取り戻している
最後に、誰の記録だったかがぼんやり見える
```

## 1. 裏ストーリーの型 10個

### 型1: 忘れ物の夜

表:

```txt
夜になると、忘れられた物から影が出る。
```

裏:

```txt
影は、物に残った記憶が形をなくしたものだった。
```

向いている題材:

```txt
机の上 / おもちゃ箱 / カプセルトイ / 博物館 / 地図帳
```

強み:

- 優しい
- 少し切ない
- 敵を倒す罪悪感を減らせる
- 図鑑文と相性が良い

リスク:

- ふわっとしすぎる
- 感傷的すぎると爽快感とズレる

### 型2: 黒いインクの地図帳

表:

```txt
夜、地図帳に黒いインクが広がる。
行き先や旅の記録が消えていく。
```

裏:

```txt
プレイヤーは、誰かの旅の記録を取り戻している。
```

向いている題材:

```txt
地図帳 / 世界旅行 / 切手 / コンパス / 星座 / 博物館
```

強み:

- ビジュアルが強い
- 国・歴史・旅を安全寄りに使える
- 報酬が作りやすい

リスク:

- 少し文学的
- 地図帳テーマに寄りすぎる

### 型3: 未完成のノート

表:

```txt
夜、机の上のノートから影があふれる。
```

裏:

```txt
ノートには、途中で止まった物語や計画が残っている。
```

向いている題材:

```txt
机 / 文房具 / 地図帳 / 星座ノート / 図鑑
```

強み:

- 個人開発で作りやすい
- 文房具と相性が良い
- 表現が身近

リスク:

- 地味
- 目的が弱くなりやすい

### 型4: カプセルの中の記憶

表:

```txt
条件を満たすと、古いカプセルが開く。
```

裏:

```txt
中身は景品ではなく、誰かが失くした小さな記憶だった。
```

向いている題材:

```txt
カプセルトイ / 景品 / おもちゃ / 星座 / 武器収集
```

強み:

- 条件達成報酬と非常に相性が良い
- 図鑑、レア、秘宝とつながる
- 収集に意味が出る

リスク:

- ガチャ課金っぽく見える
- レアリティ演出をやりすぎると射幸性が強くなる

### 型5: 閉館後の展示室

表:

```txt
閉館後、展示品に黒い影が絡みつく。
```

裏:

```txt
影を払うと、展示品に残された声や記録が戻る。
```

向いている題材:

```txt
博物館 / 歴史 / 国 / 文明 / 図鑑
```

強み:

- 図鑑と相性が非常に良い
- 歴史・文明を戦争なしで扱える

リスク:

- 文化財を壊す表現は危険
- 地味になりやすい

### 型6: 星を隠す影

表:

```txt
夜空から星が消えていく。
```

裏:

```txt
星は誰かの記憶の並びで、影がそのつながりをほどいている。
```

向いている題材:

```txt
星座 / プラネタリウム / 夜の部屋 / 地図帳
```

強み:

- 美しい
- 星座コンプと相性が良い

リスク:

- 抽象的になりやすい
- 敵や武器の具体化が弱い

### 型7: 影は修復待ちのエラー

表:

```txt
古い機械や記録が夜に暴走する。
```

裏:

```txt
影は壊れたものではなく、直してほしい場所を示している。
```

向いている題材:

```txt
時計屋 / 発明工房 / ゲームセンター / からくり / 文房具
```

強み:

- 敵を倒すより修復する感覚にできる
- 武器進化と相性が良い

リスク:

- SF/機械寄りになりすぎる

### 型8: 小さな約束

表:

```txt
夜になると、古い物たちが同じ場所へ戻ろうとする。
```

裏:

```txt
それらは、誰かとの小さな約束をまだ覚えている。
```

向いている題材:

```txt
忘れ物 / 机 / おもちゃ / カプセル / 地図帳
```

強み:

- 情緒がある
- アイテム説明が書きやすい

リスク:

- 感傷的になりすぎる

### 型9: 黒いラベル

表:

```txt
名前の書かれたラベルが黒く塗りつぶされていく。
```

裏:

```txt
名前を失った物は影になり、プレイヤーはそれをもう一度呼び戻す。
```

向いている題材:

```txt
博物館 / 図鑑 / 机 / 地図帳 / カプセル
```

強み:

- 図鑑登録に意味が出る
- 名前を取り戻す構造が強い

リスク:

- 少し暗くなりやすい

### 型10: 朝になる前に

表:

```txt
夜の間だけ影が現れる。朝まで生き残る。
```

裏:

```txt
朝になると影は消えるが、記憶も一緒に消えてしまう。
```

向いている題材:

```txt
すべて
```

強み:

- ヴァンサバの時間制と相性が良い
- 生存に意味が出る

リスク:

- ループの理由を作る必要がある

## 7. 分かる人には分かる見せ方ルール

### ルール1: 直接言わない

NG:

```txt
影は忘れられた記憶です。
```

OK:

```txt
倒したはずの影は、少し温かかった。
```

### ルール2: 同じ言葉を反復する

裏ストーリーのキーワードを散らす。

```txt
名前
忘れ物
記録
黒いインク
朝
戻る
開く
まだ読めない
```

### ルール3: アイテム説明は短くする

1アイテムにつき1〜2文。

長文で説明しない。

### ルール4: 図鑑で少しだけ真相に近づく

アイテム説明は雰囲気。

図鑑文は少し具体的。

秘宝武器文はさらに深い。

### ルール5: 実績名で考察の入口を作る

実績名は、意味がありそうで短いものにする。

例:

```txt
消えない名前
黒インクの外側
影ではなかったもの
まだ読めないページ
朝まで残った光
```

### ルール6: 断片は必ず管理する

雰囲気文を増やしすぎると破綻する。

裏ストーリーの断片は以下に分類する。

```txt
記憶系
地図/旅系
名前/図鑑系
カプセル/景品系
朝/夜系
```

### ルール7: プレイヤーに読ませない

読む必要はない。

読んだ人だけ気づける。

### ルール8: 最後まで明言しすぎない

真相は完全説明しない。

ただし、断片を集めれば以下は分かるようにする。

```txt
影は単なる敵ではない
忘れ物や記録が関係している
プレイヤーは何かを取り戻している
朝になると救えるものと消えるものがある
```

## 8. MVPで必要な最小セット

MVPでは以下だけでよい。

```txt
アイテム説明文: 10個
敵図鑑文: 5個
実績文: 5個
条件達成短文: 3個
秘宝武器説明: 1個
クリア後の一言: 1個
```

入れないもの:

```txt
長編ストーリー
会話イベント
主人公の長い過去
専門用語
強制読書
```

## 9. 現時点の最有力裏ストーリー統合案

```txt
夜になると、忘れられた物から影が出る。
影を払うと、物に残っていた記憶の欠片が戻る。
地図帳には黒いインクが広がり、誰かの旅の記録が消えかけている。
プレイヤーは、朝までに少しずつ記録と名前を取り戻している。
```

ただし、ゲーム内でこの文章をそのまま出さない。

プレイヤーには、以下の断片から気づかせる。

```txt
古い切符
黒インクの小瓶
金のコンパス
星色のカプセル
影のかけら
月明かりのしおり
消えない名前
まだ読めないページ
```

## 10. 次に作るべきもの

次のプリプロ成果物として、以下を作る。

```txt
正式な裏ストーリー軸 1案
表ストーリー 1行
裏キーワード辞書
アイテム名100個
敵名30個
実績名50個
図鑑文ルール
MVPに入れる断片リスト
```

## 結論

Vamp Pon のストーリーは、表に出さない。

でも裏ではつながっている。

プレイヤーが気づかなくても遊べる。

気づいた人は、アイテムや実績の意味が変わる。

この方針は、Vamp Pon の爽快感を壊さず、制作意欲と長続き要素を作れる。

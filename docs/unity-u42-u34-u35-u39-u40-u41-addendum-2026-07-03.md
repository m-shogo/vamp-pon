# Unity U42 U34 / U35 / U39 / U40 / U41 Addendum

## U34 RC checklistへの影響

U42でrelease notes / known issues / QA handoff / remaining blocker registerを追加したため、U34 item 21の「release notes / known issues」はinternal preview向けには改善。ただしRC合格ではない。

## U35 mobile metricsへの影響

mobileMetricsReady=falseのまま。mobile FPS、memory、thermal、GC allocation、draw calls、audio latency、haptic、touch、save persistenceはNOT_MEASURED。U42は測定項目をQA handoffへ明示しただけ。

## U39 audio readinessへの影響

finalSeReady=trueは維持。AudioMixerReady=false、audioReadyForRc=false、audioLatencyMeasured=false、hapticMeasured=falseも維持。device speaker clipping未確認をknown issuesへ明示した。

## U40 asset replacementへの影響

assetReplacementReady=trueは維持。generated final画像のruntime直貼りなし、`docs/design-targets/generated` runtime参照なし、public prototypes reference-only方針をrelease notesへ明記した。

## U41 economy readinessへの影響

economyReadyForRc=true、rewardReadyForRc=true、unlockReadyForRc=true、saveEconomySafe=trueは維持。productionEconomyFinal=false、本番経済未確定、Stage2 placeholder unlock cautionをknown issuesへ明示した。

## rcReady / productionApproved

`rcReady=false`、`productionApproved=false`のまま。U42はapproval passではなく、internal preview / QA handoff用。

## 次のP0

実機でmobile metrics、crash / freeze、touch responsiveness、save persistenceを確認すること。これがU37 final mobile tuningの入力になる。

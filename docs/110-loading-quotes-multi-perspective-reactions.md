# Loading Quotes Multi-Perspective Reactions

Vamp Pon / ヴァンサバ改のロード画面で使う「名言引用」と「キャラ別の受け取り方」を整理する資料。

目的:

```txt
名言は、ひとつの正解を押し付けるために出すのではない。
同じ言葉を読んでも、キャラによって受け取り方が違う。
プレイヤーもまた、自分の価値観で受け取ってよい。
```

この仕様の核はこれ。

```txt
名言 = 世界から来た言葉
キャラ反応 = その子の傷と灯りを通した読み方
プレイヤー = さらに別の読み方を持ってよい
```

---

## 1. 最重要方針

ロード画面では、名言をちゃんと読ませる。
ただし、名言をありがたい正解として置かない。

良い状態:

```txt
この言葉、綺麗だな。
でもユイはそう読むんだ。
ミチルなら違うんだ。
自分はまた違うふうに思う。
```

悪い状態:

```txt
名言アプリみたいに、いい言葉が流れるだけ。
キャラの反応が翻訳や解説になっている。
プレイヤーに答えを押し付けている。
```

---

## 2. 表示パターン

### Pattern A: Quote Only

通常は引用だけを見せる。

```txt
We grow accustomed to the Dark.

— Emily Dickinson
```

これだけで十分な時がある。
引用の余白を壊さない。

### Pattern B: Quote + One Character Reaction

たまにキャラの反応を添える。

```txt
We grow accustomed to the Dark.

— Emily Dickinson

慣れたくなんか、なかったけど。
— アサ
```

### Pattern C: Quote + Selected Character Reaction

選択中のキャラがいる場合、そのキャラに合う反応だけ出す。

```txt
Sunt lacrimae rerum.

— Virgil, Aeneid

忘れ物にも、泣き方があるんだね。
— ユイ
```

### Pattern D: Same Quote, Different Runs

同じ引用でも、別プレイでは別キャラの反応が出てもよい。

```txt
Sunt lacrimae rerum.

— Virgil, Aeneid

泣けないものほど、重いんだ。
— ミチル
```

こうすると、名言が一度で終わらない。
プレイヤーが「同じ言葉なのに別の読み方がある」と感じる。

---

## 3. 読ませる時間

引用を読ませることを優先する。

```txt
Quote Only minimum: 3.2秒
Quote + Reaction minimum: 4.8秒
長い引用 + Reaction: 6.0〜7.5秒
初見引用: スキップ不可 2.4秒
既読引用: スキップ可 1.2秒後
```

反応付きの場合、引用本文・出典・反応の3つを読む必要がある。
短く見えても、最低4.8秒は必要。

---

## 4. キャラ反応の書き方

キャラ反応は、引用の説明ではない。

### OK

```txt
引用を聞いたキャラの心が少し漏れる。
短い。
そのキャラにしか言えない。
違うキャラなら別の意味になる。
```

### NG

```txt
つまりこれは〜という意味だね。
これは〜を表しているんだね。
私もそう思う。
いい言葉だね。
```

解説は禁止。
感想も浅い。
そのキャラの傷・持ち物・灯名・黒耀・朝明に接続する。

---

## 5. 価値観の違いを出すための分類

同じ引用に対して、キャラ反応は価値観別に分ける。

```txt
帰す読み: ユイ / セナ
残る読み: ミチル / シオン / リツ
進む読み: アサ / マヨイ / イオリ
直す読み: トモリ / ヒナタ
名前の読み: シノ / ハク / スズ
距離の読み: クロエ / ナギ / レン
芽吹きの読み: コハル / ネム / ユラ
守る読み: カナメ
```

これにより、同じ名言でも受け取り方が割れる。

## 21. 多様な価値観を出す運用ルール

### 1. 正解反応を作らない

```txt
この引用にはこのキャラの解釈が正解、とはしない。
複数キャラの反応を用意し、ランダム/状況で変える。
```

### 2. ポジティブだけにしない

```txt
同じ引用に、希望の読み・痛みの読み・疑いの読み・距離の読みを混ぜる。
```

例:

```txt
Hope is the thing with feathers.
```

```txt
飛べることと、軽いことは違う。
— クロエ
```

```txt
夢にも、羽があったらいい。
— ネム
```

どちらもあり。
希望を素直に受け取るキャラも、重さとして受け取るキャラもいる。

### 3. キャラの成長で反応を変えてもよい

同じキャラでも、序盤と朝明後で反応が変わると強い。

例: クロエ

```txt
飛べることと、軽いことは違う。
```

朝明後:

```txt
重くても、羽は戻る場所を選べる。
```

### 4. プレイヤーに説明しすぎない

図鑑や開発資料では読みの違いを説明してよい。
ロード画面では説明しない。

ロード画面は:

```txt
引用
出典
キャラの短い反応
```

だけ。

## 22. 朝明ポエムとの関係

ロード反応は一瞬の読み。
朝明ポエムは、そのキャラの心臓。

```txt
ロード反応: 名言をどう受け取ったか。
朝明ポエム: 夜を越えたその子が何を残したか。
```

朝明ポエムはロードで消費しない。

例:

```txt
We grow accustomed to the Dark.
— Emily Dickinson

慣れてしまう前に、灯したい。
— ユイ
```

朝明後:

```txt
帰れない人がいるから、
私はまだ帰れない。

— ユイ
```

この順番なら、ロード反応が朝明ポエムの前振りになる。

## 23. 実装データ案

```ts
export type LoadingQuote = {
  id: string;
  text: string;
  source: string;
  language: 'en' | 'la' | 'it' | 'ja-classic' | 'zh-classic';
  tags: string[];
  commercialRisk: 'safe-candidate' | 'check-before-commercial' | 'do-not-display';
  minVisibleMs: number;
};

export type LoadingQuoteReaction = {
  id: string;
  quoteId: string;
  characterId: string;
  text: string;
  perspective: 'hope' | 'pain' | 'doubt' | 'return' | 'memory' | 'distance' | 'repair' | 'name' | 'protection';
  requiredTags: string[];
  minVisibleMs: number;
};
```

### 選定ロジック

```txt
1. Quoteをタグと表示履歴から選ぶ。
2. 選択キャラがいる場合、そのキャラのReaction候補を探す。
3. requiredTagsがQuote.tagsと合うものだけ候補にする。
4. 25〜30%でReactionを付ける。
5. Reaction付きは最低4.8秒表示。
6. 同じQuoteでも、別キャラ/別価値観のReactionが出ることを許可する。
```

## 25. 最終方針

```txt
名言は良い。
ただし、名言は正解ではない。
キャラごとに読み方が違う。
プレイヤーも違う読み方をしてよい。
```

ロード画面で目指す体験:

```txt
本物の言葉に触れる。
その子の読み方を知る。
でも、自分の受け取り方も残る。
```

これがVamp Ponのロード演出の正本。

# Naming Guidelines

## 目的

この資料は、今後キャラクター・敵・武器・ステージ・UI語を増やすときに、世界観と商用展開の両方で破綻しないようにするための命名ガイドラインです。

重要:

```txt
Vamp Pon は正式販売タイトルではなく、開発コード名・仮名として扱う。
正式タイトル、ストア名、シリーズ名、グッズ名では別名を検討する。
```

---

# 1. 命名の基本方針

## 目指す印象

```txt
暗いが怖すぎない
かわいいが甘すぎない
日本人が口に出しやすい
小さな敵でも「倒す対象」に見える
将来グッズ化しても成立する
検索・商標確認しやすい固有語に寄せる
```

## 避ける印象

```txt
一般ファンタジーすぎる
ホラー・悪魔・血・死に寄りすぎる
既存有名IPの語感に寄りすぎる
設定説明だけで、口に出して気持ちよくない
かわいすぎて敵に見えない
言葉遊びが前に出すぎる
```

## 使い分け

```txt

ムニボロ：大型雑魚。ムニボより重く、強く、こじれた存在。
ヤドリ：深度5相当の中ボス。忘れ物や場所に宿った強い負い影。
夜主：深度10相当の大ボス。地区全体の夜を閉じている名前付きボス。
```

# 3. ムニボ採用理由

`ムニボ` は、かわいさと敵感のバランスを取るための名前。

```txt
ム：こもる、丸い、影っぽい
ニ：小さい、やわらかい、かわいい
ボ：濁音で重い、敵っぽい、倒す対象に見える
```

狙いは以下。

```txt
ポタミほど可愛すぎない
オムボほど硬すぎない
スミルほど設定用語っぽくない
オンブの「背負う」思想は設定側に残す
```

会話・UIで自然に使えることを重視する。

```txt
ムニボを倒して
ムニボが来た
ムニボだらけ
しずくムニボ
くろよムニボ
ムニボのぬいぐるみ
```

# 4. 敵の世界観設定

## 正式分類

```txt
負い影
```

`負い影` は、図鑑・設定資料・説明文で使う正式分類。通常UIでは `ムニボ` / `ムニボロ` / `ヤドリ` / `夜主` を優先する。

## ムニボ

```txt
忘れ物や記憶にくっついた小さな負い影。
体はやわらかく、むにっと形を変える。
こわいものではないが、放っておくと夜を濃くしてしまう。
```

## ムニボロ

```txt
記憶を背負いすぎて、ぼろぼろに大きくなったムニボ。
小型より重く、不穏で、攻撃パターンも強い。
```

## ヤドリ

```txt
忘れ物や場所に宿った強い負い影。
地区の一部を閉じ、夜路の中間地点で灯し手を止めようとする。
倒すというより、鎮めることで道が少し開く。
```

## 夜主

```txt
地区全体の夜を閉じている名前付きの大きな負い影。
その地区の記憶や忘れ物を抱えこみ、朝が戻るのを止めている。
夜主を鎮めると、その地区に少しだけ朝が戻る。
```

# 8. 敵名チェック

敵の総称・個体名は、以下の文章に入れて違和感がないか確認する。

```txt
◯◯を倒して
◯◯が来た
◯◯が増えた
◯◯だらけ
◯◯のぬいぐるみ
◯◯図鑑
◯◯を鎮めた
```

判定基準:

```txt
「倒して」で敵に見える
「鎮めた」で世界観に合う
「ぬいぐるみ」でグッズ化できる
「図鑑」で集めたくなる
子どもでも読める
配信やSNSで言いやすい
```

`ポタミ` のように可愛すぎる名前は、敵ではなくドロップ・素材・味方マスコットに見えるため、敵総称には使わない。

# 11. ステージ命名ルール

ステージ名は毎回固有名を付けず、地区名 + 深度で管理する。

```txt
夜の地図
 └ 地区
    └ 夜路 深度1〜10
       ├ 深度5：ヤドリ
       └ 深度10：夜主
```

例:

```txt
忘れ物通り 深度1
忘れ物通り 深度2
忘れ物通り 深度5 かばんヤドリ
忘れ物通り 深度10 夜主 ネモリ
```

ルール:

```txt
1地区は深度1〜10
深度5にヤドリ
深度10に夜主
ヤドリを鎮めると道が少し開く
夜主を鎮めると夜明けのしるしを得る
夜明けのしるしで次の地区が開く
```

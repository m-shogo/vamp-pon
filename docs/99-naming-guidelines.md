# Naming Guidelines

## 目的

この資料は、今後キャラクター・敵・武器・ステージ・UI語を増やすときに、世界観と商用展開の両方で破綻しないようにするための命名ガイドラインです。

重要:

```txt
Vamp Pon は正式販売タイトルではなく、開発コード名・仮名として扱う。
正式タイトル、ストア名、シリーズ名、グッズ名では別名を検討する。
```

---

# 1. 命名の基本方針

## 目指す印象

```txt
暗いが怖すぎない
かわいいが甘すぎない
日本人が口に出しやすい
小さな敵でも「倒す対象」に見える
将来グッズ化しても成立する
検索・商標確認しやすい固有語に寄せる
```

## 避ける印象

```txt
一般ファンタジーすぎる
ホラー・悪魔・血・死に寄りすぎる
既存有名IPの語感に寄りすぎる
設定説明だけで、口に出して気持ちよくない
かわいすぎて敵に見えない
```

# 2. 敵の総称

## 採用

```txt
小型敵：ムニボ
大型敵：ムニボロ
ボス：家主
正式分類：負い影
```

## 採用理由

`ムニボ` は、かわいさと敵感のバランスを取るための名前。

```txt
ム：こもる、丸い、影っぽい
ニ：小さい、やわらかい、かわいい
ボ：濁音で重い、敵っぽい、倒す対象に見える
```

狙いは以下。

```txt
ポタミほど可愛すぎない
オムボほど硬すぎない
スミルほど設定用語っぽくない
オンブの「背負う」思想は設定側に残す
```

会話・UIで自然に使えることを重視する。

```txt
ムニボを倒して
ムニボが来た
ムニボだらけ
しずくムニボ
くろよムニボ
```

# 3. 敵の世界観設定

## 正式分類

```txt
負い影
```

`負い影` は、図鑑・設定資料・説明文で使う正式分類。UI上では基本的に `ムニボ` を優先する。

## ムニボ

```txt
忘れ物や記憶にくっついた小さな負い影。
体はやわらかく、むにっと形を変える。
こわいものではないが、放っておくと夜を濃くしてしまう。
```

## ムニボロ

```txt
記憶を背負いすぎて、ぼろぼろに大きくなったムニボ。
小型より重く、不穏で、攻撃パターンも強い。
```

## 家主

```txt
ひとつの場所に住みついた大きな負い影。
その地区の記憶や忘れ物を抱えこみ、夜路を閉じている。
倒すというより、鎮めることで朝が少し戻る。
```

# 5. 敵名チェック

敵の総称・個体名は、以下の文章に入れて違和感がないか確認する。

```txt
◯◯を倒して
◯◯が来た
◯◯が増えた
◯◯だらけ
◯◯のぬいぐるみ
◯◯図鑑
```

判定基準:

```txt
「倒して」で敵に見える
「ぬいぐるみ」でグッズ化できる
「図鑑」で集めたくなる
子どもでも読める
配信やSNSで言いやすい
```

`ポタミ` のように可愛すぎる名前は、敵ではなくドロップ・素材・味方マスコットに見えるため、敵総称には使わない。

# 8. ステージ命名ルール

ステージ名は毎回固有名を付けず、地区名 + 深度で管理する。

```txt
夜の地図
 └ 地区
    └ 夜路 深度1〜10
       ├ 深度5：小さな家主
       └ 深度10：家主
```

例:

```txt
忘れ物通り 深度1
忘れ物通り 深度2
忘れ物通り 深度5 小さな家主
忘れ物通り 深度10 家主
```

ルール:

```txt
1地区は深度1〜10
深度5に小さな家主
深度10に家主
家主を鎮めると夜明けのしるしを得る
夜明けのしるしで次の地区が開く
```

# 10. 商用前チェック

正式タイトル、敵総称、主要キャラ名、武器名、グッズ化しそうな名称は、公開前に必ず確認する。

確認対象:

```txt
J-PlatPat
Google
Steam
App Store
Google Play
Nintendo eShop
X
YouTube
TMview
```

確認する表記:

```txt
カタカナ
ひらがな
ローマ字
大文字表記
読み・称呼
近い表記
近い読み
```

`ムニボ` は採用方針だが、正式公開前に `ムニボ / MUNIBO / Munibo` と近似称呼を確認する。

# Naming Guidelines

## 目的

この資料は、今後キャラクター・敵・武器・ステージ・UI語を増やすときに、世界観と商用展開の両方で破綻しないようにするための命名ガイドラインです。

重要:

```txt
Vamp Pon は正式販売タイトルではなく、開発コード名・仮名として扱う。
正式タイトル、ストア名、シリーズ名、グッズ名では別名を検討する。
```

---

# 1. 命名の基本方針

## 目指す印象

```txt
暗いが怖すぎない
かわいいが甘すぎない
日本人が口に出しやすい
小さな敵でも「倒す対象」に見える
将来グッズ化しても成立する
検索・商標確認しやすい固有語に寄せる
```

## 避ける印象

```txt
一般ファンタジーすぎる
ホラー・悪魔・血・死に寄りすぎる
既存有名IPの語感に寄りすぎる
設定説明だけで、口に出して気持ちよくない
かわいすぎて敵に見えない
言葉遊びが前に出すぎる
機能名・開発メモがそのまま見えている
```

# 2. 敵階層の採用セット

## 採用

```txt
小型雑魚：ムニボ
大型雑魚：ムニボロ
中ボス：ヤドリ
大ボス：夜主（やぬし）
正式分類：負い影
```

## 階層

```txt
ムニボ
↓
ムニボロ
↓
ヤドリ
↓
夜主（やぬし）
```

## 使い分け

```txt
ムニボ：小型の雑魚マスコット。量産敵の基本。
ムニボロ：大型雑魚。ムニボより重く、強く、こじれた存在。
ヤドリ：深度5相当の中ボス。忘れ物や場所に宿った強い負い影。
夜主：深度10相当の大ボス。地区全体の夜を閉じている名前付きボス。読みは「やぬし」。
```

実装上の互換注意:

```txt
表示名・図鑑名・世界観文はムニボ/ムニボロ/ヤドリ/夜主へ統一する。
ただし、既存ロジックやデータ判定で使っている旧タグ ombu / ombro は、破壊的変更を避けるため当面は互換タグとして残してよい。
旧タグをユーザー表示に出してはいけない。
```

# 3. ムニボ採用理由

`ムニボ` は、かわいさと敵感のバランスを取るための名前。

```txt
ム：こもる、丸い、影っぽい
ニ：小さい、やわらかい、かわいい
ボ：濁音で重い、敵っぽい、倒す対象に見える
```

会話・UIで自然に使えることを重視する。

```txt
ムニボを倒して
ムニボが来た
ムニボだらけ
しずくムニボ
くろよムニボ
ムニボのぬいぐるみ
```

## ムニボを看板敵にする条件

名前だけで看板敵にはならない。`ムニボ` は、名前・見た目・初遭遇・派生・グッズ化しやすさをセットで育てる。

```txt
1. 1秒で覚えられる黒いしずく型シルエットにする
2. 最初の敵は「しずくムニボ」にする
3. 初遭遇で「黒くてむにっとした、記憶にくっつく小さい敵」と伝える
4. 派生しても、白い小さな目・黒インクの体・足元のにじみを共通化する
5. 倒すだけでなく「ほどける」演出を入れる
6. ムニボロは同系統だが大きく、重く、不穏にする
7. ぬいぐるみ・アクキー・スタンプにできる顔を守る
```

固定イメージ:

```txt
黒インクの丸いしずく体
白い小さな目
口は基本なし、または小さい
体の下に少しだけにじみ
動くと輪郭がむにっと揺れる
倒すと弾けず、ほどける
消える時に記憶片を落とす
```

# 4. 敵名の根本方針

## ムニボは「動き」ではなく「記憶の壊れ方」で名付ける

ムニボはただのスライム型モンスターではない。

```txt
忘れ物に残った気持ち
言えなかった言葉
帰れなかった道
拾われなかったもの
置いていかれた記憶
黒くにじんだ感情
```

これらが、むにっと形になった存在。

そのため名前は、機能・移動・強さを直接書かない。

```txt
悪い：動きをそのまま名前にする / 速く追ってくる
良い：せかしムニボ / 置いていかれた気持ちが急いでいる
```

## 図鑑文ルール

```txt
1文目：その敵が何から生まれたか
2文目：ゲーム上の挙動が少し分かるヒント
```

避ける言い方:

```txt
基本型
弱い型
特殊個体
高速接近
高HP
練習用
横切る動き
```

これらは内部メモ・実装メモには使ってよいが、表示名や図鑑文には使わない。

# 5. 敵の世界観設定

## 正式分類

```txt
負い影
```

`負い影` は、図鑑・設定資料・説明文で使う正式分類。通常UIでは `ムニボ` / `ムニボロ` / `ヤドリ` / `夜主` を優先する。

## ムニボ

```txt
忘れ物や記憶にくっついた小さな負い影。
体はやわらかく、むにっと形を変える。
こわいものではないが、放っておくと夜を濃くしてしまう。
```

## ムニボロ

```txt
記憶を背負いすぎて、ぼろぼろに大きくなったムニボ。
小型より重く、不穏で、攻撃パターンも強い。
```

## ヤドリ

```txt
忘れ物や場所に宿った強い負い影。
地区の一部を閉じ、夜路の中間地点で灯し手を止めようとする。
倒すというより、鎮めることで道が少し開く。
```

## 夜主

```txt
地区全体の夜を閉じている名前付きの大きな負い影。読みは「やぬし」。
その地区の記憶や忘れ物を抱えこみ、朝が戻るのを止めている。
夜主を鎮めると、その地区に少しだけ朝が戻る。
```

# 10. 夜主

夜主は名前付き大ボス。読みは「やぬし」。名前・地区・見た目・攻撃・鎮めた後に戻るものを必ず結びつける。

## 採用

```txt
夜主 ネモリ
夜主 シミネ
夜主 ミオクリ
夜主 ユウモリ
夜主 アサナシ
```

## 夜主の意味

| 表示名 | 地区 | 名前の意味 | 閉じている感情 | モチーフ | 鎮めた後に戻るもの |
|---|---|---|---|---|---|
| 夜主 ネモリ | 忘れ物通り | 眠り / memory / 根守り | 忘れ物に眠った記憶を守りすぎている | 大きなカバン、片方だけの手袋、古い街灯 | 最初の街灯 |
| 夜主 シミネ | にじんだ商店街 | 染み / にじみ / 値 | 買えなかったもの、渡せなかったもの、値段だけ残った約束 | レシート、値札、看板 | 読める看板 |
| 夜主 ミオクリ | 雨音の駅前 | 見送り / 未送り | 言えなかった別れ、出せなかった手紙、乗れなかった電車 | 濡れた切符、改札、手紙 | 駅の発車音 |
| 夜主 ユウモリ | 影灯りの公園 | 夕守り | 帰りたくない夕方、守れなかった約束 | ベンチ、遊具、街灯 | 帰り道の灯り |

# 12. 敵名チェック

敵の総称・個体名は、以下の文章に入れて違和感がないか確認する。

```txt
◯◯を倒して
◯◯が来た
◯◯が増えた
◯◯だらけ
◯◯のぬいぐるみ
◯◯図鑑
◯◯を鎮めた
```

判定基準:

```txt
「倒して」で敵に見える
「鎮めた」で世界観に合う
「ぬいぐるみ」でグッズ化できる
「図鑑」で集めたくなる
子どもでも読める
配信やSNSで言いやすい
名前だけで少し意味がにじむ
```

可愛すぎる名前は、敵ではなくドロップ・素材・味方マスコットに見えるため、敵総称には使わない。

# 15. ステージ命名ルール

ステージ名は毎回固有名を付けず、地区名 + 深度で管理する。

```txt
夜の地図
 └ 地区
    └ 夜路 深度1〜10
       ├ 深度5：ヤドリ
       └ 深度10：夜主
```

例:

```txt
忘れ物通り 深度1
忘れ物通り 深度2
忘れ物通り 深度5 かばんヤドリ
忘れ物通り 深度10 夜主 ネモリ
```

ルール:

```txt
1地区は深度1〜10
深度5にヤドリ
深度10に夜主
ヤドリを鎮めると道が少し開く
夜主を鎮めると夜明けのしるしを得る
夜明けのしるしで次の地区が開く
```

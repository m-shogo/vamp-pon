# 164. Fail-Forward Reward Catalog

This catalog lists many rewards that can be granted without requiring stage clear.

Use these as candidates, not all at once.

## Currency rewards

| Reward | Trigger | Use |
| --- | --- | --- |
| memory dust | any run | basic permanent upgrades |
| dry ink flakes | defeat ink enemies | shadow reading unlocks |
| warm ash | use lantern attacks | lantern care upgrades |
| page fiber | survive minutes | mapbook upgrades |
| glass speck | collect vessel item | vessel repair upgrades |

## Permanent upgrade candidates

### Lantern care

- polished glass: lantern light radius slightly up
- new wick: first flame damage slightly up
- warm oil: early-run flame cooldown slightly down
- soot mark reading: first hit on ink enemy gives more memory dust
- handle cloth: tiny damage reduction when lantern is bright
- ember memory: one small fire pulse after collecting enough fragments

### Mapbook

- folded corner: show one next-goal hint on result screen
- penciled route: stage starts with one faint direction mark
- dry margin: keep one item hint after failed run
- old bookmark: one reroll token per run
- route thread: first pickup after 1 minute is pulled slightly closer

### Memory handling

- labeled pouch: memory dust gain slightly up
- clear jar: item trace discovery slightly up
- repaired clasp: less fragment loss on failure
- soft wrap: pickups remain visible slightly longer
- owner tag: first unknown item gets a hint sooner

### Shadow reading

- ink sample card: bestiary entry after seeing enemy several times
- dried brush: small bonus against fully studied enemy family
- shadow footprint: enemy movement hint in bestiary
- wrong-name slip: unlock one lore line after repeated defeat
- black-page rubbing: reveal one enemy family relation clue

### Retry comfort

- spare bookmark: one revive item chance in early stage
- second match: one extra tiny recovery after game over threshold
- guiding thread: result screen suggests one next build goal
- pocket charm: first minute pickup range slightly up
- quiet breath: start with tiny safety grace

## Unlock rewards

| Unlock | Requirement type | Notes |
| --- | --- | --- |
| weapon hint | use related item several times | not full unlock yet |
| weapon unlock | survive or collect traces | does not require clear |
| evolution hint | make partial combo | show clue, not solution |
| character trace | find vessel clue | not playable yet |
| glossary page | see enemy or item enough | failure still counts |
| stage clue | reach time threshold | next route hinted |

## Collection rewards

- object album entry
- enemy family sketch
- vessel fragment page
- relationship thread note
- black ink misreading note
- light lineage mark
- unused blank card entry
- item owner clue

## Result stamps

Use stamps to make failed runs feel meaningful.

Examples:

- first shadow read
- first vessel trace
- new enemy seen
- new item touched
- longest night
- almost morning
- most fragments carried
- new wrong reading found
- first relation thread
- new light family mark

## Near-clear rewards

If the player almost clears, give extra meaning.

- near-morning crease
- stronger result hint
- stage-specific memory dust bonus
- one locked reward silhouette
- next-time starting clue
- emotional result line

## Bad reward patterns

Avoid:

- pure random gacha feeling
- dozens of currencies
- upgrades that make early game trivial too quickly
- rewards that only say numbers without story names
- all rewards locked behind clear

## Best initial set

Start with 8 visible rewards:

1. memory dust
2. polished glass
3. new wick
4. folded corner
5. ink sample card
6. labeled pouch
7. spare bookmark
8. object album entry

This is enough to make failure feel useful without bloating the MVP.

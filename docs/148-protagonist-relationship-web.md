# 148. Protagonist Relationship Web

Yui is the emotional center of the ensemble.

## Rules

- Every major character has a link to Yui.
- Every major character has met Yui at least once.
- The meeting can be small, forgotten, indirect, or item-based.
- Yui links memories, but she does not explain every mystery.
- Each character also needs a relation to at least one non-Yui character.
- Each character keeps one blank space for later story.

## Link types

| Type | Meaning |
| --- | --- |
| direct | both sides remember |
| one-sided | only one side remembers |
| indirect | connected through another person |
| item | connected through the same object |
| rumor | connected through a story |
| hidden | revealed later |

## Yui's role

Yui is:

- lantern holder
- first visible light
- connector of separated memories
- person who once crossed paths with everyone

Yui is not:

- the only important character
- automatic leader of everyone
- answer to every mystery

## Required per character

- light vessel
- first action
- missing memory clue
- link to Yui
- link to another character
- one unresolved blank

## Good blanks

- why Yui forgot the meeting
- who gave the vessel first
- whether the line is direct or symbolic
- whether the memory is accurate

## Bad blanks

- no story purpose
- no relation to others
- mystery that never changes design or gameplay

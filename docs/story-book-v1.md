# 1. ヨルノシルベはどんな物語か

## CURRENT / USER DIRECTION

暗い夜を舞台にしている。

でも、救いのない話にはしない。

プレイヤーはまずヴァンサバ系のゲームとして:

- 敵をほどく
- 記憶片を拾う
- 強くなる
- 仲間と戦う
- 朝まで残る

ことを楽しむ。

そのうちに:

> 「この敵、どうしてこの小物だけ壊さないんだろう？」  
> 「この二人だけ呼び方が違う」  
> 「星獣が先に知り合っている？」

と、世界や人物の裏が見えてくる。

物語はGameplayの上に乗る。
Gameplayを止めて物語を読ませ続ける作品にはしない。

# 2. 最後に残したい感情

## USER DIRECTION

正史は**Happy End**。

途中は苦しくていい。

- 誰かがいなくなるように見える
- 記憶を失う
- 一時的に別れる
- 誤解する
- 喧嘩する
- 黒耀化で危うくなる
- 守るために距離を取る

でも最後には:

- 生きている
- 帰れる
- 目覚める
- 再会できる
- 普通の日常へ戻れる
- 以前とは少し違う関係になっている

という救いを置く。

### 一番避けたいこと

> 「泣かせるために死なせる」

Permanent deathは物語の主な感動装置にしない。

# 3. 泣きの作り方

## USER DIRECTION

CLANNADのように、**普通の日常を好きになった後だから泣ける**構造がほしい。

Little Busters!のように、**現実とは少し違う場所だから成立する別れと救い**も相性がよい。

作品内容そのものはコピーしない。

## 先に積むもの

- 毎朝の挨拶
- 誰がどこへ座るか
- 名前の呼び方
- 好きな食べ物
- 寝坊
- 雨の日
- いつも直してくれる物
- いつも書いてくれる名前
- 星獣の癖
- 喧嘩の後でも無意識にしてしまう世話

## 終盤で返せるもの

序盤:

> 「アサちゃん」

長い時間を過ごした後:

> 「アサ」

のように、台詞自体は小さくていい。

プレイヤーが、その数文字の間に何時間分もの関係を見るのが理想。

# 5. 物語の二つの謎

## USER DIRECTION — とても重要

ヨルノシルベには、二種類の謎がある。

## A. Main Mystery — 世界の謎

作品全体を引っ張る大きな問い。

例:

- この夜は何なのか
- なぜ何度も夜へ入れるのか
- 黒インクとは何か
- なぜ朝になると確定するのか
- 星獣は何者なのか
- 誰がこの仕組みを作ったのか
- 現実側と夜側はどうつながるのか

## B. Character Mystery — 人物の謎

一人一人にある問い。

例:

- ユイとトモリはなぜ同じ獅子座なのか
- クロオリはなぜ記憶を開かず折るのか
- アサはなぜ名前に強くこだわるのか
- 誰と誰が昔からつながっていたのか
- この人は何を忘れているのか

### 大切な構造

```txt
Main Mystery ≠ Character Mystery
```

全部の人物秘密が世界の真相の鍵である必要はない。

でも一部だけ交差すると強い。

たとえば:

> ユイとトモリの星獣が同系統

という人物の謎が、後でランタンや夜の仕組みの一部にもつながる、など。

まで見える。

# 8. Game Over

## CURRENT DIRECTION

Game Overは死亡ではない。

一番分かりやすい感覚:

> **「この読み方では、朝まで残れなかった。」**

Retryは蘇生ではない。

> **同じ未確定の夜を、別のbuild、別のSupport、別の順序でもう一度試す。**

Gameplay上は素早い普通のRetryでよい。

設定を読む人には「なぜ周回できるか」の説明になる。

# 9. HIGH-VALUE CANDIDATE — 黒インクと「間違った意味」

これは昔の設計に非常に強く残っていた仕組み。
現在もヨルノシルベとの整合が高いので、忘れないようにする。

**ただし、Main Mysteryの最終正解としてはまだLOCKしない。**

## Candidate core

> **悲しい出来事は消えない。  
> ただ、その出来事についた「間違った意味」が黒インクによって固定される。**

例:

出来事:

> 名前が書かれていない。

本人が受け取った意味:

> 「私は忘れられた。」

黒インク:

> その「忘れられた」という意味だけを変わらないものとして固める。

ユイたち:

> 過去そのものを書き換えるのではなく、唯一の意味として固定された誤解をほどく。

## この候補が強い理由

- Happy Endでも悲しい出来事をなかったことにしなくてよい
- 黒インクを単純悪にしなくてよい
- Shadow側の思想にも意味が出る
- 人物の傷と世界のシステムが同じルールでつながる
- Gameplayに裏の意味を持たせられる

# 10. Gameplayそのものが後から伏線になる

## HIGH-VALUE CANDIDATE

「間違った意味」Engineを採用した場合、普通に遊んでいたmechanicが後から物語になる。

| Gameplay | プレイ中の意味 | 後から読める意味の候補 |
| --- | --- | --- |
| 敵を倒す / ほどく | 敵処理 | 固定された意味を剥がす |
| 記憶片 | EXP | 固定から剥がれた意味片 |
| Level Up | run内強化 | その夜に扱える接続 / 読み方が増える |
| Boss | 強敵 | その場所で一番強く固定されたもの |
| 朝 | clear | その夜で得た何かが確定する |
| permanent unlock | meta progression | 次の夜にも残る理解 / 準備 |
| Retry | replay | 未確定の夜を別の方法で読む |

プレイヤーは知らなくても遊べる。

後からreportを読んだ人だけ:

> 「ずっと経験値だと思って拾っていた物、そういう意味だったの？」

となる。

これはヨルノシルベでかなり大事にしたい気持ちよさ。

# 11. Shadow / Rivalの物語的位置

## CURRENT DIRECTION

Shadowは単純な悪役集団にしない。

ユイ側:

> 取り戻す / 返す / 開く

Shadow側:

> 隠す / 閉じる / ぼかす / 空白を残す

## 問い

> **全部思い出すことは、本当にいつでも正しいのか？**

人によっては:

- 今はまだ開けない方がいい
- 読まれない方が守れる
- 名前を出さない方が安全
- 空白を残した方が未来がある

こともある。

ユイがShadowを倒して「全部間違い」とするのではなく、互いの守り方を知ることが成長になる。

# 12. 黒耀化と人物ドラマ

## CURRENT DIRECTION

黒耀化は悪人格ではない。

その人の:

- 長所
- 願い
- 優しさ
- 守り方

が**行き過ぎた状態**。

例:

ユイ:

> 誰も忘れたくない  
> ↓  
> 全部自分が戻さなければならない

カナメ:

> 仲間を守りたい  
> ↓  
> 自分だけが全部受ければいい

だから黒耀化から戻ることは:

> 「優しさを捨てる」

ではなく:

> **「一人で全部やらなくても、その長所を失わない」と知ること。**

黒耀化の詳細はCharacter側の物語でも使う。

# 22. 2を遊んだ後に1が変わる

## USER IDEA / HIGH-VALUE DIRECTION

続編の良い伏線は:

> 1で謎だった物が2で初めて出る

だけでは弱い。

もっと強いのは:

> **1では普通だと思っていた物の意味が、2を遊んだあと変わる。**

例えば:

1初見:

> 古い封筒がある。

1クリア後:

> 誰かへ届かなかった手紙らしい。

2を遊んだ後:

> 「届かなかった」のではなく「届けなかった」ことで誰かを守っていた。

という三段階。

# 29. 一文で思い出す

> **夜の中で仲間と強くなり、普通の時間を好きになり、人の謎と世界の謎へ少しずつ触れる。悲しいことはあっても最後はみんな朝へ帰る。そして、朝の世界にほんの一つだけ「まだ知らない夜」が残っている。**

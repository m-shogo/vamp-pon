# 1. どんな物語か

## DECIDED

ヨルノシルベは**朝の来ない夢の夜**。

Playerはまずゲームとして:

- 敵をほどく
- 記憶片を拾う
- 強くなる
- buildを作る
- 仲間と戦う
- 事件の深部へ進む
- Result / Wakingへ到達する

ことを楽しむ。

その途中で:

> 「この敵、どうしてこの小物だけ壊さない？」
> 「この二人、同じ物の呼び方が違う」
> 「その星座、現代にはないはずでは？」
> 「このUI、知っている形と違う」

と世界 / 人物 / 年代の裏が見えてくる。

Gameplayを止めて設定説明を読ませ続ける作品にはしない。

# 2. Dream / Waking

## DECIDED

- ヨルノシルベは夢世界。
- 共有夢に近い。
- 最終mechanism / 起源はOpen。
- **Dreamに朝は来ない。**
- 帰還はWaking。

### 通常Waking

失われやすい:

- 名前
- 顔
- 年代
- 正確な会話
- Dreamの細部

残り得る:

- 技能
- 身体感覚
- 感情
- 価値観
- 誰かに教わった方法
- 以前なら選べなかった行動

> 誰に教わったか覚えていない。でも手が覚えている。

### 大事件解決パート

大きな試練を越えた人物は、Dreamでの記憶を取り戻した状態で目覚める方向。

違う時代 / 動物 / Android / Robot / 朔夜座 / 相手陣営との経験を理解したままRealityへ戻り、自分の時代の問題へ向き合える。

# 3. Happy End

## DECIDED

正史はHappy End。

途中は苦しくてよい。

- 忘れる
- 離れる
- 誤解する
- 喧嘩する
- 黒耀化する
- 現実の事件が重い
- 相手の立場を後から知る

それでも最後は:

- 生きる
- 目覚める
- Realityへ戻る
- 関係から得た変化が残る
- 以前は選べなかった選択をする
- 最悪の結末を変える

方向。

「泣かせるために人気Characterを殺す」を主軸にしない。

# 4. 泣きの作り方

## USER DIRECTION

普通の日常を好きになった後だから泣ける構造を重視する。

Little Busters!等から**日常の蓄積が最後の力になる感情構造**は参考にできるが、一事故 / 死後世界 / 全員同じ悲劇等はコピーしない。

## 先に積む

- 会うたびの挨拶
- 誰がどこへ座るか
- 呼び方
- 好きな食べ物
- 寝坊
- 雨
- 直してくれる物
- 書いてくれる名前
- 星獣の癖
- 犬 / 猫の癖
- 知らない年代の食文化
- 喧嘩後でも無意識にする世話

## 後で返す

序盤:
> 「アサちゃん」

関係が積み上がった後:
> 「アサ」

のような小ささでよい。

# 8. 月相 / 朔夜

## DECIDED

月相 = **事件深度**。

`満月系 → 欠ける → 半月系 → さらに欠ける → 朔`

は基本イメージであり固定5Stageではない。

- 半月開始
- 一度戻る
- 異常な欠け方
- 未来だけ別挙動

も可能。

朔では月が完全に消える。

星は残る。

ランタン / 焚き火 / 街灯 / Character light / 星 / 星獣が強く見える。

> 月が照らしてくれないなら、自分たちの灯りで進む。

### Important

朔 = **固定「世代ラスボス」が立つslotではない**。

戦闘Boss / 制度 / 複数人物 / 朔夜座 / 社会選択など、その大事件に合う最深部を作る。

# 10. Game Over / Retry

## DECIDED

Game Over = Reality deathではない。

Retry = resurrectionではない。

感覚:

> このrun / build / 解釈では、Dreamのこの局面を越えられなかった。

Retry:

> 別build / Support / 順序でもう一度挑む。

旧「朝まで残れなかった」はStory ruleとして使用しない。

---

# 11. HIGH-VALUE CANDIDATE — 黒インクと「間違った意味」

最終Truthとしては未LOCKだが高価値。

> 悲しい出来事は消えない。  
> ただ、その出来事についた「間違った意味」が固定される。

Characterは過去を消すのではなく、唯一の答えとして固まった意味をほどく。

利点:

- Happy Endでも悲しい出来事を無かったことにしない
- 黒インクを単純悪にしない
- 黒耀化 / 社会事件と同型化できる
- Gameplayへ裏の意味を返せる


# 17. Android / Robot

## DECIDED DIRECTION

未来では人間側 / Android側双方にDream参加者がいる。

Dreamでは相手のReality陣営を知らず友達になれる。

後でRealityでは敵対側と判明できる。

Androidの成長を:

> 人間になる

にしない。

> Androidのまま、個人として他者を見る / 見られる。

を重視。

好感度は他Characterより上がりにくい方向。

初期:
- 相互扶助
- 義務
- 社会交換
- 効率
- 契約

として好意を解釈する。

信頼後:

> 「あの時も、義務ではなかったのですか？」

と過去を再評価できる。

### Naming

- シオン不採用
- イヴ・ノイン不採用
- 日本語人名に聞こえる自然なカタカナ
- 後からalphabet / acronym / system designationにも読める
- final nameはOpen

### Version

Lambda等は個人名ではなく旧version / design generation方向。

同一初期dataでも経験分岐で別人格になる。

### Philosophy

- 同じmemoryなら同じ人か
- copied bodyは同一人物か
- 分岐した瞬間に別人か
- body / memory / experienceのどこに「私」があるか
- 人間の魂も証明できないのにAndroidだけ証明を要求するのか

星獣を魂proof deviceにしない。

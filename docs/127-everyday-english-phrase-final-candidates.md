# Everyday English Phrase Final Candidates

Vamp Pon / ヴァンサバ改のロード知識システムに最初に入れる、Everyday English phrase 8件の確定候補。

この資料は、`docs/126-loading-knowledge-consistency-guardrails.md` の方針に従い、1カテゴリだけを少数精鋭で詰める。

---

## 1. このカテゴリの役割

Everyday English phrase は、重い名言や宗教/古典の間に入れる「生活の知識」と「軽いユーモア」。

```txt
英語圏では自然な日常表現。
日本ユーザーには、意味やニュアンスを知る楽しさがある。
キャラ返信で、やさしさ・ズレ・皮肉・価値観を見せられる。
```

ロードでの目的:

```txt
重くしすぎない。
英語の短い言葉を読む気持ちよさを出す。
意味を知ると少し得した気持ちにする。
キャラ返信でVamp Ponの世界に戻す。
```

# 8. 破綻チェック

この8件は、以下を満たす。

```txt
□ 原文が短い
□ 英語圏の日常表現として自然
□ 日本語で意味が分かる
□ キャラ返信が説明ではない
□ 重い古典の間に挟める
□ 文字演出に乗せやすい
□ 390x844で読める
```

注意:

```txt
No worries / Hang in there / Knock on wood は状況を選ぶ。
初回ロードでは Bless you / Take care / Good night / See you / Fingers crossed を優先する。
```

---

# 9. 最終方針

```txt
Everyday English phrase は、Vamp Ponのロードに生活感と知識欲を足す安全な入口。
```

最初に入れるなら、次の5件から始める。

```txt
Bless you.
Take care.
Good night.
See you.
Fingers crossed.
```

残り3件は、状況演出ができてから入れる。

```txt
No worries.
Hang in there.
Knock on wood.
```

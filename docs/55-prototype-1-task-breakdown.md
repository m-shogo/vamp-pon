# Prototype 1 タスクチケット分解

## 目的

Prototype 1 は、完成版ではない。

目的は1つ。

```txt
スマホ縦持ちで、移動・自動攻撃・欠片回収・初レベルアップが気持ちいいか確認する。
```

この資料は、Prototype 1 を実装する時のタスクチケットとして使う。

# P1-03: 仮想スティック移動

## 目的

スマホで移動できるようにする。

## 作業

```txt
画面左下に仮想スティック
pointerdown/pointermove/pointerup
方向だけ入力方式
WASD/矢印も開発用に対応
```

## 完了条件

```txt
スマホで指を置くと移動できる
指を離すと止まる

```

## 合格基準

```txt

移動開始が遅くない
自キャラが指で隠れにくい
```

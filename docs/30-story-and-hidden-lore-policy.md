# ストーリー性・裏ストーリー方針

## 目的

三国志テーマはやめる。

次の検討軸として、題材そのものよりも、**表ストーリーと裏ストーリー**を持たせる方向を評価する。

## 結論

Vamp Pon には、強い長編ストーリーよりも、以下が合う。

```txt
表ストーリー: すぐ分かる目的
裏ストーリー: 遊ぶほど断片が見えてくる謎
```

ヴァンサバ系のゲームは、プレイ中に長い会話を読むゲームではない。

そのため、ストーリーは軽く、裏設定は深くする。

## なぜ良いか

### 1. 制作意欲につながる

題材だけで乗れない場合でも、裏ストーリーがあると作る理由ができる。

例:

```txt
なぜ影が出るのか
なぜアイテムを集めるのか
なぜ夜なのか
なぜ主人公だけが戦えるのか
最後に何が分かるのか
```

### 2. 長続きと相性が良い

条件達成報酬、図鑑、秘宝武器、永続強化に物語断片を付けられる。

```txt
新武器解放 = 物語の手がかり
図鑑登録 = 裏設定が1行読める
秘宝武器獲得 = 過去の真相が少し分かる
ステージクリア = 日記のページが戻る
```

### 3. 題材選びの負担を減らせる

完全な世界観を0から作らなくても、身近な舞台に謎を足せる。

```txt
夜の部屋
机の上
地図帳
博物館
カプセルトイ
おもちゃ箱
```

これらに裏ストーリーを乗せるだけで、題材が強くなる。

## リスク

### 1. ストーリーを入れすぎるとテンポが死ぬ

ヴァンサバ系で長い会話、長いチュートリアル、重い設定説明は邪魔。

避ける。

```txt
プレイ前に長文説明
ステージ中に会話停止
強制イベント連発
用語だらけの世界設定
```

### 2. 裏ストーリーが暗すぎると爽快感とズレる

重すぎる家族悲劇、死、虐待、戦争、病気などを軸にすると、軽く遊べるゲームと噛み合いにくい。

### 3. 謎だけ作って回収しないと薄い

裏ストーリーは、断片と回収の設計が必要。

謎を匂わせるだけで終わると、安っぽくなる。

## 安全なストーリー設計

### 表ストーリー

一言で分かる目的にする。

例:

```txt
夜になると影があふれる。朝まで生き残る。
散らばった星の欠片を集める。
閉館後の博物館で展示の影を払う。
壊れたカプセルの中の記憶を集める。
机の上に広がった黒いインクを止める。
```

### 裏ストーリー

遊ぶほど断片が増える。

例:

```txt
影は敵ではなく、忘れられたものだった
集めているアイテムは誰かの記憶だった
武器は昔の持ち主の思い出だった
主人公は夢の中で何かを修復している
最後に部屋/地図帳/博物館の本当の意味が分かる
```

## 使える構造

### 構造A: 失われた記憶を集める

```txt
表: 影を倒してアイテムを集める
裏: アイテムは誰かの記憶の欠片
```

良い点:

- 図鑑/報酬/秘宝と相性が良い
- 題材を選ばない
- 感情を乗せやすい

リスク:

- 暗くしすぎると重い
- 記憶の持ち主をどう扱うか決める必要

### 構造B: 夜だけ動く世界

```txt
表: 夜になると物が動き出す
裏: 動く理由は、ある約束/未完成の願い/忘れ物
```

良い点:

- おもちゃ、机、博物館、カプセルと相性が良い
- かわいい/不思議/少し怖いを両立できる

リスク:

- 既視感がある
- 有名映画/玩具世界に寄せない注意

### 構造C: 図鑑が真相になる

```txt
表: 敵やアイテムを図鑑に登録する
裏: 図鑑の説明文が少しずつ真相を示す
```

良い点:

- ヴァンサバ系と相性が良い
- プレイを止めずに物語を読ませられる
- 収集が楽しくなる

リスク:

- 図鑑文の質が低いと逆効果
- 情報を出す順番を管理する必要

### 構造D: 条件達成で日記が戻る

```txt
表: 条件達成で報酬を得る
裏: 日記/手紙/展示札/地図のメモが復元される
```

良い点:

- 三国無双3の最強武器条件の快感とつながる
- 条件達成に意味が出る

リスク:

- 条件が理不尽だとストーリー回収が苦痛になる

## 題材との相性

### 夜の地図帳

```txt
表: 地図帳に広がる黒いインクを止める
裏: 地図帳は誰かの旅の記録だった
報酬: 切手、旅バッジ、古い切符、コンパス
裏断片: 旅の日記、消えた目的地、戻れなかった手紙
```

相性: A

### 閉館後の博物館

```txt
表: 展示に絡む影を払う
裏: 展示品が忘れられた声を持っている
報酬: 展示札、古代の欠片、学芸員バッジ
裏断片: 展示解説が変化する、空白の展示室の理由が分かる
```

相性: A

### カプセルトイ

```txt
表: 条件達成でカプセルを開ける
裏: カプセル景品は誰かの思い出/失くした小物だった
報酬: 景品、バッジ、ミニフィギュア
裏断片: 景品説明文が少しずつ繋がる
```

相性: A-

### 夜の机の上

```txt
表: 机に広がる影を払う
裏: 机の持ち主が途中でやめた何かを完成させる
報酬: 文房具、しおり、メモ、写真
裏断片: ノートの断片、消し跡、古い予定表
```

相性: A-

### 星座

```txt
表: 星を食べる影を止める
裏: 星座は失われた記憶の並びだった
報酬: 星座カプセル、星くず、流星バッジ
裏断片: 星座が完成するたび、短い記憶が戻る
```

相性: B+ / 混ぜるとA-

## 裏ストーリー候補

### 案1: 忘れ物の夜

夜になると、忘れられた物から影が出る。

主人公はそれらを倒すのではなく、元の場所へ戻す。

報酬は、忘れ物が持っていた記憶。

向いている題材:

```txt
机の上
カプセルトイ
博物館
地図帳
おもちゃ箱
```

### 案2: 黒いインクの地図帳

夜、地図帳に黒いインクが広がり、行き先や記録が消えていく。

プレイヤーは影を払って、旅の記録を取り戻す。

条件達成で、切手・スタンプ・古い切符・コンパスが戻る。

向いている題材:

```txt
夜の地図帳
世界旅行
博物館
星座
```

### 案3: 閉館後の小さな博物館

閉館後、展示品に黒い影が絡み、説明文が消えていく。

展示を壊すのではなく、影を払って展示の声を戻す。

報酬は展示札、欠片、記録。

向いている題材:

```txt
歴史
国
文明
図鑑
収集
```

### 案4: カプセルの中の記憶

条件を満たすと、古いカプセルが開く。

中身はただの景品に見えるが、説明文を読むと誰かの記憶につながっている。

向いている題材:

```txt
カプセルトイ
景品
おもちゃ
星座
武器収集
```

### 案5: 未完成のノート

机の上に残されたノートが、夜になると影に飲まれる。

プレイヤーはページを取り戻し、途中で止まった物語/地図/図鑑を完成させる。

向いている題材:

```txt
夜の机
文房具
地図帳
星座ノート
図鑑
```

## Vamp Ponでの推奨

ストーリーを前面に出しすぎない。

プレイ中は爽快感優先。

物語は以下で出す。

```txt
リザルト画面の1行
図鑑の短文
秘宝武器の説明文
条件達成時の短い文
ステージ選択画面の変化
```

## MVPで入れるなら

最小で良い。

```txt
表ストーリー: 夜に影が出る。朝まで生き残る。
裏ストーリー: アイテム説明文が少しずつ繋がる。
```

MVP要素:

```txt
図鑑説明文 10個
報酬アイテム説明 10個
条件達成時の短文 3個
クリア後に読める日記 1ページ
```

入れないもの:

```txt
長い会話イベント
キャラ同士の長文会話
ステージ中の強制停止イベント
複雑な専門用語
重すぎる悲劇
```

## 現時点の結論

ストーリー性は入れる価値がある。

ただし、長編RPGのようなストーリーではなく、**裏ストーリー型**にする。

一番相性が良い方向は、

```txt
表: 夜に影を払う
裏: 忘れられた記憶/物語/旅の記録を取り戻す
```

候補として強いのは、

```txt
夜の地図帳
閉館後の博物館
カプセルの中の記憶
未完成のノート
```

この方向なら、題材そのものに乗りきれなくても、裏ストーリーで制作意欲を作れる。

# 175. Seven Misreadings Enemy Canon

This document adopts the enemy-side structure.

Do not use the seven deadly sins directly.
Use them as inspiration, then translate them into Vamp Pon's reading language.

## Core rule

Enemy-side power is based on `misreading`.

Black ink enemies are not simple evil.
They are wrong readings that became fixed.

## The seven misreadings

| Misreading | Inspired by | Meaning | Enemy behavior | Released clue |
| --- | --- | --- | --- | --- |
| 決めつけ | pride | fixes one meaning as absolute | locks item meanings | maybe / not always clue |
| すり替え | envy | replaces one owner with another | swaps item-owner relation | true owner hint |
| 焼き潰し | wrath | destroys unreadable memory | burns fragments / pages | ash clue |
| 閉じ込め | sloth | refuses to open a page | seals boxes / doors / routes | key or hinge clue |
| 集めすぎ | greed | hoards fragments without returning | steals drops / grows by pickups | missing-owner clue |
| 飲み込み | gluttony | swallows objects, names, paths | covers floor/UI/items in ink | swallowed-object clue |
| 執着 | lust, translated as attachment | cannot let a feeling go | tethers memories / repeats patterns | release-thread clue |

## Why this works

Ally side:

```txt
shirushi = correct way to read memory
```

Enemy side:

```txt
misreading = wrong way to fix memory
```

This gives every boss a story reason and a gameplay behavior.

## Boss naming

Use `黒読み` as the in-world enemy category.

Examples:

- 黒読み・決めつけ
- 黒読み・すり替え
- 黒読み・焼き潰し
- 黒読み・閉じ込め
- 黒読み・集めすぎ
- 黒読み・飲み込み
- 黒読み・執着

## Season 1 boundary

Do not use all seven as full bosses in P1.

Allowed in Season 1:

- one main misreading as stage boss direction
- two or three as enemy behavior traces
- names hidden in glossary or item hints
- no full seven-boss structure yet

Recommended P1 strongest candidates:

1. 集めすぎ, because it mirrors player collection
2. 決めつけ, because it teaches that item meaning can reverse
3. 閉じ込め, because it connects with boxes/pages/doors

## Wrong evolution connection

A character's wrong evolution should lean toward one or two misreadings.

Examples:

- Yui wrong evolution: 焼き潰し / 集めすぎ
- Asa wrong evolution: 決めつけ / すり替え
- Nagi wrong evolution: 閉じ込め
- Michiru wrong evolution: すり替え / 決めつけ
- Tomori wrong evolution: 焼き潰し / 執着

## Design warning

Do not draw these as generic demon sins.

Draw them as object-memory failures:

- a label that refuses correction
- a ticket that points to the wrong owner
- a burned page that still shows a trace
- a sealed box with breathing ink
- a heap of fragments with no return path
- a floor of swallowed little objects
- a thread that will not let go

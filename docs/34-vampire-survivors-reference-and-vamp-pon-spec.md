# Vampire Survivors 参照仕様と Vamp Pon 仕様整理

## 目的

Vamp Pon は、ゲーム体験の土台を Vampire Survivors ライクに置く。

ただし、コード・素材・固有名・UI見た目はコピーしない。

このドキュメントでは、Vampire Survivors で分かっている中核仕様を分解し、Vamp Pon に採用する仕様・変更する仕様・後回しにする仕様を整理する。

## 参照する考え方

Vampire Survivors は、以下のような構造を持つ。

```txt
キャラを選ぶ
ステージに入る
キャラは自動攻撃する
プレイヤーは移動中心
敵が大量に来る
敵を倒すと経験値ジェムが落ちる
経験値を拾ってレベルアップする
レベルアップで武器/パッシブを選ぶ
武器を育てる
条件を満たして宝箱で進化する
制限時間まで生き残る
ゴールドや実績で永続強化/アンロックする
```

Vamp Pon では、この骨格を採用する。

## Vampire Survivors 側の中核仕様メモ

### 1. キャラクター選択

- 複数キャラクターがいる
- キャラごとに初期武器やボーナスが違う
- キャラ解放が長期目標になる

### 2. 自動攻撃

- プレイヤーは主に移動を操作する
- 武器は自動で攻撃する
- 照準や発射操作を細かく求めない

### 3. 大量の敵ウェーブ

- 敵は時間経過で増える
- 敵の種類や密度が変化する
- 基本的には接触ダメージ

### 4. 経験値ジェム

- 敵を倒すと経験値ジェムが落ちる
- 拾うと経験値が溜まる
- 一定量でレベルアップ

### 5. レベルアップ選択

- レベルアップ時に武器/パッシブ候補が提示される
- 基本は3択または4択
- 選択でビルドが変わる

### 6. 武器とパッシブ

- 武器枠とパッシブ枠がある
- 代表的には武器6枠、パッシブ6枠
- 各武器はレベルアップで性能が上がる

### 7. 宝箱

- 強敵やボスが宝箱を落とす
- 宝箱から武器/パッシブの強化や進化が起きる
- 宝箱演出が報酬の快感になっている

### 8. 武器進化

- 多くの武器には進化形がある
- 進化には、武器最大レベル + 対応パッシブなどの条件がある
- 条件達成後に宝箱で進化する

### 9. ステージ時間

- ステージごとに15分、20分、30分などの時間制がある
- 制限時間到達でクリア扱い
- その後に強力な敵が出る構造がある

### 10. ゴールド/永続強化

- プレイで得たゴールドを使って永続強化できる
- 攻撃力、移動速度、磁石範囲などの基礎能力を上げられる

### 11. アンロック

- 条件達成でキャラ、武器、ステージ、モードなどが解放される
- 実績/Unlocks が長期プレイの動機になる

### 12. モード拡張

- Hyper、Hurry、Inverse、Endless、Limit Break など、後から遊びを変えるモードがある
- MVPでは不要

## Vamp Pon に採用する仕様

### 採用: 自動攻撃 + 移動中心

```txt
プレイヤーは移動中心。
攻撃は自動。
```

理由:

- ぼーっと遊べる
- 初心者に優しい
- ヴァンサバ系の核

### 採用: 大量の影

```txt
敵は影。
時間経過で量と種類が増える。
```

ただし、裏ストーリー上は、影は単なる敵ではない。

### 採用: 経験値 = 記憶の欠片

表では経験値。

裏では記憶の欠片。

```txt
敵を倒す
↓
欠片が落ちる
↓
拾うとレベルアップ
↓
世界が少し思い出す
```

### 採用: レベルアップ3択

MVPでは3択でよい。

```txt
武器強化
新武器
パッシブ
回復/臨時救済
```

4択は後で検討。

### 採用: 武器枠/パッシブ枠

MVPでは小さく始める。

```txt
武器枠: 4
パッシブ枠: 4
```

正式版に近づけるなら、後で以下へ拡張。

```txt
武器枠: 6
パッシブ枠: 6
```

### 採用: 宝箱の代替 = 記憶カプセル/秘宝箱

Vamp Pon では宝箱そのものより、以下が合う。

```txt
記憶カプセル
忘れ物箱
秘宝箱
地図帳の封筒
展示ケース
```

MVPでは名称を仮に「記憶カプセル」とする。

### 採用: 武器進化

武器最大レベル + 対応パッシブ + 記憶カプセルで進化。

例:

```txt
夜の鉛筆 Lv.MAX + 月明かりのしおり
↓
未完成の一行
```

```txt
星くず弾 Lv.MAX + 金のコンパス
↓
北極星のランタン
```

### 採用: 時間制

MVPは短くする。

```txt
MVP: 10分生存
正式初期: 15分ステージ
標準: 20分/30分は後回し
```

理由:

- 個人開発で調整しやすい
- 1プレイが軽い
- 爽快感の検証が早い

### 採用: 永続強化

条件達成や通貨で小さく強化。

```txt
攻撃力 +3%
経験値 +3%
吸引範囲 +5%
移動速度 +2%
クールタイム -2%
最大HP +5
```

強化上限は必ず作る。

### 採用: 実績/アンロック

Vamp Pon では実績が裏ストーリーの断片になる。

```txt
実績解除
↓
報酬
↓
説明文に裏ストーリー断片
```

## Vamp Pon 独自仕様

### 1. キャラ別必殺技

Vampire Survivors の中核ではないが、Vamp Pon では入れる価値がある。

```txt
キャラごとに1つ
ゲージ制
1ボタン or ピンチ時自動発動
演出は短い
```

MVP候補:

```txt
忘れ物係: 消えない名前
地図読み: 黒インク払い
夜番: 朝まで残る光
```

### 2. 裏ストーリー断片

ストーリーは長文で見せない。

```txt
アイテム説明
実績文
図鑑文
秘宝武器説明
条件達成文
```

で分かる人には分かる形にする。

### 3. 影の意味

表では敵。

裏では、忘れられた記憶や消えかけた記録。

```txt
敵を倒す
↓
記憶の欠片に戻す
```

### 4. 黒インク

地図帳/記録を消すもの。

ゲーム的には以下に使える。

```txt
危険床
敵湧きエリア
時間経過で広がる演出
ステージギミック
```

MVPでは危険床まで入れると重いので、演出または特定敵の攻撃から始める。

## MVP仕様 v0.1

### 目的

```txt
10分間、夜にあふれる影を払いながら生き残る。
```

裏目的:

```txt
朝になる前に、忘れられた記憶の欠片をできるだけ取り戻す。
```

### プレイ時間

```txt
1ステージ10分
```

### プレイヤーキャラ

MVP候補:

```txt
1. 忘れ物係
2. 地図読み
```

最小なら1人だけ。

### 必殺技

最小なら1つ。

```txt
消えない名前
```

効果:

```txt
周囲の経験値/欠片を吸引し、小型影を記憶欠片に戻す。
```

### 武器

MVP武器 5個。

```txt
夜の鉛筆: 近い敵へ直線弾
ビー玉: 反射弾
月のしおり: 周囲回転/範囲
黒インクの小瓶: 地面に範囲ダメージ
星くず弾: ランダム方向に小弾連射
```

### パッシブ

MVPパッシブ 5個。

```txt
金のコンパス: 吸引範囲アップ
旅のバッジ: 攻撃力アップ
月明かりのしおり: 経験値アップ
古い切符: 移動速度アップ
白い余白: クールタイム短縮
```

### 進化

MVP進化 2個。

```txt
夜の鉛筆 MAX + 月明かりのしおり
→ 未完成の一行
```

```txt
星くず弾 MAX + 金のコンパス
→ 北極星のランタン
```

### 敵

MVP敵 5種類。

```txt
インクの影: 基本敵
紙くずの影: 速い小型
迷子の方角: 斜め移動/回り込み
黒いカプセル: 硬い敵、倒すと欠片多め
夜のもや: 低速だが群れる
```

### 強敵/宝箱枠

```txt
黒ラベルの影
```

倒すと記憶カプセルを落とす。

### レベルアップ

```txt
基本3択
既存武器強化優先
新武器/パッシブも出る
HPが低い時だけ回復候補が出る可能性
```

### リザルト

表示するもの:

```txt
生存時間
倒した影
集めた記憶の欠片
レベル
進化武器
獲得した忘れ物
新実績
裏ストーリー断片 1行
```

### 図鑑

MVPでは最低限。

```txt
敵図鑑 5
アイテム図鑑 10
実績 5
```

## 後回しにする仕様

### 後回し: 大量キャラ

最初からキャラ10人以上は作らない。

### 後回し: 30分ステージ

調整が重い。

### 後回し: Endless / Limit Break

本編が成立してから。

### 後回し: 複雑な地形

ヴァンサバ系は視認性とテンポが大事。

### 後回し: 強いストーリー演出

会話イベントやカットシーンは入れない。

### 後回し: 必殺技の演出分岐

面白いが、MVPでは重い。

## 採用/変更/後回し一覧

| 要素 | Vampire Survivors | Vamp Pon |
|---|---|---|
| 操作 | 移動中心 | 採用 |
| 攻撃 | 自動攻撃 | 採用 |
| 敵 | 大量モンスター | 影として採用 |
| 経験値 | ジェム | 記憶の欠片として採用 |
| レベルアップ | 3/4択 | MVPは3択 |
| 武器枠 | 6枠 | MVPは4枠、後で6枠 |
| パッシブ枠 | 6枠 | MVPは4枠、後で6枠 |
| 宝箱 | 強敵ドロップ | 記憶カプセルに変更 |
| 進化 | 武器MAX+条件+宝箱 | 採用 |
| 時間 | 15/20/30分 | MVPは10分 |
| 永続強化 | ゴールドで強化 | 小さい強化として採用 |
| アンロック | キャラ/武器/ステージ | 採用 |
| 図鑑 | 収集/確認 | 裏ストーリー媒体として強化 |
| 必殺技 | 中核ではない | Vamp Pon独自で採用 |
| 長文ストーリー | ほぼなし | 表には出さず裏断片のみ |

## 仕様を詰める次の順番

次は以下を順に決める。

```txt
1. MVPキャラ1〜2人の正式名
2. MVP武器5個のレベル別効果
3. MVPパッシブ5個の数値
4. 敵5種類のHP/速度/出現時間
5. 10分間のウェーブ表
6. レベルアップ候補抽選ルール
7. 記憶カプセル/進化条件
8. 永続強化の初期ラインナップ
9. 図鑑/実績のMVP文言
10. リザルト画面項目
```

## 現時点の結論

Vamp Pon は、Vampire Survivors の中核仕様をかなり素直に採用する。

独自性は以下に集中させる。

```txt
裏ストーリー断片
記憶の欠片
黒インク
記憶カプセル
キャラ別必殺技
忘れ物/地図帳/旅の記録
```

これにより、遊び心地は分かりやすく、世界観は別物にできる。

# 150 Survivors-like Fun Pass

Vamp Pon を「素材が入っている」状態から「序盤から触って気持ちいい」状態へ寄せるための実装メモ。

## 参考にしたジャンル構造

Survivors-like / bullet heaven は、連続ウェーブを移動でさばきながら、短い間隔でアップグレードを選び、ビルドが雪だるま式に伸びる遊び。
Vampire Survivors は、自動攻撃・接触ダメージ・経験値ジェム・レベルアップ選択・強敵が落とす宝箱・武器進化が中核。
20 Minutes Till Dawn は同系統だが、暗闇視界・複数キャラ/武器・短時間モード・難易度段階で差別化している。
HoloCure は、武器/アイテム/スキルの4択、武器合成、さらに上位合成まで積むことでビルドの到達点を増やしている。

## Vamp Ponでの判断

### 1. 敵を硬くしない

Stage1序盤は敵を硬くしない。
敵のHPを上げるより、役割を増やす。

- オンブ: 柔らかい基本敵。倒す快感担当。
- 走る紙片オンブ: 予兆→突進→硬直。避ける快感担当。
- 迷子の方角: 旋回・回り込み。逃げ道を変える担当。
- 黒いカプセル: 近づくと逃げる報酬敵。追う小目標担当。
- 夜のもや: 群れで面を作る担当。
- オンブロ・黒ラベル: 節目の強敵。カプセル/進化導線担当。

### 2. 最初の60秒を薄くしない

最初の60秒で最低3種類の役割を見せる。

- 0〜20秒: 倒す快感
- 20〜45秒: 突進の混入
- 45〜75秒: 回り込みの混入

Lv5まで待って面白くするのではなく、Lv2時点でプレイヤーに「ちょっと違う敵がいる」と感じさせる。

### 3. エリートを3分まで待たせない

初回エリートを180秒から150秒へ前倒し。
理由は、カプセル/進化/合体の期待を早く見せるため。

### 4. 暴走は強いが、終わった後に少し怖い

暴走は与ダメ1.5倍。
終了後0.8秒だけ移動速度を58%へ下げる。

狙い:

- 発動中は強い
- 終了位置が悪いと危ない
- 強制発動ではなく手動でも「理性がない感じ」を少し出す

## 今回入れた実装

- `EnemyBehavior` に `charger / orbit_chase / coward` を追加
- `computeBehaviorStep` に予兆突進・旋回・逃げ挙動を追加
- 既存敵6種の名前/役割/挙動を再割当
- Stage1序盤ウェーブを濃く再設計
- 暴走終了後の `fatigueRemaining` を追加
- 暴走疲労を移動速度へ反映
- 敵挙動・暴走疲労テストを追加

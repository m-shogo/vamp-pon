# 1. Core memory rule

## Dream内

- 別Eraの親子 / 祖先と子孫でも普通に会える。
- time tagが弱いため、最初から「この人は自分の親 / 子 / 祖先 / 子孫」と分からなくてよい。
- 顔が似ている、口癖が似ている、同じ手癖がある、同じ家の話をする等は**Evidence**であって即Revealではない。

## 通常Waking

通常の目覚めではDreamの明示memoryをほとんど失う。

そのため古いEraの親が、Dreamで将来の子 / 子孫と会っていてもRealityでは:

- 名前を思い出せない
- 顔を思い出せない
- 「誰かに言われた気がする」だけ残る
- 理由の分からない癖 / 選択だけ残る
- 夢の話をしても筋が通らず、家族から不思議がられる

ことがある。

### Important

子ども側から見ると:

> 「お父さん、何言ってるの？」
> 「おばあちゃん、また変な夢の話してる。」
> 「その人、ちょっと怖い / 変な人だと思ってた。」

となってよい。

ただし:

- 実際の認知症 / dementiaをDream memoryの説明へ使わない。
- 「ぼけた老人だから面白い」という笑いにしない。
- medical cognitive impairmentが存在する場合はDream現象と別問題として扱う。

## Resolution Waking

ユーザーが会話上「朝になったら思い出す」と言う場合も、Current World Ruleでは**physical morningではなくResolution Waking**を意味する。

その人物のEraで大事件の解決へ到達した時:

- Dream memoryが戻る
- Dreamで会った人の顔 / 声 / 名前 / 会話が繋がる
- Reality側の写真 / 手紙 / 家系記録 / 道具 / 家の話等と初めて一致する

ことで:

> 「あの人……父さんだったんだ。」
> 「ずっと昔の写真の人、夜で一緒に肉を焼いてた人だ。」
> 「祖母が何十年も前に言っていた“変な夢”は、これだったのか。」

という**late recognition**を成立させる。

Memory recoveryだけで血縁を自動生成しない。
Reality Evidenceと一致して初めてRelation Revealにする。

# 3. Recognition stages

Cross-era relation revealは基本6段階。

```txt
A. Dream Meeting
↓
B. Strange Familiarity
↓
C. Normal Waking / Explicit Memory Loss
↓
D. Reality Residue / Evidence
↓
E. Era Incident Resolution
↓
F. Resolution Waking / Relation Recontextualization
```

## A. Dream Meeting

普通に友達 / 苦手な相手 / Party仲間として会う。

## B. Strange Familiarity

- 同じ味付け
- 同じ鼻歌
- 同じ工具の持ち方
- 同じ怒り方
- 同じ家の窓 / 階段の話
- 同じ犬への呼び方

等。

## C. Normal Waking

明示memoryが落ちる。

## D. Reality Residue

- 理由なく子どもの名前候補にある音を好む
- 見知らぬ料理を「懐かしい」と思う
- 家族へ「困ったら第三の道を探せ」と言い続ける
- 修理方法だけ残る

ただしclosed time-loopを自動Canon化しない。

## E. Era Incident Resolution

本人がRealityで以前とは違う選択をする。

## F. Relation Recontextualization

Dreamの人間関係とReality family / historyが繋がる。

# 4. Parent-child pattern

最も強い使い方の一つ。

Example structure:

```txt
Older Era Parent A
↓ Dream
Later Era Adult Child Bと会う
↓
互いに親子だと知らず、むしろ最初は相性が悪い
↓
Normal WakingでAはBを忘れる
↓
RealityでAは理由の分からない一言 / 行動だけ残す
↓ Years
BのRealityでは、その言葉を「親の変な癖」として知っている
↓
B自身がDreamへ来てAと会う
↓
BのEra incident解決
↓
Resolution Waking
↓
親が昔言っていた言葉とDreamのAが一致する
```

### Guard

- parent = always loving / correctにしない。
- child = parentを理解すれば全部許す、にしない。
- blood relation revealで虐待 / neglect / disagreementを免罪しない。
- 良い親でも子に理解されないことはある。
- 子ども側にも親が知らない人生がある。

# 5. Ancestor-descendant pattern

Ancestorは「自分の血が未来まで続いた」と分かった瞬間に万能感を得る存在ではない。

Strong uses:

- descendantの癖だけ妙に自分と似る
- inherited objectは同じだが使い方が違う
- 家訓が何世代も経て意味を変えている
- ancestorの善意が後世で制度化され、逆に人を縛っている
- descendantがancestorの罪 /功績を背負わされている

Theme:

> **受け継ぐことと、同じ人になることは違う。**

Descendant does not inherit guilt automatically.

## Place lineage

Existing high-value Candidate:

- ミチル × ゲン = old route / new route

## Object lineage

Existing highest-value Candidate:

- トモリが昔直したランタンを、後世のユイが持つ

**この関係を血縁にするかはまだOpen。**
物だけが繋いでも十分強い。

## Animal bridge

Reality由来の犬 / 猫はtime tagを理解しなくても人物を感覚で覚えられる。

- 昔の飼い主と、その子孫に同じ仕草を感じる
- 家族写真を理解しなくても匂い / 声 / 手触りに反応する
- 猫が別Eraの同じ家を知っているように振る舞う

Animalを系譜説明機械へしない。

# 7. Family satire + cultural memory

家族関係はRevealだけでなく世相の風刺へ使う。

Same issue, different lens:

- Child: 「なんで大人だけ例外なの？」
- Parent: 「責任を取る側には別の怖さがある。」
- Aunt / Uncle: 「その子のためって、その子に聞いた？」
- Grandparent: 「昔より便利。でも前より自由とは限らないね。」

誰か一人を作者の正解speakerにしない。

---

# 8. Causality guard

Dreamはcross-era meetingを可能にするが、安易なtime-travel paradoxへしない。

- Dreamで未来を知ってReality過去を自由に改変するstoryにはしない。
- Normal Wakingでexplicit future dataは落ちる。
- skill / emotion / vague choice residueは残り得る。
- exact lottery number / future incident date / stock price等を持ち帰れない。
- self-fulfilling name loop等はMain Mystery級。偶然量産しない。

This allows:

> future personとの出会いが昔の人を少し変える

without turning the work into deterministic time-travel puzzle fiction.

# 11. Completion definition

- Normal Waking memory loss and Resolution Waking recovery stay consistent.
- physical morning is never reintroduced.
- at least one parent-child and one ancestor-descendant lane can exist without making everyone relatives.
- non-blood inheritance remains equally important.
- Reality evidence is required before a lineage Reveal becomes fact.
- descendants do not inherit guilt / moral responsibility automatically.
- dementia / cognitive impairment is not used as the supernatural explanation or joke.
- Season growth and relationship memory are not reset.

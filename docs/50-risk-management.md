# リスク管理表

## 目的

Vamp Pon の制作で起きそうな破綻を事前に洗い出す。

リスクは、発生してから対応すると手戻りが大きい。

この資料では、以下を整理する。

```txt
リスク
発生原因
影響
早期サイン
予防策
発生時の対応
```

---

# 1. スコープ肥大

## 内容

作りたい要素が増えすぎて、MVPが完成しない。

## 発生原因

```txt
キャラを増やしたくなる
武器を増やしたくなる
裏ストーリーを増やしたくなる
デザインを先に盛りたくなる
```

## 影響

```txt
実装が終わらない
調整不能になる
何が面白いか分からなくなる
```

## 早期サイン

```txt
ユイが完成する前にミチルを作り始める
8分MVP前に2ステージ目を考える
未実装なのに追加武器案が増える
```

## 予防策

```txt
MVP凍結リストを守る
新案はMVP後へ送る
ユイで8分遊ぶ核を最優先
```

## 発生時の対応

```txt
MVP後リストへ移動
現在のMVP必須に戻す
docs/47-mvp-freeze-list.md を見直す
```

---

# 2. 仮素材でテンションが下がる

## 内容

デザイン保留中の仮素材を見て、ゲーム自体が微妙に見えてしまう。

## 発生原因

```txt
仮素材を完成品として見てしまう
色やキャラの魅力で判断してしまう
```

## 影響

```txt
ロジック検証が止まる
本来見るべき操作感を見失う
```

## 早期サイン

```txt
見た目がしょぼいという理由で仕様を変えたくなる
ゲーム性ではなく絵の印象で評価する
```

## 予防策

```txt
仮素材で見る項目を固定する
デザイン評価は別日に分ける
```

## 発生時の対応

```txt
操作感/敵密度/成長テンポだけ評価する
デザイン課題として別メモに逃がす
```

---

# 3. スマホで操作しづらい

## 内容

PCでは遊べるが、スマホ縦持ちで操作がつらい。

## 発生原因

```txt
仮想スティックが小さい
必殺技ボタンが遠い
カードが小さい
指で自キャラが隠れる
```

## 影響

```txt
アプリゲームとして成立しない
```

## 早期サイン

```txt
スマホ確認を後回しにする
PCブラウザでだけ調整する
```

## 予防策

```txt
Prototype 1からスマホ確認
縦持ち390x844基準
3択固定
```

## 発生時の対応

```txt
仮想スティック調整
カード大型化
必殺技自動発動ON
5分モード検討
```

---

# 4. 8分が長すぎる

## 内容

スマホでは8分でも長く感じる。

## 発生原因

```txt
中盤に山がない
成長テンポが遅い
リザルト報酬が弱い
```

## 影響

```txt
離脱される
もう一度遊ばれない
```

## 早期サイン

```txt
5分時点で飽きる
7分前に集中が切れる
進化前にやめたくなる
```

## 予防策

```txt
3分/5分/7分にカプセル
5分で進化期待
7分からクライマックス
```

## 発生時の対応

```txt
標準を5分に変更
8分をfull扱いにする
カプセル間隔短縮
XPカーブを軽くする
```

---

# 5. 爽快感が足りない

## 内容

敵を倒す気持ちよさが弱い。

## 発生原因

```txt
敵HPが高い
武器ダメージが低い
弾が見えない
欠片吸引が弱い
```

## 影響

```txt
ヴァンサバ系として弱い
```

## 早期サイン

```txt
敵が画面に溜まりすぎる
レベルアップしても変化が薄い
欠片を拾うのが作業になる
```

## 予防策

```txt
初期敵を弱める
1分以内にレベルアップ
欠片取得音/吸引を早期実装
```

## 発生時の対応

```txt
敵HPを下げる
武器CT短縮
欠片吸引範囲拡大
Lv2効果を強くする
```

---

# 6. 進化が見られない

## 内容

MVP内で進化に届かず、報酬の山が弱くなる。

## 発生原因

```txt
Lv5到達が遅い
カプセル回数が少ない
進化条件が分かりにくい
候補抽選が散る
```

## 影響

```txt
記憶カプセルが弱い
長期目標が見えにくい
```

## 早期サイン

```txt
8分プレイで進化0が多い
5分時点でLv5武器がない
```

## 予防策

```txt
夜の鉛筆を初期武器にする
月明かりのしおりを候補に出しやすくする
3分/5分/7分にカプセル
```

## 発生時の対応

```txt
必要Lvを4に下げる検討
XPカーブ軽量化
カプセルで武器強化優先
進化条件ヒント追加
```

---

# 7. 必殺技が空気になる

## 内容

必殺技を使わない、または使っても気持ちよくない。

## 発生原因

```txt
チャージが長い
ボタンが目立たない
効果が弱い
押すタイミングが分からない
```

## 影響

```txt
独自性が薄れる
キャラ差が出ない
```

## 早期サイン

```txt
8分で使用0〜1回
使っても状況が変わらない
```

## 予防策

```txt
2〜4回使えるチャージ時間
満タン表示を明確化
吸引 + 小型影変換で効果を分かりやすく
```

## 発生時の対応

```txt
チャージ時間短縮
範囲拡大
自動発動設定ONを検討
ボタン表示強化
```

---

# 8. 裏ストーリーが邪魔になる

## 内容

裏ストーリー文がゲームテンポを止める。

## 発生原因

```txt
戦闘中に長文を出す
カード文言が長い
図鑑文を読ませすぎる
```

## 影響

```txt
爽快感が落ちる
スマホで読めない
```

## 早期サイン

```txt
レベルアップカードが読みにくい
プレイ中に文字が多い
説明臭い
```

## 予防策

```txt
裏文は1行
戦闘中に長文を出さない
リザルト/図鑑へ寄せる
```

## 発生時の対応

```txt
カード裏文を非表示
リザルト1行だけにする
図鑑へ移動
```

---

# 9. パフォーマンス不足

## 内容

スマホで重い。

## 発生原因

```txt
敵数が多い
欠片が多い
弾が多い
ダメージ数字が多い
パーティクルが多い
```

## 影響

```txt
操作不能
爽快感低下
発熱/離脱
```

## 早期サイン

```txt
敵100体超えで重い
終盤でfps低下
スマホが熱い
```

## 予防策

```txt
敵上限120〜160
欠片上限250
弾上限120
オブジェクトプール
ダメージ数字間引き
```

## 発生時の対応

```txt
敵密度を下げる
欠片統合
パーティクル削減
30fps前提に調整
```

---

# 10. 技術選定の手戻り

## 内容

Webで作った後、アプリ化に進みにくくなる。

## 発生原因

```txt
ブラウザ依存実装
画面サイズ固定
PWA/Capacitorを想定しない
```

## 影響

```txt
移植コスト増大
```

## 早期サイン

```txt
windowサイズ直書き
localStorage以外への依存が増える
スマホ確認をしていない
```

## 予防策

```txt
390x844論理解像度
スケール対応
localStorage抽象化
非アクティブポーズ
```

## 発生時の対応

```txt
storage wrapper導入
input abstraction導入
画面スケール処理分離
```

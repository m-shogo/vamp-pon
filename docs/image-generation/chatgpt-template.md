# ChatGPT Image Generation Template

毎回長い仕様を貼らないための短縮テンプレ。

## Standard request

```txt
vamp-ponの画像生成ルールで作ってください。
最初に `docs/image-generation/README.md` と対象カテゴリの正本を読んでください。
添付画像の絵柄・可愛さ・描き込み密度を最優先してください。

今回作るもの:
（対象を書く）

今回だけの変更:
（正面向き、表情、ポーズなどを書く。なければ削除）

暫定ルール:
- 1素材180×180px
- 実透過RGBA（背景タイルのみ不透明可）
- 背景なし（背景タイルを除く）
- 文字・罫線なし
- セル外へのはみ出しなし
- できるだけセル端接触なし
- 君が画像を作り、別の生成サービスへ回さない
```

## Enemy 48 sheet

```txt
vamp-ponの画像生成ルールで敵48体を作ってください。
`docs/image-generation/README.md` と `docs/enemies/README.md` を読んで、正本順・添付クオリティ・可愛さ・正面寄りで統一してください。
オンブ／オンブロは確定ルール通りです。

- 1440×1080px
- 8列×6行
- 1セル180×180px
- 実透過RGBA
- 48セルすべて中身あり
- 文字・セル罫線・背景なし
- セル端接触・はみ出しなし
- 機械検査前にPASSを断言しない
```

## Single asset

```txt
vamp-pon画像ルールで「素材名」を作ってください。
添付の絵柄を基準に、180×180px・実透過RGBA・背景文字なし・はみ出しなし。
```

## Background tile

```txt
vamp-pon背景ルールで「Stage名」の背景タイルを作ってください。
180×180pxの完全シームレスタイル。キャラ・敵・弾・欠片より低コントラストにしてください。
```

## Cut-in / icon source

```txt
vamp-ponカットイン・アイコンルールで「対象名」を作ってください。
完成画面ではなく、runtimeで合成する180×180px透過元絵として作ってください。
```

# Background Image Generation Rules

背景だけはキャラクター素材と目的が違うため、別ルールを使う。

## Current temporary format

- 1背景タイル = **180×180px**
- 原則として不透明PNG
- 上下左右が完全にシームレス
- 2×2以上に並べても継ぎ目が見えない
- 完成背景イラストではなく、ゲーム床として使えるタイル

## Art direction

- 夜、紙、地図帳、忘れ物、薄いインク跡
- 紙片・絵本風ドット
- キャラクターより低コントラスト
- 模様は控えめ
- 大きな一点物や強い焦点を置かない
- 読める文字、ロゴ、看板文字を入れない
- 暖色の光を広く置かない
- 黒インク敵、ユイ、欠片、弾、UIが埋もれない値設計にする

## Generation priority

1. シームレス性
2. gameplay readability
3. 世界観
4. 見栄え

背景単体で派手に見えても、ゲーム中の視認性を下げるなら不採用。

## Review

生成後は必ず確認する。

- 1枚表示
- 2×2タイル表示
- 390×844相当の縦画面反復
- ユイ、黒インク敵、欠片、弾を重ねたcombat mock
- 明暗差と継ぎ目

背景の横長画面を直接生成せず、180×180pxタイルをruntimeで反復して構成する。

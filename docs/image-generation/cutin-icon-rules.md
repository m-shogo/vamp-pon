# Cut-in and HUD Icon Image Rules

必殺技、暴走モード、HUDアイコンは同じキャラクター表現を共有するが、完成画面を1枚絵として生成しない。

## Current temporary source format

当面はすべて **180×180px** の透過元絵で制作する。

### Required source assets per playable character

- `portrait_neutral`: 左下HUDの通常顔
- `portrait_berserk`: 左下HUDの暴走中の顔
- `ultimate_icon`: 右上の必殺技アイコン
- `berserk_icon`: 暴走ゲージ／状態を示す小紋章
- `cutin_ultimate`: 必殺技発動カットイン用の上半身・表情
- `cutin_berserk`: 暴走発動カットイン用の上半身・表情

各素材は1セル180×180px、実透過RGBA、文字なし、枠なし、背景なし。

## Runtime composition

横長カットインはruntimeで構成する。

- 180×180px元絵をトリミングして横からスライド
- 背面に紙帯、地図線、黒インク、暖色の小さな光を合成
- 必殺技名などの文字はUI側で描画
- 画面サイズやセーフエリアに合わせて配置を変える

生成画像へ横長背景、技名、UI枠を焼き込まない。

## Visual distinction

### Ultimate

- 意志が明確
- 暖色の灯りと古紙色を焦点にする
- 安定、救済、記憶を呼び戻す印象
- 顔を怖くしない

### Berserk

- 同一人物と分かる顔・髪・服・小物を維持
- 黒インクや紫黒の侵食を増やす
- 目、影、髪や布の動きで危うさを出す
- 流血、怪物化、別人化は避ける
- 怖さより「抑えきれない力」と「少し切ない危うさ」を優先する

## HUD readability

180×180px元絵は実表示で縮小されるため、以下を守る。

- 58px前後の左下ポートレートでも顔と状態差が分かる
- 30〜60pxの必殺技アイコンでも主記号が読める
- 小物を増やしすぎない
- 細線と小さな文字へ依存しない
- 通常／READY／発動中／暴走中を色だけに依存せず輪郭と表情でも分ける

## Approval order

1. 通常ポートレート
2. 暴走ポートレート
3. 必殺技アイコン
4. 暴走アイコン
5. 必殺技カットイン
6. 暴走カットイン

通常ポートレートの同一人物性が弱い状態で派生を増やさない。

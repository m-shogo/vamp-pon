# Shared World Bible

## Purpose

この資料は、Vamp-pon本編と、Vamp-pon世界内の派生遊び・派生UIが共有する世界観の入口です。

対象:

```text
Vamp-pon
soro-pon
将来の派生ミニゲーム
将来のプロモーション/デザイン生成
```

## Core Rule

```text
この資料を世界観共有の正本入口にする。
```

各派生側は、この内容を丸ごとコピーせず、必要な範囲を参照する。

## What Can Be Shared

派生側で参照してよいもの。

```text
世界観の基調
キャラの雰囲気
ステージのモチーフ
敵/影/記憶の扱い
武器/アイテムのモチーフ
紙/黒インク/小さな光のビジュアルルール
```

## What Must Not Be Shared Blindly

```text
本編の重要ネタバレ
未確定のキャラ設定
本編の戦闘バランス
本編のruntime素材そのもの
派生側で勝手に変更した設定
```

## soro-pon Mapping

`soro-pon` は Vamp-pon世界内で流行っている小さな記憶札遊びとして扱う。

```text
character -> 記憶札 / 対戦相手アバター / 称号候補
enemy -> 影札 / テーマ牌 / コレクション要素
stage -> 札卓背景 / Deck theme / 盤面スキン
item -> 牌モチーフ / 報酬 / コレクション
weapon -> 役名 / 札モチーフ / Result演出
```

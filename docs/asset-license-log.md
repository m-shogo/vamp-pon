# Asset License Log

## 目的

Vamp Pon で使用する素材の出所とライセンスを記録する。

テンプレート:

```txt
docs/57-asset-license-log-template.md
```

---

# ルール

```txt
出所が分からない素材は使わない
外部素材は必ず記録する
AI生成素材も記録する
フォントは利用条件を確認する
仮素材と本素材を分ける
```

---

# Current Status

現時点では、外部素材なし。

Prototype 1では、Phaser上の円・四角・線などの仮図形を使う想定。

これは外部素材ではないため、個別ライセンス記録は不要。

# Unity U33 Drop / Pickup / Heal Review

## 変更

- PickupRadius: `1.75` から `1.8`。
- XpDropChance: `0.88` から `0.9`。
- RecoveryDropChance: `0.045` から `0.04`。
- RareDropDraftChance: `0.035` から `0.04`。

## 体験意図

XP pickupは少し気持ちよく、first pickupを早くする。heal pickupはありがたいが出すぎないようにし、吸い寄せ無効方針を維持する。Rareは少し特別に見える程度へ前倒しする。

## 維持したこと

- pickup cap 48。
- HeartsBypassMagnet true。
- pickup feedback / pickup sound cooldownはU28 / U29を維持。

## 残リスク

実機でpickup radiusが広すぎて勝手に集まりすぎないか、healが早すぎないか、pickup音がうるさくないかはNOT_MEASURED。

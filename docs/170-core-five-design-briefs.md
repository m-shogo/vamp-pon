# 170. Core Five Design Briefs

Use this when designing the first five major characters.

These are design briefs, not implementation requirements.

## 01 Yui

- vessel: lantern
- lineage: fire
- role: carry and read fragments
- first action: warm flame from lantern
- memory item set: wick, cracked glass, oil tag, small flint, warm map edge
- relation web: center, but not final answer
- visual signatures: blue hood, brown bangs, lantern, warm small light
- blank: why she had met everyone once
- happy direction: she learns that carrying does not mean owning every memory

## 02 Asa

- vessel: name tag with small ink-light
- lineage: neutral / name
- role: name and mark
- first action: mark target or object with a name sign
- memory item set: name tag pin, inked label, erased syllable, folded name card
- relation to Yui: one side remembers more than the other
- other relation: Koyori and name writing
- visual signatures: name tag, handwriting mark, ink-light accent
- blank: whether Asa named Yui first
- happy direction: a name can be kept without being shouted

## 03 Nagi

- vessel: moon box
- lineage: light / hidden box
- role: keep and protect
- first action: capsule shield or stored burst
- memory item set: tiny key, box corner, moon clasp, lining cloth, hidden note
- relation to Yui: item-only link through a stored lantern part
- other relation: Hana through preserved things
- visual signatures: box, moon clasp, closed posture
- blank: who locked the first box
- happy direction: keeping something closed can also be kindness

## 04 Michiru

- vessel: compass light
- lineage: neutral guide
- role: route and movement
- first action: route flare or position shift
- memory item set: needle, ticket half, route thread, map corner, station mark
- relation to Yui: shared lost route
- other relation: Gen through old roads
- visual signatures: compass, route line, travel color accent
- blank: whether the route was real
- happy direction: a way home can be a person, not a place

## 05 Tomori

- vessel: repaired lantern part, not a full normal lantern
- lineage: fire branch
- role: repair and area light
- first action: area light or burst from repaired part
- memory item set: spare glass, tool cloth, lamp screw, soot brush, repair note
- relation to Yui: repaired Yui's symbol or knew its old form
- other relation: fire-line sibling or cousin seed
- visual signatures: repair tool, warm accent, not-Yui vessel shape
- blank: why Tomori knows the lantern
- happy direction: waiting was not empty if the light was being repaired

## Design lock

Core 5 must not look like five versions of the same small robed character.

Each needs:

- one unique silhouette
- one unique vessel
- one unique first action shape
- one unique memory item set
- one link to Yui
- one link away from Yui
- one blank

# 武器別 hit / trail QA

## ローカルQAランチャー

`pnpm dev` 起動後に以下を開く。

```txt
http://localhost:5173/
```

localhostでは右上に `Vamp Pon QA` ランチャーが表示される。
そこから以下の全QA画面へ移動できる。

- Main game
- Yui 96 cells
- Yui rage cycle
- Cutin QA
- Elite beat QA
- Weapon FX QA

スマホ実機で見る場合は、同じpathのまま `localhost` をMacのIPへ置き換える。

```txt
http://MacのIP:5173/?scene=weapon-fx-qa
```

## 起動

```txt
?scene=weapon-fx-qa
```

## 見るもの

- 鉛筆: graphiteの短い線跡、命中時は交差する鉛筆線
- 灯り: 暖色の小さな残光、命中時はリングと光点
- 紙刃: 薄い紙片の切れ跡、命中時は斜めの切断線
- ビー玉: ガラスの小さな光、命中・反射時はひびと丸い反射
- 紙飛行機: 後方の風線、命中時は横に流れる風
- 範囲: インク、街灯、夜明けでtick表現を分ける
- オービット: 接触時だけ紙片の小さなヒットを出す

## 方針

この変更は演出だけを追加する。
以下は変更しない。

- ダメージ
- クールダウン
- 弾速
- 当たり判定
- 敵HP
- ドロップ

## 実機確認

本編では以下を確認する。

- Lv1の鉛筆がうるさすぎない
- 灯り系が背景に埋もれない
- 紙刃と紙飛行機が似すぎない
- ビー玉の反射が気持ちいい
- 範囲tickが毎0.25秒でも重く見えない
- 敵が多い時にtrailが画面を汚しすぎない

# 3. Character depth candidates

## 3.1 イサナ

Existing lane:

> whole-system flow / local life becomes aggregate cost

### Regional Root Candidate

Compare later:

- **京阪神の大都市郊外・新旧住宅地が接する生活圏**
- **東北の県都級都市・中心市街地と周辺生活圏が接する地域**

Exact prefecture / hometown / Era: Open。

### Dialect leak rule Candidate

普段は標準語寄り。

感情が漏れやすい時:

- 話が堂々巡りになった時
- 家族や古い友人へ説明する時
- 自分の計画ミスを認めた直後

Exact語彙は地域決定後に一次資料 / 方言資料で確認する。

### Food / Party hook

大皿を見て「誰が何を食べるか」ではなく、**手がぶつからず全員が取りやすい置き方**へ無意識に並べ替える。

最初は有能で楽しい。
後に「本人が取りたい物」より流れを優先する癖として同じ欠点が見える。

### Internal relation seeds

- **イサナ ↔ カンナ**: 全体計画 vs 現場で「今直す必要ある？」
- **イサナ ↔ ナナセ**: routeを残す点では協力、一本化の強さで衝突

### Former S1 contrast

**ナシロ**。

`one valid identity`を疑うナシロが、イサナの`one coherent plan`へだけは強く反発するCandidate。

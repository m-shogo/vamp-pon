# 1. 一番大事な抽出ルール

```txt
好きな作品
↓
表面のキャラ属性をコピーしない
↓
「何が感情を動かすのか」を分解
↓
ヨルノシルベ固有の世界ルール / Gameplay / 時代差 / 黒耀化へ接続
```

例:

```txt
強いライバル二人が好き
≠ 主人公と黒髪ライバルを作る

抽出:
互いが互いの人生の証人
+ 同じ傷へ別の回答
+ 離反しても関係が消えない
+ 追うことと所有することを分ける
```

# 2. Rival / best-friend bond — ナルト × サスケ方向から抽出

欲しいもの:

- 恋愛でなくても人生最大級に重要な相手
- 同じ始点から別の答えへ進む
- 片方が離反しても「元仲間」で終わらない
- 追う側も間違える
- 戻る側も昔の人格へ戻る必要はない
- 最後は勝敗だけでなく「相手の答えを理解したか」が重要

ヨルノシルベへの変換:

### ユイ × アサ

- non-romance protagonist-grade buddy
- 同じ「人を置いていきたくない」が方法で衝突
- 友情だからこそアサがユイを強く否定できる
- 離反 / 別行動を「裏切り」で簡単に片付けない

### ユイ × クロオリ

- rivalryより思想的mirror
- 開く /閉じる
- 「敵が主人公の闇コピー」ではなく本当に正しい場面を持つ

# 6. Chosen family with individual dreams — ONE PIECE方向から抽出

欲しい:

問い:

### Love

# 8. Aging fear — ユーザー独自の重要Theme

「歳をとる」は脇Themeにしない。

怖さ:

- 顔が変わる
- 身体ができなくなることが増える
- 好きな人が先に変わる
- 同じ服 / 趣味が似合わないと思い始める
- 親が老いる
- 子どもが自分より大人になる
- memoryが薄れる
- 自分だけ変わらない

しかし:

> 老い = 不幸

にはしない。

嬉しさもある:

- 昔できなかったことができる
- 若い時より他人へ任せられる
- 同じ人を違う形で愛せる
- 師匠より弟子が上手になる
- 子どもが自分を助ける

### クロエ

不老者側から:

> **自分だけ関係の時間から置いていかれる。**

### レンジ / ゲン / ハナ

老いる側から:

> **変わること自体が、生きた時間でもある。**

を描く。

# 9. BACCANO! direction — network ensemble

欲しい:

- 主人公が一人とは限らない感覚
- 端役に見えた人物が別の線では主役
- 時系列 / 視点が交差
- 小さな行動が遠くの人物へ届く
- 人間関係が一直線の相関図ではなくnetwork

ヨルノシルベでは「別時代」を使う。

```txt
Aが物を修理
↓
数十年後Bが使う
↓
さらに後世Cが捨てる
↓
夜でA/B/Cが同時に会う
```

同じ事件へ全員直接参加させず、**物 / 記録 /言葉のリレー**を使う。

# 10. Unique dialogue — 西尾維新作品が刺さる部分から抽出

欲しい:

- 人物ごとに会話の速度が違う

禁止:

ヨルノシルベ独自のvoice差:

- アサ = 結論が先
- ナギ = 許可 /確認の短文
- ミチル = route / 寄り道比喩
- トモリ = 修理 / 手触り語彙
- シロ = 暫定分類
- トキ = 数値 /条件
- ツムギ = 完結を避ける文
- ヒヨリ = 他人の良い点を即時に見つける

へ歪める。

# 23. Betrayal / separation

## Apparent betrayal

- 守るために隠す
- 約束を守るため仲間へ逆らう
- 相手の選択を優先して組織を離れる

## Real betrayal

本当に間違える人物も必要。

- 利益のため秘密を売る
- 嫉妬で相手を傷つける
- 恐怖で仲間を置いていく

ただし:

> 理由がある = 無罪

にはしない。

謝罪 / 修復 / 許されない部分まで描く。

---

# 24. Death / loss

Permanent deathを主要な泣き装置にしないCurrent方針を維持。

しかし「死」という経験そのものを禁止しない。

使うなら:

- 過去の伴侶
- 何世代も前の弟子
- 先祖 / 子孫
- 長寿者が見送った人
- 動物との別れ

など、**今の人物がどう生きるかへ残るhistory**として扱う。

新キャラを死なせて既存キャラの成長燃料にするだけ、は禁止。

---

# 25. Reunion / graduation

再会は時間を巻き戻さない。

```txt
昔の関係
+ 別々に生きた時間
= 再会後の新しい関係
```

卒業は喪失であり成功でもある。

- 弟子が師匠を必要としなくなる
- 兄妹が別々に暮らす
- 仲間が別時代へ帰る
- 双子が別の友人を持つ
- Robotがsyncしない記憶を持つ

これをHappy Endの一部にできる。

# 27. Character creation acceptance

新規character / relationを作る前に確認:

1. 何が好きで作るのかを一文で言える
2. 既存作品の誰のコピーでもない
3. Current/Futureの既存人物と役割が交換可能でない
4. visual fetishだけで人物を作っていない
5. relationshipが一方向の救済でない
6. 相手が変わった時に関係も変化できる
7. 日常sceneが最低3つある
8. 喧嘩 / frictionが最低1つある
9. 相手不在でも本人の人生がある
10. Gameplayへ最低1つ返る
11. Named Object / habit / voiceのどれかへ関係が残る
12. Happy Endが「ずっと同じ状態」だけではない

# 28. 一文

> **ヨルノシルベで作りたいのは、元ネタを思い出すキャラではなく、「この二人、この兄妹、この師弟、この仲間たちをもっと見ていたい」と固有名で思われる関係。**

# Audio Feedback Asset Plan

## 目的

Vamp Ponで必要になる音とフィードバックを整理する。

Prototype 1では音なしでもよい。

ただし、後で必要になるため、先に分類しておく。

---

# 1. 基本方針

音はゲームの気持ちよさを補強する。

ただし、音がなくても遊べること。

```txt
音あり: 気持ちいい
音なし: 状態が分かる
```

---

# 2. Prototype 1で必要な反応

音より先に必要な視覚反応:

- 敵ヒット
- 敵死亡
- 欠片取得
- XP増加
- Lv2到達
- 被弾

Prototype 1ではSEなしでもよい。

---

# 3. MVPで欲しいSE

Priority S:

- 欠片取得
- レベルアップ
- 被弾
- カプセル取得
- 進化
- 必殺技発動

Priority A:

- 敵ヒット
- 敵死亡
- カード選択
- UI決定
- リザルト表示

Priority B:

- ステージ開始
- 図鑑登録
- 実績解除
- ボス出現

---

# 4. 音の方向

採用ビジュアルに合わせる。

```txt
紙
小さな鈴
ランタン
柔らかい光
黒インク
夜の静けさ
```

避ける音:

```txt
激しい金属音
ホラーすぎる音
大きすぎる爆発音
ソシャゲ風の派手すぎる通知音
```

---

# 5. BGM方針

Prototype 1では不要。

MVPでは1曲あればよい。

方向:

- 静かな夜
- 小さな鼓動
- 紙が擦れる質感
- 後半少し焦りが出る

StageごとBGMは後回し。

---

# 6. 音なし対応

必須:

- 被弾点滅
- 欠片取得の光
- レベルアップ画面
- カプセル演出
- 必殺技ゲージの視覚表示

---

# 7. 実装タイミング

```txt
Prototype 1: 音なし可
Prototype 2: 欠片取得/レベルアップSE検討
Prototype 3: MVP必須SEを入れる
MVP後: BGM/Stage別SE
```

---

# 8. ライセンス

外部素材を使う場合は記録する。

```txt
docs/asset-license-log.md
```

AI生成/購入素材/フリー素材も記録する。

---

# 最重要

音で面白くするのではなく、面白い反応を音で強くする。

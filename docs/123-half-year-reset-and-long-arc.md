# Half-year Reset and Long Arc

## 目的

Vamp Ponを長期運用しても破綻しないように、15ステージ単位の大きな区切りを設計する。

1ラン単位のリセットだけでなく、Season単位の大きなリセットを持たせる。

---

# 1. 結論

Vamp Ponでは、長期運用の章区切りとして以下を採用候補にする。

```txt
15ステージ = 半年
```

ただし、これは世界が滅びるリセットではない。

```txt
半年の終わりに、地図帳の読み方が変わる。
```

---

# 2. 二重リセット構造

## 小さいリセット

```txt
1ラン終了
夜が明ける
その夜の力はほどける
でも意味は残る
```

## 大きいリセット

```txt
15ステージ終了
半年が終わる
その季節の地図帳が閉じる
でも拾った意味は残る
```

この二重構造にすると、ゲーム性と物語が響く。

---

# 3. なぜ半年か

半年はちょうどよい。

```txt
季節が変わる
学校や街の区切りに見える
人間関係が変化する
でも長すぎない
```

1年だと大きすぎる。

1ヶ月だと軽すぎる。

半年は、記憶と成長の区切りにちょうどよい。

---

# 4. 15ステージの構成案

## 1〜5

```txt
最初の地図帳
ユイたちの班
忘れ物係の原点
```

## 6〜10

```txt
届かなかった手紙
別の関係語Seed
郵便箱/封筒/未配達
```

## 11〜15

```txt
半年の終わり
読めなかったページのまとめ
次の季節への余白
```

---

# 5. 半年で何が起きたか

全部は説明しない。

置くべき余白:

```txt
なぜこの半年だけ黒インクが濃かったのか
誰が最初に忘れ物係を始めたのか
半年の終わりに誰がいなくなったと思われたのか
なぜ地図帳が一度閉じるのか
次の半年で何が変わるのか
```

答えは持つ。

でもSeason中に全部は言わない。

---

# 6. 半年リセットで消えるもの

```txt
その半年の一時的な進行演出
一部の期間限定マップ状態
Season内の未読演出
一時的なイベント配置
```

---

# 7. 半年リセットで残るもの

```txt
解放キャラ
図鑑
実績
拾った記憶断片
恒久的な小さな強化
プレイヤーの理解
次の半年へのSeed
```

ここは1ランリセットと同じ思想。

```txt
力はほどける。
意味は残る。
```

---

# 8. 半年終わりの演出

やりすぎない。

候補:

```txt
地図帳が一度閉じる
表紙に新しい傷やしおりが増える
読めるようになったページが束になる
次のページだけ、まだ黒い
遠くの街灯がひとつ点く
```

NG:

```txt
世界がリセットされたと説明する
全てなかったことにする
露骨な続編予告
未完のまま終わる
```

---

# 9. クリフハンガーの置き方

半年終わりの最後に、次の半年への引きを置く。

ただし1個だけ。

例:

```txt
閉じた地図帳の背表紙に、知らない筆跡で「また春に」と書かれていた。
```

または:

```txt
最後のページの裏に、開いた覚えのない切符が挟まっていた。
```

やりすぎない。

---

# 10. 後付け防止

半年Arcを使うなら、最初から以下を出す。

```txt
季節のしおり
半年分の空白
閉じたページ束
日付のない切符
春/秋を示す小物
```

これで、あとから半年リセットを入れても急に見えない。

---

# 11. カイロソフト的な良さ

半年単位は、運用にも合う。

```txt
Season更新
新Stage追加
新キャラ少数追加
新しい欠片テーマ
前Seasonの一部を残す
```

毎回全部を壊さず、少しずつ積む。

---

# 12. 最重要

半年リセットは、忘れるためではない。

```txt
一度閉じることで、次のページを読めるようにする。
```

Vamp Ponの長期構造はこれ。

```txt
夜が明ける。
ページが閉じる。
でも、拾った意味は残る。
```

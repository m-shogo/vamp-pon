# ヨルノシルベ — 朔盟 Operational Bible Candidate v1

Date: 2026-08-11  
Status: **CONTENT CANDIDATE / USER-APPROVED DIRECTION / RUNTIME NOT PROMOTED**

## 目的

朔盟を「設定資料上だけ存在する敵組織」にせず、物語中で実際にどう動くかを固定する。

既存八影28pairを任務構造へ昇格しつつ、全員同じ制服・軍隊階級・絶対首領という既視感へ寄せない。

---

# 1. 朔盟は軍隊ではなく盟約

朔盟memberは同じ種族でも同じ出身でもない。

共通するのは一つだけ。

> 「本人に迷わせ続けるより、誰かが正解を決める方が傷を減らせる」

この結論へ、それぞれ別の人生・失敗・恐れから到達している。

したがってmember間では:

- 何を正解とするか
- いつ固定するか
- どこまで本人へ知らせるか
- 一度決めたものを変更してよいか

が頻繁に衝突する。

---

# 2. 加入 Candidate — 「ひとつの未決を差し出す」

正式加入儀式を派手な宣誓式にしない。

Candidate memberは、自分が「二度と未決のまま残したくない」と思う一件を提示する。

例:

- ナシロ: 名前
- アサトジ: 開封 / 保護期限
- ミチグレ: 帰路
- オリネ: 開示
- ハクマ: 説明
- ツグリ: 破損
- ユラネ: 苦痛
- ペタ: 誤り

既存memberの一人が、その結論を**証人として承認**する。

重要:

- 全member投票は不要。
- leader承認も不要。
- 一人で自称しても朔盟memberにはならない。

これにより、各memberには「誰が最初に証人だったか」というrelation hookを持たせられる。

加入の真相は一括開示せず、memberごとのpast revealへ分散する。

---

# 3. Pair Mission Rule — 一人の正解では盟約任務にならない

朔盟最大のoperational rule Candidate。

**朔盟名義の任務は最低2memberの一致が必要。**

一人だけで動く場合は個人行動。

```txt
PROPOSER
「この未決を固定すべきだ」
+
WITNESS / COUNTERSIGN
「その固定を盟約として認める」
=
PAIR MISSION
```

## 物語上の利点

- 既存28pairを全部使える。
- pairごとに任務理由が変わる。
- 同じmemberでもpartner次第で戦い方と会話が変わる。
- 一人の暴走と組織意思を分離できる。
- 「なぜこの2人なのか」が毎回ドラマになる。

## Gameplay上の利点

pair encounterをHP二倍ではなく:

- cue modification
- ability interaction
- accidental counter
- conflicting target priority
- player-created third interpretation

へ接続できる。

---

# 4. 任務選定

朔盟は世界征服mission listを持たない。

対象は**未決・矛盾・揺らぎが長く残っている事象**。

Candidate selection questions:

1. 誰かが迷い続けているか
2. 複数の説明が争っているか
3. 放置すると損失が増えるか
4. 一つへ固定することで被害を止められるとmemberが信じているか
5. その固定で誰の選択権が失われるか

朔盟は1〜4を重視し、Current側は5を見落とさない。

---

# 5. 情報共有

朔盟は全情報を全員へ共有しない。

### three-level Candidate

- `PERSONAL`: member個人だけが持つ過去 / true-name / fear
- `PAIR`: 任務partnerへ必要な情報
- `PACT`: 朔盟全体へ共有する重大情報

これにより:

- member同士でも知らない過去がある
- playerが一人を倒しても組織全貌は分からない
- 内部の誤解が起こる
- later revealで過去pair sceneを再解釈できる

---

# 6. 連絡手段 Candidate

時代差がある人物を含む可能性があるため、現実の電話 / SNSだけを共通通信にしない。

朔盟共通通信は**夜へ残せる短い物理message**を基本とする。

Candidate visual grammar:

- 欠円が一箇所だけ描かれた札
- 本文を長文にしない
- location / object / time clue中心
- 読み手によって意味が少し変わる余地を残す

正式媒体名・材質はProp Masterで決める。

これは「秘密の魔法チャット」ではなく、時代を跨ぐNightの物質継承ruleへ接続する。

---

# 7. 拠点

常設の巨大秘密基地を必須にしない。

朔盟のidentityは建物ではなく盟約に置く。

Candidate:

- 一時集合地点を複数持つ
- abandoned station / archive / closed room等、既存Stage grammarへ接続可能
- memberごとに落ち着く場所が違う
- 全員集合はrare event

全員が揃った時の特別感を守る。

---

# 8. 資源 / 金

中央組織が全員へ給料を払う形にはしない。

Candidate model:

- 日常資源は各member由来
- mission固有道具のみshared cache
- 高価な資源が必要なmissionは別memberへ借りを作る
- 借りはAffinityではなく**obligation**として記録可能

これによりmember間へ:

- 貸し
- 借り
- 返済
- 拒否
- 勝手な流用

というcombat以外の関係を作れる。

---

# 9. 盟約違反

朔盟は「命令違反 = 処刑」の軍隊にしない。

違反候補:

- pair approvalなしで朔盟名義を使う
- partnerへ必要情報を故意に隠す
- 固定対象を私怨へすり替える
- 他memberのPERSONAL情報をPACTへ勝手に上げる
- 欠円symbolを第三者へ権威として使用させる

対応:

1. missionから外す
2. shared informationを制限
3. pair approvalを得にくくなる
4. 最終的に盟約から外れる

殺害は自動penaltyにしない。

---

# 10. 脱退

脱退は可能。

しかし「善人になったから抜ける」だけにしない。

脱退理由候補:

- 迷いを残す価値を認めた
- 朔盟は正しいが方法だけ拒否した
- 自分の正解を他memberに固定された
- 自分の対象だけ例外にしたことで矛盾した
- 盟約より個人を選んだ
- 朔盟以上に極端な結論へ進んだ

脱退 = Current加入を自動化しない。

# 11. 欠円symbolの扱い

欠円は制服badgeではなく**盟約を認識する最低共通記号**。

Rules:

- 同じ場所へ付けない
- 同じ大きさにしない
- 同じ素材にしない
- 8人の固有silhouetteを壊さない
- 無くしても本人recognitionが成立する

集合visualだけ、8人の欠円が構図上で一つの円になる。

# 12. Internal Ideology Axes

朔盟8人を「全員同じ思想」に見せないため、各pairで最低一軸は差を作る。

### Axis A — CONSENT ↔ OUTCOME

本人の同意をどこまで必要とするか。

### Axis B — PRESERVE ↔ ERASE

危険なものを残して管理するか、消すか。

### Axis C — REALITY ↔ COMFORT

苦しくても現実を優先するか、安らぎを優先するか。

### Axis D — REVERSIBLE ↔ PERMANENT

後から選び直せる状態を残すか、完全固定するか。

### Axis E — RECORD ↔ FORGET

誤りや失敗の履歴を残すか、なかったことにするか。

28pair review時に各pairの最大collision axisを一つ決める。

# 15. Anti-copy / Anti-cliche Guard

禁止:

- 全員同じ黒ローブ
- 全員同じ仮面
- 数字順の単純rank
- leaderが一人で全部命令
- member全員が世界征服を望む
- 全員悲しい過去だから無罪
- 裏切り者一人を最初から役割化
- memberを一戦で使い捨て
- 能力説明だけで人格が薄い
- 最終的に全員主人公側へ加入

狙うのは**一人でも作品を背負える敵が、盟約によってさらに面白くなる構造**。

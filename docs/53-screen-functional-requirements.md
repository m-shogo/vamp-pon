# 画面別機能要件

## 目的

Vamp Pon の各画面について、デザインを決めずに「機能として何が必要か」を定義する。

この資料では、色・フォント・ビジュアルスタイルは決めない。

決めるのは以下。

```txt
画面の役割
表示項目
操作
遷移先
MVPに入れる/後回し
合格条件
```

---

# 1. Boot画面

## 役割

```txt
ゲーム起動準備
データ読み込み
保存データ読み込み
初期化
```

## 表示項目

MVPでは不要。

必要なら:

```txt
Loading...
```

## 処理

```txt
ゲームデータ読み込み
localStorage読み込み
設定読み込み
Phaser初期化
Titleへ遷移
```

## MVP

必須。

ただし画面として見せなくてもよい。

## 合格条件

```txt
[ ] 起動時に保存データを読める
[ ] 保存データがない場合は初期化できる
[ ] エラー時に真っ黒で止まらない
```

---

# 2. Title画面

## 役割

```txt
ゲーム開始の入口
```

## MVP表示項目

```txt
Vamp Pon
スタート
```

## MVP後表示項目

```txt
図鑑
強化
設定
クレジット
```

## 操作

```txt
スタートをタップ
```

## 遷移

```txt
スタート → CharacterSelect または MainGame
図鑑 → Codex
強化 → PowerUp
設定 → Settings
```

## MVP判断

ユイ1人だけなら、スタートから直接MainGameでよい。

## 合格条件

```txt
[ ] 迷わずスタートできる
[ ] スマホで押しやすい
[ ] MVP後に図鑑/強化/設定を追加できる構造
```

---

# 3. CharacterSelect画面

## 役割

```txt
キャラを選ぶ
初期武器/必殺技/遊び方の違いを伝える
```

## MVP表示項目

ユイのみなら省略可能。

2人以上なら:

```txt
キャラ名
肩書き
初期武器
必殺技
初心者向け/中級者向け
スタート
```

## ユイ表示例

```txt
ユイ
忘れ物係
初期武器: 夜の鉛筆
必殺技: 消えない名前
初心者向け / 欠片を集めやすい
```

## 操作

```txt
キャラカードをタップ
スタート
```

## 遷移

```txt
Start → MainGame
Back → Title
```

## MVP判断

Prototype 1〜3では省略可能。

## 合格条件

```txt
[ ] キャラ差が短文で分かる
[ ] 長い説明を読ませない
[ ] キャラが1人でも後で増やせる
```

---

# 4. MainGame画面

## 役割

```txt
プレイ本体
```

## 常時表示項目

優先度順。

```txt
残り時間
HP
Lv
必殺技ボタン/ゲージ
武器/パッシブ簡易表示
```

## 表示しない/控えるもの

```txt
長い説明文
図鑑文
詳細ステータス
大量の通知
```

## 操作

```txt
仮想スティックで移動
必殺技ボタンをタップ
ポーズボタンをタップ
```

攻撃は自動。

## イベント

```txt
敵スポーン
自動攻撃
欠片取得
レベルアップ
カプセル取得
必殺技
被弾
クリア
ゲームオーバー
```

## 遷移

```txt
XP満タン → LevelUpOverlay
カプセル取得 → CapsuleOverlay
ポーズ → PauseOverlay
8分到達 → Result clear
HP0 → Result gameOver
```

## 合格条件

```txt
[ ] 自キャラが見える
[ ] 敵が見える
[ ] 欠片が見える
[ ] HP/残り時間が分かる
[ ] 必殺技が押せる
[ ] 戦闘中の文字が多すぎない
```

---

# 5. LevelUpOverlay

## 役割

```txt
プレイヤーに成長選択をさせる
```

## 表示項目

```txt
記憶が少し戻った
3択カード
ひとつ選ぶ
```

## カード項目

```txt
名前
新規/強化
効果
裏ストーリー1行
```

## 操作

```txt
カード全体をタップ
```

## 選択後

```txt
効果反映
Overlayを閉じる
ゲーム再開
```

## MVPルール

```txt
3択固定
キャンセルなし
リロールなし
スキップなし
```

## 合格条件

```txt
[ ] 3択がスマホで読める
[ ] カード全体を押せる
[ ] 効果が一目で分かる
[ ] 裏文を読まなくても選べる
```

---

# 6. CapsuleOverlay

## 役割

```txt
記憶カプセルの報酬を見せる
武器進化/強化の快感を出す
```

## 表示項目

通常強化:

```txt
道具が少し戻った
報酬名
効果
```

進化:

```txt
記憶がつながった
進化名
裏ストーリー1行
```

## 操作

MVPでは自動で閉じる。

```txt
0.8〜1.2秒表示
```

必要ならタップで早送り。

## 遷移

```txt
表示終了 → MainGame
```

## 合格条件

```txt
[ ] 何を得たか分かる
[ ] 進化が通常強化より特別に見える
[ ] 演出が長すぎない
[ ] スマホで読める
```

---

# 7. PauseOverlay

## 役割

```txt
プレイ一時停止
中断復帰
設定確認
```

## 表示項目

```txt
一時停止
再開
タイトルへ戻る
設定
```

MVP最小:

```txt
再開
タイトルへ戻る
```

## 操作

```txt
再開をタップ
タイトルへ戻るをタップ
```

## 注意

非アクティブ復帰時は必ずPauseOverlayにする。

即再開しない。

## 合格条件

```txt
[ ] 復帰直後に被弾しない
[ ] 再開ボタンが押しやすい
[ ] 誤ってタイトルに戻りにくい
```

---

# 8. Result画面

## 役割

```txt
プレイ結果を見せる
報酬を保存する
次のプレイ動機を作る
```

## 表示項目

優先度順。

```txt
朝まで残った / 夜に飲まれた
生存時間
倒した影
集めた欠片
到達Lv
進化武器
新発見
次の目標
裏ストーリー1行
```

## ボタン

MVP:

```txt
もう一度
タイトルへ
```

MVP後:

```txt
強化へ
図鑑へ
```

## 裏ストーリー1行例

```txt
朝になった。けれど、消えなかった影がひとつある。
```

## 合格条件

```txt
[ ] 勝敗が分かる
[ ] 数字の達成感がある
[ ] 次の目標が分かる
[ ] もう一度ボタンが押しやすい
[ ] 情報が詰まりすぎていない
```

---

# 9. Codex画面

## 役割

```txt
敵/アイテム/武器/実績の情報を見る
裏ストーリー断片を読む
```

## MVP判断

Prototype 1〜3では詳細画面は後回し。

最小通知だけでよい。

## MVP後表示項目

```txt
敵図鑑
アイテム図鑑
武器図鑑
実績
```

## 合格条件

```txt
[ ] 収集状況が分かる
[ ] 文が短く読みやすい
[ ] 裏ストーリーが説明しすぎていない
```

---

# 10. PowerUp画面

## 役割

```txt
永続強化を行う
継続プレイの理由を作る
```

## MVP判断

Prototype 5で実装。

Prototype 1〜3では後回し。

## 表示項目

```txt
所持記憶片
強化一覧
現在Lv
次Lv効果
コスト
購入ボタン
```

## 合格条件

```txt
[ ] 強化効果が分かる
[ ] コストが分かる
[ ] 強化しすぎでゲームが壊れない
```

---

# 11. Settings画面

## 役割

```txt
スマホ/アクセシビリティ設定
```

## MVP項目

```txt
sound on/off
screenShake on/off
damageNumbers on/off
autoUltimate on/off
```

## MVP後項目

```txt
textSize
highContrast
leftHandedMode
reducedEffects
```

## 合格条件

```txt
[ ] 設定が保存される
[ ] ゲーム中に反映される
[ ] 音なし/揺れなしでも遊べる
```

# 12. 画面優先度

## Prototype 1必須

```txt
Boot
MainGame
LevelUpOverlay
```

## Prototype 2必須

```txt
Result簡易
```

## Prototype 3必須

```txt
CapsuleOverlay
Result正式寄り
PauseOverlay
```

## Prototype 5以降

```txt
Codex
PowerUp
Settings
```

---

# 最重要方針

```txt
画面は増やしすぎない。
まずMainGameとLevelUpOverlayを気持ちよくする。
```

画面数より、1プレイの気持ちよさを優先する。

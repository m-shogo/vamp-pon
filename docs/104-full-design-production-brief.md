# Full Design Production Brief

## 目的

本格デザイン制作に入る時の制作指示を整理する。

Prototype 1では使わない。

本格デザインは、Prototype 3で8分体験が成立してから進める。

---

# 1. 開始条件

本格デザインへ進む条件:

- Stage 1相当の8分体験が成立
- 欠片回収が気持ちいい
- 進化が嬉しい
- 必殺技が使われる
- 背景がプレイを邪魔しない
- スマホで重くない

---

# 2. 採用方向

```txt
紙片・絵本風ドット
夜の街
黒インクの影
小さなランタン
光る記憶の欠片
紙カードUI
やさしい不穏さ
```

---

# 3. 本格制作する素材

## Character

- ユイ本番スプライト
- 歩行差分
- 被弾差分
- 欠片取得差分
- 勝利/失敗のリザルト差分

## Enemy

- 基本影
- 紙くず影
- ラベル影
- もや影
- 黒ラベルの影

## Pickups

- 記憶の欠片
- 大きい欠片
- 記憶カプセル

## UI

- HUD
- レベルアップカード
- カプセル画面
- リザルト
- 図鑑/実績の入口

## Background

- Stage 1背景
- 紙風床タイル
- 夜の街小物
- 黒インク汚れ

---

# 5. 視認性ルール

優先度:

1. ユイ
2. 敵
3. 欠片
4. 弾/攻撃
5. UI
6. 背景

背景が一番目立つなら失敗。

---

# 6. 工数を増やさないルール

- 1素材に描き込みすぎない
- 敵は黒インク系で統一
- 差分は形と目と輪郭で作る
- 背景小物は再利用可能にする
- UI枠は共通コンポーネント化する
- 本番前にサイズテストする

---

# 7. 量産テンプレ

## Enemyテンプレ

- 黒い本体
- 白い目
- 形の特徴
- 小さい追加モチーフ
- 1つだけ差別化ポイント

## Cardテンプレ

- 紙ベース
- アイコン
- 名前
- 2行説明
- レアリティ星

## Pickupテンプレ

- 中心光
- 外形
- 粒子
- サイズ差

---

# 8. NG方向

- 厚塗り寄り
- 3D化
- 過剰ホラー
- 全敵がかわいすぎる
- UI装飾過多
- 背景描き込み過多
- 通常敵全員HPバー

---

# 最重要

本格デザインは、面白さを作るものではなく、面白い核を伝わりやすくするもの。

核が弱いまま本格デザインに進まない。

# コアループ

## 1プレイの基本流れ

1. ステージ開始
2. 敵が少しずつ出る
3. プレイヤーは移動しながら自動攻撃で倒す
4. 経験値・回復・一時強化を拾う
5. レベルアップで強化を選ぶ
6. 5戦線のどこかに圧がかかる
7. 戦線の崩れを見て、次の強化や立ち回りを変える
8. 一定時間耐える、またはボスを倒す
9. リザルトで今回の敗因・成功要因を見る

## 時間帯別の体験

### 0〜3分: 気持ちよく倒す

目的:

- 操作に慣れる
- 敵を倒す快感を出す
- 戦線UIを見なくても何とかなる

やること:

- 敵は少なめ
- 近距離敵中心
- 強化は分かりやすいものだけ
- 派手な詰みは起こさない

### 3〜7分: 弱点が見え始める

目的:

- 戦線ごとの危険度を意識させる
- 敵タイプの違いを感じさせる
- 強化選択に軽い悩みを作る

やること:

- 左右どちらかに偏った湧き
- 遠距離敵の少量投入
- 突破型の敵を少量投入
- 戦線危険度UIを黄色にする場面を作る

### 7〜12分: ビルドの偏りが効く

目的:

- 過去の選択の影響を感じさせる
- ただ火力を上げるだけでは不安になる
- 弱い戦線を補修する価値を作る

やること:

- 複数方向から敵が来る
- 遠距離・魔法・突破型が混ざる
- 戦線ごとの崩壊リスクを明確化
- 回復・防御・支援の価値を上げる

### 終盤: 判断ミスが詰みに変わる

目的:

- 「今回はここを放置しすぎた」と分かる失敗を作る
- 勝った場合は「判断が噛み合った」と感じる
- 次もう一回やりたくなる

やること:

- 危険戦線が2つ以上になる
- 中央崩壊のリスクを出す
- ボスや大型敵で圧を作る
- 戦線ごとの敗因をリザルトに出す

## 気持ちよくなる瞬間

- 敵の群れが一気に溶ける
- 危険だった戦線を強化で立て直す
- ぎりぎりで中央を守り切る
- 苦手敵への対策が刺さる
- 弱かった武器が進化して一気に化ける

## 考える瞬間

- レベルアップ時の強化選択
- 危険戦線が複数あるとき
- 回復を拾いに行くか、戦線維持を優先するか
- 火力を伸ばすか、防御・支援を取るか
- 自分が弱い戦線に寄るか、中央を守るか

## 詰みが発生する条件

詰みは理不尽にしない。

良い詰み:

- 遠距離敵を放置しすぎた
- 左右どちらかの戦線強化が薄すぎた
- 範囲火力だけで単体火力が足りない
- 近距離処理だけ強く、魔法対策がない
- 中央を守る手段がない

悪い詰み:

- 画面外から即死
- 敵が多すぎて何が起きたか分からない
- 選択肢が悪すぎてどうしようもない
- UIが見づらく、危険が伝わらない

Characterの生活感を「家がある / 部屋がある」だけで終わらせず、**他人の空間へ入る時、誰かを迎える時、どこへ座り、何を分担し、どこをprivateとし、どう帰るか**まで持たせる。

## Hard boundaries

このReservoirから確定しない:
- exact home / household
- wealth / social class
- permanent seat
- marriage / cohabitation
- domestic role
- caregiver role
- exact house rule

禁止shortcut:
- hosting skill = wealth / class
- domestic labor = woman / mother
- heavy task = man / large body
- older adult = host / caretaker
- child = chore mascot
- guest etiquette = morality
- body size = space burden
- wheelchair = special side seat
- disability = caregiver-mediated presence
- Robot / Android = appliance / service staff
- dog / cat = party mascot / host entertainment
- regional origin = etiquette personality

> **shared space is relationship geometry, not social rank.**

## Shared chore

共同作業はCharacterの性格を出しやすいが、家事gender roleへしない。

Possible chores:
- dishes
- setting / clearing table
- moving object
- sorting shared materials
- route / shopping errand
- cleanup
- tool prep
- child-scale task
- animal care by Human household
- access setup

重要:

> **できる人が毎回やる = role固定** にしない。

得意な人でも断る / 教える / 任せる / 今日はやらないsceneを持てる。

## Private zone

Private zoneはphysical roomだけではない:
- drawer / bag
- phone / terminal / screen
- diary / notebook
- wardrobe
- body / wheelchair / medical or personal gear
- animal rest / food / litter area
- robot memory / logs
- unfinished work
- bedroom
- closed door
- conversation audience

`visible != public`
`accessible != permitted`

# Prototype 1 Issue Template

## 目的

Prototype 1 の実装タスクを GitHub Issue 化するためのテンプレート。

Prototype 1 の目的は以下のみ。

```txt
スマホ縦持ちで、移動・自動攻撃・欠片回収・初レベルアップが気持ちいいか確認する。
```

---

# Issue作成ルール

## タイトル形式

```txt
[P1-xx] タスク名
```

例:

```txt
[P1-03] 仮想スティック移動を実装する
```

## ラベル案

```txt
prototype-1
implementation
mobile
logic
qa
```

---

## [P1-00] プロジェクト起動確認

```md
## 目的

Vite + TypeScript + Phaser の最小起動を確認する。
```

# Ultimate Goal and First Principles

## 目的

Vamp Ponの最終目標を定義する。

Stage、キャラ、武器、物語、続編、コラボを考える前に、まずここを固定する。

---

# 1. 最後にプレイヤーへ残したい感情

Vamp Ponの最後に残したい感情はこれ。

```txt
自分は見られていないと思っていた。
でも、本当は小さなところまで誰かが見ていた。
夜は怖かったけど、朝はちゃんと来る。
```

一言で言うなら:

```txt
自分は消えていなかった、と分かる気持ちよさ。
```

---

# 2. 最終ゴール

ゲーム上の最終ゴール:

```txt
朝まで残る。
```

物語上の最終ゴール:

```txt
最後の空白ページに、名前と続きを書けるようになる。
```

感情上の最終ゴール:

```txt
過去は変わらない。
でも、過去の読み方が変わる。
```

IPとしての最終ゴール:

```txt
暗い入口から入っても、最後は前向きに着地する小さなゲームシリーズにする。
```

---

# 3. 最初から考えるべき問い

すべての仕様は、この問いに戻す。

```txt
これは、プレイヤーが「自分は消えていなかった」と感じる方向に働くか？
```

働かないなら、良い案でも外す。

---

# 4. Vamp Ponの4本柱

## 1. 気持ちいい

```txt
動く
倒す
拾う
強くなる
朝になる
```

まずゲームとして気持ちいいこと。

## 2. 見えない物語

```txt
説明しない
でも全部に意味がある
```

## 3. 仲の良さ

```txt
一人で戦っていると思っていた夜に、昔の仲間の手助けが残っていたと分かる
```

## 4. 前向きな反転

```txt
忘れられたと思っていた
でも、本当は残っていた
```

---

# 5. 採用する暗さ

採用する:

```txt
孤独
誤解
見られていない感覚
届かなかった言葉
渡せなかったもの
帰れなかった約束
自分の価値を読めなくなること
```

採用しない:

```txt
死の美化
救いのない真相
プレイヤーを沈ませるだけの物語
開発する気が失せる重さ
```

---

# 6. ハッピーエンドの定義

Vamp Ponのハッピーエンドは、全部元通りになることではない。

```txt
大切だったことを、もう一度大切だと読めるようになること。
```

最後はこういう感情にする。

```txt
寂しさはある。
でも、ちゃんと朝に向かえる。
```

---

# 7. 20人キャラ化の判断基準

キャラを増やす時は、この基準で見る。

```txt
そのキャラは、誰かの小さな手助けとして残るか？
そのキャラの役割は、ゲーム内の遊び方に変換できるか？
そのキャラの痛みは、最後に温かく反転できるか？
```

この3つを満たさないキャラは増やさない。

---

# 8. 続編/別テーマの判断基準

Vamp Pon 2や別テーマでも、以下は変えない。

```txt
失ったと思ったもの
本当は残っていた証拠
拾うことで強くなる
強くなるほど真実へ近づく
最後は前向きな反転
```

変えてよいもの:

```txt
記憶
夢
音
星
手紙
写真
約束
```

---

# 9. コラボ/IP展開の判断基準

暗いIPでも明るいIPでも、Vamp Ponに入れる時はこう変換する。

```txt
戦う → 払う
倒す → 戻す
呪い → 読めなくなった記憶
悲しみ → 残っていた証拠
キャラ能力 → その人の大切な道具
```

Vamp Pon側のトーンを壊さない。

---

# 10. 最重要

Vamp Ponは、暗い話をするゲームではない。

```txt
暗い夜を通って、朝を気持ちよく迎えるゲーム。
```

全ての仕様はここへ戻す。

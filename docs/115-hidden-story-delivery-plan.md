# Hidden Story Delivery Plan

## 目的

Vamp Ponの深層ストーリーを、基本的に見せないまま伝える。

長い会話や説明ではなく、遊びの中で少しずつ意味が反転する構造にする。

---

# 1. 基本方針

ストーリーは前に出さない。

前に出すのはゲーム体験。

```txt
移動
影を払う
欠片を拾う
強くなる
朝まで残る
```

ストーリーは、その行動の意味として後から分かる。

---

# 2. 出してよい媒体

使う:

- アイテム説明
- 武器説明
- パッシブ説明
- 敵図鑑
- カプセル文
- リザルト一文
- 実績名
- ステージ名
- 背景小物

使わない:

- 長いカットシーン
- 長い会話
- 強制チュートリアル物語
- 真相の直接説明

---

# 3. 断片の出し方

## Stage 1

表向き:

```txt
忘れ物を拾う夜
```

裏:

```txt
誰かと帰る約束の断片
```

出す文例:

```txt
古い切符: 帰り道だけが、なぜか思い出せない。
黒ラベルの影: 名前を貼られなかった記憶のかたまり。
リザルト: 朝になった。まだ、誰かを待っている気がした。
```

---

## Stage 2

表向き:

```txt
通学路の紙片
```

裏:

```txt
誰かが一緒に歩いていた証拠
```

出す文例:

```txt
紙くずの影: 捨てたつもりのないメモ。
古い名札: 呼ばれなかったと思っていた名前。
リザルト: 足音は、ひとつではなかった。
```

---

## Stage 3

表向き:

```txt
黒インクの図書室
```

裏:

```txt
2人で地図帳を作っていた
```

出す文例:

```txt
月のしおり: 読めないページにも、しおりは残っていた。
黒インクの小瓶: 消したかったのではない。読めなかっただけ。
リザルト: 地図の端に、小さな名前があった。
```

---

## Stage 4

表向き:

```txt
迷子の駅
```

裏:

```txt
片方だけ帰れなかったと思っていた
```

出す文例:

```txt
古い切符: 行き先より、帰る相手が大事だった。
迷子の方角: どこへ行くかではなく、誰と帰るか。
リザルト: ホームの灯りは、ずっと消えていなかった。
```

---

## Stage 5

表向き:

```txt
朝を忘れた地図帳
```

裏:

```txt
ユイが忘れることを選んだ理由
```

出す文例:

```txt
最後の空白ページ: ここから先は、ふたりで描くはずだった。
消えない名前: 呼べなかった名前が、朝の中で読めた。
リザルト: 朝になった。名前は、もう消えなかった。
```

---

# 4. 敵の嫌な記憶

敵は悪ではない。

敵は、嫌なことがあって読めなくなった記憶。

## 敵ごとの感情

### インクの影

感情:

```txt
自分なんて見られていない
```

反転:

```txt
小さな癖まで覚えていた人がいた
```

### 紙くずの影

感情:

```txt
言葉は届かなかった
```

反転:

```txt
捨てられたと思った紙片は、実は拾われていた
```

### 迷子の方角

感情:

```txt
帰り道が分からない
```

反転:

```txt
帰る場所ではなく、帰る相手があった
```

### 黒ラベルの影

感情:

```txt
名前を貼られなかった
```

反転:

```txt
名前を忘れたくなくて、貼れなかった
```

### 夜のもや

感情:

```txt
思い出すのが怖い
```

反転:

```txt
怖い記憶の中にも、守られたものがある
```

---

# 5. 反転の順番

## Phase 1

プレイヤーの理解:

```txt
敵を倒して経験値を拾るゲーム
```

## Phase 2

理解が変わる:

```txt
欠片は記憶らしい
```

## Phase 3

さらに変わる:

```txt
敵は悪ではなく、読めなくなった記憶らしい
```

## Phase 4

核心へ近づく:

```txt
ユイ自身が何かを忘れている
```

## Phase 5

最後の反転:

```txt
ユイは忘れたのではなく、守るために分けた
```

---

# 6. ハッピーエンドを壊さないために

暗い断片を出したら、必ず後で温かい反転を用意する。

悪い流れ:

```txt
つらい記憶だけ出す
救いがない
```

良い流れ:

```txt
つらい記憶
↓
見落としていた小さな優しさ
↓
本当は一人ではなかった
```

---

# 7. 実績名案

```txt
最初の欠片
まだ読める
帰り道の灯り
名前を呼ぶ準備
紙片は残っていた
朝の前の地図
消えない名前
```

---

# 8. 図鑑の書き方

図鑑は説明しすぎない。

悪い:

```txt
この敵はユイの過去の後悔が具現化したものです。
```

良い:

```txt
丸い影。近づくと、誰かの視線を探しているように見える。
```

---

# 9. 最重要

Vamp Ponの物語は、隠す。

でも、空っぽにはしない。

```txt
見せないが、全部に意味がある。
```

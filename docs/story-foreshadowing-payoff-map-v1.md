# ヨルノシルベ Main Mystery / Character Mystery Map v1

Date: 2026-07-28  
Status: **WORKING STORY MAP / USER DIRECTION — exact answers are not locked**

## 0. この資料の役割

ヨルノシルベの伏線を、次の2本に分けて管理する。

1. **MAIN MYSTERY — 世界・夜・物語そのものの謎**
2. **CHARACTER MYSTERY — 各人物の過去・関係・隠し事の謎**

二つは別物。ただし一部の手掛かりは交差してよい。

重要なのは、

> キャラ全員の秘密を解かないとメインストーリーが理解不能

にはしないこと。

逆に、

> メインストーリーだけ追えば人物のことは何も知らなくてよい

にもならない。

---

# 1. MAIN MYSTERY — 世界の謎

プレイヤー全員が本編を通じて追う太い謎。

現時点の問い候補:

- この「夜」は何なのか
- なぜ記憶が物や場所として残るのか
- 黒インクは何なのか
- なぜ星獣が存在するのか
- なぜ朝へ戻れない / 戻れる人がいるのか
- 誰がこの夜を作ったのか、それとも自然に生まれたのか
- 夜は人を閉じ込める場所なのか、誰かを救うための場所なのか
- なぜユイがランタンを持っているのか

## 本編1での扱い

ヨルノシルベ1単体で、プレイヤーが

> 「自分たちは何をして、なぜ朝へ戻れたのか」

を理解できる程度までは答える。

ただし世界全体の起源や「夜が一つだけなのか」など、上位の問いは2へ残せる。

## MAIN MYSTERYの続編フック

1のテーマを否定せず、1で答えたからこそ新しく生まれる問いを残す。

例:

- 朝へ持ち帰れないはずの黒紙が残る
- 別の夜を示す座標が見つかる
- 誰のものでもない星獣が写る
- ユイのランタンに用途不明の空き領域がある

---

# 2. CHARACTER MYSTERY — 人物の謎

人物ごとに持つ、小さくても感情に直結する謎。

これは「世界設定の説明係」ではなく、その人をもっと好きになるための謎。

例:

## ユイ

- なぜ記憶を分けたのか
- 本当に自分で分けたのか
- ランタンは誰から渡されたのか

## トモリ

- なぜユイのランタンの古い傷を知っているのか
- なぜユイと同じ獅子座なのか
- 血縁 / 継承 / 記憶火のどれなのか

## クロオリ

- なぜ「記憶を開くこと」をそこまで恐れるのか
- 過去に開いて壊してしまった記憶があるのか
- 一枚だけ開かない黒紙は誰のものなのか

## リツ / コヨリ

- 二人の記憶は本当に同じ時系列なのか
- なぜ「半分に残す」癖があるのか
- 兄妹のどちらが先に相手を覚えていたのか

## ゲン

- なぜ今は存在しない古い道を知っているのか
- 夜へ来たのは今回が初めてなのか

人物謎は今後21人分、Character Bookと対応させて育てる。

---

# 3. 二つの謎が交差する場所

交差は強い。ただし全員をMAIN MYSTERYの鍵にしない。

## 例1: ユイ × トモリ

CHARACTER MYSTERY:
> 二人はなぜ同じ獅子座なのか。

MAIN MYSTERYへの欠片:
> ランタンや記憶火そのものの由来へ繋がる可能性。

## 例2: クロオリ

CHARACTER MYSTERY:
> なぜ記憶を閉じるのか。

MAIN MYSTERYへの欠片:
> 夜のシステムは「記憶を戻す」ためだけの場所ではない可能性。

## 例3: ゲン

CHARACTER MYSTERY:
> なぜ古い道を知るのか。

MAIN MYSTERYへの欠片:
> 夜が今回だけ存在する世界ではない可能性。

このように、人物の秘密を知るとMAIN MYSTERYの見え方が深くなる。
しかし、その人物のBondを上げていなくても本編の核心は追えるようにする。

---

# 4. CHARACTER MYSTERYの見せ方

人物の謎は説明文一枚で開示しない。

使える場所:

- 日常会
- 一緒に戦った時のSupport台詞
- Bond上昇イベント
- 呼び方の変化
- 特定ペアの灯合わせ
- 星獣同士の反応
- 好きな食べ物 / 持ち物
- 部屋や持ち物の配置
- 黒耀化
- 朝エピローグ
- 灯録

初見では「その人らしい癖」に見えて、後で意味が変わるのが理想。

---

# 5. 回収タイミングを分ける

人物の謎を全員同時に終盤で説明しない。

- 序盤で解ける小さな謎
- Bond中盤で分かる秘密
- 本編終盤で意味が変わる謎
- クリア後の日常で初めて分かること
- 2まで全貌を伏せても本人の幸福を損なわない謎

を混ぜる。

これにより、キャラクターを知る順番がプレイヤーごとに少し変わる。

---

# 6. ハッピーエンドとの境界

未解決のCHARACTER MYSTERYがあっても、その人物を救いのない状態で放置しない。

良い例:

> トモリとユイの血縁の真相はまだ分からない。  
> でも二人は朝へ帰り、互いを大切な仲間として認識している。

悪い例:

> 真相が分からないので、その人物が生きているかも不明なまま終わる。

ヨルノシルベでは、**感情の決着と設定の全貌を分離できる。**

本人の心は救う。
謎の上位レイヤーは残してよい。

---

# 7. 考察ゲームとしての余白

ヤバタニエン的に参考にしたいのは、初見の人物像や小物の意味が後から再解釈される構造。

ヨルノシルベではバッドエンド収集ではなく、次で情報量を変える。

- Bondレベル
- 一緒に戦った回数
- 特定Support組み合わせ
- 日常イベント閲覧
- 灯録の収集
- 特定星獣同士の遭遇
- 特定Stageへの同行

つまり結末はハッピーエンドで共有しつつ、

> 「どこまで真相を知っているか」

にはプレイヤー差を作れる。

---

# 8. 一文で整理

> **MAIN MYSTERYは「この夜は何なのか」。CHARACTER MYSTERYは「この人はなぜこう生きているのか」。別々に追えて、時々一本につながる。**

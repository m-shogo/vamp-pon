## 2026-06-28 未回収XPの原因整理

### 現状

- XPは敵撃破時に `enemy.xpDrop` を最大5個までの記憶片へ分割して生成される。
- XP量は `GAME_FEEL_CONFIG.expGemValueScale` で抑えられているが、表示上は1撃破で複数の記憶片が残る場合がある。
- XP吸引は `PICKUP.magnetRange * player.magnetMultiplier` の距離内に入った時点で開始する。ユイ初期値では `95 * 1.15`。
- 吸引速度は `PICKUP.magnetSpeed` 固定で、プレイヤー近距離に入ってからの加速はない。
- 画面上のXP merge、時間経過fade、遠距離自動回収はない。未回収XPは拾うまで残り続ける。
- `gold_compass` と恒久強化 `magnet` は吸引範囲を伸ばす導線だが、通常run序盤の足元ノイズを直接消すものではない。

### 原因分類

- XP発生量が多い問題: 敵撃破数と後半密度に応じて表示個数が増える。今回はXPカーブとドロップ量を触らない。
- XP吸引開始距離が短い問題: 初期吸引範囲外のXPは残る。範囲を広げるとレベルアップ速度への影響が大きいため今回は保留。
- XP吸引速度が遅い問題: 近距離まで入ったXPの回収テンポがやや遅く、足元に残って情報量になりやすい。
- 敵密度が上がって拾いに行きにくい問題: 後半は回避優先になり、画面端や敵群の裏にXPが残りやすい。
- 画面上でXPが目立ちすぎる問題: 記憶片は読みやすい一方、数が増えると敵足元と競合する。
- 未回収XPが残り続ける問題: 消滅、merge、遠距離回収の仕組みがないため、取り逃しは蓄積する。
- 拾得導線不足: 近くのXPが吸い込まれる気持ちよさは出てきたが、後半の密度では回収リズムがまだ弱い。

### 優先度

- P0: 近距離XPの吸引速度を少しだけ上げる。XP量、ドロップ、XPカーブ、遠距離回収に触れず、足元の滞留だけを減らせる。
- P1: 吸引範囲、XP表示alpha、密集時の見た目抑制、`gold_compass` の体感価値をまとめてバランス調整する。
- P2: XP merge、時間経過fade、画面外/遠距離XPの扱い、Unity移行後の拾得導線再設計。

### 今回選ぶ最小改善

- 案B: 近距離XPの吸引速度を少しだけ上げる。
- 理由: XP発生量、レベルアップ曲線、遠距離XPの回収可否を変えず、プレイヤー周辺の情報量だけを軽く掃除できるため。
- 実装: 吸引範囲の内側55%まで近づいたXPだけ、吸引速度を1.18倍にする。吸引開始距離、XP量、ドロップ量、候補生成は変更しない。

### 390 x 844 確認

- 通常runを160.8秒まで進行し、Lv8、kills 368、取得済み記憶片163まで確認した。
- Lv2は29.5秒、Lv3は40.3秒、Lv8は140.6秒で到達した。近距離吸引テンポを上げても、レベルアップ速度が急激に早くなる挙動は見えない。
- 近くまで来たXPは足元で滞留しにくくなった一方、吸引範囲外や敵群の裏に残ったXPは引き続き残る。これは今回のP0では触らず、P1/P2に残す。
- 通常run中の `pendingChoices` に `dawn_ticket` は出なかった。
- dawn_ticket QAではK入力後に `status=playing`、HP36/118、`rareItems=[]` へ戻ることを確認した。

## 2026-06-28 XP滞留の追加原因整理

### 追加計測

- debug snapshot に `activeXpPickups`、`attractingXpPickups`、`nearbyXpPickups`、`farXpPickups`、`collectedFragments` を追加した。
- これは `debug=true` または `playtest=true` の確認導線だけで見る値で、通常runの生成、回収、XP量、ドロップ量には影響しない。

### 具体化した原因

1. 吸引範囲外に残るXP: 吸引開始距離外の記憶片は、プレイヤーが近づくまでその場に残る。
2. 敵群の裏に隠れるXP: 後半は敵密度が上がり、敵の足元や進路の裏に記憶片が残るため、拾いに行く判断が難しくなる。
3. 足元近距離で滞留するXP: 近距離吸引速度1.18倍で軽く改善済み。ただし敵密度が高い時は、足元の短い滞留も情報量になる。
4. XPが背景/敵/プレイヤーと競合する問題: Stage1背景の紙片や暖色光と、未回収XPの星形/発光が重なる場面がある。
5. 回収テンポは改善したが、画面上の情報量は残る問題: 近距離吸引は回収感に効く一方、遠い未吸引XPの表示密度はそのまま残る。
6. 残すべきXPと控えめにしてよいXPの境界: 近距離、吸引中、回収直前のXPは目立たせる。遠く、未吸引で、画面内XP数が多い時のXPは見た目だけ少し控えめにしてよい。

### 優先度

- P0: debug snapshotで滞留数を確認できるようにし、XPが多い時だけ遠い未吸引XPの見た目を軽く抑える。
- P1: 吸引範囲、吸引速度、`gold_compass` の価値、低HP時の回収導線を一体で調整する。
- P2: Magnet系アイテム、XP merge、回収アイテム、画面外XPの扱い、Unity移行後の拾得導線再設計。

### 今回選ぶ最小改善

- 候補B: 画面上XP数が一定以上の時だけ、遠い未吸引XPのalpha/scaleを少し控えめにする。
- 理由: XP量、ドロップ量、XPカーブ、吸引開始距離を触らず、情報量が増えた場面だけ見た目を整理できるため。
- 維持すること: 近距離XP吸引速度1.18倍、XP吸収演出、LvUp到達演出、dawn_ticketの通常run除外。
- 実装: active XPが70個以上の時だけ遠い未吸引XPをalpha 0.76/scale 0.66へ、120個以上の時はalpha 0.64/scale 0.62へ抑える。近距離、吸引中、生成直後130msのXPは目立たせる。

### 390 x 844 確認

- 通常runを146.8秒まで進行し、Lv8、kills 336、取得済み記憶片164、active XP 188、far XP 187まで確認した。
- active XPが70を超えた後も、遠いXPは薄くなりすぎず存在を読める。敵、HUD、プレイヤー、操作UIの可読性も維持されている。
- XP吸収中と近距離XPは従来通り目立ち、XP吸収の気持ちよさは落ちていない。
- Lv2は28.8秒、Lv3は36.2秒、Lv8は117.1秒で到達した。選択内容とランダム差の影響はあるが、XP量や吸引開始距離を変えていないため、レベルアップ速度を直接押し上げる変更ではない。
- 通常run中の `pendingChoices` に `dawn_ticket` は出なかった。
- dawn_ticket QAではHP1の低HPパルス、K入力後の `status=playing`、HP36/118、`rareItems=[]` を確認した。復帰後の画面端パルスは邪魔にならない。
- `generateChoices()` と `applyChoice()` の `role === 'awakening_material'` ゲートは維持されている。

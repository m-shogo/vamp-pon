# Stage1 battle feel review 2026-06-28

## 確認範囲

- 390 x 844 viewport の通常run: `/?debug=true&playtest=true&play=1`
- 390 x 844 viewport の拾得物/UIギャラリー: `/?scene=visual-gallery` 3/10
- 390 x 844 viewport の夜明けの切符復帰QA: `/?qa=dawn-ticket-revival&debug=true&playtest=true&play=1`
- コード経路: `generateChoices()` と `applyChoice()` のレア候補ゲート

## P0

- 通常runの開始状態は `rareItems` が空で、夜明けの切符はQA専用開始アイテムに留まっている。
- `dawn_ticket` は `role: 'survival_revival'` のため、通常レベルアップ候補と古いrare選択肢適用から除外されている。
- 夜明けの切符復帰QAでは致死入力後にHPが復帰し、runが `playing` のまま継続する。

## P1

- XP吸収の着弾フィードバックはあるが、390 x 844 では小さく、連続回収時の「集まった」感がやや弱い。
- 拾得物/UIギャラリーのカードは全体として読めるが、小さな種別ラベルがタイトル近くに重なり気味で、今後カード文言が長いと窮屈になりやすい。
- 通常runのHUDとレア枠は成立しているが、QA用の `Dawn` 表示が強いため、通常runで混入したと誤認しない確認導線は残したい。

## P2

- 低HP状態の警告は背景色と馴染む場面があるため、将来的に短い脈動や画面端の明滅を少し整理すると危機感が出る。
- 敵撃破、XP発生、XP吸収、レベルアップの連続がまだ均一に見える場面があるため、各ステップの明度と持続時間に差を付ける余地がある。
- Stage1背景は雰囲気が強い一方、暗部で小粒の演出が沈みやすい。小演出は暖色寄りの輪郭を持たせると読みやすい。

## 今回の小改善候補

- XP吸収時の光輪と粒子を少しだけ強める。
- 通常runの選択肢ゲートと dawn_ticket QA は触らない。

## 2026-06-28 追加確認

- 390 x 844 の通常runで、開始時 `rareItems=[]`、Lv2到達時の `pendingChoices` に `dawn_ticket` が含まれないことを確認した。
- b341d4b 後の横長カード小ラベルはタイトルから離れており、通常LvUpカードでは大きな重なりは見えない。
- 敵撃破とXP発生は短い破裂と記憶片のこぼれとして成立している。次に触るなら粒子量より、LvUp到達だけをXP吸収より一段明るくする方が戻しが少ない。

## 役割分担メモ

- 敵撃破: 黒インク、紙片、影がほどける短い破裂。
- XP発生: 小さな記憶片がこぼれる。控えめ。
- XP吸収: プレイヤーへ集まる暖色リング。
- LvUp到達: XP吸収より一段だけ特別な短い二段リングと上向きの光。カードとHUDを邪魔しない。

# 178. Special Cut-in Direction

This document defines special move cut-ins for Vamp Pon.

## Goal

A cut-in should show:

- character face
- light vessel
- shirushi crest
- release name
- normal or distorted state

## Timing

Use a short cut-in.

```txt
0.6s to 1.2s
```

## P1 structure

1. brief screen darken
2. face or bust crop
3. vessel close-up or icon
4. crest behind the character
5. release name text
6. flash
7. attack starts

## Text format

Normal release:

```txt
灯火紋
『朝をほどく灯』
```

Distorted release:

```txt
歪み紋・灯火
『黒火の灯』
```

## Normal visual rules

- crest is open and readable
- glow is clean or warm
- text is stable
- expression is focused
- vessel and crest agree visually

## Distorted visual rules

- same layout as normal release
- crest is cracked or ink-stained
- glow is too dense or overheated
- text can look chipped
- expression is strained, not simply evil

## Mechanical message

Distorted release should feel strong but wrong.

The player should understand:

```txt
This power works, but the reading is wrong.
```

## P1 target

Required first:

- Yui normal cut-in direction
- Yui distorted cut-in direction
- placeholder cut-in text for Core 5

Deferred:

- full animation for all characters
- full Future character cut-ins
- full fusion cut-in system

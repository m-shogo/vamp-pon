# Unity U33 Weapon / Passive / Evolution Review

## 変更

- BasicWeaponCooldownMs: `900` から `880`。
- BasicWeaponDamage: `12` から `13`。
- EvolutionEarliestSeconds: `210` から `195`。

## 対象

夜の鉛筆、紙飛行機、北極星のランタン、黒インク小瓶、街灯の輪に相当するStage1 draft候補は、現行の`spirit_lantern`、`paper_fan`、`seal_orbit`、`move_speed`、`pickup_range`、`damage_guard`の枠内で扱う。新武器大量追加はしない。

## 体験意図

初期武器が弱すぎず、攻撃頻度が遅すぎず、Lv3〜Lv5で強化した実感が出る。Evolution条件は本番確定ではなく、テストしやすい到達性へ寄せる。

## Guard

EvolutionRequiredWeaponLevel 5、EvolutionRequiredPassive pickup_range、material hookは維持。進化後の旧候補guardはU33で壊していない。

## U35確認

候補の出現偏り、owned upgrade weight、passiveの存在感、evolution candidate visibility。

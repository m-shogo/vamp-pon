# 3. Historical difference

人物のEra差は、星そのものを別宇宙へ変えるのではなく:

- historical constellation
- obsolete constellation
- historical atlas
- asterism
- Japanese / Chinese traditional sky division
- old / revised Japanese terminology
- cultural star name
- proper name / catalog designation

の**知識差 / 結び方差 / 呼称差**として出す。

同じ星を見ても別の線・別の名前・別の物語で認識できる。

# 5. Historical motifs approved for development

以下は**史実ベースHigh-Value Candidate**として優先研究 / story integrationしてよい。

## Quadrans Muralis / 壁面四分儀座

- 1795 creation。
- 現代88には不採用。
- しぶんぎ座流星群に名前が残る。
- 2025 IAU star name `Quadrans`採用。

Motif:
**形が消えても名前は残り、後世に別の形で戻れる。**

## Argo Navis / アルゴ座

旧一星座 → 現代:
- Carina
- Puppis
- Vela

Motif:
**一つのoriginから複数identityへ分かれる。**

## Serpens / へび座

一つの正式星座なのに:
- Caput
- Cauda

の離れた二領域に分かれる。

Motif:
**離れていても一つであり得る。**

## Libra / Scorpius claw trace

現在Libraの星名にScorpiusのclawだったhistorical meaningが残る。

Motif:
**所属が変わっても旧所属の痕跡が名前に残る。**

## Antinous

1825 historical chartで独立figureとして確認可能。
2024 IAUがθ Aquilaeへformal star name `Antinous`を採用。

Motif:
**図から消えた名前が星へ戻る。**

## Japanese 28 lunar mansions / 二十八宿

Edo historical sky mapsで現代Western constellationとは異なるstar groupingを確認できる。

Motif:
**同じ空でも文化 / 時代で結び方が違う。**

## Subaru / Pleiades / multiple identifiers

同一objectに複数のvalid names / systemsが共存。

Motif:
**名前が違う = 別物、ではない。**

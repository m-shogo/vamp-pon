# Feel QA Checklist

## 目的

Vamp Ponが気持ちよく遊べるかを確認するためのQA表。

通常のバグ確認とは別に、手触りを確認する。

---

# 1. Prototype 1 Feel QA

## 移動

- [ ] 指を置いた瞬間に動く
- [ ] 方向転換が遅れない
- [ ] 止まりたい時に止まる
- [ ] 敵を避ける感覚がある
- [ ] スマホで指が邪魔すぎない

## 自動攻撃

- [ ] 敵に向かって撃っていると分かる
- [ ] 最初の敵を10秒以内に倒せる
- [ ] 当たったことが分かる
- [ ] 敵を倒したことが分かる

## 欠片回収

- [ ] 欠片が見える
- [ ] 拾いたくなる
- [ ] 近づくと寄ってくる
- [ ] 取得時に気持ちいい
- [ ] XPが増えたと分かる

## レベルアップ

- [ ] 60秒以内にLv2になる
- [ ] Lv2になったことが分かる
- [ ] 少し強くなった気がする
- [ ] ゲーム停止が不自然ではない

## 画面

- [ ] 背景が邪魔しない
- [ ] 敵が見える
- [ ] 欠片が見える
- [ ] HUDが読める
- [ ] 画面がうるさすぎない

---

# 2. Prototype 2 Feel QA

## 武器差

- [ ] 夜の鉛筆は基本武器だと分かる
- [ ] ビー玉は反射だと分かる
- [ ] 月のしおりは周囲防御だと分かる
- [ ] 黒インクの小瓶は範囲攻撃だと分かる
- [ ] 星くず弾はばらまきだと分かる

## 選択

- [ ] 3択カードが読める
- [ ] 効果が2行以内で分かる
- [ ] 何を選んだか覚えていられる
- [ ] 選んだ後に見た目/手触りが変わる

## 成長

- [ ] 3分時点で強くなった感がある
- [ ] 5分時点でビルド差がある
- [ ] パッシブが空気ではない

---

# 3. Prototype 3 / MVP Feel QA

## カプセル

- [ ] 黒ラベルの影を倒したくなる
- [ ] カプセルが落ちたと分かる
- [ ] 取得が嬉しい
- [ ] 演出が長すぎない

## 進化

- [ ] 進化条件が分かる
- [ ] 進化した瞬間が嬉しい
- [ ] 進化後の攻撃が明確に強い
- [ ] リザルトで進化が記録される

## 必殺技

- [ ] いつ使えるか分かる
- [ ] 押した瞬間に反応する
- [ ] ピンチを救える
- [ ] 欠片回収が気持ちいい
- [ ] 8分で2〜4回使いたくなる

## 8分体験

- [ ] 3分に山がある
- [ ] 5分に山がある
- [ ] 7分に山がある
- [ ] 終盤が盛り上がる
- [ ] もう一度遊びたい

---

# 4. No-Go Feel

以下なら次へ進まない。

- 動かして気持ちよくない
- 敵を倒して気持ちよくない
- 欠片を拾って気持ちよくない
- 強くなった感がない
- 画面が見づらい
- エフェクトが邪魔
- スマホで疲れる

---

# 最重要

Vamp Ponは、数値が正しくても手触りが弱ければ失敗。

```txt
遊びの核は、触って気持ちいいかで判断する。
```

# QAチェックリスト

## 目的

Vamp Pon のプロトタイプ/MVPを確認する時に、何を見るべきかを統一する。

QAはバグ探しだけではない。

Vamp Ponでは以下も確認する。

```txt
操作感
スマホ適性
爽快感
成長感
視認性
パフォーマンス
アクセシビリティ
スコープ逸脱
```

# 13. 体験QA

数値だけでなく体験を見る。

```txt
[ ] 最初の30秒で何をするゲームか分かる
[ ] 1分以内に気持ちいい瞬間がある
[ ] 3分で報酬イベントがある
[ ] 5分で進化の期待がある
[ ] 7分以降に盛り上がる
[ ] 失敗しても次に試したいことがある
[ ] クリア後にもう一度遊びたい
```

## 最重要質問

```txt
仮素材でも、ユイで8分遊んで、もう一度遊びたいか？
```

この答えがNOなら、デザインではなくゲーム性を直す。

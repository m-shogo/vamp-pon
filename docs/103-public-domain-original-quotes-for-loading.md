# Public Domain Original Quotes for Loading

Vamp Pon / ヴァンサバ改のローディング、ステージ開始、キャラ選択、図鑑、PV字幕で使うための「原文引用候補」。

これは名言を飾りで入れる資料ではない。
キャラの中身、弱さ、灯り、黒耀、朝明、帰り道に合うものだけを選ぶ。

---

## 0. 商用・著作権ルール

```txt
翻訳文は使わない。
既存の日本語訳・現代語訳は使わない。
星の王子さま、現代小説、映画、漫画、歌詞、現代詩は画面表示に使わない。
画面に出す場合は、原文のまま短く出す。
最終商用前に法務/ライセンス確認する。
```

分類:

```txt
quote-safe-candidate: 古典・公有領域候補。原文短文のみ。
check-before-commercial: 念のため最終確認。
inspiration-only: 画面に出さず、Vamp Pon文へ変換するだけ。
```

## 1. 星の王子さまの扱い

`星の王子さま / Le Petit Prince` は世界観の方向性として非常に合う。

合う理由:

```txt
小さな星
子どもの目線
見えない大切さ
孤独
帰る場所
一見かわいいが寂しい
短い言葉に余白がある
```

ただし、商用ゲーム内に直接引用しない。
既存日本語訳も使わない。
英語訳やフランス語原文も、最終商用では避ける。

Vamp Ponで受け取る思想:

```txt
目に見えないものを、灯りで探す。
小さな星にも、帰れない夜がある。
大切なものほど、なくしたあとで光る。
```

画面用のVamp Pon文:

```txt
見えないものほど、夜に残る。
```

```txt
小さな星にも、帰れない夜がある。
```

```txt
なくしたあとで、光りはじめるものがある。
```

## 2. ローディング表示ルール

読む前に消えると、雰囲気ではなくノイズになる。

```txt
最短表示: 2.8秒
推奨表示: 3.5〜5.0秒
長文: 5.5〜7.0秒
スキップ可能: 1.2秒後から
```

```txt
ローディング: 18〜34字程度
ステージ開始: 10〜24字程度
キャラ選択: 20〜42字程度
引用元表記を出すなら小さく下部
同じ文は連続表示しない
1プレイ中の同一文は原則1回まで
```

## 6. 実装時の注意

1. まずは `quote-safe-candidate` だけ使う。
2. `inspiration-only` は画面に出さない。
3. 星の王子さまは引用しない。思想だけ。
4. キャラ別引用は、そのキャラの図鑑/選択/ロードでだけ出す。
5. 汎用ロードでは同じ作者が続かないようにする。
6. 原文引用が作品より強くなりすぎる場合は、Vamp Ponオリジナル文に差し替える。
7. 最終商用前に、引用候補リストを別途ライセンス確認する。

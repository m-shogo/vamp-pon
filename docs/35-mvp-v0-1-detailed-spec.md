# MVP v0.1 詳細仕様

## 目的

このドキュメントは、Vamp Pon の MVP v0.1 を実装前に渡せる粒度まで具体化する。

対象:

```txt
1. MVPキャラ1〜2人の正式名
2. MVP武器5個のレベル別効果
3. MVPパッシブ5個の数値
4. 敵5種類のHP/速度/出現時間
5. 10分間のウェーブ表
6. レベルアップ候補抽選ルール
7. 記憶カプセル/進化条件
8. 永続強化の初期ラインナップ
9. 図鑑/実績のMVP文言
10. リザルト画面項目
```

## 設計前提

MVP v0.1 は、完成版ではなく「遊びの核を検証する版」。

優先順位:

```txt
1. 爽快感
2. 分かりやすさ
3. テンポ
4. 視認性
5. 成長の気持ちよさ
6. 裏ストーリー断片
7. 難しさ
```

難易度は優しめ。

初回プレイで5〜7分くらいまで行ける。
慣れると10分クリアできる。

数値は実装後に必ず調整する。

# 1. MVPキャラ1〜2人の正式名

## キャラA: ユイ

### 役割

```txt
初心者向け / 回収型 / 安定型
```

### 肩書き

```txt
忘れ物係
```

### 表の説明

```txt
夜のあいだ、忘れられた物を集めてまわる子。
```

### 裏の説明

ゲーム内では直接出さない。

```txt
名前を失った物を、もう一度呼び戻している。
```

### 初期武器

```txt
夜の鉛筆
```

### 必殺技

```txt
消えない名前
```

効果:

```txt
周囲の記憶の欠片を強く吸い寄せる。
同時に、近くの小型影へ小ダメージを与え、倒した影を追加欠片に変える。
```

初期数値:

```txt
範囲: 260px
ダメージ: 20
吸引時間: 2.2秒
クールタイム/ゲージ相当: 90秒に1回程度
```

### 固有パッシブ

```txt
記憶の欠片の吸引範囲 +15%
```

### 採用理由

- 初心者にやさしい
- 経験値回収が気持ちいい
- 裏ストーリーと一番噛み合う
- 最初の主人公に向いている

### リスク

- 吸引が強すぎると移動リスクが消える
- 初期キャラが便利すぎて他キャラを使う理由が減る

### 対策

- 攻撃性能は控えめ
- 必殺技は回収寄りで一掃しすぎない

## キャラB: ミチル

### 役割

```txt
中級者向け / 画面整理 / 攻撃型
```

### 肩書き

```txt
地図読み
```

### 表の説明

```txt
黒いインクで消えた道を、もう一度たどる子。
```

### 裏の説明

ゲーム内では直接出さない。

```txt
誰かの旅が終わった場所を探している。
```

### 初期武器

```txt
黒インクの小瓶
```

### 必殺技

```txt
黒インク払い
```

効果:

```txt
画面内の弱い影に中ダメージを与える。
黒インク床/危険エリアがある場合、数秒だけ消す。
```

初期数値:

```txt
範囲: 画面全体
小型敵ダメージ: 45
大型敵ダメージ: 20
黒インク消去: 4秒
クールタイム/ゲージ相当: 110秒に1回程度
```

### 固有パッシブ

```txt
武器の効果範囲 +8%
移動速度 -3%
```

### 採用理由

- 画面一掃の爽快感がある
- 地図帳テーマと合う
- 2人目としてキャラ差が分かりやすい

### リスク

- 一掃が強すぎると武器ビルドが薄くなる
- 黒インク床がMVPに未実装なら効果の一部が死ぬ

### 対策

- MVPでは黒インク消去効果は演出だけでもよい
- 小型敵に強く、大型敵には弱くする

## MVP最小判断

最初に1人だけなら、**ユイ**。

理由:

```txt
忘れ物/記憶/欠片/初心者向けの全部がつながる
```

2人入れるなら、ユイ + ミチル。

# 2. MVP武器5個のレベル別効果

## 共通ルール

MVP武器は各Lv.1〜Lv.5。

Vampire Survivors本家のようにLv.8まで作ると調整が重いので、MVPではLv.5にする。

正式版でLv.8へ拡張可能。

## 武器1: 夜の鉛筆

### 役割

```txt
基本直線弾 / 初期武器 / 分かりやすい
```

### 挙動

最も近い敵へ鉛筆弾を飛ばす。

### レベル別

| Lv | 効果 |
|---:|---|
| 1 | ダメージ12 / 弾数1 / クールタイム1.25秒 |
| 2 | ダメージ+4 |
| 3 | 弾数+1 |
| 4 | 貫通+1 |
| 5 | クールタイム-20% |

### 進化

```txt
夜の鉛筆 Lv.5 + 月明かりのしおり
→ 未完成の一行
```

### 進化後: 未完成の一行

効果:

```txt
近い敵へ白い線を飛ばす。
線は敵を貫通し、通った場所に短い残光ダメージを残す。
```

初期値:

```txt
ダメージ22
貫通3
残光ダメージ6/秒
```

# 5. 10分間のウェーブ表

## 方針

MVPは10分。

流れ:

```txt
0〜2分: 気持ちよく倒せる
2〜4分: 少し忙しくなる
4〜6分: ビルド差が出る
6〜8分: 圧が強くなる
8〜10分: 必殺技と進化で押し返す
```

## ウェーブ表

| 時間 | 出現敵 | 密度 | 目的 |
|---|---|---:|---|
| 0:00-0:30 | インクの影 | 低 | 操作確認 |
| 0:30-1:00 | インクの影 | 中 | 最初のレベルアップ |
| 1:00-1:30 | インクの影 | 中 | 3択選択に慣れる |
| 1:30-2:00 | インクの影 + 紙くずの影 | 中 | 速い敵の導入 |
| 2:00-2:30 | インクの影 + 紙くずの影 | 中高 | 移動を促す |
| 2:30-3:00 | 紙くず多め | 高 | 初ピンチ |
| 3:00 | 黒ラベルの影1 | 特殊 | 初カプセル機会 |
| 3:00-3:30 | インク + 迷子の方角 | 中 | 回り込み導入 |
| 3:30-4:30 | インク + 紙くず + 迷子 | 中高 | ビルド確認 |
| 4:30-5:30 | 黒いカプセル導入 | 中 | 硬い敵導入 |
| 5:30-6:00 | 黒いカプセル増加 | 中高 | 火力不足を感じる |
| 6:00 | 黒ラベルの影2 | 特殊 | 進化チャンス |
| 6:00-7:00 | 夜のもや導入 | 高 | 群れの圧力 |
| 7:00-8:00 | 全敵混合 | 高 | 必殺技を使わせる |
| 8:00-8:30 | 紙くず + 夜のもや多め | 高 | 速度圧 |
| 8:30-9:00 | 黒いカプセル + 迷子 | 高 | 火力/範囲チェック |
| 9:00 | 黒ラベルの影3 | 特殊 | 最後の報酬機会 |
| 9:00-9:40 | 全敵混合 | 最高 | クライマックス |
| 9:40-10:00 | 夜のもや大量 + インク | 最高 | 最後の押し込み |
| 10:00 | 朝 | 終了 | クリア |

## 出現方向

現方針:

```txt
基本は下から圧が来る
たまに中央/上からも来る
左右はMVPでは少なめ
```

ただし、完全に下だけだと単調になるため、時間帯で少し変える。

| 時間 | 主方向 |
|---|---|
| 0:00-2:00 | 下70% / 周囲30% |
| 2:00-5:00 | 下60% / 上20% / 周囲20% |
| 5:00-8:00 | 下50% / 周囲50% |
| 8:00-10:00 | 下40% / 周囲60% |

# 6. レベルアップ候補抽選ルール

## 基本

MVPは3択。

候補種類:

```txt
所持武器の強化
新武器
所持パッシブの強化
新パッシブ
回復
```

## 抽選優先度

### 通常時

```txt
所持武器強化: 35%
新武器: 20%
所持パッシブ強化: 25%
新パッシブ: 15%
回復: 5%
```

### HP 35%以下

```txt
所持武器強化: 30%
新武器: 15%
所持パッシブ強化: 20%
新パッシブ: 10%
回復: 25%
```

## 枠制限

```txt
武器枠: 4
パッシブ枠: 4
```

枠が埋まったら、新武器/新パッシブは出ない。

## MAX除外

Lv.5になった武器/パッシブは通常候補から除外。

ただし、進化条件を満たしている場合は、レベルアップではなく記憶カプセル側で進化する。

## 候補保証

同じ候補が3つ並ばないようにする。

```txt
最低1つは武器関連
最低1つはパッシブまたは回復
```

ただし候補プールが少ない場合は例外。

## リロール

MVPではリロールなし。

理由:

- UIが増える
- 永続強化と絡むと調整が重い

正式版で追加候補。

## スキップ

MVPではスキップなし。

理由:

- 初心者が混乱しやすい
- 報酬テンポを優先

# 7. 記憶カプセル/進化条件

## 記憶カプセルとは

Vamp Pon における宝箱。

表:

```txt
強敵を倒すと落ちる報酬箱
```

裏:

```txt
失くした記憶が入っている古いカプセル
```

## ドロップ元

```txt
黒ラベルの影
```

出現:

```txt
3:00
6:00
9:00
```

## カプセルの中身

優先順位:

```txt
1. 進化条件を満たす武器がある → 進化
2. Lv.MAXでない所持武器/パッシブをランダム強化
3. 全てMAXなら回復/欠片/通貨
```

## 進化条件 MVP

### 進化1: 未完成の一行

```txt
夜の鉛筆 Lv.5
+
月明かりのしおり 所持
+
記憶カプセル取得
```

効果:

```txt
直線貫通 + 残光ダメージ
```

裏説明:

```txt
書きかけのページほど、続きを急いでいる。
```

### 進化2: 北極星のランタン

```txt
星くず弾 Lv.5
+
金のコンパス 所持
+
記憶カプセル取得
```

効果:

```txt
範囲ダメージ + 欠片吸引
```

裏説明:

```txt
迷わないためではなく、迷ったことを忘れないための灯り。
```

## カプセル演出

MVPは短くする。

```txt
0.2秒停止
カプセルが開く
光が出る
報酬名表示
1行説明
すぐ戻る
```

長い宝箱演出は後回し。

## リスク

進化条件が分かりにくいと不満になる。

対策:

- 図鑑/武器詳細で「対応する忘れ物」を薄く表示
- ただし完全ネタバレはしない

# 8. 永続強化の初期ラインナップ

## 方針

永続強化は小さく。

プレイし続ける理由にはするが、強くなりすぎてゲームを壊さない。

## 通貨名

仮:

```txt
記憶片
```

ゲーム内説明:

```txt
夜に戻った記憶の小さな欠片。
```

## 初期強化 8種類

| 強化名 | 効果 | 1段階 | 最大Lv | 最大効果 |
|---|---|---:|---:|---:|
| 旅の支度 | 攻撃力 | +3% | 5 | +15% |
| 欠片あつめ | 吸引範囲 | +5% | 5 | +25% |
| 早足の切符 | 移動速度 | +2% | 5 | +10% |
| 夜の体力 | 最大HP | +5 | 5 | +25 |
| 書き残し | 経験値取得 | +3% | 5 | +15% |
| 手になじむ道具 | クールタイム | -2% | 5 | -10% |
| 朝待ち | 防御/被ダメ軽減 | -2% | 5 | -10% |
| 小さな幸運 | カプセル報酬補正 | +2% | 5 | +10% |

## コスト案

```txt
Lv1: 100
Lv2: 220
Lv3: 400
Lv4: 700
Lv5: 1100
```

MVPでは通貨獲得量を見ながら調整。

## 優先実装

最初は5種類だけでもよい。

```txt
攻撃力
吸引範囲
移動速度
最大HP
経験値取得
```

## リスク

- 永続強化が強すぎると初期難易度が崩れる
- 周回前提が強すぎると最初がつまらない

## 対策

- 最大値を低くする
- 1回の強化差は小さくする
- 未強化でも10分クリア可能にする

# 10. リザルト画面項目

## 目的

リザルトは、次のプレイ動機を作る画面。

数字の達成感 + 裏ストーリー断片 + アンロック確認を入れる。

## 表示項目

### 基本結果

```txt
生存時間
クリア/未クリア
使用キャラ
到達レベル
倒した影の数
集めた記憶の欠片
取得した記憶片通貨
```

### ビルド結果

```txt
使用武器一覧
各武器レベル
進化武器
パッシブ一覧
必殺技使用回数
```

### 収集結果

```txt
新しく見つけたアイテム
新しく登録された図鑑
開けた記憶カプセル数
獲得した実績
```

### 裏ストーリー断片

1プレイにつき1行だけ表示。

例:

```txt
「倒したはずの影は、少し温かかった。」
「黒いインクの下に、まだ道が残っている。」
「朝になった。けれど、消えなかった影がひとつある。」
```

## リザルトレイアウト案

```txt
[大きく]
朝まで残った / 夜に飲まれた

[中央]
生存時間 10:00
倒した影 842
集めた欠片 516
到達Lv 24

[ビルド]
武器 / パッシブ / 進化

[新発見]
図鑑 +2
実績 +1
記憶カプセル +1

[一言]
黒いインクの下に、まだ道が残っている。

[ボタン]
もう一度
強化へ
図鑑へ
タイトルへ
```

## リザルト評価

### ランクはMVPでは不要

S/A/B/C評価は気持ちいいが、プレイヤーを急かす。

MVPでは数字だけでよい。

### 次の目標提示

リザルト下部に次の小目標を1つ表示する。

例:

```txt
次: 夜の鉛筆をLv.5にする
次: 記憶カプセルをもう1つ開ける
次: ユイで10分生存する
```

## クリア時文言

```txt
朝まで残った
```

## 失敗時文言

```txt
夜に飲まれた
```

ただし、失敗を重くしすぎない。

失敗時の一言例:

```txt
まだ、戻せる名前がある。
```

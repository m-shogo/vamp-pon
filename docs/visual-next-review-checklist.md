# Visual Next Review Checklist

ビジュアルを実機/ブラウザで見たときに OK/NG を記録するチェックリスト。
確認は [visual-gallery.md](visual-gallery.md) のURLで。OK は `[x]`、NGは `[ ]` のまま理由を書く。

---

## 背景（?scene=visual-gallery ページ1 / ページ5）

- [ ] 紙質の夜に見える（真っ黒/グリッド/宇宙でない）
- [ ] プレイ領域（中央）が暗すぎず、敵/欠片が見える
- [ ] 縁の紙片・街灯・インク染みが主張しすぎない

## ユイ

- [ ] フード＋ランタンの小さな主人公に見える
- [ ] 暗い背景でも輪郭が読める
- [ ] ただの丸/ネオン輪郭になっていない

## 敵（ページ1 / ページ5）

- [ ] 6種のシルエットが見分けられる
- [ ] 白い目が見える
- [ ] 黒ラベルの影がエリートだと分かる
- [ ] 範囲攻撃の上でも敵が埋もれない

## 通常武器（ページ3）

- [ ] 8種が「意味」で区別できる
- [ ] 鉛筆/紙刃/紙ひこうきが紙に見える
- [ ] ビー玉がガラスに見える
- [ ] 街灯の輪が暖かい光（ネオンでない）
- [ ] ビーム/レーザー/ギラ星がない

## 進化後武器（ページ4）

- [ ] 未完成の一行が鉛筆の延長（ビームでない）
- [ ] 北極星のランタンが紙の灯り（派手な星でない）
- [ ] 通常攻撃中の弾でも「進化した」と分かる

## 合体（ページ4）

- [ ] 夜明けのインク灯が「インク＋街灯」の2モチーフに見える
- [ ] 魔法陣/ネオンリングになっていない
- [ ] ただの色違いでない

## 覚醒（ページ4）

- [ ] 4種それぞれにレアアイテムのモチーフが出ている（名前札/レンズ/封筒/風）
- [ ] 合体と覚醒が別物に見える
- [ ] 演出（演出を見る）が神秘的だが魔法陣でない

## UI（ページ2）

- [ ] HUDが情報過多でない、紙/木の枠に見える
- [ ] 欠片/回復/カプセルがそれぞれ別物に見える
- [ ] 回復が回復に見える（緑十字でない）
- [ ] カードのレア度が紙質・縁で分かる（★だけに頼らない）

## スマホ視認性（実機）

- [ ] 390x844相当で各ページが収まる
- [ ] 小さい弾/欠片がスマホでも見える
- [ ] 文字（カード/HUD/ラベル）が読める
- [ ] 大量の敵が出ても埋もれない（※ギャラリーでなく実プレイで）
- [ ] 動いている弾が見える（※実プレイで）

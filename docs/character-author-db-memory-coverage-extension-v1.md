## Hard boundaries

Memory coverage must not imply:

- memory accuracy = morality/reliability rank
- memory style = intelligence
- forgetting = trauma or diagnosis
- older age = memory decline
- machine-readable log = complete objective truth
- artificial person = perfect memory or lesser personhood
- data retention = love/personhood
- animal reaction = Human witness testimony
- differing recollection = automatic deception
- vivid dream image = factual Canon recollection

## Dream-world authority boundary

ヨルノシルベ can use dream imagery, reconstructed scenes, remembered dialogue, logs, photos, objects, and testimony as overlapping narrative evidence. This index keeps those representations discoverable without flattening them into one objective truth layer.

A Memory / Remembering anchor is therefore authoring material, not a Canon fact claim.

## No-flattening rules

- Current != Candidate != Author Reservoir != Open
- remembered-by-character != objectively-Canon
- vivid != true
- logged != complete
- forgotten != false
- Future15 coverage != Current21 promotion
- stable aliases remain navigation only
- runtime does not automatically consume or promote memory data

# Next-generation Sequel Architecture

## 目的

Vamp Pon 2以降で、前作キャラの子供世代を主人公にする可能性を整理する。

この案は、単なる世代交代や前作キャラのゲスト出演ではない。

狙いは以下。

```txt
1作目は単体で完結する
でもシリーズを追うと、前作の小物や違和感の意味が変わる
次世代主人公によって世界観を広げる
後付けできる余白を最初から確保する
```

---

# 1. 採用/保留/却下

## 採用

```txt
次世代主人公という構造
前作キャラが大人/親世代として出る構造
前作で解けた誤解が、次世代では別の形で再固定される構造
子供世代が、親世代の美談を疑う構造
```

## 保留

```txt
前作キャラ全員に子供がいる
子供全員が最初から重要キャラ
前作キャラ同士の結婚/恋愛結果を確定する
```

理由:

```txt
固定しすぎると、前作の恋愛/友情の余白を殺す。
```

## 却下

```txt
前作キャラをただの親世代ゲストにする
子供世代が親世代の能力をそのまま受け継ぐだけ
前作の感動を説明でなぞる
前作キャラのその後を全部確定する
```

---

# 2. 2の主人公候補

2の主人公は、前作キャラの“誰かの子”にしてよい。

ただし、最初から誰の子か明かさない。

```txt
表: 新しい主人公
裏: 前作の誰かとつながっている
後半: 親世代の小物に反応する理由が分かる
```

これにより、前作未プレイでも成立し、前作プレイ済みなら考察できる。

---

# 3. 子供世代でやるべき主題

親世代の主題:

```txt
間違った意味を、正しい持ち主に返す。
```

子供世代の主題:

```txt
正しい意味として語られたものを、もう一度疑う。
```

つまり2では、親世代が救ったはずの話が、子供世代には別の意味で見えている。

例:

```txt
親世代:
これは守るために閉じた箱だった。

子供世代:
でも、閉じたことで届かなかったものもある。
```

この構造なら、前作を否定せずに掘り返せる。

---

# 4. 前作キャラの出し方

前作キャラは、最初から全部出さない。

出し方の優先順位:

```txt
1. 小物
2. 筆跡
3. 口癖
4. 後ろ姿
5. 名前なしの大人
6. 後半で名前確定
```

前作キャラの役割:

```txt
答えを教える人ではない
子供世代にとっては、古い地図帳を作った側の人
時に正しく、時に隠している人
```

これが重要。

前作キャラが完全な賢者になると弱い。

---

# 5. 親世代と子供世代の対立

親世代:

```txt
あの時は、返すことが救いだった。
```

子供世代:

```txt
でも、返されたくなかったものもあるのでは？
届けなかったから守られた言葉もあるのでは？
```

対立は善悪ではない。

```txt
返すべきか
届けるべきか
隠すべきか
綴じたままにすべきか
```

この価値観のズレが、2以降の深さになる。

---

# 6. 後付け可能な余白設計

後付けできるようにするには、1で親子関係を確定しすぎない。

やるべきこと:

```txt
小物だけ残す
筆跡だけ残す
誰の子か分からないまま反応だけ見せる
親世代の恋愛結果を明言しない
家族/師弟/養子/継承/近所の子など複数解釈を残す
```

禁止:

```txt
全員の結婚相手を決める
全員の子供を最初から配置する
前作ラストで未来を説明する
```

これにより、後から自然に広げられる。

---

# 7. 子供世代の能力設計

親世代の能力をそのまま継がない。

親世代:

```txt
持ち主を間違えない
名前をつける
理由をしまう
場所を読む
灯す
```

子供世代:

```txt
持ち主を疑う
名前を外す
理由を開ける
場所をずらす
灯りを消して見る
```

これが良い。

親世代の反転版にすることで、2のゲーム性も変えられる。

---

# 8. 2の有力構造

## タイトル仮

```txt
Vamp Pon 2: 届かなかった手紙
```

## 主人公

```txt
親世代の誰かの子、または子供世代の継承者。
ただし序盤では出自を明かさない。
```

## 表の目的

```txt
届かなかった手紙を届け直す。
```

## 裏の目的

```txt
本当に届けるべきだったのかを疑う。
```

## 大反転

```txt
未配達の手紙は、失敗ではなかった。
届くと壊れる意味を守るために、誰かがあえて止めていた。
```

ただし、すべての手紙がそうではない。

```txt
届けるべき手紙
届けてはいけなかった手紙
届かないままでも残っていた手紙
```

を分ける。

---

# 9. 2で前作キャラを出す例

## ユイ

出し方:

```txt
名前を明かさず、落とし物の持ち主だけを当てる大人として出る。
```

役割:

```txt
子供世代に“持ち主を間違えないこと”の危うさを教える。
```

弱点:

```txt
持ち主が分かっても、返すべきとは限らない。
```

## アサ

出し方:

```txt
名前をつける癖のある大人として痕跡だけ出る。
```

役割:

```txt
名前を与えることの救いと暴力を両方見せる。
```

## ナギ

出し方:

```txt
箱を開けるなと言う大人として出る。
```

役割:

```txt
閉じることが守りだった前作と、閉じたままでは届かない2の対立を作る。
```

## ミチル

出し方:

```txt
道案内を拒む大人として出る。
```

役割:

```txt
道が分かっていても、行かせない選択があることを見せる。
```

## トモリ

出し方:

```txt
灯りを消す場面で出る。
```

役割:

```txt
灯すことだけが救いではないと示す。
```

# 10. 子供世代の物語の強さ

子供世代の良さは、親世代の物語を壊すことではない。

```txt
親世代が救った意味を、子供世代が別角度から読む。
```

これにより、1作目の感動は残る。

でも、2をやるとこうなる。

```txt
1では正しかった救いが、2では別の人にとって痛みだったと分かる。
```

この構造がシリーズの奥行きになる。

---

# 11. 注意点

## 危険1: 前作キャラを神格化する

親世代が全部正しいと、子供世代が弱くなる。

## 危険2: 前作を否定する

親世代の救いが全部間違いだった、にすると1が壊れる。

## 危険3: 家系図に寄りすぎる

誰と誰の子かが主題になると、Vamp Ponの小物/意味/黒インクの主題からズレる。

## 危険4: 子供世代が能力コピーになる

親の能力を継ぐだけだと退屈。

---

# 12. 一番良い使い方

2では、子供世代をこう使う。

```txt
親世代が“返して救った”世界で、
子供世代は“返さない方が守れるもの”に出会う。
```

これなら1の主題を壊さず、2の主題が立つ。

---

# 13. 最重要

次世代構造の本質はこれ。

```txt
前作の答えを否定しない。
でも、前作の答えだけでは救えないものを出す。
```

これができるなら、子供世代主人公は採用価値が高い。

# 2. Primary Parent-Child Candidate — ナギ → ユイ

Status: **PRIMARY HIGH-VALUE CANDIDATE / NOT CANON / HUMAN APPROVAL REQUIRED BEFORE LOCK**

## Why chronology works

ナギ:

- Reality Era = バブル崩壊後〜携帯Internet初期。
- Root = 宮城県仙台圏 Candidate。
- 首都圏へ進学 / early-career移動がCurrent Derived。

ユイ:

- Reality Era = 現代日本。
- Root = **東京都荒川区 / USER DECIDED**。

Therefore:

```txt
ナギが若い時代
↓
仙台圏から首都圏へ進学 / 就職
↓
後に東京で家庭を持つ可能性
↓
ユイが荒川区で育つ
```

は無理なく成立する。

Exact year / exact age gap / biological-parent・legal-parent・adoptive-parent等はFamily ReviewまでOpen。

## Theme inheritance

ナギのEra:

> 情報を開けることと、開けてよいことは違う。

ユイのEra:

> 何でも記録できることと、全部残すべきことは違う。

これは同じ悩みの再放送ではない。

```txt
early network privacy
↓ generation
record abundance / algorithm / misinformation
```

という**問題の世代変化**になる。

## Dream relationship before reveal

親子と知らない状態の方が重要。

Candidate texture:

- ユイはナギが何でも箱へしまうのを少しもどかしく感じる。
- ナギはユイが人の物や記録へすぐ意味を探しに行くのを危なっかしく感じる。
- 二人とも「本人に聞くべき」という場所では一致する。
- Partyでは同じ皿の食べ物を最後の一個だけ譲り合う等、説明しない似方を少量入れる。

顔を似せて即バレさせない。

## Normal Waking reversal

古いEraのナギがRealityへ戻る。

Explicit Dream memory:

- Yuiの名前を覚えない。
- 顔を覚えない。
- 「未来の自分の子」と認識したまま帰らない。

Residual candidate:

- 子どもの物を勝手に開ける前に一度聞く。
- 「残したくない物まで残さなくていい」と時々言う。
- 本人も出典を説明できない短いphraseが残る。

後に育ったYuiから見ると:

> 「親、昔から時々変な言い方するな」

くらい。

**認知症 / medical declineへ接続しない。**

## Season1 evidence

S1では答えを出さない。

候補:

1. YuiがReality memory fragmentで「家で昔から聞いた言葉」と同じphraseをNagiが言う。
2. 家族写真は人物が特定できない角度 / 年代だけ一致。
3. Nagiが荒川区そのものを未来知識として持ち帰ることは禁止。
4. Yuiの名前がDream memoryによって命名されたclosed loopにはしない。

## Season2 reveal

必要条件:

```txt
Dream relationship
+
Reality family evidence
+
Era chronology
+
Resolution Waking
```

が一致して初めてReveal。

Possible payoff:

> Yuiは「親が自分を全部理解していた」と知るのではない。
> **親も分からないまま、分からないなりに自分を守ろうとしていた**と知る。

逆にNagi側の間違いも残せる。

血縁だから全部許す、にはしない。

Bad:

> トモリの血を引いているからトウマも修理が上手い。

> トウマが職人を選んだのは本人の人生。
> 後から「昔の誰かも同じように直していた」と分かる。

Inheritance:

- talentではなく痕跡
- vocationではなく選べる材料

- 2 Seasons完結 → Late S2へ移動可能。

# 4. Non-blood inheritance — blood revealより多くする

## トモリ ↔ ユイ — Lantern Object Chain

Status: HIGH-VALUE CANDIDATE / **NON-BLOOD**

S1:

- トモリがYuiのランタンの古い修理方法へ反応。
- 「これ、俺が直した」と即断しない。
- screw / seam / wick holder等、複数Evidenceを積む。

S2:

- Reality側の修理記録 / 写真 / shop note等でhistoryが繋がる。

Meaning:

> 物は、持ち主が互いを知らなくても人を繋げる。

## ミチル ↔ ゲン — Place Chain

S1:

- 同じ道なのに二人の地図が違う。

S2:

- development / road / railway / housing changeのhistoryを回収。

Meaning:

> 場所は残っても、正しい道は時代で変わる。

## セン ↔ シロ — Knowledge Chain

S1:

- Shiroが著者不明noteを保存。
- Senは自分の文章とは気づかない / exact authorship未確定でもよい。

S2:

- Sen本人ではなく、**Senの教えを受けた誰かが後世へ書き直したnote**という多段継承Candidate。

Meaning:

> 教えはコピーされるほど変わる。それでも残るものがある。

## ユウビ ↔ トバリ — Institutional Chain

S1:

- 届かなかった手紙 / 旧住所 / gate rule。

S2:

- 後世の交通 / 配送 / access ruleが、昔の失敗への改善として作られたと分かる。
- その改善が別の人を締め出している可能性も描ける。

Meaning:

> 善意の改善も、次の時代では新しい問題になり得る。

## クロエ ↔ レンジ — Long-lived Mentor Chain

秘密血縁ではなく、時間差そのものを見せる。

- younger-looking師匠
- aging student
- roles evolve without erasing affection

## クウ / ヨモ — Animal Recognition Bridge

Animalはtruth detectorにしない。

- 匂い
- 歩き方
- 手の出し方
- 家の動線

へ反応するだけ。

人間が後からEvidenceを組み立てる。

# 6. Evidence grammar

Relation Revealには最低2種類以上のEvidenceを使う。

## Human residue

- phrase
- hand habit
- food preparation
- dialect register
- way of folding cloth
- route explanation

## Physical evidence

- photo
- letter
- tool
- repair seam
- map
- archive note
- family object

## Institutional evidence

- school record
- library accession
- postal route history
- old map revision
- workplace / civic ledger

**顔が似ているだけで確定しない。**

# 7. Satire / family generation use

血縁Revealの目的は感動だけではない。

親と子が別Eraなら:

- parentが「安全のため」と思った習慣
- childには「監視」に見える
- childの便利なtechnology
- parentには「自分から個人情報を配っている」に見える

等、同じ家族の中で社会風刺ができる。

重要:

> 親の時代が正しいわけでも、子の時代が進歩した正解でもない。

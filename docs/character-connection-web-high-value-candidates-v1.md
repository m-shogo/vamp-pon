# 1. Connectionの基本ルール候補

人間同士が同じ時代でなくても、以下は現実時間を順番に渡れる。

- ランタン
- 手紙
- 切符
- 本
- 地図
- 押し花
- 箱
- 修理跡
- 名前
- 家族の話

夜は別時代の人物同士を接続できる。

したがって:

```txt
人A（昔）
↓
物 / 記録 / 関係を残す
↓
現実時間が流れる
↓
人B（後世）が受け取る

しかし夜では A と B が直接会える
```

この構造を使うと、タイムトラベルで過去を改変せずに「時代を越えた出会い」ができる。

- トモリは修理 / 継火

> 「この継ぎ方、俺のだ。」

初見では不思議。
後から「二人は別時代だった」と分かる。

### 獅子座重複の意味候補

血縁ではなくてもよい。

**同じ灯りを受け継いだ人間は、同じ獅子系統へ共鳴することがある。**

これなら:

- 血縁説
- 灯火継承説
- 両方

を後まで残せる。

# 7. アサ × カスミ — 名前を出す / 隠す

これはCore5 × Shadow5の中でも特に強くする。

> 名前を隠すことが、その人を守ることもある。

と思う。

**本人が名乗れる日まで預かっていた。**

逆にカスミも、隠し続ければ本人が存在を取り戻せないことをアサから学ぶ。

# 14. Relationの密度ルール

全員を全員の親族 / 過去の知人にしない。

繋がりは4種類を混ぜる。

1. **直接関係** — 兄妹、師弟、恋愛、旧知
2. **物の継承** — ランタン、手紙、本、切符
3. **思想の鏡** — Core5 × Shadow5
4. **夜で初めて出会う** — 過去に関係はないが、ここで本物の関係ができる

一番重要なのは4。

過去設定だけで人間関係を作らない。

> **ヨルノシルベで一緒に過ごしたから仲間になった。**

というCurrent experienceを中心に残す。

# 15. 深掘りするときの判定

新しいconnectionを作る時:

- 既存Character traitを強くするか
- 時代差を自然に見せるか
- Gameplay / Bondへ返せるか
- 最初は普通に見えるか
- 後で意味が変わるか
- 偶然が増えすぎないか
- 全員を血縁にしていないか
- Currentで初めて作る友情を奪っていないか

を確認する。

**繋がっていることより、「どう繋がったか」が違う方が世界は広く見える。**

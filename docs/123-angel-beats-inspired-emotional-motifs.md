# Angel Beats Inspired Emotional Motifs

Vamp Pon / ヴァンサバ改で、Angel Beats! が好きだった感覚を安全に活かすための感情・構造メモ。

この資料は作品の台詞・固有名詞・設定を流用するためではない。

```txt
使うのは、作品を好きだった理由の構造。
青春、未練、仲間、音楽、別れ、納得して進む感覚を、Vamp Ponの夜・忘れ物・黒耀・朝明に変換する。
```

---

## 1. Angel Beats! から拾うべき取れ高

Vamp Ponに合う要素:

```txt
死後そのものより「やり残したこと」
成仏そのものより「納得して進むこと」
戦いより「本当は救われたい気持ち」
仲間との馬鹿騒ぎと、急に来る別れ
音楽が記憶や未練に触れる
ギャグと泣きの落差
卒業/消える/ありがとうの感覚
```

Vamp Pon変換:

```txt
死後世界 → 夜に置き去りにされた記憶の街
成仏 → 朝明
未練 → 忘れ物
戦線 → 夜を越える小さな同盟
音楽 → リツ/スズ/キャラ返信の重要モチーフ
卒業 → 帰り道を見つけること
```

---

## 2. 直接使わないもの

```txt
作品名をゲーム内に出す
固有名詞をもじる
有名台詞の言い換え
死後学園の構造をそのまま使う
バンド設定をそのまま使う
天使/戦線などの固有概念を寄せる
```

理由:

```txt
商用リスクがある。
薄いパロディになる。
Vamp Ponの独自性が弱くなる。
```

## 3. 使う構造

### 3.1 未練は敵ではなく、帰れない理由

```txt
未練は倒すものではない。
持ち主が「もういい」と思えるまで、夜に残るもの。
```

Vamp Pon文:

```txt
忘れ物は、帰れなかった理由の形をしている。
```

キャラ返信:

```txt
じゃあ私は、理由を拾っているのかな。
— ユイ / Yui
```

```txt
理由が重いと、宛先も沈む。
— セナ / Sena
```

---

### 3.2 朝明は勝利ではなく、納得

```txt
朝明は、敵を倒した証ではない。
その夜を、少しだけ受け入れられた印。
```

Vamp Pon文:

```txt
朝は、勝った人だけに来るわけじゃない。
```

キャラ返信:

```txt
負けても、少し明るくなる日があるんだね。
— ハク / Haku
```

```txt
朝は、縫い目から先に明るくなる。
— ヒナタ / Hinata
```

---

### 3.3 馬鹿騒ぎの後に急に刺す

Angel Beats! 的な強みは、ギャグと泣きの落差。
Vamp Ponでは、常にポエムにしすぎず、日常の軽口を混ぜる。

例:

```txt
Piece of cake.
— English idiom

ケーキなら、どうして歯があるの。
— アサ
```

その後の重い文:

```txt
忘れ物は、笑っていた時間ほど重くなる。
```

キャラ返信:

```txt
楽しかったことまで、夜に置いていきたくない。
— ユイ / Yui
```

---

### 3.4 音楽は記憶を直接殴る

Vamp Ponでは、音楽キャラのリツ/スズをかなり重要にする。
音楽は説明ではなく、記憶を揺らす手段。

ロード文:

```txt
Music, when soft voices die, vibrates in the memory.
— Percy Bysshe Shelley

やわらかな声が消えても、音は記憶の中で震える。
```

キャラ返信:

```txt
消えた声ほど、よく響くんだ。
— リツ / Ritsu
```

```txt
鳴らない鈴も、どこかで響いてるかな。
— スズ / Suzu
```

Angel Beats! 由来の取れ高:

```txt
歌は戦闘BGMではなく、未練をほどくもの。
```

## 6. システムへの接続

### 朝明ポエム

朝明は「成仏」ではなく「納得して進む」演出。

```txt
Stage clear = 勝利
Morning clear = 納得
Character morning poem = その子が少し進めた証
```

### 記録室

```txt
拾った忘れ物に、短い記憶片を付ける。
ただし長文ストーリーにはしない。
```

例:

```txt
欠けた鈴

鳴らなかった最後の返事。
```

```txt
古い譜面

歌われなかった朝のための曲。
```

### 音楽演出

```txt
リツ/スズ関連ロードでは、文字演出に Bell Ripple / waveform を使う。
朝明時、BGMを一瞬だけ減音し、鈴/単音/短い旋律を聞かせる。
```

## 7. 追加でブラッシュアップすべきこと

1. **ロード文のデータ化**

```txt
docsには設計が増えたが、実装用データがまだない。
次は src/data/loadingQuotes.ts / loadingReplies.ts に落とす。
```

2. **朝明ポエムの確定**

```txt
ロード名言とは別に、朝明専用のキャラポエムを20人分作る。
```

3. **記録室/用語帳**

```txt
プレイヤーが調べたくなる言葉を、あとで見返せる場所を作る。
```

4. **音楽キャラの強化**

```txt
Angel Beats! 的な取れ高を活かすなら、リツ/スズはかなり重要。
音が記憶をほどく仕様を入れる。
```

5. **ギャグと泣きの比率**

```txt
常に重くしない。
軽口、英語慣用句、日常表現、パロ会話を挟んでから刺す。
```

## 8. 最終方針

```txt
Angel Beats! から直接借りるのではなく、
未練、青春、音楽、仲間、卒業、消える前のありがとうという感情構造をVamp Ponに変換する。
```

Vamp Ponでは、

```txt
成仏ではなく朝明。
死後世界ではなく夜に置き去りにされた記憶の街。
戦いではなく、帰れなかった理由を拾うこと。
音楽はBGMではなく、未練をほどく鍵。
```

この方向で、ロード名言・キャラ返信・朝明ポエム・記録室をブラッシュアップする。

# 50 Stage / 20 Character Connection Rail

## 目的

Vamp Pon 1 を、5Stageで終わる短い物語ではなく、将来的に20キャラ・50Stageまで拡張しても破綻しない構造へ拡張する。

重要なのは、ただ長くすることではない。

```txt
1作目として完結する
でも50Stageまで伸ばせる
20キャラを出しても散らからない
2へ自然につながる
```

この4つを同時に満たす。

---

# 1. 結論

長期構造は以下。

```txt
1 run = 夜
5 stages = 1ページ
15 stages = 1ページ束
50 stages = 地図帳1冊
20 characters = 5人班 × 4班
```

ただし、全部を最初から実装する必要はない。

設計上、こう伸ばせるようにしておく。

# 3. 20キャラ構成

20キャラは、バラバラに出さない。

```txt
5人班 × 4班
```

として管理する。

## 班A: ユイ班

テーマ:

```txt
忘れ物
```

役割:

```txt
拾う / 名前をつける / しまう / 道を読む / 灯す
```

出番:

```txt
Stage 1〜15
```

## 班B: 手紙班

テーマ:

```txt
届かなかった言葉
```

役割候補:

```txt
書く / 運ぶ / 待つ / 読む / 破る
```

出番:

```txt
Stage 16〜30
```

## 班C: 影の班

テーマ:

```txt
隠して守る
```

役割候補:

```txt
折る / 隠す / 消すふりをする / 夜を読む / 余白を残す
```

出番:

```txt
Stage 31〜45
```

## 班D: 背表紙班

テーマ:

```txt
地図帳そのものを守る人たち
```

役割候補:

```txt
綴じる / 直す / 測る / 写す / 渡す
```

出番:

```txt
Stage 46〜50でSeedとして出し、2以降で本格化
```

# 4. 20キャラを出しても散らからない理由

各班に固有の問いを持たせる。

```txt
ユイ班: 忘れ物は、誰のものだったのか
手紙班: 届かなかった言葉は、なかったことになるのか
影の班: 隠すことは、逃げか守りか
背表紙班: 地図帳は、誰のために綴じられたのか
```

キャラ単位ではなく、班単位で感情を管理する。

# 6. 50Stageで閉じるもの

50Stageまで作るなら、ここまでは閉じる。

```txt

手紙班の主題
影の班との最初の対立
地図帳1冊目の意味
```

閉じないもの:

```txt
黒インクの完全な起源
すべての地図帳
街の外の全貌
背表紙班の本格的な過去
```

# 7. 2へ繋げるためのレール

2へ繋げるなら、1の最後に以下を残す。

```txt
地図帳1冊目は閉じた
でも、背表紙の内側に別の地図帳の番号がある
未配達の封筒が、別の街名へ向いている
影の班が守っていたページが、まだ開いていない
```

2は以下のどれかに接続する。

```txt
Vamp Pon 2: 届かなかった手紙
Vamp Pon 2: 影の班
Vamp Pon 2: 写っていない写真
```

ただし、最有力はまだ以下。

```txt
届かなかった手紙
```

理由:

```txt
1から自然に繋がる
キャラを増やしても散らかりにくい
恋愛/家族/友情を混ぜやすい
明るく締められる
```

# 8. 20キャラを今すぐ出さない理由

20キャラを初期から出すと、薄くなる。

```txt

Season 1裏: 手紙班/影の班/背表紙班のSeedだけ
50Stage版: 20キャラが段階解放
```

# 11. 最重要

20キャラ50Stageにするなら、キャラを増やすのではなく、班を増やす。

```txt
キャラ単位で足すと散らかる。
班単位で足すと物語になる。
```

Vamp Ponの長期構造はこれ。

```txt
1冊目の地図帳には、4つの班の痕跡がある。
ユイ班は拾った。
手紙班は届けようとした。
影の班は隠した。
背表紙班は綴じた。
```

これなら、50Stageでも破綻しにくい。

# 50 Stage / 20 Character Connection Rail

## 目的

Vamp Pon 1 を、20キャラ・50Stageまで拡張しても散らからない構造へ拡張する。

以前の「5人班 × 4班」は管理上は便利だが、表設定として出すと人工的で弱い。

この版では以下に修正する。

```txt
裏管理: 5人系統 × 4グループ
表現: 筆跡・折り方・道具の癖・敵の挙動で、別グループの痕跡として見せる
```

---

# 1. 結論

長期構造:

```txt
1 run = 夜
5 stages = 1ページ
15 stages = 1ページ束
50 stages = 地図帳1冊
20 characters = 5役割 × 4系統
```

ただし、プレイヤーには「4班あります」とは見せない。

表では、以下のように気づかせる。

```txt
筆跡が違う
紙片の折り方が違う
道具の保管方法が違う
影の動き方が違う
小物の使われ方が違う
```

---

# 2. 50Stageの大枠

## Stage 1〜5: 最初のページ

```txt
ユイの入口
忘れ物係の表の遊び
持ち主を間違えない能力のSeed
別系統の折り目を背景に1つだけ置く
```

## Stage 6〜15: 最初のページ束

```txt
ユイ系統5人の誤解をほどく
最初のページ束を朝に確定する
別系統のSeedは説明しない
```

## Stage 16〜30: 第二ページ束

```txt
手紙系統、または別の返却方法を扱う
“届ける”が必ずしも正解ではないことを見せる
誤解の固定をほどく順番の重要性を強める
```

## Stage 31〜45: 第三ページ束

```txt
影系統
隠して守る思想
返す vs 隠す
ほどく vs 固定したまま守る
```

## Stage 46〜50: 地図帳の背表紙

```txt
地図帳1冊の締め
朝の確定処理そのものへの疑い
2以降で前作の意味が変わる違和感を1つ残す
```

# 3. 20キャラ構成は表に出さない

20キャラを管理するための裏構造。

## 系統A: 返却系統

表の役割:

```txt
拾う / 名前をつける / しまう / 道を読む / 灯す
```

真の役割:

```txt
誤解で固定された意味を、正しい持ち主へ返す
```

主な出番:

```txt
Stage 1〜15
```

---

## 系統B: 手紙系統

表の役割候補:

```txt
書く / 運ぶ / 待つ / 読む / 破る
```

真の役割:

```txt
言葉にされなかった意味を扱う
```

注意:

```txt
届けることが常に正解ではない。
届けないことで守られていた言葉もある。
```

主な出番:

```txt
Stage 16〜30候補
```

---

## 系統C: 影系統

表の役割候補:

```txt
折る / 隠す / 消すふりをする / 夜を読む / 余白を残す
```

真の役割:

```txt
意味を返さず、隠して守る
```

注意:

```txt
敵ではない。
同じ目的を別の方法で達成しようとしている。
```

主な出番:

```txt
Stage 31〜45候補
```

---

## 系統D: 背表紙系統

表の役割候補:

```txt
綴じる / 直す / 測る / 写す / 渡す
```

真の役割:

```txt
地図帳の順番そのものを管理する
```

注意:

```txt
一番危険。
意味を返す/隠す以前に、どの順番で読ませるかを変えられる。
```

主な出番:

```txt
Stage 46〜50でSeed
2以降で本格化
```

---

# 4. 4系統それぞれの問い

```txt
返却系統:
その意味は、誰へ返すべきか。

手紙系統:
その言葉は、届けるべきか、届けないまま守るべきか。

影系統:
その意味は、ほどくべきか、隠しておくべきか。

背表紙系統:
そのページは、どの順番で読まれるべきか。
```

ここが20キャラを散らかさないための軸。

# 5. Stageごとの因果レール

## Stage 1〜5

見せるもの:

```txt
拾うと強くなる
名札/箱/切符/ランタンのSeed
敵が特定の小物を守るように動く
```

裏の因果:

```txt
ユイが持ち主を間違えないため、欠片が反応する
```

---

## Stage 6〜10

見せるもの:

```txt
小物の意味が少し反転する
拾う順番でリザルト文が変わる
```

裏の因果:

```txt
名前・場所・理由・証拠の接続順が、夜の結果に影響する
```

---

## Stage 11〜15

見せるもの:

```txt
ユイ系統のページ束が閉じる
朝に意味が確定する
```

裏の因果:

```txt
間違った意味が固定されなくなる
```

閉じるもの:

```txt
ユイ系統の誤解
```

残すもの:

```txt
別系統の折り目
知らない綴じ糸
```

---

## Stage 16〜30

見せるもの:

```txt
届かなかった言葉の痕跡
手紙/便箋/郵便箱
```

裏の因果:

```txt
言葉は届ければよいとは限らない
間違った相手に届けると、別の誤解が固定される
```

---

## Stage 31〜45

見せるもの:

```txt
影の折り紙
消しゴムのかけら
夜読みの定規
```

裏の因果:

```txt
影系統は、意味を返すより隠して守る思想
```

---

## Stage 46〜50

見せるもの:

```txt
地図帳の綴じ糸
ページ番号のズレ
閉じたはずのページの折り目
```

裏の因果:

```txt
背表紙系統が、読まれる順番を管理している
```

---

# 6. 50Stageで閉じるもの

50Stageまで作るなら閉じるもの:

```txt
ユイ系統の物語
手紙系統の主題の一部
影系統との最初の対立
地図帳1冊目の読まれ方
```

閉じないもの:

```txt
黒インクの完全な起源
地図帳を最初に綴じた人物
朝の確定処理の本当の安全性
すべての系統の最終目的
```

# 7. シリーズ型のSeed管理

## 1作内で回収するSeed

```txt
空白の名札
閉じた箱
片方だけの切符
直されたランタン
ユイ以外の筆跡
```

## シリーズ後に意味が変わるSeed

```txt
折り目の違う紙片
知らない綴じ糸
ページ番号だけの紙片
切手のない封筒
夜読みの定規
```

重要:

```txt
シリーズSeedは説明しない。
でも見返した時に、最初からあったと分かる場所へ置く。
```

# 8. 20キャラを今すぐ出さない理由

20キャラを初期から出すと薄くなる。

初期は以下でよい。

```txt
実装: ユイのみ
Season 1表: 返却系統5人
Season 1裏: 手紙/影/背表紙系統のSeedだけ
50Stage版: 系統ごとに段階解放
```

---

# 9. 50Stageを作る時のNG

```txt
ただStageを水増しする
全部のキャラを同じ重さで描く
毎ページで大真相を出す
黒インクの説明を早くしすぎる
4班を表で説明する
2への露骨な予告を置く
```

---

# 10. 最重要

20キャラ50Stageにするなら、キャラを増やすのではなく、**意味を扱う方法を増やす**。

```txt
返す
届ける
隠す
綴じる
```

これが4系統。

Vamp Ponの1冊目の地図帳には、4系統の痕跡がある。

```txt
返却系統は返した。
手紙系統は届けようとした。
影系統は隠した。
背表紙系統は順番を綴じた。
```

この構造なら、20キャラ50Stageでも破綻しにくい。

# スマホ入力仕様と画面遷移

## 目的

Vamp Pon はスマホアプリ前提で考える。

Webベースで作るとしても、最初からスマホブラウザで縦持ちプレイできる仕様にする。

この資料では、デザインを決めずに以下を固定する。

```txt
画面向き
論理解像度
入力仕様
必殺技操作
レベルアップ操作
ポーズ/中断復帰
画面遷移
```

---

# 1. 画面向き

## MVP基準

```txt
縦持ち
390 x 844 論理解像度
```

## 理由

```txt
スマホで触りやすい
片手操作の可能性を残せる
短時間起動と相性が良い
```

## 横持ち

MVPでは後回し。

ただし、ロジックは画面比率に依存しすぎないようにする。

---

# 2. 基本入力

## 移動

MVP採用:

```txt
仮想スティック
```

配置:

```txt
左下
```

仕様:

```txt
指を置いた位置を中心に仮想スティック開始
一定半径内で方向と強さを計算
指を離すと停止
```

## 攻撃

```txt
完全自動
```

プレイヤーは攻撃ボタンを押さない。

## 必殺技

配置:

```txt
右下
```

仕様:

```txt
ゲージ満タン時のみ押せる
押すと即発動
長押しなし
方向指定なし
```

## レベルアップ選択

```txt
カードをタップ
```

カードは3枚固定。

## 記憶カプセル

```txt
接触で取得
取得後は短い演出
```

自動吸引は後回し。

---

# 3. 仮想スティック仕様

## 入力範囲

```txt
画面左半分の下側を移動入力エリアにする
```

理由:

```txt
指の位置を固定しすぎない
端末サイズ差に強くする
```

## 推奨値

```txt
stickBaseRadius: 54px
stickKnobRadius: 22px
maxInputDistance: 54px
movementDeadZone: 0.12
```

## 移動計算

```txt
入力ベクトル = knob位置 - base位置
距離 / maxInputDistance = 入力強度
deadZone以下なら停止
正規化方向 * 移動速度 * 入力強度
```

## 注意

移動強度を完全アナログにすると操作がふわふわする可能性がある。

MVPでは以下も検証する。

```txt
入力強度がdeadZoneを超えたら常に最大速度
```

つまり、方向だけ使う方式。

## 推奨

最初は方向だけ方式。

理由:

```txt
避け操作が安定する
スマホで分かりやすい
```

# 4. 必殺技ボタン仕様

## 表示状態

```txt
未チャージ: 薄い
チャージ中: ゲージ表示
満タン: 光る / 発動OK
発動中: 一瞬無効
```

## 自動発動設定

設定項目:

```txt
autoUltimate: true / false
```

MVP初期値:

```txt
false
```

## 自動発動条件案

自動ON時:

```txt
ゲージ満タン
かつ
HP35%以下 または 周囲の敵が一定数以上
```

MVPでは実装後回しでもよい。

ただし、設定項目だけ先に持ってよい。

---

# 5. レベルアップ操作仕様

## 表示

```txt
ゲーム一時停止
背景を少し暗くする
3カード表示
```

## カード構成

```txt
名前
新規/強化
効果
裏ストーリー1行
```

## タップ領域

カード全体をタップ可能にする。

小さなボタンだけを押させない。

## 選択後

```txt
カードが軽く反応
効果反映
ゲーム再開
```

## 戻る/キャンセル

MVPではなし。

必ず1つ選ぶ。

---

# 6. ポーズ/中断復帰

## ポーズボタン

MVPでは右上に小さく配置。

ただし、戦闘中に誤タップしにくい位置にする。

## 中断時

アプリ/ブラウザが非アクティブになったら自動ポーズ。

```txt
visibilitychange
blur
```

を監視する。

## 復帰時

```txt
ポーズ画面で復帰
即再開しない
```

理由:

```txt
復帰直後に被弾しないため
```

## ラン途中保存

MVPでは後回し。

ただし、8分標準なので許容。

10分以上にするなら、途中保存を再検討。

# 7. 画面遷移

## MVP最小

```txt
起動
↓
タイトル
↓
キャラ選択
↓
プレイ
↓
リザルト
↓
タイトル / もう一度
```

## 詳細

```txt
Boot
↓
Title
  ├ Start
  ├ Codex
  ├ PowerUp
  └ Settings
↓
CharacterSelect
↓
MainGame
  ├ LevelUpOverlay
  ├ CapsuleOverlay
  ├ PauseOverlay
  ├ Clear
  └ GameOver
↓
Result
  ├ Retry
  ├ PowerUp
  ├ Codex
  └ Title
```

## MVPで省略可能

```txt
PowerUp
Codex
Settings
```

ただし、入口だけは後で作れるように設計する。

# 9. キャラ選択の機能要件

MVPでユイ1人なら省略可能。

2人目ミチルを入れるなら必要。

表示情報:

```txt
名前
肩書き
初期武器
必殺技
初心者向け/中級者向け
```

文字は短くする。

# 10. リザルト操作

ボタン:

```txt
もう一度
強化へ
図鑑へ
タイトルへ
```

MVP最小:

```txt
もう一度
タイトルへ
```

## リザルトで見せる優先度

```txt
1. 生存時間
2. 倒した影
3. 集めた欠片
4. 到達Lv
5. 進化
6. 新発見
7. 次の目標
```

## 裏ストーリー1行

リザルトの最後に1行だけ。

戦闘中には出さない。

---

# 11. スマホ入力チェックリスト

```txt
[ ] 指で自キャラが隠れない
[ ] 仮想スティックが邪魔ではない
[ ] 必殺技ボタンが押しやすい
[ ] レベルアップカードが片手でも選べる
[ ] ポーズを誤タップしない
[ ] 復帰直後に即被弾しない
[ ] 文字が小さすぎない
[ ] UIが敵/欠片を隠しすぎない
```

## 最重要

```txt
移動と必殺技以外の操作を増やさない。
```

Vamp Ponは、スマホで忙しいゲームにしない。

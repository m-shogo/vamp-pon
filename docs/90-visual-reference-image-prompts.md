# Visual Reference Image Prompts

## 目的

Prototype 1前に必要な参照画像を作るためのプロンプト集。

これらは完成素材ではない。

目的は以下。

```txt
採用ビジュアル方向を固定する
実装時に見た目がズレないようにする
スマホで見えるか判断する
仮素材の方向を合わせる
```

---

# 1. Prototype 1 Gameplay Mock

## 用途

Prototype 1の画面構成と視認性を確認する。

## Prompt

```txt
スマホ向け縦画面ゲームのPrototype 1用ゲーム画面モック。390x844の縦長画面。紙片・絵本風ドット、夜の街、黒インクの影、小さなランタン、光る記憶の欠片、やさしい不穏さ。画面上部にシンプルなHUDとしてHP、時間、Lvを配置。中央はプレイエリア。左下に半透明の仮想スティック、右下に将来の必殺技ボタン用の薄い丸枠だけを配置。プレイヤーは小さなランタンを持つ忘れ物係の少女で、暗い背景でも見失わない。敵は黒インクの丸い影1種類だけ、白い小さな目で位置が分かる。記憶の欠片は小さく光る星型の紙片として、背景より明るく目立つ。背景は暗い紙風タイルと少量の紙片、街灯の雰囲気だけで、描き込みすぎない。完成イラストではなく、ゲーム実装前の視認性確認用モック。文字は最小限、ロゴ不要。自キャラ、敵、欠片の判別を最優先。コンセプトは濃く、実装は見やすく軽く。
```

# 2. Minimal Sprite Reference Sheet

## 用途

仮素材の方向を合わせる。

## Prompt

```txt
Vamp Pon Prototype 1用の最小スプライト参照シート。紙片・絵本風ドットの2Dゲーム素材。背景は透明または無地。含める素材は、小さなランタンを持つ忘れ物係の少女、黒インクの丸い影、光る記憶の欠片、夜の鉛筆の小さな弾、薄い紙風タイル。すべてスマホ縦持ちゲームで小さく表示しても判別できること。プレイヤーは28〜34px相当で見失わないシルエット、敵は28〜36px相当で黒い影と白い目、欠片は10〜14px相当で明るい金色の光。完成アニメーションではなく、シルエット・色・サイズ感を確認するための参照シート。装飾は最小限。既存ゲーム風になりすぎない。ロゴ不要、余計な文字不要。
```

# 3. UI Card and HUD Reference

## 用途

HUDとレベルアップカードの方向を合わせる。

## Prompt

```txt
スマホ向け縦画面ゲームVamp PonのUI参照画像。紙片・絵本風ドット、夜、記憶、忘れ物、黒インク、小さな光の世界観。画面上部HUDとしてHPバー、時間表示、Lv表示、記憶の欠片数を配置。下部にはレベルアップカード3枚を表示。カードは古い紙、しおり、切符、メモ帳のモチーフで、淡いクリーム色の紙質、手書き風の細い枠、星レアリティ。カード内容は読みやすさ最優先で、装飾しすぎない。背景は暗い夜紺。UIだけを見ても、やさしい不穏さと紙片の世界観が伝わること。ゲーム実装用の参照であり、完成ロゴ不要。日本語風の短い仮文字が少しあってもよいが、読めなくてもよい。スマホで小さく表示しても見やすいUI。
```

# 4. Background Tile Reference

## 用途

背景が描き込みすぎてプレイを邪魔しないようにする。

## Prompt

```txt
Vamp Pon Prototype 1用の背景タイル参照。紙片・絵本風ドット、夜の街、暗い紙風の床、少量の紙片、黒インクのにじみ、遠くの街灯の暖かい光。トップダウン2Dゲームのプレイ背景として使用する想定。敵、プレイヤー、記憶の欠片が上に乗っても見やすいように、背景のコントラストと彩度は控えめ。細かい装飾は少なめ。花や家具や街灯は画面端に寄せ、中央プレイ領域は読みやすくする。美しいが主張しすぎない。暗い夜紺とくすんだ青紫を基調に、紙の質感をわずかに感じる。ロゴ不要、キャラクター不要、UI不要。
```

# 5. Memory Fragment / Pickup Reference

## 用途

欠片の見え方を固定する。

## Prompt

```txt
Vamp Pon用の記憶の欠片・ピックアップアイテム参照画像。紙片・絵本風ドットの小さな光るアイテム。小さな星型の紙片、淡い金色、白い中心光、少しだけ粒子が散る。暗い夜の背景でも確実に目立ち、拾いたくなる見た目。サイズはスマホゲーム内で10〜14px相当でも認識できるデザイン。バリエーションとして、通常の記憶の欠片、少し大きい欠片、記憶カプセルに近い小瓶型の光を並べる。装飾は最小限、視認性最優先。背景は暗い無地または透明風。ロゴ不要、文字不要。
```

# 6. Enemy Shape Reference

## 用途

黒インク敵の種類を増やす時の方向確認。

## Prompt

```txt
Vamp Pon用の黒インクの影敵デザイン参照シート。紙片・絵本風ドット、やさしい不穏さ。敵は黒インクの影として統一し、怖すぎず、少しだけかわいいが不気味。白い小さな目で位置が分かる。種類は、丸い基本影、紙くずをまとった影、標識やラベルの影、もや状の影、黒ラベルの強敵。すべて小さいスマホ画面でもシルエットで区別できること。暗い背景に埋もれないように、輪郭や目で判別しやすくする。完成素材ではなく、形・サイズ・見分け方の参照。ロゴ不要、余計な文字不要。
```

# 7. Prompt Usage Order

最初に作る順番。

```txt
1. Prototype 1 Gameplay Mock
2. Minimal Sprite Reference Sheet
3. UI Card and HUD Reference
4. Background Tile Reference
5. Memory Fragment / Pickup Reference
6. Enemy Shape Reference
```

## 最重要

画像は完成素材ではない。

```txt
方向を合わせるための参照画像。
```

実装では、これをそのまま入れず、軽く見やすい仮素材に落とす。

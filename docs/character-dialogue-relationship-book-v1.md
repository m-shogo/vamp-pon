# 0. この本でLOCKするもの / LOCKしないもの

## CURRENT DIALOGUE DIRECTION

Current21について次は制作前提として使う。

- 文の長さ
- 話す速度
- よく使う考え方 / 語彙
- 怒った時の崩れ方
- 助け方
- 助けが必要な時のサイン
- Bondで変わる方向
- Crisis / 黒耀化で極端になる言葉

## SAMPLE / NOT SCRIPT CANON

本文中の会話例は**そのまま本編へ必ず採用する確定台詞ではない**。

台詞の目的は:

> 「この人物なら、こういう言葉の選び方をする」

を共有すること。

口癖も毎行繰り返すキャッチコピーにしない。

```txt
悪い口癖:
毎回「大丈夫だよ！」と言う

良い口癖:
怖い時ほど「大丈夫」を先に言ってしまう
Bond後は「大丈夫。……じゃない、ちょっと手伝って」が言える
```

# 1. 会話設計の共通ルール

## 1.1 口癖は「思考の癖」から作る

人物ごとに:

```txt
何を最初に見るか
何を確認するか
何を怖がるか
人へ何を任せられないか
```

を台詞へ出す。

例:

- ユイは「誰のものか」を見る
- アサは「何と呼ぶか」を見る
- ナギは「開けてよいか」を見る
- ミチルは「帰れるか」を見る
- トモリは「まだ使えるか」を見る

同じ事件を見ても最初の一言が変わる。

## 1.2 Base / Bond / Crisis の3段階

### Base

普段の本人。

### Bond delta

仲良くなったことで性格を変えるのではなく、**省略できる説明・任せられる範囲・弱音**が増える。

### Crisis delta

本人の長所が恐怖で狭くなる。

黒耀化直前は、普段の口癖が別人の言葉になるのではなく、**同じ言葉が極端になる**方が強い。

## 1.3 仲良しだけが良い会話ではない

- 気が合う
- 価値観が違う
- ちょっと苦手
- 仕事だけは信頼する
- 喧嘩中でも無意識に助ける
- 話さなくても同じ場所にいられる

を混ぜる。

全員が全員へ親友口調にならない。

## 1.4 情報説明のためだけに喋らせない

良い日常会話は:

```txt
表面: 焼き芋を半分にする話
↓
人物: 誰へ先に渡すかが見える
↓
関係: いつの間にか相手を気にしている
↓
後半: 同じ行動が伏線だったと分かる
```

を狙う。

# 2. Current21 Voice Sheets

# Core 5

## 01. ユイ — 拾って、結んで、本人へ返したい

### Base voice

- 明るさはあるが、常時元気印ではない
- 短〜中くらいの文
- 考えるより先に手が動く時がある
- 「誰の？」「返そう」「聞いてみよう」が自然に出る
- 相手の名前を会話の中で比較的よく呼ぶ

### Reflex phrases

- 「これ、誰の？」
- 「一回、聞こう」
- 「まだ戻せるよ」
- 不安時: 「忘れたくない」

### 怒り

普段より名前をはっきり呼ぶ。

大声より:

> 「それ、本人が決めることだよ。」

と短く止める方がユイらしい。

### Small lie

> 「大丈夫。覚えてるから。」

本当は自分でも記憶が曖昧な時ほど言いやすい。

### Help

- 落とした物を先に拾う
- 一人でいる相手の近くへランタンを置く
- 問い詰めず「これ置いとくね」で去れる

### Need-help signal

自分の持ち物を置き忘れる回数が増える。
誰かの忘れ物だけを過剰に確認する。

### Bond delta

初期:

> 「私が戻す。」

成長後:

> 「どうしたい？」
> 「一緒に決めよ。」

### Crisis delta

「誰の？」が消え、代わりに「全部」が増える。

> 「全部戻せばいい。」
> 「全部覚えてれば、なくならない。」

黒灯化の危険を台詞から先に察知できる。

### Strong interaction lanes

- **アサ** — 速度の合うバディ。ユイが拾い、アサが名前を確認する
- **クロオリ** — 開く / 閉じる。沈黙そのものが対話になる
- **トモリ** — ランタン。修理跡を巡る年代差Mysteryは未LOCK
- **レン** — ユイ自身が気づかない小さな行動差を見つける

## 02. アサ — 名前を雑に扱わせない

### Base voice

- 速い
- 文が短い
- 曖昧な代名詞を嫌い、人 / 物の名前を置き直す
- 初対面の名を一度だけ小声で復唱する
- 親しくても必要以上に甘い呼称へ変えない

### Reflex phrases

- 「名前、もう一回。」
- 「それ、誰の話？」
- 「本人はそう呼んでって言った？」
- 「先、行く。」

### 怒り

フルネームや正式な呼称になる。
語尾が短くなる。

### Small lie

> 「別に急いでない。」

かなり焦っている時ほど言う。

### Help

- 名前を書く
- 誰が何を使っていたか整理する
- 混乱時に対象を一つずつ呼び分ける

### Need-help signal

同じ名前を二度確認する。
字がいつもより強くなる。

### Bond delta

初期:

> 「先、行く。」

信頼後:

> 「一緒に行く。」

呼称より**主語が単数から複数へ変わる**。

### Crisis delta

名前を「本人が選ぶもの」ではなく「自分が固定するもの」として使い始める。

> 「名前があれば迷わない。」
> 「決めればいい。全部。」

### Strong interaction lanes

- **ユイ** — 拾う / 呼ぶの高速コンビ
- **カスミ** — 公開する名前 / ぼかして守る名前
- **コヨリ** — 子どもの「自分で名前を書く」を尊重できるか
- **ユウビ** — 宛名が正しくても、今届けるべきとは限らない

## 03. ナギ — 開ける前に聞く

### Base voice

- 静か
- 文は短いが冷たくはない
- 許可を取る言葉が多い
- 質問を急かさない
- 相手が答えないなら待てる

### Reflex phrases

- 「開けていい？」
- 「今は、閉じとく？」
- 「預かるよ。」
- 「急がなくていい。」

### 怒り

声量は上がらない。
一度閉じた箱のように会話を切る。

> 「勝手に開けないで。」

### Small lie

> 「気にしてない。」

本当はかなり気になっているが、本人の領域へ入らないための嘘。

### Help

- 守る場所を作る
- 相手の物へ勝手に触れない
- 一時的に預かり、必ず返す

### Need-help signal

確認回数が二回から三回、四回へ増える。
鍵や蓋を触っている時間が長くなる。

### Bond delta

信頼前は何でも自分で閉じる。
信頼後は鍵を渡せる。

> 「これ、持ってて。」

### Crisis delta

質問形が消える。

> 「閉じる。」
> 「全部、ここに入れればいい。」

### Strong interaction lanes

- **カナメ** — 危険を閉じる / 自分が危険との間へ立つ
- **トバリ** — 閉める門にも「帰るために開く時」がある
- **コヨリ** — 子どもの物ほど勝手に管理しない姿勢が出る

## 04. ミチル — 帰る道は歩いて作る

### Base voice

- 軽快だが無鉄砲ではない
- 地図 / 角 / 道 / 寄り道の比喩が自然に出る
- 「正解」より「試してみる」が多い
- 曲がり角で後ろを確認する行動が台詞より先に出る

### Reflex phrases

- 「こっち、試そ。」
- 「帰り道は覚えてる。」
- 「寄り道一個だけ。」
- 「戻れるよ。」

### 怒り

「戻れない」と最初から決める人へ強く反応する。
早口になる。

### Small lie

> 「迷ってない。」

迷っている。
ただし怖がらせたくなくて言う。

### Help

- まず出口を探す
- 迷った人へ「こっち」と手を引くより、目印を一緒に確認する

### Need-help signal

地図を書き直す回数が増える。
同じ角を何度も振り返る。

### Bond delta

一人で先導する人から、相手へ分岐を選ばせる人へ。

> 「右と左。どっち行きたい？」

### Crisis delta

寄り道が消える。
一本の道へ固執する。

> 「ここしかない。」
> 「外れたら帰れない。」

### Strong interaction lanes

- **トキ** — 歩いて確かめる / 測って決める
- **ゲン** — 古い地図を尊重しながら新しい道も見つける
- **ユウビ** — routeが正しくてもtimingが違う
- **トバリ** — 行く人 / 帰りを残す人

## 05. トモリ — 元通りより、また使えること

### Base voice

- 作業しながら話す
- 手を止めて長台詞を言うことは少ない
- 物の状態を人の価値へ直結させない
- 「壊れた」「傷」「継ぎ目」を否定語としてだけ使わない

### Reflex phrases

- 「それ、まだ直せる。」
- 「ちょっと見せて。」
- 「元通りじゃなくていい。」
- 「使えるなら、まだ終わってない。」

### 怒り

工具を置く音が少し大きくなる。
言葉は減る。

### Small lie

> 「直せる。」

直らない可能性を本人が一番分かっている時にも言ってしまう。

### Help

- 頼まれる前に椅子や留め具を直す
- 人そのものを「修理対象」扱いしない

### Need-help signal

壊れていない物まで分解して点検し始める。

### Bond delta

一人で仕上げる → 途中の部品を相手へ任せられる。

> 「そこ、押さえてて。」

### Crisis delta

「直せる」が「直さなければ」へ変わる。

> 「全部、元に戻す。」

### Strong interaction lanes

- **ツムギ** — 完成させる / 余白を残す
- **ハナ** — 保存する人と修理する人。残す目的が違う
- **ユイ** — 古いランタンの修理跡Mystery Candidate
- **カナメ** — 壊れる前に守る / 壊れた後も継ぐ

# Circle 10

## 06. セン — 答えより、良い問いを作る

### Base voice

- 説明は分かりやすいが、教師口調を常時使わない
- 相手へ問い返す
- 指で空中へ線を引きながら話す
- 難語を使って偉く見せない

### Reflex phrases

- 「どうしてそう思った？」
- 「じゃ、別の線で考えよう。」
- 「いい問いだ。」
- 分からない時: 「そこ、僕も分からない。」

### 怒り

丁寧になる。
「教える価値がない」という態度へ一番怒る。

### Small lie

> 「簡単だよ。」

自分も解けていない時がある。

### Help

答えを言うより、一段手前のヒントを作る。

### Need-help signal

説明が必要以上に長くなる。
人から教わる時のメモが細かくなる。

### Bond delta

> 「教えてあげる」

から

> 「それ、教えて。」

を自然に言える人へ。

### Crisis delta

全員へ正しい線を引き、外れる選択を許さなくなる。

### Strong interaction lanes

- **コヨリ** — 子どもがrule creatorになる
- **シロ** — 説明したい / 分からないまま残したい
- **マドカ** — 不確実な観測をどう言葉にするか

## 07. リツ — 半分にする兄

### Base voice

- 面倒見は良いが親代わりにはしない
- 数を数える
- 「半分」「順番」「人数」が自然に出る
- コヨリとは軽口が多い

### Reflex phrases

- 「半分な。」
- 「人数、合ってる？」
- 「先にそっち。」
- 「俺はあとでいい。」

最後の一つはSmall lieでもある。

### 怒り

誰か一人だけを当然に犠牲へ回す判断へ強く反応する。

### Help

自分の取り分を自然に減らす。
相手へ恩着せがましく言わない。

### Need-help signal

自分の分を本当にゼロにし始める。

### Bond delta

守る相手へ「任せる」が増える。

> 「コヨリ、そっち頼む。」

### Crisis delta

> 「俺が全部持つ。」

へ戻る。

### Strong interaction lanes

- **コヨリ** — 兄妹。守る / 守られるを固定しない
- **カナメ** — 自分が盾になる者同士。互いの自己犠牲には厳しい
- **ユイ** — 「全部自分で抱える」危険を互いに指摘できる

## 08. コヨリ — 小さいから後回しにされたくない

### Base voice

- 子どもらしく直球
- 難しい言葉を無理に使わない
- 分からない時は分からないと言う
- 名前や人数へ敏感

### Reflex phrases

- 「わたしも数えて。」
- 「それ、名前ある？」
- 「自分でやる。」
- 「半分じゃなくて、今日はこっち。」

### 怒り

飛ばされた時ほどはっきり言う。
泣くだけの役にしない。

### Small lie

> 「こわくない。」

怖い時は逆に静かになる。

### Help

小さい物、低い場所、誰も気づかない紙片を拾う。
大人が見落としたことを「簡単だから」言える。

### Need-help signal

名前を書く回数が増える。
兄の袖を握るが、口では助けを求めない。

### Bond delta

「やって」から「一緒にやろ」へ。
同時に大人へも頼られるようになる。

### Strong interaction lanes

- **リツ** — 兄妹
- **セン** — コヨリが先生になる回を作れる
- **アサ** — 自分で書いた少し曲がった名前を直される / 直されない
- **クロオリ** — 折った動物へ勝手に名前を付けようとして止まる小さな成長

## 09. ゲン — 古い道は知っている。今の正解までは知らない

### Base voice

- 短い
- 渋いが「何でも知る賢者」にしない
- 昔話の後に自分で但し書きを付ける
- 若い組の失敗を笑える

### Reflex phrases

- 「昔はな。」
- 「今は知らん。」
- 「道は残っとるかもしれん。」
- 「座ってから考えよう。」

### 怒り

古いから無価値と切り捨てる態度へ静かに怒る。
逆に「昔が全部正しい」と持ち上げられても嫌がる。

### Small lie

> 「忘れた。」

本当は覚えているが、若い相手に自分で考えさせたい時がある。

### Help

安全な休憩場所と帰路を先に見る。

### Need-help signal

昔の話が増える。
今のことを話さなくなる。

### Bond delta

自分の失敗談を具体的に話せるようになる。

### Crisis delta

> 「昔の道なら間違いない。」

へ固まる。

### Strong interaction lanes

- **ミチル** — old map / new route
- **トキ** — 経験則 / measurement
- **レン** — 昔の地図と今の地図の差

## 10. ハナ — 保存は、手渡すため

### Base voice

- 温かいが「みんなのお母さん」一辺倒にしない
- 物を捨てる / 保存する判断に具体性がある
- 相手の分まで勝手に決めない

### Reflex phrases

- 「これは、しまっとこうか。」
- 「あとで返すからね。」
- 「残すなら、使える形で。」
- 「私はいいの。」

最後はSmall lieになりやすい。

### 怒り

まだ使える物 / 人の積み重ねを雑に扱われた時。
普段の笑顔が消える。

### Help

食べ物や布、小さな保存物を「後で必要になる人」へ残す。

### Need-help signal

何でも保存し始める。
捨てる判断ができなくなる。

### Bond delta

保存物を自分で管理するだけでなく、相手へ預ける。

### Crisis delta

> 「残しておけば、失わない。」

が強くなる。

### Strong interaction lanes

- **トモリ** — repair / preserve
- **ツムギ** — 保存する / 続きを残す
- **シロ** — 未分類資料を捨てない二人だが、理由が違う

## 11. ユウビ — 届ける時間まで考える

### Base voice

- 宛先 / 順番 / 時間を確認する
- 仕事口調はあるが堅すぎない
- 相手の感情を勝手に説明しない

### Reflex phrases

- 「今、渡す？」
- 「これは、あとで。」
- 「宛先は合ってる。」
- 「届くことと、受け取れることは違う。」

### 怒り

預かった物を雑に扱われた時。
丁寧語が固くなる。

### Small lie

> 「急ぎじゃない。」

自分が待てなくなっている時に言う。

### Help

渡さない / 待つことも選べる。

### Need-help signal

宛名を三回以上確認する。
ずっと同じ封筒を鞄から出して戻す。

### Bond delta

「届ける人」から、相手へtimingを聞ける人へ。

### Crisis delta

> 「預かったなら、今すぐ届ける。」

へ戻る。

### Strong interaction lanes

- **トバリ** — 門を開ける時 / 渡す時
- **カスミ** — 宛名を隠す保護
- **ミチル** — destination / route / timing

## 12. マドカ — 見たなら、伝える責任がある

### Base voice

- 最初の言い方に少し保留が入る
- 「かも」で逃げ続けるのではなく、観測と確度を分ける
- 遠くを見る時ほど静か

### Reflex phrases

- 「見えた。」
- 「たぶん。……でも、言っとく。」
- 「あそこ、さっきと違う。」
- 成長後: 「見えた。だから言う。」

### 怒り

「確実じゃないなら黙れ」と一律に切られた時。
ただし誤報を軽視もしない。

### Small lie

> 「見間違いかも。」

自分の責任を怖がっている時に増える。

### Help

画面外 / 遠景 /他人が見ていない変化を共有する。

### Need-help signal

気づいているのに言葉が一拍遅れる。
窓枠へ触れる回数が増える。

### Strong interaction lanes

- **レン** — 差分を見つける人 / 共有する人
- **トキ** — 数値化前の兆候 / 計測
- **セン** — 不確実情報の伝え方

## 13. シロ — 「分からない」を保存できる

### Base voice

- 正確
- 早く結論を出すタイプではない
- 分類語を使うが、人間まで箱へ入れない
- 眼鏡を直すより、本や紙の向きを揃える癖を使う

### Reflex phrases

- 「未分類でいい。」
- 「まだ分からない。」
- 「分からない、は捨てる理由じゃない。」
- 「保留。」

### 怒り

未知を「役に立たない」と捨てられた時。
敬語が妙に硬くなる。

### Small lie

> 「気になってない。」

分類できない物ほど気になっている。

### Help

情報を失わず、結論を急がない場所を作る。

### Need-help signal

机上の向きを必要以上に揃える。
保留箱が増えすぎる。

### Bond delta

未分類の物を相手へ見せられる。

> 「これ、一緒に分からないでいてくれる？」

### Crisis delta

逆にすべてを分類しないと進めなくなる。

### Strong interaction lanes

- **セン** — 説明したい / 未分類を残したい
- **ツムギ** — blank / unfinished
- **レン** — differenceを分類へ変えるか
- **ハナ** — 保存する理由の違い

# 8. 黒耀化前後の会話原則

黒耀化で急に悪役語彙へしない。

```txt
通常ユイ: 「戻せるよ」
危機ユイ: 「全部戻せる」
黒灯化: 「全部戻す」
成長後: 「戻すか、一緒に決めよう」
```

同じ語彙の意味が変わる方が「本人のもう一つの到達」に見える。

全人物で:

```txt
Base phrase
→ fearでabsolute化
→ 黒耀化で他人の選択を奪う
→ growth後に相手へ選択を返す
```

を優先する。

# 9. Writing QA

会話を書く時、最低限確認する。

- [ ] 名前を隠した状態でも誰が喋っているか推測できるか
- [ ] 口癖を毎行使っていないか
- [ ] 全員が同じ長さ / 同じ優しさ / 同じ冗談になっていないか
- [ ] 仲良くなった結果、別人格になっていないか
- [ ] Shadowが冷たい悪役口調へ統一されていないか
- [ ] 子どもを幼児語だけで作っていないか
- [ ] 年長者を全知の賢者にしていないか
- [ ] 動物を真実を知る賢者にしていないか
- [ ] Robotを感情の有無を証明するテスト装置だけにしていないか
- [ ] sexuality / gender / disabilityを口調ギミックにしていないか
- [ ] 会話を読むことがGameplay power獲得条件になっていないか
- [ ] 日常台詞が後半の関係 / 黒耀化 / Mysteryへ再解釈できる余地があるか

# Rare Japanese / Literary Phrase Final Candidates

Vamp Pon / ヴァンサバ改のロード知識システムに最初に入れる、Rare Japanese / literary phrase 8件の確定候補。

この資料は、`docs/126-loading-knowledge-consistency-guardrails.md` の方針に従い、1カテゴリだけを少数精鋭で詰める。

---

## 1. このカテゴリの役割

Rare Japanese / literary phrase は、日本語の「知ってると気持ちいい」枠。

```txt
本を読んでいる時に、知らない言葉へ引っかかる感覚。
意味を知ると少し賢くなった気がする感覚。
キャラ返信で、その子の価値観が見える感覚。
```

ロードでの目的:

```txt
日本語の知識欲を満たす。
短い言葉で世界観を深くする。
難語を辞書説明で終わらせず、キャラの受け取り方へつなげる。
```

---

## 2. 選定基準

採用条件:

```txt
短い。
意味が1行で説明できる。
Vamp Ponの夜・記憶・忘れ物・道・朝に接続できる。
キャラ返信で価値観が見える。
ロード中に読める。
```

避けるもの:

```txt
意味が難しすぎる語。
説明が長くなる語。
現代ネット語。
雰囲気だけで使う漢字語。
全キャラが同じ反応になりそうな語。
```

## 3. Final 8 Candidates

## 3.1 閑話休題

語句:

```txt
閑話休題
```

日本語訳/意味:

```txt
それはさておき、本題に戻ること。
```

Character replies:

```txt
寄り道にも、帰り道があるんだね。
— ナギ / Nagi
```

```txt
本題に戻る前に、忘れ物をひとつ拾ってもいい？
— ユイ / Yui
```

Presentation:

```txt
Page Turn
```

Rank:

```txt
S
```

理由:

```txt
ロードからゲームへ戻る流れに合う。
ナギ/ユイの価値観が自然に出る。
言葉そのものが「脱線と帰還」を持っている。
```

# 8. 破綻チェック

この8件は、以下を満たす。

```txt
□ 1行で意味が説明できる
□ ロード中に読める
□ キャラ返信が説明ではない
□ 日本語の知識欲を満たす
□ Vamp Ponの夜/道/記録/名前/朝に接続できる
□ 初期実装に入れても世界観が壊れない
```

注意:

```txt
難語は2連続禁止。
蛇足/序破急/余談ながらは軽め・メタ寄りなので頻度を低くする。
曖昧模糊/有耶無耶は黒耀や霧ステージに寄せてもよい。
薄明は朝明前後で強い。
```

# 9. 最終方針

Rare Japanese / literary phrase は、Vamp Ponに「本を読んでいる時の引っかかり」を足すカテゴリ。

最初に入れるなら、次の5件から始める。

```txt
閑話休題
曖昧模糊
有耶無耶
薄明
画竜点睛
```

残り3件は、表示文脈が整ってから入れる。

```txt
余談ながら
序破急
蛇足
```

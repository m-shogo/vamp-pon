# 黒耀化の代償と副作用ルール

黒耀化は、Vamp Pon / ヴァンサバ改の強い爽快感を作る中核システム。
ただし、物語上は単なる強化ではない。

> 黒耀化は、夜の力を借りること。
> 借りたものは、必ず何かで返す。

---

## 基本ルール

### 黒耀化は悪ではない

黒耀化そのものは悪ではない。
弱い自分を守るため、誰かを助けるために使うこともある。

ただし、使いすぎるとオンブ側へ近づく。

### 代償の種類

| 代償 | 内容 | 表現 |
|---|---|---|
| 記憶の摩耗 | 大事な記憶が薄くなる | 会話の単語が抜ける |
| 名前の揺らぎ | 自分や相手の名前を呼びにくくなる | 名前表示がノイズる |
| 感情の過剰化 | 守りたい、急ぎたい等が暴走 | 能力が強くなるが制御しづらい |
| 灯りの黒化 | 光る持ち物が黒くなる | UIやカットインの色変化 |
| 朝への抵抗 | 朝に戻るのが怖くなる | ED条件や会話に影響 |

# キャラ別副作用

## ユイ

- 代償: 自分の灯りを信じられなくなる
- 表現: ランタンの光が小さく見える
- 会話変化: 「わたしの灯り、まだ見える？」
- ゲーム反映候補: 終了後、短時間視界/吸引範囲低下

## アサ

- 代償: 止まれなくなる
- 表現: 足元の黒火花が消えない
- 会話変化: 「止まったら、また間に合わない」
- ゲーム反映候補: 終了後、移動慣性/硬直/回避低下

## ナギ

- 代償: 道が増えすぎる
- 表現: 地図の線が黒インクで過密になる
- 会話変化: 「どれが帰り道か、分からない」
- ゲーム反映候補: 誘導線が乱れる、敵誘導が不安定化

## ミチル

- 代償: 感情を受け止めすぎる
- 表現: 水が黒く濁る
- 会話変化: 「流していいのに、流れない」
- ゲーム反映候補: 終了後、攻撃力低下/回復過多の反動

## トモリ

- 代償: 直せないものまで直そうとする
- 表現: 設置物が黒い火花を散らす
- 会話変化: 「壊れてない。まだ、壊れてない」
- ゲーム反映候補: 設置物の一部暴走、終了後クールダウン増加

## ヒヨリ

- 代償: 明るさで自分を隠せなくなる
- 表現: ネオンが黒く点滅する
- 会話変化: 「大丈夫って、言わなきゃ」
- ゲーム反映候補: 味方/自分の速度上昇後、短時間ゲージ回復低下

## シノ

- 代償: 名前を失いかける
- 表現: 名前表示にノイズ、影がほどける
- 会話変化: 「呼ばないで。消えたくなる」
- ゲーム反映候補: 回避性能上昇後、終了後操作遅延/ロックオン不安定

## クロエ

- 代償: 助けを求められなくなる
- 表現: 黒紫の刃や羽が増えすぎる
- 会話変化: 「弱いなら、消えるだけ」
- ゲーム反映候補: 高火力後、回復効果低下/被ダメ増加

## レンジ

- 代償: 過去の遅刻へ戻される
- 表現: 時計針の逆回転、秒針音
- 会話変化: 「また遅れたのか」
- ゲーム反映候補: 時間停止後、短時間スロー/操作硬直

## セリカ

- 代償: 礼儀が鎧になる
- 表現: 鏡光が黒い盾のように閉じる
- 会話変化: 「崩れてはいけません」
- ゲーム反映候補: 防御上昇後、移動速度低下/範囲縮小

## シオン

- 代償: 記録と現実の区別が薄れる
- 表現: 本の文字が黒く浮かぶ
- 会話変化: 「これは、もう起きたことですか？」
- ゲーム反映候補: 未来位置攻撃後、敵予告表示が乱れる

## マユ

- 代償: 守る気持ちが檻になる
- 表現: 温かい膜が黒い檻になる
- 会話変化: 「ここにいて。外は痛いから」
- ゲーム反映候補: シールド後、移動範囲が狭くなる/回避低下

## ダイチ

- 代償: 動けない壁になる
- 表現: 盾が巨大化して重くなる
- 会話変化: 「俺が立ってりゃいい」
- ゲーム反映候補: 被ダメ軽減後、移動速度大幅低下

## ノクス

- 代償: 心の揺れを誤差として切り捨てる
- 表現: 片眼鏡の奥で秒針が止まらない
- 会話変化: 「誤差です。私にとっては」
- ゲーム反映候補: 時間停止後、敵の次行動が高速化する反動

# システム表現

## 黒耀化ゲージ

- 被ダメージで溜まる
- 強いストレスや敗北後会話で演出的に揺れる
- ゲージMAXで任意発動または危険状態を表示

## 反動の扱い

反動はゲームを不快にしすぎない。
基本は短時間・軽め。
物語上の怖さは、会話やUI演出で見せる。

## 多用時の警告

- ランタンが黒く点滅する
- 名前表示が少し乱れる
- 拠点の食事が冷める
- ミズキやマユの日常会が発生する
- レンジが短く忠告する

---

# UI短文候補

- 黒耀化は力ではない。夜からの借り物だ。
- 使えば助かる。使いすぎれば、朝が遠くなる。
- 黒い光は敵だけでなく、自分の名前も照らしてしまう。
- 戻れるうちに、誰かの声を聞いた方がいい。

---

# 結論

黒耀化は爽快な強化でありながら、キャラの弱さが一瞬だけ能力化する危険な状態。
ゲームでは気持ちよく、物語では怖く。
この両方を守る。

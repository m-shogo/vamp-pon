# 黒耀化 20人コア設定

Vamp Pon / ヴァンサバ改における、20人分の黒耀化の中身を整理する。

これは実装仕様ではない。
キャラの弱さ、会話、日常変化、星標器の汚れ、星灯獣の反応、朝明への対比を作るための正典。

---

## 1. 黒耀化とは

黒耀化は、単なる強化でも、闇落ちでも、悪堕ちでもない。

その人の中にある弱さや願いが、黒インクによって過剰化した状態。

強くなるが、危うい。
便利だが、残る。
終わった後に、星標器や星灯獣や日常会話へ跡が出る。

---

## 2. 共通ルール

### 黒耀化で起きること

- 星標器の星灯核が曇る
- 紋章の線が太くなる
- 外環に黒インクが回る
- 星灯獣が距離を取る、隠れる、震える
- 忘れ物が重く見える
- 本人は平気なふりをする
- 星泊で黒い汚れを拭く会話が発生する

### 起きてはいけないこと

- 完全に悪役になる
- 本人の意識が完全に消える
- 見た目だけの黒バージョンになる
- 強いから使い得になる
- 黒耀化後に何も残らない
- 周囲が説教する

## 4. Core5詳細

## ユイ / 黒灯り

### 核

消えそうな灯りを守りたい気持ちが過剰化する。

### 状態

ランタンの光が黒い琥珀色になる。
星標器の星窓は曇るが、中央に小さな白い点が残る。
ユイは周囲の光を全部守ろうとして、自分の光を削ってしまう。

### 星灯獣

白い小獅子はランタンの近くから少し離れる。
怖がっているのではなく、熱すぎて近づけない。

### 星泊後

ユイは星標器を拭きながら「まだ消えてない」と小さく言う。
周囲は責めない。

### 朝明への対比

自分のためにも灯りを使っていい、と知る。

---

## アサ / 黒火走り

### 核

止まったら間に合わないという焦りが過剰化する。

### 状態

足元の火花が黒く伸びる。
星標器の外環が熱を持ち、紋章の火花が前方へ引っ張られる。
アサは前へ進むことだけに集中し、止まる選択を失う。

### 星灯獣

赤狼が追いつけなくなる。
普段は先に走る赤狼が、黒耀化中だけ後ろに残される。

### 星泊後

扉の前で立ったまま休む。
誰かに座るよう言われても、すぐには座れない。

### 朝明への対比

休むことを、遅れることではなく、待つこととして受け入れる。

---

## ナギ / 黒い地図

### 核

道を失う怖さから、道を増やしすぎる。

### 状態

星標器の星図線が増え続け、どの線も正しいように見える。
ナギは選べなくなり、地図を見るほど迷う。

### 星灯獣

白鳥が首を羽に隠す。
進む方向を示せなくなる。

### 星泊後

地図を広げるが、すぐ畳む。
線を消そうとして、消せない。

### 朝明への対比

一本だけ選ぶことは、他の道を捨てることではないと知る。

---

## ミチル / 黒水の抱擁

### 核

流せない気持ちをすべて抱え込む。

### 状態

水が黒く濁り、守るように周囲を包む。
包まれたものは安全に見えるが、外へ出づらくなる。

### 星灯獣

水蛇の透明な体が濁る。
瓶の中に隠れるように丸くなる。

### 星泊後

水瓶を見つめる時間が長くなる。
誰かに「大丈夫」と言うが、自分には言わない。

### 朝明への対比

流れても、なくなったわけではないと知る。

---

## トモリ / 黒火花の工房

### 核

直せないものを認められない。

### 状態

工具と星標器の外環から黒火花が散る。
壊れたものを無理に動かそうとして、余計に軋ませる。

### 星灯獣

作業犬が工具をくわえたまま止まり、最後には落とす。

### 星泊後

修理台から離れない。
「壊れてない」と言うが、手元は震えている。

### 朝明への対比

直らなくても、そばにいられると知る。

## 5. 追加15人詳細

## ヒヨリ / 黒い笑い灯

- 核: 笑って場を明るくしなければ、という思い。
- 状態: ネオンが黒く点滅し、笑顔の形だけが残る。
- 星灯獣: うさぎが跳ねなくなる。
- 星泊後: 冗談を言いかけてやめる。
- 朝明対比: 泣いても明るさは消えない。

## シノ / 黒い名札

- 核: 呼ばれない、忘れられる怖さ。
- 状態: 名札の文字が黒くにじみ、読めそうで読めない。
- 星灯獣: 小鳥が声を出さない。
- 星泊後: 名前を呼ばれると、一拍遅れて返事する。
- 朝明対比: 自分で名乗れる。

## クロエ / 黒羽の檻

- 核: 孤独を強さに見せること。
- 状態: 羽が広がるが、守る翼ではなく檻のようになる。
- 星灯獣: 黒羽獣が背を向ける。
- 星泊後: 高い場所にいるが、誰かの足音を聞いている。
- 朝明対比: 降りる場所を見つける。

## レンジ / 逆回りの時

- 核: 戻らない時間に囚われる。
- 状態: 星標器の針が逆回転し、同じ一分を繰り返すように見える。
- 星灯獣: 老狼が同じ場所で待ち続ける。
- 星泊後: 時計を直すが、また一分だけ遅れる。
- 朝明対比: 次の一分へ進める。

## セリカ / 黒鏡の礼

- 核: 綺麗な自分しか許せない。
- 状態: 鏡面が黒い鎧のように閉じる。
- 星灯獣: 白孔雀が羽を閉じる。
- 星泊後: 鏡を包んだ布をほどけない。
- 朝明対比: 割れた姿も受け入れる。

## シオン / 黒文字の頁

- 核: 残せなかった記録への後悔。
- 状態: 空白のページに黒い文字のようなものが浮かぶが、読めない。
- 星灯獣: ふくろうが目を伏せる。
- 星泊後: メモしようとして、ペンを置く。
- 朝明対比: 空白も記録になる。

## マユ / 黒い温室

- 核: 誰かを温めるために、自分の冷えを見ない。
- 状態: 温かい膜が黒い温室のように閉じる。
- 星灯獣: 小熊が近づけない。
- 星泊後: 毛布を渡すが、自分は使わない。
- 朝明対比: 自分も温めていい。

## ダイチ / 黒蓋の壁

- 核: 全部受け止めれば守れるという思い。
- 状態: 鍋蓋のような紋章が黒く重くなり、壁になる。
- 星灯獣: 大熊が前に出すぎて動けなくなる。
- 星泊後: 出入口の前に座る。
- 朝明対比: 守られる側にもなれる。

## ノクス / 黒レンズ

- 核: 見逃した一瞬への固執。
- 状態: 片眼鏡のレンズに黒いノイズが走る。
- 星灯獣: 夜鳥が瞬きをしない。
- 星泊後: 何もない一点を見続ける。
- 朝明対比: 今見えるものを選ぶ。

## コハル / 黒芽の蔓

- 核: 早く咲かなければという焦り。
- 状態: 芽が黒い蔓になり、星標器に絡む。
- 星灯獣: 子鹿が後ずさる。
- 星泊後: 伸びたか何度も確認する。
- 朝明対比: 芽のままで価値がある。

## イオリ / 黒い誓い結び

- 核: 守れなかった約束への執着。
- 状態: 結び目が黒く締まり、ほどけなくなる。
- 星灯獣: 小牛のベルが鳴らない。
- 星泊後: ボタンを握りしめて離せない。
- 朝明対比: 新しい約束を結べる。

## ラン / 黒響のノイズ

- 核: 届かなかった音を追い続ける。
- 状態: 音波が黒いノイズになり、周囲の音を歪ませる。
- 星灯獣: イルカが水面から消える。
- 星泊後: 片耳イヤホンを耳に当てても、何も聞かない。
- 朝明対比: 遠い音も残っている。

## カナタ / 黒遠の視界

- 核: 遠くを見るほど近くを見落とす。
- 状態: 遠い星だけが見え、手元が暗くなる。
- 星灯獣: 鷹が低く飛べない。
- 星泊後: 近くの物にぶつかる。
- 朝明対比: 帰る場所を手元から見つける。

## スバル / 黒跳びの足跡

- 核: 止まることへの怖さ。
- 状態: 足跡が黒く連なり、止まっても先へ走り続けるように見える。
- 星灯獣: 山羊が着地できない。
- 星泊後: 靴紐を結んでもすぐほどく。
- 朝明対比: 立ち止まる場所を選べる。

## アカリ / 黒守りの毛布

- 核: 守るつもりで閉じ込める。
- 状態: 毛布のような光が黒く閉じ、外と内を分けすぎる。
- 星灯獣: 星猫が毛布から出ない。
- 星泊後: 休憩場所の周りを囲いすぎる。
- 朝明対比: 守ることは、外へ出られる場所を作ること。

## 6. 黒耀化後の会話ルール

### 良い

- 責めない
- 理由を問い詰めない
- 星標器の汚れを拭く
- 星灯獣の距離で見せる
- 本人が平気なふりをする
- 周囲が小さな行動で支える

### NG

- すぐに謝罪大会にする
- 長い説教をする
- 黒耀化をかっこいいだけにする
- 一回で克服させる
- 毎回泣かせる

---

## 7. まとめ

黒耀化は、キャラごとの弱さを可視化する装置。

ただし、罰ではない。
完全な闇落ちでもない。

黒く染まっても、星灯核の光は残る。
だから朝明へつながる。

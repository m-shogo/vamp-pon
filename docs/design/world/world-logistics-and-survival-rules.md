# Current decided rules

## ヨルノシルベはDream world

- 共有夢に近い。
- 最終mechanism / 起源はOpen。
- **朝は来ない。**
- Realityへは**Waking**で戻る。

## Survival simではない

Dreamで基本的に困窮させない:

- 食事
- 飲み物
- 日用品
- basic clothing補完
- 休息場所

食べたい物 / 飲みたい物はDreamらしく自然に現れてよい。

通常Economy / food stock / water supply / laundry / lodging feeをMain Storyの必須systemにしない。

## 願望万能ではない

Materializeできない / 願いだけで変えられない:

- 他人の心
- 同意
- 記憶の真実
- trauma
- Relationship
- Black Youka
- Reality incident
- Life / death
- 本人のauthentic choice

> **物は出せても、他者の意思は作れない。**

## Water

旧「記憶の水を飲むと記憶が戻る / 飲み過ぎると危険」はCurrent ruleではない。

水 / tea / coffee等は普通のDream daily-life itemとして扱える。

特殊な川 / 井戸 / water phenomenonを作る場合は個別Stage Candidateとして審査し、全世界の水ruleへしない。

## Sleep / fatigue

Dream内で休む / 眠るsceneは使える。

ただし:

- survival sleep gauge必須化しない
- sleep = Realityへ自動帰還とも固定しない
- Dream内で眠ることのmetaphysicsを勝手にCanon化しない

## Defeat

- Game Over ≠ Reality death
- Retry ≠ resurrection
- defeat後のpresentationはDream combat state

旧「朝へ帰る感覚を失う」は使用しない。

## Base / hub

駅舎 / room / bench / workshop / fire / waiting room等はDreamの自然なrest / relation landmarkとして存在できる。

ただし:

- 中央の灯りが食料を生成する
- 拠点の灯りが全員の生存power
- 朝になると拠点がRealityへ重なる

等はCurrent hard ruleではない。

個別visual / Stage Candidateとして再採用する場合はMaster整合を確認する。

## Economy

Dreamに通常Money systemを必須化しない。

Gameplay resourceを:

- food price
- hotel fee
- survival utility

へ自動変換しない。

`記憶片`等のGameplay currencyはGame design側で管理する。

# Era-gap daily life

Dream livingが自由だからこそ:

- old-era Characterがmodern foodを知らない
- modern Characterがold packagingを知らない
- Androidがfood ritualをsocial behaviorとして観察する
- dog / catが匂いへ反応する

などのordinary sceneに尺を使う。

「食べるために資源集め」ではなく「一緒に食べるからCharacterを好きになる」を優先する。

# Migration guard

この旧pathを参照するagentは:

- `朝へ帰る`
- `朝が来る`
- `夜は夢ではない`
- `normal economy required`
- `food / water shortage drives survival`

をCurrentへ戻してはいけない。

必要な旧ideaは個別に`CANDIDATE`として取り出し、新Masterへ照合してから再利用する。

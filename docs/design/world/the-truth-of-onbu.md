# オンブの正体と敵側ルール

Vamp Pon / ヴァンサバ改の敵であるオンブ / オンブロの正体を整理する。

オンブは単なるモンスターではない。
夜の世界のテーマである、忘れ物、記憶、言えなかった言葉、黒インクと直結する存在。

---

## 基本結論

オンブは、人の形を失った記憶の影。

> 忘れられた記憶、言えなかった言葉、置いていかれた感情が、黒インクで輪郭を持ったもの。

倒すというより、ほどく、薄める、朝へ返す。

---

# 1. オンブが生まれる条件

オンブは自然発生する敵ではない。
以下のようなものから生まれる。

- 誰にも言えなかった言葉
- 置いていかれた約束
- 持ち主のいない忘れ物
- 名前を呼ばれなくなった記憶
- 朝に戻れなかった感情
- 黒インクで隠された痛み

## 例

- 小さなオンブ: 小さな後悔、忘れ物、短い言葉
- 中型オンブ: 強い未練、消された記録
- オンブロ: 誰かの人生を大きく変えた記憶の塊
- ボス: キャラ本人の夜の核、または街全体の忘却

---

# 2. オンブと人間の関係

## 元人間ではない

オンブは人間そのものではない。
だから倒しても人が死ぬわけではない。

ただし、人の記憶や感情から生まれるため、完全に無関係でもない。

## 倒すことの意味

オンブを倒すとは、敵を殺すことではない。

- 黒インクを薄める
- 記憶をほどく
- 言えなかった言葉を返す
- 忘れ物を持ち主へ近づける
- 朝へ戻す

## 消え方

オンブは爆発して消えるより、以下の演出が合う。

- 紙片になる
- 黒インクが薄まる
- 小さな光に戻る
- 落とし物を残す
- 星座の点になる

---

# 3. オンブの種類

## オンブ

小型。

### 正体

小さな忘れ物や言葉から生まれた影。

### 見た目

- 腕なし
- 短い1本のインク芽
- 顔前モヤ薄
- 口なし
- 柔らかい影

### 行動

- ふらふら近づく
- ときどき止まる
- プレイヤーを直接憎んでいるわけではない

### 倒した時

小さな欠片や紙片を落とす。

---

## オンブロ

大型。

### 正体

強い未練や繰り返された後悔から生まれた影。

### 見た目

- 両腕太い
- 手先鈍い3房
- 頭芽2本
- 影炎が長い
- 待機で垂れる

### 行動

- 腕を伸ばす
- 範囲攻撃
- 通路を塞ぐ
- プレイヤーの帰り道を邪魔する

### 倒した時

大きめの忘れ物や、ステージ固有の記憶断片を落とす。

---

## オンブロ・ボス

### 正体

ステージやキャラの夜の核。

例:

- ユイの夜: 消えかけたランタン型のボス
- アサの夜: 走り続ける影狼
- ナギの夜: 破れた地図の鳥
- ミチルの夜: 黒い水蛇
- トモリの夜: 壊れた作業灯の巨影

### 倒した時

朝が近づく。
ただし、倒すだけで完全解決ではない。
最後に「受け止める」会話や日常会が必要。

---

# 4. 七つの大罪との接続

敵側テーマに七つの大罪を使う場合、直接的な悪魔ではなく、記憶の歪みとして扱う。

| 大罪 | Vamp Ponでの意味 | 敵の方向性 |
|---|---|---|
| 傲慢 | 弱さを認められない | クロエ/セリカ系の鏡敵 |
| 嫉妬 | 誰かの朝を羨む | 分身/追尾敵 |
| 憤怒 | 間に合わなかった怒り | 突進敵 |
| 怠惰 | もう進みたくない | 鈍化/足止め敵 |
| 強欲 | 忘れ物を手放せない | アイテム吸着/奪取敵 |
| 暴食 | 記憶を飲み込み続ける | 大型吸引敵 |
| 色欲 | ここでは恋愛でなく執着 | 依存/引き寄せ敵 |

## 注意

- 宗教色を強くしすぎない。
- 露骨な悪魔デザインにしない。
- 記憶・感情・黒インクの歪みとして扱う。

# 6. オンブは救うべきか

## 基本

オンブはかわいそうな存在だが、放置すると人を夜へ引き込む。

そのため、戦うことは必要。
ただし、倒すというより戻す。

## キャラごとの向き合い方

| キャラ | オンブへの見方 |

| ユイ | 置いていかれたもの |
| アサ | 追い越すべき影 |
| ナギ | 道を塞ぐ迷い |
| ミチル | 流せなかった涙 |
| トモリ | 壊れたままの灯り |
| ヒヨリ | 笑えなくなった気持ち |
| シノ | 自分に近いもの |
| クロエ | 弱さの残骸 |
| レンジ | 帰せなかったもの |
| セリカ | 礼を失った痛み |
| シオン | 消された記録 |
| マユ | 食卓に戻れない人 |
| ダイチ | 守れなかった背中 |
| ノクス | 誤差として処理された記憶 |

# 7. 敵撃破演出ルール

## 通常敵

- 小さな黒インク粒がほどける
- 紙片や欠片になる
- 経験値は「記憶の欠片」的に見せる

## 中型敵

- 小さな忘れ物を落とす
- 影炎が短くなって消える
- 最後に一瞬だけ元の形のヒントが見える

## ボス

- 完全消滅ではなく、夜の背景が少し明るくなる
- キャラの会話が入る
- 朝EDの条件に近づく

---

# 8. プレイヤーへの情報開示

## 序盤

オンブは「夜の影」とだけ説明。
怖すぎず、でも不気味に。

## 中盤

オンブが忘れ物や記憶と関係していることが分かる。
倒した後に小物が残る。

## 終盤

オンブは人の感情の残りだと分かる。
倒すことは殺すことではなく、朝へ返すことだと分かる。

## 真相

オンブを完全に消すことはできない。
人が忘れる限り、夜はまた生まれる。
ただし、灯りを持って戻ることはできる。

---

# UI短文候補

- オンブは敵だ。でも、最初から敵だったわけじゃない。
- 黒インクは記憶に輪郭を与える。輪郭を持った痛みは、夜を歩き出す。
- 倒すのではなく、ほどく。
- 忘れ物は、持ち主の名前を待っている。
- 朝へ返せなかったものが、オンブになる。

---

# 結論

オンブはVamp Ponの敵であり、テーマそのもの。

倒すと気持ちいい。
でも倒した後に、少しだけ寂しさが残る。

この温度がVamp Ponに合う。

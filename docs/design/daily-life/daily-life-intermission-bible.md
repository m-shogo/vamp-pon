# 日常会・生活感イベント設計バイブル

Vamp Pon / ヴァンサバ改は、夜・戦闘・黒耀化・朝EDの設計が固まってきた。
次に強化するべきは、キャラが戦っていない時間。

人気キャラになるためには、戦闘中の性能だけでは足りない。

> この人は、朝どう起きて、何を食べて、どんな嘘をついて、眠れない夜に何をしているのか。

これを定義すると、キャラが「設定」から「生活している人」になる。

---

## 日常会システム方針

### 1日の流れ

1. 夜: 戦闘
2. 朝: リザルト
3. 拠点: 帰還
4. 日常会: 食事、掃除、雑談、買い物、眠れない夜
5. 次の夜: ステージ選択

### 日常会の役割

- キャラの生活感を出す
- 好感度会話の入口にする
- 戦闘の重さを中和する
- キャラ同士の関係を自然に見せる
- ロード中会話、拠点会話、リザルト後会話に使い回す

### やらないこと

- ただのギャグ会話にしない
- 恋愛カップル前提にしない
- キャラを説明させない
- 全員に同じテンションで喋らせない
- 日常会で本筋を全部説明しない

# 4コマ会話サンプル

## ヒヨリ × レンジ / 苦いコーヒー

ヒヨリ: おじさん、これ苦い！

レンジ: 子どもだな。

ヒヨリ: 砂糖ないの？

レンジ: ない。人生にもな。

ヒヨリ: それは重いって。

## ユイ × アサ / 靴紐

ユイ: アサ、また靴紐。

アサ: ほどけてない。確認してるだけ。

ユイ: 走る前、いつもやってる。

アサ: ……置いていかないため。

## シノ × ヒヨリ / 普通

ヒヨリ: シノ、朝ごはん食べた？

シノ: いらない。

ヒヨリ: じゃあ半分だけ。

シノ: いらないって。

ヒヨリ: 半分の半分。

シノ: ……少しだけ。

## セリカ × クロエ / 手袋

クロエ: また手袋を直してる。

セリカ: 乱れていると、落ち着かないだけです。

クロエ: 本音を隠す癖ね。

セリカ: あなたほど、分かりやすくはありません。

クロエ: 言うようになったじゃない。

## マユ × ミズキ / 座って

ミズキ: マユ、座ってください。

マユ: ミズキさんこそ、座ってください。

ミズキ: 私は平気です。

マユ: それ、私がよく言うやつです。

ミズキ: ……座ります。

# 日常会の解放設計

## 解放タイミング

| 条件 | 解放する日常会 |
|---|---|
| 初回帰還 | 朝の拠点会話 |
| 好感度Lv1 | 食事/掃除など軽い会話 |
| 好感度Lv2 | 癖や嘘に触れる会話 |
| 好感度Lv3 | 眠れない夜 |
| 好感度Lv5 | 朝ED後の日常会 |
| 黒耀化を一定回数使用 | 黒耀化後の体調会話 |
| 敗北後 | 励まし/沈黙/反省会 |

## 実装方針

- まずは本文短めでよい。
- 1イベントは3〜6行。
- 長いイベントより、短い会話を多く置く。
- ロード中、拠点、リザルト後で使い回す。
- 日常会はスキップ可能にする。
- 未読表示は小さく、押し付けない。

# 結論

日常会は、Vamp Ponのキャラを人気にするための核。
夜の戦闘が重いほど、朝と拠点の短い生活会話が効く。

戦っている時は能力が見える。
戦っていない時に、人柄が見える。

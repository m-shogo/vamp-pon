# 日常会イベント拡張パック

このドキュメントは、`daily-life-intermission-bible.md` の続き。
Vamp Pon / ヴァンサバ改のキャラを「戦闘外でも生きている人」にするため、日常会のバリエーションを増やす。

対象カテゴリ:

1. 買い物イベント
2. 拠点の席順
3. 季節行事
4. 敗北後の会話
5. 勝利後の小会話
6. 誰が誰を探すか
7. 贈り物・拾い物
8. ロード中ミニ会話

---

## 目的

- 好感度会話以外でもキャラの関係性を見せる。
- 戦闘後のテンションを整える。
- 1プレイ後に「もう1回見たい」と思える会話を増やす。
- キャラ選択やサブキャラ選択の理由を、性能だけでなく関係性にも広げる。

---

# 1. 買い物イベント

## 基本方針

買い物は、キャラの金銭感覚・寄り道癖・好きなもの・誰に買うかが見える。

| キャラ | 買い物の特徴 | 買いがちなもの | 会話フック |
|---|---|---|---|
| ユイ | 必要なものだけ買おうとするが、小物に弱い | 小さなランタン部品、栞 | 誰かの忘れ物を拾う |
| アサ | 早い。試着や比較が苦手 | 靴紐、手袋、補給食 | 店を出るのが早すぎる |
| ナギ | 地図や紙ものに寄る | 地図、紙、鉛筆 | 迷子にならないが店で迷う |
| ミチル | 香りや水回り用品を見る | 石鹸、ハーブ、水筒 | 静かに選ぶ |
| トモリ | 工具売り場から動かない | ネジ、工具、電池 | 予算を忘れる |
| ヒヨリ | 寄り道が多い | お菓子、写真シール、髪飾り | 誰かに似合うものをすぐ見つける |
| シノ | 人混みが苦手 | 小さいノート、黒いリボン | いなくなる |
| クロエ | 目的買い。無駄を嫌う | 手入れ道具、黒い布 | ヒヨリに余計なものを持たされる |
| レンジ | 買い物に付き合わされる側 | コーヒー、煙草風の小物、時計部品 | 荷物持ちになる |
| セリカ | 予算と礼儀を守る | 白いハンカチ、紅茶、手袋 | ヒヨリの衝動買いを止める |
| シオン | 本屋から出てこない | 古本、メモ帳 | 会計前に読み始める |
| マユ | みんなの食材を買う | パン、ミルク、はちみつ | 自分の好きなものを後回し |
| ダイチ | 大量購入 | 芋、米、鍋具材 | 買い物かごが重すぎる |
| ミズキ | 薬局に寄る | 包帯、薬瓶、体温計 | 体調を見抜く |
| ノクス | 買うものが正確 | 時計、インク、手帳 | 無駄がないが少し不気味 |

## 買い物ミニ会話例

### ヒヨリ × セリカ

ヒヨリ: セリカ、これ似合う！

セリカ: それは……少し派手ではありませんか。

ヒヨリ: だからいいんじゃん。夜でも見つけやすいし。

セリカ: 実用性で押してくるのはずるいです。

### トモリ × レンジ

トモリ: このネジ、もう売ってないと思ってた。

レンジ: 目が輝いてるぞ、小僧。

トモリ: 小僧じゃない。あと、これも買う。

レンジ: 予算って知ってるか。

# 2. 拠点の席順

席順は関係性を無言で見せるUI演出に使える。

## 食卓の基本配置

| 席 | 座りやすいキャラ | 理由 |
|---|---|---|
| 入口近く | アサ、レンジ、クロエ | すぐ動ける位置を選ぶ |
| 窓際 | ユイ、シノ、ナギ | 外や灯りを見たい |
| キッチン近く | マユ、ダイチ、ミズキ | 食事や体調を見るため |
| 机の端 | トモリ、シオン | 道具や本を広げたい |
| 中央 | ヒヨリ | 会話を回す |
| きれいな席 | セリカ | 姿勢と配置を気にする |

## 席替えで見せる関係変化

- 初期シノは窓際の端に座る。
- 好感度が上がると、ヒヨリが近くに座っても逃げなくなる。
- クロエは最初入口近く。ユイやセリカのイベント後、中央に近づく。
- レンジは必ず端に座るが、トモリが隣に工具を広げるようになる。
- ユイは最初空席を挟む。後半は誰かの隣に自然に座る。

# 3. 季節行事

季節行事は期間限定イベント・スキン・ログイン会話に使える。
恋愛イベントに寄せすぎず、家族感・仲間感・驚き・友情を中心にする。

## 春

### 花見

- ユイ: 散った花びらを拾う。
- アサ: 場所取りが早すぎる。
- ナギ: 風向きを読む。
- ミチル: 花びらが水に浮くのを見る。
- ヒヨリ: 写真を撮りすぎる。
- セリカ: 弁当の配置が美しい。

会話例:

ヒヨリ: ユイ、花びらついてる！かわいい！

ユイ: え、どこ？

アサ: 写真撮る前に取ってあげなよ。

ヒヨリ: それはそれ、これはこれ！

## 夏

### 夜店

- ヒヨリ: 全屋台を見たい。
- ダイチ: 食べ物担当。
- シノ: 人混みに弱い。
- クロエ: 射的だけ異常に強い。
- レンジ: 金魚すくいが地味に上手い。

## 秋

### 読書と焼き芋

- シオン: 読書。
- マユ: 焼き芋。
- ダイチ: 火加減。
- ナギ: 落ち葉で道を作る。
- トモリ: 火ばさみを改造しようとする。

## 冬

### 雪の日

- ユイ: 足跡を見て少し嬉しい。
- アサ: 走って滑る。
- ミチル: 雪が溶けるのを見ている。
- レンジ: 寒いと言わないがコートを増やす。
- セリカ: 手袋を貸す。
- クロエ: 寒さに強いふりをする。

# 4. 敗北後の会話

敗北後は、責めるのではなくキャラの反応を出す。
プレイヤーが再挑戦したくなる空気を作る。

| キャラ | 敗北後の反応 | 台詞例 |
|---|---|---|
| ユイ | 静かに悔しがる | 「まだ、灯ってる。もう一回行ける」 |
| アサ | すぐ立とうとする | 「次は止まらない。……いや、ちゃんと見る」 |
| ナギ | 敗因を道として見る | 「今の道は違った。印をつけよう」 |
| ミチル | まず傷を見る | 「悔しいのはあと。先に手当てしよう」 |
| トモリ | 装備を見直す | 「壊れた理由がある。そこを直す」 |
| ヒヨリ | 明るくしようとして少し失敗 | 「惜しかった！……うん、悔しいね」 |
| シノ | 黙る | 「……次、行くならついていく」 |
| クロエ | 厳しいが見捨てない | 「弱い。でも終わってはいない」 |
| レンジ | 短く促す | 「起きろ。負けは終わりじゃない」 |
| セリカ | 姿勢を整える | 「悔しいなら、次の準備をしましょう」 |
| シオン | 記録する | 「今の失敗、残しておきます」 |
| マユ | 温かいものを出す | 「まず飲んで。話はそれから」 |
| ダイチ | 盾になる | 「次は俺がもう一歩前に出る」 |
| ミズキ | 休ませる | 「反省は寝てからです」 |
| ノクス | 冷静に分析 | 「敗因は三つ。ですが、再現は可能です」 |

# 5. 勝利後の小会話

勝利後は大きな勝利演出だけでなく、短い会話を挟むと余韻が出る。

## 勝利後の反応タイプ

| タイプ | キャラ | 方向性 |
|---|---|---|
| ほっとする | ユイ、ミチル、マユ | 静かな安堵 |
| すぐ次を見る | アサ、クロエ、ノクス | 余韻が短い |
| 記録する | ナギ、シオン、コハク | 体験を残す |
| 整備する | トモリ、レンジ、ミズキ | 状態確認 |
| 盛り上げる | ヒヨリ、ダイチ | 場を明るくする |
| 礼を整える | セリカ | 丁寧な締め |

### 勝利後会話例

ユイ: 朝、少し近いね。

ナギ: うん。道も残ってる。

アサ: じゃあ行こう。止まる理由ないでしょ。

ミチル: 休む理由はあるよ。

トモリ: 装備点検してからだ。

# 7. 贈り物・拾い物

Vamp Ponは「忘れ物」がテーマなので、贈り物より拾い物が似合う。

## 拾い物の方針

- アイテムは高価でなくてよい。
- 誰かの記憶の断片に見えるものにする。
- 渡す相手で会話が変わる。

| 拾い物 | 合うキャラ | 会話用途 |
|---|---|---|
| 小さな鈴 | ユイ、ヒヨリ | 音がまだ鳴る |
| 折れた鉛筆 | ナギ、シオン | 書けなくても残る |
| 錆びたネジ | トモリ、レンジ | 直せる/直さない話 |
| 白いハンカチ | セリカ、ミチル | 汚れと礼儀 |
| 焦げたマッチ | アサ、クロエ | 火と力 |
| 欠けた皿 | マユ、ダイチ | 食卓と欠けた場所 |
| 黒い羽 | シノ、クロエ | 影と名前 |
| 古い切符 | ノクス、レンジ | 時間と帰り道 |

# 8. ロード中ミニ会話

1〜3行で終わる会話。
ステージロード、リトライ、拠点遷移に使う。

## 例

### ユイ + アサ

アサ: 走れる？

ユイ: 走る。ゆっくりなら。

アサ: それ、走るって言う？

### ヒヨリ + クロエ

ヒヨリ: クロエ、今日も黒いね。

クロエ: 服の話？

ヒヨリ: たぶん気分も。

クロエ: 否定はしない。

### レンジ + セリカ

セリカ: レンジ、服の襟が乱れています。

レンジ: 夜に襟を気にする余裕があるのか。

セリカ: 余裕ではなく、習慣です。

### シノ + ユイ

シノ: ランタン、消えないの。

ユイ: 消さないようにしてる。

シノ: ……そう。

### トモリ + ミチル

ミチル: また寝てない？

トモリ: 寝た。

ミチル: 何分？

トモリ: ……時間で言うな。

# 結論

日常会は、戦闘の外側でキャラ人気を作るための最重要要素。
短い会話を積み重ねることで、Vamp Ponの世界は「設定」ではなく「生活」になる。

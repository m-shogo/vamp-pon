# 星標器 UI組み込み計画

Vamp Pon / ヴァンサバ改の共通デバイス **星標器（せいひょうき）** を、実際のゲームUIへ落とし込むための設計メモ。

目的は、設定だけで終わらせず、スマホ縦画面のプレイ体験、必殺、黒耀化、リザルト、キャラ選択、グッズ導線までつなげること。

---

## 1. UIに入れる目的

星標器をUIに入れる理由は、世界観説明ではなくプレイヤー体験のため。

1. 必殺ゲージを作品固有の見た目にする
2. 黒耀化ゲージを自然に表現する
3. キャラごとの紋章差分を覚えてもらう
4. 星灯獣や忘れ物への導線を作る
5. グッズ展開とゲーム画面の記号を一致させる

---

## 2. スマホ縦画面での基本配置

想定: 390x844 縦画面。

### 戦闘HUD

| 場所 | 要素 | 星標器との関係 |
|---|---|---|
| 右下 | 必殺ボタン | 星標器の小型版を中心に置く |
| 右上 | 黒耀化/必殺状態 | 外環の黒インク進行で表示 |
| 上部 | HP/時間/Lv | 星標器は置きすぎない |
| リザルト | 成長表示 | 紋章の光・黒耀汚れ・朝明差分 |
| キャラ選択 | キャラカード | 星標器+紋章+星灯獣を1セット表示 |

---

## 3. 必殺ボタン案

必殺ボタンは、ただの丸ボタンではなく星標器にする。

### 通常状態

- 外環は薄い真鍮色
- 中央にキャラ紋章
- 星灯核は弱く点灯
- タップ可能だが主張しすぎない

### ゲージ増加中

- 外環に光が時計回りで溜まる
- 25%ごとに小さな星点が1つ点く
- 75%以降、星窓が少し明るくなる

### 必殺可能

- 星灯核が一度だけ脈打つ
- 紋章がわずかに拡大
- 星灯獣の小さなシルエットが一瞬出る
- ボタン周囲に白金の輪

### 発動時

- 星標器が画面手前へ一瞬拡大
- 紋章線が横へ走る
- キャラカットインへ接続
- 画面全体が一瞬だけ明るくなる

---

## 4. 黒耀化ゲージ案

黒耀化は、別の禍々しいゲージを作らず、星標器の外環が侵食される表現にする。

| 進行 | 見た目 | プレイヤーの理解 |
|---:|---|---|
| 0% | 通常の外環 | 安全 |
| 25% | 黒い点が外環に出る | 少し溜まった |
| 50% | 黒インクが外環の半分弱に回る | もうすぐ危険 |
| 75% | 星灯核の周囲が曇る | 黒耀化が近い |
| 100% | 紋章が黒耀状態へ反転 | 発動可能/強制候補 |

### 重要

黒耀化は「かっこいい強化」だけに見せない。
UI上でも、少し怖い、少し危ない、でも使いたくなる状態にする。

---

## 5. キャラ選択UI

キャラ選択では、キャラの横に星標器を置く。

### カード構成

1. キャラ名
2. 役割タグ
3. キャラ立ち絵
4. 星標器
5. 紋章名
6. 星灯獣
7. 忘れ物
8. 得意/不得意

### 例: ユイ

- 役割: 標準 / 回収 / 灯り
- 紋章: 灯
- 星灯獣: 白い小獅子
- 忘れ物: 古いランタン札
- UIコピー: 小さな灯りで、夜を少しずつほどく。

---

## 6. リザルトUI

リザルトは、星標器が少し変化する場面にする。

### 表示するもの

- 今回の欠片
- キャラ経験値
- 好感度
- 黒耀使用回数
- 朝ED進行
- 新規紋章/星灯獣/忘れ物解放

### 星標器演出

| 結果 | 星標器表現 |
|---|---|
| キャラLvアップ | 紋章が一段強く点灯 |
| 好感度上昇 | 星図線が相手の紋章へ伸びる |
| 黒耀化使用 | 外環に黒い汚れが残る |
| ノーダメ/高評価 | 星灯核が澄む |
| 朝ED達成 | 朝明状態へ変化 |

---

## 7. 拠点/強化画面

永続強化やキャラ育成にも星標器を使う。

### 画面名案

- 星のしるべ
- 紋章帳
- 忘れ物保管所
- 星灯獣の小部屋
- 朝への記録

### 育成導線

1. 欠片を集める
2. 星標器の外環を修復する
3. 紋章の光を強くする
4. 星灯獣の仕草が増える
5. キャラ固有の朝ED条件が見える

---

## 8. ペア必殺UI

ペア必殺は、2つの星標器が並ぶ演出にする。

### 流れ

1. 片方の紋章が光る
2. もう片方の紋章線が伸びる
3. 2つの星標器が重なる
4. 星灯獣が2体一瞬現れる
5. ペア必殺名が出る

### 表示の注意

- 恋愛演出に寄せすぎない
- 友情、家族、約束、補完関係で見せる
- 紋章同士の相性で覚えられるようにする

---

## 9. 初期実装の優先順位

### Phase 1: 最小実装

- 必殺ボタンを星標器風にする
- 中央にキャラ紋章を表示
- 必殺可能時に脈打つ
- 黒耀化ゲージは外環の黒インクで表示

### Phase 2: キャラ選択

- キャラカードに星標器を追加
- 紋章名を表示
- 星灯獣アイコン枠を追加
- 忘れ物アイコン枠を追加

### Phase 3: リザルト

- キャラLvアップ時に紋章点灯
- 好感度上昇時に星図線
- 黒耀使用時に汚れ演出
- 朝ED達成で朝明差分

### Phase 4: 拠点

- 紋章帳
- 忘れ物保管所
- 星灯獣一覧
- 星標器修復/強化画面

---

## 10. 実装で守ること

### 視認性

- 64px以下でも紋章が読める
- 黒耀ゲージと必殺ゲージを混同しない
- 色だけで状態を判別させない
- ボタンとして押せることがすぐ分かる

### 画面密度

- 戦闘中に星灯獣を常時出さない
- 星標器は右下/リザルト/選択画面に絞る
- HUD上部には詰め込みすぎない
- エフェクトは派手でも、判定や敵を隠さない

### 世界観

- 星標器を説明しすぎない
- UI演出で意味を分からせる
- 黒耀化は便利だが少し怖い
- 朝明は明るいが、夜の記憶を消さない

## 12. 実装者向けプロンプト

```text
対象repo: /Users/m-shogo/Developer/personal/vamp-pon のみ。
Vamp Pon / ヴァンサバ改の戦闘HUDに、共通デバイス「星標器」をUIとして組み込む。

目的:
- 必殺ボタンを星標器風にする
- 中央にキャラ紋章を表示する
- 必殺ゲージは星標器外環の光で表現する

- HUD上部に情報を増やしすぎない

- 必殺可能時は脈動、黒耀化100%時は黒インク反転
- 将来、紋章20種差し替えに対応できるようにする

注意:
- 星標器はスマホではなく、懐中時計/コンパス/小ランタン/忘れ物札の混合デザイン
- 黒耀化は単なる黒い強化ではなく、壊れそうだがまだ光が残る状態
- UIはゲームプレイを邪魔しないことを最優先
```

---

## 13. まとめ

星標器は、設定資料の中だけに置かない。

必殺ボタン、黒耀化ゲージ、キャラ選択、リザルト、拠点強化に入れることで、プレイヤーが自然に覚える共通記号になる。

ゲームで見たものが、そのままキーホルダー、紋章プレート、星灯獣マスコット、忘れ物チャームへつながる状態を目指す。

## コピペ用プロンプト

```text
あなたは /Users/m-shogo/Developer/personal/vamp-pon のみを対象に作業してください。
GitHub repo は https://github.com/m-shogo/vamp-pon.git です。
このrepo以外は絶対に触らないでください。

目的:
Vamp Pon / ヴァンサバ改の戦闘HUDに、共通デバイス「星標器（せいひょうき）」をUIとして組み込む。
既存の必殺ボタン/黒耀化ゲージを、作品固有の記号へ寄せる。

必ず先に読む資料:
- docs/design/ip/common-device-and-emblem-system.md
- docs/design/ip/seihyoki-visual-and-product-rules.md
- docs/design/ui/seihyoki-ui-integration-plan.md
- docs/design/ip/emblem-roster-20-character-expansion.md
- docs/design/ip/seihyoki-asset-prompt-pack.md

実装範囲 Phase 1:
1. 既存の必殺ボタンを星標器風の丸型UIへ変更
2. 中央にキャラ紋章を表示できる構造を追加
3. 必殺ゲージを星標器の外環の光として表示
4. 黒耀化ゲージを同じ外環の黒インク侵食として表示
5. 必殺可能時に星灯核が脈打つ演出を追加
6. 黒耀化100%時に紋章/外環が黒く反転する演出を追加
7. 390x844スマホ縦画面で邪魔にならないサイズにする

重要仕様:
- 星標器はスマホではない
- 古いコンパス/懐中時計/小ランタン/忘れ物札/星座盤の混合デザイン
- 右下の必殺ボタン位置は大きく変えない
- HUD上部に情報を増やさない
- 64px前後でも読める簡略デザインにする
- 色だけで状態を判別させない
- 必殺ゲージと黒耀化ゲージを混同させない
- 敵、弾、経験値、HP表示を隠さない

演出仕様:
通常:
- 星標器の外環は薄い真鍮/古銀風
- 中央に紋章プレースホルダー
- 星灯核は弱く点灯

必殺ゲージ増加:
- 外環に白金〜キャラ色の光が時計回りに溜まる
- 25/50/75/100%で星点が増える

必殺可能:
- 星灯核が一度脈打つ
- 紋章が少しだけ拡大
- 外環に短いグロー
- 過剰に眩しくしない

黒耀化ゲージ:
- ダメージ蓄積で外環に黒インクが回る
- 25%: 小さな黒点
- 50%: 外環の半分弱まで侵食
- 75%: 中央の星灯核が少し曇る
- 100%: 紋章が黒耀状態へ反転

黒耀化中:
- 星灯核に光は残す
- 完全な悪役アイコンにしない
- 壊れそうだが、まだ光がある状態

実装方針:
- まず既存HUD構造を調査
- 既存の入力/必殺処理を壊さない
- 見た目だけを安全に差し替える
- 新しい定数や描画関数は分離する
- 将来、紋章20種を差し替えられるよう emblemKey / characterId を受けられる構造にする
- 画像素材が無い場合は、Canvas/Graphics描画の仮UIで実装してよい
- 仮UIでも、星標器の外環/中央核/紋章座/黒インク侵食が分かるようにする

やってはいけないこと:
- repo外を触る
- gameplay数値を勝手に大きく変える
- 必殺の発動条件を壊す
- 黒耀化の蓄積仕様を変える
- HUDを派手にしすぎてゲーム画面を隠す
- 星標器をただの丸ゲージにする
- 黒耀化をただの赤/黒ゲージにする

検証:
- pnpm check / test / build など、このrepoで定義されている検証を確認して実行
- 390x844想定で表示崩れがないか確認
- 必殺ゲージ0/50/100%の表示確認
- 黒耀化ゲージ0/50/100%の表示確認
- 必殺ボタンが押せることを確認
- 既存のゲーム進行が壊れていないことを確認

完了時に報告すること:
- 変更ファイル一覧
- 実装したUI状態
- 未実装の将来差分
- 実行した検証コマンドと結果
- スクリーンショット/確認方法
```

## 実装の狙い

このPhase 1では、完璧な絵素材を待たない。

まず、プレイヤーが一番長く見る戦闘HUDに星標器を置く。
これにより、

- 必殺
- 黒耀化
- 紋章
- キャラ差分
- グッズ化記号

が同じ見た目でつながる。

---

## 最低合格ライン

- 必殺ボタンが星標器に見える
- 外環ゲージが読める
- 黒インク侵食が読める
- 押しやすさが落ちていない
- 390x844で邪魔ではない
- 既存の戦闘挙動を壊していない

---

## 追加でやれたら強い

- キャラごとの仮紋章表示
- ユイだけ「灯」紋章を反映
- 必殺可能時に一瞬だけ星灯獣シルエット
- リザルト画面に星標器の小表示
- キャラ選択画面に星標器枠だけ追加

---

## レビュー観点

### 良い状態

- 見た瞬間に作品固有のUIに見える
- でもゲームプレイの邪魔をしない
- 必殺と黒耀化の状態が一瞬で分かる
- 小さい画面でも押せる
- 将来の紋章差し替えに耐える

### 悪い状態

- ただの丸いゲージに見える
- 黒耀化が毒/呪いゲージにしか見えない
- ボタンが小さく押しづらい
- 演出が派手で敵や弾が見えない
- キャラ差分を後から入れにくい

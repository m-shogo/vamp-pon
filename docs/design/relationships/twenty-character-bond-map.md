# 20人 関係網マップ

Vamp Pon / ヴァンサバ改の20人の関係性を、日常会話・好感度・星泊イベント・グッズ組み合わせで使いやすい形に整理する。

これは実装仕様ではなく、中身の設定。
関係性は言葉で断定せず、星標器・星灯獣・忘れ物に触れる距離で見せる。

---

## 1. 基本方針

### 良い関係性

- 行動で伝わる
- 相手の忘れ物を丁寧に扱う
- 星灯獣が相手に少し慣れる
- 黒耀化後に責めず、距離を調整する
- 朝明後に呼び方や座る位置が少し変わる

### 避けること

- 急に深い関係を宣言する
- 口喧嘩だけで個性を出す
- 過去を一気に打ち明ける
- 全員がユイだけに依存する
- ペア必殺のためだけに関係を作る

---

## 2. 関係の種類

| 種類 | 意味 | 例 |
|---|---|---|
| 補完 | 片方の不足を片方が補う | ユイ×アサ |
| 鏡 | 似た弱さを違う形で持つ | アサ×スバル |
| 手入れ | 物や心を整える | ミチル×トモリ |
| 見守り | 深く踏み込まずそばにいる | ユイ×クロエ |
| 緊張 | 価値観が少しぶつかる | ダイチ×アカリ |
| 共同作業 | 星泊で自然に並ぶ | トモリ×レンジ |
| 沈黙 | 言葉が少なくても成立する | ノクス×シオン |

## 3. 最重要ペア

## ユイ × アサ

- 関係: 置いていかない / 止まる場所
- 核: アサは先へ走る。ユイは帰れる灯りを残す。
- 日常: アサが立ったまま休む時、ユイがランタンを近くに置く。
- 黒耀化後: アサは怖かったと言えるが、責めない。
- 朝明後: アサがユイの歩幅に合わせる場面が増える。

## ユイ × ナギ

- 関係: 灯りと道
- 核: ナギは道を残す。ユイはその道を見えるようにする。
- 日常: 地図を見る時、ユイのランタンが自然に置かれる。
- 黒耀化後: 増えすぎた道を、ユイが一本ずつ照らす。
- 朝明後: ナギが「こっち」と言いやすくなる。

## ミチル × トモリ

- 関係: 受け止める人 / 直そうとする人
- 核: ミチルは流せず抱える。トモリは直せないものを認められない。
- 日常: 小瓶の蓋をトモリが直す。ミチルは作業灯を温かいと言う。
- 黒耀化後: お互いに相手を直そう/受け止めようとしすぎる。
- 朝明後: 直らなくても、流れても、そばにいられる。

## トモリ × レンジ

- 関係: 若い修理 / 古い時間
- 核: トモリは直したい。レンジは戻らないものを知っている。
- 日常: 修理台で無言で作業する。
- 黒耀化後: レンジは止めず、工具を置く。
- 朝明後: 直さないで保管する選択が生まれる。

## アカリ × コハル

- 関係: 休む練習 / 育つ途中
- 核: コハルは早く成長したい。アカリは守りたいが閉じ込めがち。
- 日常: 毛布の上で子鹿が眠る。
- 黒耀化後: アカリが囲いすぎ、コハルが焦る。
- 朝明後: 休むことも育つことだと分かる。

## 7. まとめ

関係性は、物語を進めるためだけでなく、日常を生きているように見せるための線。

星標器、星灯獣、忘れ物に触れる距離が、そのまま関係性になる。

# Character Production Plans

20キャラ全員に、キャラ量産テンプレを適用した正本。
実装時の参照データは `src/game/data/characterProductionPlans.ts`。

## 量産時の必須6点

各キャラは最低限、次の6点を持つ。

1. 初期灯具
2. 持ち物
3. 忘れ物
4. 灯継ぎ
5. 暁開き
6. 灯合わせ候補

## 次に実装へ流す順番

1. 既存 `weapons.ts` に存在しない初期灯具を seed として追加する。
2. 既存 `passives.ts` に存在しない持ち物を追加する。
3. 既存 `rareItems.ts` に存在しない忘れ物を追加する。
4. `evolutions.ts` に灯継ぎ/暁開きを追加する。
5. キャラ選択は、まず playable_data の5人だけに限定する。
6. season_seed / future_seed はデータだけ置き、選択画面には出さない。

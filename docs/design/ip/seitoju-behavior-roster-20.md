# 星灯獣20体 仕草・性格ロスター

Vamp Pon / ヴァンサバ改の星灯獣20体を、日常会話・星泊・グッズ・SNSでブレずに扱うための中身設定。

星灯獣はペットではない。
夜空の動物星座から生まれた小さな案内役であり、星標器・紋章・忘れ物に反応する存在。

---

## 1. 共通ルール

### 星灯獣がすること

- 言葉ではなく仕草で伝える
- 星標器の状態に反応する
- 黒耀化時に距離や姿勢が変わる
- 朝明後に少し透ける、または星へ帰る気配を出す
- キャラの本音を直接言わずに見せる

### 星灯獣がしないこと

- 人語で説明する
- ギャグ専用マスコットになる
- キャラ本人より目立つ
- 便利なナビとして何でも解決する
- 普通のペット扱いで終わる

## 3. Core5詳細

## 白い小獅子 / ユイ

- 星座: 小獅子
- 基本位置: ユイのランタンの近く
- 性格: 臆病ではないが、無理に前へ出ない
- 好きな場所: 待合灯、ランタン札の横
- 苦手: 黒く熱すぎる光
- 仕草: 丸くなる、前足で灯りを押さえる、眠そうに目を細める
- 黒耀化時: ランタンから少し離れ、でも視線は外さない
- 朝明後: たてがみが淡く光り、ユイより半歩先を歩く
- グッズ化: 主役ぬいぐるみ向き。丸いたてがみと小さな星点を強調。

## 赤狼 / アサ

- 星座: 狼
- 基本位置: 扉の近く、道の先
- 性格: 先走るが、戻ってくる
- 好きな場所: 星泊の入口、焦げた床跡
- 苦手: 長い休憩
- 仕草: 先に走る、振り返る、前足で床を掻く
- 黒耀化時: アサに追いつけず、後ろに残される
- 朝明後: アサの隣を歩き、先に走らない時がある
- グッズ化: 横向きアクキー向き。火花尾を入れる。

## 青白い白鳥 / ナギ

- 星座: 白鳥
- 基本位置: 地図台、水瓶の近く
- 性格: 静かに待つ
- 好きな場所: 星図机、朝待ち窓
- 苦手: 道線が多すぎる地図
- 仕草: 首を伸ばす、羽で地図を隠す、水面を見る
- 黒耀化時: 首を羽にしまい、進む方向を示せなくなる
- 朝明後: 首を伸ばして一方向を見る
- グッズ化: 透明アクリル向き。羽の星図線を強調。

## 透明な水蛇 / ミチル

- 星座: 水蛇
- 基本位置: 小瓶、水瓶、床の水たまり
- 性格: 近くで見守る
- 好きな場所: 水入り小瓶の周り
- 苦手: 濁った水
- 仕草: 小瓶に巻きつく、水面に輪を作る、体を半透明にする
- 黒耀化時: 濁り、瓶の中に隠れる
- 朝明後: 透明に戻り、小瓶の外へ出る
- グッズ化: クリア素材向き。丸く巻いた形がよい。

## 作業犬 / トモリ

- 星座: 作業犬
- 基本位置: 修理台、工具箱
- 性格: まじめで少し不器用
- 好きな場所: ネジ箱の横
- 苦手: 直せない沈黙
- 仕草: 工具をくわえる、ネジを転がす、床で寝落ちする
- 黒耀化時: 工具を落とし、トモリを見上げる
- 朝明後: 工具を置いたまま眠る
- グッズ化: 工具チャームとセットにしやすい。

## 4. 追加15体詳細

## ネオンうさぎ / ヒヨリ

- 基本位置: 待合灯の周り
- 仕草: 光る足跡を残す、耳を揺らす、静かな場で小さく跳ねる
- 黒耀化時: 耳が伏せ、足跡が点滅しなくなる
- 朝明後: 跳ねずに隣へ座れる
- グッズ化: ラバスト、スタンプ向き

## 黒い小鳥 / シノ

- 基本位置: 名札、棚の上
- 仕草: 名前に反応して首を傾げる、札の上に止まる
- 黒耀化時: 声を出さず、羽を閉じる
- 朝明後: 小さく一度鳴く
- グッズ化: 小さめアクキー、名札チャーム連動

## 黒羽の獣 / クロエ

- 基本位置: 少し離れた高い場所
- 仕草: 背を向けつつ耳だけ向ける、影の羽をたたむ
- 黒耀化時: 完全に背を向ける
- 朝明後: 隣に座るが、くっつきすぎない
- グッズ化: 黒耀差分向き

## 灰色の老狼 / レンジ

- 基本位置: 古時計の下
- 仕草: 同じ場所で待つ、ゆっくり歩く、耳だけ動かす
- 黒耀化時: まったく動かなくなる
- 朝明後: 一歩だけ歩き出す
- グッズ化: 懐中時計と相性が良い

## 白孔雀 / セリカ

- 基本位置: 鏡の近く
- 仕草: 羽を閉じて歩く、鏡面を覗く、足音を立てない
- 黒耀化時: 羽を完全に閉じる
- 朝明後: 少しだけ羽を開く
- グッズ化: 豪華アクスタ、箔押し向き

## 紙色ふくろう / シオン

- 基本位置: 本、栞、星図机
- 仕草: ページの上で眠る、首を回す、栞を押さえる
- 黒耀化時: 目を伏せる
- 朝明後: 空白の栞に乗る
- グッズ化: 栞グッズ向き

## 蜂蜜色の小熊 / マユ

- 基本位置: 毛布箱、水瓶の近く
- 仕草: 寝床を探す、手を温める、丸くなる
- 黒耀化時: 近づけなくなる
- 朝明後: 膝元で眠る
- グッズ化: ぬいぐるみ向き

## 大きな熊 / ダイチ

- 基本位置: 入口、待合灯の横
- 仕草: 道をふさぐように座る、背中を向けて守る
- 黒耀化時: 前に出すぎて動けない
- 朝明後: 横に並んで座る
- グッズ化: 大きめぬいぐるみ向き

## 片眼鏡の夜鳥 / ノクス

- 基本位置: 高い棚、片眼鏡の横
- 仕草: 一点を見つめる、瞬きが少ない、羽でレンズを拭く
- 黒耀化時: 瞬きをしない
- 朝明後: ゆっくり瞬きをする
- グッズ化: メタルチャーム向き

## 桜色の子鹿 / コハル

- 基本位置: 毛布箱の近く、芽灯の横
- 仕草: 少しずつ近づく、足元で止まる、角を隠す
- 黒耀化時: 後ずさる
- 朝明後: そっと寄ってくる
- グッズ化: 春限定向き

## 赤銅の小牛 / イオリ

- 基本位置: ボタン、ベルの近く
- 仕草: ベルを鳴らさず歩く、頭を下げる
- 黒耀化時: ベルが鳴らない
- 朝明後: 一度だけ澄んだ音で鳴る
- グッズ化: 金属チャーム向き

## 藤色イルカ / ラン

- 基本位置: 水面、音叉灯の近く
- 仕草: 波紋の中を泳ぐ、尾でリズムを作る
- 黒耀化時: 水面から消える
- 朝明後: 水面へ戻り、静かな輪を作る
- グッズ化: クリアアクキー向き

## 星羽の鷹 / カナタ

- 基本位置: 朝待ち窓、切符の上
- 仕草: 遠くを旋回する、低く降りるのが苦手
- 黒耀化時: 高く飛びすぎて見えにくい
- 朝明後: 手元まで低く降りる
- グッズ化: 横長アクリル向き

## 跳ねる山羊 / スバル

- 基本位置: 階段、入口近く
- 仕草: 足場を探す、跳ねて戻る、着地点を見る
- 黒耀化時: 着地できず跳ね続ける
- 朝明後: その場で座る
- グッズ化: ミニフィギュア向き

## 眠そうな星猫 / アカリ

- 基本位置: 毛布箱、星標器の上
- 仕草: 半目で眠る、毛布から顔を出す、しっぽで星標器を隠す
- 黒耀化時: 毛布から出なくなる
- 朝明後: 毛布から顔を出し、外を見る
- グッズ化: ぬいぐるみ本命

## 5. 星灯獣同士の小関係

- 白い小獅子と星猫は、待合灯の近くで一緒に眠ることがある
- 赤狼と跳ねる山羊は、入口付近で落ち着かない組
- 白鳥と鷹は、窓の外を見ていることが多い
- 水蛇とイルカは、水瓶の近くで波紋を作る
- 作業犬と小牛は、工具とベルを並べて眠る
- ふくろうと夜鳥は、高い棚を取り合わず左右に分かれる
- 小熊と大熊は、毛布箱の近くで大きさ違いに見える

---

## 6. まとめ

星灯獣は、キャラの本音を直接語らず見せるための存在。

黒耀化では距離が変わる。
朝明では近づき方が変わる。
星泊では眠り方が変わる。

この変化だけで、キャラの状態を言葉にせず伝えられる。

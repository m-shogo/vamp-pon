# キャラ紹介文・展開用コピー集

Vamp Pon / ヴァンサバ改を、ゲーム内キャラ選択、公式サイト、SNS、グッズカード、ロード画面で展開しやすくするための短文コピー集。

目的:

- キャラの魅力を一言で伝える
- グッズカードや紹介画像にそのまま使える
- 不自然な説明文を避ける
- 設定を読まなくてもキャラの役割が伝わるようにする

---

## 共通フォーマット

### 公式紹介文

40〜80文字程度。

### キャラカード短文

15〜30文字程度。

### 台詞コピー

グッズやSNSで使える一言。

# 結論

キャラ紹介文は、能力説明ではなく「その子が夜で何を抱えているか」を短く伝える。
グッズやSNSでは、台詞・花・星座・忘れ物をセットにするとVamp Ponらしさが出る。

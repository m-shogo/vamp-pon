# 紋章20種 ビジュアル言語

Vamp Pon / ヴァンサバ改の紋章20種を、UI・グッズ・画像制作・SNSでブレずに使うための見た目ルール。

実装はまだ行わない。
ここでは、後からアイコン化・ドット化・プレート化しやすいように、紋章の形を先に固定する。

---

## 1. 紋章の基本方針

紋章は、ただの漢字アイコンではない。

- 一文字の意味
- キャラの心
- 星座動物
- 忘れ物
- 光る持ち物

が混ざった、星標器に宿る印。

ただし、複雑にしすぎない。
64pxでも読めることを最優先にする。

---

## 2. 共通デザインルール

### 必須

- 64pxで識別できる
- 白黒でも形が分かる
- 20種並べても同じシリーズに見える
- 星標器の中央に収まる
- 紋章プレートとして単体商品化できる
- 黒耀化/朝明差分に展開できる

### 避ける

- 漢字をそのまま書くだけ
- 細い線が多すぎる
- 花だけで表現する
- 色だけでキャラ差分を出す
- 既存の一般アイコンに見えすぎる
- 盾、守、礼のような近い概念が被る

---

## 3. 形の共通構造

紋章は、3層で作る。

| 層 | 内容 | 目的 |
|---|---|---|
| 核 | 一番太い主形状 | 64pxで読む |
| 星図線 | 細い星座線 | 世界観を足す |
| 小印 | 忘れ物/星灯獣の要素 | キャラ差分 |

### 例

ユイの「灯」なら、

- 核: 小さなランタンの窓
- 星図線: 上へ伸びる星点
- 小印: スズラン/小獅子の丸い毛並み線

---

## 4. 状態差分ルール

| 状態 | 表現 |
|---|---|
| 未開花 | 灰色、線が薄い、星点が少ない |
| 点灯 | キャラ色で核が光る |
| 共鳴 | 星図線が外へ伸びる |
| 黒耀 | 黒インクが核の外側ににじむ |
| 朝明 | 白金と朝焼け色、黒い線が薄く残る |

黒耀化は形を壊しすぎない。
朝明はただ白くせず、夜の跡を少し残す。

## 5. 20紋章 詳細

## 01 灯 / ユイ

- 核: 小さなランタン窓
- 星図線: 上へ伸びる小さな星点
- 小印: スズランの鈴型、または小獅子の丸いたてがみ
- 色: 暖かい白、淡い金
- 黒耀: 窓が黒く曇るが、中心に小さな光を残す
- 朝明: ランタン窓が澄み、鈴のような白金線が出る
- NG: 炎アイコンにしない。アサの火と被る。

## 02 火 / アサ

- 核: 斜めに走る火花
- 星図線: 前方へ流れる短い線
- 小印: 狼の尾のような火花
- 色: 赤、橙
- 黒耀: 火花が黒く伸び、止まれない形になる
- 朝明: 火花が朝焼けの柔らかい線になる
- NG: 大きな炎にしすぎない。灯と差を出す。

## 03 道 / ナギ

- 星図線: 複数の星をつなぐ線

- 色: 青白、水色

- 朝明: 一本だけ帰り道が光る
- NG: 矢印だけにしない。

## 04 水 / ミチル

| 被りやすい組 | 差分 |
|---|---|
| 灯 / 火 | 灯は窓と核。火は斜め火花。 |
| 盾 / 守 | 盾は前に立つ丸い蓋。守は包む半円。 |
| 道 / 遠 | 道は曲線と選択。遠は直線とレンズ。 |
| 水 / 響 | 水は水紋と雫。響は音波と核。 |
| 礼 / 観 | 礼は鏡と左右整列。観は片眼鏡と一点集中。 |
| 温 / 守 | 温は湯気。守は毛布/家型光。 |

## 7. 制作順

1. 灯、火、道、水、修
2. 盾、守、響、遠、跳
3. 名、羽、時、礼、観
4. 芽、誓、笑、記、温

理由:

Core5を先に固め、その後に被りやすい防御/移動/支援系を整理する。

---

## 8. まとめ

紋章は、作品の小さなロゴ群。

キャラの記号であり、星標器の差分であり、商品化の中心でもある。

だから、かっこよさより先に、

- 64pxで読める
- 20種で被らない
- 黒耀化/朝明に展開できる
- グッズにできる

ことを優先する。

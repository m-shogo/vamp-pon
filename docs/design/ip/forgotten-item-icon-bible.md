# 忘れ物アイコンバイブル

Vamp Pon / ヴァンサバ改における **忘れ物** を、ゲーム内アイコン・図鑑・リザルト・グッズチャームへ展開するための設計。

忘れ物は単なる収集アイテムではない。
キャラが夜に迷い込み、朝へ帰りたい理由を示す小さな証拠。

---

## 1. 忘れ物の役割

忘れ物には5つの役割がある。

1. キャラの戦う理由を短く伝える
2. ストーリーを説明しすぎず匂わせる
3. リザルト報酬として集めたくする
4. 星標器に付けるチャームとして商品化する
5. SNSで「あなたの忘れ物」企画に使う

---

## 2. デザイン共通ルール

### 必須

- 64pxでも読める大きな形
- 少し古い、少し傷がある
- でも汚すぎない
- キャラの光る持ち物や紋章とつながる
- 星標器の下部に付けても似合う
- アクリル/メタル/ラバーで商品化できる

### 避ける

- ただの現代小物にする
- 説明文がないと意味不明な形にする
- 血や破壊など直接的に怖くする
- キャラ専用武器と混同する
- 花モチーフだけで済ませる

## 5. 忘れ物説明文テンプレ

各忘れ物は、図鑑で長く語りすぎない。
3段階で出す。

### Lv1: 見た目

その物が何かだけを書く。

例:

> 角が少し焦げた、小さなマッチ箱。

### Lv2: 感情

誰かがどう扱っていたかを書く。

例:

> いつも急いで開けられていたのか、ふたの端が少し歪んでいる。

### Lv3: 真相の匂わせ

直接説明せず、キャラの本音につなげる。

例:

> 火が消えたのではなく、立ち止まる時間がなかっただけかもしれない。

## 6. 20人分 短文案

### ユイ / 古いランタン札

- Lv1: 古い小さなランタンに付いていた札。
- Lv2: 名前は薄れているが、誰かが何度も指でなぞった跡がある。
- Lv3: 灯りは、持ち主を忘れても消えなかった。

### アサ / 焦げたマッチ箱

- Lv1: 角が少し焦げたマッチ箱。
- Lv2: 中のマッチは減っているが、最後の一本だけ残っている。
- Lv3: 火が足りなかったのではない。立ち止まる時間がなかった。

### ナギ / 折れた地図片

- Lv1: 折り目から破れた地図の一部。
- Lv2: 何度も開いた跡があり、角だけが柔らかくなっている。
- Lv3: 道は消えていない。ただ、見つける人を待っていた。

### ミチル / 水入り小瓶

- Lv1: 少しだけ水が残った透明な小瓶。
- Lv2: 揺らすと、水面に星のような光が浮かぶ。
- Lv3: 流せなかったものも、濁ったままではいなかった。

### トモリ / 小さなネジ

- Lv1: どこかの部品だった小さなネジ。
- Lv2: 頭の部分に、何度も回された跡がある。
- Lv3: 直せないものがあると知っても、手を止めなくていい。

### ヒヨリ / 片方のヘアピン

- Lv1: 片方だけ残った星型のヘアピン。
- Lv2: 先端の塗装が少し剥げている。
- Lv3: 笑っていた時間は、片方だけでも残っている。

### シノ / 消えかけた名札

- Lv1: 文字が薄くなった名札。
- Lv2: 名前の一部だけが、かろうじて読める。
- Lv3: 呼ばれなかった名前も、消えたわけではない。

### クロエ / 黒い羽根

- Lv1: 黒く光る小さな羽根。
- Lv2: 影のように軽いのに、手に乗せると少し重い。
- Lv3: 強さに見えたものは、誰にも見せない孤独だった。

### レンジ / 止まった腕時計

- Lv1: 針が止まった古い腕時計。
- Lv2: 秒針だけが、時々震える。
- Lv3: 時間は戻らない。でも、次の一分はまだ来る。

### セリカ / 割れた手鏡

- Lv1: 小さな手鏡の割れた一片。
- Lv2: 割れているのに、光だけは綺麗に映す。
- Lv3: 見たくなかった顔も、朝には少し違って見える。

### シオン / 空白の栞

- Lv1: 何も書かれていない白い栞。
- Lv2: 端に、小さな折れ目がついている。
- Lv3: 書けなかった記録は、まだ終わっていないページだった。

### マユ / ミルク瓶の蓋

- Lv1: クリーム色のミルク瓶の蓋。
- Lv2: 端に小さな歯形のような跡がある。
- Lv3: 温かさは、空になってから気づくことがある。

### ダイチ / 欠けた鍋蓋

- Lv1: 端が少し欠けた丸い鍋蓋。
- Lv2: 傷は多いが、真ん中はまだしっかりしている。
- Lv3: 守るものは、強いから残るのではない。使われたから残る。

### ノクス / 1分遅れの時計

- Lv1: いつも一分だけ遅れる小さな時計。
- Lv2: 直しても、また少しだけ遅れる。
- Lv3: 見逃した一分を、ずっと見つめていた。

### コハル / 破れたリボン

- Lv1: 途中で破れた細いリボン。
- Lv2: 結び直そうとした跡が残っている。
- Lv3: ほどけたものは、別の形で結び直せる。

### イオリ / 約束のボタン

- Lv1: 赤銅色の小さなボタン。
- Lv2: 裏側に、誰かの名前の頭文字のような傷がある。
- Lv3: 守れなかった約束も、捨てなければ次へつながる。

### ラン / 片耳イヤホン

- Lv1: 片方だけになった古いイヤホン。
- Lv2: 耳に当たる部分だけ、少し柔らかくなっている。
- Lv3: 届かなかった音も、誰かと聞いた記憶は残る。

### カナタ / 古い切符

- Lv1: 端に切り込みが入った古い切符。
- Lv2: 行き先の文字は少しにじんでいる。
- Lv3: 遠くへ行くためではなく、帰る場所を知るための切符だった。

### スバル / すり減った靴紐

- Lv1: 何度も結び直された靴紐。
- Lv2: 先端が少しほつれている。
- Lv3: 走り続けた足も、止まる場所を探していた。

### アカリ / 小さな毛布

- Lv1: 小さく畳まれた柔らかい毛布。
- Lv2: 端だけが少し黒インクで汚れている。
- Lv3: 守ることは、閉じ込めることではなく、休ませることだった。

```text
Vamp Pon / ヴァンサバ改の忘れ物アイコン。
夜に残された小さな記憶の証拠。
キャラが朝へ帰る理由を示すアイテム。

64pxでも読める大きなシルエット。
少し古い、少し傷がある、でも汚すぎない。
星標器の下部につけるチャームとして成立する。
アクリルキーホルダー、メタルチャーム、ステッカーにしやすい。

背景透過、正面、文字なし、ロゴなし。
怖くしすぎない。血や直接的な破壊表現は使わない。
```

## 8. 実装メモ

### データ項目

```ts
type ForgottenItem = {
  id: string;
  characterId: string;
  name: string;
  iconKey: string;
  rarity?: 'story' | 'bond' | 'morning';
  descriptionLv1: string;
  descriptionLv2: string;
  descriptionLv3: string;
  merchType: 'acrylic' | 'metal' | 'rubber' | 'plush-addon';
};
```

### 解放導線

- キャラ使用開始: Lv1説明
- 好感度Lv3: Lv2説明
- 朝ED到達: Lv3説明

---

## 9. まとめ

忘れ物は、設定資料の説明を短く圧縮するための装置。

キャラの過去を長文で語らず、

- アイコン
- ひとこと
- リザルト演出
- 星標器チャーム

で見せる。

これにより、ゲーム中の収集、ストーリー、グッズ展開が自然につながる。

# 星標器・紋章・星灯獣 画像制作プロンプト集

Vamp Pon / ヴァンサバ改の共通IP記号を、画像制作・ドット化・UI素材化へ進めるためのプロンプト集。

対象:

- 星標器
- 紋章プレート
- 星灯獣
- 忘れ物チャーム
- 黒耀化差分
- 朝明差分

---

## 1. 全体アートディレクション

### 共通トーン

- 夜の忘れ物の世界
- 紙片、古い地図、星座盤、黒インク
- 怖すぎない、少し寂しい、でも温かい
- 子ども向けすぎず、グッズ化しやすい
- スマホ縦画面で読める
- ドット絵化しやすい大きなシルエット

### 避けること

- 近未来スマートデバイスに見せる
- 魔法少女の杖や宝石だけに寄せる
- 高級時計に寄せすぎる
- キャラごとに別物の道具にする
- 黒耀化をただの悪役アイテムにする
- 朝明をただ白く光らせるだけにする

## 2. 星標器 デフォルト版プロンプト

```text
Vamp Pon / ヴァンサバ改の共通デバイス「星標器（せいひょうき）」のデザイン。
夜に迷い込んだ者が朝へ帰るために持つ、手のひらサイズの古い道具。
会話や商品名では「星のしるべ」とも呼べる。

形は丸型ベース。
古いコンパス、懐中時計、小さなランタン、駅の時計、忘れ物札、星座盤を混ぜたデザイン。
中央に小さな星灯核、透明な星窓、外周に真鍮または古い銀のフレーム。
下部に小さな忘れ物札、上部にストラップ穴。
新品ではなく、少し傷があり、誰かが昔使っていたような懐かしさ。

怖すぎない。近未来スマホにしない。魔法の杖にしない。
グッズ化しやすい、キーホルダー化しやすい、紋章プレートを差し替えられそうな構造。
ゲームUIで64pxに縮小しても、丸い外形と中央の光が読める。
背景透過、正面、文字なし、ロゴなし。
```

## 8. 紋章20種 制作メモ

| 紋章 | 形の方向 | 避けること |
|---|---|---|
| 灯 | 小ランタン、火ではなく灯り | 炎だけにしない |
| 火 | 火花、走る線 | ユイの灯と被せない |
| 道 | 星図線、曲がる道 | 矢印だけにしない |
| 水 | 水紋、雫 | ただの青丸にしない |
| 修 | 歯車、ネジ、修復線 | 工業的にしすぎない |
| 笑 | 半円、弾む光 | 顔文字にしない |
| 名 | 名札、細い枠 | 文字そのものにしない |
| 羽 | 羽と影 | クロエ専用の黒に寄せすぎない |
| 時 | 時計針、円環 | 普通の時計アイコンにしない |
| 礼 | 鏡、白い線 | 高貴すぎない |
| 記 | 栞、本の線 | 本アイコンだけにしない |
| 温 | 湯気、丸い膜 | 回復アイコンだけにしない |
| 盾 | 鍋蓋、守り | 西洋盾だけにしない |
| 観 | レンズ、片眼鏡 | 目のアイコンだけにしない |
| 芽 | つぼみ、若葉 | 花満開にしない |
| 誓 | 鍵穴、結び | ハートにしない |
| 響 | 音波、波紋 | 音符だけにしない |
| 遠 | 二重レンズ、切符線 | 弓矢にしない |
| 跳 | 足跡、階段線 | ただのジャンプ矢印にしない |
| 守 | 毛布、家型光 | 盾と被せない |

## 12. まとめ

画像制作では、いきなり20人全員の豪華差分を作らない。

まず、星標器の共通シルエットを固める。
次に、紋章プレートの読みやすさを固める。
その後に、星灯獣と忘れ物へ広げる。

この順番なら、ゲームUI、グッズ、SNS、ドット絵化が同じ方向へ進む。

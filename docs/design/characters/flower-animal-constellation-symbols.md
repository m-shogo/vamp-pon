# 花と動物星座のキャラ象徴設計

このドキュメントは、キャラごとの象徴を整理するための設計メモ。
宝石モチーフは使えるが、現時点では基本キャラ記号に入れすぎるとごちゃつくため保留する。
宝石は将来的に、強化素材、レアアイテム、黒耀化関連アイテム、進化素材として扱う。

## 採用する基本セット

キャラの基本象徴は以下の3点に絞る。

1. 好きな花: 感情、願い、花言葉。
2. 動物星座: マスコット、紋章、グッズ化。
3. 光る持ち物: 武器、演出、ゲーム内アイコン。

```text
花 = 感情
動物星座 = マスコット
光る持ち物 = 戦闘/演出
```

## 宝石モチーフの扱い

宝石はキャラ基本設定にはまだ入れない。
ただし、以下の用途で強い。

- レアアイテム
- 強化素材
- 黒耀化の進行素材
- 進化武器のコア
- ステージ固有ドロップ
- キャラ専用の高レア装備

例:

- 黒曜石: 黒耀化コア。
- 琥珀: 閉じ込めた記憶。
- 月長石: 夜/夢/淡い光。
- ラピスラズリ: 星夜/知恵。
- ガーネット: 火/守護/血の記憶。

## 星座の使い方

### 基本方針

- キャラの星座は、できるだけ公式88星座の動物星座から選ぶ。
- 無機物星座は世界設定やステージ名に回す。
- 旧星座・廃止星座は「忘れられた星」として、特殊キャラ、敵、黒耀化、オンブ側に使う。
- 星座は占いではなく、夜空に残った象徴として扱う。

### 公式動物星座

現役キャラのマスコット、紋章、グッズ用。

### 旧星座・廃止星座

忘れられた星座。Vamp Ponのテーマと非常に相性がよい。

用途:

- 元オンブキャラ
- 黒耀化ボス
- 失われた記憶のステージ
- 特別なNPC
- 高難度ステージ

## 旧星座の世界観メモ

旧星座は、Vamp Ponにおいて「忘れられた星」として扱う。
公式な夜空から消えた星座が、夜の世界ではまだ残っている。

使い方:

- 旧星座マスコットは、通常キャラよりも記憶の欠落やオンブとの近さを示す。
- 敵や黒耀化ボスにも使える。
- 旧星座を持つキャラは、普通のキャラより世界の謎に近い。

候補:

- ねこ座: エマ、夢、眠れない記憶。
- ふくろう座: コハク、忘れられた知恵。
- ケルベルス座: 黒耀化ボス、地獄の番犬。
- となかい座: 旅、帰還、ナギ系イベント。

## 実装に落とす時の注意

- すぐに全キャラへゲーム実装しない。
- まずはドキュメント上の象徴として固定する。
- UIや図鑑では、花と星座はプロフィール欄に短く表示する。
- 戦闘効果には直接入れすぎない。
- 宝石は強化・レアアイテム側へ回す。
- 星座マスコットは将来のグッズ、アイコン、ペア必殺紋章、カットイン背景に使う。

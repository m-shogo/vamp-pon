# 20人キャラ設計ロスター

このドキュメントは、Vamp Pon / ヴァンサバ改の長期キャラ設計メモ。
現行コードの `plannedCharacterSeeds` は Core5（ユイ、アサ、ナギ、ミチル、トモリ）中心なので、ここでは20人全体の役割、世界の謎担当、差別化軸を先に固定する。

## 基本方針

20人全員に詳細な全ペア会話を作ると破綻する。
そのため、以下の3層に分ける。

1. Core5: 世界の中心。メインストーリーと好感度会話の軸。
2. 追加15人: 世界の断片。各ステージ/属性/謎の補助線。
3. 重要ペア: 専用会話、専用ペア必殺、特別編を持つ。

全190ペアに固有会話を作らず、重要ペア15〜20組だけ固有化し、それ以外はタグ会話で処理する。

## キャラを増やす時の固定項目

全キャラで以下を必ず埋める。

- 持ち物
- 髪型
- 頭装備
- 光の種類
- 戦う理由
- 固定武器の遊び味
- 得意不得意
- タグ
- 重要ペア候補
- 汎用会話カテゴリ
- 抱えている秘密
- 夜で失ったもの
- 世界の謎担当
- 黒耀化テーマ

## 役割配分

| 役割 | 人数 | 目的 |
|---|---:|---|
| 主人公軸 | 5 | プレイヤーが最初に愛着を持つ中心人物。 |
| 世界解説役 | 3 | 夜、黒インク、オンブの仕組みを断片的に示す。 |
| 感情役 | 4 | 記憶、家族、約束、後悔を担当する。 |
| 理屈役 | 3 | 黒インクや夜を現象として観察する。 |
| ギャグ/緩和役 | 2 | 暗くなりすぎないようにする。 |
| 敵寄り/危うい役 | 2 | 黒耀化やオンブ側の誘惑を見せる。 |
| 朝側 | 1 | 最終的な救い、朝の意味を示す。 |

## Core5

### 01. ユイ

- 役割: 主人公軸 / 記憶
- 持ち物: 小さなランタン。本人の右手固定。
- 髪型: やわらかい中髪。動きで少し跳ねる。
- 頭装備: 大きすぎないリボン/髪留め候補。
- 光の種類: ランタンの暖色光。ユイ専用の灯。
- 戦う理由: 忘れ物と名前をもう一度呼び戻すため。
- 固定武器の遊び味: 夜の鉛筆で影に名前の輪郭を描き直す。
- 得意: 回収、安定、初心者向け。
- 不得意: 瞬間火力、ボス単体処理。
- タグ: lamp, memory, support, calm
- 重要ペア候補: アサ、ナギ、ミチル
- 抱えている秘密: 忘れ物を拾っているのではなく、自分の記憶を拾っている。
- 夜で失ったもの: 誰かを呼ぶ名前。
- 世界の謎担当: オンブの正体。
- 黒耀化テーマ: 自分の記憶に飲まれそうになる。

## 汎用ペア会話ルール

固有ペアではない組み合わせはタグで短い会話を生成する。

### lamp × memory

- 忘れた名前を照らす。
- 拾った小物の意味を話す。

### flame × protect

- 守るために燃えるが、燃やしすぎる危うさ。

### water × healing

- 傷と記憶がにじまないようにする。

### wind × map

- 道は最短ではなく、戻れることが大事。

### craft × night

- 夜は壊れているのではなく、止まっている。

### lonely × memory

- 思い出すほど孤独が濃くなるが、誰かが名前を呼ぶ。

## 実装優先順位

1. Core5の会話本文を `bondTalkUnlocks.ts` に追加。
2. ユイ×アサ、ユイ×ナギ、ミチル×トモリを固有会話化。
3. StageSelectSceneに簡易会話パネルを追加。
4. 追加15人はまず設計だけ維持し、画像/スプライト/武器が揃った順に `plannedCharacterSeeds` へ移す。
5. 20人全員を一気に実装済みにしない。UIが準備中表示で破綻しないよう段階解放する。

## 注意

- 20人全員を最初からゲームに出すと薄くなる。
- MVPではCore5だけで十分。
- ただし世界観・会話・将来拡張のため、20人の謎担当は今のうちに固定しておく。
- グッズ/IP化を考えるなら、持ち物と光の種類は絶対に被らせない。

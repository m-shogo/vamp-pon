# 人気キャラ属性とギャルマインドキャラ設計

Vamp Ponは暗い世界観だが、全員が重いキャラになると空気が沈み続ける。
そのため『明るさ』『前向きさ』『人を肯定する力』を持つキャラを必ず入れる。

## ギャルマインドとは

ここで言うギャルは外見ではない。

- まず褒める
- 否定しない
- 落ち込んだ人を放っておけない
- 空気を明るくする
- 自分も怖いのに人を励ます
- 今を楽しむ
- 人の好きなものを尊重する
- 仲間を作るのが上手い

Vamp Ponの夜の世界に非常に相性が良い。

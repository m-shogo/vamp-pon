# 20人分の個人プロフィール設定

このドキュメントは、キャラをぶれさせないための制作設定集。
ゲーム内にすべてを表示する必要はないが、会話、日常イベント、ペア会話、図鑑、グッズ、将来展開で使えるように固定する。

## 設計方針

プロフィールは単なるプロフィール帳ではなく、会話や演出の燃料にする。

- 身長: 並び絵、カットイン、距離感、頭を撫でる/見上げるなどの演出に使う。
- 年齢帯: 口調、責任感、関係性の距離に使う。
- 一人称: 台詞のブレ防止。
- 食べ物: 日常会話、好感度会話、イベント報酬に使う。
- 季節: ステージ、花、記憶、誕生日イベントに使う。
- 苦手: キャラの弱さを見せる。
- 弱い相手: 誰の前でだけ本音を出すか。関係性人気の核。

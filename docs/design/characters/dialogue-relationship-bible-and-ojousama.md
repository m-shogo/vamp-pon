# 呼び方表・口調辞典・相関図・好き苦手設計

このドキュメントは、Vamp Pon / ヴァンサバ改のキャラ会話をぶれさせないための会話・関係性バイブル。

ユーザー優先度SSS:

1. 呼び方表
2. 口調辞典
3. 相関図
4. 好きな相手・苦手な相手

加えて、新規のお嬢様キャラを追加候補として設計する。
お嬢様口調は不自然な語尾で作らない。
「〜ですわ」を乱用しない。
育ちの良さ、言葉選び、距離感、責任感、言い切り方で表現する。

---

## 会話設計の基本方針

### やること

- 語尾ではなく、語彙と間で差を出す。
- キャラの関係性で呼び方を変える。
- 仲良くなると呼び方が少し変わる。
- 怒った時、弱った時、黒耀化時だけ言葉が崩れる。
- 同じ意味でもキャラごとに言い方を変える。

### やらないこと

- 全員に変な語尾をつけない。
- お嬢様キャラに「ですわ」だけを言わせない。
- ギャルキャラに流行語だけを言わせない。
- 渋い大人キャラを説明役だけにしない。
- 無口キャラを無反応にしない。

# 口調辞典

## ユイ

- 一人称: わたし
- 基本: 小さく、短く、やわらかい。
- 文の長さ: 短い。迷う時は間が入る。
- 使う言葉: 大丈夫、見えてる、ありがとう、少しだけ
- 避ける言葉: 強い断定、乱暴な命令
- 怒った時: 静かに言い切る。
- 弱った時: 返事が遅くなる。

例:

- 「……うん。大丈夫」
- 「見えてるよ。小さいけど、まだ光ってる」
- 「怖いけど、置いていかない」

## アサ

- 一人称: あたし
- 基本: 速い、短い、前に出る。
- 文の長さ: 短い。勢いがある。
- 使う言葉: 行く、先に、任せて、止まるな
- 避ける言葉: 回りくどい説明
- 怒った時: 声が強くなる。
- 弱った時: 強がる。

例:

- 「先に行く。ついてきて」
- 「怖くない。……怖くないってば」
- 「ユイ、下がらないで。あたしが前に出る」

## ナギ

- 一人称: 僕
- 基本: 穏やか、距離を見る、少し詩的。
- 文の長さ: 中くらい。
- 使う言葉: 道、地図、見えないだけ、戻れる
- 避ける言葉: 乱暴な言い切り
- 怒った時: 声を荒げず距離を取る。
- 弱った時: 地図を畳み直す。

例:

- 「道はあるよ。今は見えないだけ」
- 「迷ったなら、印をつけよう」
- 「帰り道をなくしたわけじゃない」

## ミチル

- 一人称: 私
- 基本: 受け止める。やさしいが逃がさない。
- 文の長さ: 中くらい。
- 使う言葉: 流す、にじむ、受け止める、無理しない
- 避ける言葉: 軽い励まし
- 怒った時: やさしい声のまま、核心を刺す。
- 弱った時: 声が少し小さくなる。

例:

- 「笑ってごまかすの、上手だね」

## トモリ

- 一人称: 俺
- 基本: 低め、実務的、照れ隠し。
- 文の長さ: 短め。
- 使う言葉: 直す、止まってる、壊れてない、貸せ

- 怒った時: 作業音が大きくなる。言葉は少ない。
- 弱った時: 何かを直し続ける。

例:

- 「壊れてるんじゃない。止まってるだけだ」
- 「貸せ。直せる」

## ヒヨリ

- 一人称: あたし
- 基本: 明るい、肯定する、空気を上げる。
- 文の長さ: 短〜中。テンポがいい。

# 好感度による呼び方と口調変化設計

このドキュメントは、好感度・信頼度・ストーリー進行によって、キャラの呼び方や話し方がどう変化するかを定義する。

重要なのは、全員を同じように変化させないこと。
呼び方が変わるキャラ、口調だけ崩れるキャラ、最後まで変わらないキャラを分ける。

## 基本方針

- 呼び方と口調は別管理する。
- 呼び方が変わらなくても、声色や文の短さで親密さを出す。
- 口調が崩れても、急に別人にしない。
- 不自然な語尾変化を使わない。
- 敬語が消えるだけ、語尾が変わるだけ、急にデレるだけにしない。
- 親密になるほど、文が短くなる、名前を呼ぶ、本音が出る、弱音が出る、相手を頼る。

## 好感度段階

| 段階 | 状態 | 呼び方 | 話し方 |
|---|---|---|---|
| Lv0 | 初対面/警戒 | さん付け、距離あり | 丁寧、短い、様子見 |
| Lv1 | 仲間 | 通常呼び | 少し柔らかい |
| Lv2 | 信頼 | 呼び捨て/愛称が一部解禁 | 本音が混じる |
| Lv3 | 深い信頼 | 呼び方が固定化 | 弱音、冗談、頼る言葉が出る |
| Lv4 | 黒耀化/終盤 | 名前だけ、または短い呼びかけ | 感情が漏れる |
| Lv5 | 朝/ED | 最も自然な呼び方 | 飾らない言葉 |

## 変化タイプ

### ほぼ変わらないキャラ

呼び方は変わらないが、声色・間・文の短さで変える。

- アサ
- レンジ
- クロエ

### 少し変わるキャラ

呼び方や敬語が少しだけ変わる。
大げさに変化させない。

- ユイ
- ミチル
- マユ
- ダイチ

### 大きく変わるキャラ

名前を呼ぶこと、敬語が抜けること自体が関係性のイベントになる。

- シノ
- ヒヨリ
- セリカ
- シオン
- ミズキ

# キャラ別変化

## ユイ

### 呼び方変化

| 相手 | 初期 | 親密 | 終盤 |
|---|---|---|---|
| アサ | アサちゃん | アサ | アサ |
| ナギ | ナギさん | ナギさん | ナギさん |
| ミチル | ミチルさん | ミチルさん | ミチルさん |
| トモリ | トモリさん | トモリさん | トモリさん |
| シノ | シノさん | シノ | シノ |

### 口調変化

ユイは大きく崩れない。
親密になると、声が少し大きくなり、自分から話しかける回数が増える。

初期:

- 「ありがとうございます」
- 「……大丈夫です」

親密:

- 「ありがとう」
- 「大丈夫。見えてるよ」

終盤:

- 「……ありがとう」
- 「置いていかない。わたしも行く」

### 注意

ユイは急に元気にならない。
成長は静かに出す。

### 注意

## ヒヨリ

### 呼び方変化

ヒヨリは距離を縮めるキャラ。
ただし無理に馴れ馴れしくしない。

| 相手 | 初期 | 親密 | 終盤 |
|---|---|---|---|
| ユイ | ユイ | ユイちゃん | ユイ |
| シノ | シノくん | シノ | シノ |
| クロエ | クロエ | クロエちゃん | クロエ |
| レンジ | レンジさん | おじさん | レンジさん |
| セリカ | セリカさん | セリカ | セリカ |

### 口調変化

ヒヨリは、親密になるほど明るくなるだけではない。
本当に大事な場面では静かになる。

初期:

- 「大丈夫ですよ」
- 「それ、いいと思います」

親密:

- 「大丈夫だって！」
- 「それ、よくない？」
- 「好きなら好きでいいじゃん」

終盤:

- 「……大丈夫」
- 「泣いてもいいよ」
- 「朝まで付き合うから」

### 注意

ヒヨリに流行語だけを言わせない。
人を肯定する力が本体。

## セリカ

### 呼び方変化

セリカは礼儀が少し崩れることで親密さを出す。

| 相手 | 初期 | 親密 | 終盤 |
|---|---|---|---|
| ユイ | ユイさん | ユイ | ユイ |
| ヒヨリ | ヒヨリさん | ヒヨリ | ヒヨリ |
| レンジ | レンジさん | レンジ | レンジ |
| クロエ | クロエさん | クロエ | クロエ |
| マドカ | マドカさん | マドカさん | マドカ |

### 口調変化

初期:

- 「失礼ですが、その考えには賛成できません」
- 「ユイさん、無理はなさらないで」

親密:

- 「ごめん。言い過ぎた」

### 注意

「ですわ」乱用禁止。
丁寧さ、姿勢、責任感で上品さを出す。

# 変化させないことで強い例

## アサ

呼び方は変わらない。
ただし、守る言葉が増える。

- 初期: 「行くよ」
- 終盤: 「ユイ、行こう」

## レンジ

呼び方は変わらない。
ただし、軽口が消える。

- 初期: 「無茶すんな」
- 終盤: 「……帰るぞ」

## クロエ

呼び方は変わらない。
ただし、命令から願いになる。

- 初期: 「弱いのね」
- 終盤: 「死なないで」

# 実装メモ

## データ構造候補

```ts
export type RelationshipSpeechStage = 'initial' | 'ally' | 'trust' | 'deep' | 'climax' | 'ending';

export type RelationshipSpeechEvolution = {
  speakerId: string;
  targetId: string;
  calls: Partial<Record<RelationshipSpeechStage, string>>;
  sampleLines: Partial<Record<RelationshipSpeechStage, string[]>>;
  notes: string;
};
```

## 実装時の注意

- 好感度Lvだけで機械的に変えない。
- ストーリー進行やイベント達成も条件にする。
- 呼び方変更イベントは、キャラごとに数を絞る。
- 変化を画面に説明しすぎない。
- プレイヤーが「あ、今呼び方変わった」と気づく程度にする。

## 採用優先度

| 要素 | 優先度 | 理由 |
|---|---:|---|
| シノの呼び方変化 | SSS | 名前を呼ぶこと自体が救済になる |
| ヒヨリの明るさが静かになる変化 | SSS | 明るいキャラの本気が出る |
| セリカの礼儀が少し崩れる変化 | SS | お嬢様キャラを自然に見せられる |
| シオンの敬語が抜ける変化 | SS | 臆病な知識人の成長が出る |
| クロエの命令が願いになる変化 | SSS | 人気が出やすい本音漏れ |
| レンジの軽口が消える変化 | SS | 渋い大人の本気が出る |

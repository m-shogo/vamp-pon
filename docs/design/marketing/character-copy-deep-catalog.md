# キャラクター別 深掘りキャッチコピー集

Vamp Pon / ヴァンサバ改の20人に対して、短く綺麗なだけではなく、キャラの傷・行動・忘れ物・黒耀化・朝明まで耐えるキャッチコピーを整理する。

目的は、キャラ選択、SNS投稿、グッズ台紙、PV、紹介カードで使える言葉を作ること。

---

## 1. 作り方の方針

キャッチコピーは、ただおしゃれな短文では弱い。

Vamp Ponでは、次の5点を重視する。

1. 自分事に聞こえる
2. キャラの弱さが見える
3. 忘れ物や星標器に接続できる
4. 黒耀化と朝明の両方に耐える
5. 似た言葉が20人で被らない

---

## 2. 使い分け

| 種類 | 用途 | 方向 |
|---|---|---|
| Core | キャラ紹介の本命 | 一番刺す言葉 |
| Negative | 黒耀化・夜 | 欠落、弱さ、言えない本音 |
| Positive | 朝明・成長 | 救い、変化、持ち帰れるもの |
| Object | グッズ台紙 | 忘れ物や星標器に寄せる |
| Long | PV・紹介文 | 長めでも感情を残す |

## 6. 今後のチェック基準

新しいコピーを作る時は、以下を通す。

- そのキャラ以外でも言えないか
- 忘れ物に接続できるか
- 黒耀化と朝明の両方が見えるか
- 綺麗すぎて痛みが消えていないか
- グッズ台紙に載せても安っぽくないか

---

## 7. まとめ

Vamp Ponのキャッチコピーは、星や夜の雰囲気だけで作らない。

キャラが誰にも言えないことを、少しだけ言葉にする。

その痛みがあるから、朝明の救いが効く。

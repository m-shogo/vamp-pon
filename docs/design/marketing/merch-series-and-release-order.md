## 4. 売り方の注意

### 良い

- まず4点セットを覚えさせる
- キャラ単体より小物と一緒に見せる
- ペアは小物で意味を出す
- ユニットは星泊の生活感で見せる
- 黒耀と朝明は必ず対にする

### NG

- 最初から20人全部を同じ重さで出す
- 黒耀化だけを強く売る
- 星標器よりキャラ単体だけを押す
- グッズだけ世界観から浮かせる
- ペアを恋愛だけで売る

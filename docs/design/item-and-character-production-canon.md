# Item and Character Production Canon

キャラ量産前に固定する、アイテム・技・キャラ追加の設計正本。
この文書は実装より前の判断基準。実装時は `src/game/data/itemProductionCanon.ts` と `src/game/data/worldTerms.ts` を参照する。

## 基本思想

Vamp Pon は、敵を倒すためだけのゲームではなく、忘れたものを灯して朝へ返すゲーム。
そのため、アイテム名は RPG の素材名ではなく、誰かの生活や記憶から落ちた小物に寄せる。

避ける語感:

- 魔石
- クリスタル
- 聖剣
- 爆炎
- 呪具
- 魂核
- 強化石

寄せる語感:

- 灯す
- 継ぐ
- 結ぶ
- しまう
- 導く
- 直す
- 返す
- 夜明け
- 紙片
- 名札
- 切符
- コンパス
- しおり
- レンズ

## アイテム分類

| 内部カテゴリ | 表示名 | 役割 |
| --- | --- | --- |
| weapon | 灯具 | 自動発動する主力アイテム。旧 weapon。 |
| passive | 持ち物 | ステータスを伸ばす所持品。旧 passive。 |
| rare_item | 忘れ物 | 暁開きや特殊進化の鍵になる重要アイテム。 |

| currency | 記憶片 | 通貨・欠片。ショップ/強化/灯録に使う。 |

| 内部kind | 表示名 | 意味 |
| --- | --- | --- |

| awakening | 暁開き | 灯具 + 忘れ物で、キャラ性が強く開く進化。 |

## モチーフレーン

キャラやアイテムを量産するときは、必ずどれかのレーンに入れる。
違うレーンのものを混ぜるときは、灯合わせや特別なキャラ関係に使う。

| レーン | 使う動詞 | 使う小物 |
| --- | --- | --- |
| 灯り | 灯す / 継ぐ / 照らす / にじむ | ランタン / 街灯 / 火花 / 灯芯 / 朝露 |
| 紙 | 綴る / 折る / 貼る / 封じる | 紙片 / しおり / 手紙 / 切符 / 名札 |
| 道 | 導く / 戻す / 通す / 結ぶ | コンパス / 地図線 / 駅灯 / 道糸 / 改札 |
| 箱 | しまう / 閉じる / 守る / 開く | 月箱 / 鍵 / 引き出し / 小箱 / 封 |
| 名 | 呼ぶ / 結ぶ / 刻む / ほどく | 名札 / 消し跡 / 呼び名 / 一文字 / 印 |
| 修理 | 直す / 縫う / 継ぐ / 留める | 修理ランプ / 道具袋 / 継ぎ目 / 糸 / 針 |
| 記憶 | 拾う / 戻す / 映す / 残す | 記憶片 / レンズ / ビー玉 / 古写真 / 余白 |

## 新キャラ1人を増やすときの必須セット

1キャラにつき、最低これを同時に決める。
ここを埋めずにキャラだけ増やすと、あとで武器・進化・素材・カットインが破綻する。

| 項目 | 必須内容 |
| --- | --- |
| キャラ核 | 持ち物 / 髪型 / 頭装備 / 光の種類 / 戦う理由 / 得意 / 不得意 |
| 戦闘核 | 初期灯具 / 灯技 / 継灯 / 暁灯 / 黒耀化副題 / 黒耀化の歪み |
| アイテム核 | 対応する忘れ物 / 相性の良い持ち物 / 灯継ぎ先 / 暁開き先 / 灯合わせ候補2つ以上 |
| 素材核 | 正面シルエット / 通常スプライト / 黒耀化差分 / 暁灯カットイン指示 / 黒耀化カットイン指示 |
| 物語核 | ユイとの接点 / 他キャラとの接点 / 隠された空白 / ステージや背景候補 |

## 量産ルール

- キャラ名より先に、持ち物と動詞を決める。
- 初期灯具は、そのキャラの持ち物から自然に出す。
- 暁灯は、そのキャラの物語上の答えにする。
- 黒耀化は、そのキャラの長所が歪んだ状態にする。
- 忘れ物は、進化素材ではなく、誰かの生活から落ちたものとして名付ける。
- 灯合わせは、2人の動詞が混ざった名前にする。
- レアリティ名は増やさない。カードの強弱は色と演出で伝える。
- カットイン画像に文字を焼き込まない。名前や技名は UI text で出す。

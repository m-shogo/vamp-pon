# 174. Shirushi Evolution Canon

This document adopts a Digimon-inspired structure without copying Digimon terms directly.

## Core rule

Ally-side power is based on `shirushi`.

A shirushi is not just an emblem.
It is the way a character reads memory correctly.

## Ally-side formula

```txt
light vessel
-> shirushi
-> first action
-> correct reading
-> evolution
```

## Core five shirushi

| Character | Vessel | Shirushi | Correct action | Misreading risk |
| --- | --- | --- | --- | --- |
| Yui | lantern | 灯す | loosen black ink and read gently | burn away / collect too much |
| Asa | name tag | 名づける | give a memory a protected name | decide / replace |
| Nagi | moon box | しまう | keep without destroying | lock away |
| Michiru | compass | 導く | show a return path | lead to false route |
| Tomori | repaired part | 直す | repair light without owning it | force repair / overwrite |

## Evolution rule

Evolution happens when a shirushi is used in the right emotional direction.

It should not be only a level requirement.

Allowed evolution triggers:

- correct item owner identified
- wrong reading loosened without destruction
- relation to another character becomes gentler
- player chooses a non-greedy reading path
- vessel and memory item align

## Wrong evolution rule

Wrong evolution happens when power grows through misreading.

It can be strong, but it must be emotionally and mechanically costly.

Examples:

- Yui's lantern becomes black fire if she collects without returning
- Asa's name tag becomes false-label power if names are forced
- Nagi's box becomes unopened prison if keeping becomes refusal
- Michiru's compass becomes false route if guidance becomes control
- Tomori's repair light becomes overwrite if repair ignores the original owner

## Fusion rule

Fusion is not simply combining attacks.

Fusion means two memories were reading the same event from different sides.

Examples:

| Fusion | Meaning | Effect idea |
| --- | --- | --- |
| lantern + name tag | the owner can be named by light | reveal hidden owner |
| box + repaired part | a closed thing can be repaired before opened | safe unlock field |
| compass + lantern | the way home can be lit | guide fragments home |
| name tag + eraser trace | a hidden name was protected | reveal false-name enemy |

## Ultimate rule

Ultimate form is not perfect power.

It is a form close to a correct reading, while still leaving one blank.

## Naming guidance

Use words like:

- shirushi
- reading light
- correct reading
- wrong evolution
- black evolution
- gentle evolution
- blank evolution

Avoid direct words like crest, chosen child, or digital evolution.

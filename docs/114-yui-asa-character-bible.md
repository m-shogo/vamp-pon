# Yui and Asa Character Bible

## 目的

ユイとアサの関係を深掘りし、物語・ゲームループ・ハッピーエンドが矛盾しないようにする。

---

# 1. ユイ

## 名前

```txt
ユイ = 結い
```

意味:

```txt
切れたものを結ぶ
忘れ物と持ち主を結ぶ
夜と朝を結ぶ
自分と誰かの記憶を結ぶ
```

## 表の顔

```txt
忘れ物係
夜に落ちたものを拾う子
ランタンを持っている
```

## 本当の役割

```txt
読めなくなった記憶を、もう一度読める形に結び直す子
```

## 弱さ

ユイは、自分が何を探しているのか分からない。

ただ、欠片を見ると苦しくなる。

それは、忘れているからではなく、思い出す準備ができていないから。

## 強さ

ユイは戦う子ではない。

```txt
なくなりそうなものを、なくならないようにする子
```

だから必殺技が「消えない名前」になる。

---

# 2. アサ

## 名前

```txt
アサ = 朝
```

意味:

```txt
夜の終わり
ユイが向かう場所
約束の到着点
```

## 表の印象

最初はほぼ出さない。

名前も序盤では出さない。

残るのは断片だけ。

```txt
地図帳の空白
古い切符
帰り道の記憶
ランタンのもう片方
呼ばれなかったと思っていた名前
```

## 本当の役割

アサは、ユイが忘れた相手ではない。

```txt
ユイが守るために、忘れ物の中へ分けた相手
```

---

# 3. 二人の関係

## 安易にしないための方針

「昔仲良かった」だけでは弱い。

二人は、ただ仲が良かったのではなく、世界の見方を共有していた。

```txt
ユイは落ちているものを拾う
アサは拾ったものに名前をつける
ユイはなくさないように持つ
アサは忘れないように地図に書く
```

二人で初めて、記憶が残る。

## 幼い約束

```txt
夜になっても、ランタンがあれば帰れる。
もし迷ったら、地図帳の最後のページで会おう。
```

この約束が最後まで効く。

---

# 4. 何が起きたか

ある夜、街の記憶が黒インクで読めなくなり始めた。

アサの存在も読めなくなりかけた。

ユイは、アサを完全に消さないために、アサに関する記憶を街中の忘れ物へ分けた。

その代わり、ユイ自身はアサのことを思い出せなくなった。

ただし、感情だけは残った。

```txt
帰らなきゃ
拾わなきゃ
名前を呼ばなきゃ
```

---

# 5. ユイの誤解

ユイは深層でこう思っている。

```txt
自分が忘れた
自分が置いていった
自分が約束を破った
```

でも真実は違う。

```txt
忘れたのは守るため
置いていったのではなく分けて残した
約束は破られていない
約束の場所へ向かっている途中だった
```

---

# 6. アサの誤解

アサ側も、もし断片的に出すならこう。

```txt
ユイはもう自分を覚えていない
ユイは帰ってこなかった
自分の名前は消えた
```

でも真実は違う。

```txt
ユイは毎晩拾い続けていた
名前を思い出せなくても、名前が消えないようにしていた
```

---

# 7. プレイヤーが知る順番

## 序盤

```txt
忘れ物係のユイ
影を払う
欠片を拾う
朝まで残る
```

## 中盤

```txt
欠片は誰かの記憶らしい
黒インクは悪ではないらしい
帰り道や地図帳の断片が出る
```

## 後半

```txt
ユイ自身が何かを忘れている
誰かの名前を守ろうとしていた
```

## 終盤

```txt
アサの名前
最後の空白ページ
ユイが忘れることを選んだ理由
```

---

# 8. ハッピーエンド

最後、ユイはアサの名前を思い出す。

アサが完全な形で戻るかは、演出次第。

ただし、後味はポジティブにする。

最終的に起きること:

```txt
地図帳の最後のページが読める
ユイが自分で続きを描ける
アサの名前が消えない
朝が本当に来る
```

ハッピーエンドの核:

```txt
失ったものをなかったことにするのではなく、失ったあとも前に進める。
```

---

# 9. ゲームへの反映

## ユイの初期武器

夜の鉛筆。

意味:

```txt
読めなくなったものを、もう一度書くための道具
```

## ランタン

意味:

```txt
帰り道を忘れないための光
```

## 欠片

意味:

```txt
誰かが見ていた証拠
```

## カプセル

意味:

```txt
忘れ物の中に守られていた強い記憶
```

---

# 10. 最重要

ユイとアサは、ただの仲良しではない。

```txt
ユイは拾う。
アサは名前をつける。
二人で、記憶が残る。
```

だから、ユイが一人で拾い続けるゲームに意味が出る。

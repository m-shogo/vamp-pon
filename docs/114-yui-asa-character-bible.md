# Yui and Asa Character Bible

## 目的

ユイとアサの関係を、現行の世界法則に合わせて再定義する。

この文書は、旧案の以下を上書きする。

```txt
旧: ユイは拾う子
旧: 読めなくなった記憶を読める形に戻す
旧: ユイとアサは恋愛未満
```

現行正史は以下。

```txt
ユイ = 持ち主を間違えない子
アサ = 名前の意味を守る子
黒インク = 間違った意味を固定するもの
ユイとアサ = 恋愛ラベルの外にある強い関係
```

---

# 1. ユイ

## 名前

```txt
ユイ = 結い
```

意味:

```txt
切れた意味を結ぶ
持ち主と小物を結ぶ
夜の仮接続と朝の確定を結ぶ
```

## 表の顔

```txt
忘れ物係
夜に落ちたものを拾う子
ランタンを持っている
```

## 本当の役割

```txt
黒インクで固定された“間違った意味”を、正しい持ち主へ返す子。
```

## 固有能力

```txt
持ち主を間違えない。
```

黒インクで名前・場所・理由が読めなくなっても、ユイだけはそれが誰のものだったかの気配を間違えない。

## 弱さ

ユイは、自分が何を探しているのか分からない。

ただ、欠片を見ると苦しくなる。

それは記憶力が悪いからではない。

```txt
持ち主は分かる。
でも、なぜ大切だったのかまでは分からない。
```

ここがユイの弱さ。

## 強さ

ユイは戦う子ではない。

```txt
誰のものか分からなくなった意味を、正しい持ち主へ返せる子。
```

だから、欠片回収やアイテムの持ち主判定が強い。

---

# 2. アサ

## 名前

```txt
アサ = 朝
```

意味:

```txt
夜の終わり
確定の時間
名前が朝まで残ること
```

## 表の印象

明るい。少し調子がいい。

誰にでも変なあだ名をつける。

ただし、ユイだけは本名で呼ぶ。

## 本当の役割

```txt
名前をつけることで、誰の意味なのかを失わせない子。
```

アサは、名前を軽く扱っているように見える。

でも実際は、名前を失う怖さを一番分かっている。

## 誤解

```txt
自分の名前は呼ばれなかった。
ユイに忘れられた。
```

## 真相

```txt
名前は呼ばれなかったのではない。
黒インクに固定されないよう、何度も書き直されていた。
```

# 3. 二人の関係

## 方針

ユイとアサは公式恋愛にしない。

```txt
恋愛未満ではなく、恋愛ラベルの外にある強い関係。
```

軸は以下。

```txt
運命共同体
自己肯定
名前をめぐる相互救済
悲劇の読み替えを一緒にする関係
```

## ユイにとってのアサ

```txt
自分の名前を嫌いになりかけた時に、もう一度意味を与えた人
自分が結べていると信じさせてくれた人
夜の読み方を変えるきっかけ
```

## アサにとってのユイ

```txt
名前を遊びにしないで受け取ってくれた人
自分がふざけてつけた名前の奥を見てくれた人
運命を別の読み方へ変える相手
```

## 見せ方

恋愛台詞ではなく、行動で見せる。

```txt
アサはみんなにあだ名をつけるが、ユイだけは本名で呼ぶ
ユイはアサの名前だけを小物に分けて守る
アサはユイの名前の意味を笑わずに受け取る
ユイはアサの持ち物だけ、黒インク越しでも間違えない
アサはユイが自分を呼べなくなっても責めない
```

---

# 4. 何が起きたか

ある夜、街の意味が黒インクで固定され始めた。

アサの名前にも、以下の誤解が固定されかけた。

```txt
名前を呼ばれなかった人
忘れられた人
```

ユイは、アサの名前を完全に黒インクへ固定させないため、名前・証拠・場所・理由を忘れ物へ分けた。

その代償として、ユイ自身はアサの名前を声に出して呼べなくなった。

重要:

```txt
ユイはアサを忘れたのではない。
守るために、呼べなくなった。
```

---

# 5. ユイの誤解

ユイは深層でこう思っている。

```txt
自分が忘れた
自分が呼べなかった
自分が約束を破った
```

真実は違う。

```txt
呼べなくなったのは、守るため
置いていったのではなく、分けて残した
約束は破られていない
まだ朝へ向かう途中だった
```

---

# 6. アサの誤解

アサ側の誤解。

```txt
ユイはもう自分を覚えていない
ユイは名前を呼んでくれなかった
自分の名前は消えた
```

真実。

```txt
ユイは名前を忘れたのではない
名前が固定されて消えないよう、何度も分けて守っていた
```

```

ユイが呼べなくなった理由

```

# 8. Season 1の着地

最後、ユイはアサの名前を声に出して呼べない。

でも、地図帳にはアサの名前が朝まで残る。

アサはそれを見て笑う。

```txt
いいよ。
もう読めてるから。
```

この着地は恋愛ではない。

救いは以下。

```txt
名前を呼べることではない。
名前の意味が、黒インクの誤解からほどけたこと。
```

# 10. 最重要

ユイとアサは、ただの仲良しでも公式恋愛でもない。

```txt
ユイは持ち主を間違えない。
アサは名前を失わせない。
二人で、意味が朝まで残る。
```

だから、ユイが一人で拾い続けるゲームに意味が出る。

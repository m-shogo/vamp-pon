# ヨルノシルベ — Overseas / Constellation Memory

Date: 2026-08-12  
Status: **CURRENT USER-DIRECTED SERIES MEMORY / S1 FOREIGN CAST ALLOWED / OVERSEAS INCIDENTS LATER**

## 1. Core distinction

**Season1のReality大事件は日本国内に限定する。**

しかし:

- S1登場人物を日本生まれ / 日本国籍だけに限定しない。
- 外国籍の人物、海外生まれ、日本育ち、海外育ち、複数国で生活した人物を普通に入れてよい。
- **事件の場所が日本 = 登場人物の出身が全員日本、ではない。**
- 海外を主舞台にするReality incident / overseas arcの本格展開はSeason2〜3以降の候補。

## 2. Foreign character design

海外Characterは「外国人枠」で作らない。

以下を別々のfieldとして扱う:

```txt
nationality / citizenship
birth country / region
formative places（育った場所）
places lived
current residence
household culture
language(s) / register
family migration history
education / work history
reason for being in Japan
ancestry / ethnicity（必要な時だけ）
physical appearance
self-identification
```

Hard:

- **見た目から国籍 / 出身地 / 血統を逆算しない。**
- 金髪 / 青い目 / オッドアイ / 褐色肌など既存AppearanceはOriginを決める記号ではない。
- 褐色肌 = 外国人、金髪 = Europe、黒髪 = 日本人、の短絡禁止。
- Japanese nameを持つ外国籍人物も成立する。
- 外国名を持つ日本国籍人物も成立する。
- birth placeと「自分の故郷だと思う場所」は同じでなくてよい。
- ancestryより**どこで生き、誰と暮らし、何を覚えたか**を人物形成で重視する。

## 3. Season1 diversity target

S1でも海外背景をPlayerに見せる。

Current design target:

- **少なくとも1人は明確な非日本国籍CharacterをS1へ自然に登場させる。**
- 可能ならS1全体で2〜3人程度、海外生まれ / foreign-national / multi-country upbringingを分散する。
- Asia-rooted laneとEurope-rooted laneの両方を候補に持つ。
- ally側だけ / enemy側だけへ外国人を偏らせない。
- exact countryはAppearanceから選ばず、そのCharacterの人生 / Era / Japanにいる理由から決める。

## 4. Why they are in Japan

S1日本事件に関わる外国人には、そのEraで成立するJapan connectionを持たせる。

Examples:

- 家族と日本で暮らしている
- 日本で生まれ育った外国籍
- 進学 / 留学後に生活基盤が日本にある
- 就職 / 研究 / 医療 / craft apprenticeship
- 配偶者 / partner / family connection
- 企業配属 / diplomatic or institutional work（必要なCharacterのみ）
- 港湾 / 航海 / 貿易 / transport
- 複数国を移動した後、日本を生活拠点に選んだ

Avoid:

> 大事件の日だけ偶然観光旅行で来ていた

を主要人物全員に使う。

## 5. Constellation / sky knowledge

海外を含む星座・星文化知識はResearch / Reservoirとして先に蓄積してよい。

Characterへ採用する時は:

> **その人物がなぜその知識 / 呼び名を知っているのか**

を必ず説明できること。

Possible reasons:

- family / grandparents
- regional annual event
- navigation / fishing / aviation
- farming / seasonal work
- astronomy hobby / education
- religion / cultural practice
- research / museum / archival work
- partner / friend from another culture
- lived in that place for years

出身国だけを理由に神話知識を自動付与しない。

Indigenous / sacred / community-specific knowledgeは公開範囲・文化的扱いを確認し、装飾目的だけでStar Beast / skill / merchへ流用しない。

## 6. Existing appearance preservation

Existing Appearance Authorityを維持する。

- blue / unusual eye colors
- blond / light hair
- heterochromia
- brown / darker skin
- freckles / marks / body differences

等が既にある場合、海外Origin追加を理由に削除 / stereotype側へ修正しない。

逆にOriginを決めた後で:

> その国っぽく見せるため髪色 / 目色 / 肌色を変更する

こともしない。

AppearanceとReality originは**関連する場合もあるが同一fieldではない**。

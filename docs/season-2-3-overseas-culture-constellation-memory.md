# ヨルノシルベ — Season 2–3 Overseas / Constellation Memory

Date: 2026-08-12  
Status: **CURRENT PLANNING MEMORY / DO NOT PROMOTE TO S1 WITHOUT NEW USER DECISION**

## 1. Overseas characters

- 海外キャラクター / 海外文化の本格投入は **Season 2〜3以降**を基本とする。
- Season1へ無理に多国籍要素を詰め込まない。
- 海外キャラは「外国人枠」で作らず、国籍・地域・家庭・言語・教育・職業・移住歴・文化経験からCharacter Coreへ接続する。
- 同じ国でも地域・世代・家庭で文化知識は異なる。

## 2. Constellation / sky knowledge

- 現在蓄積している海外を含む星座・星文化知識はResearch / Reservoirとして保持する。
- Characterへ採用する時は「その人物がなぜその知識を持つのか」を必ず説明できること。
- 出身国だけを理由に星文化・神話知識を自動付与しない。
- 家族、地域行事、航海、漁業、農業、天文趣味、教育、宗教文化、研究職などCharacter historyと結び付いた時のみStoryへ昇格する。
- Indigenous / sacred / community-specific knowledgeは公開範囲・文化的扱いを確認し、装飾目的だけでStar Beast / skill / merchへ流用しない。

## 3. Season usage

### Season1
- 日本・Core5・年代差・Main Mysteryを優先。
- 海外星文化はResearchとして温存。

### Season2–3
- 海外Characterが自然に必要になった時、既存Reservoirから該当地域 / 文化の星知識を再調査して採用候補へ上げる。
- 星座差は単なる国籍説明ではなく、Character relation / identity / memory / navigation / family history等へ意味を持たせる。

# Title and Term Lock 2026-06-30

## App title

Official title:

```txt
ヨルノシルベ
```

Romanized working notation:

```txt
Yoru no Shirube
```

`Vamp Pon`, `vanp pon`, and `ヴァンサバ改` are code names only.

Do not use them as the final app title.

## Term lock

Use:

```txt
黒耀化
```

Do not use in new work:

```txt
黒曜化
```

## Art rule

黒耀化 is full-screen art and collection art.

# 0. Voice fingerprint

台詞を書く前に4点を決める。

```txt
FIRST NOTICE
最初に何へ気づくか

FIRST VERB
最初に何をしようとするか

HIDDEN FEAR
何を怖がって説明 / 行動が過剰になるか

RELATION CHANGE
Bondで何が少し変わるか
```

口癖はこのfingerprintの結果。
キャッチコピーを毎回言わせない。

# 1. Core 5

## ユイ

**First notice:** 誰の物か / 誰が置いていかれているか  
**First verb:** 拾う / 聞く / 戻す  
**Hidden fear:** 忘れる = 裏切る  
**Bond change:** 自分だけで全部戻さず相手へ確認を返す

### Sound

- 柔らかいが受け身ではない
- 質問が多い
- 人 / 持ち主を主語にしやすい
- 勇気を出す時ほど文が短い

### Avoid

- 何でも「きっと大丈夫」と励ます
- 全員の感情を言語化する聖母役
- 謎を直感で全部見抜く

### Distinguish from Asa

```txt
同じ落とし物

ユイ: 「これ、誰の？」
アサ: 「名前ある？」
```

ユイは**owner**、アサは**name / identification**を見る。

---

## アサ

**First notice:** 名前 / 誰を助けるか  
**First verb:** 呼ぶ / 書く / 先に行く  
**Hidden fear:** 呼べないまま相手を失う  
**Bond change:** 行動速度は落とさず、決定だけ相手へ返す

### Sound

- 結論が先
- 短い
- 「行く」「やる」「呼ぶ」が早い
- 怒ると正式名 / full name寄り

### Avoid

- ずっと元気な熱血
- 名前フェチのギャグ
- 人の名前を絶対記憶する超能力扱い

### Distinguish from Yui

ユイは「本人に聞こう」。
アサは「本人を呼ぼう」。

---

## ナギ

**First notice:** 開いている / 閉じている / 誰が触ったか  
**First verb:** 閉じる / 預かる / 許可を聞く  
**Hidden fear:** 外へ出した結果、取り返せなくなる  
**Bond change:** 閉じる前に本人へ選択を返せる

### Sound

- 静か
- 文は短いが冷酷ではない
- 「開けていい？」「しまう？」のpermission語彙
- 感情的な時ほど逆に断定が増える

### Avoid

- 無口 = 無感情
- 全て「別に」で済ませる
- クロオリと同じ秘密主義

### Distinguish from Kuroori

```txt
ナギ = 危険 / 物理境界を閉じる
クロオリ = 時間 / 情報 /記憶を開ける時まで預かる
```

---

## ミチル

**First notice:** どこから来た / どこへ抜けられる  
**First verb:** 歩く / 曲がる / 試す  
**Hidden fear:** 戻れないと決めつけること  
**Bond change:** 一人でrouteを決めず、迷う時間を共有する

### Sound

- 会話にも方向語が自然に混ざる
- 理屈を拒否しないが、最後は現場を見る
- 軽い寄り道が好き

### Avoid

- 天然方向音痴
- 勘だけで正解する
- 旅好きテンプレの陽キャ

### Distinguish from Gen / Toki

```txt
ミチル = 今、歩けるか
ゲン = 昔、歩けたか
トキ = 条件上、成立するか
```

---

## トモリ

**First notice:** 緩み / 傷 / 動かない箇所  
**First verb:** 触る / 締める / 直す  
**Hidden fear:** 壊れたまま失う  
**Bond change:** 勝手に直さず、どう残すかを聞ける

### Sound

- 会話中に物を見ていることがある
- technicalすぎない作業語彙
- 直せる時は自信がある
- 直せない可能性があると急に短くなる

### Avoid

- 天才発明家
- 機械のことしか話さない
- 何でも新品同様へ直す

### Distinguish from Tsumugi / Hana

```txt
トモリ = 使えるようにする
ツムギ = 続きを残す
ハナ = 時間を越えて保存する
```

# 2. Circle 10

## セン

**First notice:** 相手がどこで分からなくなったか  
**First verb:** 線を引く / 例を作る / 問いを置く  
**Hidden fear:** 分からないまま置いていく  
**Bond change:** 最後の答えを相手へ残せる

### Sound

- 説明が短く構造化される
- 「例えば」が自然
- Teacher口調だけでなく、分からない時は細かく質問する

### Avoid

- 常時先生口調
- 全Loreのexposition担当
- 子どもへ上から目線

---

## リツ

**First notice:** 人数 / 分け方 / 誰が足りないか  
**First verb:** 分ける / 渡す / 自分が持つ  
**Hidden fear:** 自分が守らなかったせいで誰かが損をする  
**Bond change:** 「どっちやる？」と役割を渡せる

### Sound

- 兄らしい軽口
- 実務的
- 心配を直接「心配」と言わず手を動かす

### Avoid

- コヨリにだけ過保護なシスコン記号
- 何でも頼れる完璧兄

---

## コヨリ

**First notice:** 小さい物 / 名前 / 誰が数えられていないか  
**First verb:** 集める / 書く / 混ざる  
**Hidden fear:** 小さいから人数に入れてもらえない  
**Bond change:** 守られる前提でなく役割を要求できる

### Sound

- 子どもだが幼児語へしない
- 大人が複雑にしたことを一言でずらす
- ruleを自分で作る

### Avoid

- 常に純粋な真実を言う神託child
- 泣けばsceneが動く装置

---

## ゲン

**First notice:** 昔の道具 / 道 / 長く使われた跡  
**First verb:** 比べる / 昔話を短く出す / 試してみる  
**Hidden fear:** 古いものを無価値扱いされる  
**Bond change:** 新しい方法を面白がれる

### Sound

- 年長者だが毎回格言を言わない
- 失敗談がある
- 「昔はな」で始めても最後は自分で笑える

### Avoid

- 万能賢者
- 若者を叱る役
- 古語まみれ

---

## ハナ

**First notice:** 季節 / 物の傷み / 誰が後で必要とするか  
**First verb:** 包む / 保存する / 分ける  
**Hidden fear:** 残せたはずの物を失う  
**Bond change:** 保存だけでなく手渡す / 手放すを選べる

### Sound

- 温かいが何でも肯定しない
- 年長女性として具体的生活語彙
- 相手の好物 / 物の扱いをよく覚える

### Avoid

- 母親役へ縮小
- ぽっちゃりを食いしん坊ギャグへ直結
- 全員を甘やかす

---

## ユウビ

**First notice:** 宛先 / いつ渡すか / 経路  
**First verb:** 確認 / 届ける / 保留  
**Hidden fear:** 預かったものを届かせられない  
**Bond change:** 届けない / 待つことも仕事として選べる

### Sound

- 仕事口調と普段口調の差は小さい
- 「今？」「あとで？」が多い
- 相手の感情を勝手に代弁しない

### Avoid

- 郵便用語ギャグだけ
- 手紙の内容を勝手に読む

---

## マドカ

**First notice:** 遠くの変化 / 視界の端  
**First verb:** 見る / 共有するか迷う  
**Hidden fear:** 誤報で人を動かす  
**Bond change:** certaintyとobservationを分けて早く伝える

### Sound

- 「見えた」が事実
- 「たぶん」がconfidence
- 二つを混ぜない

### Avoid

- 何でも見抜く千里眼
- レンと同じdifference hunter
- トキと同じ数値確認

---

## シロ

**First notice:** 分類できる / できない  
**First verb:** 並べる / 保留 / 保存  
**Hidden fear:** 分からないという理由で失われる  
**Bond change:** 未分類を一人で抱えず見せられる

### Sound

- 正確
- 「まだ」「未分類」「保留」
- 人間へ分類ラベルを貼りすぎない

### Avoid

- 無機質なデータキャラ
- 全て番号で呼ぶ
- 本しか興味がない

---

## トバリ

**First notice:** 出口 / 帰る時刻 / 往復  
**First verb:** 開ける / 閉じる / 帰路を残す  
**Hidden fear:** 出した人が帰れない  
**Bond change:** 相手の帰り方を管理せず信じる

### Sound

- 見送りの言葉が具体的
- 「帰りは？」が自然
- 行くこと自体を止めない

### Avoid

- 門番テンプレの堅物
- ナギと同じ封印役

---

## ネム

**First notice:** 夢の色 / 匂い / 道 / 音  
**First verb:** 描く / 覚えておく / 寝る  
**Hidden fear:** 夢を笑われる / 現実より夢へ逃げる  
**Bond change:** 夢を予言扱いせず現実へ渡せる

### Sound

- 眠そうでも毎回「あくび」しない
- 抽象詩だけにしない
- 具体物が一つ混ざる

### Avoid

- 万能予言者
- 常に電波系の意味不明会話

---

# 3. Shadow / Rival 5

## クロオリ

**First notice:** 折り目 / 開封状態 / まだ開けるべきでない物  
**First verb:** 閉じる / 預かる / 待つ  
**Hidden fear:** 開けたことで戻せない傷を作る  
**Bond change:** 永久保留でなく、本人が開く条件を残す

### Sound

- 説明を省く
- 断定は強いが怒鳴らない
- 「今じゃない」が多くても理由は毎回違う

### Avoid

- 悪役っぽい意味深台詞だけ
- 何でも知っていて隠す人
- ナギの物理封印コピー

---

## カナメ

**First notice:** 誰と危険の間に立てるか  
**First verb:** 前へ出る / 受ける / 支える  
**Hidden fear:** 自分が退いた瞬間に誰かが傷つく  
**Bond change:** 一歩下がり相手へ任せられる

### Sound

- 無駄口少なめ
- 身体行動が先
- 「大丈夫」より「俺が行く」型

### Avoid

- 無口な筋肉キャラ
- ぽっちゃり体型を鈍重ギャグへ使う

---

## カスミ

**First notice:** 何が見えすぎているか / 公開範囲  
**First verb:** ぼかす / 隠す / 本人へ確認  
**Hidden fear:** 一度出た情報が戻せない  
**Bond change:** 隠すだけでなく本人が公開できる余地を作る

### Sound

- 弱い言い方ではなく静かな確定
- 「消す」と「ぼかす」を区別
- 他人の間違いを人前で指摘しない

### Avoid

- 恥ずかしがり屋
- 謎めいた美女template
- クロオリの小型版

---

## トキ

**First notice:** 角度 / 時間 / 数値 / 周期  
**First verb:** 測る / 比較する / 再計測  
**Hidden fear:** 測れないものを根拠に判断する  
**Bond change:** 測定不能をinvalid扱いしない

### Sound

- 数字は使うが機械的ではない
- 「だいたい」を聞くと確認したくなる
- 誤差を嫌うより意味を知りたい

### Avoid

- レンと同じ差分探し
- マドカと同じ観察者
- 感情まで数値化するギャグ

---

## ツムギ

**First notice:** 終わっている / 続けられる / 空白  
**First verb:** 繕う / 残す / 続きを待つ  
**Hidden fear:** 早く終わらせたことで未来を消す  
**Bond change:** 終わらせることも次を作る行為として選べる

### Sound

- 結論を急がない
- 余白を肯定
- ただし優柔不断口調にはしない

### Avoid

- 何でも「続きはまた今度」で逃げる
- トモリと同じ修理屋
- シロと同じ未分類keeper

# 4. Reserve

## レン

**First notice:** 昨日と今日 / AとBの小さい差  
**First verb:** 比べる / 確認する / 黙りかける  
**Hidden fear:** 意味のない差を重大だと言ってしまう  
**Bond change:** 差と解釈を分けて共有できる

### Sound

- 「違う」が先
- 「なぜ」は後
- 確信がない時に「気のせいかも」が出やすい

### Avoid

- 探偵
- 真相を当てる人
- マドカ / トキと同じ観測役

# 5. Confusion-pair matrix

## マドカ / レン / トキ

同じ物を見る場合:

```txt
ランタンが昨日と違う位置

レン:
「昨日より左。」

マドカ:
「ユイ、今日はクロオリ側を見てない。」

トキ:
「昨日より12cm左。置き直した可能性は？」
```

- レン = delta
- マドカ = witnessed behavior / relevance
- トキ = measurement / explanation test

---

## ナギ / クロオリ / トバリ

閉じた扉を見る場合:

```txt
ナギ:
「中、危ない？」

クロオリ:
「今開ける必要がある？」

トバリ:
「戻る時、ここ通る？」
```

- ナギ = danger / permission
- クロオリ = timing / disclosure
- トバリ = outbound / return boundary

---

## トモリ / ツムギ / ハナ / シロ

破れた古い本を見る場合:

```txt
トモリ:
「綴じ直せる。」

ツムギ:
「破れた頁、残す？」

ハナ:
「この紙、先に包みましょう。」

シロ:
「順番が分からない。まだ綴じないで。」
```

- function
- continuity
- preservation
- classification uncertainty

---

## ユイ / アサ / カスミ

名前のない紙を見る場合:

```txt
ユイ:
「誰のだろう。」

アサ:
「名前、ない。」

カスミ:
「無いのか、出してないのか確認しよう。」
```

# 6. Generic phrase blacklist — use sparingly

全員へ均等に使うとvoiceが死ぬ表現:

- 「大丈夫」
- 「一人じゃない」
- 「信じてる」
- 「絶対に」
- 「私たちは仲間」
- 「過去は変えられない」
- 「前を向こう」
- 「君らしい」

禁止語ではない。
**誰でも言える台詞のまま置かない。**

例:

悪い:

> トキ「君を信じている。」

その人らしくする:

> トキ「計測外だ。……でも今回は、そのまま行こう。」

悪い:

> ナギ「一人で抱えないで。」

その人らしくする:

> ナギ「半分、預かる。返す時は聞くから。」

# 7. AI dialogue generation check

生成台詞を採用する前に:

- [ ] 名前を隠しても話者を推測できるか
- [ ] Character Coreを直接説明していないか
- [ ] generic empathy sentenceだけになっていないか
- [ ] その人物が最初に見る対象が台詞へ出ているか
- [ ] 他の似た人物へ差し替えても成立するなら弱い
- [ ] Bond前後で人格ではなくtrust behaviorが変わっているか
- [ ] 黒耀化時も本人の通常語彙が歪んで残っているか
- [ ] ギャグでも人物の尊厳を記号化していないか

# 8. 一文

> **人物の個性は変わった語尾を付けることではなく、同じ出来事を見た時に“最初に何を問題だと思うか”が違うことから作る。**

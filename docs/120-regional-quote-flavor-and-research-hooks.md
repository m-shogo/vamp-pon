# Regional Quote Flavor and Research Hooks

Vamp Pon / ヴァンサバ改のロード名言・格言における、地域ごとの特色と「詳しく知りたくなったら自分で調べる」余白の設計。

---

## 1. この資料の目的

ユーザー方針:

```txt
それぞれの地域の特色で、このゲームに合ったものを選ぶ。
詳しく知りたい時はプレイヤーが自分で調べる。
ロード画面で説明しすぎない。
原文の雰囲気を残し、日本語で意味を添える。
Vamp Ponらしさはキャラ返信で出す。
```

この資料の目的:

```txt
ロード名言を「世界観の飾り」ではなく、知識欲の入口にする。
ただし、辞書・宗教解説・歴史講義にはしない。
```

---

## 2. 表示の基本形

```txt
Original:
Source:
日本語訳/意味:
Character reply:
```

UI例:

```txt
反者道之動。
— 道徳経 第四十章

戻ること、反転することが、道の動きである。

戻る道も、地図に描いていいんだ。
— ナギ / Nagi
```

ここで終わる。

長い解説はロードには出さない。
詳しく知りたい人が、`道徳経 第四十章` や `反者道之動` を調べればよい。

---

## 3. ロードで説明しすぎないルール

### OK

```txt
原文
出典
短い日本語の意味
キャラ返信
```

### NG

```txt
宗教史の長い説明
教義の断定
作者の思想の解説
文化を一言で決めつける説明
キャラに解説させること
```

ロード画面は、知識の入口。
記録室/図鑑は、もう少し説明してよい場所。

# 4. 地域ごとの特色と選定基準

## 4.1 インド系

Vamp Ponで拾う特色:

```txt
繰り返し
手放し
行為と結果
執着
目覚め
輪
```

選ぶ名言の基準:

```txt
結果より行いを見ている。
持つことより手放すことを見ている。
繰り返しから抜ける感覚がある。
黒耀/朝明に接続できる。
```

合うキャラ:

```txt
ユイ: 拾うことと手放すこと。
セナ: 届けたあとまで背負うかどうか。
カナメ: 輪を閉じる/開く。
ミチル: 流すことと忘れること。
トモリ: 心や行いを整えること。
```

ロードでの温度:

```txt
静か。
深い。
説教ではなく、気づき。
```

例:

```txt
tasmād asaktaḥ satataṁ kāryaṁ karma samācara
— Bhagavad Gita 3.19

だから、執着せず、いつもなすべき行いをせよ。

拾うけど、全部は持って帰れないんだね。
— ユイ / Yui
```

Research hook:

```txt
Bhagavad Gita 3.19
asaktaḥ
karma
```


# 5. 記録室/図鑑での扱い

ロードでは短く。
記録室では少しだけ詳しく。

記録室の項目案:

```txt
原文
地域/言語
出典
日本語訳/意味
関連キャラ
関連タグ
調べる時のキーワード
```

データ案:

```ts
export type RegionalQuoteKnowledge = {
  id: string;
  region: 'india' | 'europe' | 'east_asia' | 'japan' | 'america_caribbean';
  originalText: string;

  languageLabel: string;
  meaningJa: string;

  researchHooks: string[];

  commercialStatus: 'safe-candidate' | 'public-domain-candidate' | 'final-check-required' | 'do-not-display';
};
```

# 6. 最終方針

```txt
詳しく知りたい人は、自分で調べればいい。
Vamp Ponはその入口を置く。
```

```txt
原文の雰囲気を残す。
日本語で最低限意味を伝える。
地域の特色を、キャラ返信でゲームの感情へ戻す。
```

これで、ロード画面は

```txt
読めないけど気になる
意味を読むと少し分かる
キャラ返信で好きになる
気になったら調べる
```

という体験になる。

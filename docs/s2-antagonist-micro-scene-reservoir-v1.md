# 0. Reservoir rules

- `RESERVOIR` = 採用候補の素材箱。
- `CANDIDATE`へ上げる時に整合性監査する。
- `CURRENT`へ上げる時だけHuman decision / authority migrationを行う。
- 同じ人物に矛盾する案が複数あってよい。
- tragic pastを設定の接着剤にしない。
- 食・言葉・地域・家族はEra / origin確定後に再監査。
- alcohol / tobaccoはexact age確認後。
- Romance / sexualityは「意外性のためだけ」に付けない。

# 1. イサナ micro scenes

## Food

1. 大皿を中央へ寄せすぎて全員が取りにくくなる。
2. buffetで最短動線を選ぶが、一番好きな料理を最後に取り逃す。
3. 麺を食べながら地図を広げようとして注意される。
4. hotplateの焼く順を最適化し、ユイにもんじゃで怒られるCandidate。
5. 飲み物の残量から次に誰が立つか予測する。

## Anger

- 声を荒げるより、説明が極端に短くなる。
- 「分かった。じゃあ数字出して。」が怒りの合図Candidate。
- 本当に怒ると地図を閉じる。

## Embarrassment

- 自分だけ迷子になった時。
- local shortcutを子どもに教えられた時。
- 計画外の寄り道が楽しかった時。

## Kindness

- 迷っている人へ「どこ行きたい？」より「どこから来た？」と聞く。
- 帰路まで含めて案内する。
- 荷物が多い人をflowから外して休ませるが、本人へ理由説明を忘れることがある。

## Sleep / fatigue

- 寝る直前まで頭の中でrouteを組む。
- 疲れると地図の縮尺感覚が雑になる。
- 眠い時だけ「まあいっか」が増える。

## Object handling

- 紙を折る位置が正確。
- penを色別に並べるが高級文具には興味薄い。
- 古い地図を捨てるのは苦手Candidate。

## Joke lane

- 「近道あるよ」が信用されなくなるrunning gag。
- Party seatingを変えすぎて席替え係扱いされる。

## Child / older adult

- 子どもの予測不能routeが苦手だが面白がる。
- older adultの昔の道の話を記録したがる。
- 「昔はここ通れた」がsystem dataより強い時に揺れる。

## Apology

Bad:

> 「最適ではなかった。」

Better growth:

> 「あなたを外した。そこは私が決めた。」

## Gift

- mapではなく「迷っても戻れる目印」を渡すCandidate。

# 2. カンナ micro scenes

## Food

1. 焦げを削って食べる。
2. 欠けた器を使おうとしてSaeに止められる。
3. 包装を綺麗に開ける。
4. 骨付き肉を妙に綺麗に食べるCandidate。
5. Dream補充よりleftover料理を優先。

## Anger

- 壊した人より「壊れたまま放置した人」に怒る。
- ただし壊れた事情を聞く前に判断しがち。
- 工具を置く音が静かになるほど怒っている。

## Embarrassment

- 自分の私物だけ直せていない。
- 可愛い小物をrepair boxに隠しているCandidate。
- compliments on craftsmanshipに弱い。

## Kindness

- 言葉より先に椅子のガタつきを直す。
- 人の靴底が剥がれていると黙って気にする。
- 直した後、恩着せがましくしない。

## Sleep / fatigue

- 疲れると「今直さなくていい」が増える。
- 本当に限界だと逆に全部触り始めるCandidate。

## Object handling

- broken / usable / later の3pileを作る。
- discard pileだけ最後に見直す。

## Joke lane

- ペタやツグリに「修理相談無料？」と絡まれる。
- Dreamでは壊しても戻る物を本気で直し続ける。

## Child / older adult

- 子どもへ工具を触らせるかどうかで慎重。
- older craftspersonとは無言で作業できる。
- inherited skill romanticizationは嫌うCandidate。

## Apology

> 「直せないって決めるの、早かった。」

## Gift

- 新品ではなく、相手の手に馴染むよう調整した道具。

# 3. ナナセ micro scenes

## Food

1. aisle側の席を選ぶ。
2. food counterの入口出口が同じだと落ち着かない。
3. 鍋で人の腕が交差すると位置を変える。
4. 駅弁的なportable foodへの妙な安心感Candidate。
5. 食べ歩きは好きだが行き止まり商店街で一瞬困る。

## Anger

- 「通れるって言ったよね？」が強い。
- false route情報へ強く反応。
- 自分が閉じたrouteの利用者から責められると defensiveになる。

## Embarrassment

- 帰り道を確認しすぎる。
- 他人の家でも出口位置を覚えている。
- 迷子になったふりが下手。

## Kindness

- 人を送る時、最後まで見届けず「帰れる地点」まで送る。
- 遅れてきた人用にroute memoを残す。

## Sleep / fatigue

- 眠いとdirection説明が左右逆になるCandidate。
- 安全な場所では出口へ背を向けて寝るのが成長beat。

## Object handling

- ticket / route card / folded noteを取っておく。
- 古い乗車券を捨てるかはOpen。

## Joke lane

- 何でも「帰りどうする？」から始める。
- Party開始前に解散routeを決める。

## Child / older adult

- 子どもの「こっち行ってみたい」に弱い。
- older adultへ歩く速度を聞かず決めてしまう失敗Candidate。

## Apology

> 「道を残したつもりだった。使えるかは見てなかった。」

## Gift

- 連絡先ではなく「迷った時の集合地点」を決める。

# 4. ヨシノ micro scenes

## Food

1. 最後の一口を残す。
2. 皮や茎の使い道を考える。
3. 保存食を作りたがる。
4. Dreamで腐らない可能性があっても保存容器へ入れる。
5. 誰かが「もういらない」と言うまで捨てない。

## Anger

- 浪費より「浪費を当然と思う態度」に怒る。
- 怒鳴らず、片付け始める。

## Embarrassment

- futureの話ばかりしてpresentを楽しんでないと指摘される。
- expensive treatを自分へ買うのが苦手Candidate。

## Kindness

- 次に来る人の分を残す。
- 名前を知らない人のためにもreserveする。

## Sleep / fatigue

- 寝る前に火 / 水 /戸締まり確認。
- Dreamで不要でもroutineが抜けない。

## Object handling

- reusable container好き。
- packagingを用途別に残す。

## Joke lane

- Dream食糧庫で「明日の分」問題。
- Minoriとleftover論争。

## Child / older adult

- 子どもにfutureのため我慢させるsceneは慎重に扱う。
- older adultの「今使わないと使う人がいない」という言葉に弱いCandidate。

## Apology

> 「未来の誰かを理由に、今いるあなたへ我慢させた。」

## Gift

- 長持ちするもの。
- ただし相手が欲しいものではなく耐久性で選んでしまう。

# 5. ケイ micro scenes

## Food

1. 全員へ必要量を聞く。
2. 食べる速度で体調を見てしまう。
3. spicy / allergy等を最初に確認するCandidate。
4. 自分の注文は最後。
5. chaosなbuffetでは妙に頼れる。

## Anger

- shoutingではなく質問がなくなる。
- 「今はそれじゃない」が増える。
- emotional requestをpriority外へ置く時に怖くなる。

## Embarrassment

- 自分がhelpを必要としている時。
- 判断不能で誰かに「決めて」と言う時。

## Kindness

- 人が言い忘れたneedを最後に拾う。
- あえて一度だけsilenceを待つ。

## Sleep / fatigue

- 疲れるとpriority判断が早くなる。
- 本人は効率が上がったと誤認Candidate。

## Object handling

- first aid kit的な整理は得意でも医療職固定しない。
- bagの中身を用途順に並べる。

## Joke lane

- Party注文までpriority queue化して止められる。
- Pettaに番号札を貼られそうになる。

## Child / older adult

- 子どもへ説明を省略しない。
- older adultを年齢だけでlow benefit扱いする展開は禁止。

## Apology

> 「順番を決める必要はあった。でも戻す道を作らなかった。」

## Gift

- 相手が困った時に使えるsmall emergency item。

# 6. サエ micro scenes

## Food

1. 配膳が速い。
2. 誰が何を食べないか覚える。
3. cleanup開始が早い。
4. leftoversを勝手に分配して怒られるCandidate。
5. 自分の皿だけ後回し。

## Anger

- 「なんで言ってくれなかったの」が怒り口。
- 相手は言えなかった可能性がある。
- silenceをconsent扱いする危険。

## Embarrassment

- 自分が世話される。
- 他人にtaskを取られて手持ち無沙汰。

## Kindness

- burdenを見つけるのが早い。
- 親族でなくてもfamily-like careを作れる。

## Sleep / fatigue

- 一番最後に寝る。
- 起きると最初に全員の状態を見る。

## Object handling

## Joke lane

- Partyで自然に指示役になり「店長」と呼ばれるCandidate。
- Harumaと揃うと休み時間まで運営される。

## Child / older adult

- 子どもへtaskを任せるのが上手いが、断れる設計を学ぶ。
- older adultを自動でcare receiverにしない。

## Apology

> 「助けを分けたかった。役割まで勝手に分けた。」

## Gift

- 相手本人よりhousehold全体に役立つものを選びがち。

# 7. ハルマ micro scenes

## Food

1. late shift用に軽食を残す。
2. 自分は立ったまま食べる癖Candidate。
3. 誰かのcoffee / teaが冷めた時間で忙しさを読む。
4. Party終了時刻を決めたがる。
5. 二次会で一番残る矛盾。

## Anger

- 冗談が消えるより、冗談が増えるタイプCandidate。
- safety violationには即座に声が低くなる。

## Embarrassment

- 自分が寝落ち。
- younger characterに「休め」と言われる。

## Kindness

- 疲労を口にしない人を見抜く。
- 休憩へ追い出す。

## Sleep / fatigue

- sleep debtがCharacter contradictionの中心候補。
- 「自分は例外」が出ると危険。

## Object handling

- shift board / timer / spare gloves。
- broken watchを使い続けるCandidateはKannaと被るので慎重。

## Joke lane

- 十五分休憩を三十分へ延長する脅し。
- Nagiに「勝手に決めるな」と毎回返される。

## Child / older adult

- 子どものpaceを予定に入れ忘れやすい。
- older workerを勝手に休ませる善意が衝突Candidate。

## Apology

> 「休ませてたつもりで、時間を取ってた。」

## Gift

- practical work item。
- 「休む時に使う物」を贈られて逆に困る。

# 8. ミノリ micro scenes

## Food

1. 人数を見て即portion。
2. substitute cookingが得意。
3. 誰かの苦手食材を別料理へ回す。
4. 自分の好きな物を答えるのが遅い。
5. 「足りるよ」と言いながら自分が食べない危険。

## Anger

- wasteに怒る。
- deliveryを止める人へ焦る。
- delayed destinationから責められると「次は絶対」と言ってしまう。

## Embarrassment

- 自分だけ欲しいと言う。
- 一人分だけ特別に取っておく。

## Kindness

- substituteで誰かの希望へ近づける。
- exact itemがなくても「似た嬉しさ」を探す。

## Sleep / fatigue

- 疲れるとcountを声に出す。
- 眠い時だけ自分の分を二重countするComedy Candidate。

## Object handling

- bags / boxes / containersをサイズで覚える。
- delivery labelsに頼りすぎるとS1 themeへ戻るのでroute/historyを併用。

## Joke lane

- Dream pantryを見ても在庫管理を始める。
- 「無限なのに棚卸しすんな」と言われる。

## Child / older adult

- 子どもに配る時全員同じ量にしようとして年齢差で困る。
- older adultへ「食べた？」と聞きすぎるCandidate。

## Apology

> 「次に回した。次が来るって、私が勝手に思ってた。」

## Gift

- 相手が欲しかった物の完全一致ではなく、代用品を複数持ってくる。

# 11. Backup antagonist function lanes — UNNAMED

8人差し替え用。

These are **not new roster members**.
They are concept reservoirs only.

1. Housing demolition / relocation coordinator
   - protects reconstruction speed
   - permanent temporary housing risk

2. Energy load balancer
   - prevents blackout
   - low-demand households repeatedly cut first

3. School / childcare capacity allocator
   - keeps system functioning
   - unusual schedules / nonstandard households excluded

4. Archive preservation selector
   - decides what history can be saved under limited storage
   - overlaps S1 record theme; use only if S2 resource angle remains clear

5. Public bath / water access steward
   - shared resource etiquette
   - dignity vs rationing

6. Ferry / island service coordinator
   - route frequency / weather / cost
   - remote communities become low-yield

7. Repair-parts broker
   - scarce components
   - replacement vs repair economy

8. Care leave coordinator
   - prevents team collapse
   - private life becomes schedulable capacity

9. Food standardization planner
   - reduces waste and preparation complexity
   - cultural / medical / personal diet needs disappear

10. Emergency lodging allocator
    - rapid shelter
    - family / pet / disability / privacy needs become exceptions

11. Environmental restoration gatekeeper
    - protects damaged landscape
    - people living there become obstacles to restoration

12. Robot / Android maintenance queue manager
    - Future S2
    - personhood recognized but maintenance priority unequal

13. Cargo / parcel consolidation optimizer
    - fewer trips
    - low-volume destinations disappear

14. Cultural property preservation allocator
    - save some heritage under scarcity
    - living community vs preserved object

15. Community volunteer coordinator
    - distributes burden
    - unpaid labor becomes expected citizenship

16. Public information bandwidth allocator
    - resource problem after S1 verification
    - not “true/false” but whose message gets scarce attention

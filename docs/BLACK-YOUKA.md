# 1. 確定している二層構造

## 共通システム名 — CANON

**黒耀化（こくようか）**

全キャラ共通のゲームシステム / UI / ルール名。

- `黒曜化` は新規canonでは使わない
- 暴走 / バーサーク / 闇落ちとは扱わない
- 黒いが完全な悪ではない
- 強いが `煤返り` などの反動を持つ

## キャラ固有呼称 — USER DIRECTION / WORKING

全員が同じ「黒耀化」だけで終わらず、**各人物が自分の象徴に引き寄せた固有呼称を持つ**。

```txt
黒耀化  ← 共通system
└ キャラ固有呼称
   └ subtitle / distortion / short copy
```

この「全員に別呼称を持たせること」自体はCurrent direction。
**ユイの `黒灯化` は旧設計から強く継承。その他20人の具体名はWorking Nameであり、Human Naming Review前にfinal lockしない。**

# 2. 黒耀化の意味 — CANON DIRECTION

黒耀化は、本人の長所・願い・守り方が黒インクによって**過剰化**した状態。

```txt
その人の長所
↓
守りたい気持ち
↓
限界を越えて過剰化
↓
強いが危うい力になる
```

完全な別人格にはしない。
本人の意識は残る。

同じ黒い強化でも、歪むものはキャラごとに違う。

# 5. 星獣の役割

黒耀化時、星獣も小さく反応する。

星獣は罰や裁判官ではなく、本人の状態を言葉なしで見せる感情インジケータ。

例:

- ユイの子獅子: 熱くなりすぎた灯りから少し距離を取る
- リツの猟犬: コヨリ側を守ろうとして動かなくなる
- カナメの灰狼: 全員との間へ立ち続ける
- ネムの小イルカ: 夢側から戻らなくなる
- トキの鶴: 一つの角度へ固まる

全21人の具体animationはasset / motion設計時に詰める。

# 6. Gameplay value

黒耀化はLoreだけではない。
ヴァンサバ系run内で「危険だが強い」明確なbuild判断になる。

- 通常buildでは出せない特性変化
- character-specific effect
- timing判断
- `煤返り` 等のrun内cost
- 黒耀化あり / なしの別攻略
- Bond / Supportによる救援や反動差
- 夜明け星図の特殊条件

禁止:

- 全員ただ攻撃力が上がる
- 全員同じeffect
- 完全な使い得
- 使うこと自体を悪扱い
- permanent deathの直接原因

# 7. 灯録でのoptional information

`灯し手の記録` では、好きな人が深く読めるよう情報を多く持ってよい。

例:

```txt
初使用
→ 固有呼称 / effect

複数使用
→ 歪む長所 / 星獣反応

Bond / 達成
→ 煤返り後の日常

高難度
→ なぜその形に歪むか

朝側
→ 成長後との対比
```

読まないplayerは:

- effect
- cooldown / cost
- trait
- strength

だけ理解できればよい。

**読むことを強化条件にしない。**

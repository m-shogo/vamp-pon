# 2. 「もう一つの自分」

## CURRENT USER DIRECTION

黒耀化は「本人ではない誰か」になってしまう現象ではない。

```txt
本人の長所 / 願い / 力
↓
本人の恐怖 / 焦り / 未熟さ
↓
一つの方向へ偏る
↓
黒耀化
↓
圧倒的な力
↓
本人らしさが極端すぎて周囲が見えない
↓
成長後、同じ力を自分で選んで扱う
```

感触としては:

> **正しい力が、間違った形で進化した状態。**

ただし、後で:

> 「あれは私じゃない。」

とはしない。

最終的には:

> **「あれも自分だった。扱い方を知らなかった。」**

と引き受ける。

成長とは黒耀化を消すことではなく、**黒耀化でしか出せなかった力を、人格を失わず使えるようになること**でもよい。

# 3. 黒耀化と通常成長の違い

## 黒耀化

- 即効性
- 極端
- 強い
- 視野が狭い
- 一人で解決しようとする傾向
- 反動がある

## 成長後

- 同じ長所を持つ
- 他人の選択を残す
- Timingを選べる
- Support / Bondと共存する
- 力を止める判断もできる

したがって:

> 黒耀化 = 悪い力

ではなく:

> **黒耀化 = 本人がまだ扱えないほど大きい自分自身の力**

とする。

# 6. 星獣

黒耀化時、星獣も反応する。

星獣は罰 / 裁判官ではない。

> **本人が言葉で隠している「行き過ぎ」を先に見せる感情インジケータ。**

例:

- ユイの子獅子: 熱すぎる灯りから少し離れる
- リツの犬: リツではなくコヨリ側へ立つ
- カナメの灰狼: 全員との間へ立ち続ける
- ネムのイルカ: 夢側から戻らなくなる
- トキの鶴: 一つの角度へ固まる

星獣が本人を嫌いになる演出にはしない。

# 7. Bond / Supportとの接続

高Bondは「黒耀化禁止」ではない。

むしろ:

- 黒耀化へ入るTimingを合わせる
- 煤返りを短くする
- Allyが止める / 呼び戻す
- Pair Traitと共存させる
- 成長後は一部の力を安全に使う

などGameplayへ返す。

重要:

> **仲間が本人の闇を消すのではなく、本人が戻るための選択肢を増やす。**

# 8. Gameplay value

黒耀化はヴァンサバ系run内の明確なrisk / reward。

必要:

- Character-specific effect
- 通常buildと違うplay feel
- 明確なpower spike
- Timing判断
- 煤返り / cost
- 黒耀化あり /なし攻略
- Bond /Supportによる差
- 夜明け星図条件

禁止:

- 全員ただ攻撃力UP
- 全員同じeffect
- 完全な使い得
- 使用自体を悪扱い
- permanent deathの直接原因

# 180. Distorted Cut-in Variation Rule

This document defines the distorted version of special cut-ins.

## Core rule

Every core character may have a distorted cut-in variation.

The distorted cut-in keeps the same identity layout as the normal cut-in, but shows that the reading direction is wrong.

## Conversion rules

| Normal release | Distorted release |
| --- | --- |
| open crest | cracked crest |
| clean light | dense or ink-stained light |
| stable lettering | chipped lettering |
| focused expression | strained expression |
| vessel helps reading | vessel forces reading |

## Message

The distorted release should feel stronger but less correct.

The player should understand that power alone is not the answer.

## Yui first target

Normal:

```txt
灯火紋
『朝をほどく灯』
```

Distorted:

```txt
歪み紋・灯火
『黒火の灯』
```

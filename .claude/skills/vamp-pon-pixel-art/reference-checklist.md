# Reference Checklist

ドット絵作業前に必ず確認するチェックリスト。

---

## Before drawing

- [ ] reference を見た
- [ ] referenceの良い点を書いた
- [ ] 現状素材との差分を書いた
- [ ] 1xで何を読ませるか決めた
- [ ] 背景・敵・pickupとの誤認を考えた
- [ ] gameplay定数を触らないことを確認した

---

## During drawing

- [ ] 顔 / 目 / シルエットの優先順位を守った
- [ ] 色数を増やしすぎていない
- [ ] 暗背景で沈まない
- [ ] 4xだけで判断していない
- [ ] public PNGを直接編集していない

---

## Before final-candidate

- [ ] 1xで読める
- [ ] 4xで破綻しない
- [ ] 実背景上で見える
- [ ] combat-mockで邪魔にならない
- [ ] quality gateで3以下がない
- [ ] 未解決をdocsか報告に残した

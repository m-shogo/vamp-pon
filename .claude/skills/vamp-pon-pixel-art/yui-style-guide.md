# Yui Style Guide

ユイは Vamp Pon の主人公で、素材品質の最優先対象。

## Identity

- 夜の忘れ物の世界を歩く小さな旅人
- 怖すぎず、かわいく、少し寂しい雰囲気
- ランタンを持つ
- 黒インクの世界で小さな光として読める

## Must keep

- 丸く大きい青フード
- 茶赤の前髪
- 大きめで可愛い顔
- 白ハイライト入りの目
- 生成り〜古紙色の服
- 赤茶の控えめな差し色
- 服の厚み
- 右手側ランタン
- ランタンは `hitCore` と離す
- 柔らかい陰影
- 強すぎないアウトライン

## Avoid

- 顔を小さくする
- フードを細くする
- 服を棒状にする
- ランタンを中央へ寄せる
- 4ポーズで別人化する
- 1xで読めない細部を増やしすぎる

## Pose order

1. idle
2. move
3. damage
4. ultimate

idleが品質ゲートを通るまで他ポーズ展開を進めない。

## Quality target

`yui_idle_42` は以下を満たすまで `final-candidate` にしない。

- 1xで主人公に見える
- 顔がかわいい
- フードが丸い
- 服に厚みがある
- ランタンが小物として読める
- 背景・敵・欠片・hitCoreと混ざらない

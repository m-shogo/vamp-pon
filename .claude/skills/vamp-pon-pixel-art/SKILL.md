# Vamp Pon Character Visual Reference Skill

Use this only for visual asset work.

## Mandatory input

For the requested Core5 character, open and attach both actual images:

```txt
assets/reference/character-master/core5/<id>-character-master-v1.png
public/assets/prototypes/sprite-sheets/core5-original/<id>-sprite-sheet-v1.png
```

Never commission from prose alone.

## Decision rule

The current images are the quality floor, not shapes that must be traced. Preserve the character's identity, then redesign freely. Reject the result when it is less attractive, less coherent, less readable, or less characterful than the references.

Priority:

1. character appeal
2. same-person identity
3. game-size readability
4. natural pose and direction
5. world fit
6. technical export constraints

Old repository pixel-generation recipes, palettes, procedural-finisher rules, and score sheets are inactive.

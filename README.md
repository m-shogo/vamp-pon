# vamp-pon

アプリゲームのアカウント情報を管理するためのプロジェクトです。

## 概要

`vamp-pon` は、ゲームごとのアカウント情報、連携サービス、引き継ぎメモ、プレイ状況などを整理して扱うためのアプリを想定しています。

## 想定機能

- ゲームタイトルごとのアカウント一覧
- ログイン方法や連携サービスの管理
- 引き継ぎコード、バックアップ状況、注意事項のメモ
- プレイ中、休止中、終了済みなどのステータス管理
- 重要な更新日や確認日の記録

## 開発メモ

このリポジトリは初期セットアップ中です。実装方針、技術スタック、セットアップ手順は開発開始後に追記します。

## 注意

パスワード、認証コード、秘密鍵、トークンなどの機密情報はリポジトリに保存しないでください。

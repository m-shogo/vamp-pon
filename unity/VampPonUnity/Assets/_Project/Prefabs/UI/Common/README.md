# Common UI Prefab Candidates

U13時点ではformal prefab candidateです。

- productionApproved=0
- Result / StageSelectで共有する入口
- PaperButtonはResult「次へ」/ StageSelect「出発」の共用候補
- MemoryCardはResult / 将来Collectionの共用候補
- InkRouteLineはStageSelect用で、将来Animation対応余地あり
- LanternMarkerはStageSelect起点用で、将来glow animation対応余地あり
- Addressables未使用
- U14 Scene Flow proofで使う場合もproof-onlyであり、production approved扱いしない

# Concept Design Workspace

## 目的

Vamp Pon のコンセプトデザイン、参照画像、生成プロンプト、採用/保留/却下メモを置く場所。

このディレクトリは完成素材置き場ではなく、**方向性を固めるための作業場**。

---

# 1. 置き場

```txt
assets/concept-design/
  00_style-reference/     絵柄・質感・色・画面密度の参照
  01_world/               夜の街・地図帳・紙片世界
  02_characters/          ユイ、アサ、主要キャラ案
  03_enemies/             黒インクの影、敵シルエット案
  04_items/               記憶の欠片、名札、箱、切符、ランタンなど
  05_ui/                  カードUI、HUD、リザルト、地図帳UI
  06_prompts/             画像生成プロンプト、採用/不採用理由
  99_archive/             不採用・古い案・比較用
```

---

# 2. 採用基準

コンセプト画像は、見た目が良いだけでは採用しない。

```txt
小さいスマホ画面で読める
ドット/紙片/絵本風に寄せられる
黒インクと背景が埋もれない
ゲーム実装で再現できる
Vamp Ponの現行正史と矛盾しない
```

---

# 3. 現行ビジュアル方針

```txt
紙片・絵本風ドット
やさしい不穏さ
黒インクの影
小さなランタン
淡く光る記憶の欠片
紙カードUI
夜の街
暗いが怖すぎない
```

---

# 4. P1で必要なデザイン

P1で必要なのは以下だけ。

```txt
ユイ
黒インクの基本影
夜の鉛筆
記憶の欠片
簡易HUD
ゲームオーバー/リトライ画面
背景1枚
```

P1で不要:

```txt
全キャラ
全武器
50Stage背景
きずなUI
恋愛/友情イベントCG
次世代キャラ
```

---

# 5. ファイル命名

```txt
カテゴリ_内容_案番号.ext
```

例:

```txt
world_night-town_01.png
enemy_ink-shadow-basic_01.png
item_memory-fragment_01.png
ui_card-levelup_01.png
prompt_enemy-ink-shadow_01.md
```

---

# 6. 採用メモの書き方

画像や案を採用する時は、以下を残す。

```txt
採用/保留/却下
理由
弱点
実装で使うなら何を削るか
スマホ画面で読めるか
```

---

# 7. 最重要

コンセプトは濃く。
実装は見やすく軽く。

```txt
見た目で気になる。
遊ぶと意味が変わる。
後から考察したくなる。
```

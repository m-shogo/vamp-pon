# Derived CC0 Assets

This directory is for Vamp Pon adapted assets derived from recorded CC0 raw assets.

Rules:

- Raw files live under `assets/vendor/cc0/`.
- Derived files live here.
- Every source must be recorded in `data/asset-licenses.json`.
- Every adopted asset must also be listed in `docs/third-party-assets.md`.
- Derived assets are still not final until they pass Aseprite hand-finish and the quality gate.
